Card 02 论文概述

论文概述

  • 提出了 Co²Gen 框架，用于在去中心化多机器人协作场景中自动生成任务计划并训练视觉语言动作（VLA）模型，无需人类遥操作。
  • 核心问题是：VLA 模型在单机器人示教数据上微调后，无法在零样本下与其它机器人或人类协作完成操作任务。
  • 解决方案是：利用大型视觉语言模型（VLM）生成可执行的 Python 协作计划，并通过协作蒙特卡洛树搜索（MCTS）在去中心化方式下迭代细化，进而产生协作演示数据。
Card 03 核心贡献

核心贡献

  • 证明 VLA 模型即使经过单机器人任务专属示教微调，也无法泛化到简单的多机器人协作任务。
  • 证明使用协作机器人演示数据进行微调能够显著提升 VLA 在协作任务上的表现。
  • 提出 Co²Gen 框架，通过可执行的 Python 函数将单机器人技能组合成协作计划，并利用 协作 MCTS 以去中心化方式生成该计划。
  • 证明 Co²Gen 生成的演示数据与人类遥控协作演示数据微调的 VLA 在任务性能上可匹敌，且在结合单臂数据时能超越双臂人类遥控基线。
Card 04 方法描述

方法描述

  • 协作计划生成模块：使用两个 VLM 代理（actor 和 critic）进行去中心化协作 MCTS。actor 生成初始可执行 Python 函数，critic 依据进度、子任务分配、条件检查三个准则评分并提供反馈，迭代细化计划。
  • 生成的可执行计划利用 VLM 进行语义前提条件检查（如“黄色方块是否放在中央？”），并根据环境状态调用可用的单机器人技能（如 execute_skill("MOVE_TO_VER")）。
  • 任务执行模块：感知部分使用混合斑点检测和 YOLOv8 通过深度相机估计物体坐标，轨迹规划器利用逆运动学（IK）求解生成轨迹，腕部相机用于精确抓取。
  • 数据生成与微调：成功执行的 robot episode 经人类验证器确认后纳入数据集；数据集按机器人拆分为独立数据流，每个机器人的 VLA 模型在各自数据流上分别微调（去中心化）。微调模式包括仅使用 Co²Gen 数据或与单臂人类演示数据混合。
Card 05 数据集与资源

数据集与资源

  • 使用的数据集：Co²Gen 生成的协作演示数据（每个任务 50 个 episode）；对比使用单臂人类演示数据和双臂人类遥控协作演示数据。
  • 模型规模：VLA 模型为轻量级 SmolVLA（smolvla_base）；VLM 为 GPT-5.6（gpt-5.6-sol）。
  • 机器人平台：SO-101 低功耗双臂机器人，配备 Zed2 立体相机和腕部相机。
  • 训练细节：每个任务微调 20,000 步，并使用 DAgger 收集纠正数据以提升可靠性；未明确提及 GPU/TPU 硬件资源。
Card 06 评估与结果

评估与结果

  • 评估环境：在真实双臂机器人上执行两个协作任务（协作存储任务和协作堆叠任务），分别进行 20 次去中心化执行试验和 10 次人机协作试验。
  • 主要评估指标：整体任务成功率（TSR）、任务分数（TS）和子任务成功率（ST x SR）。
  • 关键实验结果：单臂数据微调的 VLA 在协作任务中表现最差，无法协调；双臂人类遥控数据微调显著改进但成功率仍低于 50%；Co²Gen 数据 + 单臂数据混合微调的 VLA 在存储任务上与双臂基线持平，在堆叠任务上超越双臂基线；人机协作中协作数据仍很重要，但人类适应能力使整体成功率普遍提高。
