MobileVLA-R1 2.0: RL-Enhanced Reasoning for Mobile Robot Control

针对现有VLA系统高层语义推理与底层移动机器人控制（含导航、运动、操控）的固有 gap，以及长时序决策一致性差、跨异构机器人迁移难的问题，提出 MobileVLA-R1 2.0，一个RL增强的VLA框架，显式耦合结构化具身推理与可执行移动机器人控制，支撑语言导航、四足操控、人形移动操控等多类任务

02论文概述

  • 针对现有VLA系统高层语义推理与底层移动机器人控制（含导航、运动、操控）的固有 gap，以及长时序决策一致性差、跨异构机器人迁移难的问题，提出 MobileVLA-R1 2.0，一个RL增强的VLA框架，显式耦合结构化具身推理与可执行移动机器人控制，支撑语言导航、四足操控、人形移动操控等多类任务
  • 框架采用 System-2到System-1到System-0 的推理执行范式，通过多粒度CoT监督和GRPO强化学习优化推理到动作的一致性，引入推理条件动作解码器解耦高层任务级动作生成与机器人特定底层驱动
  • 在VLN-CE、QUARD及Unitree Go2、G1真实机器人的评估中，一致优于强VLA baseline，证明跨移动机器人平台的推理到动作能力迁移

03核心贡献

  • 提出 MobileVLA-R1 2.0，首个显式建立推理到动作接口的RL增强VLA框架，整合多粒度具身推理、CoT对齐与强化学习，实现高层语义推理到底层移动机器人控制的显式grounding
  • 设计推理条件动作解码器，通过交叉注意力将多模态观测与结构化推理表征映射到任务级平面运动指令与离散行为原语，解耦高层动作生成与机器人特定底层驱动，支撑跨异构机器人的能力迁移
  • 构建 MobileVLA-CoT 多粒度具身推理数据集，包含轨迹级、导航级、步级共134K推理标注实例，配套四阶段半自动质量控制流程，为推理到动作学习提供结构化监督
  • 相比会议版本，首次扩展人形机器人G1的真实部署评估，无需G1特定轨迹、演示或微调即可实现移动操控任务，全任务成功率较MobileVLA-R1提升10点
  • 提供更全面的组件分析与真实部署诊断，包含确定性解析与可学习解码的对比、GRPO奖励组件分析、端到端延迟与故障模式分解，验证框架的实用性与鲁棒性

04方法描述

  • 采用分层推理执行架构，多模态输入（RGB图像、深度图、点云、语言指令）经 modality-specific 编码器投影后输入 NaVILA初始化的LLaVA风格多模态骨干，自回归生成结构化CoT推理（包含<think>推理过程与<answer>动作意图文本）
  • 设计推理条件动作解码器，将观测表征与推理表征拼接后经两个可学习动作查询（locomotion与behavior分支）通过交叉注意力提取分支表征，分别回归连续任务级平面运动（$V_x, V_y, \omega$）与预测离散任务级行为原语$\alpha$，输出任务级动作而非机器人特定的关节指令
  • 训练分两阶段：第一阶段监督微调，先使用轨迹级与导航级CoT数据建立长时序推理能力，再使用步级CoT数据对齐推理与动作，联合优化CoT损失、locomotion损失与behavior损失；第二阶段使用GRPO（组相对策略优化）强化学习，以运动奖励、行为奖励、格式奖励为执行感知信号，结合组相对优势与参考策略的KL正则优化推理到动作的一致性
  • 创新点：显式的可学习推理到动作接口，解耦高层决策与底层驱动，多粒度推理监督，GRPO结合多维度奖励的推理动作对齐优化

05数据集与资源

  • 源数据集包括R2R（50K语言导航轨迹样本）、RxR（58K多语言导航样本）、QUARD（262K四足 locomotion 与交互样本）；构建的MobileVLA-CoT数据集总共有134K样本，包含18K轨迹级（Episode）、78K步级（Step）、38K导航级（Nav）推理标注，从168K原始生成经四阶段半自动质量控制（格式有效性、动作一致性、安全性、语义正确性验证）筛选得到
  • 模型规模：骨干为NaVILA初始化的LLaVA风格多模态模型，仅优化投影层、LoRA参数与动作解码器，modality编码器冻结，具体总参数量原文未明确说明

06评估与结果

  • 评估环境：仿真环境包括VLN-CE协议的R2R-CE与RxR-CE验证unseen集、QUARD四足操控基准；真实环境包括Unitree Go2四足机器人、Unitree G1人形机器人的真实部署，G1评估无需任何G1特定轨迹、演示或策略微调
  • 评估指标：VLN-CE采用导航误差（NE，↓）、成功率（SR，↑）、路径长度加权成功率（SPL，↑）、归一化动态时间规整（nDTW，↑）；真实部署采用全任务成功率、端到端延迟、故障模式分类准确率
  • 关键实验结果：

- VLN-CE任务上，MobileVLA-R1 2.0平均SR较MobileVLA-R1提升1.6点，R2R-CE SR达69.7，RxR-CE SR达71.5，均优于所有强VLA baseline

- QUARD四足操控任务上，动作预测精度与任务成功率均优于现有四足VLA方法

- 真实Go2四足导航与交互任务中，长时序指令跟随与闭环执行能力显著提升，故障可分解为运动、感知、操控三类模式

- 真实G1人形移动操控任务（包含物体搜索、导航、目标接近、抓取、搬运、放置等长时序组合任务）中，全任务成功率较MobileVLA-R1提升10点，故障可分解为grounding、导航、抓取、操控执行、底层控制五类，验证框架的泛化性与实用性

- 消融实验验证了推理条件解码器、GRPO优化、多粒度CoT监督各组件的必要性，其中GRPO与解码器的联合优化可进一步提升推理到动作的一致性
