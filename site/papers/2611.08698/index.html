VICTR: Value-Informed In-Context Learning for Vision-Language-Action Models

arXiv 原文 ↗ 中文翻译 ↗

论文提出 VICTR 框架，旨在解决视觉-语言-动作（VLA）模型中基于检索的上下文学习（ICL）依赖视觉相似性、无法准确捕捉任务执行阶段的问题

01研究单位

  • 所有作者均隶属于 纽约大学（New York University）

02论文概述

  • 论文提出 VICTR 框架，旨在解决视觉-语言-动作（VLA）模型中基于检索的上下文学习（ICL）依赖视觉相似性、无法准确捕捉任务执行阶段的问题
  • 核心思想是利用 任务相对进度（task-relative progress） 作为检索信号，通过参考演示视频估计当前观测的执行进度，从而选择与当前阶段对齐的演示片段作为上下文
  • 在真实世界未见过的领域外（OOD）操作任务上，VICTR 显著提升了微调 π0.5 基线的成功率和任务进度率

03核心贡献

  • 提出 In-Context Value Function Estimator (IC-VFE)：以参考演示视频、语言指令和当前观测为条件，估计任务相对进度，无需任务特定微调
  • 提出 VICTR 框架：基于 π0.5 的 ICL 方法，通过进度对齐检索演示片段来指导动作生成
  • 在 8 个域内任务和 8 个域外任务 上进行真实机器人评估，证明进度感知检索将 OOD 成功率从 2.7%（微调 π0.5）和 15.0%（视觉相似性检索）提升至 25.0%
  • 验证 IC-VFE 与人类进度标注的一致性优于现有在线价值估计器（RECAP、Robometer），并证明更好的进度估计可转化为更好的策略性能

04方法描述

  • IC-VFE 结构：使用 Gemma 3 4B 的冻结视觉编码器处理当前和参考观测，Gemma 3 270M 解码器进行进度预测；参考演示被压缩为每视图 16 个摘要 token，当前观测保留 256 个细节 token
  • 混合注意力机制：大多数层使用块内双向注意力，在特定层（第 6、12、18 层）使用块因果注意力实现参考演示的时间聚合；引入可学习的块索引嵌入编码顺序信息
  • 进度预测头：将输出映射到 201 个离散 bin（支持 -1 到 0），通过 softmax 后取期望并平移至 [0,1] 得到连续进度值
  • 检索与策略：演示池被索引为键值存储，键包含 IC-VFE 估计的进度和 DINOv2 视觉嵌入；检索时选择进度距离最小的示范块；IC-VLA 将检索到的上下文块、当前观测和指令拼接后预测动作块
  • 训练监督：IC-VFE 使用 Robo-Dopamine 生成的离线进度伪标签训练；IC-VLA 基于 π0.5 官方 checkpoint 微调，训练时使用 oracle 进度值采样上下文，部署时使用 IC-VFE 估计

05数据集与资源

  • 自建真实机器人数据集：28 个任务，1,180 条 episodes，总计 7.5 小时（7 小时训练，30 分钟演示池）
  • 演示池：每个评估任务提供 10 条上下文演示，其中最短的作为 IC-VFE 的参考演示
  • 机器人平台：YOR 双手机器人，头部 ZED 相机和两个腕部鱼眼相机，两个 7-DoF AgileX Piper 机械臂
  • 模型规模：IC-VFE 使用 Gemma 3 4B 视觉编码器 + 270M 解码器；IC-VLA 基于 π0.5（参数规模未具体说明）
  • 训练资源：使用 NVIDIA RTX 6000 Ada GPUs（由 NVIDIA Academic Grant Program 提供）；计算支持来自 NYU IT 高性能计算资源

06评估与结果

  • 评估环境：真实机器人，8 个域内任务和 8 个域外任务（包含新物体替换、技能组合、语义相似但未见任务）；每任务 10 次 rollout
  • 主要指标：二值成功率（binary success rate）和任务进度率（task progress rate，基于预定义里程碑）
  • 主结果（OOD）：微调 π0.5 基线成功率 6.2%、进度率 28.9%；RICL-π0.5（无插值）成功率 15.0%、进度率 42.1%；VICTR 成功率 23.8%、进度率 55.5%；VICTR+vision 成功率 21.2%、进度率 47.8%
  • 域内结果：所有检索方法进度率 87.5%-90%，对比 π0.5 的 82.2%，差异较小
  • IC-VFE 质量：在 16 个评估任务上与人类标注的 Kendall τb 和 Pearson r 均优于 RECAP、Robometer 及无上下文/无块嵌入消融基线
  • VFE 部署影响：使用 IC-VFE 检索的 OOD 进度率达 62.7%，远高于 Robometer（29.2%）等替代方案
  • 消融研究：演示池大小从 1 增至 5 时性能提升并趋于饱和；训练与部署使用相同检索信号时性能最佳，但交换后仍具一定泛化能力
