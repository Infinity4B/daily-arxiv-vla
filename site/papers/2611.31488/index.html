02论文概述

  • 针对当前端到端视觉‑语言‑动作（VLA）系统在真实世界部署中面临的泛化脆弱、物理/因果推理不足、细粒度运动控制不一致以及缺乏审计能力等问题，提出一种面向部署的 Embodied Neuro-Symbolic (NeSy) AI 范式。
  • 核心思想是将神经感知、规划与控制同显式、机器可读的背景知识及形式化约束相结合，使机器人行为具备可审计性、安全性和可扩展性。

03核心贡献

  • 提出 Embodied NeSy AI 框架，将知识引导的语义感知、约束感知的符号规划和混合学习三大组件紧密集成，支持机器人行为的审计、安全和规模化部署。
  • 将显式知识表示（本体、知识图谱、约束规范）作为贯穿感知、规划、学习的统一接口，使领域知识、操作流程、产品/工具元数据和安全规则成为决策循环中可查询、可更新的部分。
  • 设计不确定性感知的符号信念状态，通过为每个三元组附加出处（如 VLM、CAD）和置信度，使下游符号规划器能够对低置信度信息进行门控，提高系统在模糊和新奇条件下的鲁棒性。
  • 通过精密螺钉紧固用例演示三阶段流水线：感知输出带出处和置信度的 KG 三元组，规划器基于本体公理和 KG 查询生成经约束验证的动作序列，混合学习在三个更新流（感知、知识、规划）中持续改进。
  • 论证了该框架在制造单元、家庭与人形机器人、自主移动以及仿真评估等多个应用领域的可推广性。

04方法描述

  • 知识引导的语义感知：使用 VLM 或 VLA 的感知编码器（或 Grounded-SAM 等类型化感知原语）在本体词汇引导下处理 RGB‑D、力觉和关节编码器等输入，提取对象类型、属性、几何关系和任务相关谓词，同时跟踪每种事实的不确定性。输出为可查询的信念状态（知识图谱三元组+逻辑谓词）。
  • 约束感知的符号规划：利用 PDDL、HTN、TAMP 或 LLM 代码生成器（如 Code-as-Policies、Graph-as-Policy）等符号规划形式，基于任务目标、本体公理和 KG 查询结果，生成满足安全和操作约束的动作序列（如扭矩上限、线程匹配、禁止区域）。所有计划在执行前都经过机器可检查的验证。
  • 混合学习：采用神经参数（梯度）更新与符号工件（离散）更新并行的机制，神经证据驱动符号更新，符号约束正则化神经更新。具体包含三个更新流：感知更新改善 grounding 精度和不确定性校准；知识更新扩展和细化 KG 规则（如扭矩表值由 0.60 Nm 调整为 0.55 Nm）；规划更新从执行轨迹中调优启发式和控制器策略。
  • 用例说明：精密螺钉紧固任务中，感知输出示例为三元组（如 (screw_12, threadSize, "M3") [VLM, 0.70]），规划器查询如 compatible(screw_12, hole_A)?，并分解动作序列 pick → align → insert → tighten → verify_torque，其中 tighten 步骤强制执行扭矩 ≤ 0.6 Nm 和扭矩斜率阈值以防止交叉螺纹。
