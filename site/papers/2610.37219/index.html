论文概述

  • 提出 Just Action Model（JAM）：一个统一框架，用预训练视觉骨干加动作专家，通过动作损失和“前瞻损失（foresight loss）”训练，无需任何图像/视频生成即可利用未来观测改善控制
Card 03 核心贡献

核心贡献

  • 提出 JAM 单一配方：记录的未来观测仅作为冻结的预测目标进入训练，前瞻分支（未来锚点+预测头）在训练后丢弃，部署时不增加任何推理开销
  • 在固定策略架构的对照实验中证明前瞻监督可替代视觉生成损失，同时保持或提升成功率；未来位置的目标比当前位置目标更有效，最佳目标表示依赖骨干类型（Wan 骨干用纯 VAE 特征即可）
  • 将同一前瞻目标应用于生成式、自监督和视觉语言三类骨干（Ovis-U1、DINOv2、Qwen3.5-2B），均超过 ImageWAM 基线
  • 借助缓存的前瞻目标，JAM 相对 FastWAM 将每个样本每次更新的在线训练 FLOPs 估计值降低 73%（ImageWAM 降低 36.8%）
  • 分析表明骨干预训练对策略性能至关重要，而未来锚点（目标分支）可用随机初始化的冻结骨干，二者角色解耦
Card 04 方法描述

方法描述

  • 策略由预训练视觉骨干 + 动作专家组成，动作专家沿用 flow matching 动作损失 $\mathcal{L}_{\mathrm{act}}$；总损失为 $\mathcal{L}_{\mathrm{JAM}}=\mathcal{L}_{\mathrm{act}}+\lambda_{\mathrm{F}}\mathcal{L}_{\mathrm{F}}$
  • 前瞻损失：冻结的“未来锚点”$E_\varphi$ 编码记录的未来观测提供目标 $\mathbf{g}_k$；可训练的预测头（小型 token-mixing transformer，每个偏移一个线性读出）将当前观测 token 映射到目标空间，以余弦距离监督（目标端 stop-gradient）
  • 训练与推理解耦：锚点分支和预测头仅训练时使用，训练后丢弃；部署时骨干编码当前观测与指令，动作专家复用上下文进行流匹配采样，训练和推理均不生成任何未来帧
  • 关键配置：策略与锚点在约 60% 深度处读取特征（如 Wan 第 18/30 块、Yak 第 11/18 层）；前瞻读出偏移选择对性能影响显著（未来偏移 [1]/[1,2] 优于当前偏移 [0]）
Card 05 数据集与资源

数据集与资源

  • 基准：LIBERO（Spatial/Object/Goal/Long 四套件，40 任务 × 50 rollouts）、LIBERO-Plus（按 15% 子集协议抽取 1,506 个扰动任务）、RoboTwin 2.0（50 个双臂任务，Clean 与 Randomized 两种设置）
  • 骨干规模：Wan2.2-5B（FastWAM 视频）、Yak18/Ovis-U1（1.13B，ImageWAM 图像编辑）、DINOv2-B（86.6M）、DINOv2-L（304M）、Qwen3.5-2B（2.0B）
  • 训练预算遵循 FastWAM/ImageWAM 原始配方：LIBERO 上 FastWAM 配方 20k 更新、ImageWAM 配方 21.7k 更新（全局 batch 128）；RoboTwin 2.0 上 5 个 epoch（FastWAM 29,355 更新 @ batch 1024，ImageWAM 69,900 更新 @ batch 384）
  • 前瞻损失权重：Wan 为 $\lambda_F=0.6$，其他策略为 0.3（论文正文未披露具体 GPU 型号/数量）
Card 06 评估与结果

评估与结果

  • 评估采用成功率为主指标，并与已发表系统（FastWAM、ImageWAM 等）在相同评测协议下对比
  • 替代生成损失的对照实验（LIBERO / LIBERO-Plus）：JAM (Wan) 最佳目标（预训练 VAE）达 98.15% / 64.54%，优于 FastWAM 的 97.00% / 55.31%；JAM (Ovis-U1) 达 96.75% / 79.95%，优于 ImageWAM 的 92.90% / 65.27%
  • 跨骨干对比（LIBERO-Plus）：JAM (Ovis-U1) 79.95%、JAM (DINOv2-L) 70.39%、JAM (Qwen3.5-2B) 81.14%，全部超过 ImageWAM (Ovis-U1) 的 65.27%；DINOv2-B 为 68.19%
  • RoboTwin 上 JAM 与 FastWAM 成功率相近或略高（91.2% → 91.4%）；消融显示未来帧信息在 JAM 特征中更易解码（未来帧 PSNR 更高）
  • 注意力分析表明不同骨干的动作接口注意力分配不同：DINOv2-L 偏向图像键、JAM (Ovis-U1) 偏向文本键、Qwen3.5-2B 偏向动作键
  • 结论：未来监督可在无视觉生成、无额外推理模块的前提下提升控制性能，且生成式初始化与视觉语言骨干均可达到强前瞻性能
