ActionCodec2: A Streaming Action Tokenizer

02论文概述

  • 提出 ActionCodec2，一种非神经的流式动作分词器，用于自回归视觉-语言-动作（VLA）模型，逐步释放动作而非等待整个动作块解码完成。
  • 解决现有块式动作分词器无法在块内利用状态反馈、轨迹误差累积导致漂移的问题。
  • 目标是在保证轨迹重构误差有界的前提下，实现高效的流式动作离散化，并提升 VLA 在仿真和真实机器人任务中的性能。

03核心贡献

  • 将有界误差流式动作分词形式化为覆盖问题，证明“固定运动基元”在单符号每步解码器中的最优性，给出平移情形的精确解和旋转情形的常数因子紧界。
  • 提出 Set-BPE 算法，无损合并跨坐标和相邻步共现的基元符号，不依赖固定坐标顺序，相比标准 BPE 在 held-out 数据上降低 token 数 6.6%–10.7%。
  • 在相同 VLA 骨干（G0.5）下取得领先结果：LIBERO 成功率 98.2%，SimplerEnv 93.8%，LIBERO-Plus 79.5%，并在四个零射击 Franka 任务上平均任务进展 73.9%，优于 FAST、OAT、X-Tokenizer 和 ActionCodec。
  • 展示流式表示的优势：允许策略在动作块内纳入状态反馈，在随机化动力学、外部扰动和移动物体等闭环设置下显著优于开环执行。
  • 验证 ActionCodec2 tokens 可作为 VLM 智能体的直接控制接口，智能体可将成功 token 序列组合为可复用的宏，减少控制决策和思考 token 使用，并迁移到新任务。

04方法描述

  • 流式量化与误差反馈：编码器维护与解码器相同的重构状态，每步基于当前跟踪误差选择运动基元，将残差误差纠正到容差范围内，避免独立量化导致的误差累积。
  • 最小基元集推导：将有界误差流式编码转化为集合覆盖问题（\(\mathcal{E}\mathcal{A} \subseteq \bigcup_{u\in\mathcal{U}} u\mathcal{E}\)），对平移得到闭式解 \(K^*_{\rm trans} = \prod_j \lceil 1 + \Delta a_j/(2\epsilon_j) \rceil\)，对旋转利用测地体体积给出紧界。
  • Set-BPE 无损打包：在基元原子序列上执行顺序无关的字节对编码，先合并步内共现原子，再合并相邻步模式，不固定坐标顺序，从而捕获协调运动模式。
  • 非梯度拟合：基元集合由运动边界和容差解析确定；Set-BPE 通过统计符号共现学习合并，无需反向传播或学习式码本。
  • 通用版本：在约 20k 小时、24 种 embodiment 的数据上拟合 universal ActionCodec2，适用于不同机器人和任务。

05数据集与资源

  • 仿真基准：LIBERO、LIBERO-Plus、SimplerEnv-WidowX、DROID-Franka（用于零射击真实机器人评估）。
  • 训练数据规模：通用 tokenizer 使用约 20,000 小时、来自 24 种 embodiment 的机器人数据。
  • 模型骨干：G0.5 VLA（具体参数量未在正文明确给出）。
  • 训练硬件：论文未明确列出 GPU/TPU 配置，仅说明非神经 tokenizer 的拟合无需梯度优化，因此主要计算成本来自 VLA 训练。

06评估与结果

  • 重放保真度测试（LIBERO 演示数据）：原始演示成功率 100%；FAST 单步重构误差 1mm 但累计漂移约 40mm，成功率仅 90%；其余块式基线≤80%；ActionCodec2 漂移低于 5mm，成功率 97%。
  • 仿真基准成功率：

- LIBERO: 98.2%

- SimplerEnv: 93.8%

- LIBERO-Plus: 79.5%

- 对比方法：FAST、OAT、X-Tokenizer、ActionCodec

  • 零射击真实机器人（Franka 任务）：平均任务进展 73.9%。
  • 闭环反馈性能：在随机物理参数、随机外力与随机运动、移动物体等环境下，流式反馈显著优于开环执行；支持在动作块内每步融入新观测。
  • Token 效率：15Hz 末端执行器控制平均 8.8 tokens/s，关节控制 10.8 tokens/s。
  • VLM 智能体控制实验：ActionCodec2 tokens 作为控制接口，智能体构建的宏可跨尝试复用并迁移到 held-out 任务，减少控制决策和思考 token 使用。
