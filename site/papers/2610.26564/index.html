02论文概述

  • 论文提出 PrismWAM，用于解耦世界动作模型（WAM）中的状态表示，将“世界如何看起来”的语义上下文与“世界如何响应动作”的物理状态分离。
  • 现有 WAM 依赖预训练视频潜变量，导致外观、纹理等语义信息与占用、姿态等物理信息纠缠，限制了动作生成的效率与泛化。
  • 论文将具身任务分解为 语义规划 → 物理推演 → 可执行动作 的流程，仅使用初始 RGB 观测与深度数据，在不依赖具身动作预训练的情况下实现强操作性能。

03核心贡献

  • 提出 WAM 状态表示解耦原则：识别视频潜变量中语义与物理纠缠是现有 WAM 的关键局限，主张将语义上下文与物理状态分离建模。
  • 设计高效且有效的 WAM 架构：采用 Mixture-of-Transformers（MoT），通过 RGB 语义规划器引导深度物理推演，并结合稠密深度监督与稀疏 RGB 目标监督，实现快速推理。
  • 在无具身动作预训练条件下取得领先表现：在精度操作与泛化任务上显著超越多种 VLA/WAM 基线，证明合理架构设计可以比大规模动作预训练提供更数据高效的路径。
  • 展现跨基准与真实世界鲁棒性：在 RoboTwin、LIBERO 系列、RoboDojo 等五个仿真基准及真实世界操作中验证，并对真实感深度损坏具有稳健性。

04方法描述

  • 总体框架：将任务分解为 语义规划（Semantic Planning）→ 物理推演（Physical Rollout）→ 可执行动作（Executable Action），而不是用单一视频潜变量作为状态。
  • 表示选择：RGB 流通过预测单一未来目标帧学习任务语义；深度流预测稠密未来深度序列以建模物理状态演化；动作塔从深度推演特征生成连续动作。
  • 架构设计：基于预训练视频模型 WAN，采用 Mixture-of-Transformers（MoT） 架构；RGB 与深度流共享视觉块，动作块独立参数化。
  • 链式注意力（Chain Attention）：控制跨模态信息流，动作塔仅通过深度推演特征间接获取语义上下文，不直接访问 RGB 或未来 RGB，从而强化语义与物理的角色解耦。
  • 训练策略：深度 VAE 使用约 2300 小时深度数据预训练；策略训练分两阶段，先进行深度预测适配，再联合优化 RGB 目标预测、稠密深度预测与动作预测的流匹配目标。
  • 推理过程：缓存初始 RGB 特征作为语义引导，不生成未来 RGB；深度潜变量与动作块从高斯噪声联合去噪，直接输出动作，无需解码深度图。

05数据集与资源

  • 仿真基准：RoboTwin-C2R、LIBERO、LIBERO-Plus、LIBERO-Pro、RoboDojo，覆盖分布内操作和分布外迁移。
  • 深度预训练数据：约 2,300 小时深度数据，用于深度 VAE 预训练。
  • 模型基础：以预训练视频模型 WAN 为骨干；RGB 与深度 VAE、T5 在策略训练中保持冻结。
  • 模型变体：提供标准版 PrismWAM 和扩大版 PrismWAM*（论文中用于部分最强结果）。
  • 训练资源：原文未明确披露 GPU/TPU 数量及具体模型参数量。

06评估与结果

  • RoboTwin-C2R：PrismWAM* 平均成功率 83.67%（Clean 91.84% / Random 75.50%），远超 FastWAM（39.85%）和 OpenWAM-α（69.05%）；不依赖动作预训练的 PrismWAM 在随机场景下比 starVLA 高 50.00 pp，比 FastWAM 高 51.26 pp。
  • RoboDojo：PrismWAM* 总分 36.23，成功率 29.30%；在 Precision 任务上比 OpenWAM-α 高 21.37 pp，体现精度操作优势。
  • LIBERO 系列：LIBERO 总体成功率 99.35%，LIBERO-Plus 总体 79.44%，LIBERO-Pro 总体 54.48%；在布局扰动、光照变化、物体属性改变等迁移任务上优于 FastWAM 和 OpenWAM-α。
  • 鲁棒性分析：在真实感深度损坏（Metric Jitter、Edge Missing、Patch Hole）下，最强损坏级别下平均性能仅下降 2.45 pp，表明对深度噪声与缺失具有较强稳健性。
  • 消融实验：移除 RGB 或深度流均降低性能；允许 RGB 直接到动作或深度访问未来 RGB 会削弱泛化；完整设计取得最佳 Clean/Random 平均。
