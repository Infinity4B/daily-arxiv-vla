Card 02 论文概述

论文概述

  • 提出一个模块化推理框架，将 Flow Matching 生成模型 与 Control Barrier Function (CBF) 形式化安全保证深度融合
  • 不同于对模型最终输出施加外部安全过滤器，该方法在 Flow Matching 内部修改去噪过程，内在生成安全轨迹
  • 通过平滑的 Log-Sum-Exponential 聚合障碍函数 在整个动作块上执行安全约束，计算开销极小且不改变模型语义意图
Card 03 核心贡献

核心贡献

  • 将 CBF 集成到 Flow Matching 推理过程中，实现生成式策略的安全控制
  • 提供可证明的安全保证，并分析保证安全生成的条件
  • 使用 Log-Sum-Exponential 聚合安全约束，同时对轨迹平滑性进行优化
  • 在多个真实机器人硬件平台和 2D 导航基准上验证框架性能，并与现有方法对比
Card 04 方法描述

方法描述

  • 在 Flow Matching 的常微分方程中引入安全修正项 δ_s，通过求解 CBF 二次规划 得到最小调整量
  • 利用 Log-Sum-Exponential 平滑函数将逐点安全约束聚合为整个动作块的单一连续可微障碍函数，避免 min 算子不可导问题
  • 仅在去噪晚期（τ ∈ [τ_s, 1]）施加安全过滤，早期噪声状态无物理意义，降低计算开销
  • 进行分布偏移分析，证明修改后的生成分布与目标分布之间的 2-Wasserstein 距离保持有界，不会导致分布外样本
Card 05 数据集与资源

数据集与资源

  • 论文使用预训练 VLA 模型（如 SmolVLA，约 550M 参数）作为基座，无需额外安全数据集或模型重训练
  • 实验平台包括 2D 迷宫仿真环境及两个真实机器人操作平台（例如 SO-101 机器人）
  • 方法可在便携式计算机上完成推理，计算开销低
Card 06 评估与结果

评估与结果

  • 在 Maze 2D 导航任务中与 Safe Diffuser 等现有安全规划方法对比，验证了框架的安全性和成功率
  • 在实际机器人操作任务中，部署基于 SmolVLA 的安全 VLA，结果表明安全过滤不降低任务成功率，且维持较高的安全裕度
  • 通过消融实验分析了平滑参数 κ 和安全过滤起始时间 τ_s 对安全性能的影响，验证了理论分析
