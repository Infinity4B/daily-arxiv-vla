Card 03 核心贡献

核心贡献

  • Gym-Anything for Robotics 框架：模块化的多智能体流水线，可自动构建高质量机器人仿真，并首次定义了“好仿真”（10 项标准）与“好任务”（6 项标准）的规范
  • RoboWorld 基准：25 个基于 GDP 数据的仿真，包含 25 个测试与 175 个训练 RL 环境（共 200 个），支持可更换机器人（单臂、双臂、人形）及物体位姿、外观、物理属性的变化
  • 评估发现：前沿模型在 RoboWorld 全部测试任务上失败，完整基准上无一模型得分超过 0%，平均奖励仅 0.06
  • 多种新学习范式：上下文内学习、特权状态教师-学生教学、模型从自身特权经验中学习、代码策略生成演示训练 VLA（如 π₀.₅）
  • 发布流水线、RL 环境与基准，促进后续研究
Card 04 方法描述

方法描述

  • GDP 引导的仿真选择：将各职业任务分解为原子物理动作，按经济价值加权，用优化方法选出覆盖最有价值物理工作的动作组（共选出 120 组，构建 25 组），不局限于现有仿真器支持的物理现象
  • 创建-审计循环：创建智能体（基于 Claude Opus 5.5，通过 Claude Code 运行）用代码构建仿真并产出证据（渲染、物理测量、辅助演示），4 个独立审计智能体（含对抗性智能体）按真实性、可解性、速度、抗漏洞四大类标准审查，共 3 轮迭代，所有智能体共享经验记忆
  • 任务创建-审计循环：任务创建智能体为每个仿真生成约 5 个不同难度的任务，6 个审计智能体分别检查意义性、场景适配、验证器正确性、可解性、奖励质量与难度覆盖；用强弱模型（Claude Haiku 5.5 与 Claude Opus 5.5）测量难度并控制任务难度梯度
  • 特权状态学习方法：利用仿真提供的全真值状态设计三种学习信号传递方式——教师通过定性提示教学生、模型从自身特权经验学习、特权代码策略生成演示数据训练仅观察相机图像和本体感觉的 VLA
Card 05 数据集与资源

数据集与资源

  • RoboWorld：200 个 RL 环境（25 测试 + 175 训练），覆盖制造、建筑、餐饮、家庭、实验室、医疗、物流、体育、教育等领域
  • 物理现象覆盖：液体、化学反应、布料、熔融金属、颗粒土壤、膏体、软组织、声学等
  • 机器人类型：单臂（如 Panda、FR3）、双臂（如 UR10e+FR3）、移动操作平台、人形机器人（如 Unitree G1、H1-2），共支持多种机器人配置互换
  • 仿真实现细节示例：酒水倾倒使用 DFSPH 流体（2mm 粒子，每瓶 93,750 粒子）、滴定使用 348,160 粒子并携带化学物种、衣物折叠采用各向异性膜模型
  • 所用模型：Claude Opus 5.5（创建/审计智能体）、Claude Haiku 5.5（难度测量）、VLA 模型 π₀.₅（Physical Intelligence）
Card 06 评估与结果

评估与结果

  • 评估设置：每个任务支持受限访问（仅相机图像与机器人反馈）与特权访问（完整仿真状态）两种模式；奖励为 [0,1] 连续值，同时衡量进展与结果
  • 主要结果：最强前沿模型在 RoboWorld 全部 25 个测试任务上全部失败，平均奖励仅 0.06；在较简单的 25 个任务子集上最佳模型达到 32%
  • 任务成功率随机器人自由度增加而下降
  • 学习效果显著：通过代码策略生成多场景演示训练后，π₀.₅ 成功率从 0% 提升至 53%；上下文内学习可持续改进前沿模型表现，且特权状态加速学习；特权教师可通过语言提示将能力传递给学生模型
  • 仿真质量：与 SoftGym、ManiSkill2、Chemistry3D、GarmentLab 等最接近的既有仿真相比，RoboWorld 对关键物理（如瓶中空气滞留导致的咕咚声、滴定局部变色、衣物摩擦抓取）建模更精细，并通过 6-12 项真实物理量校验（如静水压力、晃动频率、物种守恒）验证
