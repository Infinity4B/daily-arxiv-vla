Card 02 论文概述

  • 解决导航成功率无法区分模型是真正遵循指令还是依赖视觉线索或历史的问题
  • 通过路线分叉处的反事实语言对，评估指令变化是否影响动作概率分布
Card 03 核心贡献

核心贡献

  • 构建 NavBind 数据集：从 R2R-CE 和 RxR-CE 重组指令片段，生成两个可行分支的完整指令对，保持代理状态、导航历史和已完成指令前缀一致
  • 提出三种互补诊断方式：生成动作序列变化、固定目标动作似然比较、视觉注意力和梯度归因热图变化
  • 发现更高的导航成功率并不等同于更忠实的指令遵循，支持在导航成功之外评估语言对局部决策的影响
  • 提供 3,252 个共享上下文，覆盖 1,648 个源路线对，供所有模型统一评估
Card 04 方法描述

方法描述

  • 路线对齐源对构造：利用细粒度子指令注释（FGR2R、Landmark-RxR），识别在同一场景中共享一段路径后在分叉处分开的路线对
  • 前缀-后缀重组：将完整指令在分叉点切割为描述已完成路线的前缀和指定不同分支的后缀，交叉配对生成干预指令
  • 固定上下文诊断：保持导航历史和分叉状态不变，比较不同后缀下的生成序列、参考动作序列似然（NLL），以及视觉注意力和梯度归因的 IoU
Card 05 数据集与资源

数据集与资源

  • 使用 R2R-CE 和 RxR-CE 数据集及其细粒度注释（FGR2R、Landmark-RxR）
  • 构建 NavBind 集：包含 3,252 个上下文，来自 1,648 个源路线对
  • 评估四个导航 VLA 模型：Uni-NaVid、StreamVLN、JanusVLN、FutureNav（均为已发布检查点）

Card 06 评估与结果

评估与结果

  • 评估环境：使用四动作接口（Forward, Left, Right, Stop），动作区间 K=4，遵循各模型原生的动作增量和解码策略
  • 主要指标：生成序列相同率（Same seq.）、固定目标似然差异（\(\bar{d}\)）、Both+ 百分比、KL 散度、注意力/梯度热图 IoU
  • 关键结果：

- Uni-NaVid 报告成功率最高（56.1%），但其诊断分数（如 Both+ 仅 29.15%）低于 StreamVLN（\(\bar{d}=0.8360\)）

- StreamVLN 与 FutureNav 成功率相近（54.4% vs 54.5%），但 StreamVLN 在 \(\bar{d}\)、Both+、KL 上均显著更高

- 更长的指令前缀导致模型对剩余指令的响应更弱（Same seq. 升高，\(\bar{d}\) 和 KL 下降）

- 左转-右转（L/R）对比比前进-转弯（F/L、F/R）对比引起更强的指令响应

- 注意力差异最大的位置与两个参考动作序列首次分叉的位置一致
