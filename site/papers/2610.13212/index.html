论文概述

Card 03 核心贡献

核心贡献

  • 提出 VLA 目标学习的三个耦合要求：从当前观测可预测性、任务相关未来变化的信息量、以及连续动作可执行性。
  • 提出 AFCE，一种时序 Effect 表示：通过联合重构"已执行动作、真实机器人响应、稀疏世界变化"来从共享表示中学习。
  • 设计两阶段训练流程：Stage I 学习可执行的未来锚定 Effect；Stage II 用流匹配 VLA 预测 Effect 并由状态条件解码器还原动作。
  • 引入跨本体因子化设计：不同单/双臂配置使用各自适配器，但共享 Effect 形状与主干，实现异构示教的混合训练。
  • 通过重构、GT-Effect 回放、预测-Effect 闭环控制三类实验分别评估表示与完整策略，在混合单/双臂训练下取得总体增益，同时明确指出细粒度控制仍存在的局限。
Card 04 方法描述

方法描述

  • Stage I（Effect 分词器 T_φ）：输入为动作序列 A_t、机器人真实响应 ΔS_t（掌部平移、相对姿态、指尖位移、指关节变化）、以及由冻结 DINOv3 特征采样的稀疏视觉转移 V_t，输出有序 Effect 令牌 **E\*_t ∈ R^{H×D_E}**。
  • 先融合后压缩：先由步级查询经交叉注意力融合各模态证据，再由时序 Transformer 在整窗口内交换信息，保留每个令牌的时序位置。超参为 H=30、D_E=256。
  • 可执行瓶颈监督：状态条件解码器 **D_ψ(E\*_t, s_t) 重构示教动作；损失为分组 Huber 动作损失（位置权重 2、旋转、手指按 1/3 平均）、状态重构、稀疏视觉重构，并加 SO(3) chordal 旋转正则**。
  • Stage II（流匹配 VLA）：冻结 T_φ 并缓存 Effect 输出，用固定统计量归一化得到目标 **Z\*_t；将 π_0.5 的动作输入/输出投影替换为宽度 D_E 的投影，用条件流匹配损失 L_FM** 学习从噪声到 Effect 的速度场。
  • 动作锚定预测：在干净端点估计上叠加 GT 动作辅助损失 L_GT 与手指相邻差分损失 L_Δf，总目标为 L_II = L_FM + r(u)·E_τ[g(τ)(λ_GT·L_GT + λ_Δf·L_Δf)]，解码器与策略联合、以较小学习率更新。
  • 部署与跨本体：部署时只使用当前图像、指令与机器人状态预测 Effect，再由 N^{-1} 反归一化并解码为动作块，执行前缀后重新规划；单/双臂通过 f^e_A、f^e_S、D^e_ψ 等配置专属接口共享同一 Effect 主干。

Card 06 评估与结果

评估与结果

  • 对比方法：UVT 与官方发布的 DexJoCo π_0.5 多任务检查点。
  • 评测协议：每任务 50 个回合 × 3 个环境种子（0/1/2），每方法共 1,650 个回合；报告跨评测种子的均值与样本标准差（非独立训练重复）。
  • 总体性能：AFCE 达到 50.97 ± 1.65%（841/1,650），比 π_0.5（39.15 ± 2.11%）高 11.82 个百分点，比 UVT（35.76 ± 0.56%）高 15.21 个百分点；在 7 个任务上取得最高均值。
  • 双臂操作：在全部五个双臂任务上领先，均值 37.33%，对比 π_0.5 的 9.73% 与 UVT 的 14.53%；最大增益出现在 Microwave（81.33% vs 32.00%）与 Photograph（59.33% vs 8.00%），Hanoi 从 5.33% 提升至 29.33%。
  • 单臂操作：均值 62.33%，略低于 π_0.5 的 63.67%，但高于 UVT 的 53.44%；在 Hammer Nail、Pick Bucket 上领先，Fold Glasses 提升明显（62.00% vs 38.00%）；Pinch Tongs 出现最大回退（5.33% vs 43.33%）。
  • 增益来源分析：双臂相对 π_0.5 的 27.60 点增益贡献约 12.55 点，单臂 1.34 点劣势抵消约 0.73 点，净增益 11.82 点；种子 0 上双臂失败率由 76% 降至 26%、协调类由 95% 降至 79%，但 Precision（51.3%→58.7%）与 Tool use（11%→13%）失败率上升。
  • Effect 维度敏感性（表 2）：d=256 时位置误差 7.794、双臂位置误差 9.507、FK 误差 10.519，GT-Effect 回放为 SA 20/60、BA 5/50、All 25/110；d 减小到 128、64 时误差升高、回放成功率下降，表明 256 维最优。
  • 结论与局限：Effect 监督对协调性灵巧操作价值显著，但细粒度单臂精密控制仍具挑战，且尚无证据表明不同本体产生了完全一致的 Effect 编码或本体不变对齐。
