Don't Lose the Future: Latent-Aware 4-Bit Quantization of World Action Models

02论文概述

  • 论文研究世界动作模型（WAMs）的 4 位量化部署问题，目标是使模型在机器人机载计算机上以 W4A4KV4 精度运行。
  • 现有量化方法只保护动作生成路径，忽略了预测未来的保真度，导致动作误差主要通过退化的未来进入。
  • 提出 LAQ（latent-aware quantization） 框架，在预测未来的写入、存储和读取环节均进行精度保护，从而实现可靠的闭环动作。

03核心贡献

  • 识别未来潜在保真度为 WAM 量化的关键目标：保护动作路径后，仍有 71.2% 的剩余动作误差来自退化的预测未来，且写一次读多次的舍入误差损害最大。
  • 提出 LAQ 框架：引入 reader metric（衡量未来误差对动作的影响）和 read count（衡量舍入误差在去噪步中的累积效应），得到激活与缓存精度分配的闭式解。
  • 开发 gaze-guided refinement：根据动作 token 的注意力实时选择关键 token，为其赋予第二个 4-bit 量化编码，进一步提升精度。
  • 在 LIBERO-Plus 和真实机器人上验证：LAQ 达到与 BF16 模型接近的成功率，显著优于现有量化基线，且模型压缩 3.8 倍，峰值 GPU 内存降低 2.3 倍，推理速度提升 1.66 倍。

04方法描述

  • Reader metric：通过线性化 reader 并计算 Gauss-Newton 矩阵，衡量预测未来误差对动作的影响，离线估计并混合单位矩阵以保证稳定性。
  • Read count：通过干预实验量化舍入误差在去噪步中冻结与重绘的比率，得到误差源的累积读取次数，用于加权灵敏度。
  • Joint allocation：将动作、未来和 reader 误差统一为目标函数，利用阈值决定哪些 token 在去噪循环和缓存中获得更高精度，实现闭式分配。
  • Gaze-guided refinement：对选中 token 的激活残差进行第二次 4-bit 量化，缓存则存储第二个 4-bit 码；运行时通过动作 token 的 attention 确定 gaze，无需额外训练或任务校准。

05数据集与资源

  • 数据集：LIBERO-Plus（对四个 LIBERO 套件进行七维扰动）、LIBERO 原始套件、真实机器人任务数据（AgileX PiPER 臂，每任务 75-80 个演示）。
  • 模型规模：Fast-WAM（6B 参数，其中 1B 动作专家）、Cosmos-Policy（2B 参数）。
  • 校准资源：使用 80 个 LIBERO 上下文进行离线校准，论文未明确说明具体 GPU 型号。

06评估与结果

  • 评估环境：LIBERO-Plus 和 LIBERO 模拟基准，以及真实 AgileX PiPER 机械臂。
  • 主要指标：平均成功率（%）、模型压缩比、峰值 GPU 内存、推理速度。
  • 关键结果：在 LIBERO-Plus 上，LAQ 使 Fast-WAM 达到 76.4% 平均成功率（BF16 为 77.6%，最强基线 SVDQuant 为 73.0%）；Cosmos-Policy 达到 83.3%（BF16 为 83.5%）。真实机器人上，LAQ 平均成功率 47.0%（BF16 为 52.0%，QuaRot 为 17.0%）。
