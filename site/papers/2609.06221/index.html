02论文概述

  • 解决语言引导机器人操作中的identity switch问题：机器人在杂乱场景中对重复对象、模糊锚点或依赖帧的空间术语执行几何有效但非预期的操作
  • 将指称解析形式化为对三个耦合潜变量（target, anchor, reference frame）的联合后验推断
  • 提出RefGuard框架，通过延迟承诺保持指称不确定性，直到决策阶段，支持execute/clarify/reobserve/abort四种决策

03核心贡献

  • 将identity switch识别为一种失败模式，形式化为对target, anchor, reference frame三个耦合变量的联合推断
  • 引入RefGuard，基于双层场景图（分离帧无关几何与方向关系）和联合目标-锚点-帧后验推断，支持execute/clarify/reobserve/abort决策
  • 在UF850真实机器人六组应力测试和3,200集过程套件中验证，显著降低identity switch同时保持高执行覆盖率
  • 通过匹配消融实验证明保留联合不确定性而非早期承诺是优势来源

04方法描述

  • 使用GPT-4o将自然语言指令解析为符号原语查询序列（pick/place, target phrase, anchor phrases, relations, frame cues）
  • 基于SAM 3的感知模块从RGB-D观测构建双层场景图：帧无关层存储拓扑关系（near, on, inside），帧条件层存储方向偏移（left-of, right-of）
  • 联合假设表对所有可能的target-anchor-frame解释进行评分，通过soft object score, relation score, action feasibility计算行分数
  • 后验到决策策略：计算目标边际信念B_T(i)，通过后验集中度分数κ和top-1/top-2差异决定execute/clarify/reobserve/abort
  • 后验感知规划与验证：规划时保留高权重锚点和帧假设，执行前验证目标和锚点是否仍可见且约束满足

05数据集与资源

  • 真实机器人平台：UF850机械臂，配备Intel RealSense D435i RGB-D摄像头
  • 真实测试集：6组设置（S1-S6），共90次ambiguity-stress试验
  • 大规模过程测试集：3,200集LIBERO风格过程套件，20个对象类别，每场景5-20个对象
  • 基线模型：GR00T, π₀.₅, LLM-based pipeline

06评估与结果

  • 评估环境：UF850真实机器人厨房场景 + 3,200集过程套件
  • 主要指标：Task Success (TS), Identity-Switch Rate (ISR), Correct Execution (CE), Coverage (Cov), Deferral Rate (DR)
  • 关键结果：

- 在S2-S4 ambiguity-stress试验中，RefGuard实现0% identity switch（81/90正确执行），而VLA基线ISR为33-46%

- 在S1清晰场景中保持93.3%任务成功率

- 在S5执行时扰动下实现86.7%恢复率

- 在S6硬负例中实现100%正确延迟

- 在3,200集过程中套件中，将可解指令的正确执行率从56.6%提升至80.5%，同时将延迟率从43.4%降至19.5%
