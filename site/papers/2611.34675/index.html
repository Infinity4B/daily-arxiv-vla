RoboEvo$^2$: Recursive Robot Self-Improvement via Harness-Policy Co-Evolution

02论文概述

  • 提出 RoboEvo2，一种通过 harness–policy 协同进化 实现递归机器人自我改进的框架，无需额外人类演示。
  • 解决视觉-语言-动作策略在分布偏移下脆弱以及推理代理反复修复成本高的问题。
  • 利用当前政策失败驱动 harness 搜索解决方案，并将验证的修正内化到政策中，形成双向改进循环。

03核心贡献

  • 提出 Policy-to-Harness (P2H) 进化：针对政策失败，并行搜索 Code、Code+ICL、Code+Policy 三条路线，选择最低归一化运动 jerk 的验证解。
  • 提出 Harness-to-Policy (H2P) 进化：结合监督学习和 Counterfactual Preference Distillation (CPD)，利用同一初始状态下的失败-修正对，训练政策偏好修正行为。
  • 设计 递归协同进化框架，政策与 harness 相互增强：政策提供更强运动基元，harness 指导后续搜索，逐步降低 agentic 推理成本。
  • 在 LIBERO-PRO、RoboTwin C2R、MolmoSpaces 和真实 Unitree G1-D 上验证有效性，展示数据效率和跨具身转移能力。

04方法描述

  • P2H 采用失败引导的多路线搜索：对每个失败，VLM 编码 agent 并行尝试 Code（纯代码技能）、Code+ICL（结合演示）、Code+Policy（组合代码和策略），基于执行反馈迭代修复，选择最小化运动 jerk 的验证解。
  • H2P 利用成功轨迹和匹配的失败-修正对进行训练；CPD 损失包含偏好间隔项和不对称邻近项，鼓励政策相对于冻结参考政策增大成功与失败目标的损失差，同时避免过度抑制。
  • 采用 失败感知的任务平衡采样 和 EWC 正则化以缓解灾难性遗忘。
  • 支持 standalone（仅政策执行）和 hybrid（harness 协调政策与代码技能）两种执行模式。

05数据集与资源

  • 数据集：LIBERO-PRO（800 未见 seeds）、RoboTwin C2R（5,000 未见 episodes）、MolmoSpaces（40 个操纵任务）、真实世界 Unitree G1-D 机器人。
  • 初始政策：在机器人演示上微调的预训练 VLA 或 WAM（如 FastWAM、π0.5）。
  • Harness 初始化：基于 CaP-X 和 RATs 的参数化代码技能，包含技能库、记忆和路由。
  • 编码 agent：GPT-6 Astra（VLM 基础）。
  • 训练资源：未明确说明 GPU 规格，但涉及离线训练和 PPO 在线细化。

06评估与结果

  • LIBERO-PRO：8 轮进化后，standalone 成功率从 11.0%→84.1%，hybrid 从 30.4%→90.5%，API 成本从 $430.63 降至 $98.92。
  • RoboTwin C2R：5 轮进化后，standalone 从 46.0%→77.5%，hybrid 从 48.8%→87.4%，API 成本降低。
  • 数据效率：在 RoboTwin C2R 上，仅用 7.5K 自动收集轨迹达到 77.5%，匹配传统训练 27.5K 轨迹的 76.8%。
  • 对比：超过 harness-only 方法（如 EmbodiedRSI 的 86.8% hybrid），经 PPO 细化后 standalone 94.8%、hybrid 96.8%。
  • 消融：全协同进化优于单独 P2H 或 H2P；三条 P2H 路径组合提升最大；CPD 的 gap 与 proximity 组件均有效。
  • 任务获取：MolmoSpaces 上 standalone 57.0%，hybrid 65.8%，优于 RATs 的 38.0%。
  • 跨具身转移：harness 从 ALOHA AgileX 转移到 ARX-X5 和 Franka-Panda，成功率分别 42.5% 和 41.0%（原 45.8%）。
  • 真实世界：Unitree G1-D 上，使用 120 自动演示达到 85.0% standalone，优于 200 人类演示的 80.0%；hybrid 达到 95.0%。
