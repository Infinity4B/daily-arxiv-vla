TRACE: Target-State Risk-Aligned Conditional Execution for Embodied Tracking

02论文概述

  • 论文研究具身视觉跟踪（Embodied Visual Tracking），即机器人根据语言描述持续跟随目标人物，需应对遮挡、相似干扰和指令歧义
  • 发现对紧凑 VLA 跟踪器进行仅限规划头的 PPO 微调会提升跟踪成功率，但同时增加碰撞风险
  • 提出 TRACE（Target-State Risk-Aligned Conditional Execution），一种执行时风险门控机制，在保持策略学习成果的同时选择性干预不安全动作

03核心贡献

  • 构建基于 Qwen3-0.6B 冻结骨干的紧凑 VLA 跟踪器，并仅对规划头进行 PPO 微调，量化了跟踪持久性与碰撞安全之间的权衡
  • 提出 TRACE 执行时目标状态风险门控：通过轻量风险头预测碰撞风险，仅在风险超过阈值时缩放平移分量，减少碰撞率的同时提升成功率和跟随率
  • 设计并发评估协议（concurrent evaluation），使用相同 episode 配对和相同臂 null pairs 区分干预效果与基准波动，证明效果显著
  • 通过匹配衰减控制（平均衰减、随机触发、滞后风险）证明干预的时序对齐目标状态是有效的关键

04方法描述

  • 跟踪系统采用冻结的视觉编码器、语言骨干和识别适配器，仅训练确定性 waypoint 规划头，输出 8 个未来 waypoints
  • 使用 PPO + GAE 对规划头进行两轮 200 个 on-policy episodes 的微调，奖励函数包含跟随、碰撞、距离变化和远距离惩罚
  • TRACE 风险门控：风险头接收 84 个目标相关线索（候选框、身份边际、学习到的距离方位探测、策略命令等），输出碰撞风险分数
  • 当风险分数超过阈值（如 DT 设置下 τ=0.868）时，仅缩放下一个 waypoint 的平移分量，保留偏航；在超过 98% 的步骤上执行动作与 PPO 完全相同
  • 对单目标跟踪采用规划头侧的低学习率 PPO 轮次选择；对干扰跟踪和歧义跟踪则测试运行时条件执行

05数据集与资源

  • 使用 EVT-Bench 基准，包含三个设置：单目标跟踪（STT）、干扰跟踪（DT）、歧义跟踪（AT），每个设置 1,380 个评估 episode
  • 场景数据基于 HM3D 和 Matterport3D 场景
  • 模型骨干为 Qwen3-0.6B（约 6 亿参数），风险头为约 28k 参数的小型前馈网络
  • 训练资源（GPU/TPU 等）在提供的 HTML 摘要中未明确列出

06评估与结果

  • 评估指标：成功率（SR）、跟随率（FR）、碰撞率（CR），遵循 EVT-Bench 协议
  • 在 DT 设置下，PPO 将 CR 从 11.01 升至 13.78，但 SR/FR 提升；加入 TRACE 后 CR 降至 9.83，SR 提升 +2.03，FR 提升 +2.14
  • 配对统计显示 TRACE 的 DT 碰撞率变化为 -3.96（95% CI 排除零）；并发评估中 ΔCR 为 -3.77，对比 null pairs 的 -0.29，表明效果超过评估波动
  • 匹配衰减控制（平均衰减、随机触发、滞后风险）均保持在 PPO 参考水平，证实目标状态时序对齐是关键
  • 在 AT 设置下，AT 校准门控的原始评估碰撞降低未在并发评估中重现，表明在该设置下效果受基准漂移影响
