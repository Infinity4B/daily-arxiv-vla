Card 02 论文概述

论文概述

  • 提出 PhyAI，一个统一的物理 AI 推理引擎，旨在为 VLA（视觉-语言-动作）和 WAM（世界-动作模型）等具身模型提供单一推理路径
  • 解决现有具身模型在模型评估、云端 RL 推演、边缘 GPU 服务和板载部署等场景中依赖分散推理程序的问题
  • 目标是实现一个运行时，同时满足边缘实时性和云端批处理扩展性，并保持模型语义和动作语义的一致性
Card 03 核心贡献

核心贡献

  • 统一推理运行时：PhyAI 提供一条模型路径，支持 VLA 和 WAM 在板载、边缘和云端执行，模型适配器保留架构特定语义，共享服务提供图执行、内核、内存管理、量化、通信和并行性
  • 控制时间 Roofline 分析：提出一种分析模型，将推理延迟与环境执行时间相关联，区分推理受限和环境受限的控制，为实时部署提供决策依据
  • 系统评估：在多种模型和硬件上测量单请求延迟、阶段行为、静态批处理扩展、多 GPU 执行和模拟 RL 推演工作负载，验证了统一运行时的有效性
  • 显著加速效果：相对于官方实现，在所有 11 个测量对中均实现加速，范围从 1.40× 到 4.65×；Cosmos3 在 8 个 H20 GPU 上延迟从 2.46s 降至 1.18s（2.08× 加速）
Card 04 方法描述

方法描述

  • 架构分离：将模型特定逻辑（预处理、求解器、缓存、动作转换）封装在模型适配器中，与共享执行服务（图重放、优化内核、内存管理、量化、并行通信）分离
  • 优化技术：包括内核融合（如自定义 RMSNorm、融合 GEMM）、CUDA 图重放、基于性能分析的算子选择（根据形状和硬件动态选择最优内核）、离线量化（支持 W4A16、W8A16、W8A8、W4A8）
  • 并行执行策略：支持数据并行（DP）、张量并行（TP）和分类器自由引导（CFG）并行，根据模型结构灵活组合；例如，π0.5 使用 DP 扩展，Cosmos3 使用 TP 和 CFG 并行
  • 控制时间 Roofline 模型：将推理延迟与环境执行时间对比，通过 max(L_inference, L_env) 计算理想重叠控制周期，区分推理受限和环境受限的场景

Card 06 评估与结果

评估与结果

  • 评估环境：单 GPU（Thor、RTX 5090、A40、H100）和多 GPU（H20×8、A100×8）硬件，所有延迟测量均使用 CUDA 事件，排除模型加载和观测传输
  • 主要指标：单请求推理延迟（L_inference）、批处理吞吐量（Q(B)）、同步批处理时间（T_sync(B)）、阶段延迟占比、控制时间 Roofline（X 和 Y）
  • 关键实验结果：

- 单请求延迟：PhyAI 在所有 11 个模型-设备对中均快于官方实现，加速比 1.40×–4.65×；Cosmos3 在 H20×8 上从 2.46s 降至 1.18s

- 阶段分析：π0.5 在 batch-1 时动作专家占 8.8% FLOPs 但 57.2% 延迟，batch-32 时降至 13.5%；GR00T 在 batch-1 时瓶颈为 Action Head，batch-4 后转为 Backbone；Cosmos3 生成阶段主导，batch 从 1 到 16 吞吐量仅提升 14.3%

- 控制时间 Roofline：π0.5 在四个 LIBERO 套件中均为环境受限，而 Cosmos3 仍为推理受限

- 云 RL 推演模拟：在 A100×8 上，推理时间占比从 53.1% 降至 36.2%，训练吞吐量提升约 1.36×
