STVLA: Spatial-aware and Temporal-memory forVision-Language-Action Models

02论文概述

  • 论文提出 STVLA，一个空间感知与时序记忆相结合的视觉-语言-动作模型，用于机器人操作任务
  • 核心问题：许多 VLA 策略仅依赖当前观测，未显式整合空间场景结构与任务历史；基于外观特征的记忆易受遮挡和视角变化影响，而仅对当前场景的空间表征无法保留任务执行过程中场景的变化
  • STVLA 将预训练视觉几何基础模型特征融入有界时序记忆，使策略能够将过去的场景结构作为当前动作决策的上下文进行回忆

03核心贡献

  • 提出一种新的 VLA 记忆范式：将预训练视觉几何基础模型特征引入时序记忆，使策略能同时以外观和几何信息作为历史上下文
  • 开发联合视觉-空间检索机制：基于“相关性-非冗余性”评分（由当前-记忆特征相似度与归一化特征差计算），作为注意力先验，无需引入额外可学习评分器
  • 设计专用空间 token 化通路：冻结的 VGGT-Ω 提取场景几何特征，经可训练压缩器生成紧凑空间 token，通过块因果注意力掩码直接供动作生成使用
  • 在四个仿真基准上平均成功率均超过 π₀.₅ 基线，在真实世界任务上提升 30.0–58.3 个百分点

04方法描述

  • 架构基于 PaliGemma 视觉-语言模型与 π₀.₅ 的 flow-matching 动作专家，并增加空间 token 化与有界视觉-空间记忆模块
  • 空间 token 化：冻结的 VGGT-Ω 从多帧 RGB 观测中提取几何特征，可训练压缩器通过学习查询的池化交叉注意力与变分瓶颈将其压缩为 256 个空间 token
  • 有界时序记忆库存储成对的视觉与空间 token（容量 L_m=16），当前 token 通过带评分偏置的多层交叉注意力检索历史，采用学习门控融合，超容量时丢弃最旧条目
  • 检索评分：s_j = r_j·u_j，其中 r_j 为余弦相似度（相关性），u_j 为归一化特征差异（非冗余性），标准化后作为注意力偏置项 β·s̃_j 融入 softmax
  • 训练目标：flow-matching 动作损失 + 辅助重建损失 + KL 正则，策略与空间压缩器联合训练

05数据集与资源

  • 仿真基准：LIBERO（五个套件）、LIBERO-Mem（十个记忆任务）、MIKASA-Robo（五个任务）、SimplerEnv Bridge
  • 真实任务：AGIBOT G2 双臂机器人上的块堆叠、物体整理、手机包装三个任务
  • 几何模型：冻结的 VGGT-Ω（1B 参数），512px 输入，每帧 1024 个宽度为 2048 的 patch 特征
  • 训练资源：8 块 NVIDIA H100 GPU，每 GPU batch size 16，图像输入 224×224

06评估与结果

  • 评估基准：LIBERO 五套件、LIBERO-Mem、MIKASA-Robo、SimplerEnv Bridge，以及三个真实世界任务（块堆叠、物体整理、手机包装）
  • 主要指标：任务成功率
  • LIBERO：STVLA 五套件平均成功率 97.8%，超过 π₀.₅（96.6%）与 MemoryVLA（96.5%）
  • LIBERO-Mem：平均成功率 41.0%（π₀.₅ 为 38.0%），MemoryVLA 仅 9.5%
  • MIKASA-Robo：平均成功率 45.2%，超过 MemoryVLA（41.2%）与 π₀.₅（32.4%）
  • SimplerEnv Bridge：平均 74.0%，超过 MemoryVLA（71.9%）
  • 真实世界（AGIBOT G2）：块堆叠、物体整理、手机包装任务上分别比 π₀.₅ 提升 58.33、30.00、35.00 个百分点
