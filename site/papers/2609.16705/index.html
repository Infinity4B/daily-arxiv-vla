02论文概述

  • 针对Physical AI（物理人工智能）发展中对高物理真实性、可复用机器人经验的迫切需求，指出当前现有机器人数据集多为静态、单平台收集、任务特定的产物，无法支持跨平台学习、世界模型、视觉-语言-动作（VLA）模型训练及可复现的科学对比
  • 提出Robot Data Factory（RDF，机器人数据工厂）这一任务驱动的闭环框架，将机器人经验从实验的被动副产品提升为Physical AI的核心科学资源，实现其持续生成、验证、工程化与复用
  • 该框架旨在支撑机器人从基础运动、操作到人机协作等全能力等级的渐进式评估，同时为物理AI提供可扩展的基础设施支撑

03核心贡献

  • 提出任务驱动的机器人经验生成方法论，形式化为Mission → Task → Skill → Episode → Dataset → Benchmark → Capability的层级结构，实现可复用、可验证的机器人经验生产
  • 设计配套的基准测试框架，包含显式加权任务得分与难度乘数，同时支持任务级与技能级配对评估指标
  • 构建连接数据生成、模型训练、物理与模拟部署的闭环飞轮（cyber-physical flywheel），实现机器人能力的持续迭代提升
  • 实现三个已落地的多环境训练场地：Home（家庭服务场景）、Environment（海洋与户外作业场景）、Energy（能源基础设施巡检场景），配套智能机器人网络、统一数据管道与运营排行榜
  • 对闭环机器人数据生产的计算与存储扩展定律进行定量分析，为基础设施规模化部署提供参考

04方法描述

  • RDF基于四个核心原则设计：任务驱动（数据为可复现的任务目标生成，而非被动收集）、生成循环（任务、机器人、评估协议持续迭代，模型不断优化）、多腔室环境特定（按场景划分训练场地，支撑跨环境技能迁移）、能力导向（以技能为可复用单元，以能力提升而非数据规模为进度衡量标准）
  • 系统架构包含五大核心组件：智能机器人网络（Agentic Robot Network）连接不同腔室的异构机器人、任务控制中心（Mission-Control）负责任务调度与全流程管理、无处不在的数据管道（Ubiquitous Data Pipeline）完成多模态数据的同步、验证与标准化、基准测试框架支持可复现的能力评估、Pitstop排行榜跟踪能力迭代进度
  • 采用Deploy → Measure → Learn → Repeat的闭环迭代流程：机器人执行任务生成交互episode，多模态观测被验证为可复用经验，经验支撑模型训练与基准测试，优化后的模型再部署生成下一代更高性能的经验
  • 核心创新点在于将机器人经验作为主动工程化的核心对象，而非被动收集的产物；通过多腔室设计覆盖多样化物理场景，支撑跨平台、跨任务的技能迁移；通过闭环飞轮实现数据生成、模型训练、评估部署的自动化迭代，最终可扩展为全球联邦式机器人数据网络

05数据集与资源

  • 已落地的场景化训练场地对应数据集：Home腔室家庭服务数据集、Environment腔室海洋/户外作业数据集、Energy腔室能源巡检数据集，所有数据集均配套任务定义、技能标注与外部真值标注
  • 支持的模型类型：世界模型、视觉-语言-动作（VLA）模型、具身机器人策略、数字孪生模型等，未公开具体模型参数量
  • 硬件平台示例：Energy腔室采用B2移动机器人系统，Home腔室采用WidowX机械臂系统
  • 计算与存储资源：配套物理AI集群、边缘计算节点、云/归档存储资源、网络化存储系统，附录中提供了完整的计算存储扩展定律分析与基础设施参考模型
  • 项目公开资源：项目官网提供相关数据集、基准与工具的开源发布入口

06评估与结果

  • 评估环境：基于三个已落地的物理训练场地（Home、Environment、Energy），配套真实机器人硬件与仿真环境，支持可复现的物理世界评估
  • 主要评估指标：任务级加权得分、难度乘数、技能级完成率、成功率、与人类表现的对比指标，通过Pitstop排行榜跟踪能力迭代
  • 关键实验结果：

- 当前Phase 1阶段三大训练场地、智能机器人网络、任务控制中心、数据管道与排行榜已全部在MBZUAI投入运营，完成概念验证

- 定量分析验证了闭环数据生产的计算与存储扩展规律，给出了单机器人、机队级别的数据生成、存储与学习负载的参考稳态模型，以及不同场景下的敏感性分析结果

- Phase 2阶段正在扩展任务库、实施例类型、数据集与基准发布，持续迭代闭环飞轮性能；跨平台迁移与学习增益的量化评估为后续研究计划
