Card 03 核心贡献

核心贡献

  • 识别了在线 VLA 后训练中演化模拟器的可靠性瓶颈，并将其形式化为信任校准问题：想象的 rollout 应依据其估计可靠性影响策略学习。
  • 提出 MeRL（Model-Evolving Reinforcement Learning） 框架，将在线模拟器演化与两级信任控制（stage-level 与 chunk-level）结合，实现真实策略更新与想象数据的自适应使用。
  • 设计无需 oracle 的递归想象评分机制：通过残差预测器（residual predictor）在无未来真实观测的情况下估计递归 generate 的 chunk 级信任。
  • 提供理论分析：Proposition 1 给出想象代理偏置随视觉预测误差累积的上界；Proposition 2 说明为何需联合调度想象比例与 rollout 时域。
  • 在受扰动的 LIBERO-PRO 任务与真实机器人上完成受控消融、同协议外部对比、无 oracle 信任诊断与固定数据物理部署验证。
Card 04 方法描述

方法描述

  • 演化模拟器由世界模型 W_φ（视频预测器）和奖励代理头 Q_ψ 组成，每个在线 stage 用当前策略收集的真实轨迹在线更新。
  • Stage-level 信任：模拟器更新后，用存储的真实 continuation 重放测量观测预测误差与代理进度误差，得到平滑后的可靠性误差，映射为想象数据比例 ρ_s 和 rollout 时域 h_s（两者均随误差非增）。
  • Chunk-level 信任：对每个想象 chunk 估计可靠性误差 ε_{s,i}，转化为重放概率 p_{s,i}（控制局部进入想象 batch）与优化权重 w_{s,i}（控制局部梯度影响）。
  • 残差预测器 g_ξ：对无配对真实 continuation 的递归想象 chunk，基于 anchor/想象 latent、动作、rollout 深度与 stage 上下文预测残差，更新后冻结，且不查询未来真实状态。
  • 混合策略目标：L_MERL = (1-ρ_s)·L_real + ρ_s·L_imag，两条分支使用相同裁剪策略梯度形式，想象分支额外按 w_{s,i} 加权。

Card 06 评估与结果

评估与结果

  • 评估指标：最终成功率 SR、成功率学习曲线归一化面积 AUC、到达阈值所需 stage 数 S2T（报告 S2T-H，混合 Spatial/Object/Goal 的 S2T@80 与 Long 的 S2T@65）。
  • 受控对比：SFT、MFRL、Static-MBRL、Static-MBRL+Trust、Online-Updated MBRL 与 MeRL 共享策略优化器与奖励接口。
  • LIBERO-PRO 主要结果：MeRL 平均成功率 79.7%、AUC 70.6、S2T-H 92.1；相比 MFRL（SR 77.2 / AUC 67.9 / S2T-H 103.4），高阈值学习速度提升 10.9%；相比 Online-Updated MBRL（SR 76.2 / S2T-H 139.6）提升 3.5 个点并大幅降低 S2T-H。
  • 外部同协议对比（三个训练种子）：SimpleVLA-RL 77.1±1.1、WMPO 75.4±1.2、WoVR 77.8±0.9，MeRL 为 79.7±0.7；相对 WoVR 的 AUC 差值 ΔAUC = 2.2 [1.2, 3.3]，S2T-H 差值 −9.2 [−15.4, −3.1]。
  • 组件消融：仅加 stage-level 信任使 AUC 由 65.4 升至 68.4、S2T-H 由 139.6 降至 113.2；仅加 chunk-level 信任使 AUC 升至 67.6、S2T-H 降至 121.5；两级同时使用效果最佳，表明全局调度与局部重放控制互补。
  • 无 oracle 信任诊断：在递归深度 2–4（N=1500）下 Pearson r=0.68、Rank-AUC 0.80、ECE 0.067、top-30% 低误差精度 0.77；深度 3–4 时相应值为 0.64/0.77/0.074/0.74；按信任分箱的 matched-count 精炼策略 AUC 为 69.9±0.8 / 68.3±0.9 / 66.7±1.0，ΔTop−Bottom = 3.2 [2.0, 4.4]。
  • 真实机器人部署：在每任务 50 条示范的固定数据离线精炼下，MeRL 在两物理任务上取得 80.0% 平均成功率（SFT 35.0%、MFRL 55.0%、Online-Updated MBRL 约 60%）。
