LTM: Latent Transition Based In-Context Memory for Vision-Language-Action Models

2026-10-15 · 原文 · 翻译 · 2610.21362

论文提出 Latent Transition Memory (LTM)，一种面向视觉-语言-动作（VLA）模型的上下文记忆机制，用于解决机器人操作中当前观测无法包含历史交互信息（如已完成动作、被遮挡物体状态）的部分可观测性问题。 传统方法保留密集视觉历史会占用大量上下文，稀疏采样会丢失中间交互，语言摘要会抽象掉视觉细节，循环状态难以决定保留内容；LTM 转而记忆"连续观测之间的紧凑潜在转移"，聚焦于交互引起的变化。 通过在 π0.5 上实例化为 LTM-π，在不依赖外部推理模型调用或记忆专用语义标注的前提下，实现高效的在线控制。

Card 03 核心贡献

核心贡献

  • 提出 Latent Transition Memory (LTM)：用相邻观测之间的紧凑潜在转移作为历史上下文，替代完整视觉历史，聚焦交互引发的状态变化。
  • 开发 LTM-π：通过轻量适配器将转移记忆注入 π0.5 的推理上下文，结合因果注意力、持久 KV 缓存与异步转移编码，支持高效在线控制（H100 上策略推理时间 66.71 ms）。
  • 系统刻画了转移记忆的信息量、数据缩放与上下文预算权衡：消融实验区分转移内容与时间线索；RoboMME 数据十倍扩展将成功率从 57.67% 提升到 87.50%；过程监督的 Cup Swap 解码以 97.93% 精度恢复最终状态；200 token 预算仍保留 84.00% 成功率。
  • 在真实机器人上验证有效性：Galbot G1 重复拾放计数任务成功率从 11.25% 提升到 82.50%。
Card 04 方法描述

方法描述

  • 使用冻结的潜在动作模型（LAM）将相邻观测对 $(o_{i-1}, o_i)$ 编码为 32 维潜在转移码 $z_i$，解码器在给定 $o_{i-1}$ 条件下重建 $o_i$，从而迫使码捕获时序变化而非冗余外观信息。
  • 通过两层 MLP 投影器（$32 \to 512 \to 2048$）将归一化的转移码映射为 PaliGemma-3B 隐空间中的记忆 token，并按 $[X^{lang}(\ell); m_1,\dots,m_{\tau_t}; X^{vis}(o_t)]$ 顺序插入语言与当前视觉 token 之间。
  • 引入固定延迟 $k$：$\tau_t = \max(0, t-k)$，最新 $k$ 步转移被排除，为 LAM 编码争取计算余量，可异步编码并与动作执行重叠，将延迟编码受阻时间从 114.25 ms 降至 9.47 ms。
  • 采用因果注意力 + 持久 KV 缓存：每 chunk 骨架自注意力成本从 $\mathcal{O}((n+b)^2)$ 降至 $\mathcal{O}(nb+b^2)$；可选 token 压缩规则（合并最相似相邻 token）用于在有界预算下控制记忆增长。
  • 针对视频演示任务，额外加入稀疏视觉锚点（演示与执行的初始帧）以增强视觉语义对齐，并通过可学习类型嵌入区分演示段与执行段。
Card 05 数据集与资源

数据集与资源

  • 数据集：RoboMME（16 个历史依赖任务，分 Counting、Permanence、Reference、Imitation 四个套件）、LIBERO-Mem（10 个任务，覆盖 OM/OS/OR/OO 四个物体中心记忆维度）、Cup Swap 诊断数据集，以及真实 Galbot G1 机器人拾放数据。
  • 冻结编码器：DreamDojo 与 CD-LAM 两种预训练潜在动作模型。
  • 基础模型：π0.5（PaliGemma-3B 骨架），记忆适配器参数量轻量（$W_1 \in \mathbb{R}^{512\times32}$，$W_2 \in \mathbb{R}^{2048\times512}$）。
  • 训练资源：8 张 H100 GPU，batch size 128；RoboMME 原始数据 40K 步、LIBERO-Mem 30K 步、RoboMME-10x 120K 步；学习率从 $2.5\times10^{-5}$ 衰减至 $2.5\times10^{-6}$，含 1K 预热步。
Card 06 评估与结果

评估与结果

  • 评估环境：仿真（RoboMME、LIBERO-Mem）与真实机器人（Galbot G1）两类环境。
  • 主要指标：任务成功率（%），并对比策略推理时间、潜在编码受阻时间、记忆 token 数量等效率指标。
  • RoboMME 结果：DreamDojo 变体平均成功率 58.54%，显著高于无记忆 π0.5 基线 17.93%；在无外部推理模型且无记忆专用标注的方法中表现最佳。
  • LIBERO-Mem 结果：达到 80.5% 成功率，优于对比中最强基线 42.5%。
  • 消融实验：用固定随机表示替换依赖观测的潜在转移，RoboMME 成功率从 57.67% 降至 44.50%，验证转移内容的独立贡献；五步延迟在保持成功率（57.88% → 57.67%）的同时大幅降低编码阻塞。
  • 数据缩放：RoboMME 从 100 增至 1,000 episodes/task family，成功率从 57.67% 提升到 87.50%；仅延长训练到 120K 步而数据不扩展则无明显收益。
  • Token 预算：在 200 token 记忆预算下仍保持 84.00% 成功率（无压缩为 87.50%），profile 训练查询中平均转移 token 数至少减少 38.26%。
  • Cup Swap 诊断：过程监督实现 97.93% 最终状态恢复，而仅最终状态监督仅为 2.40%，凸显中间过程监督的重要性。
  • 真实机器人：重复拾放计数任务成功率从 11.25% 提升到 82.50%。
