PREM: Prediction-Regulated Memory for Robot Manipulation

02论文概述

  • 论文提出 PREM（Prediction-Regulated Memory） 框架，利用动作条件未来预测来指导机器人操作中的视觉记忆学习与更新
  • 解决当前视觉-语言-动作（VLA）策略在部分可观测环境下难以有效保留和利用任务相关历史信息的问题
  • 通过预测未来视觉特征提供时间监督，并利用预测差异调节视觉状态更新，使策略能够结合当前观测与历史上下文进行动作生成

03核心贡献

  • 提出 PREM 框架：将动作条件未来预测同时用于记忆学习监督和视觉状态更新调节，无需额外关键帧或事件标注
  • 设计 预测差异（Prediction Discrepancy） 机制：比较当前视觉特征与上一步缓存的预测，计算空间归一化差异，作为更新反馈信号
  • 提出 预测调节视觉状态更新：利用归一化预测差异计算逐空间位置的更新系数，动态调节候选视觉状态的融入程度，保留重要历史信息
  • 在 DOMINO、RMBench、LIBERO、LIBERO-Pro 等多个基准上验证有效性，覆盖动态操作、记忆依赖操作、一般操作和空间扰动鲁棒性

04方法描述

  • 循环视觉记忆（RVM）架构：维护固定大小的视觉状态，结合门控网络从当前观测和前一状态生成候选视觉状态
  • 预测差异计算：使用余弦距离和 Smooth-L1 惩罚的组合函数，对预测和观测特征进行逐空间位置比较，并进行空间归一化
  • 更新系数生成：通过 sigmoid 函数将归一化差异映射到 \([β_min, 1]\) 区间，控制候选更新的融入比例
  • 动作条件预测器：基于 Transformer 解码器，从历史视觉状态、当前视觉特征和策略的潜在动作表示预测下一决策步的视觉特征
  • 联合训练：初始化自 π₀.₅，同时优化动作损失和预测损失（权重 λ=0.1），训练中因果展开循环路径，推理时使用完整调节系数

05数据集与资源

  • 数据集：LIBERO（包含 Spatial、Object、Goal、LIBERO-10 四个套件）、LIBERO-Pro（位置扰动鲁棒性）、DOMINO（35 个动态操作任务）、RMBench M(1)（5 个记忆依赖任务）
  • 模型基座：基于预训练的 π₀.₅ VLA 模型，保留其 VLM 骨干和动作生成通路
  • 训练规模：LIBERO 使用 1693 条演示、批量大小 128、3 万步；RMBench 每任务 50 条演示、批量大小 32、2 万步；DOMINO 使用 1750 条轨迹、批量大小 64、10 万步
  • 训练资源：8 × NVIDIA H800 80GB GPU，学习率从 2e-5 余弦退火至 1e-5
  • 推理延迟评估：单张 NVIDIA H800 80GB GPU，批量大小为 1，10 次预热后取 100 次平均

06评估与结果

  • LIBERO 一般操作：PREM 平均成功率 98.7%，较 π₀.₅ 基线（96.9%）提升 1.8 个百分点；LIBERO-10 提升最显著（+4.8 个百分点，达到 97.2%）
  • LIBERO-Pro 空间扰动鲁棒性：PREM 平均成功率从 25.7% 提升至 43.1%，其中 Object 套件提升最大（+51.2 个百分点）
  • DOMINO 动态操作：PREM 平均成功率 20.74%，较 π₀.₅（9.63%）提升 11.11 个百分点，较 PUMA（17.20%）高 3.54 个百分点；在 35 个任务中 31 个任务取得提升
  • RMBench M(1) 记忆依赖操作：PREM 平均成功率 83.8%，较 π₀.₅（14.4%）提升 69.4 个百分点，较 MaP-WAM（75.6%）高 8.2 个百分点；在 Rearrange Blocks、Put Back Block、Swap Blocks、Swap-T 上达到 98% 以上
  • 推理效率：PREM 端到端平均延迟 51.5 ms，较 π₀.₅（43.8 ms）增加 7.7 ms 开销，优于 PUMA（57.4 ms）、Mem-0（96.6 ms）和 MemoryVLA（133.8 ms）
  • 消融实验：仅添加 RVM 架构提升至 15.43%，加入未来预测监督提升至 18.31%，完整加入预测调节更新后达到 20.74%，验证各组件均有正向贡献
