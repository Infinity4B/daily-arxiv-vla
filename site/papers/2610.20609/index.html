Card 03 核心贡献

核心贡献

  • 提出首个同时评估导航跟随与导航-场景冲突感知的基准套件，并额外包含对抗指令鲁棒性测试，对应 LLM 对齐中的 helpfulness–harmlessness 权衡。
  • 提出 SafeDriveVLA：首个显式预测三级导航遵从模式（strict / cautious / fallback）的驾驶 VLA，将冲突推理与动作生成解耦。
  • 提出导航条件世界模型 dreaming：世界模型在“严格执行导航信号”的条件下进行潜在未来推演，揭示跟随时是否安全，使模型比仅使用 mode token 时更少保守。
  • 在 Bench2Drive 与自建基准上系统评估，闭环语言跟随提升 49.3%，不安全指令下的碰撞从 60 降至 38。
Card 04 方法描述

方法描述

  • 驾驶模式归因（Driving Mode Attribution）：为每个专家帧重新标注三档模式——strict（立即执行）、cautious（谨慎跟随、避让局部危险）、fallback（因无安全动作而覆盖信号）；在 VLA 词表中加入 、、 特殊 token，并在动作 token 之前自回归输出。
  • 潜在世界模型（Latent World Model）：基于 V-JEPA 2 架构（冻结的 V-JEPA 2 ViT-L 目标编码器 + 从零训练的 Transformer 动作条件预测器），在 CARLA 数据上预训练，2.5 s 时域、2 Hz；使用连续两帧编码一个 latent，使每个 latent 携带 0.25 s 运动信息（相较长视频/单帧更能反映周围交通速度）。
  • 导航条件 dreaming：不同于以往按专家动作或规划动作推演的世界模型，本方法按由导航信号隐含的动作锚（action anchor） 进行多步推演，暴露该机动在当前场景下是否可行。
  • World model 探针验证：预测 latent 的危险检测 AUC 在各时域均高于首帧 latent，恢复编码器 oracle 增益的 49%–78%；在 GT / 置零 / 侧向镜像动作下推演距离差异明显，证明预测依赖动作输入。
  • VLA 骨干：基于 InternVL3-1B（LoRA 微调），动作以离散 token 形式从 N=2048 的 motion-primitive 码本（K-disk 聚类得到）中输出， 为起始分隔符，T=10 个 token 对应 4 Hz、2.5 s 轨迹；另有轻量 MLP 路径头回归 20 个自车坐标系路径点，经横向 PID 控制，动作 token 积分得到纵向目标速度。
  • 动作锚（Action Anchor）：每个 meta-command 预计算一条锚（对 2.5 s 训练轨迹取平均），变道锚额外做校准；meta-command 由 planner command、waypoint 附带的 command 或语言指令词表匹配解析得到。

Card 06 评估与结果

评估与结果

  • 评估环境：CARLA 闭环仿真（Bench2Drive、CARLA-F、B2D-C、B2D-Adv）+ NavSim 真实数据开环诊断（NavSim-C）。
  • 主要指标：DS（Driving Score）、SR（Success Rate）、Efficiency、Comfortness；CARLA-F 的 NCR（Navigation Compliance Rate）、SE（Speed Error）；NavSim 的 PDMS / NC / DAC / TTC / EP；违规项细分（collision、traffic violation、out-of-route）。
  • Bench2Drive（Table 2）：SafeDriveVLA（WP 导航）达 88.16 DS / 68.64% SR / 264.51 Efficiency；CMD 导航达 87.29 DS / 68.18% SR；相较长于同一 PDM-Lite 数据的 SimLingo 平均提升 +2.15 DS、+1.89% SR。
  • CARLA-F（Table 3）：语言指令下平均 NCR 提升至 83.0%（SimLingo 系列最高仅 55.6%）；变道 NCR 从 0% 提升到 63.6%（左）/ 72.4%（右）；指令跟随较最佳 SimLingo 变体提升 49.3%；命令接口下 78.8% vs SimLingo 73.6%。
  • B2D-C（Table 4）：85.9 DS / 67.3% SR，碰撞 38（↓36.7%）、交通违规 9（↓85.2%）、脱离路线 4（↓63.6%）；对比最佳 SimLingo-Safe 的 72.8 DS / 38.0 SR / 60 碰撞 / 61 违规 / 11 脱离；SimLingo-IF 盲目执行不安全指令时崩溃至 56.3 DS、12.7% SR、166 次碰撞。
  • B2D-Adv：对抗指令下 SimLingo DS 从 95.7 降至 76.0（降幅 19.7），SafeDriveVLA 仅从 94.7 降至 83.9（降幅 10.8）；无 mode token 与 world model 输入的同一骨干降幅最大（93.0→69.7），说明鲁棒性来自显式驾驶模式。
  • NavSim-C（诊断性评估）：所有被测模型在冲突命令下显著退化——AutoVLA PDMS 从 88.2 降至 70.7（DAC 崩至 79.0）；DriveVLA-W0 与 ReCogDrive 分别下降 10.1 与 8.8；CuriousVLA 冲突感知最强（PDMS 84.4，降 6.2，EP 85.4）。
  • 消融：在 CARLA-F NCR 与 B2D-C DS 的 Pareto 前沿上，简单干预（提示、数据扩展）只能以牺牲一个维度换取另一个维度，而 mode token + 世界模型 dreaming 同时改善两者。
