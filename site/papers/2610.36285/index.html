ASPEN: Adaptive Semantic Reasoning via Command Persistence Prediction for Efficient Navigation VLAs

02论文概述

  • 导航视觉-语言-动作（VLA）策略在后续命令未发生变化时，仍会反复调用代价高昂的语义推理，造成大量冗余计算
  • 简单的命令复用虽能降低计算量，但存在遗漏依赖指令的转弯或停止命令的风险
  • 论文提出 ASPEN，一种基于命令持续性预测（command persistence prediction）的事件触发调度器：预测冻结的基础策略是否会重复发出上一条命令，从而决定是复用命令还是触发 VLA 重新推理

03核心贡献

  • 提出面向冻结导航策略的基于命令持续性的调度机制，区别于以往仅判断场景/运动是否变化的方法
  • 设计带显式资格检查的上下文条件化轻量多模态预测器，融合时序观测、语言指令、执行历史与缓存的 VLA 置信度
  • 完成 R2R-CE 到 RxR-CE 的跨数据集评估，在无目标域调优的情况下降低估计推理成本，同时保持相近导航性能和高动作序列一致率
  • 给出包含调度开销的推理成本估计方法，揭示效率-性能权衡

04方法描述

  • 调度器在高层命令边界（而非模拟器单步）运行：先进行资格检查（仅限前进类命令且连续复用少于 8 次），再计算持续性分数
  • 轻量多模态命令预测器：冻结的 SigLIP 编码首帧视图与最近两个历史决策点视图（池化为 9×9 token 网格、宽度 256），冻结的 Llama-3 每回合编码一次指令文本
  • 学习的状态向量编码执行命令、幅度、步数、重复标志、回合进度与缓存的 NaVILA 置信度，按 DINO-WM 方式与视觉 token 相加并作为独立状态 token
  • 两层宽度 256、4 头注意力的 Transformer 执行因果自注意力与指令交叉注意力，经 MLP 输出 NaVILA 十类规范命令上的分布，状态输出通过注意力池化查询当前视图
  • 触发规则：持续性分数 q ≥ τ（τ=0.9418，由校准集重放选定，发散率上限 10%）时复用命令，否则调用 NaVILA
  • 训练采用冻结 NaVILA 轨迹上的十类下一命令交叉熵，AdamW（学习率 5×10⁻⁴）、批大小 32、3 个随机种子、最多 100 epoch（15 epoch 早停耐心）

05数据集与资源

  • 训练/校准数据：R2R-CE 训练划分（训练/检查点选择/校准分别为 42/6/13 栋建筑、2,536/405/1,685 回合）
  • 评估数据：RxR-CE val-unseen 1,223 回合（跨数据集，无目标域训练或调优）
  • 基础模型：冻结的 NaVILA；冻结编码器：SigLIP、Llama-3；预测器为轻量级（宽度 256 的 2 层 Transformer）
  • 性能分析资源：单块 NVIDIA RTX PRO 6000 Blackwell GPU；ASPEN 门控单次估计成本 19.45 ms（预测器仅 1.5 ms，共享 SigLIP 视觉编码 10.5 ms）

06评估与结果

  • 评估环境：1,223 个 RxR-CE val-unseen 回合，对比冻结 NaVILA 基线、FlashTrigger、SP-VLA 及两个诊断方案（Free Rule、Full Gate）
  • 指标：成功率（SR）、预言成功率（OS）、nDTW、导航误差（NE）、每回合 VLA 调用次数、估计推理时间、动作序列完全一致率
  • ASPEN 将 VLA 调用减少 9.5%、估计推理时间减少 8.1%（含调度开销），SR 保持 53.1（基线 53.0），nDTW 63.2（基线 63.3），92.1% 的回合动作序列与基线完全一致
  • 对比分析：FlashTrigger 调用仅减 5.1%（一致率 97.5%）；SP-VLA 虽时间略省但 SR 跌至 42.7%、一致率仅 7.3%；Free Rule 节省 19.6% 但 SR 降至 49.1%；Full Gate 调用减 11.7% 但时间仅省 3.3%
  • 结论：ASPEN 在效率-性能权衡上表现最优，实现语义推理成本降低的同时维持与基线相当的导航性能和高保真度
