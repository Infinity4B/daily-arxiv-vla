Card 02 论文概述

论文概述

  • 论文提出了 SimPT，一个仿真框架，用于自动化基于干预的视觉-语言-动作（VLA）策略后训练流程
  • 解决人机协同后训练中人工监督成本高、真机评估耗时且受环境波动影响、算法探索受限的问题
  • 框架集成策略 rollout、纠正数据收集、策略训练和独立评估，支持系统性算法开发
Card 03 核心贡献

核心贡献

  • 引入 SimPT 仿真框架，自动化干预式 VLA 后训练工作流，支持算法探索与开发
  • 开发 Agent-Compiled Progress Graph，利用特权模拟状态跟踪任务进度并保留稳定快照，在 rollout 失败后从较高级任务阶段向较早阶段逐步回退进行专家恢复
  • 在七个 RoboTwin 操作任务上实现并比较 RECAP、HG-DAgger、DPO+SFT 和 FlowPRO 四种后训练方法
  • 基于 SimPT 开发 RECAP-CF-LPF，通过交叉拟合和低通滤波改进价值预测，在仿真和真机实验中显著提升策略成功率
Card 04 方法描述

方法描述

  • 使用语言模型代理（GPT-5.6-Sol）读取任务源码，生成候选进度图，并进行静态验证和自动修订
  • 进度图由任务阶段节点和转移条件组成，通过校准阈值检测阶段完成和回归（如抓取丢失）
  • 策略执行期间根据进度图保留每个阶段的最新快照，失败后由基于 CuRobo 的程序化专家从快照恢复，生成纠正轨迹
  • 后训练数据包含成功/失败 rollout 和专家纠正轨迹，支持不同学习目标（如行为克隆、强化学习、偏好优化）
  • RECAP-CF-LPF 使用五折交叉拟合避免价值模型过拟合，并用 1 Hz 巴特沃斯低通滤波器平滑时序价值信号
Card 05 数据集与资源

数据集与资源

  • 使用 RoboTwin 仿真基准中的七个双臂操作任务：Lift Pot、Move Can Pot、Place Empty Cup、Beat Block Hammer、Place Can Basket、Handover Block、Stack Blocks Two
  • 策略骨干为 π0.5 VLA 模型，动作块大小为 50，每个任务用 50 个专家演示进行 SFT 预训练
  • 数据收集使用 240 个预设环境种子，专家恢复基于 CuRobo 运动规划
  • 策略训练共 10,000 步，使用 40 个验证种子调参，最终评估使用每任务 200 个 held-out 种子（共 1,400 次试验）
  • 真机验证使用 AgileX PiPER 双臂机器人、三个 RGB 相机和主臂遥操作，共 1,672 条训练轨迹
Card 06 评估与结果

评估与结果

  • 与固定间隔快照基线（Naive）相比，Progress Graph 将恢复尝试次数减少 75.0%（从 3,781 降至 945），恢复成功率从 93.4% 提升至 98.9%
  • 四种后训练方法中，HG-DAgger 总体成功率最高（82.14%），RECAP 为 76.50%，FlowPRO 为 71.86%，DPO+SFT 为 63.14%，均高于 SFT 基线 67.29%（DPO+SFT 除外）
  • 使用 PG 收集的数据，RECAP 成功率从 Naive 收集的 66.64% 提升至 76.50%（+9.86 个百分点），HG-DAgger 和 DPO+SFT 分别提升 1.93 和 0.50 个百分点，FlowPRO 下降 4.21 个百分点
  • RECAP-CF-LPF 在仿真 held-out 评估中将总体成功率从 76.50% 提升至 79.36%（+2.86 个百分点），在真机以太网线插入任务中将成功率从 72% 提升至 96%（25 个场景中 24 个成功）
