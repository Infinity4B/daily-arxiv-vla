02论文概述

  • 研究长时程语言指令下的人形机器人多目的地导航，要求机器人在连续目标间保持前进并产生自然、稳定的全身运动。
  • 现有方法中，任务分解本身无法保证执行过程中的持续进展，而基于路径点的导航无法保证自然且忠实于路线的全身运动。
  • 提出 LHNav 框架，通过异步多速率协调和物理基础的动作数据，使单目标策略能够扩展到多目标长时程导航。

03核心贡献

  • 设计异步三层系统 Brain（任务推理）、Cerebellum（运动 token 预测）、Brainstem（全身执行），利用进度感知的目标转换实现长时程导航。
  • 提出可扩展的物理基础数据引擎，通过特权编码器（P-SONIC）和冻结的 SONIC 解码器改进全局运动参考跟踪，生成执行对齐的导航演示数据。
  • 在仿真的未见场景中验证了更高的导航成功率、更平滑的运动、更少的碰撞和摔倒，以及更快的长时程完成时间；同时实现了真实机器人上的单目标和零样本长时程导航。

04方法描述

  • Brain 使用任务管理工具和到达验证工具，维护显式计划并在执行过程中修订待办目标，通过进度和到达反馈协调目标切换。
  • Cerebellum 基于 GR00T N1.7 和 SONIC 微调，联合预测运动 token 和辅助路径点，使用共享 DiT 进行流匹配，并引入基于 SDF 的几何监督以提升路径点可穿越性。
  • Brainstem 使用冻结的 SONIC 解码器，以 50 Hz 频率将运动 token 解码为关节目标，与 Cerebellum 的约 8 Hz 异步执行。
  • 数据引擎使用 ARDY 生成自然运动参考，利用 P-SONIC 在 MuJoCo 中进行物理跟踪，将执行状态与渲染的视觉观察对齐，生成训练演示。

05数据集与资源

  • 数据集基于 InteriorGS，选择 100 个训练场景和 20 个 held-out 测试场景，构建 GS+Mesh 可重构场景。
  • 单目标评估使用 185,401 个训练演示，长时程评估使用 14,410 个单目标演示训练单独的策略。
  • 模型基于 GR00T N1.7 预训练权重微调，Cerebellum 预测 40 步运动 token 和路径点。
  • 训练使用 8 个 NVIDIA H20 GPU，全局 batch size 64，训练 100K 步。
  • 真实机器人平台为 Unitree G1，配备前置 Orbbec Gemini335L 相机。

06评估与结果

  • 单目标导航（522 个 episode）：LHNav 获得 SR0.5 52.3%、SR1.5 75.7%、NE 1.7m、CR 8.6%、Jp 75.6、Falls 0；优于 OmniNav（SR0.5 36.0%、Falls 7）和 DualVLN（SR0.5 18.6%、Falls 91）。
  • 长时程导航（45 个任务）：Full system 达到 Task SR1.5 75.56%、Progress 82.2%、OSR 91.1%、平均完成时间 82.1s；移除任务管理或到达验证后成功率分别降至 0% 和 55.6%。
  • 真实机器人测试：家庭单目标导航成功率 100%；重配置布局中目标导航成功率 93.3%-100%；三目的地长时程任务 5 次试验中 4 次成功（80%）。
  • 消融实验：P-SONIC 将跟踪误差降低 96.4%；联合预测动作 token 与辅助路径点相比仅用路径点或仅用动作 token 提升成功率并减少碰撞；几何监督将 SR0.5 提升 4.98 个百分点并降低 CR；约 8 Hz 的 VLA 更新频率获得最低 CR 和零摔倒。
