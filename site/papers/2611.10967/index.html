BAT-WAM: Bridging Action and Touch in World-Action Models for Dexterous Hands

02论文概述

  • 论文研究世界动作模型（WAMs）在灵巧手操作中的多模态表示问题，特别是联合建模视觉（RGB）、手部关节状态（Joint）和全手触觉（Touch）信息。
  • 现有方法中关节状态和触觉观测可能部分或完全缺失，而仅靠 RGB 图像难以可靠恢复这些模态；论文观察到手部配置与触觉接触之间存在强相关性，并据此提出桥接两者的表征框架。
  • 目标是通过跨模态桥接，使触觉与关节状态能相互监督、相互补全，从而提升 WAM 在缺失模态下的重建与预测能力，并最终改善真实机器人灵巧操作性能。

03核心贡献

  • 发现灵巧手关节状态与触觉观测之间的强相关性，此前这一跨模态关系被忽视。
  • 提出 BAT-WAM，一种新颖的跨模态表示框架，将离散触觉和状态表示与连续 RGB 上下文通过多模态桥接 Transformer 集成，支持双向条件重建。
  • 在 HT-Bench 基准上，BAT-WAM 在全掩码触觉重建、局部掩码补全和条件未来触觉预测任务中均取得最先进性能。
  • 在真实机器人灵巧操作（7 个任务）中，BAT-WAM 平均成功率显著优于 OpenWAM-α 和 OpenWAM-α + HandTouch 基线。
  • 在零样本泛化（物体颜色、大小、形状、场景布局、姿态变化）评估中，BAT-WAM 在所有未见设置下均优于基线模型。

04方法描述

  • 模态特定分词器：触觉（Touch）和关节状态（Joint）各使用独立的编码器、投影层、码本（codebook）和解码器。Touch 被编码为 196 个空间网格 token，Joint 编码为 8 个 token；RGB 通过冻结的 SigLIP 编码器提取连续上下文特征，不进行量化或重建监督。
  • 跨模态桥接：共享 Transformer 将掩码触觉特征、可见关节状态特征、RGB 特征以及任务/掩码提示拼接，并通过可控注意力（visibility mask）防止访问缺失信息；通过静态训练目标（锚定重建 + 掩码预测 + 码本与对齐损失）学习模态间的条件依赖。
  • 多模态时间预测：在静态桥接基础上扩展时序建模，以历史触觉、历史关节状态和目标时间 RGB 为条件，预测目标时间的触觉观测，目标时间触觉仅用于监督。
  • 桥接输出作为额外前缀 token 输入到 π₀.₅ 世界动作模型骨干，用于动作生成。

05数据集与资源

  • 离线基准：HT-Bench，包含自我中心视觉与全手触觉数据的多任务灵巧操作基准，提供掩码触觉重建、视觉-触觉合成、时序预测等评估协议。
  • 真机实验数据：7 个多样任务（抓取放置、堆叠、拉推、长时操作），每个任务采集 200 条演示。
  • 机器人平台：6 自由度 AgileX PiPER 机械臂，配备 Linker Hand L6 灵巧手和 Juqiao Industrial 全手触觉手套；视觉传感器为 Intel RealSense D435（顶视）和 D405（腕视）。
  • 骨干模型：基于 π₀.₅ 架构的 WAM 接口，桥接模块输出作为附加 token 条件。

06评估与结果

  • 评估环境：HT-Bench 离线评测 + 真实桌面机器人实验。
  • 全掩码触觉重建（F-RMSE↓ / F-cIoU↑）：BAT-WAM（Action+Image）达到 0.0145 / 0.8933，相比 HandTouch 的 0.0221 / 0.8316，RMSE 降低 34.73%。
  • 局部掩码触觉补全（H-RMSE↓ / H-cIoU↑）：BAT-WAM（Action+Image）达到 0.0137 / 0.8984，相比 HandTouch 的 0.0224 / 0.8211，RMSE 降低约 38.84%。
  • 条件未来触觉预测（RMSE↓ / cIoU↑）：BAT-WAM 达到 0.0157 / 0.8901，相比 HandTouch（0.0211 / 0.8486），RMSE 降低 25.59%；摘要中报告相对于 OpenWAM + HandTouch 降低 85.56%。
  • 真机成功率（平均）：BAT-WAM 79.3%，OpenWAM-α 66.4%，OpenWAM-α + HandTouch 69.3%；在擦白板任务上优势最大（45% vs 15% vs 25%）。
  • 零样本泛化成功率（未见设置平均）：BAT-WAM 54.5%，OpenWAM-α 38.5%，OpenWAM-α + HandTouch 42.0%；在未见布局和颜色场景下 BAT-WAM 均达 80.0% 成功率，但未见尺寸和形状仍较困难（37.5% 和 27.5%）。
