Card 02 论文概述

论文概述

  • 论文旨在解决冻结的视觉-语言-动作 (VLA) 策略在测试时接收外部检索文本作为指令干预时，出现的提示词形式崩塌 问题
  • 研究发现，直接将检索到的文本附加到原始指令中会导致执行成功率从 92.47% 暴跌至 3.00%，且无论附加文本是否有意义均会失败
  • 提出 TOWN-VLA (Think Only When Needed) 接口，通过将候选文本生成与提示词修改权限分离，仅在满足兼容性规则时授权规范化紧凑指令，否则完全恢复原始基础提示词
Card 03 核心贡献

核心贡献

  • 首次将提示权限控制 定义为冻结 VLA 的测试时接口问题，并识别出提示词形式崩塌这一关键失败模式
  • 实现了“提议不等于权限”的机制，通过 Top-2 失败关闭级联机制，确保仅授权规范指令，且拒绝时逐字节恢复原始基础提示词
  • 在匹配评估中，TOWN-VLA 将 LIBERO-Plus 成功率提升 3.61 个百分点，并在物理 PiPER 机械臂上将成功率提升 26 个百分点
  • 量化了选择性计算的上界，证明 Oracle 路由可减半慢路径调用且不损失成功率，指出无 Oracle 准入校准是未来部署的挑战
Card 04 方法描述

方法描述

  • TOWN-VLA 包含兼容性重排序胶囊和 Top-2 失败关闭级联机制
  • 兼容性重排序胶囊利用 CLIP 文本特征和最近邻索引检索 Top-K 候选，并结合任务对象-目标的结构重叠与 Jaccard 相似度进行固定规则重排序
  • Top-2 失败关闭级联最多检查两个候选，首个符合条件的候选被渲染为规范紧凑指令；若均未通过，则精确恢复基础提示词
  • 整个流程保持冻结策略的参数、动作空间和控制频率不变，仅在提示词边界进行选择性干预，并提供可审计的运行时状态与哈希记录
Card 05 数据集与资源

数据集与资源

  • 使用 LIBERO-Plus 仿真基准（包含 10,030 个评估 episode，涵盖四个任务套件和七个扰动轴）
  • 物理机器人实验在 PiPER 机械臂上进行，每种方法进行 150 次试验
  • 基础模型为 OpenVLA-OFT（仿真）和冻结的 π0.5 检查点（物理实验）
  • 训练与评估资源为 NVIDIA RTX A6000 硬件，使用 CUDA 12.1 和无头 MuJoCo 渲染
Card 06 评估与结果

评估与结果

  • 评估环境为 LIBERO-Plus 仿真器及物理 PiPER 机械臂，主要指标为成功率
  • 在仿真中，接口将加权平均成功率从 69.5% 提升至 73.1%（+362 个成功 episode，95% CI 1.89–5.45）
  • 在物理机械臂上，成功率从 52.7% 跃升至 78.7%（Fisher 精确检验 p=3.16×10^-6）
  • 审计结果表明，所有未授权路由均精确恢复原始基础提示词，而授权路由保持了任务签名
