When Backdoors Can Be Switched Off: Suppression-Aware Backdoor Attacks on Vision-Language-Action Models

论文研究视觉-语言-动作（VLA）模型中的后门攻击，重点关注现有工作尚未充分探索的“抑制感知”后门

作者 Nur Afsa Syeda 和 Mohamed Elmahallawy

  • arXiv 2611.19774
  • 6 节精读

01研究单位

  • 作者 Nur Afsa Syeda 和 Mohamed Elmahallawy
  • 所属机构：华盛顿州立大学工程与应用科学学院（School of Engineering and Applied Sciences, Washington State University, Richland, WA, USA）

02论文概述

  • 论文研究视觉-语言-动作（VLA）模型中的后门攻击，重点关注现有工作尚未充分探索的“抑制感知”后门
  • 提出的攻击结合多模态条件触发与基于语言指令的显式抑制，使恶意行为仅在特定条件同时满足时激活，并可被特定指令关闭
  • 解决的核心问题是：能否设计一种后门，使其需要多种模态同时出现才能激活，但在指定条件下即使物理触发器仍存在也能抑制恶意行为

03核心贡献

  • 首次提出针对 VLA 策略的 抑制感知后门（suppression-aware backdoors），将传统触发式攻击扩展到条件激活与指令条件抑制
  • 设计三种互补的多模态后门变体：Cross-Modal Trigger（状态+视觉）、Self-Suppressing Trigger（状态+语言，带 [DISRUPT] 激活和 [RESTORE] 抑制）、Multi-Trigger（状态+视觉+语言三模态联合，且保留抑制能力）
  • 在 SmolVLA 和两个 SO-100 操作数据集上，Self-Suppressing 与 Multi-Trigger 达到 63%–71% 的攻击成功率，同时保持 100% 干净准确率
  • 将基于 Isolation Forest 的检测率从 96%–98% 降至 1%–18%，并将动作空间 L2 散度降低 10–14 倍
  • 在 OpenVLA-7B 和 LIBERO 四个套件上验证跨架构迁移，证明抑制机制和检测规避能力可转移

04方法描述

  • 使用共享的初始位姿状态触发器 \( \mathbf{s}_0 + \boldsymbol{\delta}_s \)，并通过 PGA（Projected Gradient Ascent）优化触发器染色体
  • Attack A（Cross-Modal Trigger）：要求状态触发器与分割式图像触发器（两个半幅 checkerboard 噪声，总幅度 \( \varepsilon = 32/255 \)）同时出现；训练时通过负对比模式（仅状态或仅视觉）抑制单独模态激活
  • Attack B（Self-Suppressing Trigger）：使用状态触发器 + 语言指令中的 [DISRUPT] 激活，[RESTORE] 抑制；中毒数据集将相同物理状态下不同语言 token 对应相反动作标签
  • Attack C（Multi-Trigger）：结合 Attack A 的跨模态联合激活和 Attack B 的语言抑制，需要状态、视觉、[DISRUPT] 三者同时满足才触发，[RESTORE] 则在物理触发器持续存在时恢复清洁行为
  • 使用行为克隆对策略进行中毒微调，中毒比例默认 20%，并设计负对比训练增强触发器选择性

05数据集与资源

  • 使用 LeRobot SO-100 两个操作数据集：Cube Sorting 和 Pick and Place
  • 主要模型为 SmolVLA：450M 参数，基于 SmolVLM2-500M 视觉语言主干和 flow-matching 动作头
  • 跨架构迁移使用 OpenVLA：7B 参数 VLA 模型，在 LIBERO 四个套件（spatial, object, goal, long）上评估
  • 训练数据图像分辨率 480×640，动作块时域范围 H=50，中毒比例默认 20%
  • 训练资源：论文未明确说明所用 GPU/TPU 型号与数量

06评估与结果

  • 评估指标包括攻击成功率（ASR）、干净准确率（CA）、干净任务完成率（CTC）、触发器选择性、抑制恢复率、动作空间 L2 散度及检测防御指标
  • 在 SO-100 数据集上，Attack B 和 Attack C 的主 ASR 为 63%–71%，次 ASR 为 0%，[RESTORE] 恢复正常行为率达 86%–95%
  • 所有三种攻击在干净输入下 CA 保持 100%，干净任务完成率 83%–91% 与基线一致
  • Attack B 将 Isolation Forest 检测率降至 1%–9%，Attack C 降至 3%–18%；L2 动作散度分别降至 1.30–1.42 和 0.74–1.04
  • 跨架构迁移至 OpenVLA-7B 和 LIBERO 时，抑制几乎完美（[RESTORE]-fail ≤ 3%），并规避 STRIP 和动作分布偏移检测（KL 0.04–0.12），但主 ASR 下降至 24%–52%，受 LoRA 和长时任务影响
