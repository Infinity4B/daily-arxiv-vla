Card 03 核心贡献

核心贡献

  • 提出 训练无关、无需奖励/成功标签 的视觉 token 剪枝框架 SAPrune，通过离线校准集观察动作到视觉注意力的跨层动态来选择剪枝层。
  • 设计 阶段感知的剪枝层选择算法：将 Transformer 层分为浅层、中层、深层三个相对深度区域，利用 top-κ 注意力质量、层间移动平均、分位数阈值和重分布事件检测，选取每个区域中最稳定的剪枝位置。
  • 提出 Layer-Local Dual-Path Pruning（层内双路径保留机制）：attention-core path 保留高动作注意力的核心 token，functional-diversity path 基于行动与语言查询条件的功能签名选择互补 token，避免仅靠注意力塌缩到单一区域或仅靠视觉多样性保留无关 token。
  • 引入 reliability-adaptive budget（可靠性自适应预算）：根据候选池的保留分数 \(P_l\) 与注意力集中度 \(A_l\) 动态分配注意力路径与覆盖路径的 token 数量。
  • 在 LIBERO、SIMPLER 和真实机器人任务上验证，仅保留 32 个视觉 token（剪枝 87.5%），实现最高 1.718× 推理加速同时保持有竞争力的成功率。
Card 04 方法描述

方法描述

  • 剪枝层选择（When）：通过校准 rollout 记录每层 action-to-visual attention，计算 top-κ（默认 κ=0.125）注意力质量；对层间绝对差进行 3 点移动平均平滑，使用分位数阈值（\(q_s=0.4\), \(q_r=0.8\)）检测 plateau 起点与表注重分布事件；在浅/中/深三个区域分别选取最早 plateau 起点或最小局部平均变化层作为剪枝层。
  • 双路径剪枝（What）：在每个选定层，构建比最终预算更大的候选池 \(C_l\)（γ=1.75 倍预算），并构造注意力排序的 probe 集；通过 thin QR 分解计算保留分数 \(P_l\)，结合归一化熵得到集中度 \(A_l\)，共同决定注意力路径与覆盖路径的预算分配（\(λ_{\min}=0.1\), \(λ_{\max}=0.9\)）。
  • 注意力核心路径：直接保留候选池中 action-to-visual attention 排名最高的 \(K_l^{attn}\) 个 token。
  • 功能多样性路径：利用未被剪枝的文本 token（保留 top-6）与行动查询组成查询族，计算每个视觉 token 的查询条件功能签名；通过残差证据引导的贪心选择（与剩余证据对齐并抑制与已有 token 的冗余）填充 \(K_l^{cov}\) 个 token，最终合并两路径并填充至预算大小。
  • 关键技术：查询条件功能签名替代纯特征空间多样性，能更直接反映 token 对当前动作-语言指令的功能响应；所有操作训练无关、无需额外训练模块。

Card 06 评估与结果

评估与结果

  • 在 LIBERO 上，与多个加速基线（FastV、DivPrune、SP-VLA、VLA-ADP、EfficientVLA(T-only)）对比，采用任务成功率（每类任务及平均）、延迟（ms）、加速比（×）和 FLOPs 比作为指标。
  • OpenVLA 上：仅保留 32 token，平均成功率 74.0%（原始 74.9%），延迟 110.96 ms，加速 1.608×，FLOPs 比 39.5%，各分项成功率均优于或持平大多数剪枝基线。
  • OpenVLA-OFT 上：仅保留 32 token，平均成功率 94.5%（原始 95.4%），延迟 60.30 ms，加速 1.718×，FLOPs 比 37.8%，为所有剪枝方法中最佳。
