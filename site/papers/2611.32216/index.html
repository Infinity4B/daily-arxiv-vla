02论文概述

  • 论文提出 NativeDrive，一种面向自动驾驶的原生多模态基础模型框架，旨在统一语义理解、场景感知与驾驶动作预测。
  • 现有视觉-语言-动作模型（VLA）或视频世界-动作模型（WAM）存在动作标签监督弱、外观重建开销大等问题；NativeDrive 在统一理解与生成骨干上直接设计策略接口和驾驶专用密集监督。
  • 核心目标是让驾驶策略既复用骨干的语义先验，又不引入与规划无关的图像重建成本，推理时仅运行规划策略分支。

03核心贡献

  • 提出 NativeDrive 框架，将原生统一多模态骨干适配到驾驶策略学习，支持离散动作预测与连续轨迹生成或训练期语义编辑两种配置。
  • 设计 Native Action Interface：离散策略复用理解专家的 token 预测接口预测量化动作 token；连续策略将生成专家适配为轻量动作专家。
  • 引入 Driving Semantic Editing：利用生成专家预训练的编辑能力生成语义地图，作为训练期密集场景结构监督，推理时不额外增加计算。
  • 系统研究动作接口、视觉任务和联合训练等关键设计选择，在 NAVSIM v1 和 NAVSIM v2 上验证有效性。
  • NativeDrive-D 在 NAVSIM v1 达到 88.8 PDMS，在 NAVSIM v2 达到 88.5 EPDMS；best-of-6 下分别达到 93.8 PDMS 和 93.3 EPDMS。

04方法描述

  • 采用 SenseNova-U1-8B-MoT-SFT 作为原生多模态骨干，其无编码器架构支持直接图像 patch 输入和像素预测输出。
  • 输入包括多视角视觉观测、导航指令和自车状态；输出为未来 5 秒、2 Hz 的 10 个轨迹航点。
  • 离散动作 token 化：使用基于 Perceiver 的 VQ 编码器-解码器，对局部运动增量进行量化，每 1 秒轨迹段生成 4 个动作 token，码本大小 2048，隐维度 512。
  • 离散策略采用块级自回归预测（BAR），逐块预测、块内并行，减少解码长度和误差累积。
  • 连续策略将生成专家缩减宽度后初始化为轻量动作专家，使用条件流匹配（flow matching）从高斯噪声生成连续轨迹。
  • Driving Semantic Editing 用冻结的 Mask2Former 生成八类驾驶场景语义伪标签，并进行规则过滤与人工审核；训练时将语义编辑损失与离散策略损失联合优化。
  • 两种配置共享注意力掩码：动作 token 和生成 token 均只能关注观测上下文，彼此不可互相关注；离散推理只保留观测和动作 token，连续推理只保留观测和生成 token。

05数据集与资源

  • 主要基准：NAVSIM v1 和 NAVSIM v2 navtest（使用官方划分与协议）。
  • 轨迹 tokenizer 训练数据：NAVSIM 与 Waymo E2E 轨迹按等概率采样。
  • 语义编辑数据：NAVSIM 和 Waymo 数据集中的前视图像，经 Mask2Former 伪标注和人工审核构建。
  • 骨干模型：SenseNova-U1-8B-MoT-SFT；冻结观察图像嵌入模块和动作 tokenizer。
  • 训练资源：tokenizer 训练使用 8 块 GPU，全局 batch size 16,384；策略训练使用 8 块 H20 GPU，全局 batch size 32。
  • 离散策略训练 5 个 epoch；离散与连续联合训练 10 个 epoch；优化器为 AdamW，峰值学习率 5e-5，权重衰减 0.1。

06评估与结果

  • 评估环境：NAVSIM v1（PDMS）和 NAVSIM v2 navtest（EPDMS），包含 NC、DAC、TTC、Comf、EP 等子指标。
  • NAVSIM v1 结果：NativeDrive-D 单轨迹 88.8 PDMS，best-of-6 93.8 PDMS；NativeDrive-C 单轨迹 88.4 PDMS，best-of-6 91.1 PDMS。
  • NAVSIM v2 结果：NativeDrive-D 单轨迹 88.5 EPDMS，best-of-6 93.3 EPDMS；NativeDrive-C 单轨迹 88.1 EPDMS，best-of-6 91.0 EPDMS。
  • 在无驾驶域骨干预训练的 SFT 统一模型中，NativeDrive-D 仅用 5 个策略训练 epoch 即取得领先，并达到所列模型中最高的 best-of-6 分数。
  • 消融实验验证了动作 token 化、联合离散-连续策略训练、视觉监督等组件的有效性；定性可视化展示了辅助视觉预测效果。
