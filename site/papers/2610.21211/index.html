Card 02 论文概述

论文概述

  • 研究主动式机器人辅助（Proactive Robot Assistance）问题：机器人应预判用户需求，在用户明确请求之前提供帮助
  • 核心难点在于同一观察行为在不同用户习惯下可能对应不同需求，仅靠常识推理或零样本预测容易产生歧义与不必要的打扰
  • 提出基于程序性辅助记忆（Procedural Assistance Memory, PAM） 的智能体框架，利用日常生活惯例的高度重复性，通过部署期积累经验来消解辅助歧义
Card 03 核心贡献

核心贡献

  • 提出基于记忆的智能体框架，使高层 VLM 任务预测器结合用户特定惯例上下文，自主决定何时辅助以及执行什么任务，无需显式用户指令
  • 提出 PAM 记忆结构，采用有限状态机（FSM）形式组织活动阶段（states）、触发–动作对（trigger–action pairs）和事件驱动转移（transitions），降低辅助需求歧义
  • 设计自演化记忆循环，由反思 VLM（reflector）在每天结束后基于观测行为与用户反馈离线修订 PAM，实现免权重更新、免重训练的个人化适应
  • 采用 System 1–2 架构，将高层推理（VLM 任务预测）与底层执行（VLA 执行器）解耦，缓解低数据条件下联合优化的性能退化
  • 在 5 天桌面辅助评测中验证记忆带来的持续改进、对作息变化的快速适应，以及对单体 VLA 的性能优势
Card 04 方法描述

方法描述

  • System 1–2 架构：VLM 任务预测器（System 2）以 1 Hz 接收最近 W=5 帧视频、PAM 文本及固定指令“Proactively help the user before they ask.”，输出自然语言任务或 NO_ACT；VLA 执行器（System 1）执行预测的原子任务
  • PAM 结构：以 JSON 结构化文本序列化进预测器提示词，状态描述活动阶段，每状态触发–动作对连接线索与辅助任务，转移捕获活动进程变化（如“拿起勺子”标志从备餐进入进食）
  • 触发设计原则：触发应发生在用户开始某个机器人可代劳的动作之前（如用户坐下并拿着空碗时，机器人先取来麦片）
  • 离线记忆反思更新：反思器接收每日采样帧、上一版 PAM 文本、当日动作历史摘要及用户反馈，启用思考模式识别错过机会、推断重复模式，新增/修订状态、规则和转移
  • 预测器禁用思考模式以保证实时性，反思器启用思考模式进行深度推理；PAM 在单日内保持固定，仅在每日结束时更新
Card 05 数据集与资源

数据集与资源

  • 5 天桌面惯例评测数据：单一用户执行相同晨间桌面流程，每日录制约 3.5–4.5 分钟，1 fps 采样，共 1,146 帧标注（Day1–5 分别为 270/248/224/207/197 帧）
  • 标注标签为 6 个主动任务（T1 Cereal→Person、T2 Milk→Person、T3 Cereal→Storage、T4 Milk→Storage、T5 Bowl→Storage、T6 Wet Wipe→Trash）与 NO_ACT 共 7 类
  • VLM 模型：任务预测器与反思器均使用 Qwen 3.5–27B，通过 vLLM 部署，温度 0.3
  • VLA 执行器：基于 π0.5 微调，每任务采集 10 条遥操作演示
  • 训练资源：NVIDIA B200 GPU，有效批大小 64，微调 50,000 步，AdamW 优化器
  • 硬件平台：Franka Research 3 (FR3) 7-DoF 机械臂 + Deoxys 实时控制器（20 Hz），3 个 Intel RealSense 相机（2 个背向 + 1 个腕部），TactAR（Meta Quest 3）遥操作接口
Card 06 评估与结果

评估与结果

  • 评测任务：将主动任务预测形式化为逐帧分类问题，报告六类任务的 precision、recall、F1 及宏平均，以及 first-fire delay（首次触发延迟）
  • 基线设置：记忆无关基线 LIT、Event-driven VLM、Zero-shot VLM；记忆变体对比 Ours w/ List Memory 与 Ours w/ FSM Memory；VLA 对比 π0.5、π0.5 (Reasoning) 与 Ours
  • 记忆有效性：无记忆基线保持保守（大量输出 NO_ACT），T1–T6 召回接近零且五天无提升；Zero-shot VLM 从第 2 天起即停滞
  • 记忆设计消融：List Memory 早期饱和；FSM Memory 逐日持续提升，取得最高 precision、recall 与 F1，首次触发延迟从 Day 1 的约 5 秒降至 Day 5 的约 1 秒
  • 记忆适应与演化：用户从 Scenario A 切换到 Scenario B 时，A-Evolving 仅需一次记忆更新即可恢复到与从零构建记忆相当的水平，而冻结记忆版本 A-Frozen 持续低于 Zero-shot VLM；定性分析显示 Day 3→5 缺失的触发–动作对被补全，例行变化时相关转移被正确修订
  • 与单体 VLA 对比：单体 π0.5（含推理变体）在原子任务成功率上普遍更低（如 Milk→Storage 仅 0/10），联合优化推理与控制导致标签错误传播；本框架在表中所有六项任务上均取得最佳或并列最佳成功率（如 Cereal→Person 9/10、Cereal→Storage 8/10、Bowl→Storage 8/10、Wet Wipe→Trash 8/10）
  • 局限性：FSM 记忆在用户短暂接触触发物体时会误触发，降低 NO_ACT 召回；当前评测限于已见场景，未覆盖新物体、新布局或新用户，且框架不支持向用户主动询问澄清
