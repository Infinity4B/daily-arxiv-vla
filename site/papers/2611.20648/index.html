02研究单位

  • George Washington University（美国乔治·华盛顿大学）机械与航空航天工程系：Iman Sharifi、Peng Wei

03论文概述

  • 提出一个规则引导的视觉-语言-动作（VLA）框架，将符号化交通规则反馈融入策略优化，用于自动驾驶
  • 解决的核心问题：端到端 VLA 模型虽然能准确预测驾驶动作，但无法保证学习到的策略符合显式交通法规（模仿学习只衡量与专家演示的一致性，RL 依赖奖励设计，均不提供对成文交通规则的合规性评估）
  • 框架将监督微调（SFT）与强化学习微调（RLFT）相结合，奖励信号鼓励符合编码的交通规则，同时惩罚对专家动作的偏离

04核心贡献

  • 开发了将符号化交通规则反馈融入策略优化的 VLA 微调框架，同时保持与专家驾驶行为的一致性
  • 将选定的英国 Highway Code 条款（Rule 125 安全速度、Rule 126 安全跟车距离、Rule H 道路使用者优先级）形式化为可执行的一阶逻辑（FOL）规则，并构建符号评估器对候选动作进行上下文相关的合规性检查
  • 系统比较了三种基于分组的 RL 优化方法：GRPO、GDPO 和 Dr. GRPO，通过离线评估和规则消融实验分析其对动作预测精度和规则合规性的影响
  • 实验证明符号规则反馈可在不牺牲控制精度的前提下提升规则合规性，最佳方法将整体规则通过率从 92.9% 提升至 97.6%

05方法描述

  • 两阶段学习：先用专家演示和推理标注进行监督微调（SFT），再用规则引导的强化学习微调（RLFT）优化策略
  • 策略架构：基于 Qwen3-VL-2B-Instruct 骨干网络，使用 LoRA 适配器（rank=16）；添加可学习的 [ACT_TOKEN]，动作头（MLP + GELU）输出连续的油门和转向控制，语言头自回归生成驾驶推理
  • 符号规则评估：使用冻结的 Qwen2.5-VL-7B-Instruct 从视觉观测中提取场景谓词，借助 PyReason 符号推理引擎进行逻辑推断，结合运动学自行车模型预测候选动作的短时域后果，评估规则满足/违反/不适用状态
  • 奖励设计：规则合规奖励（对活跃规则评分取平均加小奖励项）减去模仿惩罚（与专家动作的 L2 偏差）；三种 RL 变体的区别在于组内优势计算方式（GRPO 标准化、GDPO 分量解耦归一化、Dr. GRPO 不除以标准差且省略 KL 正则化）

06数据集与资源

  • 使用 CARLA 仿真器收集数据：基于规则的智能体在多个城镇（住宅、城市、高速、多车道）和晴/雨天气下行驶，记录前视 RGB 图像、车辆运动学状态、导航指令和控制动作
  • SFT 训练集约 20,000 张 CARLA 图像（80/20 训练-验证划分），测试集约 3,600 张图像（涵盖行人过街、雨天、高速等场景）
  • 自动生成三步推理标注（感知-分析-反应）作为语言监督信号
  • 训练资源：单块 NVIDIA RTX 5070 Ti GPU（16 GB VRAM），混合精度训练；SFT 4 个 epoch（batch size 16，lr 2e-5），RLFT 15 个 epoch（lr 1e-6，每组采样 4 个候选动作）

07评估与结果

  • 评估环境：CARLA 仿真离线评估，在约 3,600 个held-out样本上比较 SFT 与三种 RLFT 方法（每个方法 3 个随机种子，报告均值±标准差）
  • 评估指标：油门/转向的 MAE 与 RMSE、整体规则通过率/违反率、逐规则符号合规分数（[-1,+1]）、场景条件级合规分析、规则消融实验
  • 关键结果：Dr. GRPO 表现最佳——整体规则通过率从 SFT 的 92.93% 提升至 97.59%，违反率从 7.07% 降至 2.41%；油门 MAE 从 47.38% 降至 19.16%，转向 MAE 从 18.70% 降至 5.36%
  • 逐规则分析：安全速度规则从 0.92 提升至完美合规（1.0）；道路使用者优先级规则从 SFT 的完全违反（-1.0）提升至 Dr. GRPO 的完美合规（1.0），GRPO/GDPO 达 0.88；安全跟车距离规则最难，仅从 0.75 提升至约 0.80
  • 场景级分析：SFT 在结冰路面场景下安全速度合规仅 43.6%（因专家演示本身不完全合规），RLFT 提升该场景合规 56.4 个百分点达到完美
  • 消融研究：每条规则主要监督其对应行为——移除 Rule H 使其违反率从 0% 升至 6.1%，移除 Rule 126 使跟车距离违反率从 5.9% 升至 8.0%；移除单条规则对油门/转向误差影响很小，说明符号奖励主要影响安全决策而非动作回归能力
