BiDex-100: A Comprehensive Benchmark for Bimanual Dexterous Manipulation Across 100+ Simulation Tasks

02论文概述

  • 提出 BiDex-100，一个面向 双手灵巧操作 的 MuJoCo 仿真基准，包含 106 个任务，覆盖 泛化、指令遵循、有限演示、长程、记忆 五大能力轴。
  • 每个任务配有 域外（OOD） 变体，包含受控的外观、布局、干扰物、物体尺度和左右镜像变化，用于系统评估鲁棒性。
  • 提供 8,080 条成功验证的遥操作演示（约 625 万帧），并在统一协议下评测 7 个近期 VLA 模型，建立能力、鲁棒性和数据效率基线。
  • 要解决的问题：现有基准大多基于单臂或平行爪夹具，缺少高自由度双手灵巧操作、能力诊断式评分和配对 ID/OOD 评估。

03核心贡献

  • 构建 能力导向的双手灵巧操作基准：106 个声明式任务按五大能力轴组织，可形成可解释的能力画像，而非单一总分。
  • 提出 匹配的 In-Domain / Out-of-Domain 评估协议：每个任务都有可复现的 OOD 变体，使域内性能和鲁棒性可直接比较。
  • 发布 大规模遥操作数据集：8,080 条成功验证的演示、6.25M 帧，覆盖 106 个任务，支持 LeRobot v2.1/v3.0 格式。
  • 完成 7 个 VLA 模型的统一参考评测：提供能力分层、 ID→OOD 退化、低数据学习和过程评分基线。

04方法描述

  • 双实体平台：主要使用 双 Franka Research 3 臂，每臂配 22-DoF 灵巧手，总计 58-DoF 动作空间；10 个厨房泛化任务使用 Astribot S1 人形机器人。
  • 观测与动作：头部、左腕、右腕三路 RGB-D 相机（480×360@25Hz）+ 本体感受状态；动作输出为 58 维关节目标，仿真运行于 MuJoCo（500Hz 物理，25Hz 控制）。
  • 声明式任务规范：每个任务由区域、物体、关节初始状态、复合目标和语言指令/指令调度定义；目标是若干子任务的谓词合取。
  • 进度评分机制：采用 latch 语义、must-hold 谓词、latch-violation 谓词 和 有序子任务 防止退化；严格成功率为所有子任务有效完成状态乘积，过程分为加权和（0-100）。
  • OOD 变换：包括场景随机化、相机外参变化、布局变化、干扰物注入、物体缩放和左右镜像，所有模型在相同种子和随机化键下评估。
  • 演示采集与重定向：通过 FACTR 型外骨骼手套 和 Apple Vision Pro WebXR 遥操作，统一优化重定向管道生成 58-DoF 数据。

05数据集与资源

  • 数据集名称：BiDex-100 数据集；包含 8,080 个成功验证片段、6.25M 帧，总大小 94GB。
  • 数据格式：提供 LeRobot v2.1/v3.0 格式（parquet + H.264 mp4）；每片段含 6 路 480×360 彩色/深度图像、58-DoF 动作、130 维观测、子任务进度和可复位初始状态。
  • 物体资产：使用 266 个唯一可见资产，来源包括 RoboCasa-Objaverse、Lightwheel、HOPE、Turbosquid、Articraft 等。
  • 模型规模：评测的 VLA 骨干约为 2B–4B 参数，例如 PaliGemma-2B、Cosmos-R2-2B、Qwen3.5-2B、Qwen3-VL-4B、Gemma3-4B；动作专家约 300M–1B。
  • 训练资源：论文正文未明确披露训练所用 GPU/TPU 数量；训练遵循各模型官方配置和优化步骤。

06评估与结果

  • 评估协议：每任务在 ID 和 OOD 各用 2 个固定种子 × 25 episodes（共 50 次 rollout），每模型总计 10,600 次 rollout；报告严格成功率与过程分（0-100）。
  • ID 总体结果（成功率 / 过程分）：LingBot-VLA-v2 52.21 / 70.22 最佳；π0.5 50.40 / 68.97；GR00T-N1.7 42.32 / 63.43；OpenDM-DM05 23.06/40.66；Galaxea G0.5 21.68/41.73；Xiaomi XR1 4.40/20.67；InternVLA-A1.5 1.51/8.98。
  • OOD 总体结果：GR00T-N1.7 5.45 / 20.65 最佳；π0.5 3.30/14.77；LingBot-VLA-v2 1.68/11.54；其余模型更低。
  • 能力诊断：记忆、长程任务普遍最弱；ID 长程任务最高成功率仅 38.20%，但最高过程分达 66.78，说明大量接近完成的尝试被二元成功隐藏。
  • 鲁棒性结论：所有模型在 OOD 下成功率显著下降，表明当前 VLA 对外观、布局、干扰物和尺度等分布外变化仍缺乏鲁棒性。
