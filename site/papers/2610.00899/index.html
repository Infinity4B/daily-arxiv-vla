TOAST: Stochastic Robot Action Tokenization for Autoregressive Vision-Language-Action Models

Card 02 论文概述

论文概述

  • 提出 TOAST（TOkenization of Action Sequences with STochastic Sampling），一种面向自回归视觉-语言-动作模型（VLA）的随机动作 tokenization 方法
  • 针对 FAST 等频率压缩 tokenizer 对同一量化动作序列仅分配单一确定性 tokenization 的问题，TOAST 在训练时采样多个等价 token 序列，在保留底层机器人动作的同时多样化离散监督
  • 在 LIBERO 仿真基准和四个真实机器人操作任务上验证了该方法在演示数据有限时提升策略学习效率的有效性，无需额外收集机器人数据
Card 03 核心贡献

核心贡献

  • 识别确定性动作 tokenization 是导致策略过度依赖单一离散表示的问题来源，并将随机 tokenization 形式化为自回归 VLA 的表示级正则化效应
  • 引入 TOAST 框架，通过 unigram 语言模型与 n-best 搜索采样等价 tokenization，使每个演示在不增加机器人数据的情况下产生更多样化的监督
  • 在 LIBERO 上证明随机 tokenization 的收益随训练数据减少而增大，仅用 1/16 数据时成功率提升 6.8 个百分点
  • 在四个真实机器人操作任务上将平均成功率提升 15.8 个百分点（对比确定性对应物），验证了数据受限真实场景下的实用价值
Card 04 方法描述

方法描述

  • 采用 DCT 量化（缩放因子 10）+ 维度主序展平（dimension-major flattening），使用 SentencePiece 在量化动作序列上构建 unigram 语言模型，词表大小为 512
  • 训练时通过 **Forward-DP Backward-A\* 算法**进行 n-best 搜索（n=64），按 P(t^i\|q) ≈ P(t^i)^α / Σ P(t^j)^α 的多项分布采样候选 token 序列，α 控制采样分布尖锐度（LIBERO 用 α=0.1，真实机器人用 α=0.5）
  • 所有采样的 token 序列都解码回相同的量化动作序列；采样仅用于训练阶段，推理时保持贪婪解码；策略架构和标准下一 token 预测损失不变，仅修改训练目标表示
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO（Spatial/Object/Goal/Long 四个任务套件），Franka Emika Panda，10 Hz 控制频率，7 维末端执行器动作
  • 真实机器人：Franka Research 3，配备 RealSense D405 腕部相机、两台 RealSense D435 场景相机和 Robotiq 2F-85 夹爪；四个任务（Table Bussing、Grocery Bagging、Breakfast Setup、Drawer Stowing）通过 GELLO 遥操作收集 200/200/100/60 条演示
  • 词表构建：来自 DROID 数据集的 1M 动作块（外部语料，LIBERO 用末端执行器动作，真实机器人用关节角）
  • 策略骨干：PaliGemma-3B，从视觉-语言预训练权重微调；30,000 步训练、batch size 32、AdamW 优化器，推理在单张 RTX 4090 上生成 1 秒关节角块耗时 168 ms
Card 06 评估与结果

评估与结果

  • LIBERO 评估：每套件 500 次 rollout（每任务 50 次）、每随机种子共 2,000 次；数据规模取 1/k（k∈{1,2,4,8,16}）；使用分层 bootstrap（10,000 次重采样）进行显著性检验
  • TOAST 在 LIBERO 所有数据规模下均优于确定性对应物：1/1 时 91.4 vs 90.9，1/8 时 60.2 vs 55.0，1/16 时 42.8 vs 36.0（+6.8）；在 1/4 及以下数据时超越全部基线（FAST+、FAST rebuilt、BEAST、VQ-VLA、Binning）
  • 真实机器人：TOAST 平均成功率 50.8%，比 TOAST (deterministic) 高 15.8 点、比 FAST+ 高 20.0 点，两者均显著；除 Grocery Bagging 外所有任务均获得较大收益
  • 设计分析：α 在 [0.05, 1.0] 区间内性能稳定；词表越贴近目标域采样增益越大（仅用 LIBERO 词表时 +11.9 点）；维度主序展平优于时间步主序；随机训练将等价 tokenization 的损失差距降至接近零（Δtok），且持出集 loss 更低；训练额外开销仅 0.4%
