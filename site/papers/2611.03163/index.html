02论文概述

  • 提出 FineCraft 框架，用于在 MetaFine Challenge 挑战赛中适配预训练模型完成细粒度操作（fine-grained manipulation）
  • 解决的问题：细粒度操作需要同时耦合指令 grounding、局部视觉精度和持续执行能力，即在遵循指令的前提下作用于正确的物体部件/属性，并满足空间与时间约束
  • 通过任务路由的策略混合体（task-routed mixture of policies），在统一的观测-动作接口下选择独立适配的 DINOv2-DiT 或预训练 π₀.₅ 策略完成五个任务

03核心贡献

  • 提出任务路由的策略混合体（MoP）架构：由任务 ID 选择独立的任务策略，两类骨干网络覆盖五个任务实例
  • 针对不同任务定制视觉特征与训练示范：局部视觉特征帮助识别指令指定的物体部件，演示数据与专家续写（expert continuations）教会所需动作
  • 执行过程中基于新观测进行动作重规划（replanning），结合候选动作块比较、阶段分类器切换等反馈机制
  • 在 MetaFine Challenge 五个任务上总得分 0.878，排名第四，并在所有任务和评估维度上超过官方公布的 π₀ 参考基线（平均提升 44.8 个百分点）
  • 代码开源：https://github.com/eqcy/FineCraft

04方法描述

  • 任务选择与动作执行：回合重置时由任务 ID τ∈{1,…,5} 选择独立策略；观测包含两个 512×512 RGB 图像（基座/腕部相机）和 9 关节本体感知状态；动作 a_t∈ℝ⁸（7 关节 + 1 夹爪），按块预测并执行部分动作后重规划
  • DINOv2-DiT 视觉扩散策略（T1/T5）：DINOv2 提取双视角空间特征图，经热图与可见性头转为关键点和置信度；指令选择目标分支（瓶盖/瓶身或目标字母）；Diffusion Transformer（DiT） 从噪声预测动作序列
  • 预训练 VLA 适配（T2/T3/T4）：对 π₀.5 使用 LoRA 低秩适配（W = W₀ + UVᵀ）进行微调，每个任务有独立权重和动作归一化统计量
  • 指令接触学习（T1/T3）：T1 使用 π₀.5 教师离线生成完整成功轨迹，并对困难状态引入专家续写（DAgger 风格），重规划时比较三个候选动作块的差异度进行选择；T3 在同一物理场景演示红/蓝指令并涵盖相机与光照扰动
  • 反馈式插入完成（T5）：通用 DiT 策略 + 收尾策略 + 字母特定纠错策略的组合；四帧循环编码器融合关键点、局部视觉特征、机器人/动作历史与时间；学习到的相位分类器实现单向阶段切换（通用→收尾→纠错）

05数据集与资源

  • 基准：MetaFine Challenge 五任务协议（T1 瓶部件抓取、T2 马克杯搬运、T3 开关拨动、T4 立方体分拣、T5 字母插入）
  • T2 与 T4 各使用 300 条演示、30,000 次更新
  • T3 使用 864 条轨迹、共 88,059 帧动作数据（含接近、拨动、保持）
  • T1 cap 模型使用离线 π₀.5 教师生成的成功轨迹；body 模型混入专家续写动作
  • 论文未明确披露 GPU/TPU 训练资源与具体模型参数量

06评估与结果

  • 评估协议：遵循官方五任务挑战协议与 MetaFine 的感知（P）、理解（U）、行为（B）三维评估；任务得分 S_τ=(P+U+B)/3，总分为五任务平均
  • 官方结果（排名第四，总分 0.878）：T1 得分 0.796；T2（马克杯搬运）达 1.000 满分；T3 得分 0.925；T4 得分 0.987；T5 得分 0.681
  • 对比基线：在所有任务与维度上超过公布的 π₀ 参考（其均值 0.430），总增益 44.8 个百分点；立方体分类感知增益最大，字母插入的指令条件增益最大
  • T1 本地诊断：body/cap 指令在相同场景种子下分别成功 70/80 和 72/80；cap 相机与光照扰动测试新增 560 次 rollout，720 次 rollout 总体感知得分 0.874、综合得分 0.883
  • T5 诊断：感知与理解得分较参考分别提升 56.9 和 67.5 个百分点，但感知分数较低表明相机/光照扰动仍比固定场景中的指令变化更具挑战性
  • T3 适配研究：在三个本地开发组（每组 60 场景、540 次 rollout）上，持续训练使平均评估得分从 0.841 提升至 0.894，三组均有提升，且训练与评估场景种子不相交
