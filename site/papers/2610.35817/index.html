Pretraining Knows What, Simulation Teaches How: Compositional Generalization in a Sim-Trained Robot Agent

02论文概述

  • 提出 Zero-real Agent Policy (ZAP)：一个教会小型现成视觉语言模型（VLM）通过简单工具框架（harness）控制机器人的训练配方
  • 解决的核心问题：机器人策略需要同时具备语义推理（理解任务要求）和运动控制（将理解转化为精确物理动作），现有方法（VLA/WAM 端到端策略、Code as Policies、前沿大模型智能体）在速度、成本和泛化能力之间难以兼顾
  • 核心理念："Pretraining Knows What, Simulation Teaches How"——预训练赋予模型世界理解与推理能力（知道做什么），仿真训练教会模型运动控制（知道怎么做），全程不使用任何真实机器人数据

03核心贡献

  • 无教师的仿真训练配方：无需前沿教师模型、无需真实机器人数据，通过 SFT（使用自身成功轨迹挖掘）+ RL（GRPO）教会预训练 VLM 控制机器人，采用仿真与硬件完全一致的统一接口
  • 真实硬件迁移与新本体迁移：无真实机器人训练数据情况下，ZAP 在 10 个真实任务上达到 96.7% 成功率，匹配 GPT-6 Astra 且速度快 3 倍、成本低 17 倍；同一检查点无需再训练即可迁移到全新本体（单臂 Franka），在 RoboLab-120 上超过领先 VLA/WAM 基线
  • 泛化到新目标、语言与推理：在训练中从未出现的新物体、目标、策略和复杂推理任务上（试管入架、空中双臂交接、画井字棋 X、下国际象棋一步将杀）实现组合泛化
  • 密集奖励阶梯与自蒸馏初始化：设计针对部分进度的密集奖励机制，并通过 GRPO warm-up 挖掘成功轨迹 + 前缀树搜索解决 RL 冷启动问题
  • 消融验证：证明更好的 SFT 数据（更长时间的轨迹挖掘）可大幅提升泛化（17.2% → 58.3%），且配方在 9B 小模型和不同本体上同样有效

04方法描述

  • 基座模型：从 Qwen 3.6 27B 预训练模型出发，保留其世界理解与推理能力，仅通过仿真训练添加运动控制技能
  • 统一工具框架（Harness）：模型通过 5 个工具（move_to、set_gripper、change_query、update_todo、done）以对话方式控制机器人，命令绝对末端执行器位姿和夹爪开合，无抓取宏或运动原语；感知端用 SAM 3.1 分割 + 标定深度相机生成 3D 物体读数和标注图像
  • 仿真训练：在 Isaac Sim 中构建 40 个简单操作任务（抓取、单/多物体拾放、堆叠、重定向），采用 GRPO 强化学习，使用按任务类型手工设计的密集奖励阶梯（如接近 0.2、抓取 0.2、抬升 0.55、运输至 0.9、成功 5.0），并惩罚无效工具调用
  • 模型初始化：先运行短程 GRPO warm-up 并挖掘成功 rollout 作为 SFT 数据（近在线自蒸馏），对仍无法成功的任务采用前缀树搜索（每个任务最多约 1000 个叶子节点）生成成功轨迹
  • 关键创新：将推理（来自预训练）与运动（来自仿真）解耦，无抓取宏、输出完整末端执行器位姿，使运动技能可跨任务、跨本体组合

05数据集与资源

  • 训练数据：Isaac Sim 中自建的 40 个仿真任务（双臂 YAM），无真实机器人数据；SFT 数据来自挖掘的 3.9k 条成功轨迹
  • 评估基准：RoboLab-120（双臂 YAM 适配版与单臂 Franka 版）、10 个真实世界任务、多个全新泛化任务
  • 模型规模：主模型 Qwen 3.6 27B；消融实验使用 Qwen-3.5 9B（直接在单臂 Franka Isaac Sim 任务上训练）
  • 感知组件：SAM 3.1 分割 + 标定深度相机
  • 部署资源：vLLM 推理框架，单张 B300 GPU（$7.10/小时），2-token 多 token 预测头

06评估与结果

  • 评估环境：仿真双臂 YAM、真实双臂 YAM 硬件（10 个任务 × 3 次试验）、单臂 Franka 新本体迁移
  • 主要指标：任务成功率、每任务耗时、每轮耗时、成本（USD）
  • 仿真结果：RoboLab-120 双臂版上，基座模型 8.3% → SFT 58.3% → SFT+RL 74.0%，超过 GPT-6 Astra（72.2%）和 Opus 5.5（61.2%）
  • 真实世界结果：ZAP 达到 96.7%，与同框架下的 GPT-6 Astra（96.7%）持平，远超 Robocurve 框架下的 GPT-6 Astra（36.7%）、MolmoAct2 VLA（33.3%）和基座模型（16.7%）
  • 效率优势：平均每任务 146s vs 397s（3× 更快），每轮 6.2s vs 19.0s，成本 $0.29 vs $4.87（17× 更便宜）
  • 新本体迁移：零样本迁移到单臂 Franka，RoboLab-120 上达 55.9%，领先 Lakeside（51.0%）和 FLUX 3 Action（42.9%）等 SOTA VLA/WAM 基线 4.9 个百分点
  • 泛化能力展示：完成训练中从未出现的新任务——试管垂直插入试管架（可根据指令选择不同孔位）、空中双臂交接、在井字棋盘中心画 X、执行国际象棋一步将杀，均需预训练推理与仿真所学运动技能的组合
  • 消融结果：更长轨迹挖掘使 SFT 泛化从 17.2% 提升至 58.3%；9B 模型直接在 Franka 仿真任务训练后达 53.4%，超过 Lakeside（51.0%）和 FLUX 3 Action（42.9%），证明配方跨模型规模和本体有效
