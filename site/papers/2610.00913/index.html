Card 03 核心贡献

核心贡献

  • 提供了受控实验证据，表明 VLA 中最适合在线 RL 的层和 token 在不同下游任务间存在差异。
  • 提出 eRLT 方法，利用可学习路由 token 和轻量级层路由器，从冻结 VLA 的多层表示中构建固定维度的 RL token。
  • 设计了两阶段训练策略：先通过专家动作预测离线初始化路由模块，再在在线 RL 阶段通过 critic 的 Bellman 目标持续精炼路由参数。
  • 在 LIBERO 和 RoboTwin 共 7 个仿真任务以及两个真实高精度插入任务上验证了 eRLT 的样本效率优势。
Card 04 方法描述

方法描述

  • 采用 frozen VLA + 轻量级 actor-critic 框架，VLA 在整个过程中保持冻结。
  • Token-wise routing：在 VLA 输入前缀中附加 K 个可学习路由 token，在多个选定 VLM 层上通过注意力机制动态聚合视觉-语言特征。
  • Layer-wise routing：通过 softmax 归一化的可学习层权重（含温度系数）将各层汇总向量加权组合成最终 RL token。
  • Offline initialization：利用现有 SFT 演示数据，通过轻量动作探针预测专家动作 chunk，引导 RL token 保留动作精修所需信息。
  • Critic-driven online adaptation：将 critic 损失回传到路由参数，使 RL token 适应动作价值估计所需的任务进度和结果线索；actor 更新时冻结 RL token。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO（Drawer Opening、Bowl-to-Plate、Cabinet-Bowl-to-Plate、Two-Moka-Pots）和 RoboTwin（Adjust Bottle、Move Can–Pot、Place Container Plate）。
  • 真实世界任务：USB 连接器插入（99 条遥操作演示）和 主板排线插入（800 条遥操作演示），使用 RB-Y1 机器人左臂和两个腕部相机。
  • 基础模型：使用 π₀.₅ 基础检查点，任务特定 VLA 基于该检查点微调。
  • 训练资源配置：未明确说明具体 GPU/TPU 数量，但采用轻量级 RL 训练，VLA 冻结，仅训练小型 actor-critic 和路由模块。
Card 06 评估与结果

评估与结果

  • 主要评估指标：归一化学习曲线下面积（AUC），真实世界还报告最终 10 轨迹窗口内的成功率。
  • 仿真结果：eRLT 在全部 7 个任务上的平均 AUC 为 0.626，相比固定 VLA 特征压缩基线（RLT*，0.506）提升 23.7%，相比 VLA 无关编码器基线（DSRL*，0.585）提升 7.1%。
  • 真实世界结果：USB 插入任务中，eRLT 的 AUC 为 0.562，相对 RLT（0.269）提升 108.9%，最终窗口成功率从 50% 提升到 90%；排线插入任务中，AUC 从 0.484 提升到 0.710（相对提升 46.7%），二者均达到 100% 最终窗口成功率。
  • 消融实验表明，token-wise 路由、offline 初始化、layer-wise 路由和 online 适应均对性能有正贡献，其中 token-wise 路由影响最大；默认使用 1 个路由 token，更多路由 token 并不单调提升性能。
