02论文概述

  • 论文提出 GTA-2（Grounded Task Axes v2），是一个模块化多VLM框架，旨在解决传统机器人操作技能要么需要为特定任务预定义、要么粗粒度无法适配场景几何/控制细节的问题，同时规避端到端VLA策略决策不可解释、Code-as-Policies依赖固定原语的局限
  • 核心思路是将技能表示为可重用的以物体为中心的任务轴组件组合，通过分离抽象技能合成与场景特定落地，实现零样本生成可执行操作技能，无需任务特定机器人演示、策略训练或模型微调
  • 框架还支持细粒度的人工定向反馈，可针对技能生成 pipeline 的不同阶段修正错误，同时保留已生成的正确组件，无需重新训练整个策略

03核心贡献

  • 解决了前代GTA框架依赖人工设计任务分解、控制器配方、任务轴定义和参数选择的问题，实现全流程自动化技能生成
  • 提出包含4个专用VLM智能体的模块化 pipeline，分别承担任务分解、抽象技能构建、参数分配、视觉特征落地职责，各阶段输出结构化中间结果
  • 定义显式的任务轴技能表示，支持将操作技能表示为可组合的优先级任务轴控制器集合，包含关键点、轴定义、参数占位符，可跨场景复用抽象结构
  • 实现细粒度人工引导的定向修正能力，可将反馈精准指向出错模块，仅修正错误组件，保留正确部分，大幅提升技能成功率
  • 在14个真实机器人操作任务上验证有效性，平均零样本成功率达73.9%，定向修正后提升至90.7%，显著优于VLA和Code-as-Policies基线

04方法描述

  • 采用抽象到落地的因子化设计：首先由任务分解器将自然语言指令拆分为有序语义子任务序列，再由技能生成器将每个子任务映射为抽象（lifted）任务轴技能步骤，选择控制器组合、关键点/轴定义、参数占位符和优先级，高优先级控制器先执行，低优先级控制器投影到高优先级的零空间避免干扰
  • 场景落地阶段由两个模块协同完成：参数设置器为控制器占位符分配数值（如偏移量、力大小、方向目标等），视觉模块则将抽象的关键点和轴定义解析为当前RGB-D场景的3D度量坐标和单位方向
  • 确定性编译器将落地后的技能编译为可执行的机器人脚本，通过ROS接口输出位置、姿态、力、夹爪命令执行任务
  • 核心创新点在于将技能生成拆分为独立的专用VLM阶段，既保证中间决策的可解释性，也支持针对性的错误修正，同时任务轴控制器的组合方式支持复用抽象技能结构，仅需重新落地即可适配新场景配置

05数据集与资源

  • 未使用预训练的策略数据集，实验基于14个真实桌面机器人操作任务，涵盖拾放、铰接物体交互、接触丰富操作、工具使用、受限运动等类别
  • 模型：所有4个VLM智能体均使用Gemini 3.1 Pro，无任务特定微调；对比基线使用π₀.₅（DROID微调版）通用VLA策略
  • 实验硬件：UR5e机械臂、Robotiq 2F-85平行夹爪、ZED 2i固定双目相机（校准到机器人基坐标系），技能生成无需GPU/TPU训练，仅需VLM推理资源

06评估与结果

  • 评估环境：真实机器人实验平台，任务泛化对比实验中每个任务、每个方法进行20次独立试验，零样本与修正实验中每个任务进行15次独立试验
  • 评估指标：任务执行成功率（%）
  • 关键实验结果：

- GTA-2零样本平均成功率为73.9%，超过最强基线CaP-Primitive（42.5%）31.4个百分点，在接触丰富操作、工具使用类任务上优势更明显

- 经一轮定向修正后成功率提升至86.2%，两轮后达99.0%，所有任务在三轮修正内均能成功，修正后的技能可跨新场景配置复用，平均成功率保持90.7%

- 对比基线中，使用任务轴控制器的CaP-TAC在倒液体、切割、 sweeping等接触相关任务上优于传统原语基线CaP-Primitive，验证了任务轴表示对复杂操作的有效性；但CaP-TAC单步生成代码的耦合性导致整体性能低于GTA-2的多阶段分离式生成

- 反馈分布显示初始错误主要集中在技能生成器，修正后转向视觉模块，验证了pipeline各阶段对应独立的可修正错误模式
