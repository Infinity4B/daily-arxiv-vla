02论文概述

  • 论文提出 PhyDEX，一个通过“动态外部灵巧性”（dynamic extrinsic dexterity，即投掷任务）评估视觉-语言-动作（VLA）模型物理推理能力的基准
  • 现有基准主要评估夹爪-物体接触，忽略了物体与环境通过重力、摩擦、惯性、质量分布的交互；PhyDEX 要求机器人推断物体的质量、质心和摩擦，并将其投掷到运动学工作空间之外的目标位置
  • 核心问题：检验当前策略是真正理解物理，还是仅从训练数据中插值，并识别当前 VLA 模型在物理理解上的瓶颈

03核心贡献

  • 提出 PhyDEX 基准：包含 9 个投掷任务、35K 条轨迹（143 小时）和 100 个场景，覆盖均匀、不规则和动态质量物体，以及静态、多目标和移动目标三类目的地
  • 引入可扩展的全自动数据构建流水线，结合抓取生成、运动规划与闭环投掷优化，并在随机化物理属性下生成端到端数据
  • 在多种本体（机械臂、人形机器人）和真实世界中进行广泛评估，发现数据稀缺/鲁棒性不足与物理盲区是当前策略的主要瓶颈
  • 揭示两个关键瓶颈：预训练模型鲁棒性有限（约 89% 的失败发生在投掷之前），以及“物理盲区”（提供真值物理属性可使成功率约翻倍）

04方法描述

  • 基于 NVIDIA Isaac Sim 构建可扩展的全自动仿真数据生成流水线，包含四个阶段：环境构建、域随机化、轨迹生成与数据存储
  • 环境构建：从资产库中检索目标物体、目标容器与场景（UR5e 机械臂 + Robotiq 2F-85 夹爪），并放置干扰物体
  • 域随机化：视觉（相机位姿、光照）、轨迹（GraspGen-X 抓取候选、物体位置/朝向、机器人初始状态）和物理属性（质量缩放 [0.5, 2.0]、质心偏移 ±15 mm、摩擦系数 [0.8, 1.2]）三个维度的随机化
  • 轨迹生成：GraspGen-X 生成抓取位姿 → cuRobo 规划无碰撞接近轨迹 → 基于 SLSQP 的闭环投掷优化器（五次多项式关节轨迹 + 弹道拦截约束），迭代修正瞄准偏移直至投掷成功
  • 数据以 LeRobot 格式存储，包含多视角 RGB、力/扭矩（F/T）信号、本体感知状态与动作标签

05数据集与资源

  • 主数据集：35,357 条轨迹（143.2 小时，10 Hz），9 个投掷任务，100 个 RoboCasa 厨房场景；物体来自 RoboCasa、RoboTwin 2.0、Objaverse-XL（共 107 个资产：20 个目标容器、46 个均匀物体、37 个不规则物体、4 个动态物体）
  • 任务设计：三类物体难度（均匀 31.8%、不规则 39.2%、动态质量 29.0%）× 三类目标（静态单目标、静态多目标、移动单目标）
  • 跨本体数据：Unitree 人形机器人上生成 2,400 条轨迹；真实世界使用 UR10e 机械臂采集 3 种外观相同但物理属性不同的 3D 打印立方体（每物体 300 条示范）
  • 计算资源：数据生成使用 8 块 NVIDIA RTX A6000 GPU（128 并行环境，物理仿真 120 Hz）；微调使用 16 块 NVIDIA A100 (40GB) GPU

06评估与结果

  • 评估三个代表性 VLA：GR00T N1.7（通用型）、DynamicVLA（基于 SmolLM2 的 25 Hz 高频策略）、ForceVLA（多感官力觉 VLA）；指标为成功率（SR），每任务单独微调、每策略 50 次 rollout
  • 整体结果：所有策略成功率低于 3%（GR00T N1.7：0.9%，DynamicVLA：0.2%，ForceVLA：2.4%），无任何策略能完成移动目标任务
  • 多样性消融：引入多样性分数 α，当 α 从 1 降至 0 时 ForceVLA 从 3.3% 升至 35.3%（超十倍提升），表明高多样性是低分主因，但即使无随机化也无策略超过 44%
  • 物理属性注入：提供真值物理属性后，GR00T N1.7 提升 12.5%、ForceVLA 提升 24%，证实“物理盲区”是核心瓶颈
  • 人形机器人与真实世界评估呈现相同失败模式：真实世界中 ForceVLA 平均达 51.3%（得益于力/扭矩输入），GR00T N1.7 仅 10.7%，DynamicVLA 为 0%
  • 失败分析：约 89% 的失败发生在投掷前（抓取错误 38.5%、无效够取 28.8%、接近错误 22.0%），仅约 21.24% 的轨迹能成功抓取物体
