Card 02 论文概述

论文概述

  • 论文提出 Recursive Harness Distillation (RHD)，将强 agent 与 frozen VLA 交互产生的经验蒸馏为可复用的 playbook，供轻量 agent 在机器人操作中引导策略执行
  • 旨在解决 VLA 模型在动态任务和环境中执行失败时缺乏自适应干预能力的问题，通过累积和提炼人工干预经验来提升策略成功率
  • 核心目标是在不更新模型参数的前提下，让轻量 agent 复用强 agent 积累的干预知识，降低部署成本同时提升操作成功率
Card 03 核心贡献

核心贡献

  • 提出递归式蒸馏框架，通过强 agent 初始化 playbook，并利用轻量 agent 的执行反馈递归精炼，实现干预经验在跨 agent 间的复用
  • 形式化了 harness distllation 的策略优化视角，利用有限视界性能差分恒等式建立 playbook 优化的理论目标
  • 设计了三种可干预位点：instruction editing（修改语言输入）、attention guidance（调整视觉 token 注意力）、action correction（修正动作输出）
  • 在 SimplerEnv Bridge 和真实 Franka Panda 机器人上验证，轻量 agent 配合 playbook 成功率从 37.3% 提升至 64.0%，仿真中达到 66.7%，超过强 agent 无 playbook 时的表现
Card 04 方法描述

方法描述

  • 采用固定的 VLA 策略（GR00T-N1.7 或 π₀.₅），外部 agent 通过暴露的接口在推理过程中进行三层干预：指令转换 $f_I$、注意力偏置 $u^F$、动作变换 $f_A$
  • 强 agent (Astra, GPT-6) 首先在 frozen VLA 上交互产生经验 $\mathcal{E}_T$，提取初始 playbook $P_0$；轻量 agent (Luna, GPT-5.6) 使用 playbook 执行任务产生 $\mathcal{E}_{S,k}$，再由强 agent 根据执行结果递归修订 playbook
  • 通过搜索候选 playbook $\mathcal{C}_k$ 并在开发集上评估，采用阈值 $\eta$（教师成功率）作为接受标准，迭代精炼直到找到优于当前 playbook 的版本
  • 将问题建模为策略优化：$\max_{P \in \mathcal{P}} J_S(P) = \mathbb{E}_{\tau \sim p_{\mathcal{D}}(\tau;\Pi_{S,P})}[Y(\tau)]$，其中 $\Pi_{S,P}$ 是 agent 与 playbook 组合 induced 的执行策略
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：SimplerEnv Bridge 中的 4 个 WidowX 操作任务（spoon-on-towel、carrot-on-plate、cube stacking、eggplant-in-basket），使用 GR00T-N1.7-SimplerEnv-Bridge checkpoint，保留 12 个初始配置用于开发，12 个用于评估
  • 真实机器人：Franka Panda（7-DoF），配备腕部、前部和右侧 RGB 相机，执行 3 个任务（Cube-to-Tray、Cube Stacking、Button Pressing），使用微调后的 π₀.₅ 策略
  • Agent 模型：强 agent 为 GPT-6 Astra，轻量 agent 为 GPT-5.6 Luna，均通过 API 调用
  • 训练/开发资源：真实任务每任务收集 50 条人类遥操作演示用于微调 π₀.₅；开发过程每轮结合 8 个新教师案例与 8 个历史案例进行 playbook 修订
Card 06 评估与结果

评估与结果

  • 评估环境：SimplerEnv Bridge 仿真与真实 Franka Panda 硬件，每任务 25 次试验（真实环境）或 48 个实例（仿真）
  • 关键指标：任务成功率（%）、每回合平均 token 消耗、API 推理成本
  • 主要结果：

- 仿真 Bridge：仅 GR00T 为 41.7%，Luna 无 playbook 为 43.8%，Luna + refined playbook 达 66.7%，Astra + playbook 达 79.2%

- 真实环境：π₀.₅ 单独为 37.3%，Luna 无 playbook 为 0%，Luna + refined playbook 达 64.0%

- 消融实验表明 instruction editing 对性能贡献最大，移除后下降最显著

- 部署成本：Luna 每回合约 $0.63，Astra 每回合约 $3.43，轻量 agent 成本仅为强 agent 的约 1/5.5
