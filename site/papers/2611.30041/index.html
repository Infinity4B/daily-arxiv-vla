02论文概述

  • 提出 SpikingWAM，首个脉冲世界-动作模型（Spiking World-Action Model），将世界预测与动作生成统一在一个脉冲神经网络中
  • 解决现有世界-动作模型计算量大、难以在机器人上低功耗部署的问题，利用脉冲神经网络的稀疏事件驱动特性大幅降低规划能耗
  • 通过任务骨架状态替代密集视频表示，克服脉冲神经网络在细粒度操作任务中精度不足的障碍

03核心贡献

  • 提出 Task Skeleton State (TSS) 和配套的小型脉冲感知前端，将世界状态压缩为机械臂和任务物体的关键点，使事件和注意力集中在任务相关部位
  • 提出 Body Frame Spike Coding (BFSC) 和 Grid Coincidence Attention (GCA)，通过身体相对坐标编码和网格脉冲重合检测恢复整数脉冲丢失的毫米级精度
  • 提出 Persistent Single Step Readout (PSR)，实现单步读出和持久样本流，使每个规划只运行一次网络，并复用连续规划间的计算
  • 构建了首个稀疏事件驱动的脉冲世界-动作模型 SpikingWAM，在多个基准上达到与 ANN 方法竞争的性能，能耗降低一个数量级以上
  • 在模拟和真实机器人上验证了模型的有效性，真实机器人完成夹取放置任务的单次规划仅需 3.07 mJ

04方法描述

  • 任务骨架状态 (TSS)：使用机械臂关节的正向运动学关键点和由小型脉冲网络从图像中估计的物体关键点作为世界状态，替代密集视频表示
  • 身体框架脉冲编码 (BFSC)：将节点坐标同时编码为全局归一化坐标和相对于抓取点的相对坐标，并提高输入层脉冲等级数，减小量化误差
  • 网格重合注意力 (GCA)：受生物网格细胞周期放电和皮层神经元重合检测启发，将位置编码为网格脉冲码，通过脉冲重合直接计算相对几何关系并注入自注意力
  • 持久单步读出 (PSR)：利用流匹配在纯噪声处的速度场即为条件均值这一性质，将多次采样压缩为一次网络前传，并通过增量式脉冲传播复用连续规划之间的计算
  • 双专家架构：世界专家处理当前和未来骨架，动作专家处理含噪动作块，两者在每层共享自注意力，未来骨架仅在训练阶段使用

05数据集与资源

  • 模拟基准：LIBERO（40 任务，4 个套件）、LIBERO-Plus（10,030 扰动变体，7 种扰动类型）、RoboTwin 2.0（50 个双手操作任务，含 Easy 和 Hard 设置）
  • 感知前端训练使用程序化随机生成的图像，不使用 LIBERO-Plus 资产
  • 模型参数量约 0.15B（含文本编码器和感知前端），LIBERO 系列共享一个模型
  • 能量估算基于 45 nm 工艺，脉冲层累加能耗 0.9 pJ，连续值层 MAC 能耗 4.6 pJ

06评估与结果

  • LIBERO：平均成功率达到 98.25%（Spatial 98.1%、Object 100.0%、Goal 98.2%、Long 97.6%、Avg. 98.5%），与大规模 ANN 方法竞争
  • LIBERO-Plus：七种扰动条件下总成功率达到 88.76%，超过所有对比方法（含 ANN 大模型和轻量模型及脉冲 VLA）
  • RoboTwin 2.0：双手操作平均成功率达到 80.20%（Easy 和 Hard 设置），无需机器人数据预训练
  • 能耗：LIBERO 上单次规划能耗 1.467 mJ（含感知前端），比所有对比方法低一个数量级以上
  • 真实机器人实验：完成语言指令的夹取放置任务，成功率与 ANN VLA 相当，单次规划能耗 3.07 mJ
