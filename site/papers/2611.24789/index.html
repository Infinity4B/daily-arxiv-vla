HINT-WAM: Hindsight-Informed Training for World Action Models

01研究单位

  • 作者均来自 新加坡国立大学（National University of Singapore）
  • 作者包括 Phuong Tuan Dat、Qi Li、Xinchao Wang（通讯作者）

02论文概述

  • 论文提出了 HINT-WAM，一种面向世界动作模型（WAMs）的在线策略自蒸馏后训练框架
  • 针对现有 WAM 后训练方法（离线 SFT 存在曝光偏差和目标歧义，在线 RL 奖励稀疏）的不足，利用演示中的未来视频帧（后见之明）作为特权信息，让模型在自身采样轨迹上自我监督
  • 目标是在不依赖环境奖励或模拟器交互的情况下提升 WAM 在机器人操作任务上的可靠性和泛化能力

03核心贡献

  • 提出 HINT-WAM 框架：无需单独训练教师模型，仅通过添加轻量后见之明分支使同一模型同时充当教师和学生，且无需环境奖励或模拟器交互
  • 针对流匹配动作专家，设计了基于 能量分数（energy score） 的分布级蒸馏目标，避免速度回归导致的模式平均问题，且不需要动作似然评估
  • 在 LIBERO-90 和 RoboTwin 2.0 上全面验证，HINT-WAM 显著优于 SFT 和匹配基线，并有效缓解预训练技能的灾难性遗忘

04方法描述

  • 基于 Fast-WAM 架构，冻结大型视频专家，只训练轻量动作专家
  • 分三阶段：Stage 0 对动作专家进行 SFT 初始化；Stage A 冻结骨干，训练轻量后见之明编码器和门控交叉注意力适配器，使模型能读取未来视频帧作为教师；Stage B 在教师固定下，学生在自身 ODE 采样轨迹上通过能量分数匹配教师动作分布，并辅以行为克隆锚定项
  • 后见之明编码器：丢弃当前帧，空间池化未来帧并利用可学习查询进行多头注意力池化，得到后见之明 token
  • 门控交叉注意力适配器：以 Flamingo 风格的门控残差分支注入后见之明信息，零初始化为恒等映射
  • 能量分数目标：学生抽取 M 条采样轨迹，教师抽取一个动作样本，通过拉近学生样本与教师样本、推开学生样本间距离来匹配分布，避免模式平均

05数据集与资源

  • 数据集：LIBERO-90（90 个未见过任务，来自 LIBERO 四套件共享动作空间的演示，3921 条演示）和 RoboTwin 2.0（50 个双臂操作任务，选用预先选定的 25 个困难子集，干净和随机设置各 50 回合）
  • 模型规模：基础模型为已发布的 Fast-WAM 检查点；后见之明分支（编码器 + 适配器）额外增加约 13M 参数（约占 0.2%），仅教师使用
  • 训练资源：8 块 A5000 GPU，有效批量大小 192，使用 AdamW 优化器与余弦调度；Stage 0 训练 5000 步，Stage A 训练 2000 步，Stage B 训练 2000 步

06评估与结果

  • 评估环境：LIBERO 基准测试标准评估协议，每任务 50 次试验；RoboTwin 2.0 干净与随机设置各 50 回合
  • 主要指标：任务成功率（%）
  • LIBERO-90：HINT-WAM 成功率 85.18%，较 SFT 的 78.88% 提升 6.30%，较全 SFT 的 81.24% 提升 3.94%；同时超过 BC 控制 71.56%、自模仿 79.62%、乱序后见之明 80.28%
  • RoboTwin 2.0：HINT-WAM 在干净设置下 87.04%，随机设置下 83.68%，优于 BC 控制（85.36% / 82.08%）和全 SFT（84.12% / 83.24%），且几乎不损失预训练性能
  • 持续学习：无回放时 HINT-WAM 保留原始套件平均成功率最高（44.05%，SFT 为 37.45%，全 SFT 为 32.85%）；有回放时 HINT-WAM 新任务 81.56%、原始套件平均 95.10%，均显著优于 SFT 和全 SFT
  • 计算成本：HINT-WAM 训练时间约为 SFT 的 1.28 倍，仅为全 SFT 的 0.56 倍，但取得更高成功率；蒸馏单步比 BC 慢 1.5 倍，该开销仅存在于训练阶段
