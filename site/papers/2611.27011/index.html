02论文概述

  • 针对 VLA（视觉-语言-动作）模型在抓取操作中的局限：抓取失败后可能继续执行运输动作而非重试，导致局部错误升级为任务失败
  • 提出 FoRe（Force-guided Recovery）框架，利用力反馈实现自主抓取恢复
  • 解决两个关键问题：过度依赖本体感觉线索推进任务阶段、以及成功演示中重试监督不足

03核心贡献

  • 提出 FoRe 框架：集成两个阶段特定策略的独立训练、专用重试策略的局部强化学习优化、以及力引导的阶段控制，支持跨 VLA 骨干的自主抓取恢复
  • 构建 LIBERO-SUCTION 基准：一个力增强的吸力操作基准，包含 22 个任务、3 个套件、1,100 条完整演示轨迹，用于研究吸力抓取恢复
  • 在 LIBERO-SUCTION、LIBERO 和真实世界任务中，对 VLA-Adapter 和 π₀.₅ 均实现一致的任务成功率提升
  • 证明 FoRe 在每个任务仅一个演示的低数据条件下仍然有效

04方法描述

  • 阶段标注：利用力反馈和抓取命令状态，将成功演示自动划分为 接近-抓取（Stage 1） 和 运输-放置（Stage 2） 两个阶段
  • 阶段特定训练：分别训练 M₁（接近-抓取策略）和 M₂（运输-放置策略）
  • 重试策略优化：从 M₁ 初始化 M₃（重试策略），在模拟的失败后状态上使用局部强化学习（RL）进行细化，奖励基于提升测试成功与否
  • 推理时策略切换：控制器结合 力信号 和 抓取命令状态 在 M₁、M₂、M₃ 之间切换，通过接触丢失检测抓取失败并调用重试策略
  • 创新点：力引导的显式阶段控制缓解本体感觉混淆，局部 RL 补充重试监督

05数据集与资源

  • LIBERO-SUCTION：自建基准，22 个任务，1,100 条演示，覆盖 Suction-Spatial、Suction-Object、Suction-Goal 三类
  • LIBERO：现有基准，4 个套件（Spatial、Object、Goal、Long），40 个任务，用于平行夹爪抓取评估
  • 真实世界数据：在 DOBOT CR10AF 机器人上采集，使用 Robotiq EPick 真空吸盘和 Intel RealSense D435i 相机
  • 模型骨干：主要评估 VLA-Adapter 和 π₀.₅；基线包括 OpenVLA、OpenVLA-OFT、π₀、π₀-FAST、SmolVLA、GR00T N1
  • 训练资源：服务器配备 8 块 NVIDIA 4090 GPU；真实机器人上执行 on-robot RL

06评估与结果

  • LIBERO-SUCTION：VLA-Adapter 成功率从 69.2% → 87.6%（+18.4%），π₀.₅ 从 85.9% → 92.4%（+6.5%）
  • LIBERO：VLA-Adapter 从 91.0% → 98.6%（+7.6%），π₀.₅ 从 92.1% → 98.3%（+6.2%）；均优于 CycleVLA 基线
  • 真实世界任务：VLA-Adapter 平均成功率从 26.7% → 51.7%，π₀.₅ 从 48.3% → 70.0%；在 Long 任务上 VLA-Adapter 提升超过一倍
  • 低数据场景（每任务 1 个演示）：LIBERO-SUCTION 上 VLA-Adapter 32.8% → 55.5%，π₀.₅ 39.2% → 63.3%；LIBERO 上 VLA-Adapter 49.4% → 67.1%，π₀.₅ 46.5% → 64.7%
  • 消融实验：移除重试、RL 优化、阶段特定训练、抓取状态条件或力切换均导致成功率下降，其中移除力切换影响最大（-13.3%），验证各组件必要性
