Q-WAM: 4-Bit Quantization of World Action Models with Action-Subspace Protection

02论文概述

  • World Action Models (WAMs) suffer from prohibitive compute and memory costs during deployment, and existing post-training quantization (PTQ) methods such as smoothing, rotation, and SVDQuant fail to preserve action generation precision because they minimize local output error rather than tracking how quantization errors propagate through the full iterative denoising process to affect the final action.
  • This paper proposes Q-WAM, a 4-bit weight-activation quantization framework that preserves generated actions by introducing the Action Observability Gramian (AOG) to measure per-layer sensitivity of final actions to rounding errors, and Action-Subspace Protection (ASP) to keep only the most action-sensitive activation directions in 16-bit precision while quantizing the remainder to 4-bit.
  • The method is evaluated on three WAM architectures across RoboTwin 2.0 simulation and real-world tasks on Unitree G1 humanoid and bimanual UR3 robots, demonstrating substantial memory savings with minimal performance degradation.

03核心贡献

  • Introduce the Action Observability Gramian (AOG), a per-layer matrix that predicts how much rounding errors in each weighted combination of a layer's input channels change the final action through all denoising steps, estimated label-free using random probes.
  • Propose Action-Subspace Protection (ASP), which splits each protected linear layer into a small 16-bit low-rank branch for the most action-sensitive subspace and a 4-bit deflated path for the remainder, both implemented as efficient dense GEMMs on GPUs.
  • Develop a method to identify which experts in Mixture-of-Transformers (MoT) architectures require protection by aggregating AOG-derived action mass across layers, concentrating protection on high-sensitivity experts (e.g., the action expert in Fast-WAM and ImageWAM carries 89.3–99.99% of action mass despite holding under 20% of parameters).
  • Achieve state-of-the-art results on RoboTwin 2.0 (89.6–93.0% success rate, within 1.1 percentage points of bf16) and real-world robots, outperforming SVDQuant by 2.5–8.7 points in simulation and 12.8–17.6 points in physical deployment, while reducing targeted-block memory by 3.1–3.4×.

04方法描述

  • Action Observability Gramian (AOG): For each layer ℓ, AOG is defined as $G_\ell = \mathbb{E}\big[\sum_{i \in \mathcal{I}_\ell} J^{(i)\top}_\ell J^{(i)}_\ell\big]$, where $J^{(i)}_\ell$ is the Jacobian of the final action with respect to the layer input at token-step pair i. It approximates the expected squared change in final action caused by rounding errors $\delta_\ell$ via $\delta_\ell^\top G_\ell \delta_\ell$. Estimated efficiently using random probes $u \sim \mathcal{N}(0, I_m)$: a single backward pass of $\langle a, u \rangle$ returns $J^{(i)\top}_\ell u$ for all layers and token-step pairs simultaneously, requiring only $P=12$ probes per input instead of $hd_a$ exact backward passes.
  • Action-Subspace Protection (ASP): After applying smoothing and rotation to handle activation outliers, the AOG is rotated into this coordinate system ($\widetilde{G}_\ell$). Its top-$r$ eigenvectors (where eigenvalues decay rapidly, Figure 3b) define the action subspace. The activation $\tilde{x}$ is split into protected component $V(V^\top \tilde{x})$ inside this subspace (computed in 16-bit via $(V^\top \widetilde{W})^\top (V^\top \tilde{x})$) and remainder $\tilde{x}_\perp$ orthogonal to it (computed in 4-bit via $Q_4(\widetilde{W}_\perp)^\top Q_4(\tilde{x}_\perp)$). The top-$r$ eigenvectors are proven optimal for minimizing action distortion under isotropic rounding errors.
  • Expert Selection: For MoT models, the action mass $\mu_E = \sum_{\ell \in E} \text{tr}(\widetilde{G}_\ell)$ of each expert $E$ is computed. ASP is applied only to experts with highest action mass per added 16-bit value. In Fast-WAM and ImageWAM, the action expert holds under 20% of parameters but carries 89.3–99.99% of action mass, so only the action expert is protected, while LingBot-VA (shared backbone) covers all layers.

05数据集与资源

  • Datasets/Benchmarks: RoboTwin 2.0 (50 simulation tasks with 100 demonstrations, evaluated under clean and randomized conditions); real-world evaluation on Unitree G1 humanoid (tool sorting, item classification) and bimanual UR3 arms (table cleaning, cube stacking, drawer manipulation) with 25 trials per task.
  • Models: Fast-WAM (2-expert MoT with video generation backbone), ImageWAM (2-expert MoT with image editing backbone), LingBot-VA (shared backbone for video and action).
  • Resources: Calibration on NVIDIA H100 GPUs; simulation evaluation on NVIDIA L40S GPUs; real-world inference on NVIDIA RTX 5090. Quantization uses group size 32 with protection rank $r=32$.

06评估与结果

  • Environment: RoboTwin 2.0 simulation and real-world robotic setups (Unitree G1, bimanual UR3).
  • Metrics: Task success rate (%), bits per weight (BPW), memory consumption (GB), normalized root-mean-square error (NRMSE) of generated actions, Pearson correlation for AOG prediction accuracy.
  • Results:

- Q-WAM achieves 90.78% (Fast-WAM), 92.97% (ImageWAM), and 89.56% (LingBot-VA) average success on RoboTwin 2.0, dropping only 0.29–1.03 points from bf16 upper bounds (91.81%, 93.26%, 90.52%).

- Reduces targeted-block memory by 3.1–3.4× (Fast-WAM: 11.85→3.44 GB; ImageWAM: 9.11→2.69 GB; LingBot-VA: 10.16→3.27 GB).

- Outperforms SVDQuant by 2.5–8.7 percentage points in simulation and 12.8–17.6 percentage points in real-world tasks.

- AOG predicts per-layer quantization damage with Pearson correlation $\rho=0.95$, significantly outperforming local output error ($\rho=0.04$).
