论文概述

  • 提出 Magic-W0，一个结构化世界-动作基础模型（World–Action Foundation Model），旨在为物理智能（Physical Intelligence）提供更强的世界建模能力
  • 核心问题：现有世界-动作模型（WAMs）缺乏结构化、面向控制的世界表示，且世界预测与动作生成之间的耦合不够紧密
  • 通过Structured World Transition（结构化世界转移）将环境演化组织为 Current State–Transition–Future State 三阶段，并将世界预测与连续动作生成双向耦合在统一模型中
Card 03 核心贡献

核心贡献

  • 结构化世界-动作基础模型：提出 Magic-W0，将机器人交互建模为 Current State–Transition–Future State，其中 Current State 结合 VLM 上下文与 Current 3D Geometry，Transition 用 3D Motion 表示，Future State 用 Future Semantics 表示
  • 层对齐双向耦合架构：设计世界-动作交互架构，3D 流、语义流和动作专家在多个网络深度通过层对齐联合注意力持续交换信息，实现 action-conditioned world transition 与 world-informed action generation
  • 统一跨具身表示：构建统一的 34 维状态-动作接口，涵盖关节、夹爪、末端位置和旋转，支持来自第一人称人类操作、UMI、真实机器人和模拟数据的异构预训练
  • 大规模预训练与高效微调：在约 201.4 万个有效操作片段和 261 万视觉语言样本上联合预训练，仅需少量下游数据即可实现复杂真实机器人任务的快速适配
Card 04 方法描述

方法描述

  • 使用 Qwen3.5-2B 作为 VLM 主干，多视角图像、语言指令和本体感觉状态编码为任务上下文
  • 动作生成采用 Flow Matching 连续动作专家，行动块包含 50 个时间步，默认 10 步欧拉积分
  • 世界表示包含三个预测头：Current 3D Geometry（当前几何）、3D Motion（跨时间三维运动）、Future Semantics（未来语义），均由冻结的教师模型（Track4World、DINOv3）在训练时提供潜在空间监督
  • 采用 Gated DeltaNet 进行流内更新，在层 4、8、…、24 处进行跨流联合注意力交互
  • 预训练时使用梯度隔离（knowledge insulation），世界与动作损失不反向传播到 VLM 主干；微调时移除隔离
  • 推理时缓存 VLM 键值，每个积分步重新计算 3D、语义和动作流，实现世界-动作联合演化
Card 05 数据集与资源

数据集与资源

  • 预训练操作语料库：约 201.4 万有效片段，涵盖第一人称人类操作、UMI、真实机器人和模拟四个采集域
  • 视觉语言语料库：约 261 万样本，包括 EO-Data1.5M、Robo2VLM-1 和自建标注
  • 动作-世界时间对齐：根据各数据源的采样倍率动态计算未来帧偏移（如 EgoDex 的 ρ=1.95，偏移 26 帧），确保动作块与世界监督描述同一交互过程
  • 模型以 Qwen3.5-2B 为 VLM 主干，附有 3D 流、语义流和动作专家三个独立参数流，共 24 层
Card 06 评估与结果

评估与结果

  • RoboDojo-Sim：42 个仿真任务，Magic-W0 平均 Score 27.10，为所比较的世界-动作模型中最高；在 Generalization 维度表现尤为突出
  • LIBERO：用于评估多任务操作与长时程任务，主要衡量在场景随机化下的表现
  • 真实机器人：在 5 个下游操作任务上微调后表现强劲，验证了有限数据下的泛化与快速适配能力
  • 机制分析：推理时干预实验表明，结构化世界表示会随候选动作变化而响应，且动作相关信息通过共享 3D 表示传播到未来语义预测中，证实了双向交互的有效性
