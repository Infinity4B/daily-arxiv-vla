Card 03 核心贡献

核心贡献

  • 提出分解论证：在同一固定策略下对比端到端与 oracle 差距，定位 VLA 记忆任务的真正难点在 memory-to-grounded-subgoal 阶段。
  • 提出 Gamma 系统：以 SAM-3 作为空间 grounding 工具、VLM writer 逐 tick 蒸馏出一行 grounded 文本、append-only 文本记忆库承载全部历史、VLM reasoner 仅读文本库输出下一 grounded 子目标。
  • 提出通用 propose–verify harness 契约：每个智能体声明（事件、进度、grounding）都必须通过机械视觉证据检查，被 admit / defer / correct / reject；该契约在训练语料构造与部署时完全一致。
  • 在 RoboMME 十六任务上以固定策略取得非特权方法最好成绩，并不改契约迁移到第二个基准 RoboMemArena。
  • 给出tick 级诊断协议，把闭环失败归因到具体的记忆行或缺失，转化为可修复的记忆缺陷。
Card 04 方法描述

方法描述

  • 系统结构：与策略 replan tick 对齐，每 tick 先运行 writer 后运行 reasoner；两个智能体不共享隐藏状态，唯一接口是可读的文本记忆库。
  • Detector（grounding tool）：使用 SAM-3（facebook/sam3）配合按类调优的文本提示，逐帧输出 name⟨x,y⟩ 检测串；训练语料生成与部署使用完全相同的检测器、提示与后处理。
  • Agent-1（memory writer）：微调 VLM，每 tick 从窗口帧、检测结果、已有记忆和上一子目标中提取视觉身份 ι与视觉动态 δ，输出至多一条 grounded 文本行或 none。
  • 文本记忆库：append-only 列表 M_k = M_{k-1} ⊕ m_k，永不重写或摘要，保证信息不被选择器丢弃、每条事实可核查、数百步压缩为少量行。
  • Agent-2（reasoner）：微调 VLM，完全不用像素，仅读指令与整个文本库输出下一 grounded 子目标，训练目标为 oracle 字符串逐字匹配；只能引用库中已有的坐标。
  • Propose–verify harness：将声明分为 event / progress / grounding 三类，用小型通用感知词汇表（存在性、遮挡、到达半径、位移阈值）按声明类型参数化判定，处理admit（生效）、defer（挂起重试，不推进计划）、correct（修正 grounding 绑定）、reject（丢弃，含重复或由证据提取器拥有者）。
  • 训练几何：writer 先在验证过的事件行语料上微调（上下文中给真值 bank），再 rollout 生成预测 bank，reasoner 在预测 bank 上以 oracle 子目标为目标微调，保证训练分布与部署一致。

Card 06 评估与结果

评估与结果

  • 评估协议：闭环运行，每任务每 serving seed 30 个 episode，9B 配置用 3 个 serving seed、单一 agent checkpoint；基线与 oracle 行为 RoboMME 官方报告值，指标为环境成功谓词下的 episode 成功率。
  • 主结果：Gamma 在 16 任务上平均 66.0%，比此前最好的非特权方法 FrameSamp+Modul（44.5%） 高 +21.5，达到特权 GroundSG oracle（84.1%） 的 78.5%；在 9/16 任务上为最优非特权方法，并在 PickXtimes、PatternLock、RouteStick 上达到 oracle 上限。
  • 分组表现：shuffle/reveal（身份类）任务约为最佳基线的两倍（VUS 75.6 vs 38.0，VRP 65.6 vs 30.4，VPO 66.7 vs 36.0）；按键计数任务领先（BU 84.4，BUS 35.6）；路径追踪任务达到 oracle（PL 98.9，RS 56.7）。
  • 规模对比：0.8B 智能体版本平均 57.4%，仍大幅优于所有非特权基线，显示 harness 契约在小模型上依然有效。
  • Harness 消融（9B）：去掉 defer 平均降至 62.7（BU 84→57，BUS 36→13）；去掉 reject 降至 55.1（PL 99→3，RS 57→7）；去掉 correct 降至 65.0（绑定类任务损失 4–7 点）；不启用完整 harness 亦明显低于 66.0，说明收益主要来自机械审计契约而非模型本身。
