Ego2X: Contact-aware Transfer from Egocentric Human Data to Any Robot

02论文概述

  • 论文提出 Ego2X，一个以物体为中心的框架，将单目第一人称人类操作视频转换为物理可执行的机器人数据，支持灵巧手与平行夹爪。
  • 核心目标是解决现有 ego-to-robot 流水线中“手指悬空、夹爪夹空”的物理不可行问题，通过显式建模物体表面的接触点、力、抓取模式与交互状态来提升接触精度与下游策略成功率。
  • 论文强调应转移物体参照系下的接触动态而非单纯的手部运动轨迹，从而克服单目深度漂移、跨形态差异与视频合成中的物体擦除问题。

03核心贡献

  • 提出 CORE（Contact-centric Object-interaction REpresentation）：在物体坐标系中记录每个接触的锚点、法向、推力方向、相对力、抓取模式与交互状态，作为统一表示贯穿整个转换流程。
  • 开发 CORE 驱动的 Ego2X 框架：集成接触驱动的解耦深度校正、跨形态逆运动学、接触感知的视频擦除与合成，以及 URDF 编译与闭环仿真验证。
  • 首次利用 第一人称视频对 VLA 模型进行后训练：仅用 Ego2X 转换的机器人数据（无需仿真专家演示）即可显著提升下游任务成功率。
  • 在多个基准上验证了 物理接触实现与几何精度：HOT3D 上手部深度误差降低 33.7%，EgoDex 上接触实现率 62.9%（官方 HuRo 为 27.9%），平行夹爪接触适配率 63.2%（Ego2Robot 为 9.7%）。

04方法描述

  • 手与物体的几何重建：使用 WiLoR、ACE-Ego-Hand、EgoHand 等恢复 3D 手部网格，用 SAM 3D 重建物体带符号距离场（SDF），FoundationPose 跟踪物体 6-DoF 位姿。
  • CORE 提取：利用触觉时序检测与相机射线-物体表面求交得到接触锚点；根据 MANO 表面区域分类 7 种抓取模式与 5 种交互状态；引入视觉相对载荷分布与运动学支撑载荷先验，形成结构化力先验。
  • 解耦深度校正：用无真实标记训练的单调 GBDT 评估物体位姿可信度，分别沿物体路径与手部路径优化深度，避免手-物尺度耦合的循环漂移；手部沿相机射线做 1-DoF Cauchy 优化。
  • 接触驱动逆运动学：对灵巧手，将 URDF 碰撞几何采样为与抓取模式匹配的接触垫，用 Geman–McClure 残差、法向对齐与推进方向约束求解关节角；对平行夹爪，在物体 SDF 上搜索对跖接触对并生成物体参照系抓取。
  • 接触感知擦除与合成：在 Acquire/Hold/Transport 状态下保护物体区域不被擦除；通过去皮肤边缘掩模保留原始物体像素，仅去除手部重叠区域，避免人类皮肤残留。
  • 仿真验证与数据编译：URDF 编译器自动映射接触垫与抓取参数；在 RoboTwin 2.0 中进行闭环物理回放，筛除不通过物理验证的片段，生成 LeRobot 格式的机器人数据用于 VLA 后训练。

05数据集与资源

  • 数据集：HOT3D（评估接触恢复与深度校正）、EgoDex（评估跨形态重定向与视频转换）、RoboTwin 2.0（闭环仿真验证与 VLA 后训练）。
  • 接触标注：基于 HOT3D 多摄像头 MoCap 接触真值（MANO 与物体网格距离 ≤ 5 mm 且连续 ≥ 3 帧），EgoDex 用于接触实现率评估。
  • 模型与工具：涉及 WiLoR、EgoHand、SAM 3/ SAM 3D、FoundationPose、DROID-SLAM、ProPainter 等基础模型；自身模型包括手部/物体几何重建、CORE 提取、位姿可信度 GBDT、接触驱动 IK 与渲染模块。
  • 训练资源与模型规模：论文未明确提及 GPU/TPU 型号或数量；后训练仅使用从视频转换的 Ego2X 数据，没有依赖仿真专家演示（具体 GPU 规模未说明）。

06评估与结果

  • 评估协议：采用 cluster-bootstrap 95% 置信区间、Wilcoxon 符号秩检验与 Holm 调整 McNemar 检验；评价指标包括 F1、IoU、接触锚点误差、MPJPE、射线误差、物体平移误差、接触实现率、成功任务率。
  • 接触恢复（HOT3D）：CORE 在可靠位姿下帧 F1 0.924、3D 锚点误差 2.39 mm（消融前 6.69 mm）；在估计位姿下目标深度融合使帧 F1 从 0.191 提升至 0.386。
  • 深度校正（HOT3D）：接触时手部射线误差降低 33.7%；估计位姿下物体平移误差降低 30.4–47.3 mm；位姿可信度 GBDT 在多个划分上 AUROC 达到 0.789–0.899，优于单特征 IoU。
  • 重定向与编译（EgoDex）：灵巧手接触实现率 62.9% vs HuRo 27.9%；平行夹爪物理接触适配率 63.2% vs Ego2Robot 9.7%；省略接触项的手腕跟随消融实现率显著下降。
  • 闭环仿真与 VLA 后训练（RoboTwin 2.0）：在 200 个配对场景中，X-VLA 零样本任务成功率 40.5%，后训练后提升至 67.0%；闭环仿真转换通过率 59.6%，而对比方法仅 1.9%。
