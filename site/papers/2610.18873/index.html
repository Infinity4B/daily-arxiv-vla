02论文概述

  • 论文提出 LoopWAM，一个闭环世界-动作模型，可直接从部署 rollout 的全质量谱（成功、次优、失败）中学习并改进通用机器人策略。
  • 研究目标：解决仅扩展专家演示无法让通用策略从部署中持续改进，以及混合质量 rollout 中“模仿所有动作会强化坏行为、过滤失败会丢弃物理交互信息”的难题。
  • 核心思路：让所有质量的轨迹按行为质量和观察到的转移贡献监督，并讓视频与动作 token 在并行去噪中双向交互，使学习到的后果直接参与动作生成。

03核心贡献

  • 提出 LoopWAM，支持从部署 rollout 直接改进通用策略，并兼容来自自身和其他部署策略的经验。
  • 设计 源相关噪声采样，在单一模型中统一行为学习与动作条件世界建模。
  • 引入 质量引导 与 质量加权监督，保留全质量视频监督，同时调控动作模仿强度（失败轨迹 λ=0，专家 λ=1）。
  • 通过 并行视频-动作去噪 和双向注意力，使世界预测特征直接参与动作生成，无需单独的后果评估阶段。
  • 在真实与仿真基准上验证闭环自改进，并在多个任务上取得领先结果。

04方法描述

  • 采用 Mixture-of-Transformer 双流扩散 Transformer：视频分支初始化自 Wan2.2-TI2V-5B，动作 DiT 隐藏维度为 1024，使用流匹配训练。
  • 视频和动作目标独立加噪，block attention mask 连接 observation、future video、action token，支持跨模态双向交互。
  • 源相关噪声采样：专家数据视频噪声服从 Beta(7,1)，动作噪声服从基础分布；rollout 数据视频噪声服从基础分布，动作噪声服从 Beta(1,7)，以增强动作条件世界建模。
  • 质量引导：将质量分数 q 作为指令后缀（如“Quality: q”）输入，部署时使用专家分数 q* 采样。
  • 质量加权监督：视频监督覆盖所有质量；动作损失按非递减权重 λ(q) 加权，失败轨迹不做动作模仿但保留世界模型梯度。
  • 闭环自改进：部署收集 rollouts，质量标注后与专家演示和累积 rollout 一起重训，迭代进行部署-训练循环。

05数据集与资源

  • RoboChallenge Table30-V2：真实机器人基准，包含 30 个桌面操作任务和 4 种本体（ALOHA、DOS-W1、ARX5、UR5）。
  • RoboTwin 2.0：仿真双手机器人基准，包含 50 个任务；使用 2,500 条 clean 专家演示、25,000 条随机化专家演示，以及 22,500 条来自 LoopWAM、X-VLA、π0.5 的 rollout。
  • RoboCasa365：仿真家庭操作基准，包含 50 个任务，采用 Human300 训练划分，训练数据含专家演示与 RLDX-1 rollout。
  • 模型资源：视频 backbone 初始化自 Wan2.2-TI2V-5B，动作 DiT 隐藏维度为 1024；总参数量与训练 GPU/TPU 资源在可见正文中未明确说明。
  • 训练与评估使用不同随机种子以避免数据泄漏，多相机视图拼接为单图，动作和机器人状态按专家数据统计归一化。

06评估与结果

  • 评估环境：真实机器人 RoboChallenge Table30-V2，仿真基准 RoboTwin 2.0 与 RoboCasa365，另有真实衬衫折叠单任务后训练。
  • 主要指标：成功率（SR, %）和 score；仿真中按 clean/randomized 或 Atomic/Composite/Unseen 等设置分别报告。
  • RoboChallenge Table30-V2：三轮部署-训练将成功率从 23.67% 提升至 28.00%、37.67%、43.33%，提升 19.7 个百分点；最终 score 为 56.80，在比较方法中成功率和 score 均第一。
  • RoboTwin 2.0：平均成功率 94.5%（clean 94.6%，randomized 94.4%），优于 AHA-WAM 1.7 个百分点，优于 LingBot-VA 2.0 0.9 个百分点。
  • RoboCasa365：总体成功率 49.5%（Atomic-Seen 79.7%，Composite-Seen 50.3%，Composite-Unseen 14.9%），超过 ABot-M0.6 2.9 个百分点。
  • 衬衫折叠：两轮部署驱动改进将成功率从 13.20% 提升至 32.54% 和 55.56%，score 从 14.44 提升至 38.89 和 67.78。
  • 消融实验表明：质量引导对混合质量 rollout 学习关键，即使粗粒度标注也有效，质量加权动作监督可进一步提升性能。
