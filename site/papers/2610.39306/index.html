Card 02 论文概述

论文概述

  • 提出 CAD-WAM 框架，用于从文本描述生成可编辑的 CAD 模型，通过耦合几何条件动作生成与下一状态预测来提升多步建模的可靠性。

  • 受世界-动作模型启发，将动作学习与未来几何状态预测结合，并利用 CAD 内核执行提供准确的几何反馈。
Card 03 核心贡献

核心贡献

  • 提出 CAD-WAM，一种将几何条件动作生成与下一状态预测相耦合的文本到 CAD 框架，推理时通过内核执行实现闭环几何反馈。
  • 设计操作级 CAD DSL，将草图、拉伸和布尔操作组合为完整动作，确保每一步都产生有效实体；并引入基于 SetVAE 的紧凑潜在几何状态表示。
  • 构建逐步训练数据集，将 DeepCAD 模型转换为 DSL 动作序列并与专家文本描述配对，提供每步的动作及对应几何结果作为监督。
  • 在 DeepCAD 测试集上证明模型优于现有任务特定和通用语言模型，尤其对需要更多操作的模型增益更大；消融实验表明状态预测头可使平均 Chamfer 距离降低 13.2%。
Card 04 方法描述

方法描述

  • 将 CAD 建模过程形式化为状态依赖的动作序列，每个动作由 DSL 定义，通过 CAD 内核（CadQuery）确定性更新当前 B-rep 几何。
  • 使用预训练的 SetVAE 编码器将中间实体表面点云编码为 1024 维潜在几何状态，并提供给模型作为条件输入和预测目标。
  • 模型架构：几何状态嵌入将潜在向量映射为 16 个几何 token，与文本 token 一同输入共享的 LLM 骨干（Qwen2.5-1.5B-Instruct）；动作头生成下一个 DSL 动作，状态预测头回归下一个潜在状态。
  • 训练时联合优化动作 token 的交叉熵损失和状态预测的 MSE 损失，SetVAE 编码器冻结；推理时闭环生成，预测动作由内核执行，新几何重新编码后输入下一步。
Card 05 数据集与资源

数据集与资源

  • 使用 DeepCAD 数据集（178,238 个参数化 CAD 模型），并配对 Recap-OmniCAD 提供的专家级文本描述。
  • 构建逐步训练数据集，经筛选后得到训练 157,945 个模型（475,656 条记录）、验证 8,755 个模型、测试 7,962 个模型。
  • 模型基于 Qwen2.5-1.5B-Instruct 骨干（约 1.5B 参数），额外引入几何状态嵌入和状态预测头共 11.4M 参数（不足骨干参数的 1%）。
  • 使用 CadQuery 作为 CAD 内核执行动作；训练硬件和超参数详见论文附录 C。
  • 代码公开在 GitHub: https://github.com/Lzy-1037/CAD-WAM
Card 06 评估与结果

评估与结果

  • 评估环境：DeepCAD 测试集 7,962 个模型，采用统一几何评估协议（网格化、归一化、采样一致），比较生成模型与参考实体的几何精度和有效性。
  • 主要指标：无效率（IR）、Chamfer 距离（CD）、Hausdorff 距离（HD）、法向一致性（NC）、边缘 Chamfer 距离（ECD）、交并比（IoU）、欧拉特征匹配率。
  • 关键结果：CAD-WAM 在大多数指标上最优，无效率 0.666%，平均 CD 1.142，中位 CD 0.166，IoU 0.964，Euler 匹配 95.85%，优于所有任务特定基线；与最强通用模型 GPT-6 Astra 相比，平均 CD 更低（1.142 vs 1.755）。
  • 消融实验表明：状态预测头使平均 CD 从 1.316 降至 1.142（降低 13.2%），无效率从 0.779% 降至 0.666%；潜在状态表示优于文本状态表示。
