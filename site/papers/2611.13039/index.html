02论文概述

  • 提出 Robo-MLT（Robotic Medical Laboratory Tasks），一个面向长时程医学实验室任务的双系统机器人操作框架。
  • 解决的问题：医学检验流程步骤严格有序、不同阶段视觉上高度相似（感知混叠），且操作员可能随时干预、移除样本，要求机器人既能跟踪工作流阶段，又能在不可完成时调整剩余计划。
  • 通过分离低频率的工作流监控与高频率的连续动作生成，Robo-MLT 使机器人能够区分“插入”与“拔出”等视觉相似阶段，并在样本被移除后继续处理其他样本。

03核心贡献

  • 提出 Robo-MLT 分层框架：将显式的低频率工作流监控与高频率生成式控制分离开，分别负责离散决策和连续轨迹生成。
  • 开发轻量级多帧执行监控器 System 2：包含完成头和恢复头，判断当前技能是否已完成、是否已无法完成，并触发基于当前场景的剩余流程重规划。
  • 在两个真实医学实验室任务上进行评估：血气分析和血液样本管分拣，包括对比实验、消融实验、离线切换时序分析以及样本移除干扰测试。
  • 验证了在操作员移除机器人手中样本后，系统可重新规划并继续完成其他样本，而非停滞等待。

04方法描述

  • 顶层规划：使用冻结的 Qwen3.7-Max API 作为规划器，根据任务指令、操作规程和初始场景观测，在原子技能库（$\mathcal{S}$，血气分析 7 个技能，分拣 5 个技能）上生成有序技能序列；同一模型也作为重规划器。
  • System 2（低频率执行监控器）：采用冻结的 SigLIP2-300M 图像/文本编码器、因果时序 Transformer 与交叉注意力构建技能-时序特征；两层 MLP 头分别预测完成概率和恢复概率；恢复触发后调用 VLM 重规划器修订剩余流程。
  • System 1（生成式执行器）：基于 Qwen3-VL-2B 骨干（从 StarVLA 权重初始化）提取多视图语义特征，结合机器人本体状态，通过流匹配（flow matching）生成连续动作片段。
  • 异步推理框架：控制环频率 20 Hz，动作块长度 N=30；System 2 以固定节奏 K=15 步采样观测历史（窗口长度 M=6），System 1 通过预取、动作拼接与首段混合实现高频率动作流，避免慢速监控阻塞手臂控制。

05数据集与资源

  • 自采集遥操作数据集：血气分析 1200 个示教片段、血液样本管分拣 1000 个示教片段；包含完整长时程示教（带技能起止标注）和单原子技能随机初始位姿示教，以及干扰/失败片段用于恢复头正样本训练。
  • 模型规模与组件：规划器 Qwen3.7-Max（冻结 API）；System 1 Qwen3-VL-2B + 流匹配动作头；System 2 SigLIP2-300M 编码器 + 时序 Transformer + 双 MLP 头。
  • 硬件平台：Agilex 双臂 Static-Aloha 机器人，三台 Intel RealSense D435i RGB 相机（一个全局视图 + 两个腕部视图）；训练使用 NVIDIA A100，部署使用 RTX 4090。

06评估与结果

  • 评估环境：真实机器人平台，两个任务——血气分析（7 个技能，含 5 mm 进样口精确对齐）和血液样本管分拣（凝血/常规管随机放置，需规划拾放顺序）。
  • 评估条件与基准：名义执行 50 组预设配置，样本移除干扰 20 组配置；基线包括 ACT、SmolVLA、π₀、π₀.₅、VLM-Monitor，以及多个 Robo-MLT 消融变体和 Oracle Pointer。
  • 主要评估指标：任务成功率 SR、样本完成率 SCR、完成时间；离线监控器评估采用技能边界分类（准时/过早/过晚/漏检），只有所有边界准时才算工作流正确。
  • 关键实验结果：Robo-MLT 在长时程、存在感知混叠的医学检验任务中表现出更高的端到端成功率；在样本移除干扰下，System 2 能识别当前技能不可完成并触发重规划，使机器人继续处理其余样本；消融实验表明移除 System 2、时序上下文或重规划通路均会降低恢复成功率与任务完成表现。
