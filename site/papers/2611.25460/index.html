LoongForge-Embodied: A Unified Framework for Training Heterogeneous Embodied Models

提出 LoongForge-Embodied，一个原生 PyTorch 框架，用于统一和加速异构具身模型（VLA 和 WAM）的训练。

02论文概述

  • 提出 LoongForge-Embodied，一个原生 PyTorch 框架，用于统一和加速异构具身模型（VLA 和 WAM）的训练。
  • 针对 VLA/WAM 模型架构异构、训练栈碎片化、系统优化难以跨模型复用的问题。
  • 核心思路是通过统一抽象层解耦模型特定实现与共享训练基础设施，既支持跨模型复用又保留模型级优化灵活性。

03核心贡献

  • 统一训练框架：通过公共抽象层统一异构 VLA 和 WAM 架构的训练，实现跨模型的训练基础设施复用。
  • 系统级加速：开发可组合加速栈，涵盖高效注意力内核、图编译、CUDA Graphs、算子与优化器融合、数据加载，以及针对 FSDP 和 DDP 的 FP8 分布式通信优化。
  • 评估加速：通过并发 episode 执行、降低每 episode 推理和渲染开销、复用策略无关计算，将评估墙钟时间减少 4.1×–23.2×。
  • 广泛实证验证：在九个代表性 VLA/WAM 模型和多个常用具身基准上评估，实现 1.47×–4.38× 训练吞吐量提升，同时保持与官方基线相当的任务成功率。

04方法描述

  • 采用配置驱动的模型注册、轻量级模型接口和可扩展训练引擎，实现统一抽象层与训练执行模板。
  • 提供可组合加速工具包，包括高效注意力（FlashAttention-2/3、FlexAttention）、混合精度（FP8/BF16）、算子融合以及 torch.compile 和 CUDA Graphs 等执行优化。
  • 分布式训练支持 DDP、FSDP2 和 HSDP，并引入 FP8 通信优化（delta-FP8 AllGather、AllToAll-AllGather 梯度压缩）以降低通信开销。
  • 统一数据基础设施：格式无关数据集抽象，支持 LeRobot 和 HDF5，并通过 Ego2Robot 实现跨具身数据合成。
  • 评估框架采用训练对齐的客户端-服务器架构，基于 WebSocket RPC，支持并发评估、动作块缓存和计算复用。

05数据集与资源

  • 支持的数据集格式：LeRobot（v2.0/2.1/3.0）和 HDF5。
  • 评估基准：LIBERO、CALVIN、SimplerEnv、RoboTwin、ManiSkill。
  • 涵盖模型：π0.5、GR00T N1.7、X-VLA、Wall-OSS-0.5、FastWAM、LingBot-VA、DreamZero (Wan2.2-TI2V-5B)、Cosmos 3 等九个代表性模型。
  • 训练资源：论文提到 CUDA、GPU 架构（Ampere/Hopper），但未在可见部分明确列出具体 GPU 型号和数量。

06评估与结果

  • 训练吞吐量提升：相比各自开源基线，实现 1.47×–4.38× 端到端训练吞吐量提升。
  • 评估速度提升：在相同协议下，评估速度提升 4.1×–23.2×。
  • 训练保真度：保持训练损失行为一致，任务成功率与官方基线相当。
  • 通信优化：FP8 通信降低梯度同步和参数收集流量，特别是在带宽受限环境下效果显著。
