Utility-WAM: Correcting Future-Induced Action Changes

02论文概述

  • 论文研究 World Action Models (WAMs) 中由预测视觉未来引起的动作变化（动作增量 Δa），即未来条件路径与无未来路径在同一模型下的行为差异。
  • 发现平均基准成功率几乎不受未来信息影响（LIBERO +0.8 点，RoboTwin 2.0 -0.8 点），但存在未来诱导的负迁移：少数精度任务（如 Press Stapler、Place Can Basket）性能严重崩溃（损失高达 54.0 和 34.0 点），且该现象在不同 WAM 变体中反复出现。
  • 论文提出 Utility-WAM，旨在纠正未来诱导的有害动作变化，同时保留有益的长期预见，并通过选择性跳过视频生成来降低推理开销。

03核心贡献

  • 形式化未来诱导的负迁移：将动作增量 Δa 定义为核心研究对象，证明小平均效应掩盖了在精度任务上集中且可复现的严重性能退化。
  • 定向动作纠正：提出残差适配器，在冻结的共享 WAM 上修复未来诱导的速度增量，通过真实未来对齐和过多误差惩罚，使 Press Stapler 和 Place Can Basket 的损失分别从 54.0 和 34.0 降至 6.0 和 14.0 点，同时保持其他任务和长程任务性能。
  • 自适应推理路由：训练轻量级门控网络，在视频生成前预测当前查询是否需使用未来信息，在 RoboTwin 2.0 上仅对 24.5% 的查询生成视频，降低 38% 延迟，同时将平均成功率提升至 93.3%（RoboTwin 2.0）和 98.9%（LIBERO）。
  • 真实世界验证：在双臂操作平台上，Utility-WAM 在 60 次试验中成功 53 次（88.3%），相比 FAST-WAM 的 43 次（71.7%）显著提高。

04方法描述

  • 基于 FAST-WAM 架构和 Wan2.2-TI2V-5B 骨干网络，构建共享 WAM，支持两种动作路径：无未来路径（π_wo）和未来条件路径（π_w）。
  • 三阶段训练：Stage 1 联合训练视频和动作 DiT，两种动作路径共享参数；Stage 2 冻结 WAM，训练残差适配器，通过动作损失、对齐损失（向真实未来支持的速度增量靠拢）和过多误差惩罚（限制超过未来自由基线的误差）来修正速度增量；Stage 3 冻结前两部分，训练轻量级门控网络，使用适配器的成对动作结果预测未来信息是否有益。
  • 适配器以未来自由速度为锚点，当真实未来无增益时抑制偏离，反之进行有益修正；门控网络在推理前运行，选择执行未来条件路径（经适配器修正）或无未来路径，从而在保证性能的同时节省视频生成计算。

05数据集与资源

  • 仿真基准：LIBERO（40 个任务，2000 次试验，执行 10/32 预测动作）和 RoboTwin 2.0（50 个任务，每个任务 100 次试验，干净与随机化条件，执行 24/32 动作）。
  • 模型规模：骨干网络为 Wan2.2-TI2V-5B（约 50 亿参数），残差适配器和门控网络为轻量级附加模块。
  • 训练资源：每个基准训练一个模型，具体 GPU/TPU 细节在论文附录中说明，未在摘要中明确列出。

06评估与结果

  • 评估环境：LIBERO 和 RoboTwin 2.0 模拟环境，以及真实世界双臂操作平台（两个 AgileX PiPER 手臂，三个 RGB 视角）。
  • 主要指标：任务成功率（百分比）、动作增量 ΔJ（百分点）、推理延迟、有效视频生成步数（N_eff）。
  • 关键结果：

- 未来条件路径在 LIBERO 上平均 +0.8 点，在 RoboTwin 2.0 上平均 -0.8 点，但个别任务损失严重（Press Stapler -54.0，Place Can Basket -34.0）。

- Utility-WAM (Correction) 将上述任务损失降至 6.0 和 14.0 点，同时 LIBERO-Long 增益保持不变（98.4% vs 97.8%）。

- Utility-WAM (Selective) 在 RoboTwin 2.0 上仅对 24.5% 查询生成视频，延迟降低 38%，平均成功率达 93.3%（RoboTwin 2.0）和 98.9%（LIBERO）。

- 真实世界测试中，Utility-WAM 成功率 88.3%（53/60），显著高于 FAST-WAM 的 71.7%（43/60）。
