02论文概述

  • 提出了 Event-VLA，一个事件增强的视觉-语言-动作框架，旨在提高机器人在光照退化（如低光、运动模糊）条件下的操作鲁棒性。
  • 解决了现有 VLA 模型通常假设良好光照和稳定 RGB 输入，导致在真实世界视觉观测退化时语义基础和动作预测失效的问题。
  • 引入事件流作为对光照鲁棒且对运动敏感的补充观测，并通过动作查询路由路径融合，以保留预训练的 RGB-语言语义先验。

03核心贡献

  • 将退化可见度下的 VLA 操作建模为事件到 VLA 的接口问题，并提出了 PREI，一种将事件流分解为动作时间物理残差的轻量级方法。
  • 提出了 Event-VLA，一种动作条件接口，将事件 token 保留在语义骨干网络之外，并通过门控交叉注意力和查询引导路由将其注入动作表征。
  • 在 LIBERO、LIBERO-Cross 和真实世界 Franka 任务上验证了该接口在提高低光鲁棒性的同时，保持了正常光照下的 VLA 性能。

04方法描述

  • PREI (Physical Residual Event Integration)：将异步事件流转换为 3 通道残差图（瞬时、显著、持久），分别捕获最近的机器人-物体运动、局部显著活动和短期轮廓。
  • Action-Conditioned Event Interface：使用可学习的动作查询和事件查询在 VLA 骨干内提取语义。事件 token 通过 门控交叉注意力 与 VLA 隐藏状态融合，并通过查询引导路由选择性地导向动作槽，避免了直接的全局语义 token 合并。
  • Auxiliary Event Head：基于路由的事件 token 和动作表征预测未来的 PREI 目标，作为训练期间的辅助正则化，在推理时可移除。

05数据集与资源

  • 数据集：LIBERO、LIBERO-Cross（本文提出的渐进式可见度退化扩展）、N-ImageNet、LIBERO 视频（通过 v2e 生成事件）、真实世界 Franka 演示数据（80 演示）。
  • 基础模型：Prismatic-7B，使用 OpenVLA 权重（在 OXE 上预训练）初始化。
  • 训练资源：8 张 H100 GPU，batch size 64，约 140k 训练步数。

06评估与结果

  • 评估环境：LIBERO（正常光照）、LIBERO-Cross（LL-Mild/Dark/Severe）、真实世界 Franka（正常/低光/近黑暗）。
  • 主要评估指标：Success Rate (SR)。
  • 正常光照结果：Event-VLA 在 LIBERO 上平均 SR 达 96.5%；禁用事件路径（Ours w/o event）仍达 96.2%，证明事件接口保留了 RGB-语言先验。
  • 严重退化结果：在 LIBERO-Cross LL-Severe 设置下，Event-VLA 平均 SR 保持 95.6%，而 RGB 基线（如 π0, MM-ACT）下降至 61-69%。
  • 真实世界近黑暗结果：Event-VLA 在近黑暗条件下 SR 达 52.5%，显著优于 π0 (15.0%) 和 OpenVLA-OFT (12.5%)。
  • 消融实验：PREI 表征和 Query routing 接口在提供最佳鲁棒性的同时，仅增加极小的推理延迟开销 (+2.157 ms)。
