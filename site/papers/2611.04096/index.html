02论文概述

  • 论文提出并实现了一个基于 CUDA 的实时 GPU 求解器，用于计算 Hamilton–Jacobi (HJ) 可达性中的后向可达管 (BRT)，在机器人控制循环内运行。
  • 解决传统 HJ 水平集方法因计算复杂度随状态维度指数增长而只能离线使用的问题，使安全关键自主系统能够在线重新计算 BRT。
  • 面向下一代自主系统（如 ADAS/AV、人形机器人、视觉-语言-动作策略）中黑箱概率策略的安全保障需求，提供确定性的安全层。

03核心贡献

  • 实现了经典 WENO5 + TVD-RK3 + Lax-Friedrichs 水平集 HJ 求解器的 CUDA 版本，支持 2D、3D 和 4D 动力学，在单块工作站 GPU 上达到控制级求解速率（如 3D Air3D 112 Hz，4D 追击-逃避 61 Hz）。
  • 提出了 FP32 精度模式，相比自身 FP64 路径加速 21–33 倍，相比 JAX 参考实现 hj_reachability 在相同精度下加速 5.9–17.5 倍，且 BRT 集合偏差在亚网格级。
  • 在八个基准案例上验证了求解器的数值准确性：FP64 下与 hj_reachability 点对点一致，并复现 Mitchell Air3D BRT 至细胞计数误差 0.04%。
  • 展示了嵌入式平台性能：在 NVIDIA Jetson AGX Thor 上 Air3D 达 66 Hz、2D 漂移器达 54 Hz，证明可部署于机载环境。
  • 提出内核算子标签传播扩展，从单次组合 HJ 求解中恢复 K 智能体捕获盆 Voronoi 划分，成本不随舰队规模增长，并在野火响应仿真中验证（6 架四旋翼，4.0 ms/tic，标签一致性 99.5%）。

04方法描述

  • 求解 Hamilton–Jacobi–Isaacs (HJI) 偏微分方程，采用后向积分和 Mitchell 的 BRT 钳位操作（V ← min(V_new, V_old)），将 BRT 表示为值函数的零下水平集。
  • 数值离散：空间梯度采用五阶 WENO (WENO5) 重构，时间积分采用三阶 TVD Runge-Kutta (TVD-RK3)，数值哈密顿量使用 Lax-Friedrichs 耗散，并用 CFL 条件限制时间步长。
  • GPU 核结构：每个 TVD-RK3 阶段融合为单个核（包括 WENO5 重构、哈密顿量、阶段合并、BRT 钳位），减少全局内存往返；采用除法精简的 WENO5 重构（一次浮点除代替 13 次）；主机端静态 CFL 步长；3D 求解器使用 CUDA Graph 减少每步开销。
  • 边界条件支持 Neumann 外推和周期性；提供静态障碍物和 reach-while-avoid 两种后处理器。
  • 实时模式使用一阶迎风格式（RK1 + upwind）用于多智能体演示，单核每步，支持 ping-pong 缓冲。
  • 多智能体扩展：在核内进行标签传播，类似竞争快速行进，从单个 HJ 求解恢复 K-agent Voronoi 捕获盆。

05数据集与资源

  • 基准案例：8 个案例，涵盖 2D 完整/二重积分、2D 漂移器（常风、空间风、有障碍）、3D Mitchell Air3D 追击-逃避、4D 双车辆追击-逃避（含墙变体）。
  • 网格规模：2D 案例 N 最高 200（200×200 单元），3D Air3D N 最高 101，4D 追击-逃避 N 最高 51（约 10^6 单元）。
  • 硬件资源：主要基准使用 NVIDIA RTX 4000 Ada (20 GB)，嵌入式验证使用 NVIDIA Jetson AGX Thor。
  • 软件参考：Stanford ASL 的 hj_reachability (JAX) 作为主要参考，以及一个 torch.compile 重新实现作为张量编译器基线。

06评估与结果

  • 交叉库一致性：在 FP64 下与 hj_reachability 在八个基准案例上点对点 L∞ 差异 ≤ 0.04（2D）或 ≤ 0.4（4D），复现 Air3D BRT 细胞计数误差 0.04%。
  • 速度对比：FP64 下 CUDA 求解器比 hj_reachability 快 2.0–4.6 倍，比 torch.compile 快 1.3–1.4 倍；FP32 下比 hj_reachability 快 5.9–17.5 倍，比 torch.compile 快 1.7–16 倍。
  • 实时性能：FP32 单次调用 Air3D 8.91 ms（112 Hz），4D 追击-逃避约 16 ms（61 Hz），2D 漂移器 6.8–13.5 ms（74–147 Hz）。
  • 嵌入式性能：Jetson AGX Thor 上 Air3D 66 Hz，2D 漂移器 54 Hz，总系统输入功率约 31 W。
  • 多智能体演示：六架四旋翼野火响应闭环仿真，每 tick 求解 4.0 ms，捕获盆标签一致性 99.5% 与逐智能体 argmin 参考一致。
  • 等精度加速比：在相同目标精度下，CUDA 求解器比 JAX-GPU 快 3.1–4.9 倍。
