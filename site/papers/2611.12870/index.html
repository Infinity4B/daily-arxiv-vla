SWAM: Scaling World Action Models with Cross-Modal Alignment

02论文概述

  • 论文提出 SWAM，一种通过跨模态对齐扩展世界动作模型（World Action Model, WAM）的方法，目标是在引入动作学习时保留视频预训练获得的语言–视频能力，并将其泛化到机器人控制。
  • 核心问题是：现有工作通常把视频预训练中的语言–视频对齐视为既定基础，但动作学习可能破坏该对齐，缺乏关于数据与监督设计的系统性指导。
  • 论文构建约 47,000 小时多源数据池，系统研究语言–视频监督、语言–视频–动作监督及二者联合训练对 WAM 性能和泛化能力的影响。

03核心贡献

  • 构建并发布约 47,000 小时多源预训练数据池，涵盖通用视频、自我中心视频、UMI 人类操作演示和机器人演示。
  • 发现详细、准确的语言描述，结合环境和子任务级标注，能更好地保持语言–视频对齐并提升下游控制泛化。
  • 证明 UMI 人类操作演示中的动作监督可有效增强语言–视频–动作对齐，提升仿真与真实机器人控制性能。
  • 提出双流世界动作模型架构：视频与动作分支保持独立残差流，视频到动作单向注意力，动作分支仅通过视频特征获取语言信息。
  • 在 RoboTwin 和真实机器人上验证多源预训练可扩展性，Hard 场景下平均成功率 40.00%，超过最强基线 OpenWAM 的 23.33%。

04方法描述

  • 将视频和动作预测统一为条件流匹配目标：视频分支预测视频潜空间流速度，动作分支预测动作空间流速度，总损失为视频损失与动作损失之和。
  • 模型基于 MoT 架构，视频分支由 Wan2.2-TI2V-5B 初始化，动作分支随机初始化；视频和动作各保持独立残差流，通过共享 masked attention 单向从视频流向动作。
  • 语言仅通过视频分支的 cross-attention 注入，动作分支不直接做文本 cross-attention，从而复用视频预训练学到的语言–视觉对应。
  • 多源经验提供不同监督形式：通用/自我中心视频提供语言–视频监督；UMI 和机器人演示额外提供动作监督；无效动作目标不参与动作损失。
  • 数据整理流程包括质量过滤、VLM 内容审核、子任务分割、多级 caption 生成（Brief/Medium/Detailed + 环境/光照信息）。

05数据集与资源

  • 预训练数据总规模约 47,016.7 小时、4,407,996 条 episode、5,071.5M 帧。
  • 通用视频：OpenVid（822.1h）、Panda-70M（10,087.4h），合计约 10,909.6h。
  • 自我中心视频：EgoSuite（8,600.6h）、Ego4D（1,339.7h）、EgoVerse（1,046.0h），合计约 10,986.3h。
  • UMI 演示：RoboPocket 采集的 in-house UMI 数据，约 15,284.9h、411,754 条轨迹。
  • 机器人演示：ABC、AgiBot World、InternData-A1、Galaxea、RoboCOIN、RoboMIND，合计约 9,836.0h。
  • 模型视频主干为 Wan2.2-TI2V-5B（约 5B 参数），动作分支额外随机初始化；具体总参数量未在片段中给出。
  • 训练优化：AdamW，初始学习率 4e-5，预训练默认全局 batch size 256；仿真后训练 20k 步/batch 128，真实后训练 50k 步/batch 128；具体 GPU/TPU 型号未在提供的 HTML 片段中说明。

06评估与结果

  • 仿真基准：RoboTwin 2.0，50 个双手操作任务，仅使用 Clean 演示后训练；评估 Easy（Clean-to-Clean） 与 Hard（Clean-to-Random） 两种设置。
  • 真实机器人：Flexiv Rizon 4 双臂平台，评测杯子堆叠、毛巾折叠、礼物装盒 3 个任务；每个任务/设置 10 个布局 × 3 次试验。
  • 对比基线：VLA 基线 StarVLA、π0.5、Xiaomi Robotics-0、X-VLA；WAM 基线 Fast-WAM、LingBot-VA、OpenWAM、X-WAM、4D-WAM。
  • 语言–视频对齐消融：Subtask Detailed + Env. 配置达到 Easy 83.92%、Hard 55.04%；打乱 caption–视频对应使 Hard 从 53.52% 降至 52.00%。
  • 动作监督消融：UMI 动作标签覆盖率从 0% 到 100%，Hard SR 从 46.72% 提升到 51.28%。
  • 多源整合：等比例 Ego:UMI 采样 Hard SR 53.84% 最高；过渡性通用视频预训练 +25k 步使 Hard 从 53.84% 提升到 56.48%；最终架构 Hard SR 57.36%，超过 Single-stream 的 52.56% 和标准 Dual-stream 的 52.48%。
  • 最终模型：RoboTwin Easy 88.10%、Hard 61.56%；真实机器人 Hard 平均 SR 40.00%，显著优于 OpenWAM 的 23.33%。
