Ground, Guide, Act: Improving VLA Spatial Generalization with Multimodal Foundation Models

02论文概述

  • 针对视觉-语言-动作（VLA）模型在物体位置和任务目标变化时泛化能力差的问题，提出利用多模态基础模型（MFM）增强 VLA 空间泛化能力的框架
  • 通过系统能力分析发现，VLA 失败主要源于目标定位和全局空间路径规划，而局部操作技能大多仍可用
  • 提出 MFM-VLA，一种选择性协作框架，由 MFM 提供目标定位和空间引导，控制器执行自由空间运动，VLA 保留精细操作控制

03核心贡献

  • 通过反事实指令测试和相位解耦干预阶梯（PDIS）对多个预训练 VLA 进行系统分析，揭示视觉场景捷径现象，明确目标定位、空间路径和局部操作在失败中的角色
  • 提出 MFM-VLA 框架，整合密集几何策略自适应、扰动状态恢复、开发集校准的能力路由和基于 MFM 的空间引导
  • 在 LIBERO-PRO、ALOHA-Sim-PRO、RoboCasa365 和真实世界化学任务上验证有效性，成功率分别提升 14.9、74.0、3.6 和 30.9 个百分点
  • 进一步探索扩展系统 MFM-VLA + Code Policy，由 MFM 在自适应 VLA 和任务专用代码控制器之间选择，显著提升整体性能

04方法描述

  • 密集几何策略自适应：对 VLA 进行微调，使用动作块级密集几何标注（包含场景、子目标、几何偏移和短视域动作描述），并利用扰动状态恢复数据提升从非熟悉交接状态恢复的能力
  • 开发集校准能力路由：在开发集上比较直接执行和辅助执行的成功率，冻结路由决策，仅在辅助执行增益超过阈值且任务支持空间交接接口时选择辅助模式
  • 任务感知定位与空间引导：MFM 根据任务要求识别操纵目标点（如瓶盖、篮子内部），通过双视图三角化估计 3D 目标位置；控制器执行 Reach 和 Carry 阶段，VLA 执行 Grasp/Lift 和 Place/Release 阶段
  • 抓取验证与局部恢复：独立监控器检查抓取成功、物体保持和误抓，检测失败时进行有界的重试恢复

05数据集与资源

  • LIBERO-PRO：160 任务、16 个套件、4 类扰动，使用 14,075 条轨迹微调
  • ALOHA-Sim-PRO：双臂搬运任务，含语义、物体、位置、任务扰动
  • RoboCasa365：50 个移动操作任务（18 原子已见、16 复合已见、16 复合未见），微调使用 1,437 条已见任务轨迹
  • 真实世界化学任务：Franka-XHand 平台，11 个玻璃器皿操作任务
  • 使用的 VLA 模型：π₀.₅（LIBERO-PRO、RoboCasa365、真实世界）和 π₀（ALOHA-Sim-PRO）
  • MFM：GPT-6 Astra
  • 训练和推理使用的计算资源在提供的文本中未详细说明

06评估与结果

  • LIBERO-PRO：MFM-VLA 将整体成功率从 54.9% 提升至 69.8%；加入 Code Policy 后达 84.4%
  • ALOHA-Sim-PRO：平均扰动成功率从 23.5% 提升至 97.5%；Position 和 Task 扰动下分别达 92.0% 和 100.0%
  • RoboCasa365：整体成功率从 16.9% 提升至 20.5%；Composite-Seen 任务从 7.1% 提升至 17.1%；加入 Code Policy 后整体达 30.3%
  • 真实世界任务：原子任务平均成功率从 15.3% 提升至 54.4%，多阶段任务从 0.8% 提升至 31.7%
  • 零样本 MFM 对比：GPT-6 Astra 直接控制在 LIBERO-PRO 上仅达 3.5% 成功率，远低于 MFM-VLA 的 74.3%，验证了 VLA 接触控制的重要性
  • 消融实验验证了策略自适应、路由和空间引导各组件的贡献
