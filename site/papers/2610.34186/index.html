HuGe: Scaling Humanoid Generalist Vision-Language-Action Models with Egocentric Experience

02论文概述

  • 提出 HuGe（Humanoid Generalist VLA），基于现有 VLA 架构，在超过 2000 小时的第一人称人类与机器人数据上训练，实现语言指令驱动的仿人机器人全身控制。
  • 核心解决两个问题：仿人机器人高维动作空间与协调全身控制难以直接沿用机械臂 VLA；真实机器人演示采集成本高，而第一人称人类演示存在视觉外观差异和缺少机器人本体感受信息。
  • 通过三阶段训练（第一人称预训练、仿人适应、下游微调），结合伪本体感受状态和视觉适配，实现人类经验向仿人机器人策略的有效迁移。

03核心贡献

  • 贡献点 1：提出 HuGe 模型家族，以 OFT、GR00T、π 三种代表性 VLA 架构为基础，无需新增模块或修改架构设计。
  • 贡献点 2：开发数据适配方法，包括用仿真回放构造伪本体感受状态，以及在下游微调时重新渲染并替换第一人称观察中的手臂外观，缩小人与机器人之间的 embodiment gap。
  • 贡献点 3：在 HumanoidArena 仿真基准上取得 SOTA，HuGe-GR00T 和 HuGe-Pi 的平均成功率分别达到 66.67% 和 65.00%。
  • 贡献点 4：在真实 Unitree G1 人形机器人上验证可乐抓取-投放任务，视觉适配的第一人称演示将成功率从 43.3% 提升到 66.7%。

04方法描述

  • 架构：给定视觉观察、本体感受状态和语言指令，HuGe 预测 66 维动作，包括 64 维 SONIC 全身控制器潜在运动 token 和 2 个手部开合信号；SONIC 解码 token 为关节级全身运动命令。
  • 三种 VLA 实例：OFT 用轻量 MLP 直接从动作 token 生成动作块；GR00T 用 DiT 通过 flow matching 生成动作；π 用 DiT 动作专家以层级交叉注意力连接多层骨干隐藏状态。
  • Stage 1 第一人称预训练：在 EgoDex、EgoVerse、Xperience-10M、BEHAVIOR-1K 上学习动作预测，并利用仿真回放为第一人称数据构造伪本体感受状态。
  • Stage 2 仿人适应：在 Humanoid Everyday、UniFoLM-WBT、HIW-500 上继续训练，统一动作和状态接口，适应真实机器人观测。
  • Stage 3 下游微调：针对 HumanoidArena 和真实可乐抓取-投放任务；用 Phantom 视觉编辑管线去除人手和手臂、修复并合成机器人手，保留原始动作、状态和语言监督。

05数据集与资源

  • Stage 1 第一人称预训练：EgoDex 821.8h / 334,991 episodes；EgoVerse 47.08h / 1,704 episodes；Xperience-10M 478.33h / 10,651 episodes；BEHAVIOR-1K 322.4h / 3,426 episodes。
  • Stage 2 仿人适应：Humanoid Everyday 16.47h / 4,064 episodes；UniFoLM-WBT 22.96h / 3,656 episodes；HIW-500 378.15h / 23,743 episodes。

06评估与结果

  • 仿真基准：HumanoidArena 七个任务，包括三个 HOI 任务（Football、DoubleDesk、P&PBox）和四个 HSI 任务（OpenDoor、SitSofa、Boxing、VisNavi），指标为成功率。
  • 训练策略：全参数微调显著优于 frozen 和 LoRA；无预训练时 full FT 的平均成功率为 HuGe-OFT 55.00%、HuGe-GR00T 58.33%、HuGe-Pi 60.24%。
  • 伪本体感受状态：HuGe-GR00T 提升 +5.00（61.67→66.67），HuGe-Pi 提升 +2.86（62.14→65.00），但 HuGe-OFT 因文本状态截断下降 -2.38（56.43→54.05）。
  • 预训练规模：HuGe-GR00T 与 HuGe-Pi 随第一人称预训练数据增大而持续提升，最终分别达到 66.67% 和 65.00%。
  • 主结果：HuGe-GR00T 66.67%、HuGe-Pi 65.00%、HuGe-OFT 54.05%；最强基线 π0.5 53.81%，HuGe-GR00T/HuGe-Pi 分别领先 12.86/11.19 个百分点；DoubleDesk 任务所有方法成功率仍在 0%-15% 之间。
  • 真实世界实验：Unitree G1 可乐抓取-投放任务，110 个机器人遥操作演示单独微调成功率 43.3%（13/30）；加入 400 个原始第一人称演示后为 60.0%（18/30）；使用视觉适配后的第一人称演示为 66.7%（20/30）。
  • 视觉适配量化：视觉适配将第一人称观察与真实机器人分布之间的 Fréchet 距离降低，Wan2.2 降低 33.54%，VideoMAE V2 降低 27.07%，V-JEPA 2 降低 13.83%。
