02论文概述

  • 提出 Cairn 框架：在保持 VLA（视觉-语言-动作模型）完全冻结的情况下，通过学习到的被持物体 3D SE(3) 轨迹先验，在测试时“引导”冻结的 VLA。
  • 解决的问题：VLA 虽然具备底层操作技能，但将物体放置位置与训练布局绑定——当物体被移动或存在障碍物时，会把物体放错位置或撞上障碍物；微调需要每个新布局的机器人数据且会导致技能遗忘。
  • 核心思想：一个小的 3D 运动先验读取场景点云、被持物体点云、抓取位姿和指令，采样从抓取到释放的 SE(3) 轨迹（绕开障碍、旋转以穿过缝隙），引导冻结 VLA 的动作去噪过程。

03核心贡献

  • 首个用学习到的 SE(3) 物体路线（从抓取到释放，条件于场景、物体形状与指令）引导冻结 VLA 的框架
  • 双向反馈的分层规划器：学习的路线先验与冻结 VLA 在测试时互相引导（VLA 意图选择并重塑路线，路线引导 VLA 去噪），两者均无需重新训练
  • 自动化演示数据生成器：生成移动物体、迫使绕行与转向的障碍物布局、每场景多条备选路线，并构建 LIBERO-Shift 留出基准（1,941 个未见场景）
  • 大量仿真与真机实验表明：Cairn 使冻结 VLA 对布局变化和障碍物鲁棒，优于微调且不遗忘原有技能，并迁移到第三方基准 LIBERO-PRO 与真实 Franka 机器人

04方法描述

  • 对象中心 SE(3) 规划：先验基于 3DFA 架构改进，场景用 Point Transformer V3 编码，物体点云由独立的 point MLP 分支编码，结合 CLIP 指令特征；用 rectified flow 采样 20 个 SE(3) 路标点的路线，并加入局部注意力更新（每个路标点关注其最近场景 token）
  • 训练数据生成：仿照 MimicGen 重锚定人类演示到新布局，放置六类障碍物（门、柱、杆等迫使转向），用 MPLib 检查可行路；从 LIBERO 的 4,605 条人类演示生成 16,049 条演示加 79,470 条备选路线（路线差异 23–31 cm，对比 LIBERO 原始的 2–4 cm），仅在仿真中执行并通过硬性检查后保留
  • 分层引导：将 VLA 动作块经可微分运动学映射 Φ 映到被持物体位姿；用阻尼 Gauss-Newton 步（式 7）在每个去噪步将 VLA 干净估计的物体位姿拉向下一个路标点，结合位置、旋转（测地能量）和夹爪能量三项修正，VLA 权重完全不变
  • 训练采用 rectified flow 速度场 + SO(3) 测地旋转监督项；测试时采样 16 条路线，拒绝不清晰路线并取 medoid 作为计划

05数据集与资源

  • 数据：LIBERO（4,605 条人类演示）→ 生成 16,049 条演示 + 79,470 条备选路线；评估用 LIBERO-Shift（1,941 场景 / 5,823 回合，27 个任务）、LIBERO-PRO 第三方基准
  • 模型规模：路线先验仅 4.35M 参数；被引导的 VLA 为冻结的 π₀.5（含 DROID 版本 π₀.5-DROID）
  • 计算资源：推理在单张 NVIDIA B200 GPU 上运行（路线采样 0.37 s/次抓取，每动作块引导耗时 190 ms）
  • 真机平台：Franka FR3（DROID 设置），先验仅在仿真（实验室扫描复刻）中训练，无真实演示

06评估与结果

  • 评估基准：LIBERO-Shift（1,941 个移动/障碍场景，5,823 回合）、标准 LIBERO、第三方 LIBERO-PRO、真实 Franka 机器人
  • 主要指标：任务成功率（物体放入指定容器且无碰撞）、无碰撞率、路线有效性/多样性、每动作块耗时
  • LIBERO-Shift：冻结 π₀.5 从 24.5% → 95.1%，超过在相同布局上微调的 π₀.5（91.3%，且标准 LIBERO 从 96.5% 退化到 70.5%，Cairn 保持 97.0%）；转向场景从 13.4% 提升到 88.8%
  • 路线质量：5,823 回合中 100% 有可行路线，97.3% 到达指定容器；每次抓取 0.37 s（对比 RRT-Connect 45.5 s）；3D HAMSTER 仅 37.7% 到达目标
  • 基线对比：OmniGuide 类局部场仅 24.8%（加目标吸引子 50.9%），3D HAMSTER 路径引导 29.2%，均远低于 Cairn 的 95.1%
  • LIBERO-PRO：成功率从 27.3% 提升到 38.0%；在其可引导回合（正确抓取的单搬运任务）上从 54.4% → 81.1%
  • 真机实验：冻结 π₀.5-DROID 上，绕过障碍物放置 0/10 → 9/10，臂展极限的柜顶放置 0/10 → 8/10（先验纯仿真训练迁移到真机）
