SVD-Prune: Spectral Vision Token Pruning under Extreme Compression

02论文概述

  • 针对视觉-语言模型（VLM）和视觉-语言-动作模型（VLA）处理数百个视觉 token 导致的计算瓶颈问题，提出视觉 token 剪枝的新范式
  • 论文主张将视觉 token 剪枝重新表述为低秩子空间保留问题，而非识别单个重要 token，即在极端压缩下保留视觉表示的主导谱结构
  • 提出 SVD-Prune：一个免训练（training-free）、不依赖注意力机制的谱剪枝框架，可在编码器端、解码器端或混合配置下应用

03核心贡献

  • 将视觉 token 剪枝重新表述为低秩子空间保留问题，提供了一种区别于局部交互式重要性评分的全局化剪枝准则
  • 提出 SVD-Prune 框架，结合奇异值分解（SVD）与统计杠杆分数（leverage scores）进行全局感知的 token 选择
  • 框架与架构无关（architecture-agnostic），支持编码器侧、解码器侧和混合三种剪枝配置
  • 在 VLM 和 VLA 上进行统一评估，证明在极端压缩（token 预算削减高达 99.3%）下的强鲁棒性
  • 在 16 token 预算下，编码器端剪枝将推理 FLOPs 降低 82.4%，实现 4.18× 端到端加速（含剪枝开销）

04方法描述

  • 核心思想：不估计局部交互的 token 重要性，而是保留完整视觉 token 集合的主导低秩谱结构，包含四个阶段
  • 全局模式提取：对视觉 token 特征矩阵 F∈ℝ^(N×d) 进行 SVD 分解（F = UΣV^T）
  • 谱能量截断：计算归一化谱能量，选取最小秩 m 使累积能量 c_m ≥ ε（依据 Eckart–Young 定理保证最优低秩近似）；ε 控制子空间秩，剪枝比例由独立 token 预算 k 控制
  • Token 贡献估计：使用统计杠杆分数 h_t = ‖U_m[t,:]‖²₂ 衡量每个 token 对保留子空间的影响力（子空间感知评分）
  • Token 选择与剪枝：按杠杆分数确定性 top-k 选择，并恢复原始序列顺序以保持位置一致性；全程免训练、不依赖注意力
  • 支持三种部署模式：编码器端（视觉编码后）、解码器端（LLM 第 8 层后）、混合模式（编码器端先降至 64 token + 解码器端二次剪枝）

05数据集与资源

  • VLM 模型：主基准 LLaVA-1.5-7B（336×336 输入，576 个视觉 token），泛化性验证用 QwenVL（448×448，1024 token），补充材料含 LLaVA-1.5-13B
  • VLA 模型：OpenVLA（256 个视觉 token），在 LIBERO-Spatial、LIBERO-Goal、LIBERO-Object、LIBERO-10 四个套件上评估（每套件 10 任务 × 50 次试验，固定随机种子 7）
  • 评估基准：SQA、VizWiz、POPE、GQA、TextVQA、MME 六大多模态基准
  • 对比方法：FastV、PDrop、SparseVLM、VisionZip
  • 训练资源：免训练方法，所有实验基于 PyTorch，在单张 NVIDIA RTX 3080 16GB GPU（Intel Core i7-11800H CPU）上进行

06评估与结果

  • 评估指标：VLM 准确率（SQA、VizWiz、POPE、GQA、TextVQA、MME）、VLA 任务成功率（SR）、延迟、FLOPs、FPS
  • token 压缩范围极广：从 192 token（33.3%）直至 4 token（0.7%），最大削减达 99.3%
  • 极端压缩下的鲁棒性：编码器端剪枝仅用 4 个 token 时 SQA 仍达 68.69（较未剪枝模型下降不到 2 分）；32/16 token 预算下在六个基准中匹配或超越所有对比方法
  • 效率提升：16 token 预算下，编码器端剪枝将 FLOPs 从 3.450T 降至 0.606T（降低 82.4%），延迟从 930.00 ms 降至 222.56 ms，实现 4.18× 端到端加速
  • 相比 VisionZip 虽稍慢（222.56 vs 184.52 ms），但精度更高：GQA 提升 +8.83 分、POPE 提升 +10.11 分
  • 剪枝开销极小：SVD + 杠杆评分 + 选择总开销约 24.73 ms，计算开销仅 1.740–5.181 GFLOPs（低于总成本的 0.4%）
  • 跨架构泛化：在 QwenVL 上，保留 784/900 token 时性能几乎无损，SQA 甚至略有提升
  • VLA 结果：OpenVLA 上 LIBERO-Spatial/Goal/Object 在激进剪枝下成功率接近基线（LIBERO-Object 56 token 时差距在 1.4 分内），LIBERO-10 因长时序多目标任务更敏感（55.8% → 47.0%）；LIBERO-Spatial 上 256→56 token 使计算成本从 4376.05 降至 2349.89 GFLOPs
