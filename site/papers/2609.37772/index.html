Urgent Actions Go First: Urgency-Aware Denoising for Real-Time VLA Control

论文针对扩散/流匹配 Vision-Language-Action (VLA) 策略在迭代去噪过程中推理延迟过高、严重限制实时机器人控制的问题。

01研究单位

02论文概述

  • 论文针对扩散/流匹配 Vision-Language-Action (VLA) 策略在迭代去噪过程中推理延迟过高、严重限制实时机器人控制的问题。
  • 核心洞察：动作块中的动作是联合生成但顺序执行的，因此不同动作具有异构执行紧迫性。现有加速方法将动作块视为整体，忽略了这一物理现实。
  • 论文提出 Urgency-Aware Denoising (UAD) 推理框架，根据动作的实际需求时间分配去噪计算，在保持任务成功率的同时显著降低动作可用延迟（AAL）。

03核心贡献

  • 紧迫性感知推理范式：提出按时间执行紧迫性而非均匀分配去噪计算的新视角，使紧迫动作可显著提前释放，降低延迟。
  • 实用系统设计：UAD 由三个组件构成——Urgency-Aware Early Release (UAER) 提前释放紧迫动作，Trajectory Reconciliation (TR) 零额外模型评估地恢复联合去噪一致性，Ghost Action Correction (GAC) 利用“幽灵动作”动态补偿早期释放误差。
  • 全面实证评估：在多种 VLA 架构（SmolVLA、π₀.₅）、模拟基准（LIBERO-Plus、Meta-World+）及真实机器人（Dobot Nova2）上验证，模拟中最高达 1.89× 的速度提升，同时成功率达与最优去噪步数的原始推理相当。

04方法描述

  • Urgency-Aware Early Release (UAER)：将动作块分为紧迫动作（前 U 个）与尾部动作，紧迫动作仅用 K (< N\*) 步去噪后即释放执行，尾部动作保持 N\* 步完整去噪，与物理执行重叠。
  • Trajectory Reconciliation (TR)：利用已缓存的速度向量，以规范步长 1/N\* 重新积分得到“调和状态”，恢复联合去噪的输入一致性，零额外 DiT 评估；当 K=1 时理论上可精确恢复原始轨迹。
  • Ghost Action Correction (GAC)：调和后的紧迫状态继续去噪产生“幽灵动作”（接近原始完整动作），用其与已释放动作的差异估计总误差，并均匀分配到剩余可执行尾部动作上进行运动学补偿（平移加法、旋转 SO(3) 合成、夹爪二值维度屏蔽）。
  • 创新点在于利用动作联合生成但顺序消费的不对称性，将“何时需要动作”作为推理算力分配的维度，并系统解决异构去噪带来的轨迹不一致与早放误差。

05数据集与资源

  • 模拟基准：LIBERO-Plus、Meta-World+
  • 模型：SmolVLA（LIBERO-Plus、Meta-World+）、π₀.₅（Meta-World+、真实世界）
  • 真实部署：Dobot Nova2 机器人，5 个操作任务
  • 硬件：NVIDIA H20 GPU；实现基于 LeRobot 框架
  • 参数配置：动作块 H=50，执行 S=10，UAD 默认 K=1、U 取覆盖剩余计算的最小值

06评估与结果

  • 评估指标：Success Rate (SR)、Average Action Availability Latency (AAL)、ΔSR（相对 Vanilla (N\*) 的变化）、Speedup（AAL 加速比）
  • 主要结果（三个模拟设置）：UAD 相对 Vanilla (N\*) 实现 1.30–1.89× AAL 加速，SR 变化仅 -2.9 到 +1.2 pp；相对 Vanilla (N=1) SR 提升 2.6–9.2 pp，AAL 相当
  • 与 SOTA 基线对比：优于 D3P（更大加速）、BAC（更高 SR 且延迟更低）、RTC（SR 下降 10.7–26.5 pp 换取极致延迟）
  • 真实世界部署：AAL 从 34.3 ms 降至 15.2 ms（2.26× 加速），SR 保持 84%，而 Vanilla (N=1) 仅为 71%
  • 消融研究：UAER 单独会降低 SR，加入 TR 部分恢复，再加 GAC 后 SR 恢复至接近 Vanilla (N\*)；TR 与 GAC 引入的额外暴露延迟可忽略
