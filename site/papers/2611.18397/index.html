Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent

02论文概述

  • 提出 Gamer，一个面向复杂交互环境中长时程任务的通用智能体框架，采用端到端架构融合感知、记忆管理与多步推理
  • 解决现有游戏智能体的核心问题：依赖特权内部状态或专用 API 导致泛化性差、推理延迟导致动作滞后于游戏状态变化、长时程任务中的上下文窗口受限与稀疏奖励问题
  • 以 Honkai: Star Rail 等复杂 3D 开放世界游戏为测试平台，探索从屏幕像素观察到原生键盘鼠标动作的统一设备级接口，通向跨数字与物理世界的通用智能体

03核心贡献

  • 通用游戏智能体框架：以屏幕图像为输入、标准键鼠操作为统一动作空间，实现跨游戏的非侵入式交互，无需依赖游戏专用 API
  • 可扩展的长时程指令数据构建管线：通过 LLM 辅助标注将数万小时多源游戏轨迹转化为超一千小时的高质量指令数据，覆盖操作、子目标和完整任务三个层级
  • 统一训练与实时推理基础设施：将 Verl 扩展为覆盖 CPT、SFT 和 TA-GRPO 的统一训练评估框架，并自研 Streaming-vLLM 推理引擎支持有状态 KV 缓存复用、FSM 引导的投机解码与流式动作分发
  • Temporal-Aware GRPO（TA-GRPO）：通过记忆链接的分段 rollout 和时间感知信用分配，解决长时程在线强化学习中的上下文限制、误差累积和稀疏奖励问题
  • 强实证结果：在 3D 商业游戏任务上达到与熟练玩家相当的泛化与操作效率，并在多个传统 2D 游戏基准上取得有竞争力的表现

04方法描述

  • 继续预训练（CPT）：在统一观察-动作表示上进行跨游戏控制学习，观察采样频率 5 Hz，动作以 6 个连续键盘-鼠标动作块序列化（约 30 Hz 动作率）；采用随机按键重映射消除按键频率偏差，采用重复感知损失衰减（γ=0.9）降低重复动作的监督权重
  • 稀疏推理与跨上下文记忆的 SFT：单一自回归策略在直接控制、稀疏推理与记忆更新间自适应切换（推理可为空、当前决策推理或记忆摘要）；基于摘要的长期记忆在上下文边界处压缩保留任务进度
  • TA-GRPO 在线强化学习：将长 rollout 划分为由记忆压缩机制连接的有限分段，使用环境可验证结果进行组内相对优势估计，并以指数时间加权将段级优势分配到各时间步决策
  • Scaling Law 分析：基于 D-CPT Law 建立组成感知的缩放关系，刻画模型规模、游戏数据预算与游戏组合对控制学习和跨游戏泛化的影响
  • Streaming-vLLM 推理引擎：结合状态化 KV 缓存复用、架构感知执行、FSM 引导投机解码（BF16 验证）与流式动作分发，降低实时推理延迟

05数据集与资源

  • 使用数万小时设备级键盘鼠标交互轨迹（涵盖模拟游戏与具身环境），经 LLM 辅助标注产出超 1000 小时多层级指令数据
  • 基座模型：Qwen3-VL 与 Qwen3.5（支持稠密与 MoE 架构）
  • 训练硬件：NVIDIA A800（Ampere）与 NVIDIA H200（Hopper）GPU 集群，训练框架基于 Verl 扩展
  • 数据构建采用 LLM 辅助标注与质量校验，覆盖本地操作、中间子目标、完整任务三级指令

06评估与结果

  • 评估环境：自建 Honkai: Star Rail（HSR）评估套件（涵盖开放世界探索、回合制战斗、小任务与长时程里程碑）以及多个公开 2D 游戏基准
  • 评估指标：任务完成率、长时程里程碑达成、指令泛化能力、实时推理延迟与吞吐
  • 关键结果：在多个具有挑战性的 3D 开放世界游戏任务上展现出与熟练玩家相当的泛化能力与操作效率；在传统 2D 游戏基准上取得有竞争力的实时表现
  • CPT 缩放实验表明：早期 CPT 使预训练模型适配统一控制接口，后期收益越来越依赖游戏数据组成；缩放律拟合可支持测量范围内的 held-out 预测，但对分布外较远游戏无持续增益
  • 实时 rollout 显著影响在线 RL 效果，Streaming-vLLM 通过低延迟并发服务支撑大规模在线策略优化
