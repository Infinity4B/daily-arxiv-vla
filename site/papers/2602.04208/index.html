SCALE: Self-uncertainty Conditioned Adaptive Looking and Execution for Vision-Language-Action Models

02论文概述

  • 论文提出了一种名为 Scale 的简单推理策略，旨在增强视觉-语言-动作（VLA）模型在测试时的鲁棒性
  • 现有测试时扩展（TTS）方法需要额外训练验证器、多次前向传播，且仅干预动作解码而忽略视觉感知的调整，Scale 旨在解决这些局限性
  • 通过自适应性调节视觉感知和动作，在不增加额外训练、无需验证器且仅需单次前向传播的条件下提升模型性能

03核心贡献

  • 提出 Scale 框架，一种训练无关、单次前向传播的自适应推理策略，联合调节 VLA 模型的视觉注意力和动作解码
  • 设计了一种新颖的 自不确定性 (self-uncertainty) 度量，通过测量模型预测分布与“完全确定”和“完全模糊”两个参考分布之间的相对距离，同时捕捉分布不确定性和模型对首选动作的决断力
  • 引入 自适应动作解码，根据 token 级不确定性动态调整采样温度，实现从贪婪执行到探索性采样的平滑过渡
  • 引入 自适应视觉注意力，基于不确定性相对于近期历史的变化，在时间步级别动态调整视觉编码器的注意力温度，实现感知的探索与聚焦
  • 在多个模拟和真实世界基准上验证了 Scale 的有效性，其性能优于现有的训练依赖的 TTS 方法，同时保持单次推理效率

04方法描述

  • 自不确定性度量：定义两个参考分布（以 top-1 token 为中心的 one-hot 分布和均匀分布），通过计算模型预测分布与这两个参考分布的 KL 散度之差，得到一个连续且有界的自不确定性分数
  • 自适应动作解码：将 token 级的自不确定性分数通过 sigmoid 函数转换为动态采样温度，高不确定性时提高温度以鼓励探索，低不确定性时降低温度以实现近似贪婪解码
  • 自适应视觉注意力：聚合 token 级不确定性为步级不确定性，并计算其相对于指数移动平均的偏差，将此偏差通过 tanh 和指数函数转换为视觉编码器的注意力温度，以调制所有层的自注意力机制
  • 创新点：将 Active Inference 理论中的不确定性驱动探索原理应用于 VLA 模型，实现了感知和动作的联合自适应调制，且整个过程无需额外训练或外部模块

05数据集与资源

  • 模拟基准：LIBERO (多任务泛化)、SIMPLER-WidowX (执行精度)、LIBERO-PRO-Long (鲁棒性测试)
  • 真实世界设置：使用 6-DoF UR10e 机械臂和 Robotiq 2F-85 夹爪，进行“Pick-and-Place”任务
  • 模型架构：在 OpenVLA、π0-FAST 和 SpatialVLA 等多个自回归 VLA 模型上进行验证
  • 训练资源：论文主要关注推理阶段，未明确提及特定训练 GPU 资源，但实验基于官方代码库和模型权重

06评估与结果

  • 评估基准：在 LIBERO、SIMPLER-WidowX 和 LIBERO-PRO-Long 等模拟基准及真实世界任务上，与贪婪解码、多种训练无关解码策略以及训练依赖的 TTS 方法进行对比
  • 主要评估指标：成功率 (Success Rate, %)
  • 关键实验结果：

- Scale 在所有模拟和真实世界基准上，跨不同模型架构一致地提升了贪婪解码的性能（例如，在 OpenVLA 的 LIBERO 基准上平均提升 +5.8%）

- 简单的固定参数解码策略（如温度采样、top-k、top-p）常导致性能下降，而 Scale 通过动态调整提供了稳健的改进

- Scale 在 LIBERO-Long 基准上以 +10.7% 的优势显著优于训练依赖的 TTS 方法 MG-Select，且仅需单次推理

- 消融实验表明，自适应动作解码和自适应视觉注意力具有协同效应，联合使用带来的增益超过两者单独使用增益之和
