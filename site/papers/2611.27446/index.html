02论文概述

  • 论文研究如何将预训练图像生成模型直接适配为高效机器人动作策略，而不依赖“未来视觉预测”这一中间代理目标
  • 提出 GenPA，在 FLUX.2 klein Base 4B 图像生成骨干上微调，使用轻量 19M 参数动作回归适配器，并复用原生生成目标进行感知协同训练
  • 解决现有方法将预测未来视觉状态作为视觉生成预训练与动作学习之间核心桥梁的问题，证明图像生成模型本身可以转化为强动作学习器

03核心贡献

  • 提出 GenPA，证明图像生成骨干可以直接适配为强、高效的机器人策略，且无需未来视觉预测目标
  • 使用原生图像编辑接口进行感知协同训练，支持深度、法线、语义等多种视觉目标，无需任务特定感知头，支持统一架构下的视觉监督对比
  • 采用 19M 参数的轻量回归动作适配器，推理仅需一次骨干前向和直接动作回归，无需视觉生成或迭代动作去噪
  • 在多个仿真基准和真实世界操作中验证了性能和鲁棒性；编译后 H100 上每动作块 20.9 ms，较 VLA/WAM 基线快 1.7–3.4×
  • 消融研究表明当前深度监督是简单有效的训练配方，并揭示视觉生成骨干在观测编码与指令编码分离上的架构优势

04方法描述

  • 骨干模型采用预训练整流流 Transformer FLUX.2 klein Base 4B，文本编码器和 VAE 冻结
  • 动作路径：当前 RGB 观测经 VAE 编码为参考潜变量，语言指令经文本编码，加入可学习动作前缀，仅使用文本+参考图像 token 进行双向注意力，输出最终参考 token 特征
  • 动作读取：4 层 Transformer 解码器，每个动作步一个可学习查询，条件化于本体感知，线性头并行预测动作块；训练使用均方动作损失
  • 感知路径：复用原生图像编辑和整流流目标，将深度图、表面法线、分割等图像形式目标编码为 target-image token，以视觉速度预测损失联合训练共享骨干
  • 训练时每个动作前向与一个随机采样的感知任务配对联合更新；推理时仅执行动作路径，一次骨干前向+回归，无迭代去噪

05数据集与资源

  • LIBERO：Spatial、Object、Goal、Long 四个套件共 40 个任务，使用 2,000 条演示回放构建视觉标签，保留 1,808 条成功演示训练
  • LIBERO-Plus：10,030 个发布实例，覆盖 7 类扰动（相机、机器人初始状态、语言、光照、背景、噪声、布局），使用标准 LIBERO 检查点直接评估
  • RoboTwin 2.0：50 个双手协调任务，使用 2,500 条干净演示 + 25,000 条随机化演示（含深度标注），99%/1% 训练/验证划分
  • 真实世界 USB 转移任务：600 条演示，三种条件（标准、背景干扰、光照干扰），每策略每条件 50 次试验
  • 模型：FLUX.2 klein Base 4B 骨干 + 19M 动作适配器（LIBERO 配置）；RoboTwin 使用更宽动作适配器
  • 训练和推理主要使用 H100 GPU；多卡训练（如 8 张 H100），推理测量包括 H100 和 L40S

06评估与结果

  • LIBERO：GenPA 平均成功率 99.10%，在无外部机器人数据预训练方法中最高，与有大规模机器人数据预训练的 ABot-M0.5 仅差 0.30 个百分点
  • LIBERO-Plus：Clean-Instruction 评估总体成功率 83.79%，高于 ImageWAM 1.66 个百分点，逼近 π₀.₅ 和 Cosmos Policy（分别 85.90%、85.60%）
  • RoboTwin 2.0：Clean 92.08%、Randomized 90.82%、平均 91.45%，接近 Fast-WAM 的 91.83%
  • 真实世界：USB 转移任务平均成功率 78.0%，标准/背景/光照为 92.0/90.0/52.0%，在背景和光照扰动下显著优于 ImageWAM 和 π₀.₅
  • 延迟：H100 编译推理每动作块 20.9 ms，未编译 27.9 ms；相对 Fast-WAM、ImageWAM、π₀.₅ 等基线实现 1.7–3.4× 加速
  • 消融：直接回归优于 flow 动作头（LIBERO 98.87 vs 98.27；Plus 82.33 vs 81.49）；原生 flow 深度监督在 LIBERO-Plus 上优于 DPT 直接深度回归（82.33 vs 80.61）
