02论文概述

  • 提出 VLA-MOPD（VLA Multi-teacher On-Policy Distillation），一种将多个 flow-matching VLA 专家策略 整合为单一多任务 VLA 的在线蒸馏协议。
  • 解决任务专用后训练导致技能分散在多个专家检查点、混合任务强化学习奖励稀疏、离线蒸馏忽略学生访问状态、端点蒸馏缺乏中间动作生成监督等问题。
  • 核心目标是在学生自身 rollout 分布上，利用任务路由的冻结教师提供局部 ODE transition 监督，实现多任务能力整合。

03核心贡献

  • 提出 两阶段训练范式：先分别获取任务或任务套件的专家策略，再通过在线蒸馏将其能力整合到一个共享学生模型中，解耦技能获取与整合。
  • 设计 局部 ODE transition matching 目标：在学生诱导的外层机器人观测和内层 flow 状态上，匹配教师与学生的 ODE step mean，提供逐流步骤的密集监督。
  • 引入 可选参考策略正则化（reference-policy regularization）：在保留任务上匹配初始冻结策略的 step mean，缓解整合过程中的遗忘。
  • 在 LIBERO、RoboTwin 2.0 和真实 Piper 机器人 上验证了多任务能力整合效果，并进行了保留性与训练效率分析。

04方法描述

  • 首先通过多任务 SFT 初始化学生模型，再获取并冻结任务/任务套件级专家教师模型。
  • 学生收集自身 rollout，同时保存外层观测与内层 flow ODE 状态；每条指令路由到对应教师，教师在这些状态上计算并 stop-gradient 的每一步 transition 目标。
  • 学生通过 masked local matching loss 匹配教师的 ODE step mean（等价于 velocity field 匹配），仅更新 VLM LoRA 模块和完整 action expert。
  • 采用 deterministic Euler ODE 生成动作块；目标函数为 \[

\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{ODE}} + \beta \mathcal{L}_{\text{ref}}

\]，其中参考损失用于保留未参与当前适应的任务能力。

  • 每次更新后刷新学生 rollout snapshot，继续保持在线策略分布。

05数据集与资源

  • 模拟基准：LIBERO 四个套件（Spatial、Object、Goal、LIBERO-10）；RoboTwin 2.0 三个任务（Place Empty Cup、Pick Dual Bottles、Stack Bowls Two）。
  • 真实机器人：Piper 单臂机器人，三个任务（Pick Banana、Stack Cup、Sort Number）。
  • 学生模型初始化：采用 RLinf 中的 π0.5 SFT 流程；LIBERO 实验使用每任务 1 条轨迹（1-traj）初始化，RoboTwin 2.0 使用每任务 50 条干净轨迹。
  • 训练参数：论文未给出具体模型参数量；仅训练学生 VLM 的 LoRA 参数和 action expert，其余 VLM 与教师参数冻结。
  • 训练资源：论文未明确列出 GPU/TPU 等硬件资源；LIBERO 消融实验设置 64、32、16 个并行环境进行 rollout 采集。

06评估与结果

  • 评估指标：主要使用 success-once rate（执行过程中任一时刻任务成功即计为成功），多套件/多任务时报告未加权平均。
  • LIBERO 结果：从 1-traj 初始化平均成功率 75.4% 提升至 98.9%，高于 endpoint action distillation 的 98.15%。
  • RoboTwin 2.0 结果：平均成功率从 73.0% 提升至 89.3%，接近路由教师平均 94.0%。
  • 真实机器人结果：Piper 机器人上两轮整合后平均成功率从 70.0% 提升至 90.0%，教师为 93.3%。
  • 保留性实验：在近匹配 Spatial 适应对比中，reference matching 将 Object 套件下降限制在 3.0 个百分点，而无参考项下降 13.2 个百分点。
  • 训练效率：在相同步骤预算下，VLA-MOPD 在第 400 步达到 97.6%，显著优于 MixRL（GRPO）的 82.55%；中间 flow-state 监督在 Goal 和 LIBERO-10 上分别带来 1.2 和 1.4 个百分点的提升。
