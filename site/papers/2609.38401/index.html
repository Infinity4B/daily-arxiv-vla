Card 02 论文概述

论文概述

  • 论文研究训练数据变化（如域随机化（DR）和演示数据多样化）如何影响机器人操纵策略的鲁棒性，但现有方法通常依赖昂贵的试错来设计随机化参数，缺乏对底层学习机制的理解。
  • 核心问题是区分三种学习机制：记忆（Memorize）、适应（Adapt） 和忽略（Ignore），即策略是在记忆孤立环境、自适应泛化，还是对任务无关因素产生不变性。
  • 论文提出基于表示核（representation kernel）的诊断框架，以经验神经正切核（eNTK）为主要工具，跨越RL、模仿学习和VLA模型，为数据设计提供可操作的指导。
Card 03 核心贡献

核心贡献

  • 提出基于表示核（eNTK）的诊断框架，能够显式区分策略的"记忆—适应—忽略"三种学习机制，而不仅仅是评估任务成功率。
  • 引入有效秩（effective rank） 和因子敏感性比率（FSR / SNR）、CKA 等核统计量，用于量化和跟踪训练数据变化对内部表征结构的影响。
  • 通过多项实验证明了 NTK 几何结构与经验成功率之间的强相关性（Spearman ρ 高达0.92），可作为无需完整评估滚动就能预测 OOD 鲁棒性的代理指标。
  • 揭示独立变化（factorial design）优于混淆变化：在相同数据预算下，独立变化显著提升对新类别的泛化性能（0.0755 vs. 0.0846动作误差）。
  • 展示不同表示核（输出核、最后隐藏层核、eNTK）具有互补的盲点，并验证硬件实验中光照域随机化可将真实场景成功率从1/10提升至8/10。
Card 04 方法描述

方法描述

  • 采用三阶段流程：受控训练（系统变化单个或多个因素并固定其他分布）、探针集构建（保留位置和动作不变，重渲染变化因素的专家轨迹或验证帧）、表示核诊断（计算eNTK矩阵并提取统计量）。
  • eNTK 作为默认诊断工具，通过参数梯度内积表征一个样本上的训练如何传播到其他样本；为降低计算成本，将 Jacobian 限制在 LoRA 适配器 的参数空间。
  • 设计了多种核统计量：FSR（因子敏感比） 衡量不同因素引起的表征距离变化之比；SNR 为任务相关因素与任务无关因素的 FSR 特例；CKA 用于单因素组织对齐分析。
  • 通过 PCA 可视化探针表示，观察表征随训练颜色数量增加而从分离状态过渡到状态相关/颜色不敏感的结构。
Card 05 数据集与资源

数据集与资源

  • 使用 ManiSkill 模拟器（pick-and-place / pick-cube任务，CNN策略）
  • 使用 LIBERO 和 RoboTwin 基准（OpenVLA、RIPT-VLA、OpenVLA-OFT 模型）
  • 使用 ACT（Action Chunking with Transformers） 策略进行 peg insertion 和硬件实验
  • 使用 LoRA 适配器模块对VLA/Transformer模型进行受限 eNTK 计算
Card 06 评估与结果

评估与结果

  • NTK 预测有效性：NTK 余弦相似度与经验成功率间的 Spearman 相关 ρ 在多种DR配置下为0.57–0.92（p<0.01），验证 NTK 几何作为诊断代理的有效性。
  • 记忆→适应相变：在颜色数量从1增到27的过程中，eNTK 矩阵从块状结构平滑过渡为平坦结构，有效秩先升后降，OOD 成功率与有效秩平台期同步跃升。
  • 忽略机制：足够背景和物体 DR 后，SNR 从约 3.0 升至 3.5–4.1，状态 CKA 上升、颜色 CKA 下降，证明策略正忽略任务无关颜色/光照变化。
  • ACT 策略（单因素）：无 DR 策略验证损失最低（0.098）但 OOD 成功率最差（0.05）；充分 DR 下 OOD 成功率升至 0.43，SNR（激活和 eNTK）均正确追踪 OOD 改善趋势。
  • ACT 策略（双因素）：联合探针 SNR 正确排序四种训练条件的联合 OOD 成功率（joint DR 达到 0.35），单因素变化主要改善对应因素的泛化。
  • VLA 零样本模型选择：在 LIBERO 光照扰动下，eNTK SNR 排序（OpenVLA-OFT 3.53 > RIPT-VLA 3.51 > OpenVLA 2.80）与实证 OOD 亮度鲁棒性一致（88.7% > 88.4% > 8.1%）。
  • 捷径学习检测：在 RoboTwin 任务中，引入第三个任务打破视觉—文本混淆后，场景/语言 FSR 从21.4降至11.0（p=0.002），而对照保持15.0，无需任务级评估即可检测捷径学习。
  • 表示核比较：eNTK 和最后隐藏层均能检测捷径学习（10/10次），输出核失败（4/10次）；在双臂任务中，最后隐藏层因双臂共享无法分辨（SNR≈1），输出核则从 1.4–1.9 升至约48；eNTK 弱但可靠的上升趋势（1.02→1.14）。
  • 硬件验证：在真实世界 ACT 金字塔拾取任务中，亮度 DR 将 SNR 从2.5提高到5.5；明亮光照成功率从1/10升至8/10，暗光照从1/10升至6/10，分布内从6/10升至10/10。
