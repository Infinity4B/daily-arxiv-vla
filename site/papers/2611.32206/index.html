Seeing Is Not Reaching: Instruction Shortcuts Override Visual Grounding in Vision-Language-Action Models

02论文概述

  • 论文研究视觉-语言-动作模型（VLA）在目标物体位置变动后的动作执行问题，发现模型常回到物体的训练位置而非当前视觉位置。
  • 在六种 VLA 中识别出两种捷径：场景捷径（场景原任务被重复执行，忽略新指令）和指令捷径（指令直接检索训练位置而非当前物体）。
  • 在 π0.5 模型中，物体名称注意力能够跟随移动后的目标，但机械臂仍受指令捷径支配，论文将此现象命名为 “Seeing Is Not Reaching”（看得见但够不到）。

03核心贡献

  • 发现并区分了 VLA 中的场景捷径和指令捷径，并揭示 π0.5 存在“Seeing Is Not Reaching”现象，即视觉接地存在但被指令捷径覆盖。
  • 通过路径掩盖实验证明视觉接地已实际参与动作引导，但被直接指令到动作路径上的捷径效应所覆盖。
  • 提出路径分离引导（Pathway-Separated Guidance, PSG）方法，在推理时分别放大接地效应、抑制捷径效应，无需额外训练或外部目标位置。
  • 在 LIBERO-PRO Object 位置扰动下，PSG 将 π0.5 的目标到达率从 22.0% 提升至 52.6%，任务成功率从 16.6% 提升至 40.8%，同时基本保持原任务性能。

04方法描述

  • 将 VLA 中指令到动作的信息流拆分为接地路径（图像令牌读取物体名称令牌）和直接路径（动作令牌直接读取指令令牌）。
  • 通过掩盖每条路径并测量预测流速度的变化，定义接地效应 \(v_g\) 和直接效应 \(v_d\)。
  • 在流匹配采样过程中，修改预测速度为 \(\tilde{v} = v[A \nrightarrow \ell] + a \cdot v_g\)（即减去直接效应，放大接地效应），实现对两条路径的分离调整。
  • PSG 不需要训练更新参数，不使用物体坐标、分割掩码或检测器，仅需额外的注意力掩盖计算。

05数据集与资源

  • 使用的基准数据集包括：LIBERO、LIBERO-PRO（含 Position、Task、Goal、Spatial 扰动）、LIBERO-Plus（Layout 扰动）。
  • 评估的 VLA 模型包括：OpenVLA-OFT、SmolVLA、TurboVLA、π0-FAST、π0 和 π0.5。
  • PSG 主要应用于 π0.5 模型（基于 PaliGemma 视觉-语言主干与流匹配动作专家）。
  • 论文未明确提及模型参数量与训练硬件资源。

06评估与结果

  • 评估指标包括目标到达率（Reach）（首次闭合位置是否在目标物体上）和任务成功率（Succ）。
  • 在 LIBERO-PRO Object Position 扰动下，π0.5 基线 Reach 为 22.0%、Succ 为 16.6%；PSG 后提升至 52.6% Reach 和 40.8% Succ。
  • 在 LIBERO-PRO Goal 和 Spatial 扰动下，PSG 同样显著提升 Reach 和 Succ（如 Goal: Reach 从 75.8% 升至 87.0%，Succ 从 33.2% 升至 40.8%）。
  • 在原始 LIBERO 任务上，PSG 保持 95.2% 平均成功率（基线为 96.7%），表明对已训练任务性能影响较小。
  • PSG 与 CAG 对比：π0.5 + CAG 在 Position 下仅获得 26.6% Reach、16.4% Succ，而 PSG 分别达到 52.6% 和 40.8%，显示出分离引导的优势。
