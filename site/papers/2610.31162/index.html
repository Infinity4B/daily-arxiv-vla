核心贡献

  • 提出 HiSTEVE：分层 VLA 智能体 + 能力感知 agent harness，在长程执行中持续维护目标并在线调整计划
  • 设计 regime-specific RMSNorm（RS-Norm） 与 Dual-Mouse 鼠标位移 token 表示，缓解非 GUI 与 GUI 交互之间的负迁移
  • 采用 三阶段训练：世界知识注入、模仿学习、环境反馈强化学习，提升执行可靠性和恢复能力

Card 04 方法描述

方法描述

  • 能力感知 harness：包含能力约束规划、证据驱动交接与恢复、结构化记忆（工作记忆、情节记忆、程序记忆、世界记忆）
  • VLA 策略：基于 Qwen2.5-VL-7B，以 20Hz 从指令和第一人称视觉预测原生键鼠动作
  • RS-Norm：在每层 decoder 的 attention 和 MLP 前分别维护非 GUI/GUI 两组 RMSNorm 缩放向量，仅增加 2Ld 参数
  • Dual-Mouse：非 GUI 与 GUI 使用不相交的鼠标位移 token 集合，解决相机旋转与光标移动的语义模糊
  • 三阶段训练：先世界知识注入（概念与视觉接地），再模仿学习（指令+观察到键鼠动作），最后强化学习（环境验证分支比较 + GRPO + DPO 式成对优化）
  • 任务完成状态检测器：骨干 Qwen2.5-VL-3B，共享 VLA 图像编码器，通过归一化残差交叉注意力注入 VLA 策略上下文，并用 Wanda 风格剪枝 FFN 中间宽度约三分之一

Card 06 评估与结果

评估与结果

  • 评估基准：MineStudio Bench（strict pass@1）、OpenHA（family-wise episode success + macro average）、LongBench（final-goal success + hidden diagnostic progress）
  • 原子任务：HiSTEVE 在 MineStudio 平均 85.0%，较 OpenHA Text/CoA 提升 20.0 个百分点；在 OpenHA 平均 37.4%，提升 0.6 个百分点
  • 长程任务：LongBench 四类家族分别达到 42.9%、28.6%、14.3%、14.3%，相对 OpenHA Text/CoA 提升达 28.6 个百分点
  • 完成检测器：准确率与 F1 均为 0.863，FPR 0.140、FNR 0.135，优于 GPT-4o（F1 0.690）和 GPT-5.5（F1 0.776）等通用 VLM 基线
  • 消融实验：验证世界知识注入、环境反馈 RL、RS-Norm、Dual-Mouse 和完整 harness 对性能的贡献；固定 VLA 下完整 harness 相比固定步数交接将目标成功率提高超过一倍
