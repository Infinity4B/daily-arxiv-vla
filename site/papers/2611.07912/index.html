Card 02 论文概述

论文概述

  • 提出 GuidedWAM，一个无需训练的能耗引导（energy guidance）框架，用于在采样时向冻结的世界动作模型（WAM）中注入新的驾驶目标
  • 解决的问题：WAM 在训练完成后行为目标固定，新增驾驶目标通常需要重新训练十亿级参数模型，缺少训练后的控制通道
  • 在 NAVSIM v2 hard-split 上验证，引导可提升三个公开 WAM 的规划性能
Card 03 核心贡献

核心贡献

  • 在 flow-matching 采样器的 单步干净估计（one-step clean estimate） 上推导出能量引导，并以 雅可比自由（Jacobian-free） 形式实现，只需对冻结模型进行前向访问
  • 提出三项稳定化技术：采样时间引导调度（sampling-time guidance scheduling）、逐能量归一化（per-energy normalization）、速度有界修正（velocity bounded correction）
  • 在 DriveWAM、SimWAM、DriveLaW 三个公开 WAM 上实现无需推理特权信息的 EPDMS 提升，验证了训练后控制通道的可行性
  • 实验表明，与事后投影（post-hoc projection）相比，引导在满足约束的同时对舒适度等子指标影响更小，轨迹更平滑
Card 04 方法描述

方法描述

  • 利用 flow-matching 中的单步干净估计 \(\hat{\tau}_0 = \tau_t - t\,v_\theta\)，在动作流的当前干净估计上定义可微分能量
  • 通过倾斜分布 \(p_\gamma(\tau_0 \mid X) \propto p(\tau_0 \mid X)\, e^{-\gamma \mathcal{E}(\tau_0)}\) 实现目标注入，将能量梯度加入采样速度场
  • 用 detach 的干净估计替代网络 Jacobian，得到速度更新 \(v' = v_\theta + \lambda(t)\, \nabla_{\hat{\tau}_0} \mathcal{E}(\hat{\tau}_0)\)，仅需对解析能量求梯度，避免对冻结模型反向传播
  • 稳定化方法包括：将引导限制在噪声水平中间段的梯形窗口；将每个能量梯度归一化为单位范数；按首次引导步的速度范数对校正量进行截断
  • 能量示例：距车道中心线距离、到可行驶边界的带符号距离、与预测智能体框的间隙
Card 05 数据集与资源

数据集与资源

  • 使用 NAVSIM v2 hard-split：包含 450 个真实场景 和 5,462 个由扰动初始位姿生成的合成场景
  • 模型为三个公开、冻结的 WAM 检查点：DriveWAM、SimWAM、DriveLaW，论文提及这些为十亿参数级模型
  • 推理只需冻结模型前向访问，评估使用三个随机采样器种子，不依赖特权信息
  • 论文未明确列出训练 GPU/TPU 资源；报告引导带来的采样时间增加为每步低于 10%
Card 06 评估与结果

评估与结果

  • 主要指标为扩展预测驾驶模型分数 EPDMS，同时报告子指标：NC、DAC、DDC、TLC、EP、TTC、LK、HC、EC
  • 能量引导在 NAVSIM v2 hard-split 上提升：DriveWAM +1.8（35.9→37.8）、SimWAM +1.8（37.8→39.6）、DriveLaW +3.6（30.0→33.6）
  • 可行驶区域 DAC 分数在两个阶段均有提升；碰撞 NC 与驾驶方向 DDC 基本保持不变
  • 与事后投影相比，引导对两帧舒适度 EC 的损失更小（最多下降约 2 点，而投影为 5–7 点），且轨迹更平滑
  • 引导后的 SimWAM 是该表中表现最强的世界动作模型，但仍低于经过强化学习或记忆后训练的 DriveVLA-M0
