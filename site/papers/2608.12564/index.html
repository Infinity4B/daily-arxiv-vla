Scaling Automatic Research Agents via World Models

2026-08-12 · 原文 · 翻译 · 2608.12564

论文针对 AutoResearch agents 在强化学习（RL）训练中面临的环境执行瓶颈问题，提出 World Model RL (WMRL) 框架，用世界模型替代昂贵的真实环境执行来加速训练。 世界模型的预测存在偏差和噪声，论文设计了 Online Debiasing 和 Inverse-Variance Denoising 两种纠错机制来消除这些误差。 理论上证明了 WMRL 相比标准 RL 具有更严格的收敛保证，并在 AutoResearch 任务和具身智能 VLA 任务上验证了方法的有效性和通用性。

Card 03 核心贡献

核心贡献

  • 引入世界模型替代 RL 训练中的真实环境执行，将环境执行成本从线性增长降低到与生成计算相当，实现 3–4 倍训练加速。
  • 提出 Online Debiasing 机制（保序回归映射）和 Inverse-Variance Denoising 机制（逆方差加权融合），分别消除世界模型奖励的偏差和噪声。
  • 理论上证明使用不完美世界模型会引入可量化的误差项，而 WMRL 的两种缓解机制能严格改进收敛界，使训练收敛到与真实执行相同的优化点。
  • 实验表明，Qwen3.5-4B 和 Qwen3.5-9B 的 WMRL agent 在 MLE-Dojo 和 DSBench 上超越了 Kimi-48B-A3B 和 Nemotron-120B-A12B 等更大规模的 baseline 模型。
Card 04 方法描述

方法描述

  • 采用 GRPO (Group Relative Policy Optimization) 作为基础 RL 算法，通过组内相对优势估计进行策略更新。
  • 世界模型使用与 agent 相同架构的语言模型，输入任务上下文和解决方案，预测执行结果和奖励，替代真实的 Docker 沙箱执行。
  • Anchor Signal 机制：保留约 10% 的轨迹组由真实环境执行，获取成对的 (世界模型分数, 真实分数) 用于在线纠错。
  • Online Debiasing：使用保序回归 (isotonic regression) 拟合单调映射函数 $\hat{f}$，将世界模型预测分数校准为无偏分数。
  • Inverse-Variance Denoising：将真实执行梯度 $g_E$ 和世界模型梯度 $g_{WM}$ 按逆方差加权融合，权重比 $\rho = 1 + \hat{\eta}^2/\hat{\eta}^2_{\mathrm{cal}}$ 自动衡量世界模型的可信度。
Card 05 数据集与资源

数据集与资源

  • AutoResearch 数据集：MLE-Dojo（基于 Kaggle 机器学习竞赛，分为训练集和测试集）、DSBench（数据科学基准测试）。
  • VLA 数据集：LIBERO-Long（标准模拟操作基准，用于验证方法泛化性）。
  • 模型规模：研究 agent 使用 Qwen3.5-4B 和 Qwen3.5-9B；VLA agent 使用 MiniVLA-1B；世界模型使用与 agent 同架构的模型或 Robometer。
  • 训练资源：使用 A100 GPU 进行训练，总训练计算量以 GPU-hours 计量。
Card 06 评估与结果

评估与结果

  • 评估基准：MLE-Dojo (test) 包含 Tabular、Text、Image 三类任务；DSBench 包含 Bin-Cls、Multi-Cls、Regress、Other 四类任务；LIBERO-Long 用于具身智能任务。
  • 评估指标：Leaderboard 百分位（%）、平均 per-task avg@8、GPU-hours（训练效率）。
  • 关键结果：

- WMRL 在相同或更少的 GPU 时间（269–555 GPU-hours vs 883–1174 GPU-hours）内达到或超越了在真实环境上训练的 GRPO baseline。

- Qwen3.5-4B-WMRL 和 Qwen3.5-9B-WMRL 在平均表现上优于 Kimi-48B-A3B 和 Nemotron-120B-A12B 等大型 baseline 模型。

- 在 LIBERO-Long 上，WMRL 同样优于真实环境 RL baseline，证明了方法的跨领域泛化能力。
