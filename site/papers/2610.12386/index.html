02论文概述

  • 论文提出 Arc（一种推理配方），旨在通过正确的推理机制而非暴力扩展数据/模型来显著提升现有机器人基础模型（RFM）的零样本任务性能。
  • 核心问题是：如何在不修改架构、不新增机器人数据、不进行 foundation-scale 训练的前提下，提升已有 RFM（如 π0.5 和 Cosmos3-Nano-Policy）的任务成功率。
  • 论文表明，通过在现有演示数据上自动生成"动作锚定的因果推理轨迹"并微调预训练 RFM 使用这些轨迹，可获得前所未有的零样本性能提升。

03核心贡献

  • 提出动作锚定因果推理轨迹（action-grounded causal traces）作为机器人推理的中间表示，包含 State、Cause、Consequence、Effect、Action、Avoid、Completion 七个要素。
  • 提出 Arc-Trace，一个可扩展的自动标注流水线，在不对 DROID 采集新数据的情况下，将其重标注为 Arc-Trace-DROID（约 75K 条轨迹、1.2M 帧）。
  • 开发了将预训练 RFM 适配为使用推理轨迹进行控制的微调策略，针对 VLA（π0.5）和 WAM（Cosmos3-Nano-Policy）的架构分别定制（含反事实监督、轨迹监督等）。
  • 在 Cosmos3-Nano-Policy 与 π0.5 上于仿真和真实机器人基准中验证 Arc，取得了被认为无需额外演示或基础级训练的最高增益。

04方法描述

  • 推理表示：对每个动作块生成自然语言形式的因果轨迹 rt = [State, Cause, Consequence, Effect, Action, Avoid, Completion]t，将"当前状态→为何该动作→预期效果"显式连接。
  • 自动标注流水线：利用 VLM 从指令、视频和执行动作中提取结构，生成与动作块对齐的因果轨迹，无需人工逐帧标注。
  • VLA 微调（π0.5）：将轨迹编码为 token 附加到图像-指令上下文，联合微调 PaliGemma 骨干与 300M 动作专家，并引入 5% 反事实轨迹的负监督损失 Lcf 防止捷径学习。
  • WAM 微调（Cosmos3-Nano-Policy）：生成器在每层注意力中同时关注推理器 token 与视觉 token，联合优化预测损失与轨迹生成损失 Ltrace；因 8B 推理器已能区分冲突轨迹，不额外加反事实损失。
  • 推理阶段：冻结微调后的模型，使用外部 VLM（默认 Qwen3.6-35B-A3B）按需刷新生成推理轨迹，控制环开销仅为 ~10ms。

05数据集与资源

  • DROID 数据集（重标注为 Arc-Trace-DROID，约 75K 条轨迹、1.2M 动作对齐帧）。
  • π0.5：VLA 模型，PaliGemma 骨干（SigLIP 视觉编码器 + Gemma 2B 语言模型），另含 300M 参数动作专家。
  • Cosmos3-Nano-Policy：WAM 模型，含 8B 参数推理器与扩散生成器。
  • 评估使用 DROID 具身平台，仿真与真实硬件均已覆盖。

06评估与结果

  • 基准：RoboLab-120（vague/default/specific 三档指令）、MolmoSpaces、新构建的 RoboLab-Reasoning-50 及真实硬件 RoboLab-Reasoning-Hardware。
  • RoboLab-120：π0.5+Arc 在 vague 档达 45.1%（+29.8 p.p.），Cosmos3-Nano+Arc 达 44.9%（+24.3 p.p.）；两模型在 default 与 specific 档亦分列前两名（最高 48.8% / 51.2%）。
  • MolmoSpaces：Cosmos3-Nano+Arc 达 57.6%（+18.6 p.p.），π0.5+Arc 达 45.0%（+27.2 p.p.），均超过此前 SOTA。
  • RoboLab-Reasoning-50：Cosmos3-Nano+Arc 达 61.0%（+50.0 p.p.），π0.5+Arc 达 57.0%（+46.8 p.p.）。
  • 真实硬件：π0.5+Arc 任务成功率 91.7%，较 π0.5 提升 82.2 p.p.；控制频率 15Hz，轨迹刷新约 1Hz。
  • 效率收益：Cosmos3-Nano-Policy 仅需 4.3× 更少的训练更新即可达到基线成功率；推理时 π0.5 与 Cosmos3-Nano 分别只需 10× 与 2× 更少的去噪步数即可匹配基线性能。
