REFACTOR-VLA: Unsupervised Library Learning of Typed Motor Programs

02论文概述

  • 解决当前 VLA 模型（如 OpenVLA、π₀、RT-2、RDT-1B）的"monolithic"问题：它们直接生成原始电机命令或极短动作序列，缺乏可重用、定义良好的行为抽象，导致长程任务性能差且模型决策难以解释
  • 指出现有技能发现方法（如 AtomicVLA、AtomSkill、BLADE、LRLL）回避"行为等价"核心问题，或依赖未校准到机器人自身动力学的 LLM 进行判断，导致动力学无关的聚类错误
  • 提出 REFACTOR-VLA：采用 wake/sleep 架构，睡眠阶段使用基于潜在世界模型的行为等价核（BEK）对运动程序片段进行聚类，唤醒阶段生成类型化 lambda 程序并由库条件整流流动作解码器（LCAD）执行，仅通过 MDL 准则与回报保持门控的抽象才会被接纳为技能

03核心贡献

  • 行为等价核（BEK）公式化：定义片段级发散度 D_φ，结合 M_φ-rollout 值差异与 k 步 Wasserstein 距离，用于睡眠阶段聚类，并证明 NMI 集中率（Theorem 1）
  • 类型化 lambda 发射器与 LCAD：设计基于 Hindley-Milner 类型系统的词表（Σ = {Twist, Wrench, GripperPhase, Pose, Lang}）和语法，由带完整 occurs-check 的 Robinson 合一器进行类型检查，配合 4 层整流流 LCAD（~10.9M 参数）产生 16 步动作块
  • 带 MDL 门控的 Wake/Sleep 循环：候选抽象必须同时满足 BEK 合理性（ε_t）、回报保持（ε=0.05, K_v=32）和 MDL 增益（>4 nats）才能被准入，选择 top-K_max=8 被接纳候选
  • 端到端经验验证：在完整 LIBERO 4 套件、合成递归倾倒基准上进行验证，复现 4 个基线，完成 7/12 预注册消融；在 188M 参数下以 n=3 多种子实现 4-of-4 NMI 胜利（平均 Δ=+0.184），跨提供者 n=12 评估达到 95% CI [0.683, 0.729]

04方法描述

  • 四模块架构：骨干 VLA 策略 π_θ（含 TPE 与 LCAD）、层次潜在世界模型 M_φ、类型化 lambda 程序库 F_t、后验分布 ρ_t，外循环交替执行唤醒与睡眠阶段
  • 潜在世界模型 M_φ：基于 DreamerV3 的层次世界模型，采用冻结 DINOv2-base 视觉编码器与因果 Transformer（d_model=1024, 8 层），总参数 188.16M（101.58M 可训练），使用 KL 散度与视觉特征重建目标预训练
  • BEK 聚类与摊销：通过固定 k KMeans 聚类，计算 D_φ(τ,τ') = w_R·E\|V^τ_φ - V^τ'_φ\|+ w_E·E_s W_2(P^k_φ(·\|s,τ), P^k_φ(·\|s,τ'))；为降低 O(B²) 复杂度，采用 2.4M 参数的 Siamese Transformer k_χ 进行严格特征蒸馏（MSE）
  • Wake/Sleep 交替循环：每个外迭代执行三步——Wake 阶段训练 TPE（交叉熵）与 LCAD（整流流 MSE）；Sleep 阶段训练 BEK 头 k_χ；Library refactor 阶段执行语法反统一，通过 MDL 与回报保持门控准入新抽象
  • 关键创新：将行为等价性从单状态推广到轨迹片段，使用动力学校准的聚类替代语法或 LLM 判断，实现从语法压缩目标到行为压缩目标的转变

05数据集与资源

  • 数据集：LIBERO 基准套件的四个 LeRobot v3 子集（libero_object_image、libero_spatial_image、libero_goal_image、libero_10_image），以及合成 RecursivePourEnv 环境
  • 模型规模：世界模型 M_φ 188M 参数（d_model=1024, 8 层）；Siamese 摊销器 k_χ 2.4M 参数；LCAD ~10.9M 参数；另有 430M 参数规模作为容量探测
  • 训练资源：使用 8 张 H100 GPU 以 Distributed Data Parallel (DDP) 和 bfloat16 精度训练 4,000 步；跨提供者评估与基线运行在 单张 H100 GPU 上进行

06评估与结果

  • 评估基准：完整 LIBERO 4 套件矩阵、RecursivePourEnv 合成环境、4 个基线复现（AtomicVLA、AtomSkill、BLADE、LRLL）
  • 主要指标：Normalized Mutual Information (NMI)（聚类质量 vs task_index）、TPE 程序准确率、LCAD 速度误差、任务成功率
  • 关键实验结果：

- 容量反直觉发现：将 M_φ 从 188M 扩展到 430M 导致 4/4 套件 NMI 下降（libero_object: 0.4176 → 0.3555），falsify 了"更大世界模型总是更好"的假设

- 目标函数决定论：在 Phase A 添加辅助监督对比 InfoNCE 损失显著提升 Phase C 聚类质量，实现 4-of-4 头对头 NMI 胜利，平均提升 Δ=+0.184

- 具体 NMI 分数（n=3 多种子）：Object 0.462±0.021、Spatial 0.867±0.025、Goal 0.915±0.013、LIBERO-10 0.754±0.010

- 跨提供者收敛（n=12）：95% bootstrap CI 为 [0.683, 0.729]，均值 0.705，处于阈值边界

- 端到端有效性：睡眠阶段编译器生成首个真实 LIBERO 任务语言库（3 个抽象 / 1211 nats），其中 2 个抽象被 LCAD 使用，成功重写全部 256 个演示
