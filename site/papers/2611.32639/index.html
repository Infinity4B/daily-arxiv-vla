ReFocus: Progress-Guided Adaptive Practice for Long-Horizon Robotic Manipulation Reinforcement Learning

01研究单位

  • 作者主要来自 浙江大学 与 香港大学

02论文概述

  • 论文提出 ReFocus，一个面向长视野机器人操作的进度引导强化学习框架，通过交替全局与局部强化学习解决稀疏反馈和瓶颈练习不足的问题。
  • 针对在线强化学习在长视野操作中稀疏成功/失败反馈难以定位瓶颈、以及重复全任务 rollout 导致瓶颈分析不足和练习不充分的问题，ReFocus 利用任务 DAG 分解和进度奖励来诊断并强化瓶颈阶段。

03核心贡献

  • 提出 ReFocus 框架，交替 Global RL 与 Local RL，识别任务特定瓶颈并分配针对性练习。
  • 在 Global RL 中使用 DAG-based progress reward 提供密集反馈并解决奖励不平衡问题，同时用于瓶颈诊断。
  • 设计 Adaptive Practice Windows 和三种 rollout 模式（Normal、Prefix、Suffix），将局部练习与全任务执行连接。
  • 在 LIBERO-Long、RoboCasa365 及真实世界任务上验证有效性，大幅提升成功率。

04方法描述

  • 将每个长视野任务表示为 Directed Acyclic Graph (DAG)，节点为子任务，边为前置依赖，相同前置条件的子任务组成一个阶段。
  • DAG-based Progress Reward：为每个阶段分配均等的进度奖励预算（总预算为 2），阶段内子任务均分，避免分解粒度影响权重；结合子任务完成记录进行瓶颈诊断。
  • LLM-based Scheduler 根据验证 rollout 的进度序列和视觉观察识别停滞阶段，并结合历史记录（History Buffer）选择 Adaptive Practice Windows（定义从入口阶段到目标阶段的任务段）和里程碑奖励。
  • Local RL 使用三种 rollout 模式：Normal window（从恢复入口开始聚焦瓶颈）、Prefix window（从正常任务开始到窗口目标）、Suffix window（从恢复入口继续到全任务完成）。此时用里程碑奖励替代目标子任务奖励。
  • 两个阶段均使用 PPO 优化共享策略，交替多轮迭代，每轮后评估全任务成功率并更新历史缓冲。

05数据集与资源

  • 使用 LIBERO-Long（10 个桌面任务）和 RoboCasa365 Composite-Seen（16 个厨房任务）基准。
  • 基础模型为 π0.5（通过监督微调初始化），具体参数量未在文中明确提及；训练资源（GPU/TPU）未在摘要中提供，详情见论文附录。
  • 真实世界实验在三个长视野任务（BreadBaker、StackBowl、PickFruit）上进行，使用 RECAP 适配。

06评估与结果

  • 在 LIBERO-Long 上，ReFocus 取得 97.8% 成功率（基线 π0.5 为 90.6%），在 RoboCasa365 上取得 51.3%（基线为 39.3%）。
  • 与 Sparse-RL、SimpleVLA-RL、PolicyTrim、StructRL 等基线相比，ReFocus 均取得最优，尤其在长视野任务组中增益最大（如 RoboCasa365 1400–2900 步任务从 39.4% 提升至 46.4%）。
  • 真实世界实验中，BreadBaker 任务成功率从 30%（π0.5）提升至 95%（ReFocus）；StackBowl 和 PickFruit 均达到 100%，优于 RECAP 的 90% 和 85%。
  • 消融实验表明：单独使用 Progress Reward 或 Practice Window 只能部分提升（96.8% 和 93.4%），两者结合达到 97.8%；Local RL 的三种 rollout 模式组合（Normal+Suffix+Prefix）效果最佳。
