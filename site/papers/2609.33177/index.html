DeltaWAM: Change-Centric Visual Foresight via Delta Tokens for an Efficient World-Action Model

02论文概述

  • 针对现有World-Action Models（WAMs）在预测未来场景时重复建模静态背景，导致时空冗余、计算开销大，且动态信息不足影响低层控制精度的问题，提出轻量化的DeltaWAM模型
  • 核心思想是将未来预测的基本单元从完整场景帧转变为仅编码帧间动态变化的delta token，丢弃跨帧共享的静态上下文，减少冗余
  • 目标是实现低延迟、高泛化、轻量化的机器人操作策略，同时提供更适合低层控制的动力学先验

03核心贡献

  • 识别出现有WAM的时空冗余问题，提出将视觉前瞻分解为静态视觉锚（当前观测的DINO特征）和动态转换token（帧间变化delta token），将世界建模从场景重建转向变化预测
  • 提出DeltaWAM轻量世界-动作模型，总参数量仅0.725B，推理峰值内存仅3.86GB，大幅降低计算与训练开销
  • 通过实验验证压缩后的delta token比全状态预测提供更优的、更适合策略学习的动力学先验，在标准基准和扰动场景下均表现出色

04方法描述

  • 基于DeltaWorld构建变化中心的世界模型：使用预训练的DINOv3骨干提取多视角观测的密集特征，通过delta tokenizer将连续帧的特征差异压缩为单维度delta token，仅保留动态变化信息，丢弃静态共享上下文
  • 任务条件化适配：冻结T5编码器提取语言指令嵌入，通过Gated AdaLN将指令注入DeltaWorld的每个注意力与MLP分支，零初始化输出投影，让语言引导动力学预测而非覆盖预训练先验，解决无条件预测可能出现的任务对齐偏差问题
  • 两阶段训练范式：第一阶段采用Best-of-Many（BoM）范式微调DeltaWorld，通过采样多个高斯查询选择最接近真实未来轨迹的候选进行监督，支持多模态未来预测；第二阶段冻结微调后的DeltaWorld，训练flow-matching Action DiT，以当前DINO特征作为空间锚、预测的delta序列作为动态子目标进行条件动作生成，训练时随机选择oracle分支或随机分支conditioning提升鲁棒性

05数据集与资源

  • 预训练数据集：Kinetics-700大规模视频数据集，用于DeltaWorld的预训练
  • 仿真评估数据集：LIBERO基准（包含Spatial、Object、Goal、LIBERO-10四个操作任务套件）、LIBERO-Pro基准（用于测试程序扰动下的鲁棒性）
  • 真实世界数据集：在AgileX PiPER六自由度机械臂上收集的150集30Hz抓取放置数据集，包含前腕和手腕视角RGB观测及14维机器人状态
  • 模型规模：DeltaWAM总参数量0.725B，其中可训练参数120.3M
  • 训练资源：2张H100 GPU，总训练耗时256 GPU小时；推理在A100上测试，峰值内存3.86GB，单动作块延迟142.1ms，单动作算力需求约0.584 TFLOPs

06评估与结果

  • 评估环境：LIBERO四个标准任务套件、LIBERO-Pro程序扰动场景、真实世界PiPER机械臂抓取放置任务
  • 主要评估指标：任务成功率、模型推理延迟、峰值内存占用、程序扰动下的泛化鲁棒性
  • 关键实验结果：

- 在LIBERO标准基准上平均成功率达92.8%，在Spatial、Object、Goal、Long套件上分别达到92.6%、97.0%、95.8%、85.8%的成功率

- 消融实验证明delta token的必要性：仅用当前DINO特征conditioning的成功率降至73.9%，将delta token解码回完整DINO特征的版本成功率比DeltaWAM低13.8个百分点

- 在LIBERO-Pro程序扰动测试中平均成功率达17.85%，远高于多数基线（多数接近0%），证明模型学习到可迁移的任务相关动力学而非机械记忆轨迹

- 推理效率显著优于现有WAM：延迟仅142.1ms每动作块，峰值内存3.86GB，训练成本仅为256 GPU小时，大幅降低部署门槛

- 真实世界抓取放置任务验证了DeltaWAM的实际可用性
