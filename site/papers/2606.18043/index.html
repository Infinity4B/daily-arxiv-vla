02论文概述

  • 旨在解决基于流匹配的视觉-语言-动作模型（VLAs）缺乏不确定性量化机制的问题，该缺陷导致模型在分布外场景下产生不可靠动作且无法自我感知失败。
  • 提出了一种高效的认知不确定性估计方法，即速度场分歧（VFD），通过测量小规模集成模型中速度场之间的差异来量化不确定性。
  • 基于该不确定性估计，提出了样本高效的主动微调框架 SAVE，用于指导专家演示的数据采集，以降低模型适应新任务的高昂数据成本。

03核心贡献

  • 引入了基于速度场分歧（VFD）的流匹配模型认知不确定性估计器，并提供了严密的数学理论推导（Theorem 4.1）。
  • 提出了 SAVE 框架，利用 VFD 引导基于流的 VLAs 进行主动多任务微调，优先为最不确定的任务和初始状态请求专家演示。
  • 实验证明了 VFD 在预测任务性能和检测部署失败方面优于基线方法，且 SAVE 在多任务适应中所需的专家数据量比基线减少至少 22 倍。

04方法描述

  • 核心技术为速度场分歧（VFD），通过计算集成中各模型在学习速度场上的缩放平方差来近似分布间的 KL 散度，从而量化认知不确定性。
  • 理论推导表明，速度场差异在流匹配的后期时间步（噪声较低）权重更大，权重因子 $\kappa_s = s/(1-s)$。
  • SAVE 框架流程：从基础 VLA 训练集成 -> 计算候选初始观测的 VFD -> 在任务级别聚合不确定性均值 -> 使用带温度参数的分类分布采样任务 -> 选择该任务中最不确定的初始状态请求专家演示 -> 使用新旧数据混合微调集成模型。

05数据集与资源

  • 使用的数据集名称：LIBERO 机器人操作基准测试集
  • 模型架构：基于流匹配的视觉-语言-动作模型
  • 集成规模：使用小规模集成网络（Ensemble）进行不确定性估计

06评估与结果

  • 评估环境和基准：LIBERO 仿真环境中的多任务机器人操作
  • 主要评估指标：不确定性校准度、失败检测准确率、多任务适应的数据效率（所需演示数量）
  • 关键实验结果：VFD 提供了更好校准的不确定性估计并能强效检测失败；SAVE 框架在多任务微调中所需的高成本专家演示样本比基线方法至少减少 22 倍
