SilentWAM: Planning in the Masked State of a Diffusion World Model

论文提出 SilentWAM，一种在掩码扩散世界模型的掩码未来状态中进行规划的自动驾驶 planner，核心是用未来预测但无需解码未来帧。

01研究单位

  • 作者均来自 Zoox（自动驾驶公司），邮箱域为 @zoox.com
  • 作者：Ziyu Zhao、Casey Sun、Zeyu Wang、Shicong Ma、Emily T. Zhang、Cheng Lu

02论文概述

  • 论文提出 SilentWAM，一种在掩码扩散世界模型的掩码未来状态中进行规划的自动驾驶 planner，核心是用未来预测但无需解码未来帧。
  • 解决现有一类 world-action model 的矛盾：想象后行动模型需要额外生成步骤；未来联合训练模型在推理时丢弃未来预测。
  • 通过帧级掩码世界建模与掩码状态模仿，实现单次前向传播同时获取未来表示并预测轨迹。

03核心贡献

  • 首次展示掩码扩散世界模型的掩码未来状态可直接作为规划器输入，单次前向传播中利用预测未来，不生成帧、不增加独立预测器。
  • 提出帧级掩码世界建模（frame-level masked world modeling），显式训练全掩码未来，从观测上下文预测多帧未来。
  • 在 NAVSIM v1 使用单前视相机达到 92.0 PDMS，在 NAVSIM v2 达到 89.3 EPDMS，端到端延迟 60.3 ms。
  • 消融显示保留掩码未来可将 nuScenes 碰撞率从 0.18% 降至 0.06%；解码未来帧只带来边际改善。
  • 建立了统一图像-文本掩码扩散模型 + 连续轨迹头的规划范式，并引入模拟器奖励后训练。

04方法描述

  • 基于 MMaDA-Parallel-M（8B 掩码扩散模型，双向注意力，统一文本/图像 token），利用 PWM tokenizer 生成高分辨率 anchor tokens 与紧凑 dynamic codes。
  • 帧级掩码世界建模：将未来 K 帧的最后 n 帧整体替换为 [M]，损失仅在掩码帧上计算；分布 T 以概率 ρ 设置 t=1（全掩码），其余按 MaskGIT 余弦调度。
  • 规划输入由上下文（当前帧 anchor tokens、ego state、导航命令、当前帧 compact grid）+ K 个全掩码未来帧 + N 个可学习 query 组成，与训练时 t=1 一致。
  • 每层 query 同时关注上下文、掩码位置状态和其他 query，未来帧永不被解码；MLP 头预测相对恒速直线参考的 waypoint 残差，heading 由位置差分推导。
  • 后训练采用模拟器奖励 + Gaussian surrogate（轨迹拉伸采样、NAVSIM PDMS 作奖励、碰撞负优势），并使用足迹细化损失惩罚车辆角点驶出可行驶区域。

05数据集与资源

  • 预训练：OpenDV-YouTube（1.34M clips）、nuPlan（692k clips），无轨迹标签。
  • 微调/评估：NAVSIM navtrain（103k scenes）、navtest（12,146 scenes）、nuScenes，仅使用前视相机。
  • 模型规模：MMaDA-Parallel-M 8B；当前帧 448 tokens，每帧 compact grid L=28 tokens；规划查询 + 轨迹头约 25M 参数，动态码词汇扩展 8,192 行。
  • 训练资源：8 张 B200 GPU，有效 batch 32；端到端延迟 60.3 ms。

06评估与结果

  • NAVSIM v1：PDMS 92.0，NC 98.2，DAC 98.0，EP 90.1，TTC 97.8，C 99.8；人类 PDMS 94.8。
  • NAVSIM v2：EPDMS 89.3（修订版），NC 98.6，DAC 98.0，DDC 99.4，TLC 99.8，EP 87.1，TTC 98.0，LK 97.2，HC 98.1，EC 80.0。
  • nuScenes：消融中保留掩码未来使碰撞率从 0.18% 降至 0.06%；解码未来帧仅带来 NAVSIM PDMS 边际提升。
  • 对比方法涵盖无世界模型/有世界模型两类；在 NAVSIM v1 上 SilentWAM 与 SparseDriveV2 并列最佳 92.0（排除人类参考）。
