MOSAIC: Modular Obstacle and Spatial-Aware Framework for Manipulation In Cluttered Scenes

02论文概述

  • 针对视觉-语言-动作（VLA）模型主要依赖 2D 视觉与语言指令、在杂乱场景中空间推理不足的问题，提出 MOSAIC 模块化框架。
  • MOSAIC 可集成到预训练 VLA 策略中，通过显式语义掩码、物体级深度信息和障碍物感知注意力来增强物体理解与动作生成。
  • 重点解决杂乱场景下因空间误差导致意外接触或碰撞的问题，提升操作安全性与鲁棒性。

03核心贡献

  • 提出 MOSAIC 模块化框架，将目标物体、目的地和周围障碍物分离为不同语义角色，增强 VLA 的物体中心理解与空间推理。
  • 利用 VLA 自身骨干网络生成角色特定掩码，同时将语义物体级深度信息注入动作专家，显式建模障碍物与空间关系。
  • 引入接触感知的注意力引导策略，引导 VLA 在目标物体和目的地之外关注周围障碍物，改善杂乱场景中的动作生成。
  • 在 RoboPRO 基准和真实机器人上验证有效性，杂乱场景成功率提升 5.1%，视觉扰动下提升 9.7%，最困难环境提升高达 25.0%。

04方法描述

  • 语义掩码生成：在 VLM 骨干中引入目标、目的地、障碍物三类角色令牌，通过掩码头预测对应语义掩码，并将角色令牌加入前缀供动作专家隐式条件化。
  • 物体深度注入：使用冻结的 VGGT-Ω 进行 3D 场景重建，结合预测掩码生成统计量 token 和 4×4 网格几何 token，将目标与目的地深度信息注入动作专家最后六层。
  • 障碍物感知注意力引导：利用物体 OOBB 与机器人关键点的距离，构造接触感知的注意力真值热图，以 KL 散度监督动作专家前几层，并将注意力特征通过残差交叉注意力注入后续层。
  • 两阶段训练：首先在基座 π0.5 上使用 LoRA 微调掩码模块，随后全模型联合微调，结合流匹配动作预测、掩码监督与注意力监督。

05数据集与资源

  • 主要仿真基准：RoboPRO，包含 Office、Study、Kitchen-S、Kitchen-L 四个环境、80 个任务、每任务 200 条示范（100 干净 + 100 杂乱），杂乱场景含 6–15 个干扰物。
  • 真实机器人数据：使用 UR5e 机械臂和 Robotiq 2F-85 夹爪，采集 1000 条标注 episodes，覆盖杯子入碗、碗上架、杯子放杯垫、两方块堆叠、三杯入三碗等任务。
  • 传感器配置：仿真使用 320×240 RGB-D 观测（台面和双腕相机），真实世界使用三台 Intel RealSense 相机，模型输入为 224×224 三视角，预测 50 步动作块。
  • 基础模型：基于开源 VLA 模型 π0.5，在 RoboPRO 上预微调 30K 步；MOSAIC 全局批量大小 64，Stage 1 使用 rank-32 LoRA，Stage 2 全模型微调两个 epoch；论文未披露模型参数量与具体 GPU/TPU 资源。

06评估与结果

  • 评测指标：成功率（SR）、硬成功率（HSR，无碰撞成功） 与 碰撞率（CR）。
  • 干净场景：基线 π0.5 平均 SR 66.0%，HSR 61.0%；完整 MOSAIC 达到 SR 70.1%，HSR 64.8%，SR 提升 4.1 个百分点。
  • 杂乱场景：基线 SR 52.7%，HSR 39.7%；完整 MOSAIC 达到 SR 57.8%，HSR 41.3%，SR 提升 5.1%；Office 环境提升最大（SR +9.9%，HSR +7.1%）。
  • 消融实验：掩码单独带来干净 +1.0% / 杂乱 +2.7% 的 SR；去除障碍物掩码使杂乱 SR 从 55.4% 降至 52.7%；注意力引导额外增加 0.5% 干净 / 1.5% 杂乱；深度注入带来总计 +4.1% 干净 / +5.1% 杂乱。
  • 视觉扰动鲁棒性：在光照、模糊和逐帧像素偏移扰动下，MOSAIC 将平均 SR 从 65.2% 提升到 74.9%（+9.7%），HSR 从 63.4% 提升到 72.7%（+9.3%）；Office 环境 SR 提升高达 +25.0%（51.7% → 76.7%）。
  • 真实机器人验证：论文使用 UR5e 在五个真实任务上进行验证，体现了仿真到真实的迁移能力（具体量化结果未在提供的 HTML 片段中给出）。
