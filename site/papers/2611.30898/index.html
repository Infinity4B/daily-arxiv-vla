World Models as Native Latent Action Models

02论文概述

  • 论文提出 Native LAM，将预训练视频世界模型（Kairos 3.1 4B 机器人世界模型）直接作为潜在动作模型使用，同时承担逆动力学模型（IDM）和前向动力学模型（FDM）的角色，无需单独训练编码器和解码器。
  • 针对现有 LAM 从零训练 IDM/FDM 时需在像素重建与潜在空间质量之间折衷、训练脆弱的问题，通过动力学寄存器作为唯一因果桥梁，从预训练世界模型中提取紧凑的“原生潜在动作”（native latent action）。
  • 进一步提出 PAWlicy 预训练范式，利用冻结的 Native LAM 作为动力学教师，在大规模视频上为 VLA 策略提供潜在动作监督，而无需在训练或推理时生成视频。

03核心贡献

  • 提出 Native LAM：一个预训练视频世界模型同时作为 IDM 和 FDM，仅通过可学习的动力学寄存器桥接，无需单独编码器或解码器。
  • 提出反事实时间对训练方法（共享首帧但运动不同的视频对）和无文本 FDM 模式，迫使世界模型依赖潜在动作，避免后验坍缩；应用于 46 个机器人、人类和仿真数据源。
  • 提出 PAWlicy VLA 预训练范式：冻结 Native LAM 从任意视频中提取潜在动作标签，VLA 学习预测这些潜在动作并据此生成控制动作；训练和推理阶段均丢弃像素渲染。
  • 在 LARY 基准上，Native LAM 在动作分类和底层控制回归两个维度均优于现有 LAM；在 RoboTwin 2.0、RoboDojo 和真实机器人上验证了 PAWlicy 的有效性。
  • 证明原生潜在动作具备跨具身、跨场景、从人类到机器人的迁移能力，且潜在空间插值对应运动插值而非外观叠加。

04方法描述

  • 单一骨干双模式：Native LAM 使用预训练视频扩散 Transformer（Kairos 3.1 4B）作为共享骨干；在 IDM 模式下，动力学寄存器以只读注意力读取干净视频片段并输出潜在动作；在 FDM 模式下，同一网络从首帧和潜在动作出发，通过 MLP_in 适配器将潜在动作注入 token 序列，取代文本条件，用原始流匹配损失再生未来帧。
  • 动力学寄存器：短序列可学习 token 是 IDM 和 FDM 之间唯一的因果桥梁；IDM 模式读取潜在动作仅需一次前向传播，无需去噪。
  • 反事实时间对：对每个片段构建共享首帧但运动不同的配对片段（保持静止、暂停、变速、改变时序或倒放），两者共享噪声和扩散时间，迫使潜在动作携带运动差异。
  • 运动学接地：在 AgiBot World 2026 和 DROID 两个具有动作标签的数据集上，浅层运动学头从潜在动作预测末端执行器航点，损失权重 0.1，并在前 2000 步预热，其余 44 个数据源仅使用视频。
  • PAWlicy 架构：由 VLM（PaliGemma，初始化为 π0.5 骨干）、潜在动作 DiT（从噪声预测潜在动作）和动作 DiT（生成动作块）组成，三者共享注意力；潜在动作 DiT 重构过去一组潜在动作并预测未来三组，动作 DiT 以潜在动作作为逐层条件生成动作。
  • 训练细节：Native LAM 使用流匹配目标（公式 4）和总损失（公式 5）训练；PAWlicy 使用双流匹配损失（公式 6）预训练和微调。

05数据集与资源

  • Native LAM 训练数据：46 个视频源，包括真实机器人数据集（65% 采样率）、人类自我中心与手物交互视频（30%）和仿真（5%）；机器人数据如 AgiBot World 2026、DROID、ALOHA、Bridge V2、Galaxea、Unitree G1/Z1、Humanoid Everyday、MIME、1X World-Model、Fourier ActionNet、Fanuc Manipulation、GR00T Teleop、Jaco Play、RoboChallenge、RoboVQA、TACO Play、OXE 子集等；人类视频如 Xperience-10M、CASTLE 2024、DexYCB、EgoDex、Ego-Exo4D、EPIC-KITCHENS-100、GigaHands、HOI4D、HoloAssist、Kinetics-400、Motion-X++、OakInk2 等；仿真如 RoboCasa、RoboTwin 2.0。
  • 仅 AgiBot World 2026 和 DROID 使用动作标签进行运动学接地，其余为纯视频。
  • PAWlicy 预训练数据：16 个数据集（12 个与 Native LAM 重叠 + RoboCOIN、RoboMIND、InternData-A1、CALVIN）；RoboTwin 2.0 和 RoboDojo 被排除在 PAWlicy 预训练之外。
  • 模型规模：Kairos 3.1 4B 骨干；原生潜在动作为 32 个 token、维度 128（将 3456 个维度 2560 的 token 压缩而来）；PAWlicy 总参数量约 3.78B（VLM + 两个各 0.43B 的 DiT 专家，18 层、宽度 1024）。
  • 训练资源：Native LAM 训练 13k 次迭代，使用 32 块 GPU；PAWlicy 预训练 50k 次迭代，32 块 GPU，全局批大小 512。

06评估与结果

  • LARY 基准：在动作分类（top-1%）和控制回归（归一化 MSE）两个轨道上，Native LAM 均排名第一；分类平均准确率 71.77%（对比 WLA³ 的 70.75%），回归平均 MSE 0.25（对比 WLA³ 的 0.37），在全部四个回归数据集（CALVIN、VLABench、RoboCOIN、AgiBot-Beta）上均优于现有 LAM，且这些数据集均未用于训练 Native LAM。
  • 运动迁移与插值：从机器人视频中读取的潜在动作可在新机器人、新场景、人类手到机器人手、仿真到真实感场景中重放相同运动；潜在空间插值产生连贯的中间运动，而非图像像素叠加。
  • 视觉对比：与 DreamDojo、AdaWorld、Moto、LAPA 等其他 LAM 比较，Native LAM 能更清晰地重建大幅运动和完整片段，支持一次性生成整个视频片段，而其他 LAM 需自回归生成且误差累积严重。
  • RoboTwin 2.0：PAWlicy 达到 93.6% 的平均成功率（在对比方法中最高）；仅使用干净演示数据时仍比使用相同输入和增强的 π0.5 基线高出 5.5 个百分点。
  • RoboDojo：PAWlicy 在评估的四个维度上均领先对比方法，其 Precision 指标（由论文作者评估）与公开排行榜领先条目相当。
  • 真实机器人：在 AgileX NERO 机器人上，PAWlicy 将 π0.5 基线从 23.3% 提升至 76.7%（堆叠三个积木）和从 33.3% 提升至 90.0%（将鞋放入箱子）。
