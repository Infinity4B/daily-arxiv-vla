Humanoid World Action Model With Joint State--Action Generation

2026-10-08 · 原文 · 翻译 · 2610.12026

提出 HWAM（Humanoid World Action Model），一个面向人形机器人的世界动作模型，核心创新是将后执行本体感知状态（post-execution proprioceptive state）与高层参考动作联合生成，以显式建模分层控制系统中的“动作-执行差距”（action–execution gap）。 在分层控制架构下，高层 VLA/WAM 策略输出运动参考（reference actions），低层全身跟踪控制器将其适配为实际运动。HWAM 通过显式预测执行后的身体状态，为动作学习引入执行级监督，并将状态-动作轨迹与视觉转型双向 grounding。 论文在 LimX OLI 人形机器人上验证了 HWAM 在静止和移动操作任务上的有效性，并展示了其在 ALOHA 双臂衣物折叠任务上的适用性。

Card 03 核心贡献

核心贡献

  • 后执行状态–动作联合生成（Post-execution state–action generation）：将每个高层动作与其时间对齐的后执行本体感知状态配对，作为一个联合目标通过共享的状态–动作生成器去噪。
  • 执行状态 grounding（Execution-state grounding）：在后向动力学建模（IDM）和前向动力学建模（FDM）中，后执行状态分别作为联合预测目标与未来视频预测的条件，将执行状态监督与视觉转换相互连接。
  • 双向状态–动作–视觉 grounding：通过三条互补训练路径（Policy、FDM、IDM）将策略参考、实际身体运动与视觉结果关联起来。
  • 受控真实机器人实验证据：在移动操作任务上进行了目标（action-only vs joint state–action）与训练配方（VGM/Policy vs FDM/IDM/Policy）的因子消融，验证了联合目标与三路径训练之间的交互效应。
  • 开源：代码、数据集和项目页面已公开（https://hwam.vercel.app/）。
Card 04 方法描述

方法描述

  • 层次控制接口：高层策略输出运动参考动作 $a_t$，低层全身跟踪控制器通过本体感知反馈将其适配为实际运动，测得状态 $s_{t+1}$ 反馈给高层策略。
  • 联合状态–动作目标：定义状态块 $\mathbf{S}_t=[s_{t+1},...,s_{t+H}]$ 和动作块 $\mathbf{A}_t=[a_t,...,a_{t+H-1}]$，拼接为 $\mathbf{Y}_t=\text{Concat}(\mathbf{S}_t,\mathbf{A}_t)$，在特征维度上对齐同一时间步的状态和动作，使用共享的流匹配去噪器联合生成。
  • 架构：由两个交互专家组成——视频专家（视频过渡建模）和状态–动作专家（联合轨迹生成），两者通过路径相关的掩码交叉注意力交换信息。使用冻结的 Wan2.2 视频 VAE 提供视觉潜在编码，语言条件使用 UMT5-XXL 嵌入。
  • 三条训练路径：

- Policy 路径：仅条件于当前观测（视频+语言+当前本体状态），生成状态–动作轨迹，匹配部署条件。

- FDM（前向动力学建模）：条件于当前观测和完整状态–动作轨迹，预测未来视频。

- IDM（逆向动力学建模）：条件于当前和未来视觉潜在编码，联合预测动作与状态。

  • 训练目标：使用条件流匹配（conditional flow matching）和 MSE 损失，三条路径均匀采样（各 1/3），总损失为三者之和。

Card 06 评估与结果

评估与结果

  • 真实机器人评估（LimX OLI 三个任务，成功率 %）：

- Candy Picking：HWAM 达到 70.6%，优于 π0.5（62.5%）、DiT4DiT（52.5%）、Fast-WAM（43.3%）、GR00T N1.5（40.5%）、Cosmos3-Edge（15.8%）。

- Object Collection：HWAM 达到 46.7%，优于 π0.5（45.0%）、GR00T N1.5（42.5%）、DiT4DiT（15.0%），Cosmos3-Edge 和 Fast-WAM 为 0.0%。

- Plush-Toy Picking：HWAM 达到 73.3%，优于 π0.5（60.7%）、GR00T N1.5（60.0%）、Fast-WAM（60.0%）、Cosmos3-Edge（56.7%）。

  • 开环预测诊断（Candy Picking held-out episodes）：

- HWAM 在 32 步 chunk 上的平均动作 MAE 为 3.816°，优于 action-only FDM/IDM/Policy 的 4.024°。

- 在基于真实轨迹条件下的未来视频预测中，HWAM（条件包括动作+状态）PSNR 为 23.336，远高于只用动作的 20.559。

  • 受控消融（Plush-Toy Picking 移动操作）：

- HWAM（联合目标 + FDM/IDM/Policy）：73.3% 成功率。

- Action + VGM/Policy：60.0%；State–Action + VGM/Policy：45.5%；Action + FDM/IDM/Policy：55.0%。

- 结果显示联合目标在 FDM/IDM/Policy 配方下提升成功 18.3 个百分点，而在 VGM/Policy 下反而下降 14.5 个百分点，表明目标与训练配方存在显著交互。

  • 动作–执行差距测量：LimX OLI 上直接 MAE 为 4.420°，稳态 MAE 为 2.885°；ALOHA 上直接 MAE 为 0.648°，稳态 MAE 为 0.402°，证实分层控制下存在非零跟踪误差。
