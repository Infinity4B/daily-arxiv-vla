02论文概述

  • 论文研究机器人操纵策略在包含镜子反射的场景中的可靠性，灵感来自动物认知中的镜像自我识别测试。
  • 引入 RoboDojo-Mirror 基准，在保留任务目标与成功标准的前提下，系统比较无镜、单镜、双镜和镜面桌面四种条件下的策略表现。
  • 核心问题：反射是否导致机器人策略对物体定位和操作产生显著退化，以及退化是否仅由镜面作为物理障碍引起。

03核心贡献

  • 提出 RoboDojo-Mirror 评估基准，扩展 RoboDojo 以支持镜面配置下的配对评估。
  • 在五种策略（WALL-OSS-1.0-Lite、VPP2、Awomo-0.5、Rex-M1 Preview、GPT-6-Astra）上验证：所有镜面条件均降低成功率，平均下降 10.8 至 56.7 个百分点，镜面桌面上最高下降 62.5 个百分点。
  • 通过几何匹配的非反射面板对照实验，证明 50%–88% 的镜面特定失败在无机器人–面板接触时发生，表明直接碰撞不是性能退化的唯一原因。
  • 通过轨迹与接触分析，揭示两种典型失败行为：幻影目标定位（针对反射物体操作）和空间错位（对真实物体定位错误）。
  • 设计三项行为诊断（镜面桌面抓取、推连体反射物体、主摄像头遮挡下利用反射），进一步表征不同策略的抓取、推动和交互模式。
  • 在真实 Franka 机器人上验证：π₀.₅ 和 FastWAM 在镜面条件下均表现下降，与仿真趋势一致。

04方法描述

  • 基于 RoboDojo 构建 RoboDojo-Mirror，保留原始任务目标与成功标准，引入四种场景条件：无镜、单镜、双镜、镜面桌面。
  • 采用配对评估：同一策略、同一任务、匹配布局和策略种子，逐条件比较成功率和任务得分。
  • 对部分策略（WALL-OSS 和 Awomo-0.5）使用几何匹配的非反射面板作为物理障碍对照，分离视觉干扰与物理碰撞的影响。
  • 记录接触事件、轨迹、视觉观测和机器人状态，定义接触事件率、接触时间分数等指标，区分碰撞、幻影目标定位和空间错位行为。
  • 设计三项诊断实验：①镜面桌面上的抓取分析（ECL-G、NL、NF 指标）；②推连体反射物体（Push-T 变体）的多轮廓测试；③主摄像头遮挡下利用反射定位目标的指令条件对比。

05数据集与资源

  • 使用 RoboDojo 基准中的共享八任务集（含 produce placement、block stacking、bracket flipping、cylinder insertion 等）。
  • 模型规模：论文未明确提供参数数量，但涵盖 VLA 模型（WALL-OSS、VPP2）、世界动作模型（Awomo-0.5、Rex-M1 Preview）和智能体策略（GPT-6-Astra）。
  • 训练资源：论文致谢提到使用 Google Cloud TPUs (TRC)；真实机器人实验使用 Franka 机器人 和 π₀.₅、FastWAM 策略。

06评估与结果

  • 评估环境：RoboDojo 仿真环境（四类镜面条件）和真实 Franka 机器人（无镜、直立镜、镜面桌面）。
  • 主要指标：成功率（SR）、任务得分、接触事件率、接触时间分数、行为指标（ECL-G、NL、NF 等）。
  • 关键结果：

- 仿真中，五种策略在无镜条件下 SR 为 60.8%–72.5%，所有镜面条件均导致下降；镜面桌面使 VPP2 从 72.5% 降至 27.5%，Rex-M1 Preview 从 66.7% 降至 4.2%。

- 双镜条件通常比单镜造成更大退化（VPP2 例外）。

- 面板对照显示，镜面特定失败中 50.0%–87.5% 无接触记录，且双镜下接触时间分数镜面比面板高 1.85–6.83 倍（提示幻影目标重复尝试）。

- 镜面桌面抓取诊断中，VPP2 的 ECL-G 率从 0.0% 升至 95.6%，SR 从 97.8% 降至 4.4%。

- 真实机器人：π₀.₅ 总 SR 从 77.5% 降至 52.5%（直立镜）和 27.5%（镜面桌面）；FastWAM 从 60.0% 降至 30.0% 和 10.0%；两块策略在镜面桌面下块堆叠任务均降至 0.0%。
