02论文概述

  • 论文提出 Gnomon4D，一种世界-动作模型（World-Action Model, WAM），可联合生成未来视频、机器人动作以及 GeoDelta——一种视频对齐的 4D 几何运动场，编码本体与物体点的跨帧图像平面位移和深度变化 (Δu, Δv, Δd)。
  • 针对现有 WAM 的两大缺陷：RGB 未来预测将物理状态变化与外观纠缠（易过拟合外观、缺乏 3D 几何）；逐帧深度/点图缺乏时间对应关系。现有 4D 方法要么将运动隐含在视觉特征中（训练后丢弃），要么通过独立接口将轨迹转换为动作。
  • 研究目标：让显式 4D 几何运动与视频、动作在线联合生成，并指导动作专家“在哪里”（交互区域）和“何时”（接触/释放等转变帧）聚焦，从而提升闭环操作性能与泛化能力。

03核心贡献

  • Gnomon4D 架构：基于 Mixture-of-Transformers 的 WAM，联合生成未来视频、动作和显式 4D 几何运动表示 GeoDelta，使本体-物体交互动力学直接暴露给动作专家。
  • InSAttn 与 TransAgg 读出机制：任务自适应的时空重加权——InSAttn（Interaction-Salient Attention）聚焦交互显著的区域，TransAgg（Transition-Anchored Aggregation）聚合相对运动发生转变（如抓取、释放）的关键帧。
  • Embodiment 无关的共享“准动作”：GeoDelta 仅描述表面运动、不含本体特定控制参数，可作为人类与机器人共享的 quasi-action，支持在 EgoManip-5000H（5000+ 小时无动作标签自我中心操作视频）上进行无动作预训练，再在 Robot-30H 真机数据上中期训练。
  • 在 RoboTwin 2.0、VLABench、RoboDojo 三个仿真基准上取得领先，真机实验中在分布内/分布外设定下分别超过最强基线 7.0 和 16.0 个百分点。

04方法描述

  • GeoDelta 表示：对前景（本体+被操作物体）表面点，记录同一物理点在相邻采样帧间的像素位移与深度变化，并对相机运动不变；通过软阈值、固定尺度归一化和 μ 律压扩（μ=31）编码为 8 位 RGB 三通道，复用冻结的视频 VAE，且 μ 律为小幅接触运动保留更多精度。
  • 联合世界-运动-动作生成：Video、GeoDelta、Action 三个专家（各为 DiT 块堆叠）通过逐层联合注意力交互，并经交叉注意力读取语言指令与本体状态；GeoDelta 与 Action 专家共享去噪时钟（σ_G(u)=σ_A(u)=max(1−2u,0)，比 Video 快一倍），动作与几何运动在前半程联合去噪、后半段作为干净条件供视频细化；注意力掩码遵循执行的因果顺序。
  • 关系引导交互读出：由 GeoDelta 特征预测 token 级运动与本体/物体角色概率，构造相对运动场 c（衡量 token 运动偏离本体局部运动的程度）；用 K=32 个可学习查询先经 InSAttn 逐帧空间读出（显著度加权注意力），再经 TransAgg 按转变分数 r_n 时间聚合，交互 token 以残差方式注入动作专家，并配辅助读出头强制 Z 携带动作相关信息。
  • 推理：20 步求解器，GeoDelta 与动作在第 10 步即达干净状态，控制器执行动作块前缀并重规划，其余步骤仅在需要时细化视频。

05数据集与资源

  • 预训练：EgoManip-5000H——5000+ 小时无动作标签的自我中心操作视频（Video 与 GeoDelta 专家预训练）。
  • 中期训练：Robot-30H——来自 IG-10K 的 30+ 小时真机数据，用于将运动空间对接到机器人控制；随后在目标任务上后训练。
  • 监督构造：RoboTwin 2.0 由 SAPIEN 种子回放、VLABench 用 MuJoCo 官方采样器重生成得到精确 GeoDelta；RoboDojo 用前向运动学 + DA3 深度 + SAM 3.1 掩码 + RAFT 光流估计；真机使用 RGB-D 相机深度 + SAM 3.1 掩码 + RAFT 光流。
  • 模型规模：Video 专家初始化自 Wan2.2-TI2V-5B（30 层、宽度 3072）；GeoDelta 与 Action 专家宽度 1024，经宽度插值共享注意力空间；训练采用 FSDP 混合分片与 bfloat16 精度。
  • 推理设置：预测 H=32 控制步动作块，视频/GeoDelta 以步长 4 采样得 N=8 帧，20 步求解器，GeoDelta 与动作在第 10 步收敛。

06评估与结果

  • 仿真基准：RoboTwin 2.0-Full（50 个双臂任务）、VLABench（ID/Cat/CS/Ins/Tex 五轨道）、RoboDojo（多维度评测）。
  • 真机评测：5 个真实机器人任务，含分布内（ID）与分布外（OOD）设定；对比 Fast-WAM（RGB）、X-WAM（RGB-D）、FlowWAM（RGB+2D 光流）等基线。
  • 主要结果：RoboTwin 2.0-Full 上平均成功率 94.33%（Clean 94.56 / Rand. 94.10），超过 π₀.₅、Galaxea G-0.5、OpenWAM-Alpha、WAM4D、FlowWAM、STARRY 等 VLA/WAM 基线；VLABench 平均成功率 62.5%，领先 OpenWAM-Alpha（58.9%）等；真机实验在 ID/OOD 设定下分别超出最强基线 7.0 和 16.0 个百分点。
  • 消融研究：系统消融未来表示形式、交互读出机制与预训练课程，验证显式 4D 运动及交互读出各组件的贡献。
