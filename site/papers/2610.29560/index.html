Card 04 方法描述

方法描述

  • 总体框架：SERA 将高层 VLM 置于可编辑 harness 中，固定 VLA 执行器负责底层动作执行；harness 负责输入组织、上下文维护、命令检查和反馈使用。
  • 每个规划轮：harness 提供任务指导、近期视觉观测、运行时上下文、前次命令和动作候选；VLM 同时输出更新后的上下文与高层命令。
  • 执行流程：命令转换为执行器所需的输入格式，VLA 预测动作块并在多个控制步内执行；执行后的观测作为反馈进入下一轮规划。
  • 自演化阶段：分析 agent 诊断失败原因，修订 agent 生成候选 harness 修改（planning guidance、assessment criteria、control rules）；验证器通过环境 rollout 评估候选，比较修复、回归和不变结果，迭代选择后固定 harness 再进行测试。
  • 关键创新：将 within-episode 上下文管理与跨 episode 经验复用统一到可编辑 harness，整个自演化过程不训练 VLM 规划器或 VLA 执行器。

Card 06 评估与结果

评估与结果

  • 评估设置：按任务平均计算成功率，16 个任务等权；每任务 50 episodes，因此任务平均与 episode 池化结果一致。
  • 总体结果：SERA 取得 51.38% 总体成功率；未自演化初始 harness 为 44.38%，自演化提升 +7.00 个百分点。
  • Suite 成绩：Counting 49.00%，Permanence 57.00%，Reference 69.50%，Imitation 30.00%；在 Permanence 和 Reference 上优于所列对比方法。
  • 对比基线：MemER 42.38%，FrameSamp+Modul 44.51%，SAM2Act 21.37%，π0.5 17.93% 等。
  • 自演化案例：PatternLock 中修复了方向映射错误和缺失候选动作；VideoPlaceOrder 中展示了从演示中推断目标并在多个抓取尝试中保持任务上下文。
