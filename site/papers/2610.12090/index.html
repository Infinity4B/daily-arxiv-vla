Card 02 论文概述

论文概述

  • 论文提出 FlowMem（Reasoning and Flow Memory），一个统一的视觉-语言-动作（VLA）模型，将成功的潜在推理计算转化为可复用的推理经验，而非每次从零生成
  • 现有潜在推理 VLA 模型在每次策略查询后即丢弃推理结果，无法复用过去成功连接感知与控制的潜在推理计算；已有记忆增强方法保留的是文本笔记、感知证据或历史动作，未保留潜在推理本身的演化过程
  • 核心思想：将成功推理表示为有序的"潜在推理流"（latent reasoning flow），按任务进度感知的轨迹组织、检索并重组，用当前具身上下文细化后作为动作生成的先验。在 RoboMME 和 LIBERO-Plus 基准上分别达到 48.0% 和 77.3% 成功率，超过无记忆策略 1.7 和 4.1 个百分点
Card 03 核心贡献

核心贡献

  • 引入潜在推理流作为成功具身计算的可复用表示，捕获推理在任务进度中的演化方向，而非将经验简化为孤立向量或历史上下文
  • 提出 FlowMem 统一 VLA 模型，包含四个协调组件：Embodied Context Encoder、Reasoning Flow Memory、Recompose-and-Refine Reasoning Expert、Memory-Adaptive Action Expert
  • Recompose-and-Refine Reasoning Expert 实现锚定对齐的片段检索、跨片段多源重组、以及基于当前场景的残差细化三阶段机制
  • 实验验证潜在推理复用能提升闭环 VLA 控制性能，在 RoboMME 上提升 1.7 点、LIBERO-Plus 上提升 4.1 点
Card 04 方法描述

方法描述

  • Embodied Context Encoder：将当前观测、机器人状态、语言指令编码为上下文令牌，并提取视觉语义描述子和归一化状态作为检索查询
  • Reasoning Flow Memory：将成功轨迹中的潜在推理状态序列划分为有序的连续片段，存储片段载荷及检索元数据（视觉描述子、状态、进度区间、来源信息）
  • 片段对齐与重组：检索分数结合视觉余弦相似度与归一化状态距离，保留锚点后的有序局部后缀，通过确定性约束搜索跨源重组兼容片段形成推理路径；限定在任务命名空间内检索，排除当前评测片段
  • 路径标记化与细化：将重组路径压缩为固定大小推理令牌，通过固定深度残差算子使用当前上下文进行修正（$\mathbf{Z}_t' = \mathbf{Z}_t^0 + \Delta_\theta(\mathbf{Z}_t^0, \mathbf{H}_t, \bar{\mathbf{s}}_t)$）
  • 学习目标：潜在对齐损失（余弦相似度监督冻结的原生潜在推理目标）加上条件流匹配动作损失
Card 05 数据集与资源

数据集与资源

  • RoboMME：评估时间、空间、物体、程序性记忆，包括 Counting、Permanence、Reference、Imitation 四个子项，采用 Full-16 协议，16 个任务各 50 个固定评测片段
  • LIBERO-Plus：基于标准 LIBERO 训练的零样本评测，覆盖相机视角、机器人初始化、语言、光照、背景、观测噪声、布局等 7 个扰动域，共 10,030 个实例
  • 基线模型包括：OpenVLA、UniVLA、OpenVLA-OFT、MemoryVLA、MergeVLA、VLA-Adapter 以及潜在推理基线 LaST₀
  • 论文未明确披露模型参数量、GPU/TPU 数量等训练资源信息
Card 06 评估与结果

评估与结果

  • RoboMME 主结果：FlowMem 平均 48.0%，超过无记忆基线 LaST₀（46.3%）；Counting 75.0%（基线 71.5%）、Permanence 29.0%（28.0%）、Reference 37.5%（36.5%）、Imitation 50.5%（49.0%）
  • LIBERO-Plus 主结果：FlowMem 合并成功率 77.3%，超过 LaST₀ 的 73.2%；Spatial 从 72.8% 提升至 84.1%，Long 从 73.8% 提升至 78.7%
  • 组合式复用分析：多源重组覆盖 70.5% 策略查询，成功率达 48.0%，优于最近邻检索（45.6%）和单源检索（44.0%）
  • 记忆反事实实验：破坏任务身份、时序顺序或进度对齐均导致性能下降（分别降至 46.1%、44.4%、46.1%），验证任务身份、时序顺序和进度对齐均有贡献
  • 核心消融：移除多源重组（RoboMME 降至 44.0%，LIBERO-Plus 降至 76.5%）和移除当前上下文细化（RoboMME 降至 46.3%，LIBERO-Plus 降至 76.7%），均低于完整模型
