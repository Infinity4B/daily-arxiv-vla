02论文概述

  • 论文提出 PILOT（Physical Inference for Latent Optimized Trajectories），一种新的世界-动作模型（WAM）框架，用于机器人操作任务。
  • 针对现有 WAM 中高层物理状态演化与低层动作轨迹生成之间的表征纠缠，以及视觉分支只预测静态观测、缺乏状态转移信息导致的结构瓶颈，提出以表示演绎（Representational Deduction, RD）机制将运动语义链（Motion-CoT）原生集成到模型中。
  • 核心目标是将运动语义从视觉外观中解耦，用显式的状态转移 token 作为推理空间中的 CoT，引导细粒度轨迹生成，提升操作成功率和泛化能力。

03核心贡献

  • 提出 PILOT 框架，通过 Representational Deduction 机制解耦运动意图与轨迹生成，并将潜在状态转移信息内化为 Motion-CoT，缓解表征纠缠。
  • 设计 Causal Dynamics Engine (CDE) 和 Action-Perceiver 中的因果解耦注意力机制，阻止带噪动作影响运动语义查询，支持无未来像素重建的动作推理。
  • 引入基于 VJEPA2-AC 冻结编码器的未来表征监督，以丰富的状态转移监督信号缓解动作生成中的稀疏监督问题。
  • 在 LIBERO、LIBERO-Plus、RoboCasa-GR1 上分别达到 97.9%、80.3%、59.75% 成功率，在 8 个真实世界任务上平均 82.5% 成功率；仅动作推理比“先预测后行动”管线延迟降低 91.6%。

04方法描述

  • 总体架构：PILOT 由三个分支组成——基于 Cosmos-Predict2.5 的世界模型分支（视觉语言编码 + 未来帧潜变量预测）、基于 Perceiver 风格的动作模型分支（可学习运动语义查询 + 流匹配动作解码）、以及 Representational Deduction 分支（VJEPA2-AC 冻结编码器 + Causal Dynamics Engine）。
  • 运动语义查询：使用 K=64 个可学习查询 token（内部宽度 768，输出宽度 1024）从当前观测、指令和本体感受状态中蒸馏 Motion-CoT；未来观测仅作为训练监督，不参与推理。
  • 因果解耦注意力：动作 token 可关注上下文、运动语义和自身，但运动语义 token 不关注带噪动作 token；只有动作 token 使用时间条件 AdaLN，语义 token 对流匹配时间 τ 保持不变。
  • 流匹配动作解码：以条件流匹配速度目标训练，推理时从高斯噪声经 Euler 积分生成动作块，条件为 Motion-CoT、视觉上下文和状态。
  • Causal Dynamics Engine：将运动语义和状态投影到 VJEPA 特征维度（1408）后，与当前帧 patch 特征一起输入 CDE，预测未来帧的 VJEPA2-AC 表征；用 SmoothL1 损失（L_RD）监督，梯度回传到可学习查询，促使运动语义编码可预测未来状态转移的信息。
  • 训练目标：总损失为动作损失、加权世界模型损失和加权 RD 损失之和；世界模型保留辅助未来帧潜变量预测目标，推理时禁用未来预测生成以消除视觉瓶颈。

05数据集与资源

  • 仿真基准：LIBERO（Spatial、Object、Goal、Long-horizon 四个套件）；LIBERO-Plus（Camera、Robot、Language、Light、Background、Noise、Layout 七种扰动零样本迁移）；RoboCasa-GR1（24 个任务，含 PnP Close、Cuttingboard、Placemat、Tray、Plate 等类别）。
  • 真实世界：在 Agibot-G1 机器人上进行标准任务和泛化迁移评估，包括更换桌面、闪光/相机偏移等条件。
  • 模型规模：PILOT 约 2.5B 可训练参数；世界模型为预训练 Cosmos-Predict2.5 视频扩散 transformer；动作模型 K=64 查询、隐藏宽度 768、输出宽度 1024；流匹配解码器为 DiT，20 步去噪；VJEPA2-AC 编码器冻结，输出 256×1408 的 patch 表征；CDE 内部宽度 1024。
  • 训练资源：论文未明确列出 GPU/TPU 型号及数量；代码基于 StarVLA 项目，使用预训练 Cosmos-Predict2.5 和 VJEPA2-AC 权重。

06评估与结果

  • LIBERO：平均成功率 97.9%，超过 Motus（97.7%）、π0.5（96.9%）等基线；Goal 达到 98.1%、Long-horizon 达到 97.2%，体现长程意图理解优势。
  • LIBERO-Plus：条件计数加权平均成功率 80.3%，超过 PokeVLA（79.3%）；其中 Robot 70.0% vs 46.1%、Layout 82.0% vs 77.2%，表明学到的是转移动态而非浅层外观。
  • RoboCasa-GR1：整体成功率 59.75%（1200 次 rollout 中 717 次成功），在 Tray（73.20%）、Cuttingboard（70.00%）等类别上取得最佳或次佳。
  • 真实世界：8 个标准任务平均成功率 82.5%；在更换桌面、闪光/相机偏移等泛化条件下仍保持较高成功率。
  • 推理效率：仅动作推理比“先预测未来帧再反推动作”的管线延迟低 91.6%，因为 RD 分支和未来帧预测仅在训练时使用，不增加推理开销。
  • 消融与表征分析：验证 RD 带来的运动语义聚类和可解释性，注意力可视化显示 PILOT 更关注末端执行器与物体的交互，而基线被背景分散。
