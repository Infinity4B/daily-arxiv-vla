02论文概述

  • 现有无人机（UAV）视觉语言导航（VLN）和视觉语言动作（VLA）任务仅覆盖离散/粗粒度动作、短程原子操作，无法同时满足长程多阶段语义理解和细粒度连续飞行控制的需求；现有方法难以解决长程任务中的语义漂移、子目标遗忘问题，且 heavyweight 视觉语言模型（VLM）的推理延迟与无人机高频实时控制需求不匹配
  • 论文提出FLIGHT（Fine-grained Long-horizon Instruction-Guided Hybrid UAV Tasks）基准与FLIGHT VLA架构，旨在让无人机自主执行复杂长程细粒度自然语言指令，同时实现稳定的闭环连续飞行控制
  • 研究聚焦于如何桥接高层任务规划与底层连续控制，解决长时域飞行中语义推理延迟与实时控制要求的核心矛盾

03核心贡献

  • 提出FLIGHT长程细粒度混合无人机导航基准，包含Fine-grained VLN（细粒度视觉语言导航）和Long-horizon Flow（长程流式飞行）两个任务，配备密集6-DoF轨迹标注与Pilot Reasoning（飞行员推理）显式监督信号
  • 引入Pilot Reasoning机制，通过大模型辅助标注结合人工校验，显式建模人类飞行员的决策链，输出当前飞行状态分析与下一步子目标规划，作为高层语义与底层控制的认知锚点
  • 提出FLIGHT VLA异步快慢架构，解耦低频Streaming Pilot VLM（负责流式视频理解、任务状态推理）与高频扩散动作模型（负责连续控制），解决长程语义理解与实时控制的天然矛盾
  • 构建完整的闭环仿真评估体系，验证了现有主流VLN、VLA基线在长程细粒度无人机任务上的局限性，证实所提方法的有效性

04方法描述

  • Streaming Pilot VLM（慢模块）：基于StreamingVLM架构，输入任务指令、近期视频-状态窗口、历史Pilot Reasoning记忆，输出当前飞行状态分析、下一步规划的Pilot Reasoning文本，以及融合指令、历史上下文、当前视觉与规划信息的语义隐特征；采用重叠块全注意力策略训练，支持长上下文流式推理，降低长视频的计算开销
  • 扩散动作模型（快模块）：基于扩散Transformer（DiT）构建，输入实时FPV帧、无人机相对姿态编码、最新的VLM语义特征，生成未来H步的连续动作序列；采用Flow Matching目标训练，学习从噪声轨迹到真实专家轨迹的条件流场
  • 延迟感知联合训练：采用两阶段训练策略，先联合优化两个模块使动作模型适配VLM语义特征，再冻结VLM单独优化动作模型提升控制精度；训练时主动模拟不同时间偏移的VLM特征输入，让动作模型适应推理延迟，解决异步特征的时间错配问题，保证部署时的控制稳定性
  • 关键创新：异步快慢架构实现长程推理与高频控制的解耦，Pilot Reasoning显式监督 bridging 高层规划与底层控制，延迟感知对齐策略解决VLM推理延迟带来的分布偏移问题

05数据集与资源

  • 使用数据集：FLIGHT数据集，包含两个划分：

- Fine-grained VLN：共6689条轨迹，平均轨迹长度154.5m，以10Hz采样连续动作，每百米包含295.45个细粒度动作步，配备密集空间与动作级语言锚定

- Long-horizon Flow：共4098条轨迹，平均轨迹长度32.8m，包含13815个原子动作实例，平均每个轨迹包含3.37个多阶段子任务

  • 模型规模：Streaming Pilot Reasoning VLM为3B参数，扩散动作模型基于DiT构建，未公开具体参数量
  • 训练资源：论文未明确披露具体GPU/TPU硬件配置，基于UnrealZoo仿真环境采集的大规模专家飞行员轨迹数据完成训练；数据集已开源，公开渠道包括GitHub仓库（https://github.com/buaa-colalab/FLIGHT）与HuggingFace（https://huggingface.co/datasets/jujujulien/FLIGHT）

06评估与结果

  • 评估环境：基于UnrealZoo构建的高保真3D仿真环境，覆盖城市、工业、乡村等多样化语义丰富的场景，采用闭环评估方式
  • 评估基准：

- Long-horizon Flow任务基线：OpenVLA-UAV、MemoryVLA

- Fine-grained VLN任务基线：CMA+LAG、NaVid

  • 主要评估指标：

- 长程流式任务：成功率（SR）（所有子任务均完成才算成功）、子任务成功率（SSR）、归一化动态时间规整（NDTW）（衡量预测轨迹与参考轨迹的相似度）

- 细粒度VLN任务：导航误差（NE）、成功率（SR）、Oracle成功率（OSR）、指令遵循成功率（IASR）（要求严格按顺序完成所有子任务才算成功）

- VLM推理能力：状态准确率（State Acc.）、动作准确率（Action Acc.），采用GPT-5评估生成推理文本与真实标注的语义一致性

  • 关键实验结果：

- Long-horizon Flow任务中，FLIGHT VLA的SR达59.00%、SSR达78.97%、NDTW达45.78%，远超基线OpenVLA-UAV（SR 10.50%）和MemoryVLA（SR 18.50%），可正确处理最多7个子任务的长程指令

- Fine-grained VLN任务中，FLIGHT VLA的SR为13.5%、IASR为11.0%，显著高于基线CMA+LAG（SR 6.5%，IASR 4.5%）和NaVid（SR 13.0%，IASR 5.0%），可实现精准起飞、导航和定点着陆

- 训练后的3B参数Streaming Pilot Reasoning VLM在UAV视频推理任务中State Acc.达64.2%、Action Acc.达68.1%，大幅优于通用VLM（如Gemini-3-flash State Acc. 25.8%、Qwen2.5VL 3B State Acc. 5.0%），验证了Pilot Reasoning设计的有效性
