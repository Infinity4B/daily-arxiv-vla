Card 02 论文概述

论文概述

  • 针对现有Vision Language Action (VLA)模型隐式假设gripper invariance的问题，指出不同gripper类型（如parallel-jaw与suction）需要本质上不同的抓取策略，而现有数据集 predominantly 依赖parallel-jaw gripper
  • 提出MiGA（Multi-Gripper-Aware Dataset）：首个大规模多gripper-aware数据集，包含103,000个演示、5种gripper类型、36个任务，显式捕捉相同任务目标下不同embodiment的策略差异
  • 提出GVLA（Gripper-aware Vision Language Action Model）：通过新的multi-gripper tokenizer和dual Mixture-of-Adapters实现gripper-aware策略学习，在仿真和真实机器人上均显著优于基线
Card 03 核心贡献

核心贡献

  • 引入MiGA数据集：首个大规模多gripper-aware数据集，涵盖5种gripper类型（parallel-jaw、three-finger、soft gripper、suction、dexterous hand）和132个 distinct gripper-strategy pairs，提供sub-step分解和失败演示标注
  • 提出GVLA框架：结合三层multi-gripper tokenizer（platform、type、instance级别）和dual MoA机制，实现参数高效的gripper-aware fine-tuning
  • 新的gripper表征方法：通过分层soft prompt学习结构化gripper嵌入，使同类gripper在嵌入空间中聚类，同时保持不同类别间的分离性
  • 实证验证：GVLA相比最强基线π₀.₅提升7.62%平均成功率（66.00% vs 58.38%），并支持零样本泛化和少样本适应到新物体、任务或gripper
Card 04 方法描述

方法描述

  • Multi-gripper Tokenizer：将gripper信息分解为三个可学习嵌入层——platform token（机器人平台运动学特性）、gripper-type token（夹爪类别约束）、instance-level token（个体夹爪特征），通过预定义顺序拼接后作为soft prompts prepend到observation tokens
  • Dual Mixture-of-Adapters (MoA)：引入platform-aware gate和gripper-aware gate两个并行路由器，分别基于platform tokens和gripper-type/instance tokens进行top-k专家选择，以残差连接方式添加到VLA backbone的最终层，实现计算层面的gripper特定调制
  • Fine-tuning Objective：结合action loss（条件流匹配损失）、gripper prediction loss（辅助分类损失，增强gripper判别表征）和load balance loss（负载均衡正则化，防止路由器崩溃），联合优化动作生成和gripper感知
  • 基于π₀.₅ backbone实现，通过layer-wise probing分析确定在最终层插入MoA以直接调制动作生成
Card 05 数据集与资源

数据集与资源

  • 数据集：MiGA（Multi-Gripper-Aware Dataset），包含103,000个演示、36个任务、5种gripper类型，涵盖仿真（NVIDIA Isaac Lab）和真实世界（UFACTORY xArm7、Franka Panda、UR5）环境
  • Gripper类型：Franka Panda、Robotiq 2f-85（parallel-jaw）、Robotiq 3-Finger（three-finger）、软体两指夹爪、Cobot Pump/UR10 Suction Cup（suction）、Inspire Hand（dexterous five-finger）
  • 模型规模：基于π₀和π₀.₅ backbone，通过bottleneck adapter（d_b << d）实现参数高效微调
  • 训练资源：在仿真和真实机器人平台上收集数据，真实机器人实验仅需10个演示和20K fine-tuning steps即可实现少样本适应
Card 06 评估与结果

评估与结果

  • 评估环境：仿真环境（Isaac Lab）和真实机器人（UR5 + Robotiq 2f-85）
  • 评估指标：Success Rate (SR)、Prediction Error (PE)、Counterfactual Action Prediction Divergence (CAPD)、Linear Probe Accuracy (LPA)、Gripper Contribution Score (GCS)
  • 主要实验结果：

- GVLA (π₀.₅ backbone)在仿真四类任务（Flat、Stacked、Constrained、Semantic）上平均成功率达66.00%，超过基线π₀.₅（58.38%）7.62%

- 传统两阶段方法（AnyGrasp、GraspMAS）在复杂场景（Flat、Stacked）上完全失效（0%成功率），GraspVLA也遭遇类似退化

- 线性探测分析显示gripper判别信号从L0层的59%持续提升至L12层的80%，验证multi-gripper tokenizer能有效编码和传播gripper特定特征

- 真实机器人验证：GVLA在所有任务上均 outperforms π₀.₅基线，demonstrate efficient few-shot adaptation to novel tasks across unseen platform-gripper configurations

- 消融实验证实三层tokenizer和dual MoA的互补性：移除任一层token或任一MoA组件均会导致性能显著下降
