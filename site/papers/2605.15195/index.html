Card 02 论文概述

论文概述

  • 提出 VGGT-Ω，一个大幅扩展的前馈式三维重建模型，在静态和动态场景重建上均取得突破性性能
  • 通过架构改进、大规模数据标注管道和自监督学习，系统性地研究了模型与数据规模对重建质量的缩放规律
  • 解决了传统前馈模型在处理动态场景、训练效率和数据规模方面的瓶颈
Card 03 核心贡献

核心贡献

  • 提出 Register Attention 机制，用寄存器（registers）作为跨帧信息聚合的瓶颈，替换部分全局注意力，显著降低训练显存和计算量（约 70% 显存节省）
  • 简化了密集预测头，仅保留单一深度头，同时仍通过多任务损失监督点图和匹配特征，减少内存开销
  • 开发了高质量动态视频数据标注管道，结合 VLM 预过滤、SfM 和几何后过滤，从约 4000 万互联网视频中筛选出 80 万条高质量动态序列，总计获得 4M 条训练序列
  • 引入自监督教师-学生蒸馏协议，利用 1800 万条无标注视频进行训练，进一步提升泛化能力
  • 展示了寄存器（scene tokens）在下游任务中的价值，如增强视觉-语言-动作（VLA）模型和语言对齐
Card 04 方法描述

方法描述

  • 架构：采用 DINOv3 初始化的 ViT 提取图像特征，附加相机 token 和 16 个寄存器 token；交替使用全局注意力、帧注意力和 Register Attention 进行跨帧信息融合
  • Register Attention：仅让寄存器参与跨帧注意力，更新后的寄存器再通过帧注意力将全局信息分发回图像 token，形成高效的信息瓶颈
  • 解码器：深度预测使用轻量级 MLP 加像素洗牌（pixel shuffle）替代高分辨率卷积层；相机参数通过轻量 Transformer 作用于相机 token 和寄存器一次性预测
  • 训练损失：包含相机损失（L1）、深度损失（带不确定性和梯度一致性）、点损失和匹配损失，均通过单一深度头间接监督
  • 动态重建：通过预测深度和相机参数解耦场景运动与相机运动，无需显式运动掩码
  • 自监督训练：使用教师-学生框架，冻结预测头，通过特征匹配和回归损失约束学生在不同增强和帧序下与教师保持一致
Card 05 数据集与资源

数据集与资源

  • 使用 30+ 个公开数据集（如 Aria, Co3Dv2, DL3DV, ScanNet, Waymo 等）和多个内部合成/真实数据集
  • 通过自研管道从约 4000 万内部视频中提取约 80 万条动态序列，总训练数据达 ~400 万条序列
  • 模型规模从 0.2B 到 10B 参数可配置，主推 1B 和 10B 版本
  • 训练时利用架构改进节省约 70% GPU 显存，相比前代 VGGT 支持 15× 以上的监督数据训练
Card 06 评估与结果

评估与结果

  • 评估基准：静态场景（7 Scenes, NRGBD, ETH3D）和动态场景（DyCheck, Sintel, TUM-Dynamic）
  • 主要指标：相机姿态估计 AUC@3° 和 AUC@30°；深度估计 δ1.25 和 AbsRel
  • 关键结果：

- 相机姿态：Sintel 上 AUC@3° 达 40.0（相对 MegaSaM 的 22.5 提升 77%），AUC@30° 达 79.1（提升 35%）；ETH3D 上 AUC@3° 达 56.3（此前最佳为 46.1）

- 深度估计：Sintel 上 δ1.25 达 93.5（MegaSaM 为 74.1），AbsRel 降至 0.081；其他数据集上均取得最优或次优

- 推理速度比动态优化方法 MegaSaM 快 50 倍，且全程前馈无需后优化

- 残差寄存器（register）可即插即用地提升 VLA 模型性能，并能与语言特征对齐，展示空间理解泛化能力
