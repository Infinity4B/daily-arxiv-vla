论文概述

Card 03 核心贡献

核心贡献

  • 提出 Optimus-R 记忆中心化 VLA 框架，将机器人适配视为显式查询-技能记忆调优，减少持续学习中对模型权重反复更新的依赖。
  • 设计 Inline Memory Interface（内联记忆接口）：在 VLA 前缀流中插入可学习记忆 token，使主干网络在原生动作条件通路上生成控制感知的查询和技能表示。
  • 构建 Query-Skill Memory Bank（查询-技能记忆库）：将技能外化为解耦的查询原型（决定"检索什么"）和技能值（决定"如何行动"），支持技能复用、技能扩展和持续任务适配。
  • 开发 Bridge-and-Adapt（桥接与适配）机制：通过轻量适配器（adapter）和残差记忆更新实现跨域（如 sim-to-real）记忆空间对齐，提升域偏移下源域技能的可检索性。
Card 04 方法描述

方法描述

  • 方法由三个训练阶段组成：Stage A（接口预训练） 训练记忆 token、查询/技能编码器、技能解码器和 Token Projector，并构建初始记忆库；Stage B（桥接适配） 针对跨域场景，解冻主干并用记忆对齐损失适配查询对齐矩阵和低秩残差技能适配器；Stage C（记忆适配） 用于域内持续学习，冻结主干，仅更新记忆对齐模块、原型残差和记忆库条目。
  • 创新点在于技能原型以解耦的 key-value 形式存储（查询原型 p^q 与技能原型 p^s），通过运动感知降采样、进度分层采样和技能聚类构建初始库，检索时采用 top-K 加权聚合与残差更新，在不覆盖基础原型的情况下适应新任务。
  • 记忆库更新规则采用"接近现有原型则更新残差，否则进入候选缓冲区；当缓冲样本聚类有足够支持且低查询-技能方差时追加新原型"的策略，支持持续学习中的技能扩展。

数据集与资源

  • 模拟数据集：LIBERO、CALVIN、RoboTwin 2.0
  • 真实世界平台：14-DoF 双机械臂 GALAXEA R1 Lite 机器人，配备腕部相机和第三人称相机（224×224 分辨率），涵盖 9 个真实世界任务

Card 06 评估与结果

评估与结果

  • 评估基准：域内适配（LIBERO 四个子套件、CALVIN ABC→D、RoboTwin 2.0 Hard）、跨域真实世界迁移（20/50/80 演示每任务）、域内终身学习（先学 4 个旧任务再增量学 5 个新任务）
  • 主要指标：LIBERO 成功率、CALVIN 平均完成长度、RoboTwin 2.0 Hard 成功率、真实世界任务成功率、平均遗忘率（forgetting）
  • 域内适配结果：30% 数据下 LIBERO 平均成功率提升 16.5%（72.1→88.6），CALVIN 平均完成长度提升 0.42（2.09→2.51），RoboTwin 2.0 Hard 成功率提升 5.0%（9.8→14.8）；100% 数据下 LIBERO 平均 97.8%，RoboTwin 2.0 Hard 达 55.0%，均优于对比方法
  • 跨域迁移结果：20 演示/任务下真实世界平均成功率 33.3%，超过 π₀.5 基线 13.9%；80 演示下平均成功率 72.2%，同样优于 π₀.5（63.3%）、OpenVLA-OFT（54.4%）等基线
  • 终身学习结果：20 演示/新任务下新任务成功率 21.0%，比 π₀.5 提升 11.0%；80 演示适配后保留 77.5% 旧任务成功率，平均遗忘率 10.0%，低于 OpenVLA-OFT 和 π₀.5（均 15.0%）
  • 效率对比：Optimus-R 训练 GPU 时长为 86 小时，低于 π₀.5 全量微调（560 小时）和 LoRA 方案（128 小时），推理频率 14 Hz
