02论文概述

  • 核心研究目标是验证预训练的冻结机器人世界模型的内部预测状态是否已包含可直接解码的故障信息，无需针对故障监控专门调整世界模型的骨干网络
  • 提出FARM（Failure-Aware Readout from World Models）方法，仅通过轻量级读出模块解码冻结VLA-JEPA的预测状态，实现步级故障评分和因果轨迹风险评估
  • 旨在解决现有机器人执行监控依赖代理信号或需要训练专门监控组件的问题，实现低开销、可迁移、符合因果性的机器人执行监控

03核心贡献

  • 将机器人故障监控形式化为冻结世界模型（WM）状态的读出问题，首次系统验证预训练世界模型内部是否已编码故障相关信息，无需故障特定的骨干适配
  • 提出FARM轻量级读出模块，总参数仅33,985，可基于冻结的VLA-JEPA预测状态生成步级故障分数和因果轨迹风险，完全保持预测骨干的冻结状态
  • 在10任务LIBERO仿真基准和4组真实机器人跨策略/跨平台场景完成全面评估，在15个匹配基线中取得最优Seen性能，同时验证了固定读出零样本迁移、仅读出适配、因果部分历史判别和超低检测延迟的有效性

04方法描述

  • 首先从冻结的VLA-JEPA中提取预归一化的世界模型预测状态（WM状态，维度为768×1024，对应768个世界状态令牌和1024维预测器隐层宽度），通过梯度停止完全保留预测骨干的冻结状态
  • 设计的轻量级读出模块包含共享令牌投影（32×1024）、GELU激活与LayerNorm、注意力池化、32维隐藏层和sigmoid输出头，总参数33,985，将预测令牌压缩为故障感知表示后输出[0,1]区间的步级故障分数
  • 通过时间最大聚合（取历史所有步级故障分数的最大值）得到因果轨迹风险，仅依赖当前时刻及之前的历史信息，满足因果性要求，无需访问未来rollout状态
  • 训练过程仅优化读出模块参数，使用任务平衡的二元交叉熵损失、AdamW优化器（学习率10⁻³、权重衰减10⁻⁴）、轨迹批次大小4、最多80轮训练、早停耐心值10、梯度范数裁剪阈值1
  • 核心创新点：完全复用预训练世界模型的预测表征，仅训练极轻量读出模块；支持固定读出零样本迁移和仅读出适配两种部署模式，无需修改世界模型骨干

05数据集与资源

  • 仿真数据集：LIBERO manipulation基准的10个操作任务（7个源任务S1-S7、3个严格未见任务U1-U3），共500条轨迹（246条成功、254条失败），每个任务50条轨迹
  • 真实机器人数据集：覆盖PIPER X、SO-101、Franka三个平台的4组策略/场景，共1445条轨迹，包括PIPER X / π*_0.6的497条轨迹、PIPER X / VLA-JEPA的100条轨迹、SO-101 / Eval-RL的70条轨迹、Franka / π_0-FAST-DROID的778条轨迹
  • 模型规模：骨干为预训练的VLA-JEPA（基于V-JEPA2编码器和时序因果预测器），读出模块总参数量仅33,985
  • 训练资源：论文未明确说明训练所用硬件；检测器延迟测试使用RTX 5090显卡

06评估与结果

  • 评估环境：仿真在LIBERO 10任务基准，真实机器人在PIPER X、SO-101、Franka三个平台的4种执行策略场景
  • 评估指标：AUROC、AUPRC（0-100分制，分为Macro（任务平等加权平均）和Pooled（全局合并计算）两种统计方式），以及检测器侧推理延迟
  • 关键实验结果：

- 7个源任务五折out-of-fold评估下，pooled AUROC/AUPRC达到85.68/88.59，在10任务基准的15个匹配基线中Seen性能最优，较SAFE-MLP提升5.42/4.88个Macro AUROC/AUPRC点

- 真实机器人场景中，固定读出零样本迁移和仅读出适配均有效：仅读出适配后Franka平台完整种群的AUROC/AUPRC达到75.78±1.08/74.31±0.96

- 因果部分历史判别下，仅观测25%的轨迹长度时，pooled AUROC/AUPRC已达75.07±0.73/80.75±0.16；观测75%时达到81.63±0.40/85.53±0.65，接近全历史性能

- 检测器侧平均CUDA推理延迟仅0.2256ms，P99延迟为0.2393ms，吞吐量达4432.8步/秒，开销极低
