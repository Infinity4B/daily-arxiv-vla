02论文概述

  • 论文研究测试时验证（test-time verified）视觉-语言-动作（VLA）策略的候选提议质量问题，指出下游微调会导致 flow matching 解码器收缩到主导动作模式，使重复采样产生高度冗余的候选动作。
  • 作者将这一现象命名为提议收缩（proposal contraction），并论证它是限制测试时扩展（test-time scaling）的关键瓶颈：即使验证器很强，也无法在策略从未提出的模式中做选择。
  • 论文提出 Action Dynamic Sampling（ADS），在训练阶段缓解该问题，从而在部署阶段为不变的验证器提供更广、更贴近有效的候选集合。

03核心贡献

  • 识别并形式化 proposal contraction 问题，证明有效模式可能变得极少被采样，但来自这些模式的动作仍保留显著的 flow support。
  • 提出 ADS 方法，通过基于 flow support 加权的有限集合 KL 项，将这种概率与支撑度的不匹配转化为训练信号，且不增加任何部署开销。
  • 在仿真与四个真实机器人任务上验证一致性收益：RoboCasa 上 oracle best-of-8 成功率从 57.6% 提升至 63.0%。
  • 使固定验证器在仿真中提升 2.4–4.9 个百分点，真实世界操作任务中 TokenPB 最高提升 13.0 个百分点。
  • 通过消融实验证明增益来自 flow support 加权本身，而非单纯增加候选分散度。

04方法描述

  • 每个训练步除了主采样噪声外，额外采样 K 个噪声向量并积分通过当前策略，得到 sibling actions（兄弟动作）。
  • 用瞬时变量变换公式沿轨迹积分速度场雅可比矩阵的迹，得到每个兄弟动作的 flow support 分数 $\ell_k$。
  • 使用 Hutchinson 迹估计器（$R$ 个随机探针）以无偏方式估计雅可比迹，避免构建高维完整雅可比矩阵；亦可用中心有限差分形式实现。
  • 通过 softmax（温度 $\tau$）将 flow support 分数归一化为目标分布 q，并与以主预测为中心的局部高斯代理分布 p 做 KL 散度对齐。
  • 兄弟动作与目标分布 q 均使用 stop-gradient，梯度仅通过主端点 $\mu_\theta(c,z^{(0)})$ 回传；总目标为 $\mathcal{L} = \mathcal{L}_{\mathrm{FM}} + s(p)\lambda\mathcal{L}_{\mathrm{ADS}}$。
  • 梯度形式为加权的兄弟动作均值之差 $\Sigma_\theta^{-1}(\sum_k p_{\theta,k\|0}\tilde{a}^{(k)} - \sum_k q_k \tilde{a}^{(k)})$；当兄弟动作完全重合时梯度为零，因此需要设计适当的启用时机与调度。

05数据集与资源

  • 仿真基准：LIBERO-Plus、SimplerEnv（WidowX-Bridge、Google Robot 两种具身）、RoboCasa、RoboTwin 2.0。
  • 真实世界：模拟超市环境中的四个四物体操作任务（篮子与台面转移、货架整理、未见过的货架整理任务）。
  • 策略实现：基于 StarVLA，采用 GR00T 风格的 flow-matching 动作专家。
  • 关键超参数包括兄弟样本数 K、迹估计探针数 R、温度 τ 与权重 λ（默认值位于宽泛稳定区间）。

06评估与结果

  • 评估设置：将 ADS 与两个固定不改动的测试时验证器（RoboMonkey、TokenPB）配对，控制主干、数据、预测时域、预算与协议一致，保证对照公平。
  • 评估指标：成功率、成对提议 RMSE、oracle coverage、有效模式数、几何冗余指数 $M_{\mathrm{eff}}$、训练集回放距离（$d_{\mathrm{mean}}$、$d_{\mathrm{best}}$）、归一化熵差 $\Delta H$。
  • 无验证器场景：ADS 在 RoboCasa/LIBERO-Plus/SimplerEnv 上分别提升未验证成功率 1.5/2.9/4.0 与 1.0 点，同时将提议分散度从 0.003 提升至 0.021；而高斯扰动 $\sigma=20\%$ 虽达 0.044 分散度，却在 RoboCasa 上损失 15.1 点。
  • 训练集回放：ADS 将 $d_{\mathrm{mean}}$ 从 0.091 升至 0.102，但 $d_{\mathrm{best}}$ 从 0.085 降至 0.032，说明分散的同时仍有一个候选非常接近演示动作。
  • 验证器耦合：LIBERO-Plus 上 RoboMonkey/TokenPB 从 77.6/76.9% 提升至 81.3/81.6%；SimplerEnv 上 RoboMonkey 从 65.6% 到 70.5%，TokenPB 提升 3.4/3.0 点；RoboCasa 上 RoboMonkey 55.5%→57.9%，RoboTwin 2.0 上 89.8%→93.5%。
  • 真实世界：平均成对动作 RMSE 从 0.0041 增至 0.0120（约 2.9 倍），配合 TokenPB 平均成功率提升 10.3 点、配合 RoboMonkey 提升 5.0 点，且在未见过的货架整理任务上仍有效。
  • 组件消融（RoboCasa）：均匀权重兄弟样本虽分散度最高但成功率降至 48.6%；加入基密度加权恢复至 53.2%；加入路径积分 flow support 达 56.4%、分散度 0.021。
  • 候选预算扩展：随 $M$ 增大，ADS 的有效模式数与 oracle coverage 显著超过基线，oracle coverage 在 $M=8$ 时为 63.0%（基线 57.6%），验证器成功率同步领先，且在较大预算下优势先扩大后趋于饱和。
