02论文概述

  • 针对视觉-语言-动作模型，提出在闭环优化下的任务重定向攻击研究：在攻击过程中扰动会改变机器人早期动作并级联影响后续物理状态，导致预先收集的固定目标监督与实际演化轨迹失配，使攻击难以持续生效
  • 核心研究问题是：当扰动使轨迹偏离预收集的目标 rollout 后，固定监督能否继续引导机器人完成攻击者指定的目标任务
  • 论文提出 TRACO 框架，通过闭环执行反馈来重建目标监督，使视觉扰动更新始终对准实际到达的状态

03核心贡献

  • 提出 TRACO 框架：将视觉任务重定向攻击扩展为闭环优化，其执行驱动监督机制在攻击诱导的状态上重建目标监督
  • 设计 PGS（进度引导选择）：利用成功目标 rollout 作为有序进度参考，通过锚点位置匹配确定前沿状态，并将监督划分为“前沿”与“前缀”两组，兼顾推进新进展与保持既有进展
  • 提出自适应的组损失组合方式：对前沿与前缀的组均值取平方后相加，随两组匹配误差的相对变化动态平衡监督重心
  • 提供通用目标对齐机制：可适配连续动作块（平方误差）、动作 token 与 CoT 序列（负对数似然）、流匹配策略（同流状态下的向量场比较）以及动作-CoT 联合目标（如 TRAP）
  • 在多个 VLA 模型与仿真环境中验证，任务重定向攻击成功率显著高于依赖预收集 rollout 的基线攻击

04方法描述

  • 威胁模型设定：白盒攻击者可访问 VLA 参数与梯度，机器人在源指令下运行，攻击目标是让生成的轨迹完成任务，同时源指令保持不变
  • 执行驱动监督：每轮在当前扰动下用冻结 VLA 执行闭环 rollout，记录到达的状态；在选定状态下用目标指令查询模型，使源预测与目标监督对应同一物理状态，解决预收集数据与实际状态失配的问题
  • 进度引导选择：以末端执行器位置的连续锚点匹配估计进度，取最长连续通过前缀的最后一个锚点为前沿；对前沿状态施加监督以推进任务，对前缀锚点保持监督以保留已完成的进展
  • 扰动优化：对前沿与前缀组的匹配损失均值取平方后相加形成组目标，用固定 VLA 上进行投影符号梯度步更新扰动，多轮迭代中保留目标任务成功次数最高的扰动，全部成功时提前停止

05数据集与资源

  • 评估环境：LIBERO 模拟基准与 SimplerEnv 仿真环境
  • 攻击对象模型：PI、GR00T、LangForce、FAST、OFT、InstructVLA 等 VLA 模型
  • 覆盖多种策略输出形式：连续动作块、离散动作 token、思维链推理、流匹配策略
  • 攻击形式：全局视觉扰动与对抗补丁，区分已见与未见任务设置；扰动预算约束于可行集内
  • 扰动更新使用 VLA 参数与梯度，在多轮闭环 rollout 构建监督数据

06评估与结果

  • 评估指标：目标任务的攻击成功率（ASR）与评分指标 H，越高越好
  • LIBERO 全局扰动下，TRACO 平均 ASR 达 85.2%（已见）与 75.9%（未见），而 Action Attack 基线仅 46.9% 与 43.2%
  • LIBERO 对抗补丁下平均 ASR 达 53.5% 与 50.6%，均优于 Action Attack（46.6%、46.2%）；Random Noise 基线几乎无效（约 0）
  • 在 GR00T 上提升尤为明显：已见全局 ASR 从 63.2% 提升至 96.4%；OFT 上从 28.4% 提升至 94.0%
  • 对 InstructVLA 的补丁攻击（SimplerEnv）同样显示 TRACO 优于 Action Attack 与 Random Noise
  • 结果表明闭环监督重建与进度引导选择能显著增强视觉任务重定向攻击的迁移性与鲁棒性，凸显了 VLA 模型在视觉-语言-动作闭环下的安全风险
