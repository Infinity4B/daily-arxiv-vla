02论文概述

  • 提出 𝒵-sight，一个统一的机器人基础模型，将视觉-语言-动作（VLA）与生成式潜在世界建模相结合。
  • 解决视频世界模型计算成本高、潜在空间策略与 VLM 特征空间脱节的问题。
  • 𝒵-sight 在 VLM 自身的视觉 token 空间中直接预测未来，无需像素重建或外部编码器。

03核心贡献

  • 引入 𝒵-sight，在 VLM 的共演化视觉表示空间内联合降噪未来空间视觉 token 和连续动作。
  • 通过匹配的架构控制和测试时干预，证明共演化原生目标和联合降噪优于隐式特征对齐和冻结外部目标。
  • 𝒵-sight 在 SIMPLE 和真实世界 Unitree G1 任务上取得领先的人类级操作表现（81.9% 和 73.3%），同时保持桌面操作基准的竞争力。

04方法描述

  • 使用 mixture-of-transformers (MoT) 架构，耦合 VLM、foresight expert（预测未来视觉 token）和 action expert（生成连续动作），注意力掩码确保动作专家可读取未来预测特征。
  • 通过 EMA teacher 生成共演化的未来视觉 token 目标，使用 flow matching 分别对视觉 token 和动作进行联合降噪，避免像素生成。
  • 三阶段训练：VLM 在人类视频上预训练（仅 FAST token 监督），在混合机器人数据上中训练（引入专家，知识绝缘保护 VLM），目标具身数据上后训练（联合优化 flow 和 view loss）。

05数据集与资源

  • 预训练人类视频：EgoDex 和 EgoVerse，约 2,000 小时。
  • 中训练机器人数据：AgiBot World 和 Humanoid Everyday，约 2,750 小时，并混合 20% 人类视频。
  • 目标适配数据：SIMPLE、LIBERO、RoboTwin 2.0 和 Unitree G1 各自的演示数据。
  • 模型参数规模、训练硬件（GPU/TPU）在提供的 HTML 原文中未明确给出。

06评估与结果

  • 评估基准：SIMPLE（人类级全身导航操作，L0-L2）、LIBERO（单臂桌面操作四套件）、RoboTwin 2.0（双臂桌面操作，C2C/C2R）、真实 Unitree G1 六个任务。
  • 主要指标：任务成功率（SR）、进度分数（progress score）。
  • 关键结果：SIMPLE 上 81.9% 成功率（+9.6 分领先最强基线），G1 上 73.3% 成功率（+20.0 分），LIBERO 平均 97.7%，RoboTwin 2.0 C2C 82.44%、C2R 39.0%，推理耗时 110 ms/action chunk。
