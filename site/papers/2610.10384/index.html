OpenViTac: Learning and Benchmarking Visuo-Tactile Policies in a Unified Sim-and-Real Framework

Card 03 核心贡献

核心贡献

  • 构建了第一个覆盖多能力维度的统一视触觉操作基准 OpenViTac，提供仿真–真实世界对齐的任务配对，支持 2 种夹爪类型和 3 种触觉传感器。
  • 系统研究了触觉表示（SigLIP、T3、Sparsh、AnyTouch2）和触觉整合策略（token 级拼接、特征级调制、动作级条件化、专用触觉专家、触觉引导精化）对预训练 VLA 适应触觉任务的影响。
  • 提出 OpenVTLA，采用 AnyTouch2 编码器和 token 级拼接，在不引入额外融合模块的前提下取得最优性能。
  • 利用配对的仿真–真实世界设置，研究了仿真–真实协同训练，验证了在固定真实数据预算下额外仿真数据对真实世界策略学习的提升作用。
  • 验证了仿真与真实世界评估的强相关性（Pearson r = 0.967），表明 OpenViTac 可作为有效的仿真代理基准。
Card 04 方法描述

方法描述

  • 基准能力维度：属性感知（WC、HC、RC、RR、ECS）、易碎感知（GC）、接触丰富操作（GA、PD）、精密操作（In-USB、In-B v1、In-B v2）。
  • 真实到仿真对齐：通过 agent 辅助的 real-to-sim 流水线，从多视图图像重建物体资产，并根据参考任务配置实例化仿真任务；支持场景外观多样化以扩展训练分布。
  • 触觉表示：对比了原生视觉编码器 SigLIP 与触觉专用编码器 T3、Sparsh、AnyTouch2；其中 Sparsh 和 AnyTouch2 利用短暂时间历史捕捉接触动态。
  • 触觉整合策略：考察了五种注入方式——① token 级拼接、② FiLM 特征调制、③ 动作级条件化（如 N0-VTLA）、④ 专用触觉专家（如 FTP-1）、⑤ 触觉引导的后期动作精化（如 T-Rex）。
  • OpenVTLA：使用 AnyTouch2 将触觉历史编码为紧凑 token，投影后拼接到视觉 token 序列，保留 π_0.5 的原生 VLM 和动作生成路径。
  • 协同训练：通过加权行为克隆损失 L_co = (1-α)L_BC(D_r) + αL_BC(D_s) 混合真实与仿真数据，无需跨域配对轨迹或显式特征对齐。

数据集与资源

  • OpenViTac 任务集：11 个仿真任务，8 个真实世界配对任务覆盖四个能力维度。
  • 触觉硬件：支持 2 种夹爪类型、3 种触觉传感器类型。

Card 06 评估与结果

评估与结果

  • 仿真结果：OpenVTLA 平均成功率 68.7%，超过最强 VTLA 基线 FTP-1（61.2%）和最强 VLA 基线（51.5%）；触觉策略在属性感知和易碎感知任务上优势明显，精密操作仍具挑战。
  • 真实世界结果：OpenVTLA 平均成功率 54.6%，FTP-1 为 51.9%，VLA 基线在 34.0%~43.1% 之间，FastWAM 为 29.0%。
  • 仿真–真实一致性：任务平均成功率的 Pearson 相关系数 r=0.967，MMRV=0.006，OpenVTLA 和 FTP-1 在两个域中均排名前二。
  • 触觉表示对比：AnyTouch2（68.7%）> Sparsh（64.7%）> SigLIP（59.5%）> T3（58.1%），时间感知编码器表现更好；去除触觉预训练或时间信息均会显著降级。
  • 触觉整合对比：token 级拼接平均性能最高，在属性感知、易碎感知和接触丰富任务上领先，优于动作级条件化（48.6%）和后期精化（50.4%）。
  • 协同训练效果：在 In-USB 和 GA 任务上，加入仿真数据提升了真实世界成功率，并增强了对光照扰动的鲁棒性。
