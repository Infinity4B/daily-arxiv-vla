HiFOR: Hierarchical Foresight with Action-Guided World Grounding for Vision-Language-Action Model

02论文概述

  • 论文提出 HiFOR 框架，面向视觉-语言-动作模型在机器人操作中的前瞻预测问题，解决现有方法将短程世界动态与长程任务目标割裂建模、且将预测未来不加筛选地直接注入动作策略的局限
  • 核心问题在于：未来信息在不同预测时域、相机视角和空间区域上对当前动作的相关性不同，且随任务执行动态演化，需要建立跨时域依赖并按动作需求自适应检索相关未来信息
  • 方法通过层次化前瞻预测、结构化潜在世界建模与动作引导的分解式世界检索，实现多时域未来信息对动作生成的定向指导

03核心贡献

  • 提出层次化前瞻预测机制（Hierarchical Foresight Prediction）：通过层次依赖掩码（Hierarchical Dependency Mask, HDM）联合预测短期状态演化、语义里程碑和最终目标状态，建立局部动态与长程目标间的显式联系
  • 提出动作引导的结构化世界检索机制（Action-Guided Factorized World Retrieval, AWR）：利用去噪过程中动态演化的动作表征，沿时域、视角、空间维度执行分解式注意力，自适应检索与当前动作相关的未来信息
  • 提出结构感知潜在世界建模（Structure-Aware Latent World Modeling）：将多时域预测组织为保留时域/视角/空间结构的潜在世界表示
  • 构建层次化规划数据集：利用 Planning Agent 从指令分解子目标，并自动在专家演示中定位里程碑完成时间戳，无需额外采集轨迹
  • 在 LIBERO、RoboTwin 2.0 及六项真实世界任务上验证有效性，并通过消融实验确认各组件贡献

04方法描述

  • 以 VLA 主干（对标 π0.5 的 VLM + 动作专家架构）编码多视角观测、语言指令和机器人状态，采用流匹配（flow-matching）损失生成连续动作块
  • 定义三个互补预测时域：短期目标（t+Δ）、里程碑目标（下一个语义子目标）与最终目标（t_K），使用冻结的 DINOv2 ViT-L/14 提取 4×4 空间网格语义特征作为视觉监督，短期预测辅以未来机器人状态序列监督
  • 通过三组可学习未来查询与共享预测模块，在 HDM 约束下（s≺m≺g 的渐进注意力可见性）建立跨时域依赖
  • 将预测特征投影后叠加时域/视角/空间位置嵌入，构成 3×V×S×d_w 的结构化潜在世界张量，并导出时域级与视角级聚合特征
  • AWR 从动作专家在去噪步 τ 的隐藏表征构造动作条件查询，沿时域、视角、空间三个层级执行分解式 softmax 注意力并加权聚合世界 token，检索特征经残差连接注入动作专家
  • 总损失为 L = L_ACT（流匹配动作损失）+ L_HFP（前瞻预测损失）

05数据集与资源

  • 仿真基准：LIBERO（Spatial/Object/Goal/Long 四套件，每套件 10 任务，500 次评估）与 RoboTwin 2.0（Hard 设置下 20 个随机任务，每任务 100 次 rollout）
  • 真实世界：AgileX Piper 6 自由度单臂机械臂，配平行夹爪与两个 Intel RealSense D435i 相机；泛化任务每任务 100 条专家演示，长程任务 200 条，共六项抓取/放置/堆叠任务
  • 训练资源：8× NVIDIA H200 GPU，全局 batch size 512，端到端训练 30000 步（AdamW，学习率 5×10⁻⁵）
  • 真实部署：单张 NVIDIA RTX 4090 GPU

06评估与结果

  • RoboTwin 2.0（Hard）：平均成功率 49.40%，超越 π0.5（40.35%）9.05%；如 Blocks Ranking RGB 从 29% 提升至 46%，Place Cans Plasticbox 从 40% 提升至 63%
  • LIBERO：平均成功率 98.3%（最优），其中 Spatial 99.4%、Goal 98.6%、Long 95.8%；相比 π0.5 基线（96.9%）最大增益 3.4% 出现在长程任务
  • 真实世界：六项任务平均成功率 81.7%，较 π0.5 提升 11.0%，其中块堆叠任务提升 16.0%
  • 消融实验：RoboTwin 2.0 上，仅短程预测 44.15% → 加里程碑 45.60% → 加目标预测 46.95% → 加 AWR 达 49.40%；LIBERO-Long 从 92.4% 提升至 95.8%
  • 短程预测长度分析：5 步预测时域最优（与 LIBERO 每 5 步的动作执行间隔对齐）
  • 预测表征对比：语义特征预测优于 RGB 像素预测（LIBERO-Long 上 95.8% vs 94.2%）；注意力可视化显示模型在不同任务阶段自适应关注不同时域、视角与空间区域
