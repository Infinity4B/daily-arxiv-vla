Card 02 论文概述

论文概述

  • 论文研究 VLA（Vision-Language-Action）模型在异构任务中整合技能的难题：训练数据分散、联合训练存在干扰、模型合并引入参数冲突
  • 提出 NestedVLA 框架，对独立微调的策略进行后置式整合，将参数聚合范式转变为参数生成范式
  • 核心思路：用嵌套超网络生成动作专家（action expert）的稀疏参数更新，同时单独保留压缩后的 VLM 任务残差，与冻结的基座模型组合生成任务专属 VLA
Card 03 核心贡献

核心贡献

  • 提出 NestedVLA 框架，用单个共享嵌套超网络生成动作专家的任务自适应稀疏参数增量，避免存储完整任务 checkpoint
  • 设计 drop-and-rescale 压缩算子（per-module top-K 保留 + 全局 rescale 因子），在保真度与压缩比间取得最佳权衡
  • 提出 patch-based 参数 tokenization，将十亿级 VLA 骨干的参数空间分解为结构化 2D patch 网格，使超网络可学习回归
  • 在 MetaWorld、ManiSkill、CALVIN 三个基准上验证，平均超过最强模型合并基线 41个百分点，ManiSkill 上接近独立微调上限（差 0.9pp）
  • 存储效率显著优于动态合并基线（1.5× vs. 2.09×~2.89×）
Card 04 方法描述

方法描述

  • 三阶段流程：技能获取（独立微调 + drop-and-rescale 压缩）→ 技能整合（训练嵌套超网络吸收所有 action-expert 目标）→ 技能生成（推理时查询超网络生成增量并与冻结基座组合）
  • 技能获取：对每个任务独立微调共享骨干 π0.5，得到任务向量 τ_m = Θ_m − Θ_0，再用 drop-and-rescale 压缩为稀疏技能 z_m
  • 压缩算子：对每个模块保留幅值最大的 top-K 元素（K=10%），应用全局 rescale 因子 α=1.1 补偿能量损失，mask 在训练和推理中复用
  • 嵌套超网络架构：包含五个可训练组件——逐任务 patch 嵌入、任务编码器（2D 卷积+平均池化）、拼接与广播、共享 FC 主干+逐任务 LoRA 路径、多头输出模块
  • 参数 tokenization：将 action expert 的 18 个 transformer 块、9 种权重类型（162 个张量）切分为 256×256 的 patch（每任务 6,480 个 patch）
  • 训练目标：多任务掩码回归损失，仅在 mask M_m=1 的位置计算 MSE，任务加权 (1.0, 0.4, 1.0) 平衡 MW/MA/CA
Card 05 数据集与资源

数据集与资源

  • 使用数据集：MetaWorld（32 个操作任务，256 条轨迹）、ManiSkill（25 个操作任务，320 条轨迹）、CALVIN ABC-D（96 次长程 rollout，每条包含 5 个语言条件子任务）
  • 骨干模型：π0.5（约 3.61B 参数，其中 VLM 部分约 3.21B，action expert 约 0.40B）
  • 超网络规模：约 430M 可训练参数（共享 FC 宽度 h=2048，rank-1024 LoRA，多头输出 h→65,536 投影）
  • 训练资源：单张 A6000 GPU，约 10小时 完成 6,000 步训练（batch size 3，基础 lr 3×10^-4）
Card 06 评估与结果

评估与结果

  • 评估环境：基于官方 RLinf 流水线，3 个随机种子，典型标准差 ±2.7%
  • 主要指标：MetaWorld 和 ManiSkill 使用 success_once，CALVIN 使用 success_at_end
  • NestedVLA 平均成功率 66.7%，显著超越所有静态合并基线（Averaging 14.8%、TIES 13.1%、WUDI 11.8%、TSV-Merging 13.4%）和动态合并基线（TALL-Mask 22.6%、EMR-Merging 23.0%、Twin-Merging 25.3%、Free-Merging 25.6%）
  • 在 CALVIN 上达到 75.0% chain completion，而所有静态合并方法均退化为 0%
  • NestedVLA 在 ManiSkill 上达到 87.2%，与独立微调上限（88.1%）仅差 0.9pp；在 MetaWorld 上仍存在差距（37.9% vs. 72.3%），论文对此进行了专门分析（§4.4）
