Token-World: World Modeling in Vision-Language Model Token Space for Robot Manipulation

Card 03 核心贡献

核心贡献

  • 首次系统研究直接 VLM 视觉 token 模拟作为 RGB 管线替代方案，使模拟器直接作用于下游 VLA 策略消费的表示接口。
  • 提出 Token-World：一个自回归动作条件世界模型模拟器，采用 flow-matching DiT（Diffusion Transformer）在紧凑 VLM token 空间中建模动态，不依赖预训练视频生成模型。
  • 通过开环预测、闭环策略评估和表示消融三方面验证，证明 Token-World 在长时程特征保真度、策略动作一致性、策略成功率估计可靠性以及模拟成本方面全面改善。
  • 分析紧凑表示设计对动力学预测的影响：表征维度与动力学性能呈非单调关系，存在最佳压缩维度。
Card 04 方法描述

方法描述

  • 紧凑 VLM 世界状态（S-VAE）：使用独立训练的语义 VAE（Semantic VAE）将高维 VLM 视觉 token（N=108，D₀=2560）沿特征维度压缩至低维空间（d=16），保持空间 token 布局不变（无空间池化或 token 融合）。
  • 动作条件动力学模型：采用时空 Transformer 架构，分解为空间注意力和因果时间注意力；额外引入固定大小的 GRU 循环状态传播跨窗口的长程上下文。
  • 训练目标：使用 x₀ 参数化的 flow-matching 目标（带加权 w(τ)=0.9τ+0.1）配合 shortcut forcing 训练，支持高效少步生成（推理时仅需 16 步，基线需 50 步）。
  • 自回归 rollout：在紧凑状态空间中逐步去噪生成未来状态，仅在需要供下游策略消费时才通过冻结的语义解码器映射回 VLM token 空间；RGB 渲染仅用于可视化评估。
  • 关键创新：压缩沿特征维度而非空间维度进行，区别于现有方法（如 OneWM-VLA 逐视图压缩为单个 token）的聚合策略。

Card 06 评估与结果

评估与结果

  • 基线方法：IRASim（ICCV'25）、Ctrl-World（ICLR'26）、WorldGym（ICLR'26），均为基于生成式视觉动态的学习模拟器。
  • 评估指标：VLM 特征保真度（余弦相似度↑、NMSE↓）、策略动作一致性（同一冻结策略在预测与真实表示上的输出对比）、模拟成功率与参考成功率的 Pearson 相关系数、每步模拟延迟、潜在可建模性指标（SEC↓、LDS↑）。
  • 开环保真度（RoboTwin 50 任务）：Token-World 特征余弦 0.7714 / NMSE 0.4892，优于 IRASim（0.7372/0.5685）和 Ctrl-World（0.7097/0.6437）；动作余弦 0.9439 / NMSE 0.1145，同样优于基线（IRASim 0.9260/0.1533，Ctrl-World 0.9265/0.1463）。
  • 长时程 rollout：在 replay chunk 0/5/10/15（每块 16 步）下，Token-World 的 VLM 特征和动作相似度衰减明显慢于 Ctrl-World，定性结果更好地保持任务相关的物体构型与交互进程。
  • 闭环策略评估：Token-World 将模拟与参考成功率的 Pearson 相关性从 Ctrl-World 的 0.583 提升至 0.794，回归线更接近 y=x 理想曲线。
  • 模拟效率：Token-World 每步模拟延迟 0.359 秒，较 IRASim、Ctrl-World、WorldGym 分别加速 2.0×、5.3×、6.1×。
  • 消融实验：紧凑维度 d 从 8 增至 128 时重建质量持续提升（NMSE 0.1026→0.0409）但可建模性指标恶化（SEC 0.3511→0.4740，LDS 0.3100→0.1182）；动力学预测中 d=16 为最佳平衡点（特征 NMSE 0.1517、特征余弦 0.8306、动作余弦 0.9641）；S-VAE 状态显著优于原始 VLM 特征（特征 NMSE 0.4892 vs 0.7851）和 SDXL-VAE 潜变量（0.8164）。
