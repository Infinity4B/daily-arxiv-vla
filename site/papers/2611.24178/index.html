Adaptive Action Horizon Selection via Flow-Field Uncertainty

01研究单位

  • 作者来自 Arm AI Research (AAIR), Arm Ltd 与 Technion Israel Institute of Technology。

02论文概述

  • 提出一种从预训练流匹配 VLA 模型向量场中提取预测不确定性的后处理方法 DUAC（Divergence-based Uncertainty-aware Adaptive Action Chunking）。
  • 解决现有自适应动作分块（AAC）方法需要多次采样动作块、引入额外推理成本的问题。
  • 利用流场后验协方差的闭式表达式，在单个生成的 action chunk 上获得逐动作不确定性，用于自适应执行 horizon 选择。

03核心贡献

  • 提出 DUAC，从单次生成的动作块出发，通过雅可比-向量积推导每个动作的不确定性分数，无需重新训练或多次端点采样。
  • 提供采样高效的替代方案，相比 AAC 仅需一个生成 chunk，显著降低不确定性估计延迟。
  • 阐明 DUAC 捕获轨迹条件局部不确定性，对多样但有效的动作策略变体不敏感，减少不必要的重规划。
  • 将 DUAC 应用于自适应执行 horizon 选择，在多个基准上取得最佳性能。

04方法描述

  • 基于流匹配模型的闭式后验协方差公式：\(\operatorname{Cov}(a_n \mid a_{n,\tau}, c_n) = \frac{(1-\tau)^2}{\tau}[I + (1-\tau)J_{v_\theta}]\)。
  • 对协方差取迹得到块级不确定性，再将雅可比矩阵按动作位置分块，导出逐动作不确定性 \(U_i(\tau)\)。
  • 使用 Hutchinson 迹估计器（40 个 Rademacher 探针）估计散度，通过自动微分计算雅可比-向量积，避免显式构建完整雅可比。
  • 选用晚期流时间 \(\tau=0.9\) 评估不确定性；自适应选择执行 horizon 时，基于不确定性前缀均值的最陡增点确定 \(h^*\)，并设置下界 \(\xi\)。
  • 与 AAC 的熵度量不同，DUAC 捕获条件于特定生成轨迹的局部不确定性，而非跨采样块的全局离散度。

05数据集与资源

  • 使用 LIBERO（含 Spatial, Object, Goal, LIBERO-10）、LIBERO-Pro（位置扰动）、LIBERO-Plus（相机、语言、背景等扰动）和 RoboCasa Kitchen-24（24 个操作任务）。
  • 模型为公开的 π0.5 策略，采用 OpenPI pi05_libero 和 LeRobot pi05_robocasa 检查点。
  • 实验在 NVIDIA A100 上运行，基于 JAX/OpenPI 实现；AAC 使用 20 个候选动作块，DUAC 使用 40 个 Hutchinson 探针，生成过程为 10 个去噪步骤。

06评估与结果

  • 评估协议：LIBERO 每任务 50 次 rollout，RoboCasa 每任务 100 次 rollout；对比固定 horizon、AutoHorizon、AAC 和 DUAC。
  • 主要指标：任务成功率、平均模拟步数、决策次数、不确定性估计延迟和相对成本。
  • 在 LIBERO-Pro 上，DUAC 总体成功率最高（49.2%），优于 AAC（48.7%）、AutoHorizon（47.3%）和 Fixed-10（47.2%），且在强扰动下优势更明显。
  • 在 RoboCasa Kitchen-24 上，DUAC 总体成功率最高（52.33%），旋转任务成功率最高（31.00%），决策次数比 Fixed-25 减少约 15%。
  • DUAC 的不确定性估计延迟约 204 ms，相对固定 horizon 的成本为 3.0×，远低于 AAC 的 582 ms 和 8.5×。
  • 在多样有效策略任务（如双摩卡壶）中，DUAC 对策略多样性不敏感，平均 horizon 提高，决策次数减少 14.7%，同时保持 75% 成功率。
