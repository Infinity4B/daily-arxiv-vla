Beyond the Sink Interpretation: Radial Attention in Flow-Based VLA Policies

01研究单位

  • 论文作者均来自 Duke University（杜克大学）
  • 主要作者包括 Yuxi Zheng、Yueqian Lin、Yudong Liu、Zijia Tang、Yiheng Wang、Hai Helen Li 和 Yiran Chen

02论文概述

  • 论文研究基于流的视觉-语言-动作（VLA）策略中动作专家（action expert）的注意力机制，特别是针对 π₀.₅ 模型中动作序列首尾 token（端点）的高注意力现象
  • 之前的研究将这两个端点 token 称为“径向动作汇聚点”（radial action sinks），但论文质疑这一命名是否准确，因为“汇聚点”（sink）在语言模型中具有特定含义：高入向注意力、小值范数、对输出贡献很小
  • 论文通过配对干预实验，系统检验端点 token 是否真正符合汇聚点的特征，并寻找真正符合汇聚点描述的 token

03核心贡献

  • 证明端点注意力质量来自 RoPE 位置编码：浅层直接由当前层的 RoPE 产生，深层则依赖上游动作 token 的 RoPE 处理
  • 证明端点值不符合汇聚点的特征：端点值范数接近动作 token 均值，其门控输出贡献高于平均水平
  • 发现真正符合汇聚点特征的是前缀 BOS token：具有高注意力质量和小的共享值，且将其值置零反而提升成功率 +13.2 个百分点
  • 揭示动作 token 间的路由遵循相对偏移轮廓（relative-offset profile），该轮廓能保持 75% 的动作 token 差异性和闭环成功率
  • 提供了系统的配对干预协议，用于分离注意力分配与值贡献的功能分析

04方法描述

  • 采用配对干预协议：每个干预与其基线共享相同的观察和初始噪声，闭环比较逐集配对
  • 设计三类干预实验：位置编辑（保持内容不变，改变 RoPE 位置）、分数和值编辑（掩码、置零、替换）、动作-动作路由编辑（均匀路由、共享偏移路由、偏移打乱、键置换）
  • 使用端点质量（endpoint mass）和门控输出比（gated-output ratio）等定量指标衡量 token 的功能角色
  • 通过在浅层和深层分别移除 RoPE 来区分当前层旋转与上游位置处理的贡献
  • 使用来自不同观察（donor）的值进行替换，测试 token 方向信息的重要性

05数据集与资源

  • 使用 RoboCasa 仿真环境的五个任务：CloseFridge、OpenCabinet、OpenDrawer、PickPlaceCounterToCabinet、TurnOnMicrowave
  • 分析模型为 π₀.₅ 的 action expert，检查点 pi05_pretrain_human300（第 75,000 步）
  • 网络包含 18 层，处理 50 个动作 token 的联合去噪
  • 实验规模：端点值分析使用 1,969 个 chunk；闭环评估每个任务运行 50 个 episode，共 250 个 episode

06评估与结果

  • 端点注意力质量：两个端点共接收 5.4% 的动作键注意力质量，仅比均匀份额（4.0%）高 1.4 个百分点
  • 端点值范数：位置 0 和 49 的相对值范数分别为 1.034 和 1.019（相对于动作 token 均值），不符合汇聚点的小值特征
  • 端点值干预：掩码、置零和替换对成功率影响均小于 4 个百分点；而替换两个已执行的内部 token（位置 2 和 3）导致成功率下降 28.4 个百分点
  • BOS token：符合汇聚点的质量和小值特征，将其值置零使成功率从 107/250 提升至 140/250（+13.2 个百分点，95% CI [+7.0, +19.4]）
  • 动作路由：共享偏移路由保持 75% 的动作 token 差异性，并在三个留出任务上保持 42.7% 的闭环成功率（基线为 38.7%）；均匀路由和打乱路由将成功率降至 3-4%
