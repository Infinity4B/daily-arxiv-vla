When Instructions Retrieve Trajectories: Diagnosing and Mitigating Generalization Failures in VLA Models

2026-09-30 · 原文 · 翻译 · 2609.39971

论文聚焦于视觉-语言-动作（VLA）模型在反事实扰动（counterfactual perturbations）下的泛化失败问题。模型在分布内任务上可超过 90% 成功率，也能承受不改变所需动作的干扰性扰动（nuisance perturbations），但在要求不同动作的场景变更（如交换物体位置、更换目标）下表现急剧下降。 论文提出并诊断了名为 instruction-action binding（指令-动作绑定）的失败模式：策略对语言和视觉各自都有响应，但未能将二者组合起来选择任务所要求的动作。指令会检索熟悉的轨迹族，视觉反馈只调整该轨迹的执行，而非纠正任务级动作选择。 基于该诊断，论文提出 Equivariant Counterfactual Training (ECT) 训练方法，通过补充"同一指令下不同场景要求不同动作"的监督信号，修复 VLA 模型的指令-动作绑定泛化失败。

Card 03 核心贡献

核心贡献

  • 识别并命名"指令-动作绑定"失败模式：在 π₀.₅ 和 GR00T-N1.7 两种 VLA 架构中，通过 381 个行为学探针测试发现，69% 的失败 rollout 表现为重放源任务或其他演示过的任务轨迹，而非无结构崩溃（仅 4%），证明策略对语言和视觉有响应但任务级动作选择错误。
  • 提供机制层面的诊断证据：通过 prefix-KV 读出实验（34/45 正确恢复已执行任务）和状态替换干预实验（200 次 rollout 全部从源任务转向目标任务方向），证明任务条件化的内部状态直接影响动作选择。
  • 形式化解释泛化失败的来源：从 flow matching 模仿目标的视角说明，当训练数据中同一指令对应的条件动作支撑（conditional action support）过窄时，指令键控（instruction-keyed）解可以在不解析场景的情况下拟合监督数据，构成欠定（underspecification）问题。
  • 提出 ECT 双层训练方法：ECT data（构造同一指令下、场景可区分且动作不同的有效反事实演示对）与 ECT loss（在同一更新步中配对计算两个分支的模仿损失）互补使用；在 LIBERO-PRO 上使 Swap 平均成功率从 36% 提升至 59%。
  • 跨环境验证 ECT 的通用性：在构造的 LIBERO 反事实、自然出现的 CALVIN 替代演示（ECT loss 单独提升五任务完成率从 58% 到 76%）、以及真实 UR5e 机器人固定演示预算（未见位置成功率从 8% 提升至 88%）三种场景下均验证有效。
Card 04 方法描述

方法描述

  • 论文构建了"干扰性 vs 反事实"扰动的分类框架，用 Δₖ（指令键是否改变）和 Δₐ（所需动作是否改变）两个指标区分扰动类型，将指令键控查找模型 π_lookup 与真实 grounded 策略进行对比分析。
  • 行为学诊断：设计定向规则扰动，人工标注失败 rollout 属于"源任务重放"、"其他任务检索"、"混合轨迹"还是"正确跟随"，并验证标注者间一致性（κ=0.78）。
  • 机制诊断：使用 prefix-KV 余弦距离读出已执行任务，并通过替换 prefix-KV 缓存或 backbone 特征序列进行干预，观察动作重定向。
  • ECT 数据构建：采用几何变换（镜像、平移）变换原始场景并重放变换后的末端执行器路径，由 replay 控制器验证动作有效性；关键设计原则是反事实对必须既能区分不同动作，又让场景线索可区分所需动作——仅改变动作而场景无法辨别（如前后镜像）会导致 ID 成功率从 94% 暴跌至 24%。
  • ECT loss：从配对集合 E 中采样匹配的演示对，在同一更新步中求和两个分支的标准模仿损失，两个分支共享 flow matching 噪声样本和时间步长，不引入额外辅助目标。

  • 训练配置：Frozen-LM 微调训练视觉编码器和动作专家，冻结语言模型；对比实验匹配训练步数与 batch size（64 examples/update），每行结果平均 3 个训练种子。
Card 06 评估与结果

评估与结果

  • LIBERO-PRO 诊断结果：在两个架构中，每个套件的干扰性单元（Semantic、Object）成功率均高于每个反事实单元（Swap、Task），Swap 和 Task 比 ID 低至少 42 个百分点；381 个 π₀.₅ rollout 中 69% 为检索式失败、27% 正确或接近正确跟随；GR00T-N1.7 上 73% 检索式行为。
  • 机制干预结果：45 个 Goal 探针中，prefix-KV 读出在 34/45 中首位命中实际执行任务（文本 TF-IDF 仅 22/45）；50 个 Object 任务对 × 4 次 rollout 中，状态注入使 109/200（π₀.₅）和 121/200（GR00T-N1.7）rollout 更接近目标任务物体，对照组均为 0/200，源任务完成率从 200/200 降至 0。
  • ECT 主结果：受控 π₀.₅ Frozen-LM 对比中，ECT 将平均 Swap 成功率从 36% 提至 59%，平均 Task 成功率从 21% 提至 28%；Full-FT 设置下 Swap 提升最高达 +26.2 点。
  • 组件消融：ECT data 贡献大部分 Swap 增益（+10.5 至 +32.8 点），ECT loss 在 Spatial/Goal/Long 上额外增加 2.3–5.2 点；在 CALVIN 上 ECT loss 单独将五任务完成率从 58% 提至 76%。
  • 行为学改善：ECT 后正确/近似跟随比例从 27% 升至 48%，检索式失败从 69% 降至 47%；新 Spatial 目的地下错误完成原放置从 29/30 降至 3/30。
  • 真实机器人结果：实时 UR5e 上 400 演示/主模型，ECT 使未见位置成功率从 3/40 提升至 35/40（8%→88%）。
