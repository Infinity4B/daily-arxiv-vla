EmbodiedEvo: Self-improving Coding Agents for Physical Intelligence

提出 EmbodiedEvo，一个面向物理智能的自改进编码智能体框架，用代码表示可执行、可检查、可修改的物理知识。

02论文概述

  • 提出 EmbodiedEvo，一个面向物理智能的自改进编码智能体框架，用代码表示可执行、可检查、可修改的物理知识。
  • 核心观点为 Code as World 与 Agent as Policy：代码既是世界模型，也是智能体求解任务的工作空间。
  • 解决物理执行中反复失败、经验无法保留和跨场景重用的问题：在单个 Playground 场景进化 Skills 与 Lessons，冻结后供新场景的 Test 智能体使用。

03核心贡献

  • 提出通过 harness evolution 实现物理自改进，将物理交互转化为持久的控制程序与决策指导，同时保持模型权重和机器人接口固定。
  • 设计 Skills + Lessons 经验表示：Skills 是可复用控制过程，Lessons 记录适用条件、失败模式、诊断与恢复经验。
  • 提出 Playground-to-Test 协议：在一个场景获取经验并冻结，让独立智能体在未见布局中只读复用。
  • 证明 获取经验与应用经验是不同能力：未完成任务也可产生有用知识，强模型经验可提升弱执行器。
  • 在 RoboDojo-Sim 上超过所有官方验证结果，并显示比原始交互历史低 53.0% 的执行成本。

04方法描述

  • Code as World：分为 L1 环境原语和 L2 可执行程序；L1 包括任务读取、观察、动作执行和 Playground 重置原语。
  • Agent as Policy：智能体在隔离工作区中编辑 submission/solution.py，通过执行客户端提交代码，并自主决定观察、编程、执行、诊断与修复。
  • Harness Evolution：在 Playground 单场景中持续编辑代码、执行并接收物理反馈，更新 Skills 和 Lessons；Test 阶段冻结且只读。
  • 失败分析驱动设计：Astra 的失败显示需要参数化抓取/放置例程，以及行动前的前置条件检查，分别对应 Skills 与 Lessons。
  • 跨模型复用：冻结的 Skills/Lessons 是显式程序与指导，可直接转移给其他执行器，无需额外 Playground 探索或参数更新。

05数据集与资源

  • 基准：RoboDojo-Sim，包含 12 个 Generalization、8 个 Precision、8 个 Long-Horizon、6 个 Memory、8 个 Open 任务。
  • 评估规模：dev set 每任务 5 个场景（每条件 210 episodes）；full set 每任务 50 个场景（2,100 episodes，一个 seed）。
  • 执行器：GPT-6-Astra（xhigh/medium）、GPT-5.6-sol（xhigh）、GPT-5.6-luna（xhigh）。
  • 输入与预算：任务描述，或任务描述 + 官方 wiki；每个 Playground 链和 Test episode 最多 100 次 accepted code executions。
  • 资源：论文未报告模型参数量、训练 GPU/TPU 或训练细节；实验基于执行器与仿真环境完成。

06评估与结果

  • 指标：Score（0–100） 与 success rate（SR, %），在 RoboDojo-Sim 上评估。
  • 全量结果：EmbodiedEvo 达到 Average Score 44.48、SR 37.82%，超过 October 9, 2026 leaderboard 中所有官方验证结果。
  • 基线对比：比 VPP2 高 5.22 Score、5.56 SR 百分点；比 Simate-beta 高 10.53 Score、9.86 SR 百分点；比 PhysicalRSI 高 8.21 Score、6.44 SR 百分点。
  • 类别表现：Memory 为 71.90 / 69.67%，Open 为 55.52 / 53.00%，明显领先；Precision 仅 13.25% SR，Long-Horizon 为 23.50% SR，精细接触与长程执行仍是瓶颈。
  • 配对提升：无 wiki 时 Score +23.87、SR +21.67 个百分点；有 wiki 时 Score +21.75、SR +21.72 个百分点；仅任务描述时成功率从 8.50% 升至 30.17%。
  • 典型案例：tic-tac-toe 与 stack blocks 的 SR 从 0 到 100%，imitation sorting 从 0 到 80%，conveyor matching 从 60% 到 100%；insert tubes/insert key 有部分 Score 提升但 SR 仍为 0。
  • 跨模型迁移：Astra 的经验使 Sol 和 Luna 的 SR 相比无经验分别提升 8.86 和 5.50 个百分点。
  • 成本：相比原始交互历史，Skills/Lessons 在约 53.0% 更低执行成本下取得可比任务性能。
