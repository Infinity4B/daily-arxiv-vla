Card 02 论文概述

论文概述

Card 03 核心贡献

核心贡献

  • 通过 Grad-CAM 可视化首次明确揭露 VLA 微调中主视图过拟合的现象，验证了模型对纹理等表面统计特征的记忆
  • 提出即插即用的 MaskVLA 微调方法，仅在训练时随机掩蔽主视图，无需改动模型架构
  • 在模拟基准 RoboTwin 2.0 上，MaskVLA 相较 π0 和 OpenVLA-OFT 平均成功率分别提升 23.2% 和 16.8%
  • 在真实 ALOHA 双机臂机器人的四项任务中验证了方法的有效性，尤其提升了长序列任务的表现
Card 04 方法描述

方法描述

  • 基于 OpenVLA-OFT 多视图 VLA 框架，输入包含语言指令、本体感受状态（14 维关节角）及主摄像头、左右腕部摄像头图像
  • 在训练时，对主摄像头图像以概率 ρ（推荐 10%）进行完全零值掩蔽，腕部摄像头保持完整，迫使模型学习利用腕部视图信息
  • 推理时恢复完整多视图输入，模型利用训练获得的平衡多视图特征预测动作序列
  • 创新点在于利用随机掩蔽作为正则化手段，有效缓解预训练（单视图）与微调（多视图）之间的领域偏差，与标准数据增强互补
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：RoboTwin 2.0，包含四个双机臂任务，每个任务 50 条干净演示轨迹用于训练；评估使用 easy（纯白背景）和 hard（随机纹理、光照）两种设定
  • 真实数据集：基于 Airbot Mobile ALOHA 平台采集，每个任务 50 条轨迹
  • 模型规模：基于 OpenVLA-OFT 的预训练权重进行微调，未详述参数量
  • 训练资源：2 块 NVIDIA A100 GPU（每 GPU batch size 4），每个任务微调 30,000 步（约 12 小时）；评估使用 A100 或 RTX 3090
Card 06 评估与结果

评估与结果

  • 评估基准：RoboTwin 2.0 的四个操作任务（Adjust bottle, Open laptop, Put object cabinet, Stack bowls），以及真实世界的四个任务（Feed carrot, Adjust cups, Place orange, Stack bowls）
  • 主要评估指标：任务完成成功率
  • 关键实验结果：

- 在 RoboTwin hard 模式下，MaskVLA（ρ=10%）平均成功率 75.0%，相较 OpenVLA-OFT（55.0%）提升 20.0%，相较 π0（36.0%）提升显著

- 在最具挑战的 Stack bowls hard 任务中，MaskVLA 达到 66.0%，而 OpenVLA-OFT 仅为 6.0%

- 真实世界实验中，MaskVLA 在 Feed carrot 和 Place orange 任务上均取得 85.0% 成功率，在所有任务上均优于 OpenVLA-OFT

- 消融实验确认完整掩蔽主视图（MaskVLA-main-10%）效果最佳，优于 patch 级掩蔽或随机摄像头掩蔽
