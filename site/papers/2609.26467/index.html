RouteRLT: Learning When and Which RL Specialist Should Control a Vision-Language-Action Policy

02论文概述

  • 提出 RouteRLT，一个学习何时及让哪个 RL 专家控制 VLA 策略的路由框架，解决通用 VLA 在接触密集型工业任务的精确关键阶段表现不佳的问题
  • 通过协调冻结的通用 SmolVLA与阶段特定的 RL 专家库，在保持通用行为的同时，仅在精确适应最有价值的阶段应用专家控制
  • 在仿真和真实机器人电缆拾取与插入任务中验证自动路由能力，支持多专家组合和失败恢复

03核心贡献

  • 引入 RouteRLT 控制器路由框架，包含 阶段选择器（phase selector）、路由器稳定器（router stabilizer）和 动作边界管理器（action-boundary manager），实现从通用 VLA 到 RL 专家的无缝切换
  • 框架支持多对象任务和包含多个精确关键阶段的轨迹，能够在多个控制器之间进行所有权决策而非仅在两控制器间切换
  • 在 LIBERO 仿真中将完整任务成功率从 85.00% 提升至 92.22%，在真实机器人插入任务中将成功率从 6.7% 提升至 35.0%，且无需部署时的特权信号

04方法描述

  • 基础模型：使用轻量级 SmolVLA 作为冻结的通用 VLA 骨干网络，提供视觉-语言-动作表示和参考动作块
  • RL 专家：每个专家是针对单个精确关键阶段训练的轻量级 Actor-Critic 策略，输出 C 步动作块，以 VLA 参考动作为条件，并加入时间平滑惩罚和参考偏离惩罚，采用离线到在线训练范式
  • 阶段选择器：基于因果窗口的潜在状态序列（W=2），通过带类平衡的二元交叉熵（单专家）或多类交叉熵（多专家）预测控制器后验概率，仅使用紧凑潜在状态 z_t 作为输入
  • 路由器稳定器：采用三阶段状态机（PRE/ACTIVE/POST），使用不对称进入/退出阈值和停留计数器抑制瞬时切换，确保进入召回率和退出稳定性
  • 动作边界管理器：当控制器所有权改变时立即使未执行的块后缀失效，立即查询传入控制器，确保切换在下一个动作生效而非等待重新规划边界
  • 训练协议：四阶段训练流程——VLA 微调、表示编码器训练、RL 专家离线到在线微调、路由器在特权路由下收集数据后拟合

05数据集与资源

  • 仿真数据集：LIBERO Object 多对象拾取和放置任务（番茄酱、黄油、巧克力布丁）
  • 真实机器人：Trossen Stationary AI 平台（基于 ALOHA），执行电缆拾取和端口插入任务，使用 1mm 间隙的 3D 打印端口
  • 模型规模：基础 SmolVLA 为紧凑型 VLA；RL 专家为轻量级策略，接收紧凑潜在状态 z_t 和机器人本体感觉 q_t
  • 训练资源：专家在线微调使用更新到数据比率 5；仿真使用 60 个保留 episodes 和 300 步时间范围；计算预算适中

06评估与结果

  • 评估环境：LIBERO 仿真（20Hz，300 步时间范围，C_VLA=10, C=5）和 Trossen 真实机器人平台
  • 主要指标：完整任务成功率、拾取成功率、每 1000 步成功率、路由器进入召回率、切换次数
  • 关键实验结果：

- LIBERO 仿真中 RouteRLT 达到 92.22% 完整任务成功率，优于 SmolVLA@10（85.00%）和 Oracle-routed RLT（91.11%），每 1000 步成功率提升 14.3%

- 路由器进入召回率 1.0，中位延迟 0 步，每 episode 平均 2.12 次切换（接近理想的双切换序列）

- 真实机器人上完整轨迹插入成功率从基线 6.7% 提升至 35.0%，自动路由到拾取和插入专家均成功

- 消融实验表明，图像-语言输入比仅图像输入更优，且分阶段专家控制优于全轨迹单一专家
