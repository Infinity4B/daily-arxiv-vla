02论文概述

  • 研究针对视觉-语言-动作（VLA）模型的安全威胁，探索通过有限数量的参数位翻转（bit flips）植入物体触发的后门攻击，且无需重新训练。
  • 核心挑战在于：仅修改少量权重比特，既要使模型在特定触发物体出现时任务失败，又要保持非触发场景（含干扰物体）的正常性能。
  • 论文提出 FlipVLA，一种两阶段 selector–amplifier 方法，利用现有 FC–GELU–FC 结构构造条件性攻击行为。

03核心贡献

  • 首次在 VLA 模型上展示通过有限参数位翻转植入物体触发后门，无需重训练，并保持非触发性能。
  • 提出 FlipVLA：在 FC–GELU–FC 模块内构造 selector（触发依赖响应）和 amplifier（放大扰动），通过通道筛选与离散位搜索实现。
  • 在 OpenVLA-OFT 和 GR00T N1.7 两个模型、四个 LIBERO 套件上实现 90.22%–100% 的攻击成功率，干净任务成功率最多下降 1.5 个百分点。
  • 系统评估了触发物选择性、位置/姿态/尺寸鲁棒性，并通过激活恢复实验追踪扰动传播路径。

04方法描述

  • Selector 构造：在投影器 FC2 层选取一个输出通道，通过位翻转优化其权重，使触发物体对应 token 的 pre-GELU 响应强正，背景 token 响应为负，利用 GELU 衰减背景。
  • Amplifier 构造：固定 selector 后，在与该通道相连的 FC3 权重上执行位翻转，最大化触发样本的动作 MAE，从而放大对动作生成的影响。
  • 离散位搜索：每次迭代评估所有可翻转位（BF16 表示），选择使损失最优的位翻转，逐步累计至预算（默认 60 位 selector + 8 位 amplifier）。
  • 损失设计：selector 使用 log-mean-exp 池化聚合触发 token 响应，对抗背景 token 响应，实现激活分离。

05数据集与资源

  • 数据集：LIBERO 四个子套件（Spatial、Goal、Object、Long），每个任务构建含触发（正）、干扰（负）、干净（对照组）的观察组。
  • 模型：OpenVLA-OFT（基于 Llama 架构，L1 回归动作头）和 GR00T N1.7（流匹配扩散 Transformer）。
