Card 02 论文概述

论文概述

  • 论文提出 ObjDream，一个以对象级理解与未来对象状态预测为核心的 object-centric 视觉-语言-动作（VLA）框架，用于提升机器人操作的泛化能力。
  • 针对的问题是：现有 VLA 模型大多沿用预训练视觉-语言骨干的图像级表示，缺乏细粒度对象理解，导致物体外观、空间布局、背景等分布偏移下鲁棒性下降。
  • 核心思路是显式地分离持久对象身份（identity）与动态对象状态（state），并在训练阶段用动作条件下的未来对象状态作为辅助监督，推理时无需预测未来。
Card 03 核心贡献

核心贡献

  • 提出 ObjDream 框架，引入时空对象编码器（spatio-temporal object encoder），通过独立通道显式表示持久对象身份与动态对象状态，并配合新颖的身份引导路由（identity-guided routing）机制将表示注入 VLM 隐空间。
  • 提出动作条件下的对象级前向动力学模块（object-level forward dynamics module），在训练时预测紧凑的未来对象状态以提供直接的辅助监督，推理阶段无需未来状态预测。
  • 额外建模对象间关系：从对象特征与成对几何关系（pairwise geometry）构建关系 token 与前瞻对象 token，为动作生成提供结构化上下文。
  • 在 LIBERO、LIBERO-Plus、RoboTwin 2.0 及真实机器人任务上验证了跨场景与环境扰动的竞争力。
  • 通过消融实验分析了关键架构组件（对象接口、ObjRel、ObjDyn、因子化注入、身份路由）的各自贡献。
Card 04 方法描述

方法描述

  • VLA 策略建模：输入语言指令、多视角观测、本体状态与对象嵌入，输出动作块；动作分布由流匹配（flow-matching）动作专家参数化，采用 receding-horizon 方式执行。
  • 时空对象编码器：以因果图像窗口与缓存短语集为输入，用 Qwen3-VL-8B 在回合初始化时解析任务相关对象短语，用冻结的 CLIP 文本编码器与 DINOv2 提取语义/视觉参考，用冻结的 SAM2 图像骨干提取空间特征，经空间查询模块与时序编码输出对象槽 $u_{i,t}^{obj}=(e_i^{id}, e_{i,t}^{state}, \nu_{i,t})$。
  • 因子化对象注入：将身份分量与动态状态分量分别投影到 VLM 隐藏空间，拼接为对象 token；注意力键值仍由完整上下文化 token 计算。
  • 关系与前瞻 token：由对象特征池化与相对几何聚合得到关系 token，再由 top-$N_p$（=2）重要槽与关系上下文生成前瞻对象 token，构成对象块并插入多模态前缀与动作生成提示之间。
  • 身份引导路由：用缓存的恒等参考计算余弦匹配分 $b_{pi}^{\ell}$ 与头特定门控 $\eta_p^{\ell,m}$，作为加性偏置调制注意力 logits（式 9），不改变标准键值。
  • 对象级前向动力学：辅助头从有效槽的停止梯度特征预测动作块，构造位置感知动作嵌入与动作条件门控，解码当前状态并并行预测 $H_f$ 步未来几何、可见性与掩码（排除机器人槽位）。
  • 训练目标：编码器预训练损失含掩码、几何、可见性与区域-文本对比损失；VLA 训练使用 $w_{act}\mathcal{L}_{act}+\mathcal{L}_{cur}+\mathcal{L}_{fut}+\mathcal{L}_{prop}+\mathcal{L}_{gate}$，其中对象编码器保持冻结。
  • 三阶段训练流程：预训练对象编码器 → 冻结编码器联合优化 VLM/动作专家/策略侧对象模块 → 冻结 VLM 与对象模块仅精调动作专家。
Card 05 数据集与资源

数据集与资源

  • 评测基准：LIBERO（Spatial、Object、Goal、Long 四个套件）、LIBERO-Plus（7 种受控偏移：相机视角、机器人初始化、物体布局、语言、光照、背景、传感器噪声）、RoboTwin 2.0 固定 8 任务子集（adjust bottle、click bell、grab roller、move can pot、open microwave、place can basket、scan object、turn switch）、以及 4 个真实世界任务。
  • 模型骨干：Qwen3-VL-4B VLM + 层级流匹配动作专家，遵循 StarVLA 训练配方；短语解析使用 Qwen3-VL-8B，另有冻结的 CLIP、DINOv2、SAM2 编码器。
  • GPU 资源：训练使用 8 张 NVIDIA H100，评测时策略推理使用 NVIDIA RTX 4090。
  • 评测协议：每个 LIBERO 任务 50 个回合；LIBERO-Plus 用同一 checkpoint 零样本评测；RoboTwin 2.0 每任务 50 条干净示范训练、100 次 rollout 评测（Easy 与 Hard）。
Card 06 评估与结果

评估与结果

  • LIBERO / LIBERO-Plus：ObjDream 在 LIBERO 取得最高平均成功率 98.6%；在 LIBERO-Plus 上整体排名第二（84.4%），在语言（90.6%）、光照（98.4%）、背景（98.5%）扰动下最优，传感器噪声第二（88.6%）；相机视角与机器人初始化仍是主要挑战。
  • RoboTwin 2.0：Easy 平均成功率 60.25%，Hard 22.75%；相比 StarVLA 分别提升 12.87 和 15.62 个百分点，Hard 设置增益更大，grab roller、open microwave、click bell 改善明显。
  • 消融实验：完整模型在 LIBERO-Long 与 LIBERO-Plus 上分别比骨干基线高 2.0 与 3.2 个百分点；移除因子化注入、身份引导路由、ObjDyn、ObjRel 的 LIBERO-Plus 整体成功率分别降至 82.5%、82.6%、83.2%、84.1%，说明三者提供互补增益。
  • 真实世界实验：在 ID 与 OOD 设置下平均成功率分别为 74% 与 55%；相比 $\pi_{0.5}$ 在 ID 下高 8 个百分点，相比 ControlVLA 在 ID/OOD 下分别高 14 和 24 个百分点；OOD 下在两果放置与桌面清扫任务上领先最佳基线 10 个百分点。
