TacDyn-WAM: Learning Implicit Tactile Dynamics in a Heterogeneous Visuo-Tactile World Action Model

2026-09-30 · 原文 · 翻译 · 2610.00638

本文提出 TacDyn-WAM，一种异构视觉-触觉世界动作模型（Heterogeneous Visuo-Tactile World Action Model），用于预测隐式触觉动力学（implicit tactile dynamics），而非像现有方法那样重建未来触觉像素图像。 核心动机是：现有触觉世界模型复用视频生成管线，在部署分布偏移（deployment drift）下易失效——接触位置或力的微小变化会显著改变触觉像素，但底层接触演化仍可预测；因此应预测动力学感知的表示空间中的接触演化，而非重建像素。 论文同时引入 TacRep（dynamics-aware 触觉表示空间）和 Tactile Understanding Memory（当前触觉状态记忆），并通过分阶段训练（staged training）整合到 InternVLA-A1 基础模型中，在模拟基准 UniVTAC 和五类真实机器人任务上验证了有效性。

Card 03 核心贡献

核心贡献

  • 提出 TacDyn-WAM，一个包含第四个专家（Implicit Tactile Dynamics Expert, ITDE）的异构视觉-触觉世界动作模型，视觉专家与触觉专家使用独立参数和目标空间，通过逐层联合注意力交互。
  • 引入 TacRep 表示空间：基于 V-JEPA 2.1 的掩码时空预测训练，并通过关系结构蒸馏（Relational Structure Distillation）保持局部空间结构，使预测在触觉分布偏移下保持鲁棒。
  • 提出 多视野隐式触觉动力学预测：ITDE 在单次前向传播中同时预测未来触觉表示及其变化（Delta 表示），覆盖多个时间视野（5/15/25 帧），无需迭代去噪。
  • 设计 Tactile Understanding Memory：使用 AnyTouch2 编码器与紧凑注意力池化器，以只读键值（read-only KV）方式向动作专家提供当前触觉状态。
  • 采用 四阶段训练策略（TacRep 训练 → 触觉世界接地 → 触觉-动作对齐 → 联合训练），逐步开放注意力连接，保护预训练专家权重。
Card 04 方法描述

方法描述

  • 基础模型为 InternVLA-A1 3B（混合 Transformer 世界动作模型），包含 Understanding Expert（Qwen3-VL-2B）、Visual Generation Expert（Cosmos tokenizer + 未来视觉 latent 预测）和 Action Expert（flow matching 动作去噪）。
  • TacRep 编码器：从 V-JEPA 2.1 ViT-B 初始化，使用 Tactile Dynamics Prediction（TDP，掩码块预测 EMA 目标特征）与 Relational Structure Distillation（RSD，对齐局部 patch 余弦关系）联合训练；训练后保留 EMA 编码器作为冻结 TacRep Encoder。
  • Implicit Tactile Dynamics Expert（ITDE）：约 0.4B 参数的 28 层 Transformer（hidden size 1024），输入为每传感器 32 个 TacRep 上下文 token 和 3 个视野共 48 个未来查询 token；通过 Future Readout 和 Delta Readout 两个细粒度读出头预测 7×7 未来表示和变化表示；损失采用补丁自适应重加权（patch-adaptive reweighting）。
  • Tactile Understanding Memory：AnyTouch2 编码器提取特征，经紧凑注意力池化器压缩为 10 token/传感器，再通过两层 Q-Former 融合跨传感器信息并接受前缀条件；以只读 KV 形式注入各专家，不参与残差流更新。
  • 异构联合注意力：每个 layer 中各 block（prefix、visual、tactile、action、memory）的 Q/K/V 拼接后执行块间因果掩码注意力；最终阶段中 prefix 只自注意力，visual/tactile 可读 prefix、memory 及彼此，action 可读所有上下文。
  • 分阶段训练：Stage 1 仅训练 TacRep；Stage 2 冻结其他专家只训练 ITDE 及读出；Stage 3 训练记忆和 Action Expert；Stage 4 联合优化所有可训练模块，整体损失为 L_act + λ_vis L_vis + λ_tac L_tac。
Card 05 数据集与资源

数据集与资源

  • 模拟基准：UniVTAC（含 8 个接触丰富的操作任务，GelSight Mini 传感器，每个任务提供独立演示）。
  • 真实世界预训练数据：OmniViTac 子集（约 6,000 条轨迹：2,500 装配、2,000 抓取、1,000 擦拭、500 调整），另加 300 条自采集真实任务演示（每任务 60 条）。
  • 真实机器人平台：Franka Research 3 机械臂 + 并行夹爪 + Xense 视觉触觉传感器（每指一个）+ 腕部相机与第三人称相机。
  • 模型规模：TacDyn-WAM 总参数量约 3.6B（基础模型 3B + ITDE 0.4B + 记忆少量参数）；对比模型 N₀-TWAM 为 7.2B。
  • 训练资源：A100 GPU（用于推理延迟测试，训练资源未详细列出）。
Card 06 评估与结果

评估与结果

  • UniVTAC 模拟基准：TacDyn-WAM 平均成功率 81.5%，仅用每任务演示训练，达到 state-of-the-art 水平；与使用超过 30,000 小时视触觉轨迹预训练的 N₀-VTLA（83.1%）和 N₀-TWAM（84.5%）差距小于 3 个点，且参数量更少（3.6B vs 7.2B）。
  • 对比基线：相比其基础模型 InternVLA-A1 提升 25.7 个点；超过最强纯视觉 VLA StarVLA-α（25.4 点优势）；超过触觉策略 FTP-1（62.9%）18.6 点；强于动作级触觉模型 TacForcing（65.3%）等。
  • 消融实验：去除触觉世界模型（仅留下记忆）平均降至 67.9%；去除触觉记忆降至 71.3%；将 TacRep 替换为 Cosmos VAE（像素重建空间）降至 62.0%；替换为单帧 DINOv2 降至 74.0%，验证了 TacRep 对触觉演化预测的关键作用。
  • 真实世界实验：训练于每个任务 60 条演示时，TacDyn-WAM 平均成功率 71.0%，高于 FTP-1（55.0%）、InternVLA-A1（40.0%）和 LingBot-VA（32.0%）；经 OmniViTac 中等规模预训练后提升至 85.0%，每个任务均有改善。
  • 推理延迟：单块 A100 上，TacDyn-WAM 每个动作平均延迟 9.7 ms（每动作块 484 ms，块长 50），显著低于 LingBot-VA 优化后的 33.5 ms/动作（块长 40），且延迟恒定不随情节历史增长。
