Card 03 核心贡献

核心贡献

  • 提出 VLA-Stem：一种轻量级 RL 安全机制，直接将 VLA 任务意图与运行时安全适应相耦合，无需微调底层 VLA 策略
  • 设计轨迹级引导目标：以 VLA 轨迹作为运动参考，保留空间意图的同时允许灵活的局部运动与时间调整；并引入教师-学生蒸馏框架与课程学习，提升避障偏差后的恢复能力
  • 在仿真和真实世界的多种操作场景中开展大量实验，实现更高的无碰撞任务成功率，且 Stem 策略可直接 sim-to-real 迁移，无需真实世界训练或微调
Card 04 方法描述

方法描述

  • VLA 条件化执行：冻结的 VLA 每隔 h 个控制步生成动作块，转换为末端执行器的相对位姿轨迹作为运动参考；Stem 策略联合条件化于该参考、机器人本体感知（关节位置与末端位姿）和局部障碍物信息（中心坐标与包围盒尺寸）
  • 轨迹级引导：将当前末端位置投影到 VLA 参考轨迹的局部线段上，计算位置与旋转偏差（而非逐步时间对齐），维护非递减的线段索引并限制在前向走廊内匹配，兼顾空间一致性与前进推进，避免逐步修正造成的偏差累积
  • 教师-学生蒸馏：教师在训练时使用特权任务信息（如目标物体位置）以结构化探索；学生通过 RL 损失（PPO）与 KL 蒸馏损失（λ=0.1）联合优化，部署时不依赖特权信息
  • RL 优化与课程学习：使用 PPO，奖励由任务完成、碰撞惩罚和轨迹引导三项组成；三阶段课程依次为：无障碍轨迹跟随 → 静态空间约束 → 动态移动障碍物（含等待时机调整）
Card 05 数据集与资源

数据集与资源

  • 仿真环境：ManiSkill，三个操作任务：PickCube、StackCube 以及自建的 Object Stowing（家庭物品收纳）；每个任务包含 Normal / Static / Dynamic 三种场景，共六个受限仿真设置
  • 基础 VLA：π₀ 与 π₀.₅，每个任务在 100 条演示上微调 30,000 步；VLA-finetune 基线最高使用 1,500 条避障演示
  • 策略网络：教师与学生均采用 MLP actor-critic 网络
  • 训练资源：PPO 使用 256（轨迹跟随）/ 192（静态与动态）并行环境；三阶段训练预算约为 38.0M、23.7M、20.6M 仿真环境转移步/种子，采用 GPU 并行仿真
Card 06 评估与结果

评估与结果

  • 评估指标：SUCC（无碰撞完成任务的比例）与 COLL（发生碰撞或违反约束的比例），每个任务-场景设置评估 3,200 个回合
  • 总体结果：六个受限仿真设置中，VLA-Stem 平均无碰撞任务成功率达 52.8%，而最强安全基线仅 23.7%
  • 无障碍场景保持性：VLA-Stem 在 PickCube、Object Stowing、StackCube 上成功率分别为 0.7325、0.7061、0.7521，均不低于 π₀.₅ 基线（0.7166、0.6138、0.7450），说明引入 Stem 不损害原任务性能
  • 安全-任务权衡：基线 π₀.₅ 在静态/动态障碍下成功率骤降（如 PickCube 从 0.7166 降至 0.0325/0.0131）；VLA-finetune 表现不稳定，微调会干扰精细操作（如抓取失败）；VLSA（CBF 安全层）虽降低碰撞率但任务成功率低（如 PickCube-Static 上 VLSA-ARM 的 SUCC 仅 0.1516 vs. VLA-Stem 的 0.5219）
  • 消融实验：移除 VLA 参考输入后学生策略 SUCC 归零，验证参考条件的必要性；轨迹干预实验（向左/右/上扰动 VLA 参考 15–20cm）显示 97.8% 的执行轨迹更接近修改后的参考（D_mod 平均 0.230 vs. D_ori 0.894），证明 Stem 执行确实跟随 VLA 空间参考
  • 真实世界评估：在 Object Stowing 和 Stacking 任务上，静态与动态障碍下均实现一致的碰撞减少，Stem 策略无需真实世界训练即可直接迁移
