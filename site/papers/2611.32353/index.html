02论文概述

  • 提出 Any2Act，一个面向机器人上下文学习（in-context learning）的基础模型，可以从单个演示中执行未见过任务，无需任务特定微调。
  • 解决机器人上下文学习的三个关键挑战：大规模监督、异构演示来源、可泛化的演示跟随能力。
  • 核心思想是将任何来源的演示统一映射到执行机器人（executor）的相机布局与动作空间，即统一具身基础表示，从而解耦“学习跟随”与“接纳新演示源”。

03核心贡献

  • 提出 Any2Act 基础模型，在 1.2M 条真实轨迹（10K 小时，10K 任务） 上预训练，实现无需微调的机器人上下文学习。
  • 提出 统一具身基础表示 与 源路由适配器（source-routed adapters），支持仿真、人类视频、UMI、其他机器人等异构演示，新增源只需约 200 对数据 且保持预训练模型冻结。
  • 提出 免训练进度跟踪器（training-free progress tracker），基于 DINOv3 特征和动态时间规整定位演示进度，支持长时程窗口和失败回退（rollback）恢复机制。
  • 实验表明：单演示下未见过任务成功率达 57.5%，超过用每任务 50 条演示微调的 VLA；异构演示保留执行器自身演示成功率的 74–91%。

04方法描述

  • 采用世界动作模型（World Action Model）架构，基于预训练视频模型 Cosmos-Predict2，结合轻量动作专家（action expert）联合预测未来帧和动作块。
  • 演示被表示为稀疏多视角视觉 token 和密集状态 token，与当前观测、本体感知历史和语言指令共同输入模型。
  • 翻译模块将不同演示源映射为执行器的头部视角、双腕视角和动作空间；源路由适配器以低秩残差分支仅作用于演示 token，保持基座模型冻结。
  • 进度跟踪器只截取执行器当前进度附近的短演示窗口，训练时对锚点加扰动和时间伸缩，部署时用单调动态规划求解锚点，并支持失败回退。

05数据集与资源

  • 预训练语料：1.2M 条真实机器人轨迹，约 10K 小时，覆盖 10K 个任务，来自例程遥操作数据收集，经 VLM 过滤和任务分组。
  • 新源适配数据：每个新源使用 200 对配对轨迹（来自 20 个不重叠任务）训练源路由适配器；跨本体机器人额外增加 embodiment adapter。
  • 评估平台：真实世界使用 Galbot G1 双臂移动机器人（头部相机+两个腕部相机）；仿真评测使用 RoboTwin 2.0。
  • 模型规模：论文未明确披露总参数量；以 Cosmos-Predict2 为视觉主干，动作专家为轻量级结构；推理在单个 H200 GPU 上生成 2 秒 30 Hz 动作块耗时 180 ms。

06评估与结果

  • 真实世界“任务泛化”基准：Any2Act 零微调平均成功率 57.5%，超过微调 50 条演示/任务的 π0.5（43.0%） 和 GR00T N1.7（47.5%）；对比上下文策略 HOST 与 Zero-WAM 分别仅 15.7% 和 19.7%。
  • 真实世界“技能扩展”基准：Any2Act 经每任务 20 条演示适配后达 72.7%，高于微调 50 条演示的 VLA 最高 47.5%。
  • 仿真 RoboTwin 2.0：Any2Act 平均 53.1%，高于 Zero-WAM（47.0%） 和语言条件模型 WAN-Action（11.0%）。
  • 数据规模消融：预训练从 400h 增至 10K h，任务泛化率由 13.3% 提升到 57.5%；去掉演示腕视图、状态 token、回退机制或整个演示均导致显著性能下降。
  • 异构演示评估：仿真、人类视频、UMI、其他机器人演示经源路由适配器后，保留执行器自身演示成功率的 74–91%，其中仿真和人类视频效果最佳。
