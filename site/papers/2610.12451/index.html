02论文概述

  • 针对Vision-Language-Action (VLA) 模型对训练时固定相机配置（相机数量、位姿）高度敏感、部署时易因相机变化而性能骤降的问题，提出相机可配置框架 VersaCamVLA。
  • 核心思路：将相机集合表示学习与动作学习解耦，学习一个统一的场景 token 接口，把任意数量、任意位姿的 RGB 视图映射为固定大小的场景 token，从而让策略面对不同相机配置时仍保持稳定。
  • 在 RoboTwin 2.0、LIBERO 和真实机器人平台上验证，VersaCamVLA 在相机数量变化和未见相机位姿下均显著优于先前 VLA 方法与直接多视图基线。

03核心贡献

  • 形式化相机可配置 VLA 策略学习问题：要求策略在可变数量、非固定位姿的 RGB 视图下运行，同时下游动作策略仍接收固定大小的视觉表征。
  • 提出 VersaCamVLA 两阶段框架：阶段一通过多信号目标视图预测（RGB、语义、边缘）学习统一场景 token 接口；阶段二将场景 token 作为补充视觉条件注入预训练 VLA。
  • 提出 Wrist-Augmented Pose Sampling (WAPS)，利用腕部相机在机器人运动中的自然位姿变化作为免费的数据多样性来源，无需额外采集多姿态演示。
  • 在仿真和真实机器人上验证，VersaCamVLA 在相机数量变化和未见位姿下均优于直接多视图拼接等基线方法。

04方法描述

  • 场景编码器：将每个输入视图的 RGB patch 与 Plücker 射线嵌入 patch 拼接投影，与可学习场景 token 一起经 Transformer 编码，得到与输入相机数量无关的固定大小场景 token。
  • 场景解码器（仅训练阶段使用）：用目标视图的射线 token 查询场景 token，通过自注意力解码并预测目标视图的 RGB、语义图和边缘图，多信号监督促使 token 保持视图一致的空间结构信息。
  • WAPS：训练时对静态相机随机采样 1 到 N 个视图，腕部相机以 0.5 概率独立加入源相机集合，目标集合为全部相机；同一场景 token 同时承担自重建和跨视图预测，提升相机配置覆盖度。
  • 策略学习：丢弃解码器、冻结场景编码器，用轻量卷积空间编码器 $g_{\eta}$ 压缩场景 token 为紧凑表征，作为预训练 VLA π_0.5 的补充视觉条件，以 flow-matching 动作回归损失联合优化。
  • 部署时仅需 RGB 图像和相机内外参，不需新视图渲染、深度估计、点云处理或显式 3D 重建。

05数据集与资源

  • 仿真数据集：RoboTwin 2.0（双臂操作，含 Clean 与 Domain-Randomized 设置）、LIBERO（单臂操作，四个套件：Spatial/Goal/Object/Long）。
  • 真实机器人平台：包含 PickCube、StackCube、Insert Test Tube 等操作任务。
  • 基座模型：预训练 VLA π_0.5，场景编码器/解码器与空间编码器为轻量模块；正文未给出具体参数量与训练 GPU 资源。

06评估与结果

  • 评估基准：RoboTwin 2.0、LIBERO 四个套件、真实机器人任务；主要指标为任务成功率（%）。
  • RoboTwin 2.0：VersaCamVLA 平均成功率 52.56%（Clean）、23.00%（DR），显著高于 π_0.5 的 35.88%/21.63% 以及 ACT、DP、DP3、OpenVLA-OFT 等基线。
  • LIBERO：VersaCamVLA 平均成功率 95.9%，优于 OpenVLA-OFT（94.5%）和 π_0.5（95.8%）。
  • 相机位姿鲁棒性：RoboTwin 2.0 未见位姿下成功率 52.63% vs π_0.5 的 32.88%；真实机器人未见位姿下 58.33% vs 13.33%。
  • 相机数量灵活性：在 RoboTwin 2.0 上，VersaCamVLA 在 3/4/5/6 视角下成功率分别为 52.56%/53.44%/53.13%/55.63%，而 π_0.5 仅支持 3/4 视角且性能大幅下滑。
