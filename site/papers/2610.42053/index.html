Card 03 核心贡献

核心贡献

  • 提出 REA 三级运行时，为 Agent、VLA 和程序化策略提供统一契约，在三个模拟器（LIBERO-Pro、BEHAVIOR-1K、RoboTwin 2.0）与真实机器人（Unitree G1、AlohaMini2）上完成验证
  • 设计具体化路由器（System 1），包含路由记忆（route memory）、边界触发的判断门（boundary-triggered judge gate）和共享预算升级阶梯（escalation ladder），在不阻断执行的前提下协调大脑与快速策略
  • 通过超过 30,000 个对齐测试 episode 验证路由与判断机制的独立贡献，并在 RoboTwin 2.0 中对比了 VLA 策略与混合 VLA+代码策略池在同一运行时下的表现
  • 证明路由记忆在调度上可替代在线 Agent，且无阻塞的异步协调比阻塞式 advisor 或 Agent 直接控制策略更低延迟、更高成功率
Card 04 方法描述

方法描述

  • 三层次结构：System 2（大脑）离线生成策略或在线提供判断与建议；System 0（小脑）运行冻结程序或 VLA 策略，以原生速率执行并在段或策略边界返回控制权；System 1（路由器）负责所有控制流决策
  • 路由记忆：在开发集上预估每个策略的成功率和平均步数，测试时直接查表选择最优策略，使调度脱离大脑推理路径
  • 边界触发的判断门：仅在策略返回时调用 System 2 视觉判断器，若判定 done 则终止并保护已完成工作，若 not_done 则沿升级阶梯继续，避免异常重触发和静默失败漏检
  • 共享预算升级阶梯：从当前状态启动下一个策略，所有运行与大脑调用共享同一步数/时间预算，确保一个 episode 不超过单策略预算
  • 统一评估协议：在相同任务-种子对、初始状态语义、时间与步数预算、策略代码共享的前提下，对不同方法进行对齐比较

Card 06 评估与结果

评估与结果

  • LIBERO-Pro 全量评估（60 tasks × 50 seeds）：REA 达到 95.9% 成功率，超过最强单方法基线 Agents SDK + GPT-6（94.7%），控制步数减少 25%，控制时间减少 17%；路由记忆与 Agent 调度成功率相同但延迟更低
  • RoboTwin 2.0（100 场景 VLA/代码研究）：REA（VLA 策略）84%，REA（VLA+代码）86%，对比最佳单 VLA MEDex 的 80%；混合池在随机场景下从 40/50 提升至 42/50
  • 策略改进：REA 将 ASPIRE Fix 策略提升 +8.6%（66.3%→74.9%），将零样本 GPT-6 策略提升 +7.0%（19.3%→26.3%）
  • 转移实验：在 BEHAVIOR-1K 上解决 27/50 个 episode（对比 Agents SDK 25/50）；在真实 Unitree G1 上成功 8/10 次；在 AlohaMini2 块放置上成功 10/10 次
  • 消融实验：路由记忆+判断门共同贡献；仅用异常门控比判断门低 15.3%；盲重试无显著提升；将大脑放入控制循环（Show-Harness）仅解决 2.6% 的 LIBERO-Pro episode
