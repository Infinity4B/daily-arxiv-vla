Card 02 论文概述

论文概述

  • 提出 Robota-Embed，据称是首个统一视觉–语言–动作（VLA）嵌入模型，在查询端和候选端同时联合编码视觉、语言和原生动作三种模态，用于物理经验检索。
  • 解决机器人上下文检索中"任务相似但执行阶段不同"的问题：检索不仅需匹配任务，还需匹配当前执行阶段与应跟随的后续动作。
  • 通过 Embed2ICL 和 Embed2Evolve 两个下游应用，验证该共享检索空间可同时支持机器人上下文学习与任务局部上下文演化。
Card 03 核心贡献

核心贡献

  • 提出 Robota-Embed：统一嵌入模型，在检索的两个端点（当前状态查询与记录的后续片段）联合编码视觉、语言和原生动作，实现预测性物理经验检索。
  • 构建多源训练语料库与 Robota-Embed-Bench 基准，并开展时序精度、表示学习和原生动作贡献的受控研究。
  • 提出 Embed2ICL：训练无关（DreamZero 视觉缓存初始化）与训练式（Fast-WAM Context Tokens）两种接口，将检索到的示范转化为有效的策略上下文。
  • 提出 Embed2Evolve：在冻结策略（GPT-6 Astra）周围进行嵌入引导的记忆与上下文演化，在匹配比较下提升成功率并显著降低 token 消耗。
Card 04 方法描述

方法描述

  • 以 Cosmos3-Edge 4B 为基座模型，查询与目标共享 Transformer、视频 tokenizer 和 head，使用独立的适配器 A_q、A_k。
  • 使用源特定的投影器 P_di 将不同来源的原生动作格式映射到主干网络，每个端点输出一个归一化向量，通过余弦相似度排序候选。
  • 训练目标由三部分组成：预测对齐 L_align（双向 InfoNCE，精确后续片段为正样本，任务/物体/动作冲突为负样本）、多模态 grounding 与判别 L_ground、表示正则化 L_reg。
  • 关键创新：原生动作不仅作为检索内容，还进入检索键本身，使运动信息直接参与相似度比较；支持人类、模拟与真实机器人经验的跨源检索。
Card 05 数据集与资源

数据集与资源

  • 训练语料：1,695,684 个过滤后的当前–未来配对，来源于 EgoDex、DROID、LIBERO、RoboMIND–Franka-dual 四个数据源。
  • 评测基准 Robota-Embed-Bench：4,000 条查询对共享的 8,000 条目 gallery，包含 4 个来源各 1,000 查询、1,000 配对后续片段和 1,000 近邻同回合片段。
  • 基座模型规模：Cosmos3-Edge 4B；对比基线包括 CLIP ViT-L/14、Perception Encoder B16、InternVideo2、Qwen3-VL-Embedding-2B、VLM2Vec-V2、WeMM-Embedding-2B、Omni-Embed-Nemotron-3B、Gemini Embedding 2 等。
  • 效率测试在单张 NVIDIA A100 上进行（含 1M 到 15M 索引扩展实验）；下游使用 DreamZero、Fast-WAM、GPT-6 Astra 等策略。
Card 06 评估与结果

评估与结果

  • 检索性能：Robota-Embed 在 Robota-Embed-Bench 上达到 47.33% clip-level R@1 和 81.77% episode-level R@1，超过无动作的 Gemini Embedding 2 达 22.09 和 33.47 个百分点。
  • 模态消融：在 DROID 匹配设置下，加入动作使 clip-level R@1 从 59.8% 提升到 78.7%；去掉动作训练下降 18.9 个百分点，而去掉视觉仅下降 1.9 个百分点，说明执行信息是检索键的核心组成。
  • 索引扩展：gallery 从 1M 扩展到 15M 时，查询编码加检索延迟从 160.36 ms 增至 195.17 ms，Top-10 搜索单独耗时 37.47 ms。
  • Embed2ICL：DROID-Sim 成功率从 47.0% 提升到 56.3%；LIBERO 困难子集从 86.4% 提升到 92.8%；真实机器人（YAM 的 Banana→Bowl）任务进度从 21.67 提升到 40.00。
  • Embed2Evolve：五个 ManiSkill 任务平均成功率达 68%，相比 GPT-6 Astra Direct 的 24% 和 Omni-Embed-Nemotron-3B 演化基线的 33%；相比后者每测试 rollout 大约减少 79.5% 的策略 token。
