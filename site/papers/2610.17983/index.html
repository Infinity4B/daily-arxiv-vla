02论文概述

  • 论文关注 Vision-Language-Action（VLA）模型（以 π0.5 为代表）在机器人操作中的分布收敛（distributional convergence） 问题：策略因训练数据中的模式平均（mode averaging）而退化为“安全但次优”的均值行为。
  • 作者将这类行为命名为 Convergent Defaults（收敛默认行为），例如无论遮挡情况一律采用俯视抓取、在货架内抓取时撞到架顶、开柜门时用直线拉拽而非弧线轨迹。
  • 目标是在不更新任何模型参数（no fine-tuning） 的前提下，识别并纠正这些默认行为，把范式从“提示工程”转向“分布塑形（distribution shaping）”。

03核心贡献

  • 提出 Diagnostic Lens Framework（诊断透镜框架），一个无需微调即可重塑 VLA 动作分布的三阶段流水线。
  • 形式化定义 Convergent Default 为动作空间中的高密度、低方差但任务表现次优的区域，并给出探测方法。
  • 提出利用 VLA 的潜在推理与语言化能力进行 Diagnostic Root Cause Analysis，让模型自行“调试”并说出次优动作背后的隐含假设。
  • 提出 Lens Prompts（透镜提示） 作为可复用的结构化干预模块，包含负约束、正向替代方案、推理锚点三要素。
  • 将通用反馈式自我修正（如 Reflexion）与结构化引导区分开，论证后者在根因层面对先验分布进行干预更有效。

04方法描述

  • 总体目标：将策略 π(aₜ\|sₜ, l) 改造为受塑形的 π(aₜ\|sₜ, l, 𝒢_lens)，且不修改权重。
  • 阶段一：探测收敛默认（Probing for Defaults）：用零样本指令 l_base 探测 π0.5，将采样动作的众数定义为默认行为 a_default，观察物理约束与统计先验冲突处的系统性失败。
  • 阶段二：诊断式根因分析（Diagnostic Root Cause Analysis）：冻结视觉上下文，用诊断查询 𝒫_diag 让模型从“动作生成”转向“状态解释”，输出推理轨迹 r_latent，区分失败源于感知幻觉还是启发式偏置。
  • 阶段三：结构化引导注入（Structured Guidance / "Lens"）：构造 𝒢_lens，包含（1）Negative Constraint 显式禁止已识别的默认行为；（2）Positive Alternative 提供几何上明确不同的替代行为；（3）Reasoning Anchor 用阶段二得到的物理逻辑为替代方案提供依据。
  • 核心机制：Lens 作为刚性上下文修改器，改变 flow matching 模型的条件变量，把概率质量从默认模式 𝒟 移向包含最优解的长尾区域。

05数据集与资源

  • 仿真环境：ManiSkill3（基于 SAPIEN 的高保真物理与真实感渲染仿真器），用于测试 VLA 感知能力。
