$Δ$ Flow Matching for Robot Foundation Models

2026-10-11 · 原文 · 翻译 · 2610.15794

论文提出 Δ-flow matching（简称 Δ-flow），针对机器人基础模型（VLA 与 WAM）的流匹配生成范式，将生成源从固定的高斯先验改为由近期历史（已执行动作、当前视觉表征）加轻度噪声构成的源分布。 核心问题是：当前 VLA（生成动作块）与世界-动作模型 WAM（额外生成未来视觉状态）均从固定高斯噪声出发，导致训练收敛慢、推理需多步迭代采样（NFE 高），WAM 因双分支（视觉+动作）代价更被放大。 研究目标是缩短"历史→未来"的传输路径，使网络只学习残差 Δ，从而同时提升训练效率、单步推理速度与分布偏移下的泛化性。

Card 02 论文概述

论文概述

  • 论文提出 Δ-flow matching（简称 Δ-flow），针对机器人基础模型（VLA 与 WAM）的流匹配生成范式，将生成源从固定的高斯先验改为由近期历史（已执行动作、当前视觉表征）加轻度噪声构成的源分布。
  • 核心问题是：当前 VLA（生成动作块）与世界-动作模型 WAM（额外生成未来视觉状态）均从固定高斯噪声出发，导致训练收敛慢、推理需多步迭代采样（NFE 高），WAM 因双分支（视觉+动作）代价更被放大。
  • 研究目标是缩短"历史→未来"的传输路径，使网络只学习残差 Δ，从而同时提升训练效率、单步推理速度与分布偏移下的泛化性。
Card 03 核心贡献

核心贡献

  • 提出统一的 Δ-flow 历史源流匹配公式：源由历史表征加噪声扰动构成（s_m = α_m h_m + σ_m b_m ⊙ ε_m），对动作与视觉两个模态同时适用，仅改变流的源而不改动网络架构或引入额外数据。
  • 将 Δ-flow 无缝集成到三类机器人基础模型：VLA 策略 π0.5、WAM 策略 ImageWAM 与 Fast-WAM，其中 WAM 的两个分支联合训练、推理时单步同时预测未来视觉表征与动作。
  • 大幅提升训练效率：ImageWAM 1 个 epoch 达 90%+ 成功率（原模型需 6 个 epoch），Fast-WAM 2 个 epoch 达 95%+（原模型需 8 个 epoch），π0.5 LoRA 微调下 1 个 epoch 即超过基线 5 个 epoch 的水平。
  • 实现高效且平滑的推理：单步采样在 π0.5 / ImageWAM / Fast-WAM 上分别带来 1.54× / 2.49× / 4.45× 加速，相比单步高斯采样在 ImageWAM 上减少 4.5× 的动作 jerk（平滑度接近十步高斯采样）。
  • 在 LIBERO-Plus 上取得 88.55% 的 SOTA 泛化成功率（跨七类扰动，无需大规模机器人训练数据）。
  • 发现免训练源适配能力：直接替换预训练 WAM 推理时的高斯动作源为动作历史源，无需重训练即可单步采样，成功率基本保持甚至略有提升。
  • 提供一系列反直觉的经验性设计结论（动作表示、未来帧密度、stop-gradient、动作流匹配必要性等），对策略设计具有普适参考价值。
Card 04 方法描述

方法描述

  • 对模态 m ∈ {a, v}（动作/视觉）采样成对的"历史-未来"表示 (h_m, y_m, c_t)；动作历史为最近 H 步已执行动作 A_t^hist，视觉历史为编码后按未来目标潜布局排列的观测表征 h_v = P_v(E_v(o_≤t))。
  • 历史源构造：s_m = α_m h_m + σ_m b_m ⊙ ε_m，其中 α_m、σ_m 控制历史与噪声尺度，b_m 为维度掩码；动作设置 α_a = 1、σ_a = 0.5，噪声掩码排除夹爪与填充维度；视觉源采用 50% 图像潜先验 s_v = (h_v + ε_v)/√2。
  • 关键创新：与 A2A 流匹配直接传输干净历史不同，本文对历史施加噪声扰动，保留目标分布的多模态性与鲁棒性；同时在动作空间而非学习潜空间操作，可直接插入现有策略。
  • 训练目标：流匹配损失 L_FM^m = E[‖f_θm(y_m^τ, τ, c_t^m) − (s_m − y_m)‖²]，并引入端点一致性损失 L_EC^m（从 τ=1 做一次 Euler 更新后与真值的 L1 距离）直接监督单步生成。
  • WAM 双分支耦合：视觉分支提供当前与未来视觉 token 的中间表征 R_t^τv 作为动作条件，但在此连接处使用 stop-gradient，使动作损失梯度不回传更新世界模型；总损失 L_WAM = λ_v(L_FM^v + λ_EC^v L_EC^v) + λ_a(L_FM^a + λ_EC^a L_EC^a)。
  • 推理：单次 Euler 更新 Â_t = s_a − f_θa(s_a, 1, c_t)，视觉端点无需解码即可供动作分支使用。
  • 训练效率提升的理论解释：高斯源将目标与无关噪声配对，要求速度场陡峭（Lipschitz 常数大）；历史源将每个目标与其自身历史配对，仅需拟合小幅平滑偏移。
Card 05 数据集与资源

数据集与资源

  • LIBERO：使用 Spatial、Object、Goal、Long 四个任务套件评估任务成功率（LIBERO Overall 汇总四套件）。
  • LIBERO-Plus：用于零额外微调的泛化评估，包含七类扰动——相机视角、机器人初始位姿、语言指令、光照、背景纹理、传感器噪声、物体布局。
  • ImageWAM：FLUX.2-klein-base-4B 图像编辑骨干 + 动作 DiT；视觉目标为未来第 16 帧编码图像，动作历史为过去 16 步已执行动作；权重 λ_a=1、λ_v=0.5、λ_EC^a=λ_EC^v=0.5。
  • Fast-WAM：Wan2.2-TI2V-5B 视频骨干 + 动作 DiT；采用稀疏联合配置（Sparse8，r=8 预测 4 帧未来帧，与密集配置 r=4 预测 8 帧对比）；编码 {t−32, t−24, t−16, t−8, t} 帧，动作历史为过去 32 步；权重 λ_a=λ_v=1、λ_EC^a=λ_EC^v=0.5。
  • π0.5：保留 PaliGemma 视觉-语言骨干与 Gemma 动作专家，仅对动作分支应用 Δ-flow，λ_EC^a=0.5，无视觉生成分支；支持全参数微调与 LoRA 微调。

Card 06 评估与结果

评估与结果

  • 评估环境：在 LIBERO 与 LIBERO-Plus 上评测三个策略（ImageWAM、Fast-WAM、π0.5），均与其原始高斯源版本在相同硬件和匹配评估设置下对比；另设相同 Sparse8 布局、联合注意力架构与采样预算的高斯稀疏联合基线（Fast-WAM-joint Gaussian）。
  • 主要指标：任务成功率（%）、训练效率（达到目标成功率所需 epoch 数）、推理延迟/加速比、动作 jerk（动作连续性/平滑度）、未来图像 PSNR。
  • 训练效率：ImageWAM 一个 epoch 达 91.30%（原模型 24.60%，+66.70 个百分点），首次超过 90% 的 epoch 数由 6 降至 1（6× 缩减）；Fast-WAM 一个 epoch 达 72.60%（高斯稀疏联合基线 42.55%），2 个 epoch 达 95.65%，而基线需 8 个 epoch（4× 缩减）。
  • π0.5 结果：全参数微调 2 个 epoch 即至少 95%，峰值 99.30%；LoRA 微调 1 个 epoch 达 92.20%，超过基线十步采样 5 个 epoch 的 91.30%（5× 缩减）；LIBERO Overall 达 99.00%（Spatial 99.60、Object 100.00、Goal 99.60、Long 96.80），优于原 π0.5 的 97.10%。
  • 推理加速：单步采样在 π0.5 / ImageWAM / Fast-WAM 上分别获得 1.54× / 2.49× / 4.45× 加速；Fast-WAM 上较十步高斯稀疏联合推理快 4.45× 且 LIBERO-Plus 成功率更高。
  • 动作平滑性：ImageWAM 上单步 Δ-flow 相比单步高斯采样实现 4.5× 的 jerk 降低，平滑度与十步高斯采样相当。
  • 泛化性能：LIBERO-Plus 七个扰动类别上平均 88.55%，达到 SOTA；推理时移除显式未来预测会损害分布偏移下的性能。
  • 免训练源适配：冻结预训练 ImageWAM 与 Fast-WAM，仅替换动作源初始化，即可用单步采样基本保持任务成功率并略有提升。
  • 消融与设计研究：(1) 动作空间参数化在标准 LIBERO 上差异极小，但在 LIBERO-Plus 上可带来 14 个百分点以上差异；(2) 在相同时间跨度下预测更少的未来帧反而提升控制性能（LIBERO-Plus 提升 5.19 个百分点）；(3) stop-gradient 同时改善未来图像 PSNR 与 LIBERO-Plus 成功率，说明特征共享与梯度耦合应作为独立设计决策；(4) 源为历史先验且保留视觉监督时，仅监督动作分支的单步端点即可接近完整流匹配目标（但收敛更慢）。
