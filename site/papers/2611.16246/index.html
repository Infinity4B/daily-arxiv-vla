What Can a VLA Learn from the Agent That Calls It? Task-Level Experience Distillation for Embodied Navigation

02论文概述

  • 论文研究导航智能体中 大语言模型（LLM）规划器 与 视觉-语言-动作模型（VLA） 的分工协作问题：规划器调用 VLA 完成每一步导航，但测试阶段仍需持续调用 LLM，带来高昂的 token 成本和时间延迟
  • 提出 任务级经验蒸馏方法 H2E（Task-Level Experience Distillation），将 LLM 智能体在训练场景中成功完成任务的经验蒸馏到其调用的 VLA 中，使 VLA 在测试时脱离 LLM 独立导航
  • 解决 agent 会话数据难以直接用于 VLA 训练的挑战：会话中包含规划器工具动作、子指令以及绕路等噪声，不能直接作为 VLA 的演示数据

03核心贡献

  • 蒸馏对象创新：首次将前沿 LLM 导航智能体的成功经验蒸馏到其调用的 VLA 中，而不是蒸馏规划器，使 VLA 在测试时独立运行，无需 LLM
  • 提出 H2E 方法：包含三条规则——① 任务级标签（将每次运动都标注为原始指令下的 VLA 动作，无论动作执行者）；② 进度掩码（屏蔽远离目标的步骤损失）；③ 停止标签（将目标 1 米内的状态标记为停止）。并从理论上证明 L1 损失 配合停止规则能教会 VLA 精确停止
  • 显著性能提升：在 REVERIE-CE val-unseen 全部 3189 个 episode 上，将 8B NavGPT VLA 的成功率从 35.0% 提升至 44.9%（+9.9 个百分点），且优于 geodesic adaptation 基线
  • 成本效率验证：蒸馏后的 VLA 以零 LLM token 和约四分之一的时间达到高于完整 LLM 智能体的成功率

04方法描述

  • 数据采集：在训练场景上运行 LLM 智能体（规划器为 gpt-6-astra，VLA 为 8B NavGPT），保留成功到达目标的会话，共获得 2395 个会话，覆盖 57 个场景
  • 三条转换规则：

- ① 任务级标签：将每个步骤的下一组 8 个位姿作为标签，使用原始任务指令，忽略动作来源（VLA 或规划器工具）和子指令

- ② 进度掩码：对远离目标的步骤（满足 \(d(p_{t+K}) \le d(p_t) + 0.25\) 或接近目标的状态）设置掩码 \(m_t=1\)，这些步骤不参与损失计算但保留在历史中

- ③ 停止标签：将目标 1 米半径内的所有访问状态标记为停止（\(y_t = \mathbf{0}\)），比成功判定的 3 米更严格，使停止位置更准确

  • 训练目标：混合三类数据源——agent 会话（权重 0.60）、DART 噪声的 geodesic 专家数据（权重 0.25）、R2R-CE 路径跟随数据（权重 0.15），使用掩码 L1 损失 进行回归训练
  • 参数高效微调：使用 LoRA（rank \(r=16\)，scale \(\alpha=32\)），仅训练 LoRA 适配器和动作头部，视觉编码器与 LLM 主体保持冻结；LoRA 权重可合并回原模型，测试时无额外开销
  • 部署：蒸馏后的 VLA 独立运行，不再调用 LLM；每步时间仅为 VLA 推理时间，且能更快停止，进一步缩短 episode 长度

05数据集与资源

  • 基准环境：REVERIE-CE 基准，基于 Habitat 仿真器，使用 MP3D（Matterport3D） 场景
  • 训练数据：2395 个 agent 会话（来自 57 个训练场景），共 332,405 个标记步骤；另混入 DART geodesic 专家数据和 R2R-CE 路径跟随数据
  • 开发集：100 个 episode，来自 26 个额外场景
  • 验证集：REVERIE-CE val-unseen 全部 3189 个 episode，来自 10 个未见场景
  • 模型规模：基础 VLA 为 8B 参数的 NavGPT 视频 VLA，输入 4 路 RGB 视图，预测 8 个航点
  • 训练资源：4 块 NVIDIA L40 GPU，数据并行；训练 9000 次更新，约 28 小时
  • 优化设置：LoRA 学习率 \(10^{-4}\)，头部学习率 \(2\times10^{-5}\)，warm-up 540 步后余弦调度，梯度裁剪 norm 1

06评估与结果

  • 评估指标：成功率（SR）、oracle 成功率（OSR）、路径加权成功率（SPL）、导航误差（NE）
  • 主要结果：

- H2E 将 VLA 的 SR 从 35.0% 提高到 44.9%（+9.9 点），95% 置信区间跨场景增益为 3.9 到 16.3 点

- Geodesic adaptation 仅用 DART + R2R 数据无增益（SR 34.9%），证明 agent 会话是关键

- 仅用 504 个会话 训练，H2E 即可达到 43.2% SR，远超 geodesic adaptation 的 34.9%

- LoRA rank 16 在 861 个 episode 子集上达到 45.6% SR，rank 64 仅为 33.2%，小适配器足够吸收经验

- H2E 同时将 SPL 提升 11.9 点，NE 降低 1.6 米

  • 与完整 LLM 智能体对比（100 个 episode，26 个场景）：LLM 智能体 SR 53%，时间 423 秒，70k tokens；H2E 蒸馏后的 VLA 在无 LLM tokens、时间约四分之一的情况下达到 更高的成功率（超过 53%）
  • 技能分析：蒸馏 VLA 学会两项关键技能——① 在目标处正确停止（基础 VLA 常走过目标区域后停在区域外）；② 找到基础 VLA 从未到达过的新目标。在按起始距离划分的长距离 episode 子集上，H2E 领先优势从短距离的 4.4 点扩大到长距离的 17.5 点
