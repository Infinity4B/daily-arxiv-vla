La-JEPA: Compact Robot Policies with Latent World Modeling

02论文概述

  • 论文提出 Latent Action JEPA (La-JEPA)，一种紧凑的世界-动作模型，用于机器人控制
  • 核心问题是：机器人策略是否必须继承生成式骨干网络的架构，以及从头训练的紧凑 Transformer 能否达到同等性能
  • La-JEPA 在预训练 V-JEPA 2.1 编码器的特征空间中训练策略 Transformer，训练时联合预测未来特征与动作，推理时仅生成动作

03核心贡献

  • 提出 La-JEPA，首个从头训练于预训练 JEPA 特征空间的紧凑世界-动作模型，将策略架构与生成式骨干解耦
  • 在 RoboTwin 2.0 的 clean 和 randomized 场景以及 LIBERO-Plus（修正指令）上，在无具身预训练策略中达到最高成功率
  • 相比 Fast-WAM 等基线，参数量大幅减少，推理速度提升最高 5 倍
  • 通过设计研究证明 JEPA 特征优于视频 VAE 潜在变量，尤其在分布外场景；并验证未来预测监督对策略的增益
  • 发现并修正 LIBERO-Plus 指令泄漏问题，重新评估多个开源基线
  • 在四个真实机器人任务上取得与具身预训练模型 π0.5 相当的平均成功率

04方法描述

  • 视觉表示使用预训练 V-JEPA 2.1 ViT-L 编码器，对每路相机分别提取上下文特征和未来目标特征，无需 RGB 重建
  • 语言指令由冻结的 FLAN-T5-large 编码，本体感受通过可学习投影映射为 token；两类信息作为条件序列
  • 策略主体由两个从头初始化的 Diffusion Transformer（World DiT 和 Action DiT）组成，通过旋转位置编码保持时空信息
  • 训练使用联合 Flow Matching，对动作块和未来特征分别采样噪声，同时预测速度场；推理时丢弃未来 token，仅对动作去噪
  • 注意力掩码确保动作 token 无法直接访问未来特征，未来预测仅通过共享 World DiT 参数影响动作通路
  • 鲁棒性设计包括：相机 dropout、本体感受 dropout、图像增强、编码器 LoRA 微调，以及 token 减少和时间编码策略（tube-motion）

05数据集与资源

  • 仿真基准：LIBERO、LIBERO-Plus、RoboTwin 2.0
  • 真实机器人任务：方块放置、水果拾取、Push T、餐具摆放
  • 模型规模：La-JEPA S/B/L 三种尺寸，可训练参数分别为 0.10B / 0.34B / 1.14B；部署参数（含冻结编码器）约为 0.74B–1.82B
  • 冻结视觉编码器：V-JEPA 2.1 ViT-L；冻结语言编码器：FLAN-T5-large
  • 训练资源：单个消费级 GPU 进行推理延迟测试；训练在 LIBERO、RoboTwin 等目标演示数据上进行

06评估与结果

  • 在 LIBERO-Plus 修正指令下，La-JEPA L 达到 88.0% 成功率，超过所有重新评估的无具身预训练基线；使用发布指令时为 84.1%
  • 在 RoboTwin 2.0 clean 场景中 La-JEPA B 达到 86.2%，randomized 场景达到 35.4%，平均 60.8%
  • 与 JEPA-WAM、LeapBot-WA 等潜在世界-动作模型相比，La-JEPA 在 LIBERO-Plus 和 RoboTwin 2.0 上均表现更优
  • 推理延迟：La-JEPA 约 25.16 ms，明显快于 Fast-WAM（88.09 ms）和 Faster-WAM（50.96 ms）
  • 真实机器人平均成功率：La-JEPA 17.50/20，与具身预训练的 π0.5（17.25/20）相当，且高于 Fast-WAM 和 Faster-WAM
  • 在 Push T 等接触密集型任务中，La-JEPA 取得最高成功率（15/20）
