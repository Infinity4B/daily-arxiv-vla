GeoVLDrive: Geometry-Grounded Vision-Language Reasoning for Autonomous Driving

02论文概述

  • 提出 GeoVLDrive，一种面向自动驾驶的几何基视觉-语言-动作（VLA）框架，用于 3D 时空推理与规划
  • 解决现有 VLA 规划器虽继承语义知识、但推理缺乏 3D 场景结构及未来演变基础的问题
  • 通过结构化潜在思维链连接未来场景几何、关键智能体运动与元动作，并联合生成和评分轨迹提案

03核心贡献

  • 提出 GeoVLDrive 框架，用结构化潜在 CoT 连接未来场景几何、关键智能体运动与元动作，在相同动作专家架构下将 NAVSIM v1 PDMS 从 90.1 提升至 91.8
  • 设计 动作专家，基于潜在 CoT 和多深度场景特征联合生成与评分轨迹提案；专用评分 token 交换候选间信息，较 MLP 评分提升 PDMS 1.6
  • 构建 NAVSIM 3DQA 数据集，包含约 1.28M 框条件问答对，覆盖对象类别、米制位置、车辆尺寸和运动行为；几何基骨干总体精度 89.2%，比微调 Qwen3-VL-2B 基线高 4.6 个百分点
  • 开发 NAVSIM-WM-CoT 注释，为未来深度、关键智能体运动和元动作提供监督，并支持文本 CoT 训练

04方法描述

  • 几何基视觉-语言骨干：使用 Qwen3-VL-2B-Instruct 与冻结的 StreamVGGT，在多个深度进行门控交叉注意力注入（GCAI），并使用共享 2D 正弦位置编码对齐语义与几何特征
  • 结构化潜在 CoT：将未来场景几何、关键智能体运动和元动作组织为三个分别监督的潜在状态组；注意力掩码允许运动状态读取几何状态、元动作读取两者，并阻断反向连接
  • 未来场景几何预测：使用 32 个潜在 token 对每个预测时步进行残差更新，解码未来深度图和置信度图，并通过深度回归、置信度加权回归和多尺度梯度一致性损失监督
  • 关键智能体运动与元动作：关键智能体 latent 编码类别、当前位置和未来位置偏移；元动作 token 表示纵向与横向意图，分别由分类和回归损失监督
  • 动作专家：专用 transformer 结合潜在推理状态、ego 状态、动作 token 和评分 token，执行多深度联合注意力；轨迹采用 winner-takes-all 回归，评分 token 进行跨提案交互并由模拟轨迹分数监督
  • 训练目标：联合轨迹回归、潜在链监督、文本 CoT 交叉熵、评分 BCE 及辅助智能体/元动作损失进行训练

05数据集与资源

  • NAVSIM v1/v2：规划评估基准；训练使用 navtrain，评估使用 navtest 的 12,146 个场景
  • NAVSIM 3DQA：从 NAVSIM 注释构建，约 1.28M QA 对，来自 95K 锚定帧，训练集 1.12M，验证集 165K
  • LingoQA：驾驶视觉问答数据集，用于 Lingo-Judge 精度评估
  • NAVSIM-WM-CoT：为未来场景几何、关键智能体运动、元动作和文本 CoT 提供注释和监督
  • 模型规模：视觉-语言骨干为 Qwen3-VL-2B-Instruct，几何编码器为冻结的 StreamVGGT，推理过程使用单前视相机和 ego 状态，不依赖 LiDAR
  • 训练资源：使用 NVIDIA H20 GPU，分四阶段训练：QA 对齐 3 epoch、未来几何/运动 5 epoch、潜在链 10 epoch、链与动作专家联合 30 epoch

06评估与结果

  • NAVSIM v1：在 navtest 上达到 91.8 PDMS，超过 SGDrive（SFT）87.4、CoWorld-VLA 90.0、DriveWorld-VLA 91.3、RL 训练的 LaST-VLA-2B 91.1、iPad 91.7 和 GeoWorldAD 91.0
  • NAVSIM v2：达到 90.9 EPDMS，在 Ego Progress 上达到 91.4，优于 PerceptDrive 90.2 和 GeoWorldAD 90.4
  • NAVSIM 3DQA：总体精度 89.2%，其中类别 98.0%、运动 91.0%、位置 76.7%、尺寸 89.1%；微调 Qwen3-VL-2B 基线总体为 84.6%
  • LingoQA：Lingo-Judge 精度 68.6%，相比微调 Qwen3-VL-2B 基线 67.0% 有适度提升
  • 消融结果：几何注入和空间对齐提升 3DQA 表现；潜在 CoT 与几何注入将 PDMS 从 90.1 提升至 91.8；交叉提案评分设计较 MLP 评分提升 1.6 PDMS
