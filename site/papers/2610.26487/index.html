SPAR: Structural Pruning and Action Recovery for Vision-Language-Action Models

02论文概述

  • 提出 SPAR（Structural Pruning and Action Recovery），用于压缩视觉-语言-动作（VLA）模型的 LLM 主干，降低机器人端侧推理成本。
  • 核心问题：激进压缩会严重损害操作性能，仅靠监督微调难以恢复；需要在压缩后通过强化学习恢复策略能力。
  • 在 π₀.₅ 上，SPAR 将语言主干从 2.34B 压缩到 0.09B，完整模型从 3.37B 压缩到 1.12B，并在 LIBERO 上获得 93.45% 平均成功率。

03核心贡献

  • 提出 双维度结构化剪枝框架：对隐藏维度和 FFN 中间维度分别设置保留目标，联合学习通道掩码。
  • 设计 正则化掩码学习目标：包含计数惩罚、熵正则和离散性正则，促进接近二值的通道选择。
  • 给出 维度敏感性分析：仅剪枝中间维度能保持较高任务成功率，进一步剪枝隐藏维度会带来较大性能损失，但可被 RL 显著恢复。
  • 验证 剪枝后 RL 恢复策略：使用 PPO 和稀疏成功奖励，在压缩策略上平均提升 8.90 个百分点。
  • 实现 1.98× 全策略推理加速，并展示压缩后模型在 LIBERO-Plus 上的鲁棒性表现。

04方法描述

  • 基于 pruning-aware tuning（PAT），在监督微调中联合学习隐藏维度和 FFN 中间维度的通道掩码。
  • 使用 soft-to-hard sigmoid 掩码调度：温度从 1 线性增加到 10，逐步锐化掩码，最后二值化并物理删除非活跃通道。
  • 损失函数为监督损失加三项正则：计数惩罚逼近目标通道数、熵正则和离散性正则推动掩码接近 0/1。
  • 物理剪枝后对紧凑模型进行监督微调，再用 PPO 和 RLinf 做并行模拟交互；策略以稀疏二元奖励（成功为 1，否则为 0）优化动作专家和价值头，冻结剪枝后的 LLM 骨干。

05数据集与资源

  • LIBERO 四个套件：Spatial、Object、Goal、Long，用于任务成功率评估。
  • LIBERO-Plus：用于评估相机、机器人、语言、光照、背景、噪声、布局七类扰动下的鲁棒性。
  • 基座模型为 π₀.₅：原始参数 3.37B（其中 LLM 2.34B）；压缩后总参数 1.12B（LLM 0.09B）。
  • 推理加速在 Jetson AGX Orin 上使用 TensorRT 测量；RL 训练基于 RLinf。
  • 论文还包含真实机器人评估（Real-Robot Evaluation）；训练所用 GPU 细节在可见原文中未明确披露。

06评估与结果

  • 评估基准：LIBERO 和 LIBERO-Plus。
  • 主要指标：任务成功率（Spatial/Object/Goal/Long 平均）、推理加速比、剪枝比例、鲁棒性得分。
  • 关键结果：在 10%/10% 保留率 下，SPAR 达到 1.12B 总参数 / 0.09B LLM，平均成功率 93.45%，相比 PAT-only 的 84.55% 提升 +8.90 个百分点。
  • 未剪枝 baseline 为 96.80%，压缩后经 RL 恢复仍接近原模型性能；同时获得 1.98× 推理加速。
  • 在 LIBERO-Plus 上，压缩模型在多种扰动下经过 RL 后表现出明显的鲁棒性恢复。
