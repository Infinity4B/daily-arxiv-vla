NarrativeFlow: Flow-Based Vision-Language-Action Model Using Robot Velocity Fields

01研究单位

  • Keio University, Japan（日本庆应义塾大学）
  • 作者：Shota Kobayashi、Koki Seno、Daichi Yashima、Komei Sugiura

02论文概述

  • 论文聚焦于语言条件化的基于流（flow-based）的机器人操作任务，即模型根据指令和初始图像生成"机器人流"（robot velocity field），再据此执行物体操作。
  • 现有方法（如 Im2Flow2Act）用稀疏关键点位移粗糙地近似机器人流，且难以处理语言条件化设置；而 Flow as Flow 虽能建模稠密速度场，却不支持语言指令。
  • 为此，论文提出 NarrativeFlow，在流匹配（flow matching）框架下将机器人流建模为连续概率速度场，并通过辅助损失增强模型对任务相关场景变化的理解。

03核心贡献

  • 提出 NarrativeFlow：一种语言条件化的机器人流生成方法，采用流匹配框架将机器人流建模为概率速度场，实现高质量、物理一致性更强的流生成。
  • 引入 Narrative Delta Loss：一种辅助训练目标，将模型中间表示与任务相关的场景变化文本表示（narrative representations）对齐，提升模型对任务相关语义的捕捉能力。
  • 提出两个 subtask tokens：分别用于条件化 Flow-as-Flow 模块和计算 Narrative Delta Loss，缓解两个下游目标之间的学习信号干扰。
  • 在 Fractal 和 Bridge V2 标准数据集上，NarrativeFlow 在 ADE、FDE、LTDR 指标上全面超越 FLIP 和 Im2Flow2Act 基线方法，差异具有统计显著性（p<0.01）。
  • 在真实世界实验中，NarrativeFlow 在多种移动操作任务上取得比基线更高的成功率，且与使用真值流的 oracle 方法差距更小。

04方法描述

  • 模型由视觉-语言融合编码器和Flow-as-Flow 模块两部分组成。
  • 语言和图像分别使用 Qwen3-Embedding-0.6B 和 DINOv3-ViT-B/16 编码，并通过 Transformer 编码器融合。
  • 两个可学习的 subtask tokens 与视觉、语言嵌入拼接后输入 Transformer，输出分别用于条件化流生成和计算辅助损失。
  • Narrative Delta Loss 离线构造：用多模态大语言模型 Qwen3.5-9B 对初始图像与目标图像生成多段（Nc=5）任务相关场景变化描述，嵌入后作为辅助监督信号。
  • Flow-as-Flow 模块基于 Diffusion Transformer (DiT) 架构，采用 adaLN-Zero 调制，接收历史点轨迹序列和条件向量，预测稠密速度场，通过积分得到未来点位置。
  • 总体损失为 L = L_FaF + λ·L_ND，其中 L_FaF 为条件流匹配损失，λ 在前 30k 步为 0.1，之后降为 1.0×10⁻⁵。

05数据集与资源

  • 使用 Fractal（Google Robot 平台）和 Bridge V2（WidowX 平台）两个标准真实机器人数据集。
  • Fractal：训练集 84,212 样本、验证集 1,000、测试集 2,000；Bridge V2：训练集 57,064、验证集 1,000、测试集 2,000。
  • 点轨迹使用 CoTracker3 提取，端点分割掩码使用微调后的 Robot-SAM 生成。
  • 模型参数量约 487M；训练使用单张 GeForce RTX 5090（32GB 显存），训练约 6 小时，推理约 62ms。

06评估与结果

  • 评估指标：ADE（平均位移误差，主指标）、FDE（最终位移误差）、LTDR（小于阈值比率），仅在端效应器区域计算。
  • 在 Fractal 测试集上：NarrativeFlow 的 ADE=21.68、FDE=31.59、LTDR=76.29%，优于最优基线 Im2Flow2Act（ADE=37.14、FDE=47.74、LTDR=60.61%）。
  • 在 Bridge V2 测试集上：NarrativeFlow 的 ADE=30.59、FDE=42.42、LTDR=66.30%，优于最优基线（ADE=50.73、FDE=68.43、LTDR=47.72%）。
  • 消融实验表明：移除 subtask tokens 或 Narrative Delta Loss 均导致 ADE 明显下降（2.6~4.2 分），验证了各组件有效性。
  • 真实世界实验使用 Toyota Human Support Robot (HSR) 在三个移动操作任务上评估：Mobile drawer closing、Mobile bin picking、Mobile cup stacking；NarrativeFlow 平均成功率 55%，优于 Im2Flow2Act（42%）和 FLIP（28%），且与 oracle（63%）的差距仅 8 个百分点（基线差距为 21 个百分点）。
