Looking Back to Move Forward: Temporal Verification for Generative Robot Policies

2026-09-30 · 原文 · 翻译 · 2609.39038

论文提出TeV (Temporal Verification) 框架，用于增强基于 flow-matching 的视觉-语言-动作（VLA）生成式机器人策略。 现有动作验证方法存在时间短视问题：仅基于当前观测评估候选动作，忽略跨 chunk 的轨迹连续性，且需要大模型验证器或额外专家标注，训练和部署成本高。 TeV 通过学习时间 token 来压缩最近的观测-动作历史，训练轻量级能量验证器对候选动作进行排序，并利用能量梯度指导生成过程，实现更平滑、更连贯的机器人控制。

Card 02 论文概述

论文概述

  • 论文提出TeV (Temporal Verification) 框架，用于增强基于 flow-matching 的视觉-语言-动作（VLA）生成式机器人策略。

Card 03 核心贡献

核心贡献

  • 提出时间 token 机制，将最近观测-动作历史编码为紧凑表示，使验证器能够评估候选动作作为执行轨迹的延续而非孤立预测。
  • 设计对比式能量验证器训练框架，利用专家 chunk 作为正样本，构造时间错配负样本和粗积分负样本，无需额外专家演示或偏好标注。
  • 首次将候选排序与生成时引导集成于同一动作验证框架：能量函数不仅用于事后排名，还通过梯度引导中间 flow 样本向低能量区域移动。
  • 作为轻量级附加模块，参数量增加小于 0.15%，验证器仅需离线模仿数据即可训练，显著降低部署开销。
  • 在仿真和真实世界实验中验证了 TeV 能提升任务成功率（6–18 个百分点）并产生更平滑的执行轨迹。
Card 04 方法描述

方法描述

  • 时间 token 学习：从预训练 VLM 骨干提取观测 token，投影后与前一时刻执行动作拼接，通过因果时序 Transformer 生成时间 token，并用未来动作预测损失作为动力学感知正则化。
  • 对比验证器训练：以专家动作 chunk 为正样本，构造两类负样本——① 时间错配负样本（同一 episode 中时间距离 ≥ δ 的专家 chunk）；② 粗积分负样本（用更少 Euler 步数从策略采样的低质量 chunk）。使用边际排序损失训练能量模型。
  • 验证作为引导：在 flow matching 的 Euler 更新中加入能量梯度项，通过线性衰减的引导强度 η_s 在生成早期施加较强引导，后期恢复原策略细化；最终选择能量最低的候选 chunk 执行。
  • 创新点在于将能量模型同时用于生成时导向与事后验证，形成“引导 + 排序”的双重机制。
Card 05 数据集与资源

数据集与资源

  • 仿真环境：LIBERO-Plus（LIBERO10 suite，2,519 个任务实例，7 种扰动类型）和 RoboTwin 2.0（7 个操作任务，每任务 50 条演示，100 次独立评估）。
  • 真实世界任务：Bottle to Bag、Cup Transport、Water Filling，共收集 180 条轨迹用于训练。
  • 基础策略：使用 π_0.5 预训练 VLA 骨干和检查点。

Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO-Plus 与 RoboTwin 2.0 仿真，以及真实机器人操作任务的任务完成分数（分步计分，30 次试验）。
  • 基线方法：Random selection、Temporal Ensembling (TE)、Bidirectional Decoding (BID)、TACO/TACO*、V-GPS、LPB、DynaGuide、FOREWARN。
  • 关键结果：

- LIBERO-Plus 平均成功率 79.8%，超过最强基线 TACO（76.0%）3.8%；在 Language、Noise、Layout 等扰动下均取得最优或次优。

- RoboTwin 2.0 平均成功率 81.3%，较基线提升 6.4%，尤其 Press Stapler 从 44.0% 提升至 54.0%。

- 真实世界任务中，TeV 在三个任务上的完成分数均显著优于基线和 TACO/BID，且产生更平滑的运动曲线，降低抖动和水溅失败。

- 消融实验显示：仅验证可稳定提升性能；引导在候选集质量差时提供额外增益；两种负样本族互补；候选数量 M=4 时效果最好；学习的时间 token 显著优于零向量、随机向量和冻结 token。

- 能量评分可靠性分析：验证器选中的候选在 >70% 情况下属于与专家行为最近的两个候选之一。
