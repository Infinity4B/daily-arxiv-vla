EffectWAM: Learning Action-Grounded Effects for Robot Manipulation

02论文概述

  • 论文提出 EffectWAM，一种面向机器人操作的世界-动作模型，通过预测动作引起的视觉变化来增强闭环控制。
  • 核心要解决的问题：现有世界-动作模型在预测未来视频时推理延迟高，且视觉预测目标未能保留对操作控制关键的小幅变化（如夹爪开合、末端位姿变化）。
  • 论文通过将视觉变化表示为紧凑的 Effect 表示，并与动作块联合预测，在不引入视频合成延迟的前提下提升操作性能。

03核心贡献

  • Effect：紧凑的视觉变化预测：将未来观测相对共享的当前观测锚点表示为差异序列，并与可执行动作块联合预测；同一 Effect-动作对可用于按需生成未来视频，实现控制与视觉预测的解耦。
  • CaPE：相机姿态感知的视觉转换编码：在端点池化中引入相对相机位姿条件，区分相机运动与场景变化；校准与未校准轨迹共享相同的池化参数，支持异构数据联合学习。
  • Action Grounding：基于测量运动的监督：从 Effect 特征中回归末端执行器和夹爪状态的变化，使视觉表示保留与机器人控制相关的运动信息；在多个基线策略上验证了该监督目标的通用性。
  • 构建了大规模异构训练数据（超过 20,000 小时），支持多种机器人本体、动作表示和相机配置，并提出了两种模型配置（Small (8B) 和 Large (26B)）。

04方法描述

  • Effect 表示：使用独立编码的当前观测和未来观测特征，通过径向映射和差分构造有界的 Effect 端点表示。
  • 相机姿态感知池化（CaPE）：将相对相机位姿变换注入注意力键向量，使池化过程感知视角变化。
  • Action Grounding 与 EMA 目标：在线分支通过辅助头回归末端执行器和夹爪状态变化；指数滑动平均（EMA）分支提供稳定的 Effect 预测目标。
  • 共享生成与训练目标：采用双模式生成架构（联合 Effect-动作模式和视频生成模式），通过流匹配（flow matching）联合优化速度预测损失，并引入中间对齐损失和观测一致性损失。
  • 闭环推理与按需视频生成：推理时联合采样 Effect 序列和动作块，控制器可直接执行动作而无需等待视频合成；视频生成仅按需触发。

05数据集与资源

  • 预训练数据：25,292.8 小时（去除未使用的链式思考数据后），涵盖 34 个多源具身交互数据集，包括 Builddotai Egocentric-10K、HY-Embodied-0.5、HiFi-UMI-2K、ABC-130K、DROID 等。
  • 模型配置：Small (8B) 包含 VLM 2.2B、Video DiT 5.0B、Action DiT 1.2B；Large (26B) 包含 VLM 8.3B、Video DiT 16.4B、Action DiT 2.0B。
  • 训练资源：论文未明确说明 GPU/TPU 类型，但强调使用超过 20,000 小时的异构具身数据进行预训练。

06评估与结果

  • 评估基准：LIBERO、LIBERO-Plus、RoboTwin 2.0、RoboCasa365、RoboDojo。
  • 主要评估指标：任务成功率（%）、部分信用任务分数（partial-credit task score）。
  • 关键实验结果：

- LIBERO 标准任务：EffectWAM Small 总体成功率 99.20%，超过 InternW0-Δ 的 99.00%。

- LIBERO-Plus 分布偏移：EffectWAM Small 总体成功率 93.10%，高于 InternW0-Δ 的 92.8%，在七个扰动类别中六项超过 91%。

- RoboTwin 2.0 双机械臂操作：Clean 条件下 91.82%，Randomized 条件下 74.22%，平均 83.02%，均超过 InternW0-Δ。

- RoboCasa365 组合泛化：总体成功率 49.27%，Composite-Unseen 提升 2.08 个百分点，显示对未知任务组合的泛化优势。

- RoboDojo 能力分析：Small 配置总体成功率 27.87%，Memory 能力达到 55.00%；Large 配置三项种子平均结果更高。
