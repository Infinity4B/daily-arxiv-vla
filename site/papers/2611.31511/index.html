Near-Zero Forgetting Is Not Enough: Out-of-Distribution Robustness in Continual Learning of Pretrained VLAs

02论文概述

  • 研究预训练视觉-语言-动作模型（VLA）在持续学习中的分布外鲁棒性，重点检验“近零遗忘”是否在域偏移场景下同样成立。
  • 通过复现 Pi0 在 LIBERO 四套基准上的经验回放持续学习范式，并在 LIBERO-Plus 的七类扰动下重新评估，揭示 ID 近零遗忘与 OOD 严重遗忘并存的现象。
  • 利用表示分析（CKA、MMD、线性探针）进一步定位 OOD 性能崩溃的表示层面原因，提出出现象的解释：OOD 特征保留信息但发生失准。

03核心贡献

  • 首次系统地在持续学习 VLA 的框架下解耦 ID 稳定性 与 OOD 稳健性，证明 ID 近零遗忘并不保证 OOD 泛化。
  • 发现 OOD 遗忘模式在不同扰动类别之间高度一致，表现为共享的行为模式与表示漂移结构。
  • 通过 CKA、MMD 和线性探针分析，表明漂移集中于 多模态表示和动作专家层，视觉编码器相对稳定；OOD 特征虽保留任务相关信息但线性读出失准。
  • 扩展了 VLA 在持续学习中的评估维度，提出用 LIBERO-Plus 的 OOD 视角重新审视近零遗忘结论。

04方法描述

  • 采用 Pi0（PaliGemma VLM 骨干 + 流匹配动作专家）进行经验回放持续微调：每任务回放缓冲 1000 帧，当前任务与回放样本 1:1 混合，使用 LoRA（VLM r=16, 动作专家 r=32）。
  • 在 LIBERO 四套序列任务上训练，保存每个任务后的检查点，构成评估矩阵 C(k,i,p) 用于追踪跨检查点、跨任务、跨域的成败率。
  • 使用 LIBERO-Plus 的七类扰动（背景纹理、机器人初始状态、相机视角、物体布局、光照、指令改写、传感器噪声）作为 OOD 评估集，与 ID 集配对比较。
  • 表示分析：提取视觉编码器、多模态（VLM 输出）和第一流匹配步骤的动作特征；用 Linear CKA 衡量表示漂移，MMD 测量 ID–OOD 分布差异，线性探针 R² 评估信息可读性。

05数据集与资源

  • ID 数据集：LIBERO 四套官方的 Spatial、Object、Goal、LIBERO-10，每套包含 10 个顺序任务。
  • OOD 数据集：LIBERO-Plus 对 LIBERO 任务施加七类扰动，每类对应一个 OOD 评估域。
  • 模型：Pi0 预训练 VLA（PaliGemma VLM 骨干 + 流匹配动作专家），未明确报告总参数量。
  • 训练与评估硬件：主要使用 NVIDIA A100-SXM4-80GB GPU；部分评估与表示分析使用 RTX 3090。
  • 超参数：AdamW（β₁=0.9, β₂=0.95, wd=1e-10）、余弦学习率（峰值 2.5e-5，结束 2.5e-6）、每任务 10,000 步、批量大小 8。

06评估与结果

  • ID 性能：四套 LIBERO 的 NBT 接近零或为负（Spatial +0.026，Object -0.005，Goal -0.017，LIBERO-10 -0.036），确认 ID 近零遗忘。
  • OOD 性能：LIBERO-Plus 上 OOD NBT 大幅上升（Spatial +0.40，Object +0.48，Goal +0.42，LIBERO-10 +0.16），OOD 成功率在 1–2 个后续任务后普遍塌缩至 0。
  • 行为模式：Spatial 和 Object 套件中，OOD 存活单元格在七类扰动间 Pearson 相关极高（均值 r=0.73/0.82），表明失败结构共享。
  • 表示漂移：CKA 显示视觉编码器漂移最小（ID–OOD 差距 ≤0.02），多模态漂移中等，动作专家漂移最大；MMD 的跨扰动相关性为 0.67–0.77，CKA 相关性 0.64–0.84。
  • 线性探针：ID→OOD 迁移读出的 R² 最差（端到端位置 96.6% 单元格、物体位置 92.9% 单元格为三者最低），而 OOD-CV 部分恢复，支持“信息保留但失准”的解释。
