ACCRUE: Continual Off-Policy Reinforcement Learning for Robot Foundation Models

02论文概述

  • 提出 ACCRUE（Actor–Critic Carryover for continual off-policy Reinforcement learning Using retained Experience），一个面向机器人基础模型（RFMs）的持续离策略强化学习框架。
  • 解决的问题：真实部署中的机器人需要按顺序持续学习新任务（如接触密集的装配任务），既要高效学习新任务，又要保留旧任务能力；已有持续 RL 方法受限于在线策略更新（前向迁移弱）或仅关注单任务样本效率（无学习者跨任务持久化）。
  • 目标：在不牺牲既有能力的前提下，减少每个新任务所需的交互量，实现「加速新任务学习 + 近零遗忘」。

03核心贡献

  • 提出跨任务继承轻量级 actor 与 critic 的持续离策略 RL 框架，使后续任务能摊销并复用先前 RL 阶段获得的行为与价值知识。
  • 设计非对称更新机制：继承的 critic 仅在当前任务转移上适配并指导当前任务 actor；旧任务行为则通过对缓存目标的 actor 蒸馏来保留（使用每个已完成任务保留的最后 N 个 episode）。
  • 采用固定外部视觉编码器保证继承学习器与其回放缓冲跨基础策略更新保持一致，并使用参考动作条件化让轻量学习器仅对当前基础策略的提案做局部精炼。
  • 在仿真与真机硬件上验证，覆盖 VLA 与 WAM 基础策略、多种离策略 RL 算法，实现显著的加速与保留效果。

04方法描述

  • 基础策略接口：$\pi_{\text{base}}$（VLA 或 WAM）在每个阶段用累计演示 $\mathcal{D}^{1:k}$ 微调得到 $\pi_{\text{base}}^k$，随后在该阶段 RL 中保持冻结；策略仅通过输入输出接口（多视角图像、本体感知、语言指令 → H 步动作块）访问。
  • Actor–Critic 输入：状态 $s_t=(E(\mathbf{I}_t),\mathbf{q}_t)$，其中 $E$ 为冻结的现成视觉编码器（仿真中使用 DINOv3），保证回放缓冲中存储的视觉特征跨阶段表示一致。
  • 参考动作条件化：actor 与 critic 同时以基础策略产生的参考动作块 $\tilde{\mathbf{a}}_t$ 为条件，学习任务级提案上的局部精炼；训练时使用参考动作 dropout 防止 actor 直接复制参考。
  • 动作块 RL：actor 输出 H 步动作块，critic 以整块动作评估价值，采用 H 步自举（chunk-level backup），将信用分配路径缩短 H 倍。
  • 当前任务离策略 RL：在 $\mathcal{B}^k$ 上使用离策略时序差分学习；actor 目标最大化 critic 价值并加 $\beta$ 惩罚偏离参考动作；critic 使用分类回报分布 + 交叉熵损失（稀疏奖励下更稳定）。
  • 持续运行（Continual Operation）：每阶段从上一阶段检查点初始化 $(\theta^{k-1}, \psi^{k-1})$；缓存上一阶段 actor 在保留样本上的确定性输出作为蒸馏目标，教师副本在缓存后丢弃。
  • 关键设计：critic 的 TD 更新与 actor 的 RL 目标仅用于当前任务缓冲 $\mathcal{B}^k$；旧任务缓冲 $\mathcal{B}^{<k}$ 仅用于 actor 蒸馏（权重 $\lambda$），避免有限回放下不可靠的价值估计导致旧行为漂移。

05数据集与资源

  • 仿真基准：AutoMate（4 条五阶段插拔装配序列）与 FORGE（3 个接触密集任务：pegged insert、gear mesh、nut thread，组成三阶段序列），均基于 Isaac Lab。
  • 真实机器人：DROID 硬件平台；NIST Assembly Task Board（三阶段插入序列）与真机 AutoMate（五阶段 3D 打印件装配）。
  • 基础策略：GR00T N1.7（VLA），每阶段全量微调（AutoMate 用 1 条演示训 1000 步；FORGE 中 gear meshing / nut threading / peg insertion 分别用 10 / 20 / 50 条演示训 2000 步）。
  • RL 算法与超参：FastSAC，动作块长度 H=16，冻结 DINOv3 特征；每阶段保留 50（AutoMate）/ 100（FORGE）条 episode；$\gamma=0.997$；仿真 $\beta=0.1$、真机 $\beta=10.0$；$\lambda=1.0$（NIST）或 $0.1$（真机 AutoMate）。
  • 计算规模：每阶段 64 个并行环境、500K 环境步预算，每 50K 步评估一次；演示量 1–50 条轨迹，保留回放每任务 20–100 episode。
  • 注：所提供文本未明确给出具体 GPU/TPU 型号与数量。

06评估与结果

  • 评估环境：仿真（AutoMate 聚合 4 条资产序列×4 种子；FORGE 聚合 4 种任务顺序×4 种子）、真机 DROID 两段多阶段序列。
  • 评估指标：前向迁移 FWT（↑）、负向后向迁移 NBT（↓）、持续 AUC（↑）、最终准确率 ACC_final（↑）、最终遗忘 F_final（↓）。
  • 对比基线：Sequential、ER、EWC、RETAIN、Simple Recipe、Single-task RL、Isolated（特权参考，每任务单独存储）。
  • FORGE 结果：ACCRUE 取得 NBT 0.065、FWT 0.823、AUC 0.869、ACC_final 0.917、F_final 0.068，均为共享 actor–critic 方法中最优。
  • AutoMate 结果：ACCRUE 取得 NBT 0.047、FWT 0.848、AUC 0.858、ACC_final 0.863、F_final 0.054，同样领先。
  • 整体提升：相较最强的离策略持续基线，持续 AUC 提升最多 21.0%，NBT 降低最多 70.0%。
  • 真机结果：两段多阶段真机序列上，后续任务的机器人 RL 交互时间减少 31.0%–68.5%，同时旧任务平均成功率约 97%。
  • 消融分析：critic 继承支撑前向迁移；将当前任务 RL 与旧任务 actor 保留分离可在有限回放下改善保持；移除参考动作条件化会在相近最终成功率下增加遗忘。
