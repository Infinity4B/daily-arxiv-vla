02论文概述

  • 论文聚焦于World Action Models（WAMs，世界动作模型）在机器人操作中的一种失败模式——task-incomplete imagination（任务不完整想象），即模型生成的视频和动作在局部上合理且相互一致，却始终遗漏了完成当前任务阶段所需的状态转换。
  • 作者指出该失败并非视频扩散主干模型的固有缺陷，而是源于固定时域视频生成目标与短时域视频-动作预测目标之间的目标失配（objective mismatch），导致完成任务所需的转换在短块自回归生成中被反复推迟。
  • 为缓解该问题，论文提出Completion Aware Guidance（CAG，完成感知引导），一种免训练（training-free）的采样时引导方法，在不重新训练模型的前提下提升WAM的任务完成能力。

03核心贡献

  • 首次系统地识别并明确定义了WAM中的task-incomplete imagination失败模式，区别于一般的视频损坏或视频-动作错位问题。
  • 通过对比原生视频生成时域与WAM短块控制时域，揭示了任务不完整想象产生的机理——模型适应短时域控制后，局部合理的延续会掩盖完成任务所必需的转换。
  • 提出Completion Aware Guidance（CAG），一种免训练、可即插即用的采样时引导算法，通过强化与当前视频-动作预测最相关的指令token的交叉注意力条件，引导生成趋向任务完成。
  • CAG在两种代表性WAM架构（DreamZero 与 Fast-WAM）上均取得一致的性能提升，表明该方法不依赖于显式未来视频生成的特定机制，具备良好的通用性。

04方法描述

  • 形式化定义WAM的短时域视频-动作块预测 z_t = (o_{t+1:t+H}, a_{t:t+H-1})，并引入阶段完成指示器 E_t(z_t) 以及含KL正则的理想完成感知分布。
  • 通过分析指令信息经由交叉注意力通路（cross-attention pathway）进入视频-动作生成的过程，对每个指令token计算聚合注意力亲和度 r_{t,j}，衡量当前生成对各个指令组件的依赖程度。
  • 采用稀疏二值门控函数将注意力信号转换为有界干预：γ̂_{t,j} = 1 + α·ψ(r_{t,j})，并据此缩放指令token的key/value，从而强化与当前动作阶段最相关的指令信号（实验中 α=0.15，且无需逐任务调参）。
  • 整个方法只作用于采样（推理）阶段，不修改WAM参数，属于训练无关的即插即用式引导。

05数据集与资源

  • RoboTwin 2.0 数据集：选取9个成功率低于90%的非饱和任务进行评估。
  • DREAM（DreamZero DROID simulation）：使用官方DreamZero的3个DROID模拟场景进行零样本（zero-shot）评估。
  • 验证的WAM模型：DreamZero（显式未来视频生成）与 Fast-WAM（隐式世界建模）。
  • 论文未报告具体的GPU/TPU训练资源与模型参数量信息。

06评估与结果

  • RoboTwin 2.0 九任务子集上，平均任务成功率由 64.4% 提升至 70.0%；其中 Hanging Mug（60→63）、Turn Switch（53→67）、Move Stapler Pad（57→73）、Stack Bowls Three（67→87）、Place Object Basket（87→90）等任务提升明显。
  • DreamZero 零样本模拟 上，平均成功率由 69% 提升至 75%，三个任务（Cube to Bowl、Can to Mug、Banana to Bin）均获得增益（如 Can to Mug 由60提升至72）。
  • 失败模式分析：在代表性子任务中，任务不完整想象占失败样本的比例由 79% 下降至 40%，证明CAG的收益主要来源于直接缓解该失败模式。
  • 论文所有实验仅改变推理时引导策略，其余评估协议与基线完全一致；但未报告方差、置信区间或消融实验等统计信息。
