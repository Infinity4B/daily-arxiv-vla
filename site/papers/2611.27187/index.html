SCAP: Stochastic Context for Action Expert Pretraining

02论文概述

  • 论文针对视觉-语言-动作（VLA）模型中的视觉捷径问题，提出 SCAP (Stochastic Context for Action Expert Pretraining)，一种随机上下文动作专家预训练方法。
  • 现有单模态动作专家预训练（如 vision-action 或 language-action）可能损害联合视觉-语言建模通路，导致模型无法有效结合视觉和语言指令。
  • SCAP 通过在预训练阶段随机掩码视觉和文本 token，然后进行全输入联合微调，旨在同时缓解视觉捷径并保留联合建模能力。

03核心贡献

  • 识别了单模态动作专家预训练的一个关键局限：它可能关闭联合视觉-语言建模途径，且后续全输入训练无法重新打开。
  • 提出了 SCAP 方法，通过随机掩码视觉和文本 token 来减少视觉捷径并保留联合建模。
  • 建立了包含多任务仿真、配对语言干预和真实机器人联合基础的控制评估协议。
  • 在四个不同的 VLA 架构上验证了 SCAP 的一致有效性，并在真实机器人任务上取得显著提升。

04方法描述

  • 采用两阶段训练：第一阶段冻结 VLM 骨干，随机掩码 30% 的图像内容 token 和指令 token，仅优化动作专家；第二阶段去除掩码，联合微调 VLM 和动作专家。
  • 使用混合变压器（MoT）架构，以 Qwen3.5-9B 作为视觉-语言骨干，动作专家约 900M 参数。
  • 理论分析：构造诊断模型证明单模态预训练会关闭联合建模通路，而 SCAP 的随机掩码保留联合通路并减少对视觉捷径的依赖。
  • SCAP 将 VA、LA 和全输入预训练统一为不同掩码分布的特殊情况。

05数据集与资源

  • 使用的仿真基准：RoboTwin 2.0 和 RoboCasa-GR1。
  • 模型配置：Qwen3.5-9B VLM 骨干 + ~900M 参数动作专家。
  • 训练数据规模和多模态构成详见论文附录，但主要使用大规模机器人操作演示数据。
  • 训练资源未在可见部分明确列出（可能使用大规模 GPU 集群，但需查阅原文）。

06评估与结果

  • 在 RoboTwin 2.0 和 RoboCasa-GR1 多任务仿真基准上，SCAP 在四个不同 VLA 架构上均超过现有方法（如 GO-1、π0.5、GR00T N1.6、RDT-1B、OpenVLA-OFT、FLARE 等）。
  • SCAP 在真实机器人三个指令条件操作任务上达到 76.67% 平均成功率，比全输入预训练高出 25 个百分点。
  • 语言干预实验表明 SCAP 提高了对指令改写的鲁棒性和对任务意图变化的敏感性。
  • 消融研究验证了随机掩码比例、文本扰动和模型规模等因素的影响（具体数值见论文）。
