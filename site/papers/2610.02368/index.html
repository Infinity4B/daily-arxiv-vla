针对长时程组合性机器人操作任务，现有世界-动作模型缺乏显式的子任务级推理能力

  • 北京大学

02论文概述

  • 针对长时程组合性机器人操作任务，现有世界-动作模型缺乏显式的子任务级推理能力
  • 提出 ViGAR 框架，将操作任务分解为视觉子目标规划和子目标执行两部分，利用共享的世界模型表征进行物理推理
  • 通过将全局目标图像作为上下文输入，无需参数更新即可实现机器人的上下文学习能力

03核心贡献

  • 将组合性操作分解为长期未来选择和短期未来实现，提出层次化框架 ViGAR
  • 提出上下文机器人操作能力，通过新的全局目标图像引导不同的子任务分解和动作序列重组
  • 在仿真基准和真实机器人组合性操作任务上超越强基线，并展现出对未见全局目标的强上下文学习能力

04方法描述

  • 包含子目标规划器和子目标引导的世界-动作模型，两者均从预训练的世界模型初始化
  • 子目标规划器将子目标预测视为图像编辑问题，引入子目标前瞻规则和端执行器 ROI 加权流匹配损失
  • 子目标执行器采用几何路由，将预测的子目标图像编码为 VAE 潜变量并直接注入生成器分支，联合预测视觉轨迹和动作块
  • 在上下文学习设定下，全局目标图像作为推理时上下文直接输入子目标规划器，实现零样本任务组合

05数据集与资源

  • 仿真数据集：RoboTwin Clean2Random 基准（使用2500条Clean专家演示进行多任务训练）
  • 真实世界数据：约900小时 AgiBot A2 机器人遥操作数据及任务特定真实机器人演示
  • 模型规模：基于 Cosmos3-Nano 检查点初始化，参数量为 16B-A8B
  • 硬件资源：论文未明确提及具体使用的 GPU/TPU 训练硬件配置

06评估与结果

  • 评估环境：RoboTwin 仿真基准和真实世界 AgiBot A2 机器人部署（5个组合任务和2个上下文学习任务）
  • 主要指标：任务成功率、任务进度以及视觉子目标预测质量（LPIPS, DINO-cos, ΔIoU, RetAcc）
  • 仿真结果：在 RoboTwin 基准的 Clean 和 Random 设置下分别达到 82.00% 和 67.02% 的成功率，平均成功率超最强基线 12.86 个百分点
  • 真实世界结果：在五个组合性操作任务中取得最佳任务进度；在上下文学习任务中，in-domain 和 OOD 设置下的任务进度分别达到 77.5% 和 47.5%
