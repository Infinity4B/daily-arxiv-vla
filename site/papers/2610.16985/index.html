论文概述

  • 提出 AUGUstus，一个自动驾驶 VLA（视觉-语言-动作）模型，旨在统一动作生成与语言理解，解决现有 VLA 模型在理解能力与低延迟控制之间难以兼顾的问题。

Card 03 核心贡献

核心贡献

  • 提出 AUGUstus，在单一 transformer 中统一了基于扩散（流匹配）的动作生成与自回归的 CoT 理解；共享模型保留了 VLM 的空间理解能力以服务于动作生成，避免 VLA 退化为 VA 模型。
  • 提出 AUGUstus-mode：一种"动作优先、CoT 其次"的排序方式，迫使模型学习对动作有益的 CoT，而推理时仅需输出动作，从而实现低延迟。
  • 提出 AUGUstus-GRPO：一个统一的 GRPO 强化学习算法，联合优化连续动作与 CoT 流，将 JaT-GRPO（对连续动作分支使用闭式高斯重要性采样比与 KL 项）与 CoT-GRPO（对语言分支使用 token 级 GRPO）结合，推理流被奖励以服务规划。
  • 在多个自动驾驶基准上取得 SOTA 性能，并验证了大规模训练、内部数据集验证与真车部署的实用性。
Card 04 方法描述

方法描述

  • 统一框架：输入驾驶上下文 c=(S, E, C, H)（相机视频、自车状态、路线命令、历史轨迹）；训练时同时接收带噪轨迹 x_t 与 teacher-forced 的 CoT 前缀 y_{
  • 注意力设计：上下文 token 为因果注意力；动作 token 组成双向块，可关注完整上下文与彼此；CoT token 为因果注意力并额外关注完整动作块；动作 token 不能关注 CoT token。
  • x₀ 参数化：模型直接预测干净轨迹 x̂₀（而非速度），使 t=1 处单步 Euler 采样即可精确返回终点，支持少步与真正的单步策略。
  • SFT 损失：结合流匹配损失（L1 重建）与 teacher-forced 的 CoT 似然（熵最小化）。
  • CoT 设计：预测关键物体的包围盒与未来位置（预测型 CoT）比感知型或规划推理型 CoT 更有益于安全高效的动作。
  • AUGUstus-GRPO：每次 rollout 产生成对的动作与 CoT，两流共享归一化的组相对优势 A_i；使用 JaT-GRPO 在 x₀ 参数化下对动作分支应用 GRPO（含闭式 log-ratio 与 KL），CoT-GRPO 用 token 级似然优化 CoT 分支。
  • 两阶段 RL：Stage I 以 PDMS 为规划奖励，鼓励激进推进与对齐基准目标；Stage II 以 R_end + R_safe 为规划奖励，在保留进度的同时细化终点精度与安全行为。

Card 06 评估与结果

评估与结果

  • 评估环境：闭环 NAVSIM 与开环 nuScenes。
  • 主要指标：PDMS、EPDMS、平均 L2 误差、平均碰撞率，以及 NC、DAC、EP、TTC、Comf. 等子指标。
  • NAVSIMv1：AUGUstus（1 步去噪）达到 94.0 PDMS；3 步去噪达到 94.6 PDMS（NC 98.9、DAC 98.9、EP 91.9、TTC 97.1、Comf. 100.0），为当前 SOTA。
  • NAVSIMv2：达到 90.7 EPDMS，为 SOTA。
  • nuScenes：平均 L2 误差 0.27 m、平均碰撞率 0.05%，均为对比方法中最优。
  • 关键结论：共享模型保留了 VLM 的空间理解能力，在改善动作生成的同时满足实时规划的延迟要求，且无需 scorer 模块。
