02论文概述

  • 论文提出 NEO-VLA，一个结构上原生的视觉-语言-动作（VLA）框架，质疑现有 VLA 模型依赖预训练视觉编码器（如 CLIP、SigLIP、DINOv2）固定输出作为动作策略输入的传统范式
  • 核心问题：动作策略应该只继承固定的视觉终点（编码器输出），还是应直接访问骨干网络中逐层演化的视觉计算？操作任务恰恰依赖最易被编码器抽象压缩掉的细粒度信号（局部几何、边界、深度、状态变化）
  • 论文发现动作关键信号往往在最终视觉表征之前就已达到峰值， embodied 控制受益于访问整个计算层级中的视觉表征，而非固定的编码器输出

03核心贡献

  • 结构原生的 VLA 策略：提出 NEO-VLA，结合轻量级像素到 token 嵌入器、共享视觉-语言骨干，以及可配置访问不同骨干层（视觉层级）的 flow-matching 动作专家，无需独立预训练的视觉编码器、图像码本或自编码器
  • 动作读取深度的系统性实证研究：通过匹配专家容量的层映射对比与附着点干预实验，证明早期视觉表征对控制非常有效（尤其在骨干冻结时），动作关键信息在最终表征之前即已出现
  • 跨骨干家族与操作基准的评估：在相同动作专家设计和机器人训练语料下对比原生与基于编码器的骨干（Qwen3-VL-2B、Gemma-3-4B），在 LIBERO、LIBERO-plus、RoboTwin 2.0 上取得强性能
  • 揭示深度依赖规律：冻结骨干时包含早期层的读取一致优于仅后期层；全微调后早晚特征组合最佳；早期层激活交换引起显著更大的预测误差

04方法描述

  • 无编码器原生视觉接口：轻量卷积 patch 嵌入器将原始像素直接映射到骨干 token 空间，图像块与指令文本在单一整体架构中联合处理；保留原生宽高比，每视图动态 patch 化（预算上限 88 个视觉 token）
  • 多模态前缀：机器人观测转化为统一前缀（多视角图像、相机几何、结构化语言、机器人状态），相机内参与旋转由轻量几何 MLP 编码，使用时间/高度/宽度三维旋转位置编码
  • 跨视觉深度的动作读取：动作专家从可配置骨干层子集读取缓存的 keys/values，层映射包括 first-28、skip-28、end-28、full-40 等配置，使视觉读取深度成为显式架构选择
  • 连续动作策略建模：流匹配动作专家预测连续动作块（每臂 R^(2×30×26)、本体 R^(30×8)），以 10 步 Euler 积分求解学习到的流，训练时按四个动作组（末端执行器、臂关节、手关节、身体）加权平衡损失
  • 三阶段训练：先冻结骨干训练动作专家，再解冻全模型共训多模态理解数据，最后用自研动作数据继续全参数微调

05数据集与资源

  • 预训练数据：9 个公开数据集家族——AgiBot-World、Bimanual YAM、RoboCOIN、Open X-Embodiment、Galaxea Open-World、RH20T、RoboMIND、InternData-A1（仿真）、DROID，共 2,231,583 个 episode、约 9,927 小时、9.28 亿行数据
  • 模型规模：40 层无编码器视觉-语言骨干，2B 参数；比较骨干包括 Qwen3-VL-2B 与 Gemma-3-4B
  • 训练配置：全局 batch size 8192；动作专家峰值学习率 2×10⁻⁴，视觉-语言参数 5×10⁻⁵；AdamW 优化器、bfloat16 混合精度（论文 HTML 原文未列出具体 GPU/TPU 数量）

06评估与结果

  • 评估基准：LIBERO（Spatial/Object/Goal/Long 四套件）、LIBERO-plus（相机、机器人、语言、光照、背景、噪声、布局七种扰动轴）、RoboTwin 2.0，以及真实世界机器人评估
  • 骨干对比：冻结骨干下 NEO-VLA 平均成功率 90.9%，显著超过 Qwen3-VL-2B（79.5%）和 Gemma-3-4B（84.5%）；LIBERO-Long 上达 85.4%，超过两者全微调结果；全微调后达 95.3%
  • 层映射消融：冻结骨干时 first-28 达 94.9%、skip-28 达 90.9%、end-28 仅 86.7%，证明早期层对控制至关重要；全微调后 skip-28 最佳（95.3%）
  • 干预实验：在层 0–10 交换缓存 keys/values 导致最大平移误差，且效应取决于被替换内容而非扰动幅度；腕部图像敏感性在层 6–10 最强，指令敏感性在层 0 峰值
  • 鲁棒性：LIBERO-plus 上在相机扰动（94.5）和图像噪声（96.9）轴上表现尤为突出，总体优于 π₀、StarVLA、ABot-M0、π₀.5 等对比方法，显示对分布偏移的更强鲁棒性
