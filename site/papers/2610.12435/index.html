VioLA: Learning Generalist Humanoid Control Policies from Human Data

2026-10-08 · 原文 · 翻译 · 2610.12435

论文提出 VioLA，一种通用人形机器人策略模型，通过预测身体和手部的运动潜变量（motion latents） 而非关节指令，来解决人形机器人全驱控制的难题。 核心目标是让策略无需针对任务微调，即可在真实机器人上零样本跟随语言指令完成移动和操作任务。 通过将人体运动与机器人运动映射到共享潜空间，使大量无关节标注的人体演示数据可直接用于监督策略训练，缓解人形机器人演示数据稀缺的问题。

论文概述

Card 03 核心贡献

核心贡献

  • 提出 VioLA，一种预测身体与手部运动潜变量的通用人形策略，预训练的冻结控制器将潜变量转换为协调的关节命令，策略不再需要学习底层关节协调。
  • 将人体演示数据转化为策略可用的动作标签，构建包含 1.406 亿帧（其中 93.2% 来自人类）的训练池，共计 781 小时数据。
  • 在真实 Unitree G1 机器人上实现零样本运动与操作：移动任务成功率 100%，操作任务成功率 88.6%，无需任务级微调。
  • 验证了方法在 VLA（GR00T N1.7、π₀.₅） 和 WAM（DiT4DiT） 三种不同骨干网络上的通用性。
  • 证明了仅用人类演示训练的策略即可在真实机器人上执行移动任务（零样本成功率 40%）。
Card 04 方法描述

方法描述

  • 共享潜动作空间：采用 SONIC 预训练的身体运动编码器和控制器，另预训练手部编码器-解码器模块；人类和机器人运动编码器将运动映射到同一 64 维潜空间，身体与手部潜变量拼接为 128 维动作空间。
  • 人体演示监督：通过冻结的编码器将人体运动转换为动作目标，同时通过模拟器闭环跟踪生成机器人本体感觉状态，使人体数据与机器人数据格式统一。
  • 流匹配（Flow Matching） 目标：策略基于 GR00T N1.7 骨干，沿用其 flow-matching 目标预测连续潜变量坐标，而非量化码本索引。
  • 实时分块（Real-Time Chunking, RTC）：在运动潜空间中应用 RTC，让新预测的 chunk 条件于推理期间正在执行的潜变量，减少 chunk 切换时的运动不连续性（最大跳变从 0.332/0.455 降至 0.064/0.070）。
Card 05 数据集与资源

数据集与资源

  • 人类数据：EgoSuite（源自 EgoStandard），20,680 个片段，约 1.31 亿帧。
  • 机器人数据：Humanoid Everyday、PSI、UnifoLM-WBT（均为真实 G1 演示）和 LeVERB（模拟 G1 演示）。
  • 训练池总量：31,988 个片段，140,572,312 帧，约 781 小时。
  • 模型规模：骨干为 GR00T N1.7-3B（3B 参数 VLM），对比骨干包括 π₀.₅ 和 DiT4DiT（Cosmos-Predict2.5-2B）。
  • 训练：150k 步人类数据预训练 + 50k 步五语料均匀采样；控制频率 50 Hz。
Card 06 评估与结果

评估与结果

  • 评估平台：真实 Unitree G1 机器人，配备五指 Inspire 灵巧手，实验室新环境中不同物体实例。
  • 任务：6 个移动/姿态任务（来自 LeVERB）+ 7 个操作任务（来自 Humanoid Everyday），每任务五次试验。
  • 零样本移动：VioLA 完成 30/30（100%）；GR00T N1.7 仅 5/30（16.7%）；Ψ₀ 为 0/30。
  • 零样本操作：VioLA 完成 31/35（88.6%）；GR00T N1.7 为 0/35，Ψ₀ 为 3/35（8.6%）。
  • 人体数据消融：human-only 训练达 40% 移动成功率；human-then-mixed 比 robot-only 在移动任务上高 20 个百分点（30/30 vs 24/30）。
  • 骨干对比：GR00T 与 DiT4DiT 均达到移动 30/30，但 GR00T 操作表现远超其他（88.6% vs 45.7% 和 25.7%）；预测延迟分别为 160.2 ms（GR00T）、208.6 ms（π₀.₅）、248.5 ms（DiT4DiT）。
  • 运动 token 分析：复杂任务可用少量运动 token 表示，如转椅执行平均仅需 60 个身体 token 和 31 个手部 token。
