WA-JEPA: Goal-Aware Predictive Feedback Action Refinement for a World-Action Model

02论文概述

  • 提出 WA-JEPA，一种世界–动作模型，将动作生成、动作条件潜在预测与目标感知反馈耦合在一起。
  • 解决 JEPA 世界模型中预测信息难以高效指导动作生成的问题，避免传统候选动作搜索带来的高在线计算开销。
  • 通过“提议–预测–目标感知反馈”迭代优化同一动作计划，在短时程、长时程和完整任务执行三个层面验证有效性。

03核心贡献

  • 提出 WA-JEPA 模型，实现无候选搜索的目标感知预测反馈动作精化。
  • 设计 目标差异残差反馈（GDRF），利用预测场景与任务目标之间的潜在差异指导分块动作修正。
  • 设计 未来场景上下文反馈（FSCF），保留细粒度预测场景表示，协调后续动作精化。
  • 联合学习动作生成、未来预测和结果对齐，使预测动作后果直接参与部署期动作优化。
  • 在短时程目标到达、长时程锚定规划和完整任务执行中，以紧凑模型和低在线计算成本取得强性能。

04方法描述

  • 使用冻结的 DINOv2-Small 提取视觉特征，通过可学习融合和查询池化生成场景 token，并与目标任务目标在同一特征空间比较。
  • 动作令牌先通过自注意力、上下文记忆、目标记忆和上一阶段预测场景交叉注意力生成动作提议。
  • 共享世界模型接收上下文、当前场景编码和动作提议，预测未来场景特征与本体感知状态。
  • GDRF 将目标差异、预测场景、动作令牌和预测本体感知拼接，生成逐块残差动作修正，并由可学习门控控制修正幅度。
  • FSCF 将未池化的预测场景 token 作为下一阶段动作更新的额外上下文。
  • 训练目标联合包含预测损失、动作监督和结果对齐损失，从离线演示中学习预测与精化循环。

05数据集与资源

  • 短时程任务：PushT、TwoRoom、OGBench-Cube
  • 完整任务：Push-T、LIBERO-Goal
  • 短时程 PushT 模型可训练参数约 13.87M，对比 LeWM 18.03M、DINO-WM 20.12M
  • 完整任务 Push-T 参数约 37.2M，LIBERO-Goal 约 37.8M
  • 视觉编码器为冻结的 DINOv2-Small；训练优化器为 AdamW，峰值学习率 5×10⁻⁵
  • 训练硬件未明确说明；计算成本与延迟评估在 NVIDIA A40 上完成，使用 BF16 和批大小 1

06评估与结果

  • 短时程目标到达中，PushT 成功率 96%，TwoRoom 和 Cube 均为 100%，达到最高或并列最高。
  • 相比 LeWM，WA-JEPA 完整计划生成延迟加速 10.8–32.6×，FLOPS 仅为 LeWM 的 1.9–5.6%。
  • 长时程 Anchored Planning 中，相比 AP（LeWM），跨任务平均成功率提升 25.78%（标准起始）和 19.14%（扰动起始），决策延迟加速 1.33–2.18×。
  • 完整任务中，Push-T 最终覆盖率 71±2%，LIBERO-Goal 任务成功率 97±1%，均优于对比基线。
  • 相比 Patch Policy，完整任务单次在线规划 FLOPS 在 Push-T 降低 94.7%，在 LIBERO-Goal 降低 93.6%。
  • 消融研究表明，移除 GDRF 或 FSCF 均导致性能下降，三阶段反馈相比零反馈显著提升最佳检查点成功率；预测与执行相关性 Pearson r 为 0.844。
