02论文概述

  • 论文提出 Hierarchical Reasoning Action Head (HR-AH)，面向轻量级 Vision-Language-Action (VLA) 模型，用于机器人实时操控。
  • 解决的核心问题：缩小 VLA 骨干网络会减少推理时的“深思熟虑”容量，而现有的链式思考（CoT）、双系统架构或更大骨干网络又会重新引入延迟和内存开销。
  • HR-AH 在单个紧凑动作头内引入两个不同更新频率的潜在状态，在不增加骨干网络规模的前提下实现层次化推理。

03核心贡献

  • 面向小规模 VLA 的层次化循环计算：HR-AH 将视觉上下文更新与运动指令细化分离为高层规划状态和低层执行状态，完全在动作头内部实现迭代式动作细化。
  • 模态特异性路由实现高效推理：视觉 token 被路由到高层规划器，动作 token 和本体感受信号被路由到低层执行器，使昂贵的视觉注意力集中在较慢的推理路径上，并通过自适应停止机制降低推理成本。
  • 紧凑动作头下的强性能：仅使用 22.5M 参数的动作头（比同骨干上的 RD-VLA 和 VLA-Adapter 小 3–4.3 倍），在 LIBERO 上达到 97.0% 成功率，在 CALVIN ABC→D 上达到 4.40 平均任务链长度，在真实 Kinova Gen3 Lite 机器人上达到 78.8% 成功率，并实现最低推理延迟。
  • 消融实验证明层次化设计的有效性：与参数匹配的单状态动作头相比，层次化状态分离贡献了大部分性能提升，模态特异性路由进一步带来 3.4 个点的提升并减少所需推理步数。

04方法描述

  • HR-AH 由三个共享同一 UBAttn 块架构的模块组成：低层执行器（\(f_L\)）、高层规划器（\(f_H\)）和自顶向下细化模块（\(f_R\)）。
  • 特征提取：从 VLM 骨干的倒数第二层提取视觉 token（\(h_{viz}\)）和动作用查询 token（\(h_a\)），并从嵌入层提取带可学习 sigmoid 门控的低层视觉特征（\(h_{viz}^{emb}\)）。
  • 层次化推理循环：每个 segment 包含 \(K_H\) 个层次化循环，每个循环先执行 \(K_L\) 次低层更新（关注动作 token 和本体感觉），再执行一次高层规划更新（关注视觉 token、嵌入层视觉特征和低层状态），最后通过细化模块将高层状态注入低层状态。
  • 自适应停止机制：推理时根据连续 segment 间动作预测的相对变化 \(\delta_s\) 是否低于阈值 \(\tau\) 来决定提前停止，训练时固定展开 \(S_{total}=8\) 个 segment 并使用深度监督。
  • 训练技巧：采用 one-step 梯度近似、RMSNorm 稳定状态、LoRA（秩 64）微调骨干网络。

05数据集与资源

  • 使用的数据集：LIBERO（Spatial、Object、Goal、Long 四个套件）、CALVIN ABC→D 模拟基准、自采的 Kinova Gen3 Lite 真实机器人数据集。
  • 模型规模：动作头 22.5M 参数，骨干为 MiniVLA（基于 Qwen2.5-0.5B，融合 DINOv2/SigLIP 视觉编码器），隐藏维度 \(D=896\)，动作块长度 \(N_{act}=8\)，查询 token 数 \(N_q=64\)，规划 token 数 \(N_{plan}=32\)，视觉 token 数 \(N_{viz}=512\)。
  • 训练资源：NVIDIA A100 GPU，批次大小 LIBERO 为 24、CALVIN 为 16，学习率 5e-5。

06评估与结果

  • LIBERO：HR-AH 平均成功率 97.0%，其中 Spatial 98.0%、Object 99.6%、Goal 97.4%、Long 93.0%，均超越或持平对比方法。
  • CALVIN ABC→D：HR-AH 平均任务链长度 4.40，与 VLA-Adapter 持平；5 任务链完成率 74.0%，显著优于 RD-VLA（45.3%）等循环头方法。
  • 真实机器人：在 6-DoF Kinova Gen3 Lite 上达到 78.8% 成功率，验证了物理环境中的泛化能力。
  • 推理效率：HR-AH 推理延迟最低，仅 49.63 ms。
  • 消融实验：层次化状态分离带来大部分增益，模态特异性路由额外贡献 3.4 个点并减少所需推理步数。
