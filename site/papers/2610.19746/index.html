02论文概述

  • 本文研究预训练视觉-语言-动作（VLA）模型的快速适应问题，目标是让 VLA 策略在仅有单个人类演示视频的情况下适应此前未见过的操作任务。
  • 现有适应方法通常依赖目标任务的机器人演示数据和额外的任务微调，数据与算力开销大，难以规模化扩展到开放世界场景。
  • 论文提出 CapPro 框架，利用人类视频作为任务级执行指导而非直接模仿轨迹，无需目标任务机器人演示，也无需目标任务微调。

03核心贡献

  • 首次形式化单样本人类视频引导的 VLA 适应问题：单个人类演示视频为目标任务提供特定执行指导，无需机器人演示或微调。
  • 提出 CapPro 框架，将阶段感知的人类视频表示与视频条件适应相结合，从单个演示中捕获分阶段的执行信息并注入机器人动作生成过程。
  • 提出阶段级文本监督（phase-caption supervision）的辅助训练目标，使可学习查询表示能编码执行阶段相关信息，且该监督仅在训练时使用。
  • 在 RoboTwin 的 26 个未见任务（含不同任务偏移程度）以及真实世界操作任务上验证了跨任务适应能力。

04方法描述

  • 基于预训练 π₀.₅ 策略构建 CapPro，包含两个核心模块。
  • 阶段感知人类视频表示模块：

- 均匀采样 Nₛ 帧，用共享视觉编码器编码。

- 通过可学习的空间 token 选择机制（GridS 采样器）每帧选取 S 个信息性 token，构建紧凑视频表示 Zᴴ。

- 加入归一化的视频进度位置编码，保留演示的时序信息。

- 将每个源任务划分为若干语义阶段，每个阶段配文本描述；引入 M 个可学习查询 token，与机器人视觉特征、Zᴴ 进行带结构化注意力掩码的交互，输出上下文相关的查询表示 Sₜᴴ。

  • 视频条件适应模块：

- 使用可学习标量 γ 的 tanh 门控对 Sₜᴴ 进行自适应缩放。

- 构造增强动作前缀 Pₜ = [Zₜᴿ; Zᴴ; S̃ₜᴴ; Zᴸ]，注入原策略的动作条件上下文，保留原有动作生成机制。

  • 训练目标：流匹配动作损失 L_act + 自回归阶段描述损失 L_cap，总损失 L = L_act + λ_cap·L_cap。
  • 创新点在于：不做显式的人到机器人轨迹转换，而是把人类视频作为条件上下文中的任务级指导。

05数据集与资源

  • 仿真基准：RoboTwin，共 39 个任务，分为四组：

- Source（13 个源任务，用于训练）

- Target-A1（6 个，近任务偏移）

- Target-A2（10 个，物体/交互/可供性偏移）

- Target-B（10 个，组合式任务偏移）

- 每个源任务含 50 条干净轨迹 + 500 条随机化机器人轨迹。

  • 真实世界任务：7 个操作任务（3 个 Source、2 个 Target-A、2 个 Target-B），如放可乐罐、放马克笔、折短袖、折裤子、工件分拣等。
  • 模型规模：基础策略 π₀.₅，包含 2B VLM 主干 + 300M 动作专家；对两者均应用 LoRA。
  • 训练超参数：人类支持帧 Nₛ=8，GridS 每帧 token 数 S=32，可学习查询 token M=4，λ_cap=0.1，动作门控初始化 0.1，batch size 128，峰值学习率 2.5×10⁻⁵，AdamW + 余弦学习率调度。
  • 主结果基于 30K 步检查点。

06评估与结果

  • 评估设置：每个目标任务在推理时仅提供一段自我视角的人类演示视频；每个任务在干净与随机化两种设置下各评估 100 个 rollout，报告任务成功率，结果取两种设置平均。
  • 对比基线：匹配的 π₀.₅ 基线（同源数据、同训练预算）和 Direct Video Prefix 基线（直接将人类视频 token 拼入前缀，无 GridS、无阶段监督、无查询引导）。
  • 仿真主结果（成功率 %）：

- CapPro：Source 68.9，Target-A1 44.8，Target-A2 29.0，Target-B 20.7，Overall 42.6。

- π₀.₅：Source 64.4，Target-A1 34.5，Target-A2 2.5，Target-B 4.0，Overall 28.4。

- Direct Video Prefix：Source 43.5，Target-A1 25.2，Target-A2 1.5，Target-B 1.4，Overall 19.1。

- CapPro 相比 π₀.₅ 提升 14.2 个百分点，相比 Direct Video Prefix 提升 23.5 个百分点。

  • 结论性发现：简单拼接人类视频 token 反而会损害性能，说明有效的人类视频引导需要结构化表示与整合，而非单纯增加视觉上下文。
  • 消融研究：移除阶段感知描述后（w/o Phase-Aware Caption）Target Avg. 降至 12.7%，且源任务成功率反而升至 76.5%，说明阶段级监督对跨任务泛化至关重要；论文还列出去除 GridS、Caption Loss、Query-to-Action Guidance、Human Video Progress、Direct Video Path 等变体。
  • 真实世界实验：论文报告了真实机器人上的部分结果（表格中数字部分截断），用于验证人类视频引导在仿真之外同样有效。
  • 局限：在存在较大物体、交互和组合式偏移的任务上性能仍然有限，作者将更强的视频表示与适应机制列为未来工作。
