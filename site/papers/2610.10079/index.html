RealtimeWAM: How Fast Can I Run My World Action Model?

Card 03 核心贡献

核心贡献

  • 设计基于层依赖的并行调度，将观察处理（Prefill）与动作预测、未来视频生成重叠执行。
  • 提出硬件感知的 token 复用策略，利用 GPU 延迟平台（latency plateau）在几乎不增加延迟的情况下额外刷新信息量大的 token。
  • 实现运动自适应细化，根据粗动作预测的位移大小动态决定 Transformer 残差缓存刷新次数，兼顾响应速度与精度。
  • 在两个 WAM 架构、三个仿真基准和五个真实世界任务上进行全面评估，并通过受控消融验证各组件贡献。
Card 04 方法描述

方法描述

  • 依赖感知并行执行：按层释放观察 K/V，使预测分支与 Prefill 剩余计算重叠；并行执行 VAE 编码与上下文准备；使用融合算子、CUDA Graph 回放降低启动开销。
  • 硬件感知 token 复用：以 RGB 变化确定必须刷新的 token，并保留一部分容量；离线分析并发第一阶段得到执行容量集合，用第一层特征变化分数排名填充容量；仅刷新选中 token 的 FFN 缓存，其余复用历史值。
  • 运动自适应细化：缓存 Transformer 输入到输出的残差；两次初始刷新后解码粗动作，计算最大位移；若位移小于阈值则采用 4 次全刷新（4F），否则仅 2 次全刷新（2F），均共享同一去噪前缀。
  • 全程无需额外训练，适用于不同 WAM 架构。

  • 模型：FastWAM、OpenWAM。
  • 硬件：RTX 4090（48 GiB 修改版），BF16 精度，batch size 1。
  • 真实世界评估：5 个真实机器人任务（详见附录 A）。
Card 06 评估与结果

评估与结果

  • 评估指标：成功率（%）、平均推理延迟（ms）、相对原生推理加速比、真实世界任务成功率。
  • FastWAM：平均延迟从 214.33 ms 降至 24.09 ms，加速 8.90×；成功率 82.77% 变为 82.75%（-0.02 个百分点）。
  • OpenWAM：平均延迟从 672.83 ms 降至 63.09 ms，加速 10.67×；成功率 87.94% 变为 87.41%（-0.53 个百分点）。
  • 相对编译 + CUDA Graph 的 Native，额外加速 4.14×（FastWAM）和 7.15×（OpenWAM）。
  • 对比基线 VLA-Cache、TeaCache、ToCa、BAC：RealtimeWAM 平均延迟最低；成功率和最优基线相当（BAC 在 OpenWAM 上成功率 87.77% 略高于 87.41%，但延迟高 305 ms 以上）。
  • 真实世界任务：FastWAM 平均成功率提升 17.2 个百分点，OpenWAM 提升 37.2 个百分点（相对原生推理）。
  • 消融实验表明：token 复用、容量填充、运动门控均有效；自适应 2F/4F 优于固定 2F/4F 在成功率与延迟间的权衡。
