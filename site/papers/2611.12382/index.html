02论文概述

  • 自回归视觉-语言-动作（VLA）规划通常直接预测连续未来轨迹，但驾驶指令常描述动作（如让行、保持、转弯）而非 ego 状态，导致最终连续轨迹的条件化较弱。
  • 提出 TrajCond，一种离散轨迹几何条件，在最终连续轨迹预测前由动作 tokens 构成并学习，从而弥合指令与连续轨迹之间的语义-几何鸿沟。
  • 方法命名为 AutoVLA-D（Double），采用两阶段训练同时在自回归过程中生成离散与数值轨迹。

03核心贡献

  • 提出将离散轨迹作为轨迹几何条件（TrajCond），先预测离散轨迹再以其几何语义指导最终连续轨迹生成，保留连续输出空间优势的同时利用离散条件的动作语义对齐能力。
  • 设计 1D-Brohan 离散化动作 tokens：对 x、y、yaw 三个自由度分别建立独立 Brohan 风格码本，相比共享码本聚类（K-Means、K-Disks）具有更低的重建误差和更强的 TrajCond 效果。
  • 引入两阶段对齐训练：Stage 1 对齐观测/指令与动作 token 序列以学习 TrajCond 语义；Stage 2 利用 TrajCond 和推理上下文回归最终连续轨迹，分离条件学习与轨迹预测。
  • 在 NAVSIM navtest、nuScenes、NeuroNCAP 三个基准上验证有效性：离散轨迹直接输出较弱，但作为 TrajCond 能一致提升连续轨迹预测，取得多项最先进结果。
  • 系统分析离散/连续轨迹形式的影响，证明离散轨迹在自回归 VLA 中作为条件（而非输出）可以编码指令语义并保持轨迹几何，提升规划性能。

04方法描述

  • 总体框架：给定图像观测和语言指令，AutoVLA-D 在最终连续轨迹回归前显式引入一个离散的轨迹几何条件 TrajCond。两者共享同一个 VLA 模型，通过两个训练阶段实现条件学习与轨迹预测的解耦。
  • 轨迹离散化：从连续轨迹构造局部坐标系下的差分动作序列（Δx, Δy, Δθ），对每个自由度使用独立 Brohan 风格码本（每个码本 256 bins，总码本大小 768）进行线性量化。通过迭代选择最小 corner 误差的 token tuple 得到离散动作序列。
  • Stage 1 训练：输入视觉-语言上下文，输出 TrajCond 动作 token 序列，采用监督微调（SFT）和自回归 token 损失，使模型学会从指令和视觉输入中生成离散几何条件。
  • Stage 2 训练：初始化自 Stage 1 模型，输出顺序为动作 tokens → 连续轨迹 tokens，损失同时包含动作 token 损失和轨迹 token 损失，采用 teacher-forcing 训练；推理时完全自回归生成。
  • 可选推理与强化微调：在 NAVSIM 设置中加入 CoT 推理 token（输出顺序 r→a→w），并采用 GRPO 进行强化微调（RFT）；nuScenes 和 NeuroNCAP 仅使用两阶段 SFT。

05数据集与资源

  • 数据集：NAVSIM navtest（大规模非反应式闭环仿真）、nuScenes（开环真实驾驶基准）、NeuroNCAP（基于 nuScenes 的逼真闭环仿真器）。
  • 模型：主要使用 Qwen3-VL-4B；nuScenes 和 NeuroNCAP 还报告了 Qwen2.5-VL 变体。连续轨迹采用归一化文本 waypoint tokens，离散 TrajCond 使用 1D-Brohan 码本（总码本大小 768）。
  • 训练资源：使用 LLaMA-Factory 实现 SFT，EasyR1 实现 RFT，优化器为 AdamW，权重衰减 0.05，warmup 比例 0.10，全局 batch size 32。Stage 1 和 Stage 2 各训练 3 个 epoch，学习率 4×10⁻⁵；GRPO 训练 160 步，actor batch size 512。具体 GPU 资源见论文附录 A（摘录中未给出）。

06评估与结果

  • 评估环境与基准：遵循 ReCogDrive 协议评估 NAVSIM navtest；遵循 Impromptu VLA 协议评估 nuScenes；遵循 ImagiDrive 协议评估 NeuroNCAP。NAVSIM 使用单前视图，NeuroNCAP 使用左-前-右三视图。
  • 主要指标：NAVSIM navtest 使用 PDMS（含 NC、DAC、EP、TTC、C 等子指标）和 EPDMS（含 NC、DAC、DDC、TLC、EP、TTC、LK、C、EC 等子指标）；nuScenes 使用 ST-P3 和 UniAD 的 L2 误差与碰撞率；NeuroNCAP 使用平均得分和碰撞率。
  • 关键结果：

- NAVSIM navtest PDMS：AutoVLA-D (Qwen3-VL-4B) 达到 92.0 PDMS，超过 Curious-VLA 的 89.7、FLARE 的 91.4 等先前最佳成绩；EPDMS 达到 86.8，超过 Curious-VLA 的 85.3 和 FLARE 的 86.3。

- nuScenes 开环：在使用 Qwen2.5-VL-3B 时，AutoVLA-D 的 ST-P3 L2 误差为 0.30（与 OpenDriveVLA 并列最佳，优于 AutoVLA 0.48 和 Impromptu VLA 0.33），UniAD L2 误差 0.60，碰撞率 0.35（与 OpenDriveVLA 持平）；使用 Qwen3-VL-4B 时（含 TrajCond）碰撞率降至 0.29，优于无 TrajCond 的 0.34。

- NeuroNCAP 闭环：AutoVLA-D 显著提升得分并降低碰撞率。在平均碰撞率上优于 VAD、UniAD、SparseDrive 等基线（具体数值见表格，如本文使用 Qwen3-VL-4B 时侧向碰撞率明显降低）。

- 消融与形式分析：离散轨迹直接作为最终输出时性能弱于连续轨迹，但作为 TrajCond 能一致提升最终连续轨迹预测；1D-Brohan 码本相比 K-Means/K-Disks 重建误差更低，TrajCond 效果最佳。
