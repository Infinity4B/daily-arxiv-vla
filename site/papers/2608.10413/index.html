Card 03 核心贡献

核心贡献

  • 提出面向VLA自动驾驶的失败感知记忆增强框架，明确针对模型表现不佳的高风险场景
  • 设计结构基础检索机制，解耦静态道路与动态代理场景特征，并集成解耦LoRA-based测试时训练策略实现高效在线适应
  • 证明记忆与TTT的结合可显著提升多基准下的鲁棒性、安全性与可扩展性，支持无额外训练的纯记忆扩展
Card 04 方法描述

方法描述

  • Base Model：采用 InternVL3 作为VLM骨干，使用Q-Former风格压缩模块（16个可学习查询，256维）将LLM最后一层特征从2800×1536压缩至16×256；动作解码器采用两阶段设计，轨迹头生成多模态轨迹簇，评分头输出碰撞率、可行驶区域合规性等K个子分数
  • Retrieve Model：基于预训练 DINOv2 配合LoRA微调，采用双分支解耦架构（Map静态分支与Agent动态分支），分别提取道路拓扑与周围代理布局特征，通过BCE损失监督 Occupancy Grid 预测
  • Memory Generation：离线阶段，利用oracle PDM评分识别基础模型的失败案例（PDM得分低于阈值β），将场景的Map/Agent检索键、语言/自我状态/轨迹簇适配输入、以及专家轨迹与评分标签写入潜在记忆池M，并采用余弦相似度去重
  • Inference with TTT：在线阶段，通过检索模型提取当前场景的Map与Agent特征查询记忆池，按阈值λ触发TTT，分别初始化Map LoRA与Agent LoRA权重，在检索到的失败案例上优化轨迹与评分损失，实现场景特定校正
  • 触发机制采用余弦相似度门控，仅当检索特征与记忆特征相似度超过λ时激活TTT，避免不必要的计算开销
Card 05 数据集与资源

数据集与资源

  • 数据集：NAVSim v1（Navtest测试集）与 NAVSim v2（Navhard测试集）
  • 模型架构：InternVL3（VLM骨干）+ DINOv2（检索模型），采用LoRA进行参数高效微调
  • 推理延迟：TTT反向传播延迟开销仅 26.44 ms
Card 06 评估与结果

评估与结果

  • 评估环境：Navtest（NAVSIMv1）与Navhard（NAVSIMv2）自动驾驶规划基准
  • 评估指标：PDMS（规划领域指标总分）、EPDMS（增强版PDMS）、NC（无碰撞率）、DAC（可行驶区域合规率）、EP（效率）、TTC（碰撞时间）、C（舒适度）
  • 关键实验结果：

- 在Navtest上达到 94.1 PDMS（DriveVLA-M0-Scale），超越此前SOTA的DriveSuprim（93.5）与Mimir（89.3）

- 在Navhard上达到 47.0 EPDMS，显著优于基线方法

- 基础版本DriveVLA-M0-Base在Navtest上达到 92.3 PDMS，已超过多数现有VLA方法

- 通过记忆池扩展可实现无训练的性能提升，验证框架的可扩展性
