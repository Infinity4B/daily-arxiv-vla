02论文概述

  • 论文研究双系统视觉-语言-动作（VLA）模型中"慢模块何时被调用"这一问题：快策略以控制频率执行，慢而昂贵的模块（大 VLM）间歇性介入以纠正或重规划。
  • 现有系统在如何介入（latent refreshing、value-guided resampling、action-suffix reuse）上已有差异，但何时介入刚开始被触发器机制化，且缺乏共享目标、实测代价和能把调度质量与慢模块质量分离的评价标准。
  • 论文把慢模块调用形式化为带查询预算的校准决策问题，证明固定比例、固定预算、历史门控调度都是单一量 Value of Intervention（VoI） 的退化情形，并将经济性定位于代价不对称连续谱 ρ=c_slow/c_fast。

03核心贡献

  • 带代价基线的决策论框架：定义 VoI 为慢模块纠正动作与纯快策略动作之间的期望质量差，并按状态 s 下快策略塌缩概率加权（定义 1）；固定比例（命题 1）、固定预算（命题 2）、历史门控（命题 3）均为 VoI 路由的退化特例；给出 renewal 基线（命题 4），证明状态无关塌缩下最优调度是周期性的，周期为 √(2c_slow/(w_fail·π))。
  • 带边界刻画的校准路由器：轻量路由器在线估计 VoI，仅在估计值超过查询代价时调用慢模块；论文不仅刻画其收益，还刻画其失效边界——优势对估计器方差不敏感，但一旦估计器在多数步上失去有效性便消失。
  • 无泄漏的测量标准：提出由 staleness 曲线、routing frontier、failure attribution、calibration reliability 组成的四项测量协议及显式无泄漏规则；在 929 条 RoboICL 部署轨迹上该规则是"承重"的，把调度统计量的早期预警 AUC 从事后 0.93 降到无泄漏 0.62（p=0.010）。
  • 调度编译：将任务实测的 staleness 价值函数编译为逐任务的刷新周期；在受控任务族上编译周期与闭环 oracle 的代价差距不超过 2.4%，编译属样本平均近似（SAA），其最优性缺口有统计证书，且继承 Harris–Wilson 订货量问题的代价平坦性（二阶敏感）。
  • 闭环验证与失效机理隔离：在 LIBERO 上发现语言重写通道无法把查询转化为成功，而"可撤销干预"的 revert 执行器是唯一零净下行的干预，给出"能力条件化"的测量判据。

04方法描述

  • VoI 分解：VoI(s)=E[Δ(s)\|s]，其中 Δ(s)=Q*(s)−Q_f(s)；最优调度在 VoI(s_t)>c_slow 时查询（附录 A 证明最优性）。
  • 代价不对称连续谱：以 ρ=c_slow/c_fast 刻画一次慢查询相当于多少个快动作；低 ρ 端固定比例调度难以被击败，高 ρ 端不确定性触发才划算。
  • 代价对称基线（命题 4）：塌缩为恒定速率 π 的伯努利过程且查询周期为 k 时，每步期望代价 C(k)=c_slow/k+w_fail·π·k/2，最优周期 k*=√(2c_slow/(w_fail·π))；自适应调度相对周期基线的增益在塌缩率时不变时为零，并随时间离散度增长。
  • 采样类最优性（命题 5）：在查询间可观测量 z_t（本体感觉、动作统计、场景变化）时，最优调度是后验塌缩概率上的阈值规则，即查询代价下的 Shiryaev 快速检测规则；周期调度仅在"零证据类"中最优；自适应的可辨识内容就是通道关于塌缩的信息量。
  • 触发器视为窗口化序贯检验（注 2）：以 Wald SPRT 为有限样本答案，部署触发器（如 15 控制步窗口、2 cm 位移阈值的 stall 检测器）是窗口化近似。
  • 库存论映射（注 3）：renewal 目标即 Harris–Wilson EOQ 权衡，给出代价敏感性恒等式 C_eoq(γk*)/C_eoq(k*)=½(γ+1/γ)≤1+(γ−1)²/2。
  • 最优探针分配（注 4）：验证阶段是 ranking-and-selection 问题，预算按 n_k/n_j=(σ_k/Δ_k)²/(σ_j/Δ_j)² 集中到接近并列的候选周期上。
  • 能力条件化测量（注 5）：闭环代价一阶分解为快策略动作能力地板 B(ε,H) 与 freshness 价值 V(k)；调度只能作用于 V，实际新鲜度价值为 V·η_C。
  • 通道分解（命题 6）：慢模块输出空间与快策略动作之间的接口只部分实现纠正，Δ_C(s) 引入通道转移系数。

05数据集与资源

  • 合成测试床（synthetic testbed）：用于匹配查询预算下与三族基线的 Pareto 比较，以及塌缩异质性扫描。
  • RoboICL 发布：929 条部署轨迹、33,443 个决策点用于无泄漏重打分；ρ≈10³ 由该发布报告的 API 代价锚定。
  • FiS-VLA：在 RLBench 上微调开源 checkpoint，在硬件上测量慢刷新代价；在 4 张消费级 GPU 上微调。
  • 硬件测量平台：单张 RTX 4090；一次慢刷新耗时 52 ms，约等于一个快动作（55 ms）或 3.8 个去噪步，ρ=0.95。
  • 闭环双臂设置：OpenVLA-7B 作为快策略、Qwen2.5-VL-7B 作为慢模块，在 LIBERO-Spatial 与 LIBERO-Goal 上运行，闭环 ρ=1.53。
  • 对比系统：FiS-VLA、Hume（Cal-QL 价值头，固定 best-of-N，ρ≈22）、RoboICL（冻结 LLM，suffix reuse gate，ρ≈10³）、TUD、System Switch（均未报告 ρ）。

06评估与结果

  • 主要评估指标：任务成功率、查询率/调用削减率、无泄漏早期预警 AUC、routing frontier、staleness 曲线、编译周期与闭环 oracle 的代价差、代价不对称比 ρ。
  • 合成测试床（匹配预算）：校准路由 Pareto 支配 固定比例、始终查询与 reuse-gate 三族基线；0.25 查询率下成功率 0.825±0.002 vs 0.762±0.002。
  • 连续谱预测的直接检验：同质塌缩下校准相对固定 cadence 的优势消失，并随塌缩异质性单调增长（第 5.7 节），与 renewal 基线预测一致。
  • 无泄漏规则效果：同样特征事后 AUC 0.93，无泄漏仅 0.62（p=0.010），若无该规则早期预警能力会被高估约 1.5×；跳过决策按 episode 聚集，设计效应 8–18，故 16,000 个决策点的 frontier 估计仅相当于约 1,000 个 episode 的信息量。
  • RoboICL 部署轨迹：失败 episode 查询慢模块密度低约 25% 且 staleness 更大，效应随任务类别而异，因此单一固定比例无法利用该信号；阈值路由在明确漏检失败代价下达到已部署 reuse gate 的 33–48% 调用削减区间。
  • FiS-VLA 实测：手调 1:4 cadence 对应 +24% 计算，位于 ρ≈1 低不对称端，界定了任何触发器在该处的增益上界；微调后测得慢 latent 的 freshness 价值函数在最多 8 个快步的年龄上非正，而摊销延迟下降 2.1×；latent 按 √δ 的 Wiener 过程律漂移，但动作映射对其局部不敏感。
  • 编译结果：受控任务族上编译的逐任务周期与闭环 oracle 的代价差距 ≤ 2.4%；发布 checkpoint 编译到其非正价值函数所决定的边界。
  • LIBERO 闭环（ρ=1.53）：自适应触发器按阈值规则的预测分配查询，但 subgoal-rewrite 通道无法转化为成功，其合并成功率 43% 对纯快策略 58%，且无剂量效应轴；替换为动作排序或加入撤销执行器只改变风险分布而非均值；revert 臂给出唯一方向一致的正向对比（15 vs 4 不一致对，名义 p=0.019，族校正下不显著）；第二套任务（LIBERO-Goal，LLM 慢端点）复现排序，rewrite 缺陷加深至 42 点，revert 臂与纯快策略完全一致（48/100 vs 48/100）。
