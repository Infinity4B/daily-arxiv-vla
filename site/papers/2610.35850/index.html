Card 02 论文概述

论文概述

  • 提出 OSWAM（One-Step World Action Model），面向自动驾驶与具身控制的单步动作生成世界动作模型
  • 解决直接策略型 WAM（direct-policy WAM）仍需数十步去噪才能生成高质量动作、延迟过高难以实时部署的问题
  • 核心洞察：单步生成失败的根源在于随机高斯噪声初始化缺乏结构化动作先验，简单减少去噪步数会导致 NAVSIM 上约 20%、RoboTwin 上约 40% 的性能下降
Card 03 核心贡献

核心贡献

  • 提出 OSWAM，通过学习紧凑的 Imagination Tokens 作为结构化动作先验，实现高质量的一步动作生成（单次去噪）
  • 引入特权信息蒸馏（Privileged-Information Distillation）：教师模型可关注完整未来视频片段，学生模型推理时仅用首帧，在不引入未来特征的前提下迁移长时程上下文
  • 设计 Role-aware 3D RoPE，用不同空间锚点区分视频 token、AIT 与 SIT 的角色，同时保持时间对齐
  • 在自动驾驶（NAVSIM）与具身控制（RoboTwin 2.0）上取得与多步 WAM 相当或更优的结果，并实现约 3 倍加速
Card 04 方法描述

方法描述

  • 基于 Fast-WAM 的直接策略范式：视频预测仅作为训练信号，推理时不进行视频 rollout
  • 采用 Wan2.2-5B 作为 Video DiT 骨干，Action DiT 由预训练 Video DiT 权重插值降采样初始化，整体为 MoT（Mixture-of-Transformer）架构并共享注意力
  • 引入两组想象 token：AIT（Action Imagination Tokens，编码动作结构先验）与 SIT（Scene Imagination Tokens，聚合场景上下文的潜在槽位），通过 LoRA 适配 Video DiT，仅引入极小计算开销
  • AIT 在 Video DiT 中与首帧视觉特征交互，生成结构化动作先验，经加噪到中间时间步（τ_r=500, σ_r=0.5）后由 Action DiT 一步去噪得到最终动作
  • 采用特权信息蒸馏：教师 AIT 关注完整未来视频片段，学生仅见首帧，通过多深度特征对齐（Video DiT blocks [8,16,24,30]）将未来信息注入 AIT，推理时教师被丢弃、保持首帧接口
  • 训练目标包含视频流匹配损失、AIT 动作先验损失、特征蒸馏损失与一步动作去噪损失
Card 05 数据集与资源

数据集与资源

  • NAVSIM（自动驾驶）：1192 个训练场景、136 个测试场景，评估指标为 PDMS（含 NC、DAC、EP、TTC、Comfort）
  • RoboTwin 2.0（具身控制）：50+ 双臂操作任务，2500 条干净场景演示 + 25000 条强随机化演示，按每任务 100 次试验评估成功率
  • 骨干模型基于 Wan2.2-5B（含 T5 文本编码器与视频 VAE），Action DiT 隐藏维度 1024，LoRA rank 8（α=4）
  • 训练使用 AdamW（lr 1e-4）：NAVSIM 训练 40,000 步、batch size 256；RoboTwin 训练 29,335 步、batch size 1024
  • 延迟测量平台：NVIDIA H20 GPU（表 1、2）与 NVIDIA RTX 5090 GPU（表 3、编译推理）
Card 06 评估与结果

评估与结果

  • NAVSIM：PDMS 达 90.3，延迟 136 ms；与 SimWAM 相比保持同等 PDMS 的同时实现 3.01× 加速，超过 Metis 1.2 PDMS 且 3.24× 加速
  • RoboTwin 2.0：50 任务平均成功率 90.00%，延迟 142 ms；较 Fast-WAM（10 步）实现 2.80× 加速，成功率仅降 1.83%；较单步 Flash-WAM 成功率提升 8.59% 且 4.29× 加速
  • 推理效率（RTX 5090）：RoboTwin 整体延迟从 Fast-WAM 的 323.67 ms 降至 95.35 ms（3.39× 加速）；NAVSIM 从 SimWAM 的 330.8 ms 降至 99.70 ms（3.32× 加速）
  • 经 torch.compile 与 CUDA Graph 编译优化后，延迟低至 40.81 ms（RoboTwin）与 52.64 ms（NAVSIM），支持 10 Hz 以上的实时推理
  • 消融实验显示 AIT 贡献最大（NAVSIM PDMS 从 71.04 提升至 89.81），蒸馏与 SIT 进一步带来增益（最终 PDMS 90.28）
