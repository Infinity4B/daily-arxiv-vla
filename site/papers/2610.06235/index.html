Card 03 核心贡献

核心贡献

  • 证明名义任务成功不能保证指令跟随：目标替换后，各策略以 86.5%–98.3% 的概率仍抓取原始目标，而仅 0.5%–13.0% 的概率遵循当前指令目标，真实世界中也一致。
  • 排除语言不敏感解释：指令扰动系统性影响任务性能；逐层 action lens 显示中间动作预测对指令变化有响应；线性探针能以近完美精度恢复当前指令目标，说明失败并非因目标信息缺失。
  • 揭示编码语言为何无法控制动作：注意力贡献分析表明指令 token 对动作生成贡献弱，目标 token 注意力可能仍停留在原目标物体上。
  • 发现微调导致表示组织向场景身份偏移：UMAP 与共享半 NMF 分析显示，微调后指令表示由目标主导聚类转向场景主导组织，目标信息虽仍可解码但组织方式改变。
  • 提出诊断框架与严格接地标准：有效的指令变化应可靠地在同一场景中选择不同行为，为后续 VLA/WAM 评估提供了具体判据。
Card 04 方法描述

方法描述

  • 场景保持指令干预：设计 Original、Noun Replacement（含 In-scene Target Replacement 与 Random Noun）和 Random Sentence 三种条件，保持场景与机器人配置不变，仅改变指令中的目标名词或整句。
  • 逐层 Action Lens：在每一层和去噪步上，用策略动作读出器读取中间隐状态并计算与原始指令的 MSE 偏差，诊断语言在动作生成中的敏感性。
  • 线性探针：在指令 token 的平均池化表示上训练岭回归探针，分别预测目标身份与场景身份，检验目标信息的可解码性。
  • 注意力贡献分析：聚合注意力加权值向量，按源模态归一化，量化指令 token 相对视觉/状态输入对动作生成的贡献。
  • UMAP 与共享半 NMF：对基座与微调检查点的指令表示进行联合分解，通过方差划分（$U_{scene}$、$U_{target}$）量化场景/目标身份的独特贡献变化。

Card 06 评估与结果

评估与结果

  • 目标替换（LIBERO-Object）：π0.5 对当前目标倾向率 13.0%、成功 11.5%；GR00T N1.7 仅 1.3%/0.5%；FastWAM 0.5%/0.0%；LingBot-VA 1.8%/1.3%——而原目标倾向率高达 86.5%–98.3%。
  • 真实世界：π0.5 当前目标拾取率 5.8%（原目标 74.2%）；GR00T N1.7 当前目标 3.3%（原目标 90.8%）。
  • 指令扰动：随机句子在 LIBERO-Goal 上导致 π0.5 成功率下降 88.1%、GR00T N1.7 下降 95.9%；名词替换影响较小且任务相关。
  • 线性探针：π0.5 与 GR00T N1.7 微调前后目标与场景身份解码均接近上限准确率。
  • 注意力贡献：π0.5 指令 token 贡献在 LIBERO 为 25.6%–27.9%、RoboTwin 约 1.7%、真实世界 9.7%；GR00T N1.7 对应为 18.5%–23.4%、约 12%、13.5%。
  • 表示组织：微调后中间层指令表示转向场景身份聚类，共享半 NMF 显示场景独特方差上升、目标独特方差下降，视觉注意力在目标替换后仍聚焦原目标物体。
