02论文概述

  • 现有Vision-Language-Action（VLA）模型通常作为冻结策略部署，无法从自身交互失败中学习，且现实场景中的强化学习应用依赖手动环境重置与人工任务成功监督，阻碍了机器人的自主持续学习
  • 本文提出FIND智能体式现实强化学习框架，旨在实现VLA模型在持久工作空间中的自主闭环学习，无需频繁手动重置场景，也无需人工提供在线奖励标签
  • 框架核心是解决“下一次该练习什么任务”的问题，通过场景理解、弱点针对性练习、自我评估、策略改进的闭环，让机器人利用上一次交互产生的场景状态作为下一次练习的起点

03核心贡献

  • 提出FIND框架，首个实现持久工作空间中场景理解、弱点感知练习、自我评估、策略改进全闭环的智能体式现实强化学习系统，支持VLA模型的自主持续提升
  • 将无重置的自主练习形式化为场景条件+性能感知的任务选择问题：通过视觉语言模型（VLM）识别当前场景可行任务，基于策略近期成功率分配练习优先级，用执行前后配对图像实现自我评估，评估结果同时用于后续任务分配和策略学习
  • 在8个真实世界操作任务上验证框架有效性：独立人工评估的任务成功率从基线55%提升至71.9%，代表性6小时自主运行仅需30次人工场景恢复干预，且在线学习全程无需人工提供奖励标签
  • 通过消融实验和分析验证了性能感知课程和critic门控机制对自主学习的必要贡献，同时评估了不同VLM作为监督组件的适用性

04方法描述

  • 场景条件任务选择：每轮交互开始时，VLM分析当前工作空间观测，推断任务相关场景状态，从预定义任务库中筛选出当前场景可行的任务子集，无需手动重置被操作的物体
  • 性能感知课程：为每个任务维护长度为20的近期成功率滚动历史，基于近期成功率计算任务采样权重（成功率越低权重越高），结合场景可行性掩码得到最终任务采样分布，自动将练习资源分配给当前场景可行且策略表现较弱的任务
  • 配对图像自我评估：执行任务前记录场景观测，执行后记录同视角观测，VLM结合任务指令和前后配对图像预测二值任务结果，无需人工标注，结果同时作为策略学习的稀疏奖励和课程更新的输入
  • 残差策略改进：冻结预训练的π₀.₅ VLA作为基础策略输出基础动作，轻量级残差策略预测修正动作，通过critic门控机制判断残差动作是否优于基础动作，仅当残差优势超过阈值时才执行修正动作；采用REDQ风格的10头集成critic提升价值估计鲁棒性
  • 采用异步线程并行执行机器人交互和策略优化，通过有序FIFO队列传递交互经验，通过最新参数队列返回更新后的策略，若采集器比学习者超前2000个环境步则暂停当前episode等待同步，在保证策略时效性的同时减少交互空闲时间

05数据集与资源

  • 使用的离线演示数据集包含8对可逆操作任务，每类任务收集50集演示，总交互transition数约6.3万，数据集采用LeRobot格式存储，包含RGB观测、机器人本体感知、末端执行器动作、语言指令和终端信息
  • 基础策略为冻结的π₀.₅ VLA，残差策略为轻量级神经网络，Critic采用10头集成Q网络结构
  • 训练与实验运行在工作站上，配备NVIDIA RTX 4090 GPU、Intel Core i9-14900K CPU、64GB RAM

06评估与结果

  • 评估环境为真实桌面场景，使用7自由度的Franka Emika Panda机械臂，配备平行夹爪和2个ZED X Mini相机（第三人称视角+腕部视角），评估任务为4对可逆操作共8个语言条件任务
  • 主要评估指标包括：独立人工评估的任务成功率、在线VLM评估的滚动成功率、人工干预率、连续自主运行时长、任务采样分布演化
  • 关键实验结果：

- 经过自主现实交互后，8个任务的独立人工评估平均成功率从基线55%提升至71.9%，在线VLM评估的滚动成功率最终达到(70.4±4.6)%，与人工评估结果趋势一致

- 代表性6小时自主运行共完成456集交互，其中426集无需人工干预，仅需30次场景恢复干预，干预率低至6.58%，最长连续自主运行时长达48分钟，全程无人工提供的在线奖励标签

- 消融实验表明，移除性能感知课程或critic门控都会导致策略改进速度显著下降，验证了两类机制对稳定自主学习的互补作用

- VLM监督组件评估中，GPT-5.6 Terra表现最优，任务选择准确率达96%，配对图像成功评估准确率达100%，平均响应延迟最低，被选为后续实验的监督模型
