Card 03 核心贡献

核心贡献

  • 提出具身技能这一统一抽象，用于标准化异构具身模块，并构建包含 250 个技能的 Embodied Skill Repository，覆盖动作、感知与经验三类角色。
  • 提出 EmbodiedSkillBench 评测框架，支持多智能体、灵活技能组合，在多轮动作—观察循环中运行，并显式规定技能供给与外围 harness。
  • 定义三种交互模式：原生控制（native control）、纯技能执行（skill-only），以及新提出的 Agent-Directed Reuse (ADR)，允许智能体保留原生控制并自主决定调用、修改或忽略技能。
  • 实验揭示技能收益随智能体能力增强而递减的规律：技能从"补充缺失能力"转向"降低执行成本"。
  • 提供开源代码：https://github.com/HanZhi306/EmbodiedSkill-Bench。
Card 04 方法描述

方法描述

  • 技能表示：技能包表示为五元组 s = ⟨m, I, S, R, A⟩，其中 m 为元数据（技能名与能力描述），I 为使用指令、反馈解释与恢复规则，S 为控制函数与模型调用脚本，R 为方法说明与程序性经验，A 为模型描述符、配置与接口 schema 等资产；采用开放 Agent Skills 格式，写入 SKILL.md 与 scripts/references/assets 目录。
  • 模块类型：区分模型模块（动作/感知模型）、代码模块（控制、观测处理、模型调用脚本）、文本模块（程序性经验、接口文档、规划与恢复指南）。
  • 技能构建流水线：模块收集 → 组件结构化 → 智能体辅助技能组装；由作者智能体编写 I 与 m，并链接到 S/R/A，通过脚本校验组件完整性与接口可用性。
  • 多轮交互环境：智能体通过 Observe 接口读取场景与腕部 RGB 图像、机器人状态与执行反馈，通过 Act 接口执行末端运动、旋转、夹爪控制或调用 VLA 技能。
  • 评测器三阶段：Rollout Logging（记录交互、Token 用量、时间戳）、Per-Task Metric Computation（成功、动作数、Token、耗时）、Cross-Task Aggregation（跨任务聚合）。
  • ADR 机制：智能体在保留原生控制的前提下，对每个技能自主决定调用、修改或绕过；另将 Jev 封装为 waypoint 执行技能，由智能体保留规划与恢复、委托局部运动决策。
Card 05 数据集与资源

数据集与资源

  • 评测基准：LIBERO-Pro 的 Clean100，由 25 个基础任务交叉语言、物体、任务、交换四类扰动构成 100 个任务用例，覆盖 LIBERO-10 / Goal / Object / Spatial（分别为 24、28、24、24 个用例）。
  • 技能仓库规模：250 个具身技能，含 133 个动作技能（53.2%）、20 个感知技能（8.0%）、97 个经验技能（38.8%）。
  • 源资源：从 1,052 条去重资源记录构建，含 227 条控制资源、33 条感知接口、20 个模型描述符、417 份经验材料、23 篇文献、13 个仓库引用、319 项支撑资产；结构化后得到 260 个脚本（S）、453 个参考（R）、339 个资产（A）。
  • 模型资源：动作侧覆盖四类 VLA 家族五个 profile（两个 π0.5 checkpoint（RLinf、Madokalif）、OpenVLA-OFT、SmolVLA、X-VLA）；感知侧使用 SAM3、Molmo2、Contact-GraspNet；另有 8 个编程控制接口。
  • 被测智能体：gpt-5.6-sol 与 gpt-6-astra（Codex CLI v0.148.0）、Kimi-K3（Kimi Code CLI v0.40.0）、claude-opus-5（Claude Code v2.1.186）。
  • 检索基线：BM25 词法检索与基于 BGE-small-en-v1.5 的 Embedding 检索（同样 250 候选、481 条任务-能力查询）。
  • 论文未明确报告训练所用 GPU/TPU 资源（评测为推理侧智能体实验）。
Card 06 评估与结果

评估与结果

  • 评估设置：在 Clean100 的 100 个扰动任务上，以 seed 26 运行；主指标为成功率（SR），辅以平均动作数、记录 Token 数与耗时。
  • RQ1（有效性）：纯技能执行将 GPT-5.6-Sol 从 11% 提升至 63%，Kimi-K3 与 Claude-Opus-5 各提升约 20 个百分点，Token 用量下降 58%–85%；三者平均动作数分别减少 90.9%、75.6%、62.9%。
  • RQ1 关键发现：四个智能体最终成功率收敛于 61%–64%，GPT-6-Astra 从原生控制的 92% 降至技能模式的 61%，说明强模型已内化部分模块能力。
  • RQ2（技能组合）：五种配置成功率跨度大——HarnessVLA (ESB) 77%、Zetta (ESB) 69%、Selected 63%、Embedding 42%、BM25 36%；Embedding 选到 54 个不同技能（BM25 为 41，Selected 为 28），但更广检索不等于更高效完成，且在 7 个任务上未提供可执行动作技能。
  • RQ3（互补性）：技能使 GPT-6-Astra 的平均动作数减少 86.50%、Token 减少 75.51%、时间减少 83.43%，呈现成功率与执行成本的权衡。
  • ADR 效果：GPT-6-Astra 在 ADR 下恢复至 85%（距原生控制仅 7 个百分点），同时 Token 减少 14.1%、时间减少 11.9%。
  • Jev 技能效果：达到 81% 成功率，Token 减少 50%、时间减少 57%，平均耗时从 20.52 分钟降至 8.74 分钟。
