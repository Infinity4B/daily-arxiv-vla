02论文概述

  • 针对现有Vision-Language-Action (VLA) 策略在机器人操控中存在的度量3D结构监督不足、时序物理演化建模冗余、部署成本高三大问题，提出GaussianDream++，是前作GaussianDream的紧凑策略原生升级版本
  • 该方法通过将角色化的世界表征直接嵌入VLA主干，在训练阶段利用3D高斯重建与短期未来预测提供 dense 物理监督，推理阶段移除所有辅助模块，仅保留20个世界token，无需在线高斯解码或未来推演即可实现高效闭环控制
  • 在仿真操控基准与真实机器人任务上验证了方法的有效性，显著提升了操控精度、分布偏移鲁棒性和部署效率

03核心贡献

  • 紧凑策略原生高斯世界建模：提出GaussianDream++，用仅20个直接嵌入PaliGemma主干的World State Tokens和World Prediction Tokens，替代GaussianDream的密集VGGT/TGE前缀，表征可直接被动作专家通过原生注意力通路使用，无需额外投影模块
  • 角色化的当前-未来表征与静态-动态分解：World State Tokens负责重建当前物理世界，World Prediction Tokens负责建模短期演化，通过静态-动态门控机制将残差运动聚焦于机器人、被操作物体和交互区域，抑制静态背景的冗余运动建模
  • 非对称训练-部署与高效推理：训练阶段通过轻量World Representation Head结合可微高斯渲染、深度、可见性、运动目标提供密集物理监督，推理阶段移除所有辅助分支，无需专用运行时几何通路，大幅降低部署成本
  • 跨仿真与真实场景的性能提升：在LIBERO、LIBERO-Plus基准和真实双臂机器人任务上均取得优于对比方法的性能，尤其在相机、布局等几何敏感的场景偏移下提升显著

04方法描述

  • 基于PaliGemma/π₀.₅的VLA主干架构，在输入前缀中嵌入16个World State Tokens和4个World Prediction Tokens，与原视觉-语言token联合进行上下文编码
  • 训练阶段，轻量World Representation Head解码两类token：对World State Tokens，通过几何-外观解耦分支预测度量深度、高斯几何属性（尺度、旋转、不透明度）与外观系数，结合标定相机参数反投影得到当前3D高斯世界，通过可微高斯渲染生成RGB、深度、覆盖率预测，用对应观测目标监督；对World Prediction Tokens，结合当前世界特征、可学习horizon嵌入预测每个高斯原语的残差中心位移，通过静态-动态门控输出运动系数，继承当前世界的其余属性得到未来高斯状态，用未来观测的渲染、深度、3D运动、静态一致性目标联合监督
  • 创新点在于将世界表征完全嵌入VLA主干，实现训练监督与推理表征的完全对齐，同时通过静态-动态分解和角色分离的token设计，在保持建模能力的同时大幅压缩表征规模，移除推理时的所有辅助计算开销

05数据集与资源

  • 仿真基准：LIBERO（包含Spatial、Object、Goal、Long四个任务套件）、LIBERO-Plus（包含Camera、Robot、Language、Lighting、Background、Noise、Layout七种分布偏移场景）
  • 真实机器人任务：Bowl-Proximity（碗具邻近精细放置）、Eggplant-to-Pink-Plate（含干扰物的长程语义操控）
  • 模型规模：基于PaliGemma/π₀.₅主干，仅新增20个可学习世界token（16个状态token+4个预测token），参数增量极小，无大规模新增模块
  • 训练资源：采用与GaussianDream家族一致的训练协议，未明确披露具体GPU/TPU配置

06评估与结果

  • 评估环境：LIBERO/LIBERO-Plus仿真环境、双臂物理机器人实验平台
  • 主要评估指标：任务成功率（%）、零样本分布偏移鲁棒性、推理效率
  • 关键实验结果：

- 标准LIBERO任务上平均成功率达98.6%，优于匹配协议下的reproduced π₀.₅（96.9%）和GaussianDream（98.4%）

- LIBERO-Plus零样本鲁棒性Overall达87.8%，较reproduced π₀.₅提升2.3个百分点，较GaussianDream提升0.8个百分点；其中Camera偏移下从77.3%提升至80.1%（+2.8%），Layout偏移下从88.4%提升至90.0%（+1.6%）

- 真实机器人任务上，平均成功率从reproduced π₀.₅的29.2%提升至52.5%，其中Bowl-Proximity任务从25.0%提升至46.7%，Eggplant-to-Pink-Plate任务从33.3%提升至58.3%

- 推理阶段仅需处理20个额外世界token，无需VGGT/TGE专用几何通路、在线高斯解码或未来推演，部署效率显著优于GaussianDream
