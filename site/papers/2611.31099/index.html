02论文概述

  • 论文针对 Flow-matching 视觉-语言-动作（VLA）模型（如 π0.5）中，2B 参数骨干网络在每个控制步骤重新编码图像和指令、其中前馈层占据大部分计算的问题，提出一种训练无关的低秩计算路由方法。
  • 核心目标是在保持动作精度的同时加速 VLA 前缀，通过仅对部分 token 进行精确 MLP 计算、其余 token 使用低秩近似来实现。
  • 论文发现：决定哪些 token 需要精确计算的正确信号是输入新颖性（token 是否超出校准子空间），而非通常认为的近似输出误差，从而提出 NoveltyGate 方法。

03核心贡献

  • 新颖性优于误差用于 VLA 前缀 token 分发：输入新颖性测试（Gated Subspace Inference 的门控）比完美的输出误差验证器选择的 token 更好，动作偏差低 1.31–1.74 倍，差距与 token 所属相机视角相关。
  • 每层每 token 一次决策、在乘法之前进行：单个 2048×544 乘积同时返回 gate/up 低秩系数和输出 sketch，下投影使用输出最优低秩，一次决策覆盖整个 gated MLP。
  • 在 π0.5 和 LIBERO 上的实证证据：在未见过任务和初始状态下，NoveltyGate 比通道剪枝、固定秩和能量分配秩压缩在等算力下更接近原始策略 2.7–2.9 倍，前缀实测加速 1.18–1.61 倍，f=0.3 时闭环成功率 10/10。

04方法描述

  • 低秩草稿（Drafts）：对 17 个活跃层拟合秩-256 的输出最优低秩近似，gate 和 up 投影使用输入空间中的输出最优投影，down 投影使用输出协方差 top 特征向量，秩-256 MLP 算术量为原始 0.14。
  • token 选择评分：比较三种可在乘积前计算的评分：输入残差（相对校准子空间的重构误差）、输出 sketch（随机投影估计误差）、两者并集；同时评估随机选择、静态位置评分和完美验证器（不计成本）。
  • 每层一次决策：所有评分仅依赖 MLP 输入 y，因此每个 token 和层只做一次路由决策；一个 2048×544 乘积返回 draft 系数和输出 sketch，输入残差额外增加一个 256×2048 乘积；固定配额 k=⌈fn⌉ 使所有张量形状静态，整个 dispatched 前缀可捕获为单个 CUDA 图。
  • 对比逐乘积决策：逐乘积决策需要移动 16384 宽中间行，在 GPU 上导致数据搬移开销，eager 执行下加速比最高仅 1.12x，故采用每层决策。

05数据集与资源

  • 数据集：LIBERO-10（10 个任务，使用任务 0,1,3,5,7 校准，任务 2,4,6,8,9 评估；另有 held-out set A/B）
  • 模型：π0.5（基于 PaliGemma 的 2B 参数骨干网络，前缀包含 256 tokens per camera、指令和离散状态，共约 968 slots）
  • 训练资源：RTX 5060 Laptop GPU（AC 电源，功率限制 115W），PyTorch 2.7，BF16 精度；校准使用 31 个闭环 rollout 观测。

06评估与结果

  • 评估环境与基准：在 LIBERO-10 未见任务和初始状态上评估，使用 CUDA graph 捕获整个前缀，与原始前缀交替重放 72 对；偏差以策略自身 seed-to-seed 变化为单位（RMS 姿态差）。
  • 主要评估指标：动作偏差（seed units）、前缀 GPU 加速比、闭环任务成功率、末端夹爪指令符号一致性。
  • 关键实验结果：

- NoveltyGate 在 f=0.2 时实测加速 1.61x、偏差 2.44；f=0.4 时加速 1.26x、偏差 1.57，优于 75% 通道剪枝（偏差 1.83）。

- 输入残差评分在所有精确比例下优于输出 sketch 和完美验证器，完美验证器/残差偏差比在 1.31–1.74 之间。

- 闭环测试：原始策略 10/10 成功，NoveltyGate f=0.3 为 10/10，f=0.6 为 9/10，未检查低秩前缀为 0/10。

- 每层一次决策使 eager 执行加速比从逐乘积的 ≤1.12x 提升至 1.50x（f=0.3），且偏差无显著差异。
