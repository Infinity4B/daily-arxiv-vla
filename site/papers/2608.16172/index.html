02论文概述

  • 现有分层Vision-Language-Action (VLA)系统孤立地决定子任务终止（何时Stop）和执行长度（执行多远），但二者相互依赖，造成结构性信息不对称
  • 提出SparkVLA，将Stop与所有action-prefix长度统一为单一候选集排序问题，仅需离线序数偏好训练，无需阈值调优或在线奖励
  • 在长程操纵基准RoboCerebra和真实机器人上验证，解决高层规划与低层执行的接口机制设计问题

03核心贡献

  • 将子任务终止和执行长度选择统一为单一排序问题，解决相互依赖，消除独立检测器、阈值调优和在线信号需求
  • 提出Anchor-Conditioned Context Encoding模块，通过历史感知锚点编码初始状态记忆与目标语义，引导视觉标记剪枝至任务相关区域
  • 设计Stop-Aware Action-Prefix Selection头，通过完整自注意力对Stop与所有action-prefix进行统一评分，仅在chunk边界运行以提高效率
  • 证明高层系统可跨不同低层执行器（OpenVLA-OFT, SmolVLA）迁移，并在仿真与真实平台间保持一致增益

04方法描述

  • 架构：基于预训练π₀.₅ VLA的双分支分层架构，高层分支保留VLM骨干用于子任务生成与选择器，低层分支使用完整VLA生成action chunk
  • 历史感知子任务锚点：从深层Transformer层提取原始锚点，通过自注意力与锚点历史池融合，编码初始状态记忆与目标语义
  • 锚点引导视觉剪枝：使用Grid-Sampler根据子任务锚点预测K个归一化2D坐标，通过双线性插值将每个相机的视觉标记从N剪枝至K个任务相关标记
  • 高层隐藏特征编码：将剪枝后的视觉标记投影并拼接proprioceptive state与子任务命令嵌入，通过高层VLM骨干前ℓₘ层计算隐藏特征
  • 统一候选评分：Stop候选与H个action-prefix候选通过完整自注意力相互评分，上下文标记（锚点与隐藏特征）提供条件信息
  • Stop感知排序目标：使用pairwise ranking loss（BCE）与stop-aware auxiliary loss（对比Stop分数与continuation分数的log-sum-exp）联合训练

05数据集与资源

  • 主要数据集：RoboCerebra（100个任务变体，平均9.1个子任务，2,972步，1,000条标注轨迹）
  • 辅助数据集：LIBERO（Spatial, Object, Goal, Long四个套件，共40个任务）

06评估与结果

  • 评估环境：

- 仿真：RoboCerebra（6种条件：Dynamic Random, Dynamic Observed, Memory Exp, Memory Exe, Mix, Ideal），LIBERO

- 真实世界：3个多步任务（Shelf Arrangement 6子任务, Drawer Restocking 6子任务, Tea Preparation 12子任务）

  • 评估指标：

- Success Rate (SR)：完成任务的比例

- Stop Accuracy：选择器Stop决策与标注子任务边界的一致性

  • 关键实验结果：

- RoboCerebra：SparkVLA达到47.12%平均SR，超过官方分层基准(HPE) 30.57%，超过可复现最优方法(Mem-0) 26.83%

- 在Dynamic Obs与Memory Exp条件下提升最大（+34.78%与+47.69%）

- 执行器通用性：替换OpenVLA-OFT与SmolVLA作为低层执行器分别提升+22.47%与+22.52%

- LIBERO：达到98.5%平均成功率，在LIBERO-Long上提升5.6%

- 真实世界：达到69.3%平均成功率，超过π₀.₅ 21.3%，在Tea Preparation上提升30.0%

- 推理效率：通过缓存子任务命令与仅在chunk边界运行选择器，达到4.14 Hz，保留standalone π₀.₅ 88%吞吐量
