02论文概述

  • 论文针对视觉-语言-动作（VLA）策略在部署时相机位姿发生扰动导致性能大幅下降的问题，提出一种无需训练、即插即用的观察适配器 Homeward。
  • 核心目标是将未校准的部署相机观察规范化回训练视角，使冻结的 VLA 策略在相机被碰撞、重装或更换镜头后仍能可靠工作。
  • 通过闭环诊断发现，使用现成 3D 基础模型进行朴素重投影会因移动机械臂的深度伪影使性能低于不做任何校正，而利用机器人运动学直接渲染机械臂可以解决此问题。

03核心贡献

  • 闭环视角诊断：量化冻结 VLA 在相机位移下的失败可恢复性，证明用 oracle 几何重新渲染可恢复大部分性能，但现成 3D 模型会在移动臂上产生撕裂和散射伪影，导致性能倒挂。
  • 训练自由的运动学-几何规范化：提出 Homeward，将观察恢复分解为单目场景重投影和前向运动学链接渲染，无需部署相机校准，仅需一次训练相机标定和参考图像。
  • 大规模评估与机制表征：在四个冻结 VLA 和五种相机扰动家族（含 LIBERO-Plus 全部 1599 个变体、6-DoF 随机位姿、连续漂移、焦距变化）上验证有效性，并与校准的视图合成基线比较，揭示适用边界。
  • 系统设计选择：引入选择性移动链接渲染（只渲染运动连杆，不渲染静态基座）、姿态缓存和运动门控，在保持性能的同时大幅降低推理开销。

04方法描述

  • 单目场景恢复：利用冻结的 VGGT 模型从参考图像和当前观测中估计相机内参、外参和稠密深度，通过反向投影和重投影将场景变换到训练视角，并用深度边缘过滤、z-buffer 溅射和参考帧填充处理遮挡区域。
  • 运动学机器人渲染与合成：利用已知的关节状态和训练相机标定，通过前向运动学渲染移动连杆的 RGB 图像和轮廓掩模，再与恢复的场景层按掩模合成最终观测。
  • 关键创新：将未知的场景几何与已知的机器人运动学解耦，只渲染运动连杆而非整个机器人，避免全机器人渲染带来的遮挡错误；引入姿态缓存（仅在首步估计位姿，后续单帧深度推断）和运动门控（检测相机是否真的移动，若未移动则绕过恢复），实现低开销部署。

05数据集与资源

  • 数据集：LIBERO-Plus 基准（含 Spatial、Object、Goal、Long 四个套件，共 1599 个相机变体），以及自定义的 CamRand（随机 6-DoF 位姿）、AnyCamVLA 轨道、相机漂移和镜头更换场景。
  • 模型：四个冻结的 VLA 策略：OpenVLA-OFT、π0.5、π0、OpenVLA；3D 基础模型 VGGT-1B（518px，bfloat16）。
  • 训练资源：在单个 NVIDIA A100 GPU 上部署；场景恢复每策略查询约 0.16s，运动学渲染 0.01s，总开销约 0.21s，对 8 步动作分块策略摊销至每控制步骤 27ms。

06评估与结果

  • 评估环境：使用 MuJoCo 仿真器的 GPU EGL 后端，在 LIBERO-Plus 以及扩展扰动基准上进行闭环评估，配对实验采用 McNemar 检验和任务级 cluster bootstrap 置信区间。
  • 主要指标：闭环任务成功率（%）。
  • 关键结果：

- 在 LIBERO-Plus 全部 1599 个相机变体上，Homeward 将 OpenVLA-OFT 从 62.5% 提升至 77.6%，π0.5 从 76.5% 提升至 95.1%，π0 从 68.0% 提升至 91.2%，OpenVLA 从 3.6% 提升至 26.4%。

- 在极端位移（Level 5）下，Homeward 显著减缓性能下降，例如 OpenVLA-OFT 从 22.0% 恢复到 53.8%，π0.5 从 55.6% 恢复到 92.6%。

- 在 6-DoF 随机位姿、镜头更换、连续漂移和 AnyCamVLA 轨道场景中，Homeward 均带来一致提升，且对前三类策略与校准的视图合成基线持平或更优。

- 消融实验表明：选择性移动链接渲染至关重要（渲染全机器人导致性能崩溃）；使用估计几何的性能接近 oracle 几何；对训练相机标定误差和渲染颜色误差具有鲁棒性。
