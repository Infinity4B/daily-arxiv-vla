Evo-World: A Lightweight Vision-Language-Action Model with Future Motion Prediction via Optical-Flow Supervision

02论文概述

  • 提出 Evo-World，一种轻量级视觉-语言-动作（VLA）模型，通过光流监督引入未来运动预测，为策略学习提供任务相关的预测信号。
  • 论文要解决的问题：动作监督本身不鼓励模型预测场景如何演变，而预测未来 RGB 图像会将任务相关运动与大量静态外观纠缠在一起。
  • 核心思路：用光流替代 RGB 作为预测目标，强调图像空间位移而抑制静态纹理，同时保持模型轻量（仅 0.87B 参数）以便在真实机器人上部署。

03核心贡献

  • 将光流监督的未来运动预测引入轻量级 VLA 策略，提供补充视觉理解与语言定位的强预测信号。
  • 结合分布正则化（SIGReg）与独立梯度路径，在策略学习过程中保留预测表征，并通过紧凑的条件模块（FiLM）将其整合进动作生成。
  • 在仿真与真实机器人操作任务上进行了全面实验，0.87B 参数模型在保持低计算开销的同时取得强任务性能。
  • 验证了光流作为预测目标优于未来 RGB 预测，且无需推理时解码未来图像或计算光流。

04方法描述

  • 运动表征模块：从指定视角图像和指令出发，用 DINOv2 和 CLIP 初始化编码器，经 MLP 预测潜在运动表征；训练时以 RAFT 计算的光流（Δ=15）渲染图编码作为目标，目标通路仅训练时使用。
  • 视觉-语言骨干：采用 InternVL3-1B（InternViT + InternVL3 LLM）提取联合视觉-语言表征。
  • 运动条件动作生成：通过有界 FiLM（α=0.1，零初始化）将当前与预测表征注入骨干特征，使用 stop-gradient 阻断动作梯度回流至运动模块；动作专家为流匹配 Transformer，采用 Beta(2,2) 时间采样和掩码前向欧拉推理。
  • 训练目标：联合优化预测损失、SIGReg 正则损失与动作流匹配损失，正则化当前与目标批表征以防表征坍缩。

05数据集与资源

  • 仿真基准：Meta-World MT50（四个难度层级）、RoboTwin（Clean 与 Randomized 设置）。
  • 真实任务：AgileX 双臂机器人，包括单臂插花、双臂挂杯和微波炉放置三项任务。
  • 模型规模：0.87B 参数（含预测分支），未使用大规模机器人数据预训练。
  • 训练资源：4× NVIDIA RTX 4090 GPU；真实部署使用 NVIDIA H20 GPU（BF16 精度）。

06评估与结果

  • Meta-World MT50：层级平均成功率 91.1%，比非预测基线相对提升 13.0%，比 Evo-1（80.6%）高 10.5 个百分点，比 FabriVLA（90.0%）高 1.1 个百分点。
  • RoboTwin：Clean 成功率 67.1%，Random 成功率 16.5%，平均 41.8%，在对比方法中最高。
  • 真实机器人：三项任务平均成功率 63.3%，优于 π₀（51.7%）和 OpenVLA-OFT（23.3%）；GPU 显存仅 2.54 GB，推理频率 6.16 Hz。
  • 消融实验：光流目标优于未来 RGB 和无预测；同时使用当前与预测表征、SIGReg 正则化和梯度分离均能提升成功率和表征质量。
