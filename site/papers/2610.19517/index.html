VLRLA: Deployment-Time Adaptation of Vision-Language-Action Models through In-Context Reinforcement Learning

2026-10-14 · 原文 · 翻译 · 2610.19517

Card 02 论文概述

论文概述

  • 论文提出 VLRLA，一个为现有 Vision-Language-Action (VLA) 模型赋予上下文强化学习 (In-Context RL) 能力的通用框架，实现部署时的持续自适应。
  • 核心问题是：传统预训练 VLA 策略缺少一种机制，无法在部署过程中通过累积的交互经验逐步自我改进；而在线深度强化学习或交互式模仿学习需要参数更新、大量人工采样和逐任务的超参调优，难以扩展。
  • 目标是让 VLA 模型在参数完全冻结的前提下，通过历史观测、动作、奖励与终止信号组成的上下文记忆，逐步改进动作生成与任务成功率。
Card 03 核心贡献

核心贡献

  • 首次将 VLA 模型的部署时自适应形式化为上下文强化学习问题，利用累积交互与奖励反馈指导下一次决策，同时保持模型参数固定。
  • 提出了一个通用框架，统一了学习历史构建策略与自适应模块的集成方式，支持多种数据构建方式、模型架构与部署任务。
  • 设计了两种策略实例化：VLRLA-simp（冻结 VLM 编码器 + 可训练循环动作模块 RLA，确定性策略，面向仿真/简单任务）和 VLRLA-bridge（复用预训练编码器与随机动作专家，通过修改 KV 缓存的残差桥接模块自适应，面向真实世界/复杂任务）。
  • 支持三种学习历史构建策略：Simulation RL、Human-in-the-Loop Curriculum 与 Hindsight Relabeling。
  • 在仿真与真实机器人上进行了大量实验，证明 VLRLA 可跨多种预训练骨干网络实现自适应，并可泛化到未见任务。
Card 04 方法描述

方法描述

  • 基于 Algorithm Distillation (AD) 思想，训练因果序列模型按顺序学习 RL 算法在历史中的行为演化，使模型在部署时能进行上下文 RL 而无需梯度更新。
  • 采用类似 Transformer-XL 的循环记忆 (Recurrent Memory) 机制，结合局部窗口内的因果注意力与对早期窗口缓存表示的注意力，降低长序列（跨多个回合、数千 token）的显存与计算开销。
  • VLRLA-simp：冻结 VLM 编码器提取前缀嵌入 $z_t^{\mathrm{emb}}$，由可训练 RLA（Transformer + 循环记忆 + MLP）输出确定性动作块，使用 MSE 重建损失训练。
  • VLRLA-bridge：以 $\pi_{0.5}$ 为例，冻结 VLM 编码器与动作专家，可训练桥接模块根据历史交互生成与 KV 缓存同结构的残差 $\Delta z_t$，得到自适应缓存 $z_t'$；采用流匹配目标训练，梯度穿过冻结专家回传到桥接模块。
  • 三种历史构建方法：在仿真中通过 PPO/GRPO 分多轮收集逐步提升的 on-policy 轨迹；人在回路课程从 0 到 1/3、2/3、3/3 逐步增加人工纠正比例；基于 HER 的语言指令重标记，将轨迹重新标注为不同指令下的成功经验。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboTwin，覆盖 6 个已见任务与 6 个未见任务；仿真数据通过 RLinf 在线 RL 采集。
  • 使用的 VLA 骨干/基础模型：π0.5 (Pi05)、LingBot-VLA (lingbotvla)、FastWAM (fastwam)。
  • 真实世界任务：Fruit-Placement（约 80 条遥操作回合 + 3×20 条 HITL 纠正回合）与 Cross-Episode Memory Task。
  • 训练资源：GRPO 基线训练使用 8 张 NVIDIA A100-80G GPU 以支持并行环境中的 on-policy 数据采集。
Card 06 评估与结果

评估与结果

  • 仿真评估：在 RoboTwin 上使用 128 个随机化环境实例，计算平均成功率；上下文长度 $h=4$ 与 $h=8$；每项结果在 5 个随机种子下取平均。
  • 对比方法：监督微调的 π0.5、RL 微调 GRPO、上下文自适应方法 RoboTTT 与 VLRLA-bridge。
  • 关键结果：

- VLRLA-bridge 在全部 12 个任务上均优于 π0.5，整体平均成功率 63.4%（相比 π0.5 提升 +12.4 个百分点），超过 GRPO (60.0%) 与 RoboTTT (58.2%)。

- 已见任务平均 66.2%（相比 π0.5 提升 +17.6%）；未见任务平均 60.6%（相比 π0.5 提升 +7.3%），接近 GRPO 水平。

- VLRLA-simp 可在 π0.5、lingbotvla、fastwam 三种骨干上学习自适应，成功率随交互经验累积而上升。

- 消融显示：无历史 (no history) 时成功率接近零；重复历史 (repeat history) 时无持续提升，证明交互历史及其持续累积的必要性。

- 历史迁移实验表明，将一次 rollout 的历史迁移到同一任务的新 rollout 可将初始成功率从约 0.55 提升至约 0.7（adjust_bottle），从 0.65 提升至 0.85（place_empty_cup）。

  • 真实世界结果：

- Fruit-Placement：随经验累积成功率稳步提升并超过 π0.5；苹果 +13.3%、杨桃 +26.7%、葡萄 +6.7%；在未见物体（红椒 + 金属锅）上同样持续优于 π0.5。

- Cross-Episode Memory Task：在第一回合获得奖励反馈后，成功率明显上升，表明策略可利用跨回合奖励反馈调整后续盘子选择。
