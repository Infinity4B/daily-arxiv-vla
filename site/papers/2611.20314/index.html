02论文概述

  • 提出 NF-VLA，一种基于归一化流（normalizing flow）的视觉-语言-动作（VLA）策略基线
  • 使用单一最大似然目标联合训练视觉-语言骨干和连续动作分布，实现动作采样与基于分数的动作细化共享同一密度模型
  • 解决现有 VLA 动作模型在条件注入与采样细化上的设计问题，展示自回归归一化流在机器人操作上的竞争力

03核心贡献

  • 提出 NF-VLA：端到端训练的归一化流 VLA 基线，仅用一个似然目标训练，学习到的密度同时用于动作采样和基于分数的动作校正
  • 系统评估条件注入的位置与机制：发现仅对深层 flow 块做前缀条件优于对所有块做条件，前缀条件优于 AdaLN
  • 利用 Tweedie 去噪思想，无需单独训练去噪器，即可在推理时对采样动作进行单步自分数校正，提升闭环成功率
  • 在 LIBERO 和 LIBERO-Plus 上验证：LIBERO 四套件平均 98.35%，LIBERO-Plus 零样本 72.6%，与主流 VLA 方法竞争
  • 报告推理效率：FP32 BF16 下 NF 采样约 50 ms，端到端推理约 74 ms，NF 参数 303M

04方法描述

  • 采用 深层-浅层架构：视觉、语言、本体感觉上下文作为前缀只条件深层高容量 block，浅层 block 提供无条件共享的可逆动作变换
  • 使用 自回归仿射流块：交替顺序、因果注意力掩码、旋转位置编码，仿射系数由 Transformer 生成，并通过 tanh 与 softplus 类技巧稳定训练
  • 训练时对动作块添加高斯噪声（σ=0.05），最小化精确负对数似然；推理时采样高斯潜变量后反转 flow，再用学习密度的分数做一步 Tweedie 去噪校正
  • 视觉语言骨干从 SmolVLM-500M-Instruct 初始化，与 flow 联合微调，无辅助预测或表征对齐损失

05数据集与资源

  • 训练数据集：LIBERO 完整数据集，包含 Spatial、Object、Goal、Long 四个套件，每套件 10 个任务
  • 评估数据集：LIBERO-Plus，共 10,030 个扰动任务实例（相机、机器人初始状态、语言、光照、背景、噪声、布局）
  • 动作表示：动作块长度 H=10，动作维度 d_a=7（3 平移、3 旋转、1 夹爪）
  • 模型规模：NF 参数约 303M（AdaLN 变体约 483M）；主干为 SmolVLM-500M-Instruct，总参数量论文未直接给出全模型总数
  • 训练资源：4 张 B200 GPU，全局批大小 256
  • 推理资源：单张 RTX 4080 SUPER GPU，FP32 配合 BF16 autocast；端到端每动作块约 74.10 ms

06评估与结果

  • 评估基准：LIBERO 四套件（每任务 50 次试验，共 2000 次）和 LIBERO-Plus 零样本鲁棒性
  • 主要指标：任务成功率（success rate, %）
  • LIBERO 结果：平均 98.35%；Spatial 97.4%、Object 99.8%、Goal 98.4%、Long 97.8%，总体在对比模型中排名最高
  • LIBERO-Plus 结果：平均 72.6%；机器人初始状态 53.8%、光照 96.9%、布局 83.7%，在光照和布局扰动上表现突出
  • 消融结果：移除分数细化平均成功率下降 1.90 个百分点；深层条件改为所有块条件下降 1.20 个百分点；前缀条件替换为 AdaLN 下降 4.30 个百分点
