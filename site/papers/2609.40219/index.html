Card 02 论文概述

论文概述

  • 论文提出 Action Experience Dictionary（AED，动作经验字典），用于 World Action Models（WAMs，世界动作模型），从历史动作轨迹中学习可复用的操作技能。

Card 03 核心贡献

核心贡献

  • 提出可学习的 Action Experience Dictionary（AED），将历史动作轨迹编码为视觉条件化的动作嵌入，使模型能利用操作任务间的隐含关联指导动作预测。
  • 设计视觉条件化动作嵌入机制，通过跨注意力将压缩后的历史视觉特征注入检索到的动作嵌入，使动作表示同时包含任务交互上下文和动作意图。
  • 引入 Motion-Aware Transition（MT）损失，监督随机时间间隔上的视觉特征变化预测，鼓励 AED 捕获动作相关运动，降低对无关背景线索的依赖。
  • 提供时序组合误差界定理（Theorem 1），证明 MT 损失控制的采样损失可与未来间隔的组合误差建立上界，为跨时间尺度的一致监督提供理论支撑。
  • 在仿真基准和真实世界跨本体（cross-embodiment）设置中验证了 AED 的有效性，一致优于现有 WAM 基线。
Card 04 方法描述

方法描述

  • 基于 flow matching 框架联合训练视频专家和动作专家，遵循 Fast-WAM 的建模方式，同时预测未来视频潜变量和动作 chunk。
  • 动作聚合：将历史动作轨迹按观测间隔聚合（累加机械臂命令、保留末端夹爪命令），解决动作频率与视觉观测频率不匹配问题。
  • AED 检索：使用预训练动作 tokenizer 将聚合后的历史动作映射为索引序列，从共享字典中检索对应动作嵌入，平均后加上位置编码得到时序动作表示。
  • 视觉条件化：用可学习 query 通过多头交叉注意力将历史视觉 patch tokens 压缩为固定数量的视觉 token，再以字典编码器（交叉注意力 Transformer）将视觉上下文注入动作嵌入。
  • 动作前缀注入：视觉条件化后的动作嵌入与噪声动作 token 拼接，送入动作专家预测动作 chunk，从而利用跨任务技能关系。
  • 训练损失：总损失为 flow-matching 损失与 MT 损失之和，MT 损失通过三层层级预测器从起始视觉特征和 AED 条件化动作隐藏状态预测视觉特征变化。
  • 推理：视频和动作潜变量从高斯噪声初始化，使用 flow-matching ODE 的 Euler 步去噪生成动作 chunk；不需要解码像素视频，也无需评估 MT 预测器。

Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率（Success Rate），仿真基准中 LIBERO 每个任务 50 次 rollout、RoboTwin 2.0 每任务 100 次试验，LIBERO-Plus 共 10,030 次试验。
  • LIBERO-10 消融：完整模型成功率 97.4%；移除 MT 损失为 96.8%，移除视觉条件化为 95.6%，移除 AED 为 94.8%，验证各组件均有效。
  • 真实世界 OOD 实验：在 Spirit AI MOZ1 和 ROKAE AR5 平台上，模型在杂乱背景、低光、未见物体等扰动条件下成功率均高于 LingBot-VA、Fast-WAM 等基线。
  • 推理延迟：在 LIBERO 上 1 步 Euler 延迟约 167.3 ms，4 步约 284.6 ms；对比实验中，Ours 在 LIBERO Goal 约 518.7 ms、MOZ1 约 520.3 ms，明显优于 Motus（2131.6/2163.7 ms）并接近 Fast-WAM，同时保持了更高的成功率。
