Card 03 核心贡献

核心贡献

  • 提出 G²WAM，一种新颖的隐式世界动作模型（World Action Model），联合预测潜在未来状态与可执行动作块（action chunks），避免昂贵的 CEM 式规划与像素级重建。
  • 提出新的空间上下文注入范式：不做显式几何重建，而是通过端到端定位网络将观测帧与目标帧锚定在共享场景坐标系，为导航历史与相对目标提供连续、几何一致的空间上下文。
  • 设计相对位姿条件（pose conditioning）与因果运动条件（motion conditioning）双通道机制，并引入规范运动适配器（canonical-motion adapter）将规范预测转换为平台可执行动作。
  • 整个 rollout 完全在潜在空间中进行，显著降低推理成本，兼顾精度与效率。
  • 在四个轨迹预测基准与闭环导航任务上取得最优结果，并承诺开源以惠及社区。
Card 04 方法描述

方法描述

  • 场景坐标锚定：使用端到端定位模块（默认 R-SCoRe）估计当前、目标与历史帧在共享场景坐标系 S 中的位姿，进而组合出当前到目标的相对变换与连续运动增量，得到相对位姿 p_t 与运动剖面 m_t。
  • 隐式世界动作模型：采用冻结的 DINOv3 编码器将观测历史与目标图像映射为 patch 潜变量；Transition 模块融合潜变量历史、目标嵌入与相对位姿条件，经 pool 后与位姿/运动嵌入相加得到步骤状态 s_{t+k}；联合解码器 𝒥 同时输出下一潜变量候选与规范路点增量 (Δx, Δy, Δθ)。
  • 残差潜变量更新：将解码器输出与基础转移结果按系数加权后经层归一化，追加到定长潜变量历史，实现自回归 rollout，无需图像解码。
  • 条件与动作适配：相对位姿条件分离平移与旋转（含 log(1+d_t) 距离项），运动条件编码中位步长、平均偏航变化及数据集级尺度；规范运动适配器按历史运动尺度将规范预测解归一化为平台动作。
  • 训练目标：多项目标函数 L = λ_z L_z + λ_a L_a + λ_traj L_traj + λ_yaw L_yaw，其中潜变量损失为余弦项加 MSE 项，动作损失为带转弯加权（weight w_{b,k}）的 smooth-ℓ1；使用 AdamW，batch size 32，零权重衰减，梯度范数裁剪为 10。
  • 关键创新点：定位模块与世界动作模型解耦且可插拔，模型仅消费相对变换与近期因果运动，因此定位网络可为任意端到端方法或传统地点识别+位姿估计流程。
Card 05 数据集与资源

数据集与资源

  • 轨迹预测数据集：RECON、SACSoN、TartanDrive、SCAND，每个数据集使用 100 个固定测试查询（跨方法共享）。
  • 零样本迁移数据集：Go Stanford。
  • 闭环导航数据集：Gibson 验证集的 100 个固定 ImageGoal 回合，场景为已知的 Mosquito，运行于 Habitat-Sim 仿真器；这些回合与用于微调导航模型、训练定位接口的同场景轨迹不重叠。
  • 模型规模：潜变量维度 D=384，上下文长度 H=4，rollout 步数 k∈{0,…,7}（8 步），视觉骨干为冻结的 DINOv3。
  • 定位模块：默认 R-SCoRe，在 RTX 2080 上每次查询耗时 140–270 ms，(0.25 m, 2°) 阈值内成功率 64.3%。
  • 推理效率测试资源：NVIDIA H800 PCIe GPU，使用 bfloat16 与 batch size 16。
Card 06 评估与结果

评估与结果

  • 评估指标：

- 轨迹预测：ATE（8 步后终端位置平均欧氏距离）、RPE（每步路点增量平均欧氏误差）。

- 闭环导航：SR（成功率）、SPL（路径长度加权成功率）、DTG（最终测地距离，≥1 步后低于 2 m 即发 STOP）。

- 效率：单步与 16 步 rollout 延迟、动作选择耗时。

  • 对比基线：GNM、NoMaD、NWM、DINO-WM、DreamerV3、LeWM、LS-NWM、EvoWorld、Geometry Forcing（Spatial-perceiving WAM、NavWAM、WAM-Nav 因官方实现未开源未做定量比较）。
  • 轨迹预测结果：G²WAM 在四数据集上平均 ATE/RPE 为 1.82/0.46，相对次优基线分别降低 40.1% 与 35.2%；在 SACSoN 与 TartanDrive 上提升最显著；在 RECON 上与基线相当，在 SCAND 上因跨平台运动、操作者差异与动态行人导致定位性能受限而退化。使用真值位姿的 G²WAM-GT 平均 ATE/RPE 达 0.78/0.28，显示更优空间上下文下的巨大潜力。
  • 零样本迁移（Go Stanford）：无空间上下文时与基线相当（ATE 2.3096 / RPE 0.6510），说明模型具备一定通用导航先验；加入位姿辅助后 ATE/RPE 分别改善 14.0%/16.5%。
  • 闭环导航结果：G²WAM 达到 SR 63.0%、SPL 59.2%、DTG 3.39 m；相较最强基线 DINO-WM（SR 54.0%、SPL 36.4%），SR 提升 9.0 个百分点、SPL 提升 22.8 个百分点，最终 DTG 比 LeWM（4.51 m）低约 25%。G²WAM-GT 达 SR 71.0%、SPL 70.0%、DTG 3.04 m。
  • 消融实验：位姿与运动信息均为必要；使用 R-SCoRe 时二者带来 ATE/RPE 平均增益 39.1%/35.2%，使用理想位姿或外部定位时可扩大至 73.9%/60.6%（Pose+motion 的 GT+GT 组合平均 0.78/0.28，完全无条件时退化为 2.99/0.71）。
  • 运行时分析：G²WAM 单步 4 ms、16 步 47 ms、动作选择 0.51 s；与最优 L-WM 方法效率相当，在动作选择上明显优于 NWM（10.98 s）、Geometry Forcing（541.23 s）、EvoWorld（150.26 s）等；其中定位耗时 0.42 s，优于 EvoWorld 几何上下文编码的 0.57 s，而 EvoWorld 因每次 CEM rollout 都需重编码几何上下文，整体动作选择高达 8.7 s。
