PhysWAM: Physically Consistent World Action Model for Autonomous Driving

2026-09-29 · 原文 · 翻译 · 2609.37970

PhysWAM 是一个用于自动驾驶的统一世界动作模型（World-Action Model），能够在单个流匹配 transformer 中联合去噪多视角视频、度量深度和自车运动（ego motion）。 核心问题：联合生成世界未来状态与动作并不必然保证两者共享同一几何约束，导致预测的深度和运动缺乏物理一致性。 论文提出 Coupled Point Projection (CPP)，通过生成的深度和运动与 LiDAR 测量几何对齐，显式耦合二者，从而在训练时同时监督两个任务，并在推理时利用简单的无标签共识规则完成轨迹选择。

Card 03 核心贡献

核心贡献

  • 统一世界动作生成：提出共享的流匹配公式，在一个模型中联合去噪多视角视频、度量深度和自车运动，避免了独立的深度生成器。
  • 物理一致性几何耦合（CPP）：通过将生成深度反投影为 3D 点并用生成的 SE(3) 运动变换，与 LiDAR 在记录运动下变换得到的测量几何比较，形成单一几何损失，同时监督深度与运动预测。
  • 简单推理与广泛评估：使用无参数的中位数轨迹选择（medoid selection）替代学习型评分器或仿真器反馈，并在 NAVSIM v1/v2、navhard 两阶段仿真和 HUGSIM 零样本闭环驾驶中取得强结果。
  • 改进深度与规划质量：CPP 同时提升了规划指标（PDMS/EPDMS）和度量深度预测的准确性，验证了几何耦合的有效性。
Card 04 方法描述

方法描述

  • 基于 Cosmos 3 预训练世界模型（Mixture-of-Transformers 架构，源自 Qwen3-VL），微调生成路径（7.0B 参数），冻结文本路径和视频 VAE。
  • 视觉表征使用冻结的因果视频 VAE 编码 RGB 和深度，深度以 log-depth 编码映射到图像通道；动作采用预训练的位姿表示（平移 + Gram–Schmidt 正交化的旋转向量）。
  • 条件化通过 Plücker ray embeddings（校准射线嵌入）和 mRoPE 位置编码实现，RGB 与深度共享射线信息，动作按时间对齐。
  • CPP 流程：深度头直接将估计的干净深度 latent 映射为度量深度，未投影到 3D，用生成运动变换，再与记录运动下 LiDAR 投影的点云计算 Huber 损失；支持多个未来锚帧和多相机。
  • 辅助几何铰链损失（障碍物、可行驶区域）监督轨迹位置；采用输出梯度平衡（output-gradient balancing）调整各几何损失幅度；推理时使用 UniPC 采样（30 步），从 K=8 个样本中选取中位数轨迹。
Card 05 数据集与资源

数据集与资源

  • 训练数据：NAVSIM navtrain 分割，共 103,281 个窗口，每窗口包含当前帧及未来 8 帧（2 Hz），来自前视、左前、右前三相机。
  • 测试/评估数据：NAVSIM navtest（12,146 场景）、navhard（450 记录场景 + 5,462 合成场景）、HUGSIM（436 个闭环 episode）。
  • 额外训练标签：密集度量深度、LiDAR 目标、障碍物与可行驶区域标注（仅训练使用）。
  • 模型规模：初始化自 Cosmos 3 Nano（总参数 15.2B），微调生成路径 7.0B 参数，其余部分冻结。
  • 训练资源：30,000 步更新，batch size 44，使用 NVIDIA RTX PRO 6000 Blackwell GPU，AdamW 优化器，峰值学习率 2×10⁻⁵，线性衰减至 0，并评估 EMA 权重。
Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 评分（PDMS）和 v2 评分（EPDMS），由官方 devkit 计算；navhard 两阶段伪仿真；HUGSIM 零样本闭环驾驶（无目标域微调）。
  • 主要指标：PDMS、EPDMS、navhard 分数、HUGSIM 路线完成率（RC）和 HD-Score。
  • 关键实验结果：

- 在 NAVSIM navtest 上，PhysWAM（单样本）在不同子指标上表现稳健，样本间标准差仅为 0.24 PDMS 和 0.30 EPDMS。

- 与 Epona、PWM、DriveVLA-W0 等世界模型/世界动作模型相比，PhysWAM 取得了具有竞争力的规划分数。

- 零样本迁移到 HUGSIM 环境无需任何目标域训练，展示了跨域驾驶泛化能力。

- CPP 消融实验表明，加入 CPP 可同时提升规划（PDMS/EPDMS）和深度预测精度；中位数轨迹选择优于单样本生成。

- 推理成本：30 步采样每场景约 9.4 GPU-秒，8 步仅需 4.4 GPU-秒且性能差异在一个百分点以内。
