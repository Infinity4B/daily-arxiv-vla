Beyond Success Rate: Interventional Evaluation of Memory in Vision-Language-Action Systems

02论文概述

  • 论文提出 Interventional Memory Evaluation Protocol（IMEP），旨在超越单纯的任务成功率，评估视觉-语言-动作（VLA）系统中的记忆是否真正被使用
  • 解决的核心问题是：成功率消融无法区分信息与计算的变化，且聚合成功率会掩盖相互抵消的增益与损失
  • 论文评估三类记忆：within-episode（回合内）、cross-episode（跨回合） 和 agentic（智能体文本记忆），发现学习到的记忆库存在结果敏感性但未建立事实特异性

03核心贡献

  • 提出 IMEP 协议，回答四个问题：净收益（Q1）、帮助条件（Q2）、结果敏感性（Q3） 和 事实特异性（Q4）
  • 构建 ChainBench 基准，要求正确决策依赖当前观测中缺失的历史信息，且决策正确性与电机执行分开评分
  • 对 within-episode、cross-episode 和 agentic 记忆进行干预评估，发现学习记忆库存在结果敏感性但未证明事实特异性
  • 在 ChainBench 上，完整记忆配置将任务成功率从 39.1% 提升至 74.3%，在共享记录执行下与 oracle 决策条件一致

04方法描述

  • IMEP 使用配对设计，比较记忆访问（A）、无记忆（N）和 oracle（O），并引入控制条件：

- C：精确复现参考记忆

- U：一位最低有效位（one-ULP）数值扰动

- S：相同事实的替换记录

- T：不同事实的替换记录

  • 评估指标包括：

- 净收益 D_X = SR_A − SR_X

- 结果敏感性 ρ_X（配对结果翻转比例）

- 事实特异性 θ = ρ_T − ρ_S（不同事实与相同事实替换的敏感性差异）

  • 决策与电机执行结果分别计算，不合并
  • ChainBench 使用多回合链条：写入回合揭示物体所在抽屉，干扰回合写入其他记录，查询回合关闭抽屉且外观观测保持一致，机器人需在冻结的 π₀.₅ 策略 执行前选定抽屉

05数据集与资源

  • 使用 MIKASA-Robo 的 Shell Game 与 Remember Color 任务评估 learned memory banks
  • 使用 SimplerEnv 的 Fractal 和 Bridge 任务进行回合内记忆消融
  • 使用 LIBERO 构建 ChainBench，主实验含 202 条链（K=2），辅助实验含 143 条链（K=3）
  • 跨回合评估使用社区 MemoryVLA checkpoint 及 structured-PCMB 配置
  • 论文未提供模型参数规模与具体 GPU/TPU 训练硬件配置；评估在机器人模拟器上完成

06评估与结果

  • 回合内 Shell Game 黑屏：读取记忆将成功率从 69.5% 提升至 73.5%（D=+4.0 pp），但低于预设 10 pp 净收益标准；视图可用时增益 +0.5 pp 不显著
  • Shell Game 黑屏干预：置换（S_π）和重采样（T_μ）分别改变 6.75%/7.25%（released）和 6.00%/7.00%（structured）的结果；one-ULP 改变 1.00%/2.50%；精确复现改变 0/400
  • 事实特异性：不同事实替换相对相同事实替换的额外敏感性 θ 为 +0.50 pp（released）和 +1.00 pp（structured），均不显著
  • 跨回合：清除 attempt-1 记录、清空持久读取、清除过期记录、Bridge 跨尝试记忆携带均未检测到净收益；训练记忆插件反而降低成功率 −8.2 pp
  • Remember Color 条件：RC3 成功率 34.0%，RC5 23.5%，接近单次选择随机基准；T/S 替换分别改变 55/388 和 51/388 结果，θ̄=+1.03 pp，CI 在 ±7.5 pp 等价带内
  • ChainBench：完整记忆配置在 202 条链 上实现 100% 决策准确率，任务成功率从 39.1% 提升至 74.3%，达到共享记录执行下的 oracle 成功上限
