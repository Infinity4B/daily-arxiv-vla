Card 03 核心贡献

核心贡献

  • 提出统一的 P³-WAM 模型，同时集成 3D 交互重建、动作条件世界预测与目标引导的世界–动作联合规划，并承诺开源代码与模型权重。
  • 提出统一训练框架，通过 mixture-of-transformers（MoT） 架构与随机模态可见性（randomized modality visibility），把预训练视频先验与结构化 3D 动作表征连接起来。
  • 实验证明感知、预测、规划三者通过统一训练相互增强，在三个任务上均超越对应的专用基线，并给出人手动作迁移到真实灵巧机器人的演示。
  • 构建了紧凑的结构化 3D 动作表征（双手 MANO 姿态 + 相机位姿），每帧仅用三个 token（相机 / 左手 / 右手）表示。
Card 04 方法描述

方法描述

  • 以预训练视频扩散 Transformer Wan2.2-Fun-A14B-Control 为骨干，保留其潜空间视频表征、文本与首帧条件、骨架控制通路，以及高/低噪声双扩散专家。
  • 采用 MoT 架构：RGB 专家与动作专家共享基座投影权重，动作专家额外加入模态特定的 LoRA 与归一化；两路 token 通过双向视觉–动作注意力相互访问对方的 key/value。
  • 观测动作通过两条互补路径注入：渲染的手部骨架视频（经同一 VAE 编码后与噪声 RGB 潜变量拼接）提供空间对齐控制，紧凑动作 token 则携带状态进入联合注意力。
  • 相机条件使用首帧相机坐标系下的逐像素 Plücker 光线图，经轻量卷积适配器映射到 DiT patch 特征空间。
  • 手部使用 MANO 参数化模型，预测全局/局部旋转、序列级形状、相机空间根位置、手部存在概率与关节点可见性；动作分支一次前向预测完整轨迹，缺失动作用可学习 query embedding 表示。
  • 训练时随机变化视频与动作的可见性：给视频隐藏动作 → Perceive；给动作隐藏未来视频 → Predict；两者皆隐藏 → Plan；视频用 flow matching 损失、动作侧用参数/空间/时序/存在性/相机多项目标。
Card 05 数据集与资源

数据集与资源

  • 四个第一视角数据集：EgoDex（EgoDex-MANO）、ARCTIC、HOT3D、EgoLive。
  • 模型基于 Wan2.2-Fun A14B-Control（约 14B 量级）初始化，含冻结的预训练动作自编码器与冻结 MANO 层。
  • 单模态与统一模型的对比实验在 5,000 训练步、其他变量固定的条件下进行。
  • 推理时使用图像生成器产生视觉子目标（visual subgoals），分窗口推进长时序任务。
Card 06 评估与结果

评估与结果

  • Perceive：报告存在性感知的 MPJPE-p（相机空间、去根 RR、Procrustes 对齐 PA）与手部可见性 F1，对比 HaMeR 与 Dyn-HaMR；在四个数据集上误差均最低，宏平均相机空间误差 63.05 mm vs HaMeR 145.34 mm / Dyn-HaMR 231.54 mm，RR 22.54 mm vs 46.61/45.25 mm，PA 11.79 mm vs 16.75/32.94 mm，F1 99.16% vs 91.78%/89.68%。
  • Predict：对比 Wan2.2-Fun-Control、DreamDojo、Hand2World、EgoSim，用全帧 PSNR/SSIM/LPIPS/CLIP-I/FVD 与手部区域指标评估；在 EgoDex、ARCTIC、HOT3D、EgoLive 上均取得最优结果。
  • Plan：采用 VLM 评分（动作过程、指令遵循、物理交互、时序/身份一致性、目标过渡，1–5 分），统一训练在五个维度全面优于 Plan-only 基线，其中时序/身份一致性从 2.15 → 3.57、目标过渡从 1.98 → 3.29。
  • 统一训练增益：相比单模态训练，Perceive 的相机空间、根相对与 PA 误差分别降低 23.46%、14.23%、5.69%；Predict 的 PSNR 由 17.356 → 18.138 dB，FVD 由 1105.95 → 1009.84。
  • 机器人部署：生成的类人动作可迁移到真实灵巧机器人执行，验证了从人类视频到机器人操作的可行性。
