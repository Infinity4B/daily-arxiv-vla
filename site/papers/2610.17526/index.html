Box-WAM: Box Trajectories as Compact State Representations for World Action Models

02论文概述

  • 论文研究世界动作模型（World Action Models, WAMs）中未来状态表示的选择问题，即机器人应当"想象"何种未来状态以提升动作预测。
  • 现有 WAM 多用稠密未来视频帧作为预测目标，表达力强但计算代价高，且需要预测背景纹理、光照等与操作策略无关的视觉细节；隐状态表示虽轻量但难以可靠学习且不可解释。
  • 提出 BoxWAM，用任务相关物体的有向 3D 边界框轨迹（box trajectories）替代稠密未来帧，作为紧凑、可解释且物体中心的状态表示来引导动作生成。

03核心贡献

  • 提出 box trajectories 作为面向 WAM 的可解释、物体中心的未来状态表示。
  • 提出 BoxWAM：一个基于 rectified-flow transformer 的模型，通过状态引导的注意力（state-guided attention）联合生成未来框轨迹与动作。
  • 设计因果状态-动作注意力结构：动作 token 可关注未来状态 token，但未来状态 token 不能关注未来动作 token，使框轨迹成为引导动作生成的物体运动规划。
  • 在仿真（RoboTwin2.0）与真实机器人上验证，证明在更低的未来建模成本下获得更好的动作预测性能。
  • 展示 box 轨迹预测可作为插件集成进预训练 VLA 模型 π0.5，在匹配数据与训练步数下带来一致增益。

04方法描述

  • 未来状态表示为被主动操作物体的最小体积有向 3D 包围盒八个角点在第三人称相机视图下的图像平面坐标，即 $\mathbf{x}_t\in\mathbb{R}^{16}$；双臂场景为左右臂分别维护 box slot，空槽置零并在状态损失中掩码。
  • 使用冻结的 DINOv3 视觉编码器提取视觉上下文 token，与含噪的未来 box token、动作 token 拼接为单一 transformer 序列，每个未来时间步分配一个 box token 与一个 action token。
  • 采用 rectified-flow 目标在联合未来变量上训练，损失为状态与动作两项预测误差的加权和（$\lambda_X=\lambda_A$）；流时间步按 Beta 分布采样（$u\sim\mathrm{Beta}(1.5,1.0)$，$\tau=0.999(1-u)$）以偏向更嘈杂的训练点。
  • 推理时从 $\tau=0$ 到 $\tau=1$ 用欧拉积分求解 rectified-flow ODE，采用二次积分调度 $\tau_k=1-(1-k/N)^2$ 在 $\tau=1$ 附近分配更多步数。
  • 动作采用关节位置控制（相对关节位置命令）或末端执行器控制，预测视界 $H=15$（单任务仿真）或 $H=50$（多任务与真实世界）；训练时用未来接触顺序构造监督目标，推理时不依赖真值框与接触顺序。
  • 关键创新：用紧凑物体运动替代稠密视频预测，并通过注意力掩码实现"先想未来、再生成动作"的因果耦合。

05数据集与资源

  • 仿真数据集：RoboTwin2.0，包含 clean 与 randomized（Hard）两种设置；单任务每任务 50 条演示，多任务共 50 个任务、每任务 50 条演示（合计 2,500 条）；另有 27,500 条演示的对比实验。
  • 真实世界数据：UFACTORY xArm7 单臂机器人、第三人称场景相机与腕部相机，通过 GELLO 遥操作采集人类演示；三个任务各采集 50 条演示；真值框由 RGB-D、已知网格与相机标定重建（附录 A）。
  • 使用预训练模型：π0.5（多任务与对比实验）、π0、DP3、Diffusion Policy、ACT 作为基线；视觉编码器为冻结的 DINOv3；消融中比较 Wan2.2 VAE 与 DINOv3 ViT-L token。
  • 模型规模：集成到 π0.5 时约 3.35B 参数。
  • 训练资源：RTX Pro 6000 Blackwell GPU；多任务对比训练 30,000 步，27,500 演示实验训练 35,000 步。

06评估与结果

  • 评估环境：RoboTwin2.0 仿真（clean 与 randomized 设置）与真实机器人三个任务（Make Coffee、Water Plant、Place Pokemon）。
  • 主要指标：任务成功率（SR）；真实世界额外报告子目标进度率（progress rate）；同时报告推理延迟（ms）与模型规模。
  • 单任务仿真（Table 1）：BoxWAM 在 clean 设置平均 78.3%（仅次于使用深度的 DP3 的 81.2%），在 randomized 设置取得最高平均成功率 37.8%，优于 action-only Flow（32.6%）、π0（33.1%）、DP3（5.1%）与 ACT（6.3%）。
  • 多任务仿真（Table 2）：π0.5 + BoxWAM 将 clean 成功率从 52.6%→61.5%，randomized 从 26.9%→34.0%，延迟仅由 55.3 ms 增至 57.7 ms。
  • 真实世界（Table 3）：BoxWAM 平均 60.9%，优于 action-only（51.1%）与 Diffusion Policy（23.7%）。
  • 消融（Table 4/5）：box 轨迹在 randomized 设置取得最高成功率，优于 VAE、DINO token、6D 姿态、2D OBB、功能关键点与末端轨迹；状态-动作交互中"Future then action"设计最优（clean 78.3%、randomized 37.8%）。
  • 与现有 WAM 及 IK 基线比较：BoxWAM 以更小训练预算在 easy/hard 设置分别达 87.94%/87.62% SR，延迟 64.9 ms；使用 Mink 与 M2T2 的差分 IK 基线仅 26.78%/26.30%。
  • 局限：依赖可靠的目标跟踪以获取监督标签，在严重遮挡、高度可变形物体或框信息不足的任务上可能退化。
