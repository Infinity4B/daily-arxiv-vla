02论文概述

  • 提出 Spatial-UMI-Dream：一个 5B 空间世界动作模型（WAM），利用 605 小时 RGB-D UMI 数据，通过两阶段训练联合预测未来 RGB、鱼眼对齐的度量深度与机器人动作。
  • 针对 UMI 腕部移动相机无固定外部视角、RGB 难以显式表达精确操控所需度量几何的问题，引入度量深度使场景尺度与空间关系更明确。
  • 同时引入 RoboTwin-UMI：包含 20 个任务的仿真基准，支持在环境变化和机器人本体迁移单独及联合条件下，对 UMI 策略进行受控、可重复评估，且无需额外微调。

03核心贡献

  • 提出 Spatial-UMI-Dream：5B 空间 WAM，在 605 小时 RGB-D UMI 数据上两阶段训练，联合预测 RGB、度量深度与动作，在仿真和真实世界均取得最高成功率。
  • 构建 RoboTwin-UMI：基于 RoboTwin 的 20 任务基准，提供腕部鱼眼观测与统一协议，支持环境鲁棒性和跨本体泛化的单独及联合评估，无需额外微调。
  • 通过匹配的 RGB-only 消融证明度量深度的重要性：引入深度后，in-domain 成功率提升 5.75 个百分点，联合环境与本体偏移下提升 8.25 个百分点。
  • 设计两阶段训练策略（世界适配 + 联合世界-动作训练），消融显示从 Wan2.2 直接微调 39.50% 提升至世界适配 61.25%、联合训练 79.10%；并设计轨迹过滤和部署夹爪补偿以连接手持演示与机器人执行。

04方法描述

  • 度量 RGB-D 表示：利用 GenRobot DAS UMI 三相机系统，取中间和右相机构成立体对，使用 Fast FoundationStereo 计算视差并恢复度量 Z 深度，映射回中间相机原始鱼眼图。
  • 深度编码与画布：对深度做固定范围归一化后采用 Turbo 三通道彩色映射；将左右夹爪的 RGB 和深度按 2×2 网格组成 320×320 双夹爪 RGB-D 画布，使用 Wan2.2 VAE 编码为统一视频 tokens。
  • 联合世界-动作建模：基于预训练 Wan2.2-TI2V-5B，在共享 transformer 中通过块因果注意力对视频潜变量和动作块联合去噪，采用加权流匹配目标优化视频和动作损失；训练中使用 teacher forcing。
  • 两阶段训练：第一阶段仅优化世界预测（未来 RGB-D 帧），适配 UMI 运动鱼眼观测和固定布局；第二阶段从第一阶段检查点初始化，加入动作流和机器人状态条件，联合优化世界损失与动作损失。
  • 轨迹过滤与部署补偿：通过逆运动学在 Dexmate Vega1 和 ManiSkill 中回放演示，过滤不可行或速度/加速度/加加速度超限的轨迹；部署时对夹爪命令做一阶响应模型求逆补偿，以对齐期望与真实钳口开合。
  • RoboTwin-UMI 构建：将 Aloha-AgileX 和 ARX-X5 安装统一 UMI 夹爪与腕部鱼眼，基于四视角共光心 pinhole 投影和 Kannala-Brandt KB4 方程合成鱼眼图；随机光照设置用于环境泛化测试。

05数据集与资源

  • 预训练数据：605 小时 RGB-D UMI 数据，由两个物体抓取集合和一个更广泛的高质量操作集合组成，按有效轨迹步占比采样；世界适配使用全部来源片段，联合训练仅使用过滤后带动作监督的片段。
  • 模型规模：5B 参数，基于 Wan2.2-TI2V-5B 初始化，冻结文本编码器、图像编码器和视频 VAE，训练完整 DiT；动作维度 20，动作块 chunk size 24。
  • 训练资源：预训练两阶段各 30k updates，每阶段 batch size 192，使用 24 张 NVIDIA RTX PRO 6000 GPU；真实世界微调 22.5k updates / batch 64 / 8 GPU；RoboTwin-UMI 微调 10k updates / batch 128 / 8 GPU。
  • 下游数据：仿真每个任务用 50 条干净 Aloha-AgileX 演示；真实世界 6 个任务，每个任务评估 20 条完整 episode。

06评估与结果

  • 评估环境：RoboTwin-UMI 20 任务，覆盖物体放置、堆叠、关节物体交互与双臂动态操作；跨本体设置 Aloha-AgileX 与 ARX-X5；环境变化为清洁光照与随机光照。
  • 主要指标：完整 episode 成功率 SR 和平均进度 Score；仿真每任务每设置 100 episodes，真实世界每任务 20 episodes。
  • 仿真 in-domain：Spatial-UMI-Dream 在 Aloha 清洁光照下平均成功率为 79.10%，比最强基线 π₀.₅（74.45%）高 4.65 个百分点；最强 WAM 基线 Fast-WAM 为 61.20%。
  • 泛化：随机光照 Aloha 为 73.35%；ARX X5 随机光照联合偏移为 72.15%，分别比最强基线高 7.20 和 10.30 个百分点；跨本体迁移的下降幅度最小，与 π₀.₅ 的差距拉大到 14.00 个百分点。
  • 真实世界：六个真实任务平均成功率 85.0%，平均进度 93.2%，超过最强基线 π₀.₅（60.8%）24.2 个百分点；其中 Bimanual Handover 从 π₀.₅ 的 45.0% 提升到 80.0%。
  • 消融：RGB-only 预训练在 in-domain 减少 5.75 个百分点、联合偏移减少 8.25 个百分点；直接微调 Wan2.2 为 39.50%，世界适配后 61.25%，联合世界-动作训练后 79.10%。
