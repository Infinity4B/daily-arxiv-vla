When Do Discrete Actions Make Good Continuous Controllers?

2026-10-14 · 原文 · 翻译 · 2610.20429

论文挑战了机器人领域的一个普遍共识——机器人基础模型（如 VLA、WAM）应当以连续向量表示动作，转而系统性地研究离散动作表示能否与连续表示相竞争甚至更优。 论文聚焦于动作头（action head） 的设计，比较 4 种代表性参数化方式在单任务模仿学习、多任务 VLA 训练、仿真与真实硬件等多场景下的表现。 核心论点是：离散动作策略的瓶颈并非动作精度，而是由时间维度和动作维度上乘积分布预测引入的因子分解误差（factorization error）。

Card 03 核心贡献

核心贡献

  • 发现 1（控制精度）：与既有认知相反，离散动作参数化（即使是最朴素的均匀分箱离散回归 DR）在任务成功率上可匹配甚至超越连续策略；这源于其对动作块内时间步和条件观测具有更强的响应性（reactivity）。
  • 发现 2（迭代精化与引导）：因子分解误差是离散策略的真正瓶颈；离散流（DF） 通过迭代计算、无分类器引导（CFG） 通过分布锐化，可以从互补机制上将其缓解——在 RoboCasa 上 CFG 将 DR 成功率从 27.1% 提升至 49.2%。
  • 发现 3（显式几何与结构化分词收益有限）：显式注入几何信息或使用替代分词器仅改善部分配置，均未超过使用均匀分箱与标准混合路径的最佳 DF 结果；相邻分箱能自发学到相似的输出嵌入，说明离散头可隐式学习局部几何。
  • 论文提供了对近期离散扩散/流 VLA 策略性能来源的更深入理解，并质疑了机器人动作预测必须与其他 AI 模态采用不同设计决策的假设。
Card 04 方法描述

方法描述

  • 比较四类动作头参数化：连续回归（CR）、连续流（CF）、离散回归（DR）、离散流（DF）。
  • 动作在末端执行器空间（EEF space） 表示，包含 3 维平移、旋转（VLA 用轴角 3 维、RoboMimic 用 6D 旋转矩阵表示）与二值夹爪坐标。
  • 离散化：将每一动作坐标归一化并裁剪后量化为 B=512 个均匀分箱，扁平化得到长度为 L=HM 的 token 序列，解码时返回分箱中心。
  • DR 采用逐 token 交叉熵训练、逐位置贪心解码；DF 基于离散流匹配（Gat et al., 2024），通过多步迭代更新 token，从乘积源分布出发进行 token 替换。
  • 无分类器引导（CFG）：用学习到的空条件与条件预测组合，对离散头用 p^{1+λ} p_∅^{-λ} 锐化，对连续流作用于速度场；CR 因只输出单一块而不施加引导。
  • 通过 Jerk Ratio（预测动作块三阶差分与专家动作块之比的均值）度量时间变化，通过状态响应性（∂π/∂o）与扰动稳定性度量对条件观测的响应程度。
Card 05 数据集与资源

数据集与资源

  • RoboMimic：单任务模仿学习基准，使用 Can、Square、Tool Hang、Transport 四个任务（后两者需高精度控制）。
  • RoboCasa / RoboCasa365：包含 MimicGen 生成演示，评估分为 atomic-seen、composite-seen、composite-unseen 三类。
  • LIBERO / LIBERO-plus 与 DROID：DROID 无仿真器，仅用于离线诊断。
  • 真实世界任务：抛瓶子入箱、打开笔帽、翻转杯子三项任务。
  • Push-T：用于可视化因子分解误差机制。
  • 骨干网络：多任务 VLA 采用 PaliGemma VLM（π 系列模型所用）；单任务从零训练使用无预训练 VLM 的独立策略。
  • 训练数据混合来自 8 个来源：六个 RoboCasa365 数据集、LIBERO-plus、DROID。
Card 06 评估与结果

评估与结果

  • 评估环境覆盖从零训练的单任务策略、仿真 VLA-scale 任务、真实世界 VLA 任务，以及离线诊断分析。
  • 主要指标：闭环部署下的任务成功率，留出验证集上的平均 ℓ₂ 动作预测误差，动作块内的Jerk Ratio 与状态响应性，以及模式混合数与动作多样性（W₉₀ 宽度）。
  • RoboCasa 对比中，DF 53.9% ≥ CF 52.7% > DR（CFG 2）49.2% > CR 38.8%，显示离散流已与连续流相当甚至略优。
  • DR 在所有基准上始终优于 CR，且在单任务从零训练场景即成立，推翻了“离散策略仅在 VLA 分词骨干下占优”的假设。
  • 各参数化的 ℓ₂ 重建误差大致相近且与任务成功率无稳定相关性，说明性能差异并非来自精度，而来自对时间/输入变化的建模能力。
  • DF 相对 DR 将不兼容模式数量降低 5.28 倍（NFE≥10 时平均不足 1），并带来 RoboCasa 成功率 +4.7 个百分点；CFG 虽能锐化分布，但几乎不改善 EEF 误差（不超过 1 mm），进一步佐证其作用在于减少因子分解误差而非提升预测精度。
