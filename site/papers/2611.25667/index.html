02论文概述

  • 提出 CauSyncVLA，一个面向异步机器人控制的因果潜世界建模框架，旨在解决视觉-语言-动作（VLA）策略中视觉推理延迟导致的感知记忆过时和动作块不连续问题。
  • 通过双系统控制架构（慢速视觉流 + 快速控制流），利用因果潜世界模型预测当前感知记忆（KV memory），并结合动作敏感蒸馏保持冻结专家的控制响应。
  • 在预测记忆的基础上引入 Predictive Flow Warm-Starting (PFWS)，以单步流修正对齐未执行的动作轨迹，无需额外训练，显著提升闭环鲁棒性和动作平滑性。

03核心贡献

  • 执行基础异步控制：将异步控制形式化为感知记忆预测与轨迹修正的耦合问题，在冻结 VLA 骨干上降低反馈延迟。
  • 因果、动作相关的潜世界建模：在潜前缀空间中将延迟 KV 锚点沿已执行的状态-动作历史传播，通过动作敏感蒸馏监督残差更新，恢复控制相关的感知条件。
  • 无训练预测性轨迹修正：提出 PFWS 重用未执行动作区间作为流先验，通过单步冻结专家欧拉步骤细化轨迹，抑制块边界模式切换。
  • 完整的理论分析与实验验证：在 LIBERO-10 和 LIBERO-Plus 数据集上验证方法，并在真实 Franka FR3 机械臂上进行物理部署，展示优于基线的性能。

04方法描述

  • 双系统异步架构：System 2 慢速视觉流周期发布 KV memory anchor；System 1 快速控制流使用 Causal Latent World Model \(W_\theta\) 预测当前 KV memory，并根据预测记忆进行动作细化。
  • 因果潜世界模型：\(W_\theta\) 是一个 24.27M 参数的 AdaLN transformer，以延迟 KV anchor 和已执行的历史状态-动作序列为输入，通过标准化、历史嵌入、自适应 LayerNorm 和残差更新预测当前 KV memory。
  • 预测性流热启动 (PFWS)：将未执行动作块平移并重复末端动作，与噪声在中间流时间插值，在预测 KV memory 条件下通过冻结流专家执行单步 Euler 修正，实现轨迹连续性和上下文对齐。
  • 动作敏感蒸馏：联合优化 KV 回归损失 \(\mathcal{L}_{\mathrm{KV}}\) 和动作损失 \(\mathcal{L}_{\mathrm{act}}\)，其中动作损失使用冻结专家输出的一阶近似进行加权，使 KV 误差对控制动作的影响最小化。

05数据集与资源

  • 数据集：LIBERO-10（500 个原生起点）、LIBERO-Plus（2,519 组配对扰动测试）、以及真实机器人演示数据集（10 Hz 时间戳适应的离线训练数据）。
  • 模型：冻结的 π0.5 骨干和流动作专家；Causal Latent World Model \(W_\theta\) 含 24.27M 参数，训练 12k 步，模拟地平线 \(H=10\)，步幅 \(C=5\)，PFWS 因子 \(\rho=0.5\)。
  • 训练与推理资源：模拟环境使用专有 RTX 5090 GPU 进行单 GPU 闭环执行评测；物理实验使用 7-DoF Franka FR3 机械臂，配置双 D405 相机，在 100 Hz 命令上限和 30 Hz 视觉感知下运行。

06评估与结果

  • 主要评估基准：在 LIBERO-10 上评估任务成功率与模型推理能力；在 LIBERO-Plus 上评估鲁棒性；在 20 Hz 定时闭环执行下评估响应延迟与完成率；在真实机器人上验证物理部署效果。
  • 任务成功率：CauSyncVLA 在 LIBERO-10 上达到 93.8% 成功率，超过同步 π0.5 基线的 91.2%，以及 PFWS-only 的 93.0%，与 VLA-Rolling 的 93.4% 相当但延迟更低。
  • 推理能力与延迟：模型批一推理延迟从同步 π0.5 的 60.01 ms 降至 11.91 ms（CauSyncVLA 快循环），推理吞吐量提升约 5.04 倍；单 GPU 闭环响应延迟从同步的 176.73 ms 降至 83.04 ms，控制速率提升至 16.60 actions/s。
  • 动作相关预测效果：在 320 个保留窗口上，因果潜世界模型将下游动作 MSE 从过时 anchor 的 0.10355 降至 0.00983（降低超过 10 倍），KV 误差从 0.42430 降至 0.31958。
  • 消融实验：逐步消融执行历史信号（年龄、端点状态、打乱顺序）表明完整因果历史对降低动作误差至关重要；PFWS 和动作敏感蒸馏均对性能有正向贡献。
