02论文概述

  • 提出 Latent-WAM++，一种以表示为中心的端到端自动驾驶世界动作模型（WAM）。
  • 现有 WAM 主要监督未来状态或最终动作，中间世界表示与动作表示仅被间接约束；本文旨在按规划角色匹配各表示的监督信号，联合塑造世界与动作表示。
  • 通过 WoRC、TrajMF、VARA 三个组件解决表示退化、动作表示未对齐与规划效率低等问题。

03核心贡献

  • 提出角色匹配的表示学习原则：世界表示应编码场景动态、保持非退化分布并保留几何信息；动作表示应直接参数化轨迹；显式正则化视觉-动作接口。
  • 设计 World Representation Construction (WoRC)：结合场景-未来预测、SIGReg 分布稳定化和冻结几何先验，无需 EMA 目标编码器即可学习时序可预测、非退化、几何感知的世界表示。
  • 设计 Trajectory MeanFlow Planner (TrajMF)：直接预测多模态轨迹提议，并采用 Improved MeanFlow 速度空间目标实现一步采样生成。
  • 设计 Visual-Action Representation Alignment (VARA)：将动作表示与当前视觉语义进行非对称对齐，提升规划相关特征的表达能力。
  • 在 NAVSIM v2 和零样本 HUGSIM 上取得最优结果，并将端到端规划器训练成本降低 88.1%。

04方法描述

  • WoRC：使用 DINOv2 编码多视图图像为视觉 token；利用冻结的 WorldMirror 教师进行几何蒸馏；通过冻结的 occupancy 提取器提供占用 token；动态世界模型预测未来场景-ego 隐状态；SIGReg 对视觉 token 分布进行无 target 正则化。
  • TrajMF：在轨迹空间中使用条件流匹配，采用多峰高斯混合先验；网络直接预测去噪轨迹，并通过 JVP 在诱导速度空间中计算瞬时速度进行监督；采样时一次前向生成多个轨迹提议，再由 refiner 聚合。
  • VARA：将轨迹提议特征投影并平均，与 stop-gradient 的当前视觉平均特征进行余弦相似度对齐，保持语义一致性而不强制逐元素相等。
  • 训练损失由 world、action、align 三部分加权组成；推理时仅使用模态编码器和 TrajMF，不依赖额外传感器。

05数据集与资源

  • 主要数据集：NAVSIM v2（开环轨迹规划评估）
  • 零样本数据集：HUGSIM（闭环多难度评估）
  • 视觉编码器：DINOv2；几何教师：WorldMirror；占用信息来自冻结 occupancy 提取器
  • 训练硬件：H20 GPU；端到端训练规划器约 190 GPU-hours
  • 采用 SIGReg 替代 EMA target encoder，避免约 86.6M 额外参数（EMA 变体需 +86.6M 参数）

06评估与结果

  • 在 NAVSIM v2 上取得 90.1 EPDMS，超过 Latent-WAM 的 89.3、MeanFuser 的 89.5、Drive-JEPA 的 87.8 等 SOTA 方法。
  • 在 HUGSIM 零样本闭环评估中，平均 RC 47.0、平均 HD-Score 30.1，均优于 Latent-WAM 的 45.9/28.9。
  • 消融实验表明 SIGReg 比无稳定器和 EMA 更有效防止视觉 token 分布退化；VARA 能改善动作表示与视觉语义的一致性。
  • 端到端训练规划器成本从 1600 GPU-hours 降至 190 GPU-hours，降低 88.1%。
