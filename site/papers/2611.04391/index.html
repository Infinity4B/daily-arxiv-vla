Card 02 论文概述

论文概述

  • 提出 H2RB（Human-To-Robot Bridge）框架，旨在利用易于收集的人类演示来适应预训练的 VLA（Vision-Language-Action）策略，减少对昂贵目标机器人演示的依赖。
  • 解决人类与机器人之间的 embodiment gap：预训练 VLA 主要基于机器人数据，直接利用人类演示面临感知和动作空间双重不匹配问题。
  • 通过桥接表示空间和动作空间，使人类演示能够为机器人策略提供有效行为监督，同时保留预训练 VLA 的视觉、语义和控制先验。
Card 03 核心贡献

核心贡献

  • 提出 H2RB 框架，结合 手部几何锚定对齐（geometry-anchored alignment）和 解耦解码器潜在分词器（decoupled-decoder latent tokenizer），在无配对数据的情况下桥接人类与机器人。
  • 手部几何锚定对齐利用手腕-指尖几何信息将 VLM 特征跨 embodiment 对齐，减轻感知差距，无需配对演示、轨迹匹配或图像合成。
  • 解耦解码器潜在分词器共享动作潜在空间，同时为每个 embodiment 保留独立解码器，避免将人类和机器人运动动态折叠到单一动作映射中。
  • 在真实世界任务中，H2RB 显著提升物体迁移（8.0 → 51.8）、技能迁移（62.7，基线为 0.0）以及 OOD 迁移（6.0 → 45.3）。
  • 展示 H2RB 在异构多 embodiment 训练和下游仅机器人适应中的益处，例如 RB-Y1 成功率从 64% → 78%。
Card 04 方法描述

方法描述

  • 使用共享的 wrist-hand 参数化将人类和机器人动作表示为统一格式（手腕位置、6D 旋转、手部关节角度）。
  • 训练一个变分动作自编码器：共享编码器将动作块映射到潜在空间，embodiment 特定解码器重建动作；通过位置级质心匹配、方差和协方差正则化对齐人类和机器人潜在分布。
  • 手部几何锚定 VLM 条件化：在 VLM 特征上添加残差适配器，并用训练时 readout 预测手腕位姿和五个指尖位置，使用 masked Smooth-L1 损失监督，使条件化特征具有跨 embodiment 几何一致性。
  • 采用 条件流匹配（conditional flow matching）在潜在动作空间中进行策略学习；部署时使用人类解码器将生成的潜在动作转换为机器人可执行命令。
Card 05 数据集与资源

数据集与资源

  • 使用 OpenArm 人形机器人（配备 Inspire 手）进行真实世界实验，基础策略为 RLDX-1-IMG 预训练 VLA。
  • 人类演示通过 HaWoR-based 重建管线获取，并统一到手腕-手部表示；机器人演示来自 OpenArm 和 RB-Y1 机器人。
  • 评估任务包括 OpenArm 上的物体迁移（Box、Ball、Towel 等）和技能迁移（Open/Close），以及 RB-Y1 上的包裹翻转/搬运任务。
  • 异构多 embodiment 训练涉及 OpenArm 和 RB-Y1 的混合数据；具体模型参数量未明确给出，但基于 RLDX-1-IMG 的 VLA 架构。
  • 训练资源依赖 GPU（致谢提及“Advanced GPU Utilization Support Program”）。
Card 06 评估与结果

评估与结果

  • 评估环境与基准：在真实世界 OpenArm 和 RB-Y1 上进行评估；基线包括 Base policy human-only、in-domain-only、co-train，以及 + HaWoR-shared action 和 + Ego-Pi-shared action。
  • 主要评估指标：OpenArm 任务采用加权任务得分（0-100），RB-Y1 采用二元成功率（50 次试验）。
  • 关键实验结果：

- 物体迁移：H2RB 平均得分 51.8，相比 Base policy co-train 的 8.0 提升 43.8；在 OOD 放置偏移下，H2RB 得分 45.3 vs. 基线的 6.0。

- 技能迁移：H2RB 达到 62.7（Open: 50.7, Close: 74.7），而所有 co-train 基线均为 0.0。

- 异构训练扩展：OpenArm 物体迁移提升至 57.2，技能迁移提升至 81.7；RB-Y1 成功率从 robot-only 的 64% 提升至 human-robot HT 的 72%，以及 geometry-grounded HT 的 78%。

- 附加指令条件化进一步提升技能迁移至 83.3。

- 动作 tokenizer 和跨域潜在回归显著降低人机潜在差距（从 3.81 到 1.53）并改善迁移性能。
