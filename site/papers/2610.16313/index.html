02论文概述

  • 论文提出 ListenVLA，一个基于 GR00T N1.7 构建的音频条件化视觉–语言–动作（VLA）策略，用于声音引导的机器人操作。
  • 解决的问题是：许多操作任务依赖视觉观测无法可靠推断的听觉线索（如哪个物体在发声、何时开始动作、容器内是否有物体），而这些线索有时必须通过物理交互（抓取、摇晃、按压）才能主动获得。
  • 核心目标是让预训练 VLA 策略能够利用听觉证据在视觉信息不足时消解动作歧义，即将声音差异可靠地映射为动作选择差异。

03核心贡献

  • 提出 ListenVLA：在 GR00T N1.7 上融合语义音频嵌入（CLAP）与波形声学线索（能量及其时序变化），通过音频 token 与特征调制（AdaLN + Output FiLM）条件化连续动作生成。
  • 提出 音频–动作绑定（audio–action binding）目标：利用上下文匹配的演示对，在固定非音频观测与相同纯噪声输入的条件下，用短时域演示动作差异监督不同音频条件下的 flow-velocity 预测差异。
  • 提出 LIBERO-Audio 八任务基准：覆盖基于声音的目标选择、事件触发响应、以及需通过交互揭示声学证据的任务，其中目标选择任务使用视觉完全相同的候选物体，使声音成为必要信息。
  • 通过对比实验、消融研究、受控音频交换测试与三个真实世界任务验证方法的有效性。
  • 音频交换测试结果表明：ListenVLA 的动作预测会随音频变化而改变，而无音频的 GR00T 基线保持不变。

04方法描述

  • 时序音频表示：将过去 2 秒划分为 3 个重叠的 1 秒窗口；每个窗口用冻结的 CLAP 产生语义嵌入，并计算声学线索 r_k = [R_k, B_k, ΔR_k, ΔB_k]（对数 RMS 幅度、200–4000 Hz 对数能量及其相邻窗口差），标准化后裁剪到 [-5, 5]，并由相对窗口年龄嵌入 e_k 编码时序。
  • 时间编码器：两层 Transformer + 掩码均值池化，得到音频上下文 z_t；不完整窗口（含依赖它的差分）被掩码。
  • 动作网络条件化：每窗口的 CLAP 嵌入与声学线索投影为独立 token，z_t 投影为 12 个上下文 token，共 18 个音频 token 与冻结 VLM token V_t 拼接，经归一化与自注意力融合；音频 token 进入 DiT 的非图像注意力分支。
  • 双重调制路径：音频上下文以残差形式加入 flow-time 嵌入以条件化 AdaLN（α=0.1），并通过 Output FiLM（η=0.5）调制动作解码前的最终特征；两条路径均受音频有效性门控。
  • 音频–动作绑定训练：离线标记锚点（运动起始、声学转换、平动反向），在同类任务其他演示中检索上下文匹配的供体（末端位置 12 mm、SO(3) 0.20 rad、夹爪开度 4 mm、前 4 步轨迹 RMSE < 12 mm、8×8 图像指纹 RMSE ≤ 0.20），并施加最小动作差异与最小声学/频谱差异约束。
  • 受控音频替换：在 τ=0 处用共享噪声 ε̃_i 做两次前向，仅替换音频历史，监督 Δv_ij 与演示动作差 A_i - A_j 在前 8 步上的一致（共享噪声在相减时抵消）。
  • 总目标：L = 2·L_all + L_bind，绑定项按上下文置信度 c_ij = exp(-D_ij) 与声学/CLAP 分离度加权，权重不参与梯度；配对选择与辅助前向仅在训练时使用，部署时只用单一条件策略。

05数据集与资源

  • LIBERO-Audio：基于 LIBERO 扩展的八任务基准（T1–T8）；演示集共 960 个 episode（T1–T4 各 60，T5–T8 各 180），动作采集频率 20 Hz，音频 16 kHz。
  • 仿真环境使用 Franka Panda 机械臂，配外部相机与腕部相机，末端虚拟单声道麦克风；音频合成含距离衰减、麦克风指向性、传播延迟与简化桌面反射。
  • 真实世界数据：Franka Panda + Intel RealSense D435 相机 + BOYA 迷你麦克风（近夹爪安装），每个任务 15 次评估试验。
  • 训练配置：从 GR00T N1.7 微调 100,000 次更新，batch size 16，AdamW，学习率 5×10⁻⁵，余弦衰减，5% warm-up，权重衰减 10⁻⁵；视觉–语言主干与 CLAP 保持冻结（只训练音频模块、动作侧融合与动作网络）。

06评估与结果

  • 评估环境与基准：LIBERO-Audio 八个任务，每任务 50 个闭环 episode，每 16 步动作查询一次、控制频率 20 Hz、上限 2000 控制步；另有受控音频交换测试和三个真实机器人任务。
  • 对比基线：适配到 LIBERO-Audio 的 HEAR（保留音频历史处理与未来音频预测目标）与 ManiWAV（逐任务训练、无语言输入、仅外部相机）；消融配置 A（GR00T 无音频）、B（去掉音频–动作绑定）、C（去掉音频调制）、D（完整 ListenVLA）。
  • 主要指标：闭环任务成功率（%）；音频交换测试使用解码动作块的平均绝对差 D_swap（16 步 × 7 维）。
  • 对比结果：ListenVLA 平均成功率 66.25%，显著高于 HEAR 33.00% 与 ManiWAV 13.25%；在 8 个任务中的 7 个取得最高成功率（如 T2 96.0%、T4 94.0%、T3 86.0%）。
  • 困难任务：需通过交互获取声学证据的 T5（抓取并摇晃盒子）与 T8（按压触发警告音）成功率仅 32.0% 与 20.0%，仍是难点。
  • 消融结果：去掉绑定目标使平均成功率从 66.25% 降至 38.25%；同时去掉音频条件化 AdaLN 与 Output FiLM 降至 59.25%；无音频 GR00T 仅 31.25%，说明绑定监督与音频调制均有显著贡献。
  • 音频交换测试：ListenVLA 的 D_swap 为 0.06214，ManiWAV 为 0.05812，HEAR 为 0.02931，无音频 GR00T 为 0.00000，表明 ListenVLA 的动作生成确实受声音影响（跨模型比较受各自原生历史差异限制）。
  • 真实世界结果：R1 声音盒选择 11/15（73.3%），R2 延迟提示音响应 13/15（86.7%），R3 含铃盒识别 9/15（60.0%）。
