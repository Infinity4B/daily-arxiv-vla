The Right Future for Action: Learning Action-Relevant Predictive States in World Action Models

02论文概述

  • 研究世界行动模型（WAM）中预测性状态的表示：应保留何种未来信息以支持下游动作预测
  • 通过表征诊断发现：更高的未来可预测性不一定带来更好的动作可读性；观察到的未来变化提供了当前表示中缺失的动作相关信息；动作可读性在空间上高度集中
  • 提出 Action‑Relevant Predictive States (ARPS)，将紧凑的状态接口与多尺度未来表示监督相结合，以提升分布内和分布外控制性能

03核心贡献

  • 首次系统诊断了预测表示的“可预测性”与“动作可读性”之间的关系，揭示二者可能分离，并量化了未来帧提供的额外动作信息及空间集中特性
  • 提出 ARPS，一个 horizon‑conditioned 的状态预测器，将中间视频特征压缩为紧凑的状态，并用 frozen V‑JEPA2 教师提供的绝对和差分未来表示进行监督
  • 验证了紧凑状态设计在多个基准上的有效性：ARPS 在 LIBERO 上达到 99.2%，在 LIBERO‑Plus 上 zero‑shot 达到 87.3%（超过 Fast‑WAM 39.2 个百分点），在 RoboTwin 2.0 上保持整体性能并降低推理延迟
  • 通过消融实验确认未来表示监督（尤其是多时间尺度和绝对+差分目标）对分布外泛化的关键作用

04方法描述

  • 基于 Fast‑WAM 架构，在视频专家的中间层插入 horizon‑conditioned state predictor
  • 该 predictor 使用可学习的查询（按未来时间步分组）通过交叉注意力从当前帧特征聚合出固定数量（如 32 个）的 state tokens，构成预测性状态 \(Z_t\)
  • 训练时，使用 frozen V‑JEPA2 教师提取多个未来时刻的表示，计算绝对未来表示和相对当前的变化（差分）作为监督目标，通过位置查询解码器从对应时间的 state tokens 解码
  • 损失包含余弦相似度与 smooth L1 的组合，联合优化绝对表示和差分表示
  • 推理时仅保留视频专家前 \(\ell\) 层的状态提取，移除教师和解码头，动作专家直接从 compact state 预测动作片段

05数据集与资源

  • 训练与评估数据集：LIBERO（四个任务套件）、LIBERO‑Plus（无适应迁移）和 RoboTwin 2.0（双机械臂操作）
  • 模型规模：视频专家为 Wan2.2‑TI2V‑5B，动作专家为 1B ActionDiT（从视频专家初始化）；ARPS 额外增加一个三块 transformer 的状态预测器（约 32 个 state tokens）
  • 教师模型：frozen V‑JEPA2（用于提供未来表示目标）
  • 训练资源：未明确说明 GPU 数量，但使用大规模视频扩散模型进行端到端训练，推断需多 GPU 并行

06评估与结果

  • 评估基准：LIBERO 情景成功率（Spatial, Object, Goal, Long 套件）；LIBERO‑Plus 的七种分布外扰动（Camera, Robot, Language, Light, Background, Noise, Layout）；RoboTwin 2.0 的 Clean 和 Random 设置
  • 主要指标：任务成功率（%），LIBERO‑Plus 上还报告总体零样本成功率
  • 关键实验结果：

- LIBERO：ARPS 平均成功率 99.2%，超过 Fast‑WAM（97.6%）和 LingBot‑VA（98.5%）

- RoboTwin 2.0：Clean 91.32%、Random 90.10%，与 Fast‑WAM 总体持平但 Clean 上略微提升

- LIBERO‑Plus：总零样本成功率 87.3%，大幅优于 Fast‑WAM（48.1%）和 Cosmos‑Policy（82.2%）；在 Camera 和 Noise 扰动下提升尤为显著（分别 +74.3 和 +58.0 个百分点）

- 消融实验表明：去除未来监督、使用 VGGT 或 DINOv2 教师、减小状态容量或改变提取层都会显著降低 LIBERO‑Plus 性能，未来差分监督和较远的预测时间步对泛化尤其重要
