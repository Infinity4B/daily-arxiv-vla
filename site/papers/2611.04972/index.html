论文概述

Card 03 核心贡献

核心贡献

  • 提出 双层 caging 架构：将高层 VLM/VLA 输出视为导航提案，与低层物理安全执行解耦
  • 设计 安全保证的运动规划器：低维 Bézier 参数化 MPPI 结合 SDF 基 dEBF 约束，在给定假设下提供可证明的碰撞避免保证
  • 提出 SDF-based dEBF 安全方案：用多球近似机器人 footprint，仅靠 SDF 值查询，限制接近障碍物的速率，确保安全集前向不变
  • 在 Unitree G1 人形机器人和 Ghost Robotics Vision 60 四足机器人上开展大量真实世界实验，验证跨平台迁移性和安全性
  • 集成开放词汇对象中心 grounding（Grounding-DINO + SAM2），改善语义终点对齐
Card 04 方法描述

方法描述

  • 语义 grounding 层：VLA/VLM 处理自然语言指令并输出离散高层动作（如左转 15°、前进 25cm），Kinematic Goal Projector 将其映射为地图中无碰撞目标位姿
  • 对象中心 grounding：使用 Grounding-DINO 和 SAM2 检测分割语言指定目标，投影到 3D 全局坐标，实现目标相对接近和停机
  • 物理 grounding 层：人形平台使用 FastLIVO2 进行 LiDAR 惯性里程计，四足平台使用不变 EKF 融合腿运动学和 IMU；环境由增量更新的 SDF 表示
  • 低维 Barrier-Certified MPPI：用 Bézier 曲线参数化控制序列，MPPI 采样优化；dEBF 代价引导采样，硬 rollout 认证加一步安全备份策略保证执行安全
  • dEBF 约束：对每个球形几何点定义离散指数屏障条件 \(h(x_{k+1})\ge \gamma h(x_k)\)，并与 MPPI 结合；由定理证明安全集的前向不变性
Card 05 数据集与资源

数据集与资源

  • 硬件平台：Unitree G1 人形机器人、Ghost Robotics Vision 60 四足机器人
  • 仿真环境：Gazebo，仿真 Vision 60、LiDAR 和真值里程计
  • 传感器：RGB 相机、IMU、LiDAR（G1 使用高质量 LiDAR，Vision 60 使用 VLP16）
  • 语义前端模型：ChatGPT 5.6 Luna、Gemini 3.5 Flash、Claude Fable 5、NaVILA
  • 计算资源：NVIDIA A4500 执行建图与运动规划栈
  • 关键参数：dEBF 衰减参数 \(\gamma=0.95\)；MPPI 使用 200 个样本、10 次优化迭代；规划步长 0.05 s，horizon 为 50 步（2.5 s）
Card 06 评估与结果

评估与结果

  • 评估指标：SR（成功率）、CR（碰撞率）、E2E SR（端到端成功率）、Object SR（对象成功率）、NE（导航误差）
  • 受控消融（G1，无 JPS）：CR 从 80% 降至 0%，E2E SR 从 15% 提升至 40%
  • 受控消融（G1，JPS + 突发障碍）：CR 从 100% 降至 0%，E2E SR 从 0% 提升至 70%
  • 端到端扩展（G1）：简单任务 CR 从 0.33 降至 0.00，复杂任务 CR 从 0.50 降至 0.00；SR 保持 0.75
  • 跨平台迁移（Vision 60）：简单任务 CR 从 0.67 降至 0.20，复杂任务 CR 从 0.91 降至 0.08，同时 SR 提升
  • 系统级 caging（12m×12m，四个语义前端）：未 caging 60/60 全部碰撞，caging 后 0/60 碰撞
  • 对象中心 grounding（Vision 60）：平均导航终点误差从 1.50 m 降至 0.29 m
  • 剩余碰撞主要来自未观测几何（细线、桌沿、传感器盲区），与定理对环境和状态估计的假设限制一致
