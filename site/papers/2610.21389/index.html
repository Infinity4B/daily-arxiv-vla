Card 02 论文概述

论文概述

  • 针对 VLA（视觉–语言–动作）策略普遍在每个动作块预测时重复运行数十亿参数骨干模型、导致控制回路推理成本高昂的问题，提出 Fast-VLA——"You Only Think Once"。
  • 核心洞察：任务理解的变化速度远慢于机器人状态变化，因此任务上下文只需建立一次，而闭环控制需持续响应。
  • 目标是在保持闭环操控性能的同时，将冻结的大模型移出重复控制回路，大幅降低摊销推理延迟与显存占用。
Card 03 核心贡献

核心贡献

  • 提出回合级（episode-level）VLA 架构：将一次性的任务理解表示为固定的多层 KV 记忆，使冻结的 4B VLM 只做一次预填充后退出控制回路。
  • 设计在线 actor：融合可学习查询与实时视觉、本体感知反馈生成动作查询，跨 VLM 深度检索任务上下文，在单次前向中预测整个动作块。
  • 在 RoboTwin 2.0、LIBERO 和 LIBERO-Plus 上验证该解耦设计能保持有竞争力的闭环性能，同时将 RoboTwin 摊销推理开销降低 10.9–17.1 倍。
  • 通过受控的记忆替换干预实验，验证 actor 确实依赖与当前回合匹配的任务记忆。
Card 04 方法描述

方法描述

  • 阶段一（任务记忆构建）：给定指令 L 与初始多视角图像 I₀，冻结的 DM0.5 4B VLM 执行一次预填充，保留全部 34 层 Transformer 的 key/value 张量构成任务记忆 M₀。
  • 阶段二（在线 actor）：由视觉编码器、查询融合、动作解码器和动作头组成；输入当前视角、本体状态及可选的短视觉历史。
  • 查询融合（Query Fusion）：为每个未来时间步 τ（0–49）与机械臂 a（左/右）初始化可学习时间嵌入与臂嵌入之和，再与各臂 7 维状态投影、腕部视角 CLS token 融合，经门控残差 MLP 生成动作查询。
  • 动作解码（Action Decoding）：4 层解码器，每层含 Self 注意力（协调双臂与未来时间步）、Cross-Visual 注意力（读取当前与历史视觉 token）、Cross-Memory 注意力（检索固定任务记忆）与 FFN。
  • KV 记忆适配器：每层解码器学习对 34 个记忆层的权重分数并经 softmax 归一化，通过 RoPE 对齐后加权混合 key/value，再用分组查询交叉注意力读取。
  • 动作头：线性头一次预测 50×14 的双臂绝对关节指令块，无需迭代去噪；单臂 LIBERO 使用 10×7 动作块且不使用视觉历史。
  • 训练：仅训练在线 actor（含 DINOv2 初始化的视觉编码器），损失为归一化动作上的 ℓ₁ 损失；VLM 保持冻结，其 KV 缓存离线预计算并复用。
  • 推理成本：每回合一次 VLM 预填充 + 每个动作块一次 actor 调用，摊销延迟为 (T_prefill + ⌈H/K⌉·T_actor)/H。
Card 05 数据集与资源

数据集与资源

  • 数据集：RoboTwin 2.0（50 任务，Clean + Randomized）、LIBERO（4 个套件共 40 任务）、LIBERO-Plus（10,030 个扰动实例）。
  • 模型规模：任务记忆基座为冻结的 4B DM0.5 VLM（34 层）；在线 actor 的视觉编码器基于 DINOv2 初始化并微调，动作解码器与动作头从头训练。
  • 训练配置：学习率 3×10⁻⁴，AdamW + 余弦调度；RoboTwin 批大小 256、200,000 步、约 150 加速器小时；LIBERO 批大小 32、30,000 步、约 5 加速器小时。
  • 显存：RoboTwin 预填充峰值 12.11 GiB，VLM 卸载后在线常驻 1.22 GiB；LIBERO 预填充峰值 11.74 GiB，在线常驻 0.86 GiB。
Card 06 评估与结果

评估与结果

  • 评测协议：RoboTwin 2.0 每任务 100 回合（共 10,000 次 rollout）；标准 LIBERO 每任务 50 个初始状态（共 2,000 次 rollout）；LIBERO-Plus 全部 10,030 个扰动实例。所有推理成本在与基线相同硬件上按统一协议测量。
  • 主要指标：成功率（Clean / Randomized / Standard / Plus）、每块时延（ms/chunk）、摊销每步时延（ms/step）、在线常驻显存（GiB）。
  • RoboTwin 2.0：Clean 92.46%、Randomized 92.40%（均值 92.43%）；每块 44.87 ms、摊销 1.437 ms/step；相比 DM0.5、Faster-WAM (HUST)、Fast-WAM 加速 10.9–17.1 倍（DM0.5 低 1.02 个百分点但快 11.2 倍；Fast-WAM 高 0.60 个百分点且快 17.1 倍）。
  • LIBERO / LIBERO-Plus：标准 LIBERO 95.95%、LIBERO-Plus 79.11%；每块 34.25 ms、摊销 3.975 ms/step；较 Faster-WAM (Noah) 与 Faster-WAM (HUST) 在 LIBERO-Plus 上分别高 4.11 与 5.54 个百分点，且快 3.1 倍与 21.2 倍。
  • 记忆替换实验：交换语言片段降至 35.18%/29.66%；换用同任务其他回合记忆仅 6.26%/8.36%；交换初始视图片段崩至 2.64%/2.62%；换成不同任务记忆仅 0.62%/0.52% —— 证明 actor 依赖与回合匹配的任务记忆。
  • 记忆构建消融：无任务记忆 69.90%/53.69%；仅文本 token KV 93.20%/73.84%；仅最后一层 94.70%/73.70%；完整 34 层最优 95.95%/79.11%。
  • 在线输入消融：无腕部视觉降至 65.60%/33.49%，仅头部视角 70.80%/30.80%，仅腕部 87.10%/68.72%，无本体状态 94.30%/72.41%，完整输入最优 —— 腕部视觉是闭环反馈的关键来源。
  • 记忆刷新频率：每动作块刷新仅使标准 LIBERO +1.80 点、LIBERO-Plus −1.23 点，但 VLM 调用增加 17.37 倍、摊销时间增至 12.391 ms/step（3.12 倍），验证"每回合仅构建一次"是效率与性能的良好折中。
  • 任务时长分析：按步数预算划分的短（S）/中（M）/长（L）任务成功率分别为 94.00% / 90.27% / 90.25%，说明长时程任务中复用一次性记忆依然有效。
