02论文概述

  • 论文针对超低比特（≤2 bit）视觉-语言-动作（VLA）模型在资源受限机器人上的部署难题，指出现有后训练量化（PTQ）方法在 2 bit 以下严重失效
  • 通过分析发现两个根本原因：量化漂移（静态演示数据校准导致 distribution shift）和读出损坏（逐层重建误差忽略动作头实际读出的表示）
  • 提出 LoopQ 框架：结合闭环校准与读出对齐微调，在保持 2 bit 权重格式不变的前提下，将 VLA 模型（含 backbone 与 action head）整体量化到 2 bit 甚至 1 bit，并成功部署于真实机器人

03核心贡献

  • 闭环失效诊断：首次系统地揭示超低比特 VLA 失败的两大机制——量化漂移（quantization drift）与读出损坏（readout corruption），并量化了由策略自身引入的状态分布偏移在总偏移中的主导地位（language model 45%，action head 最高 83%）
  • LoopQ 方法：提出无需训练的闭环校准（利用量化策略自身 rollout 产生的状态估计校准 Hessian）和轻量化的读出对齐微调（冻结 trellis 码，仅优化查找表和缩放因子），两者均不改变存储格式和 bit 预算
  • 端到端 2 bit 及以下量化：首次实现 backbone 与 action head 全部线性层量化到 2 bit 后，在 LIBERO-Plus 上仅落后全精度 1.4–1.6 个百分点；在 1 bit 下仍保持可用策略（π_0.5 完成 80.0% LIBERO 任务），远超现有最强者
  • 真实机器人部署验证：在嵌入式 NVIDIA Jetson AGX Thor 上以整数核运行 2 bit π_0.5，权重体积缩小 4.1 倍，内存占用减少 44%；在 AgileX Piper 机械臂上三个真实操作任务中，成功次数仅比全精度少 1 次（58/75 vs 59/75）

04方法描述

  • 基础格式：trellis-coded quantization (TCQ)

- 沿用 QTIP 的 bitshift 形式：对权重矩阵进行双边随机 Hadamard 变换，切分为 256 权重块，每块编码为通过 2¹⁶ 状态 trellis 的 512-bit 路径

- 解码器以 16-bit 滑动窗口索引 512 条目查找表，结合 per-row 缩放因子输出权重对，通过 Viterbi 搜索与 block-wise 误差反馈优化路径

  • 闭环校准 (Closed-loop calibration)

- 将校准 Hessian 视为不动点问题：\(H^* = \mathbb{E}_{x\sim d_{\hat\pi(H^*)}}[xx^\top]\)，其中 \(d_{\hat\pi}\) 为量化策略诱导的状态分布

- 实际执行一次不动点迭代：从基准初始状态分布出发，运行 256 次 2 bit 策略 rollout 收集 on-policy 状态；同时融合光照增强、随机裁剪，并按 trace 归一化加权合并到 \(H^{\mathrm{demo}}\) 上

  • 读出对齐微调 (Readout-aligned fine-tuning)

- 冻结所有 trellis 码和旋转，仅优化每层查找表 \(T_\ell\)、行缩放 \(s_\ell\) 及归一化权重

- 损失函数对齐量化模型与全精度教师模型的注意力读出 \(W_O o\) 和预测速度 \(v\)，并附加 Frobenius 正则锚点；每步对查找表做 RMS 重归一化以稳定训练

  • 部署格式与推理

- 存储为 packed 2-bit 码流，每层附带一个 512 条目查找表和缩放向量，总 bit 开销 2.02 bpw

- 在 GPU kernel 内以整数矩阵乘执行，8-bit 表与 8-bit 激活支持两种模式：加载时解码或 on-the-fly 解码，bit-exact 复现参考算术

05数据集与资源

  • 模型：GR00T N1.7（432 个线性层：视觉语言 backbone 216 层，1.1B 参数 diffusion transformer head 216 层）；π_0.5（414 个线性层：backbone 288 层，0.3B action expert 126 层）
  • 基准数据集：LIBERO（未扰动，多场景）；LIBERO-Plus（1000 个配对扰动实例，500 个相机视角变化 + 500 个初始状态变化，覆盖 Spatial/Object/Goal/Long 四个套件）；SimplerEnv Bridge（补充材料）
  • 校准数据：256 个演示观测；闭环校准额外使用 256 次 rollout 产生的 on-policy 状态
  • 训练与推理硬件：论文未明确给出训练 GPU 型号（正文提及 RTX 6000 Ada，但未说明用于训练还是推理）；部署平台为 NVIDIA Jetson AGX Thor（嵌入式）和 AgileX Piper 真实机械臂

06评估与结果

  • GR00T N1.7（LIBERO-Plus, 2 bit 全模型）

- 全精度：61.8%；最强基线 QTIP：55.9%；LoopQ 闭环校准仅：57.5%；LoopQ（完整）：60.4%，仅落后全精度 1.4 个百分点，恢复 2 bit 量化造成的损失的 四分之三

  • π_0.5（LIBERO-Plus, 2 bit 全模型）

- 全精度：76.5%；最佳基线 QTIP：72.6%；LoopQ 闭环校准仅：73.4%；LoopQ：74.9%，落后 1.6 个百分点，在 Spatial 套件上超越全精度

  • π_0.5（LIBERO, 1 bit 全模型）

- 最佳基线 QTIP 平均 65.6%，LoopQ 平均 80.0%；在 LIBERO-Plus 上 LoopQ 为 49.8%，比最佳基线（39.9%）高 9.9 个百分点

  • 消融实验

- 仅从单一初始姿态收集 on-policy 状态会使初始状态鲁棒性下降 4.8 个百分点；从基准初始状态分布出发则可同时提升视角鲁棒性并保持初始状态性能

- 闭环校准与读出对齐的效果可叠加：动作误差从 5.70×10⁻³ 降至 4.59×10⁻³（-20%），读出误差降低 13%

  • 真实机器人（AgileX Piper, 2 bit π_0.5）

- 三个任务（精密堆叠、带盖柠檬放置、多物体抓取）共 75 次试验，LoopQ 成功 58 次，全精度成功 59 次

  • 部署效率（Jetson AGX Thor）

- 2 bit π_0.5 + 8-bit 激活：权重体积缩小 4.1 倍，内存占用降低 44%，可在整数核上高效运行
