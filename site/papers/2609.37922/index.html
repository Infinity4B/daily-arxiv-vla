Card 02 论文概述

论文概述

  • 提出 WayFinder，一种端到端、闭环的分层视觉-语言-动作（VLA）框架，用于未知环境下的自主机器人导航。
  • 核心思想是将高层任务推理与低层运动控制解耦，避免传统 VLA 模型因微调带来的巨大计算成本与数据稀缺问题。
  • 解决核心问题：低层 DRL 控制器在复杂、分布外场景中容易陷入死锁（dead-end / infinite loop），而高频加载 MLLM 推理又不现实；WayFinder 仅在被检测到“停滞（stalled）”时才异步调用零样本 MLLM 生成恢复航点。
Card 03 核心贡献

核心贡献

  • 设计了基于 Deep Reinforcement Learning (DRL) 的低层高频运动控制策略，融合深度传感器、GPS 与 IMU 数据，实现实时点对点导航与确定性避障。
  • 提出将状态地图（occupancy grid 渲染为 RGB 图像）与结构化语言提示结合，作为零样本 MLLM（Gemma 3） 的输入，用于战略航点生成与故障恢复。
  • 构建了完整的 Hierarchical VLA edge 框架：低层策略默认运行，仅在检测到停滞状态时才触发高层 MLLM 查询，显著降低推理频率与计算开销。
  • 发布完整的训练/评估数据集与开源代码仓库（OmniNaviPy，https://github.com/WreckItTim/OmniNaviPy），支持后续研究。
Card 04 方法描述

方法描述

  • 低层策略：基于 DQN（Deep Q-Network），状态空间包括滚动时间窗内的 2D 深度图（144×256）、相对 GPS 坐标与 IMU 航向；动作空间为离散的平移（1–32 米）与 90° 偏航旋转。
  • 碰撞避免：确定性短距距离传感器机制，在检测到障碍时于碰撞前停止运动，使得碰撞惩罚从 POMDP 中移除。
  • 状态缓存与离散化：预计算 AirSim 环境中所有可能的 ego-centric 深度图与碰撞布尔状态，将训练时间从数周缩短到数小时。
  • **离线 A\* 路径生成**：利用 A\* 算法生成 ground-truth 路线，按最优步数定义路径难度，并划分训练/验证/测试集。
  • 课程学习（Curriculum Learning）：从简单路径渐进到复杂路径，配合 100 GB 大容量回放缓冲与随机采样缓解灾难性遗忘，并用早停机制冻结最优权重。
  • 高层策略（MLLM）：采用零样本 Gemma 3（4B/12B/27B），输入为彩色编码的视觉状态地图（黑=自由、白=障碍、灰=未知、紫=轨迹、红=历史航点、绿=起点、蓝=机器人、黄=目标）+ 结构化文本提示（含坐标与上下文）。
  • 停滞检测：通过滚动窗口内最大前进距离 Δρ_t 与阈值 ε 比较，判定是否触发 MLLM 查询，避免频繁推理。
  • 全局地图构建：通过相机内参、球面畸变校正与光线投射（ray tracing），将局部深度图转换为三值占用网格，再旋转/平移到全局地图，仅用新观察更新已探索区域。
Card 05 数据集与资源

数据集与资源

  • 仿真环境：Microsoft AirSim 高保真物理/图形模拟器
  • 四个 AirSim 环境：Blocks（低复杂度）、AirSimNH（城市）、CityEnviron（密集都市）、Coastline（最大地图，海岸/海洋）
  • 训练数据：离线 A\* 生成 4,000 条静态 hold-out 测试路径；训练集来自 AirSimNH 环境及其他环境分区
  • MLLM 规模：gemma3:4b、gemma3:12b、gemma3:27b
  • 训练资源：低层 DQN 训练使用预缓存离散状态，100 GB RAM 回放缓冲；高层 MLLM 通过 offboard/edge 计算托管
Card 06 评估与结果

评估与结果

  • 评估方式：AirSim 四环境中闭环导航，完全观察地图（ground truth occupancy grid）与部分观察地图（ray-traced maps）两种配置
  • 导航准确率（整体）：仅低层策略 baseline 为 44.55%–83.71%；加入 WayFinder 高层 MLLM 后提升至 72.00%–96.64%
  • 成功率提升范围：相对 baseline 提升 1.82%–27.45%（与环境及模型规模相关）
  • 恢复率（Recovery Rate）：完全观察地图下，Gemma3:27b 在各环境恢复率提升 +48.03% ~ +77.71%；部分观察地图下提升 +25.08% ~ +80.72%；模型规模越大，恢复率越高、失败恢复率越低
  • 消融实验：移除语言坐标导致恢复率大幅下降至 12.26%（vs 默认 56.79%）；移除航点历史导致重复失败方式（48.02%）；移除视觉地图仅造成中等下降（55.62%）；使用 ground truth 占用网格反而低于 ray-traced 部分观察地图（53.45% vs 56.79%），说明局部视角有助于 MLLM 进行以机器人为中心的推理
  • 计算效率：仅停滞时查询 MLLM，显著减少昂贵推理次数，实现 edge 部署可行性
