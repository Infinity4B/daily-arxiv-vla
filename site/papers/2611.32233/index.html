02论文概述

  • 论文提出 RoboClock，一个面向时间感知机器人智能的统一基准，包含 60 个时间关键操控任务，覆盖 5 个应用领域和 3 个难度等级
  • 针对现有机器人基准侧重空间正确性与逻辑完成、忽略时间约束的问题，将任务分为三类时间要求：时间窗口、事件反应、吞吐量
  • 通过 Latency-Aligned 评估协议将模型推理和接口延迟纳入环境时间推进，结合 PS、PSR、TSR、LTSR 四项指标评估物理成功与时间合规，揭示现有系统在时间推理与实时响应上的根本局限

03核心贡献

  • 构建 RoboClock 基准：60 个操控任务、三大时间约束类别、五个领域（实验室、临床、家庭、工业安全、体育游戏）和三个难度等级
  • 提出 Latency-Aligned Evaluation Framework：标准化协议持续在模型推理和接口延迟期间推进环境时间，并定义 PS、PSR、TSR、LTSR 四项时间敏感指标
  • 系统评估超过 30 种方法（VLA、WAM、VLM agent），发现最佳方法微调 π0.5 在 Easy 级别也仅 8.3% LTSR，揭示物理能力、泛化能力和实时响应能力之间的核心矛盾

04方法描述

  • 分离环境时间 \(t\) 与智能体挂钟时间 \(\tau\)，采用块-重放协议：推理暂停期间保存状态，推理完成后按推理延迟推进环境再执行动作，使动作在陈旧观测下生效
  • 任务设计覆盖三类时间约束：时间窗口要求目标事件在 \([t_s, t_e]\) 内发生；事件反应要求随机触发后 \(\Delta t\) 内响应；吞吐量要求 \(N/T \ge R_{\min}\) 并滚动检查持续服务
  • 使用 Isaac Sim 仿真场景、公开 3D 资产（RoboCasa、Sketchfab）和定制模型，脚本化 oracle 生成演示并验证可行性
  • 四个评估指标：PS 衡量物理进度，PSR 衡量物理成功，TSR 衡量暂停推理下的时间合规成功，LTSR 衡量延迟对齐下的综合成功

05数据集与资源

  • 基准名称：RoboClock，60 个任务，5 个应用领域，3 个难度级别
  • 包含 111 个物体/夹具模型（不含机器人），来自公开库和定制建模，并支持程序化生成指示器、信号灯和计时器道具
  • 微调和评测使用 8× NVIDIA A100 GPU；VLM 智能体实验使用 Qwen3.8-27B 等模型
  • 评估模型包括 VLA（π0.5、X-VLA、InternW0-Δ）、WAM（OpenWAM-α）及多种 VLM agent 框架

06评估与结果

  • 评估环境为 Isaac Sim 仿真，采用块-重放延迟对齐协议，在 Easy/Medium/Hard 三个难度下多种子评测
  • 微调后 π0.5 总体 8.3% LTSR、10.3% TSR、12.8% PSR；最佳 WAM（微调 OpenWAM-α）总体 14.8% PSR、10.0% TSR、3.8% LTSR
  • VLM 智能体零样本迁移表现较好（最高 19.0% TSR），但推理延迟使 LTSR 降至 8.2%，显示其对延迟高度敏感
  • 消融显示训练可提高物理成功率，但对时间约束的泛化仍严重不足，尤其 Throughput 类别几乎所有模型得分为 0
