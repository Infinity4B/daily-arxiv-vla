论文概述

Card 03 核心贡献

核心贡献

  • 提出 DiscoDemo 框架：训练一个特权 latent-conditioned RL 生成器，结合并行反向课程与成功门控多样性目标，在不牺牲任务成功率的前提下发现多种成功解
  • 生成的演示数据集具有更广的成功状态覆盖，在仿真和真实机器人上均显著提升下游 π₀.₅ 模型的模仿学习性能（仿真平均成功率从 40% 提升至 62%，真实机器人从 39% 提升至 78%）
  • 设计安全整形（safety shaping） 与安全过滤（safety filtering） 机制，剔除物理上不可取的交互（如非法接触、容器位移、插入力异常）
  • 证明该方法与 corrective data collection（DAgger、DART）互补，且在相同纠错监督下仍具优势
Card 04 方法描述

方法描述

  • 问题设定：在仿真环境中使用特权状态和重置能力训练生成器；下游策略仅观察视觉和本体感觉，通过模仿学习训练
  • 生成器训练：

- 使用 FlashSAC 算法和源自人演示状态的并行反向课程，从轨迹末端重置点开始逐步扩展解决更长任务段

- 扩展为 latent-conditioned 策略，采样潜变量 \(z \sim \mathcal{N}(0,I)\)，利用 METRA 风格的多样性奖励鼓励不同潜技能产生不同状态空间行为

- 采用成功门控（success-gated）机制，仅对成功完成任务的轨迹施加多样性奖励，防止无约束多样性导向失败模式

- 加入安全惩罚项，减少非必要接触、卡滞力等物理不良交互

  • 演示生成与导出：冻结生成器，从原始任务分布采样初始状态并固定每个 roll-out 的潜变量；过滤失败轨迹和不符合安全判据的轨迹；渲染下游观测并导出为静态数据
  • 下游模仿学习：使用生成数据训练 DROID 预训练的 π₀.₅ 视觉语言动作模型，仅基于观测-动作对进行行为克隆
Card 05 数据集与资源

数据集与资源

  • 任务环境：Isaac Sim 中重建的四个 Franka Research 3 操作任务：PnP-Banana、StackCube、FMB-Round、FMB-SqCircle（包含不同 peg 几何形状的插入任务）
  • 初始人类演示：每个任务 20 条（H20），所有生成方法最终提供 3000 条成功演示
  • 下游模型：DROID-pretrained π₀.₅ 视觉语言动作模型（flow-matching VLA），使用关节空间动作控制
  • 训练资源：单个 GPU 测量端到端 GPU 小时成本；RL 生成器为轻量级状态政策，可在并行仿真中大批量训练
  • 代码与数据：已开源，项目主页及 GitHub 仓库提供
Card 06 评估与结果

评估与结果

  • 评估环境：仿真（50 次评估×3 个微调种子）和真实机器人（20 次试验/任务，零样本部署）
  • 主要指标：成功率（SR）、平均完成时间（Time）、数据多样性与覆盖率（Vendi score）、生成 yield、轨迹效率、端到端 GPU 成本等
  • 关键结果：

- 仿真中 DiscoDemo 平均成功率 62%，显著高于最强基线 40%（P-RFCL 等）；真实机器人平均成功率 78% 对比最强基线 39%

- 在四个任务上均取得最高成功率，且在 PnP-Banana 真实机器人上比最强基线提升 45 个百分点（FMB-Round 仿真提升 23 个百分点）

- 生成数据集具有最高的平均多样性和覆盖率，同时保持较高的生成 yield 和较短的轨迹长度

- 端到端 GPU 成本与其他 RL 基线（PLD、ExpertGen）相比处于中等水平，远低于依赖大型视觉先验的基线

- 多样性强度 \(\alpha\) 存在最优区间：增加多样性提升成功率，但过强多样性会损害任务成功率

- 安全 shaping 与过滤结合能显著减少非法接触和容器位移，并将过滤通过率从 31% 提升至 50%（PnP-Banana）、从 24% 提升至 46%（FMB-SqCircle）

- 与 DAgger、DART 结合可进一步获得收益，证明互补性
