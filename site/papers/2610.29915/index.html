CausalAlign: Causal Alignment of Video Generation Models for Consistent Ego-Motion

2026-10-21 · 原文 · 翻译 · 2610.29915

Card 02 论文概述

论文概述

  • 针对扩散视频生成模型（如 Wan2.2）在长时生成中相机自运动漂移的问题，提出 CausalAlign 框架
  • 通过因果诊断定位自运动信息在 VGM 内部“先升后降”的遗忘位置，再利用 delta-token 对齐强化自运动状态
  • 目标是在保持视觉质量的同时提升相机轨迹的几何一致性和时序平滑性，并改善下游世界动作模型的表现
Card 03 核心贡献

核心贡献

  • 识别出 “几何状态遗忘”（geometric state forgetting） 现象：自运动信息在去噪过程中先被表示和使用，但在后期层和时间步未被保留
  • 提出 CausalAlign，将因果诊断与 delta-token 对齐结合，在诊断出的关键层和时间步强化自运动表示
  • 设计 三阶段 delta-token 对齐：从 3D 基础模型学习紧凑的相邻帧变化 token，训练 VGM 侧投影器，并用 LoRA 适配 VGM
  • 推理时无需外部 3D 缓存或额外几何计算，即可提升相机自运动一致性
  • 在 RoboCasa365 移动操作任务上显著提升下游 Fast-WAM 的成功率
Card 04 方法描述

方法描述

  • 因果诊断：使用线性探针测量可解码性，使用因果干预（Mask/Shuffle/Replace/Inject）测量因果效应，定位自运动信息衰减的 Transformer 层（14、10、12、20）和去噪时间步（398、799）
  • Delta-token 空间：基于流式 3D 基础模型 LingBot-Map 提取连续帧几何状态，学习紧凑的 delta token（128D，包括 64D 自运动、40D 几何、24D 视觉），强调帧间变化而非静态内容
  • 三阶段训练：第一阶段学习教师 delta token；第二阶段训练 VGM 侧投影器；第三阶段在选定层/时间步用 LoRA 更新，使用对齐损失和位姿损失
  • 推理流程与原始 Wan2.2 一致，所有辅助模块仅在训练时使用
Card 05 数据集与资源

数据集与资源

  • 数据集：DL3DV、RealEstate10K（提供相机位姿，90% 训练 / 10% 评估）；下游 RoboCasa365 Target100 和 Human300
  • 模型：基于 Wan2.2-14B-I2V，采用 LoRA 适配器更新，基座模型和 3D 教师模型冻结；教师模型为 LingBot-Map
  • delta token 维度为 128D，显著低于原始 3D 特征（8192D/4096D）
  • 训练分阶段使用 30%/10%/全量训练数据；原文未明确披露具体 GPU/TPU 数量
  • 推理时不引入外部缓存或额外几何计算模块
Card 06 评估与结果

评估与结果

  • 评估基准：DL3DV 和 RealEstate10K 视频生成，VBench-I2V 视觉质量，RoboCasa365 移动操作任务
  • 主要指标：运动幅度（平移/角速度接近度）、几何一致性（重投影误差、深度-光流一致性、对极误差）、时序动态（平滑度、jerk）、视觉质量（FVD、CLIP、SSIM、LPIPS）
  • 关键结果：重投影误差从 8.4 降至 6.5 像素（降低 22.6%）；轨迹平滑度从 0.71 提升至 0.88（提升 23.9%）；jerk 从 0.182 降至 0.151
  • 视觉质量基本保持：VBench-I2V Quality 从 0.805 到 0.806，I2V Score 保持 0.958
  • WAM 迁移：Fast-WAM 平均成功率从 43.5% 提升至 54.2%，Atomic Seen 成功率从 59.1% 提升至 78.1%
  • 消融研究验证了结构化 delta token 和紧凑表示优于原始高维 3D 特征
