Card 02 论文概述

论文概述

  • 引入 pico-WAM，一个紧凑的世界行动模型，通过提供显式物理状态来追踪策略-动力学交互，用于诊断世界模型在控制任务中的失败瓶颈。
  • 核心问题：当世界行动模型控制失败时，瓶颈是动作提案生成（proposal generation）还是轨迹评分（trajectory scoring）？
  • 通过受控实验（206 个 Push-T 演示、15 个训练种子）比较数据机制和搜索配置，研究反事实预测与规划误差。
Card 03 核心贡献

核心贡献

  • 提出 pico-WAM 紧凑架构：共享表示同时服务于策略、转移模型和显式状态读出，实现每一步决策可追踪。
  • 发现反事实分支训练改善短视距成本排序，并将策略重启搜索相对于热启动搜索的覆盖率优势扩大 4.8 个百分点；重启搜索在两种数据机制下均优于热启动。
  • 通过交叉实验分离提案与评分：用模拟器成本替换学习轨迹评分使覆盖率提升 12.2 个百分点，而仅替换提案生成无显著增益，识别出评分是有效改进目标。
  • 组件消融和门打开研究揭示更好的轨迹排序不一定带来更好的控制或超越模仿；提供可复现的世界模型诊断协议。
Card 04 方法描述

方法描述

  • 共享表示：输入 64×64 图像、固定指令和 8 维状态（位置、速度、块位姿），通过三层 CNN（16 个空间 softmax 关键点）、GRU 和状态 MLP 融合生成 128 维潜在向量 \(z_t\)。
  • 训练：联合优化行为克隆损失、当前与未来状态重建损失、潜在一致性损失；反事实分支通过高斯噪声（SD 0.3）扰动演示动作生成额外训练数据（6,013 分支，48,104 转移），仅提供预测目标。
  • 规划：策略前向 12 步生成提案，构建 256 个候选（提案 + 254 个噪声扰动），使用加权成本函数（块到目标角距离 + 代理接近惩罚）评分，选择第一个动作执行后重新规划。
  • 干预设计：交叉学习（L）和精确（E）组件构建 LL、LE、EL、EE 四种规划器，隔离提案生成与评分的影响；精确评分使用模拟器真实状态，精确提案涉及渲染和重新编码。
Card 05 数据集与资源

数据集与资源

  • Push-T：使用 LeRobot 的 206 个演示（25,444 个转移，10 Hz），保留原始几何和 100 Hz 物理，重建物理以实现精确回放；覆盖率衡量最大目标重叠，成功率阈值为 95%。
  • Meta-World door-open-v3：39 维状态、4 维动作，80 个脚本专家演示 + 80 个噪声专家演示（共 5,840 个五步窗口）用于门打开研究。
  • 模型规模：潜在维度 128；策略三个 512 单元隐藏层；残差动力学两个 256 单元隐藏层；状态读出线性层。
  • 训练资源：V100-SXM2 GPU；主要研究 21.3 GPU 小时，扩散策略实验 44.7 GPU 小时，动力学研究 1,390 CPU 小时。
Card 06 评估与结果

评估与结果

  • 评估环境：Push-T 任务（重建物理），200 个最终评估起始状态跨 15 个训练运行，以及原始 gym-pusht 环境。
  • 主要指标：覆盖率、成功率、预测 nMSE、候选排名相关性、选择 regret、规划增益。
  • 关键结果：分支训练将策略重启搜索覆盖率从 43.8% 提高到 78.4%（成功率 32.8%）；精确评分（LE）覆盖率比 LL 高 12.2 个百分点；分支训练将排名相关性从 0.49 提高到 0.80，选择 regret 从 7.56 降至 2.77；分支训练使随机动作下块预测误差降低约三倍；门打开研究中混合数据降低 regret 但规划器成功率仍低于反应式 BC（88.2% vs 98.6%）。
