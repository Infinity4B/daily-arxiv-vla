Route-Guided CBF-QP Repair for Safe Vision-Language-Action Models

Card 03 核心贡献

核心贡献

  • 识别了局部 CBF-QP 安全投影在 VLA 机器人执行中存在的 轨迹恢复失败模式
  • 提出了 Route-Guided CBF-QP Repair 方法，能够检测被阻塞的短期 VLA 轨迹并生成进入-退出-重新加入的路线引导
  • 证明在 SafeLIBERO 上与原始 VLA 策略和 AEGIS 风格的局部安全修复相比，路线引导能提升安全任务执行性能
  • 通过 消融实验 表明，绕过障碍物本身不足以实现安全恢复，还需要 路线评分 和 重新加入引导 的协同作用
Card 04 方法描述

方法描述

  • 使用 VLA 策略 预测的短期动作块（动作视界 H）通过累积笛卡尔位移构建预测的名义路径
  • 将每个障碍物建模为 膨胀的椭圆不安全区域，当名义路径的最小椭圆得分低于阈值时判定为阻塞
  • 生成包含 entry、exit、rejoin 三个航路点的左右候选路线，并根据 障碍物间隙、进展、长度、偏差 四项指标（固定权重：λ_clr=1.0, λ_prog=1.0, λ_len=0.3, λ_dev=0.5）选择最优路线
  • 在 CBF-QP 框架中，将选定的路线航路点作为 软引导项（仅作用于平移分量 u^{xyz}）加入目标函数，与原有的 VLA 动作保真项共存，并保留 CBF 硬约束 确保安全性
  • 采用 序贯重新加入执行 方式，当机器人接近当前航路点时切换到下一个阶段，到达 rejoin 航路点后恢复标准 VLA 执行
Card 05 数据集与资源

数据集与资源

  • 使用 SafeLIBERO 基准测试，该基准扩展了 LIBERO 风格的语言条件操作任务并加入障碍物约束
  • 评估数据集包括 Spatial、Goal、Object、Long 四个套件，每项任务评估 10 个 episodes
  • 使用 π_0.5 VLA 骨干网络及其权重（与 AEGIS 一致的固定 VLA 骨干网络）
  • 论文未提供 GPU/TPU 等具体训练资源信息
Card 06 评估与结果

评估与结果

  • 在 SafeLIBERO 上使用四个指标进行评估：碰撞避免率（CAR）、任务成功率（TSR）、SafeSuccess、执行时间步数（ETS）
  • 与 AEGIS 相比，Route-Guided CBF-QP Repair 将平均 CAR 从 64.69% 提升至 69.06%，TSR 从 62.81% 提升至 65.00%，SafeSuccess 从 47.19% 提升至 49.69%
  • 在 Object 套件上提升最大：CAR 从 56.25% 提升至 76.25%，TSR 从 67.50% 提升至 72.50%，SafeSuccess 从 41.25% 提升至 55.00%
  • 消融实验表明，去除 rejoin 引导 后 SafeSuccess 从 49.69% 下降至 47.92%，去除 路线评分 后下降至 48.15%，验证了路线评分和重新加入引导的必要性
  • 定性分析显示 AEGIS 在完成任务时仍可能发生碰撞，而该方法能围绕障碍物走绕行路线并返回任务轨迹，完成无碰撞任务执行
  • ETS 增加至 118.45，反映了为绕行和重新加入所增加的额外执行步数
