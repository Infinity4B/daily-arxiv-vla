Card 02 论文概述

论文概述

  • 论文聚焦力中心操作（force-centric manipulation）问题：接触丰富任务不仅取决于机器人移动到哪，还取决于交互力如何演化。
  • 核心痛点是数据错配：专家演示（task data）只展示成功执行，缺少力对不同动作的响应变化；而任务无关的玩耍数据（task-agnostic play data）提供广泛接触动力学经验，但不指定任务目标。
  • 提出 ForceWAM，将"什么交互结果符合任务"与"哪些动作能改变接触"两类知识解耦，从而同时利用演示数据和玩耍数据。
Card 03 核心贡献

核心贡献

  • 将接触执行形式化为以视觉-力旋量未来（visual-wrench futures）为条件的逆动力学问题，使不同类型的交互数据都能监督动作预测。
  • 提出 ForceWAM：由 ForceWM（仅用成功演示训练，联合预测未来视频与六轴力/力矩）与 IDM（用任务+玩耍数据训练，把生成的未来映射为动作）组成，二者"学什么"解耦、"执行时"通过力反馈连接。
  • 设计慢-快执行机制与时间因果 IDM：ForceWM 慢速更新生成参考，IDM 在动作块内复用生成参考并用新测得的力旋量反馈反应式更新动作。
  • 在四个真实机器人条件下验证，额外玩耍数据在固定演示、ForceWM 与 IDM 优化步数的情况下将成功率提升 15–45 个百分点。
  • 未来条件消融显示视觉未来与力旋量未来具有互补价值，并验证未来条件增强（augmentation）的有效性。
Card 04 方法描述

方法描述

  • ForceWM（世界模型）：以预训练时空视频扩散模型为骨干，采用 EDM（Elucidated Diffusion Model） 去噪训练；将隐输入组织为五个语义槽（空白前缀、当前力旋量、当前图像、未来力旋量轨迹、未来视觉隐变量），前三个槽全程钳制，后两个联合生成。
  • 固定打包适配器将低维力旋量值在视频隐槽的空间维度上重复，使同一时空骨干同时输出视觉与力旋量两种模态的未来。
  • IDM（逆动力学模型）：条件扩散模型（参考 Diffusion Policy），输入当前观测 $\mathbf{o}_t$ 与视觉-力旋量未来 $\mathbf{g}_t$，预测动作块 $\mathbf{A}_t$，不使用单独的任务指令 $\ell$；训练时使用片段中记录的未来而非 ForceWM 生成的未来。
  • 未来条件增强：对记录的视觉-力旋量未来做随机 dropout 与扰动，降低部署时对 ForceWM 预测误差的敏感性。
  • 时间因果注意力掩码：对动作自注意力与动作-力旋量注意力施加下三角掩码，动作 token $k$ 只能看到 $0{:}k$ 的动作 token 与力旋量 token，并遮蔽窗口偏移 $\leq k$ 的参考力旋量，避免未来反馈泄漏。
  • 慢-快部署：ForceWM 在请求时刻生成 $\widehat{\mathbf{g}}_r$ 并缓存慢 token、扩散噪声 $\bm{\xi}_r$ 与基准 TCP 位姿；IDM 在动作块内复用同一噪声做确定性 DDIM 重去噪，仅解码当前动作 token 下发底层控制器。
Card 05 数据集与资源

数据集与资源

  • 自采集真实机器人数据：每个任务族 200 条任务演示 + 200 条玩耍片段（Flip 与 Flip-D 共享训练数据）。
  • 数据流包含同步的腕部 RGB 图像、六轴 TCP 力/力矩测量、机器人动作；玩耍数据为无任务指令的探索性按压、滑动与接触建立/断开。
  • 任务族：力调节滑行（Sliding）、盒子翻转（Flip / Flip-D，带外部扰动）、汉诺塔圆环放置（Hanoi ring placement）。
  • 动作表示为相对窗口起始位姿的笛卡尔 TCP 位姿目标加夹爪指令，训练时还预测执行时丢弃的力派生辅助目标。

Card 06 评估与结果

评估与结果

  • 每个任务 20 次试验，初始状态匹配、使用相同安全限制与控制器接口；滑行任务额外要求满足 5–15 N 接触力判据。
  • 对比基线：RDP、ImplicitRDP、ForceVLA、Cosmos Policy、Fast-WAM、FA-WAM、π0.5。
  • 主结果（表 1）：ForceWAM（Full-play IDM）在 Sliding / Flip / Flip-D / Hanoi 上达到 85% / 95% / 85% / 90%，全部为最优；即使是 Task-only IDM 也以 40% / 75% / 65% / 75% 超过所有外部基线。
  • 最强外部基线 FA-WAM 为 20% / 60% / 40% / 50%；滑行任务差距最大（ForceWAM 85% vs 次优 20%）。
  • 玩耍数据增益：Sliding 40%→85%、Flip 75%→95%、Flip-D 65%→85%、Hanoi 75%→90%；而 ImplicitRDP 与 Cosmos Policy 加入玩耍后性能反而下降。
  • 未来条件消融（表 2）：视觉+力旋量 85/95/85/90，视觉单独 15/40/30/70，力旋量单独 20/30/25/30，无未来条件 15/30/35/50；去掉未来条件增强后为 65/80/70/75，说明两种未来模态互补且增强策略有效。
  • ForceWM 可视化：闭环翻转中预测的视觉未来再现工具-盒子几何演化，预测力未来再现加载、旋转维持与分离的接触阶段。
