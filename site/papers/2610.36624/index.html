Card 02 论文概述

论文概述

  • 论文研究世界动作模型的视觉监督空间分配问题：WAM 通过联合预测未来视觉观测与机器人动作，将预训练视频生成模型适配到机器人控制
  • 指出标准视频预训练继承的视觉预测目标对所有视觉区域一视同仁，忽略了不同区域对机器人控制的相关性差异
  • 提出将视觉监督聚焦于动态区域（如机器人运动、物体交互），使静态区域作为场景上下文，从而显著提升策略性能，且无需外部教师模型或额外模态
Card 03 核心贡献

核心贡献

  • 通过动机实验证明视觉监督的空间分配对下游控制性能有显著影响，确立其为 WAM 的重要设计考量
  • 提出 MoGAP（Motion-Guided Asymmetric Prediction）：一种非对称噪声分配的视觉预测任务，训练模型从更干净的静态上下文重建被更强破坏的动态区域
  • MoGAP 作为训练专属的辅助预测路径嵌入共享视频扩散骨干，推理时完全省略、不改变原 WAM 推理流程
  • 运动线索直接来自训练视频的时间差分，无需外部教师模型或深度/3D 等额外模态
  • 在多种 WAM 架构、仿真与真实世界基准上取得一致且显著的性能提升
Card 04 方法描述

方法描述

  • 基础框架：WAM 基于预训练视频扩散骨干，通过流匹配（flow matching）联合优化视觉预测损失 L_video 与动作预测损失 L_action
  • 动机研究：由视频潜变量的时间差计算运动分数 m_{n,p}，据此对空间位置加权重分配视觉监督，在 GR-1 tabletop 上验证可提升策略性能
  • 非对称噪声分配：利用扩散加噪即部分掩码的解释，动态区域分配更高噪声步长 τ_v⁺ = τ_v + (1−τ_v)ξ，静态区域保持基础噪声水平
  • 运动掩码：对潜变量运动分数进行阈值化得到二值运动掩码 M_{n,p}，构建双时间步分配；流匹配损失仅施加于运动 token，并按所选位置数归一化
  • 辅助训练路径：双时间步噪声潜变量与原 WAM 输入一起在共享扩散骨干中处理，通过非对称注意力掩码隔离两条路径；总损失为 L = L_video + λ_action·L_action + λ_MoGAP·L_MoGAP（λ_MoGAP = 1.0）
  • 推理时省略 MoGAP token，推理流程与原 WAM 完全一致
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboCasa GR-1 Tabletop（24 个 GR-1 人形机器人桌面操作任务，主实验基准）、RoboCasa-Kitchen（24 个单臂厨房任务，多视角评测）
  • 真实世界：OpenArm 人形机器人（双 7-DoF 手臂 + 两个五指 6-DoF Inspire RH56F1 灵巧手），第一视角立体相机
  • 主力模型：Cosmos3-Nano（16B 参数），单次前向生成 16 个动作与 8 帧未来视频；另在 Fast-WAM（Wan2.2-5B 骨干） 上验证
  • 训练配置：仿真基准 16K 梯度步、真实世界 8K 步，全局 batch size 256
  • 真实部署：单步去噪推理，Cosmos3-Nano 在单张 RTX 5090（32GB 显存） 上推理延迟 48ms
Card 06 评估与结果

评估与结果

  • 评估环境：RoboCasa GR-1 Tabletop（24 任务，每任务 50 次试验共 1,200 rollouts）、RoboCasa-Kitchen（24 任务、三相机视角）、真实机器人（In-Domain、OOD 物体与环境、OOD 物体重定位三组任务）
  • 主要指标：任务成功率（%）
  • GR-1 Tabletop：MoGAP 将 Cosmos3-Nano 从 52.3% 提升至 62.3%（+10.0 pp），将 Fast-WAM（Wan2.2-5B） 从 38.8% 提升至 47.5%，超越 GR00T-N1.6（47.6%）、StarVLA-α（57.3%）、RLDX-1（58.7%）等 VLA 基线
  • 优于使用外部教师（VGGT、DINOv2、VideoMAEv2、V-JEPA2.1-L）的表征对齐方法（最高 59.2%），MoGAP 达 62.3% 且无外部教师
  • 消融实验：去除辅助路径（54.4%）、去除噪声非对称性（55.3%）或反转非对称方向（55.2%）均显著降低性能，验证核心设计的必要性
  • 真实世界实验：在 OpenArm 人形机器人上，MoGAP 在 In-Domain、OOD 物体与环境、物体重定位任务上均优于基线，尤其能对执行过程中的目标物体位置变化做出自适应响应（训练中无此类演示）
  • 运动信号分析：动态区域 AUROC（移动手臂/手 0.887、被操作物体 0.834）显著高于背景（0.430）；训练后策略注意力更多集中于移动手臂与被操作物体
  • 局限性：MoGAP 在训练时引入额外 token，训练时间约增加 1.26 倍
