Do VLAs Really Follow Instructions? Diagnosing How-Level Instruction Following in Vision-Language-Action Models

2026-10-15 · 原文 · 翻译 · 2610.21251

论文系统性地诊断了 Vision-Language-Action（VLA）模型是否能遵循 How-level 指令（规定如何执行任务，如抓取位置、路径选择），区别于已有的 What-level 指令（规定任务本身）。 研究发现当前 VLA（包括专门强化指令遵循的模型）不仅无法利用 How-level 指令，反而会因 How-level 指令的加入而降低任务成功率，How-level 指令被视为"噪声"而非有用上下文。 论文提出数据假设：训练数据中每个 episode 仅配一条固定指令，导致语言仅作为任务标识符，无法教会模型语言如何影响执行，并据此设计 enriched instructions 与 SIMPLER-IN 基准进行验证。

Card 02 论文概述

论文概述

  • 论文系统性地诊断了 Vision-Language-Action（VLA）模型是否能遵循 How-level 指令（规定如何执行任务，如抓取位置、路径选择），区别于已有的 What-level 指令（规定任务本身）。
  • 研究发现当前 VLA（包括专门强化指令遵循的模型）不仅无法利用 How-level 指令，反而会因 How-level 指令的加入而降低任务成功率，How-level 指令被视为"噪声"而非有用上下文。
  • 论文提出数据假设：训练数据中每个 episode 仅配一条固定指令，导致语言仅作为任务标识符，无法教会模型语言如何影响执行，并据此设计 enriched instructions 与 SIMPLER-IN 基准进行验证。
Card 03 核心贡献

核心贡献

  • 提出 offline correction 与 online intervention 两种诊断框架，揭示当前 VLA 即使被专门设计用于指令遵循也无法可靠遵循 How-level 指令。
  • 提出训练数据结构假设，并基于 ECoT annotations 构建 enriched instructions（segment-level），在不改动演示数据的前提下提升动作对 How-level 指令的响应性（约 84% vs 对照组约 53%）。
  • 提出 SIMPLER-IN 基准，要求任务成功必须依赖 How-level 指令，揭示已有模型（含 enriched 模型）在严苛条件及 OOD How-level 指令下依然失效。
  • 表明提升 What-level 指令遵循能力并不自动带来 How-level 指令遵循能力。
Card 04 方法描述

方法描述

  • Offline Correction：收集失败 episode，重跑三种条件——Retry（仅换种子）、Correction（附加准确修正）、Inverted Correction（附加反转修正），通过两种 McNemar 检验判断模型是否真正利用了指令内容。
  • Online Intervention：双系统设计，Qwen3-VL-8B 作为 System 2 监控执行并生成修正/子步骤指令，VLA 作为 System 1 执行，包含 no intervention / corrector / unified 三种模式。
  • Enriched Instructions：基于 BridgeData V2 的 ECoT 标注划分 episode 段落，用 GPT-5.4-mini 为每段生成一条祈使句描述 How-level 动作。
  • Action-Level Analysis：比较 Correction 与 Inverted Correction 下的轨迹方向，判断动作是否真正遵循指令内容（随机水平 50%）。
  • SIMPLER-IN：包含 Path（绕开不可见透明障碍）、Grasp（抓取物体特定末端）、Place（放置于指定位置）三类任务，条件仅存在于指令中。
Card 05 数据集与资源

数据集与资源

  • 训练数据：BridgeData V2（基于其 ECoT 标注）
  • 生成数据规模：272,662 条 enriched instructions，覆盖 43,771 个 episodes
  • 评估基准：SIMPLER（WidowX 任务）及新提出的 SIMPLER-IN
  • 评估模型：π₀、InternVLA-M1、QwenGR00T、InstructVLA、LangForce
  • 训练方式：遵循各模型原始训练协议并使用 LoRA 微调，每个模型配备相同预算的 control 对照
  • 辅助模型：Qwen3-VL-8B（System 2）、Gemini 3.1 Pro（生成修正）、GPT-5.4-mini（生成 enriched instructions）
Card 06 评估与结果

评估与结果

  • Offline Correction：Retry 恢复的失败 episode 最多，Correction 在各 model 上均弱于 Retry（π₀: 17.3 vs 36.1；QwenGR00T: 8.5 vs 22.5），且与 Inverted Correction 无显著差异（部分模型 Inverted 更高）。
  • Online Intervention：Corrector 模式多数模型任务成功率下降（Pooled 通用 VLA Δ=−1.2，指令遵循 VLA Δ=−1.3）；Unified 模式下降更大（Pooled Δ=−12.9 与 −17.0）。
  • Enriched 模型：无干预时任务成功率与对照组持平；Unified 模式下多数模型相对对照组获益或损失更小；Action-Level 分析显示 enriched 模型约 84% episode 遵循指令方向，而公开 checkpoint 与 control 仅约 53%（接近 50% 随机水平）。
  • SIMPLER-IN：所有模型均未通过 Path（遵循率 0.0%）；Grasp 和 Place 上 enriched 模型遵循率仍在随机水平附近（Pooled enriched: Grasp 35.3%、Place 44.4%），说明响应性无法泛化到 OOD 及严苛 How-level 指令。
  • 结论：How-level 指令遵循仍是当前 VLA 的开放挑战，需要覆盖更广泛 How-level 内容的训练数据。
