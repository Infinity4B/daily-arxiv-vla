02论文概述

  • 论文提出 EgoStudy，一个系统性的控制实验，研究规模化自我中心人类操作数据对 VLA（视觉-语言-动作模型） 和 WAM（世界-动作模型） 预训练的影响。
  • 针对人类-机器人 embodiment gap 导致迁移效果不明确的问题，论文固定机器人数据量，改变自我中心数据的规模、多样性、处理策略和联合训练配置，系统回答三个问题：哪些数据处理与预训练选择最有效、哪些动作预测组件从扩展中获益最大、VLA 与 WAM 的扩展效应有何差异。
  • 研究旨在为利用自我中心视频训练机器人基础模型提供可比较的结论和实用指导。

03核心贡献

  • 提出统一预训练与评估协议 EgoStudy，支持在共享双手灵巧动作空间下系统比较 VLA 和 WAM 的 human-to-robot 迁移。
  • 进行了大规模综合实验，覆盖数据规模、语义完整性、caption 细节、来源多样性、时间采样、动作组件和 backbone 能力等因素的影响。
  • 得出三个主要发现：数据多样性和轨迹与详细语言注释对齐是有效迁移的关键；扩展自我中心数据对腕部平移预测的增益大于精细手指运动；WAM 在自我中心数据有限时表现更好，VLA 随数据量增加增益更大。
  • 通过视觉特征对齐分析和 backbone 变体实验，揭示了 VLA 和 WAM 扩展行为差异的内在原因，为模型选择与资源分配提供依据。

04方法描述

  • VLA 架构：默认使用 StarVLA，结合 Qwen3-VL-4B-Instruct 视觉语言 backbone 和 GR00T 风格动作专家，从当前相机视图、指令和几何状态预测连续动作。
  • WAM 架构：默认使用 Fast-WAM，结合 Wan2.1-I2V-14B-480P 视频 backbone 和动作扩散 transformer，联合预测未来视频和动作。
  • 共享动作空间：定义 108 维动作表示，涵盖双手腕部姿态（平移、旋转）和五个手指尖位姿（相对位置和旋转），采用 6D 旋转表示，并在初始相机坐标系中定义目标，支持跨 embodiment 的统一动作监督。
  • 数据组成与处理：从约 18,000 小时原始视频中筛选出约 2,206 小时有效数据，包括多个公开自我中心数据集和自采集数据；处理流程包括语义分割、详细 caption 生成、过滤无效片段、坐标对齐和动作归一化。
  • 训练与评估协议：使用 AdamW 优化器和余弦学习率衰减，匹配批量大小与更新次数；采用掩码动作流匹配损失监督，WAM 额外使用视频流匹配损失；离线评估计算去归一化动作的掩码 MSE，闭环评估在 RoboCasa-GR1 中进行任务成功率测试。

05数据集与资源

  • 自我中心数据集：EgoDex（633.831 小时）、VITRA（包含 Ego4D 272.855、EPIC-KITCHENS 55.808、Something-Something V2 18.554 小时）、HOI4D（1.525 小时）、HOT3D（2.936 小时）、自采集数据（867.414 小时）。
  • 机器人数据集：Bimanual XHand（272.676 小时）、RoboCasa-GR1（80.837 小时）。
  • 模型规模：默认 VLA 使用 Qwen3-VL-4B-Instruct（约 4B 参数）加动作专家；默认 WAM 使用 Wan2.1-I2V-14B-480P（约 14B 参数）加动作扩散 transformer；还测试了 Qwen3-VL-8B-Instruct 和 Wan2.2-TI2V-5B 作为 backbone 变体。
  • 训练资源：论文未明确说明具体的 GPU/TPU 数量和型号。

06评估与结果

  • 评估环境与基准：在 Bimanual XHand 和 RoboCasa-GR1 两个机器人域上进行离线 held-out 样本评估，并在 RoboCasa-GR1 上进行闭环任务成功率测试（共 240 次试验，每任务 10 次）。
  • 主要评估指标：腕部平移 MSE、腕部旋转 MSE、指尖位姿 MSE（组件级误差），以及机器人域验证损失和任务成功率。
  • 关键实验结果：

- 数据规模从 1% 增至 100%：VLA 在 Bimanual XHand 上腕部平移误差降低 20.2%，在 RoboCasa-GR1 上降低 14.6%；WAM 分别降低 18.8% 和 9.6%；WAM 整体验证损失更低。

- RoboCasa-GR1 任务成功率：VLA 从 38.3% 提升至 43.8%，WAM 从 39.6% 提升至 45.4%。

- 数据处理选择：语义完整片段、详细 caption、多样数据源均降低腕部平移误差；固定步长采样对 VLA 更优，事件级采样对 WAM 更优。

- 动作组件：扩展自我中心数据主要改善腕部平移预测，腕部旋转和指尖位姿无一致改善。

- 模型差异：VLA 的跨 embodiment 特征对齐（相对分离度 R）随数据规模下降，WAM 无一致变化；VLA 使用 4B backbone 已足够，而 WAM 依赖更大容量的视频 backbone（14B 有效，5B 无效）。
