02论文概述

  • 论文提出 OccWAM，一种占用栅格原生的世界–动作模型（occupancy-native world–action model），通过条件流匹配（flow matching）联合生成稠密未来占用栅格与连续自车轨迹，用于端到端自动驾驶。
  • 现有占用感知规划器存在层级耦合（先生成占用再规划，或先出动作再推演未来）或并行多任务（占用与规划分头输出）的局限，保留了显式的生成顺序或角色不对称，限制了世界预测与动作生成之间的双向交互。
  • 论文进一步提出 scene-to-ego world–action flow matching 两阶段框架，解决"世界演化需以场景为中心坐标建模、而规划需以自车为中心坐标推理"的坐标表示冲突。

03核心贡献

  • 提出 OccWAM，一种联合生成稠密度量占用与连续自车运动的占用原生世界–动作模型，通过耦合条件流实现世界预测与动作生成之间的逐层双向交互。
  • 提出 scene-to-ego world–action flow matching：第一阶段以场景为中心流同时生成未来占用与绝对自车轨迹；第二阶段将预测世界按轨迹诱导的未来自车坐标重索引，并由第二个条件流与自车位姿增量联合输运。
  • 构建基于共享 三专家 Mixture-of-Transformers（Understanding / World / Action Experts）的具体 WAM 实现，World 与 Action Experts 在各层间双向交互，跨阶段共享主干。
  • 与基于视频的 WAM 不同，OccWAM 保留显式语义几何，可直接进行占用监督与度量级规划查询，无需像素空间合成。
  • 在 Bench2Drive 闭环驾驶与 nuScenes 开环规划、未来占用预测上均取得 state-of-the-art 性能。

04方法描述

  • 三专家 Mixture-of-Transformers 主干：冻结的 Understanding Expert 提供语义驾驶上下文（不读取生成的世界/动作）；World Expert 与 Action Expert 在每一层通过联合注意力互相读取对方隐状态与语义上下文，实现双向耦合。
  • 条件流匹配（Conditional Flow Matching / Rectified Flow）：源到目标采用线性插值路径，训练目标为预测解析条件速度；使用偏移时间调度（shift factor ρ=5），在源附近分配更多训练样本，支持少步推理。
  • Stage I（场景中心联合流匹配）：以独立高斯为源，在锚定当前自车位的固定场景帧中生成 场景中心占用序列 与 绝对自车轨迹；仅用 1 步欧拉求解（N_I=1）。
  • Scene-to-Ego 变换：通过固定平面坐标变换 Π、相邻位姿增量算子 Δ/Δ⁻¹ 与重索引算子 W，将 Stage-I 预测的占用 warp 到由轨迹诱导的未来自车帧，并生成覆盖掩码 M^E 与 token 级可见比例 μ。
  • Stage II（自车中心联合流匹配）：目标为数据集中原生未来自车帧占用（非 warp 得到），源为模型诱导的、包含预测误差与未覆盖区域的表示；不引入新高斯噪声，World/Action Experts 联合将其输运至配对的自车中心目标。
  • 速度头设计：两阶段共享主干但采用四个表示特定的速度头（scene/ego × occupancy/action）。
  • 辅助世界–动作耦合损失：以基于占用的轨迹代价 Φ(sg(P), a) 评估预测轨迹，使用 stop-gradient 防止通过删除障碍物来降低碰撞代价的退化解。

05数据集与资源

  • Bench2Drive：闭环驾驶评测，未来世界表示为时序 BEV 占用，采用 PDM-Lite 专家策略收集数据。
  • nuScenes：开环规划与未来 体素占用 预测评测。
  • 采用冻结的逐帧占用自编码器（编码器 ℰ_occ / 解码器 D_occ）将占用映射到紧凑隐空间；Understanding Expert 冻结，仅 World/Action Experts 与速度头可训练。
  • 训练目标为 L = L_FM^S + L_couple^S + λ_II (L_FM^E + L_couple^E)，并含基准特定的辅助目标。
  • 推理时 Understanding Expert 仅前向一次并跨两阶段复用，每个阶段仅一次 World–Action 主干前向。
  • 所提供正文片段未给出具体参数量、模型规模与 GPU/TPU 训练资源细节（可参见附录 B.2 的模型与训练配置）。

06评估与结果

  • 评测环境：Bench2Drive 闭环驾驶（重复交互下的驾驶能力）与 nuScenes 开环规划、未来语义占用预测。
  • 主要指标：Bench2Drive 使用 DS（Driving Score）↑ 与 SR（Success Rate %)↑；nuScenes 开环规划使用 L2 误差（↓） 与 碰撞率（%）↓（1s/2s/3s 及平均）；占用预测使用 mIoU (%)↑ 与 IoU (%)↑。
  • Bench2Drive 闭环结果：OccWAM 取得 DS 90.45、SR 77.27%，均为最优，超越 AutoMoT+（DS 89.42 / SR 74.09）等强基线。
  • nuScenes 开环规划：OccWAM 取得 L2 平均值 0.30 m（1s 0.14 / 2s 0.27 / 3s 0.50），碰撞率平均值 0.07%（1s 0.02 / 2s 0.05 / 3s 0.14），在 L2 平均值与碰撞平均值上达到最优或并列最优（与 AutoMoT 持平）。
  • 未来占用预测：与 Copy & Paste、OccWorld、OccLLaMA、OccTENS 等基线对比，OccWAM 在 mIoU 与 IoU 指标上整体表现领先。
  • 消融实验：验证了两阶段联合流、World→Action 信息流、Action→World 信息流以及 Stage II 中联合世界–动作细化的有效性。
