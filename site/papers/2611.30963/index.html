02论文概述

  • 提出 Foresight Forcing (F²)，一种世界动作模型（WAM），通过从预训练 3D 特征空间的变化中学习空间转移表示，增强机器人操作策略
  • 解决传统 WAM 仅预测未来视觉观测、底层 3D 几何转移隐式的问题，使策略能够显式建模任务相关的几何变化
  • 在训练阶段使用冻结的 VGGT 3D 教师模型提取成对观测的特征差异作为监督，在推理阶段仅依赖当前观测、语言指令和本体感觉状态预测空间转移查询

03核心贡献

  • 过渡中心的几何监督：引入对应关系对齐的 3D 教师特征差异作为空间转移学习的监督信号，用于动作生成
  • 教师引导的空间转移学习：设计专门的空间转移查询，由共享更新器在视觉 backbone 中逐步细化，并与冻结 3D 教师目标在方向和尺度上对齐，查询直接条件化动作专家
  • 操作性能与鲁棒性提升：在 LIBERO、LIBERO-Plus、RoboTwin 2.0 上取得强操作性能和鲁棒性，在 RoboTwin 2.0 Full 和 Clean-to-Random 上达到最先进平均成功率；在六个真实世界任务上平均任务得分 85.8%
  • 推理高效：推理时无需未来观测或 3D 教师模型，保证部署效率

04方法描述

  • 基于 ImageWAM 框架，引入空间转移查询 \(Z_\Delta\)，与当前视觉特征一起条件化动作专家
  • 训练时使用冻结的 VGGT 提取对齐的当前与未来观测的 patch 特征，计算特征差异 \(Y_\Delta = \check{Y}_+ - \check{Y}_-\) 作为密集监督目标
  • 空间转移查询在视觉 backbone 的每个 double block 后由共享更新器 \(U_\theta\) 细化，更新器通过交叉注意力读取当前视觉状态 \(H_{cur}\) 和条件状态 \(H_\ell\)（包含语言指令和本体感觉状态）
  • 使用方向对齐损失 \(\mathcal{L}_{\text{ang}}\)（余弦相似度）和尺度重构损失 \(\mathcal{L}_{\text{scale}}\)（L2 距离）监督查询投影到教师空间后的特征
  • 引入 reference-condition dropout：训练时以概率 0.5 启用动作专家对当前视觉状态的注意力，推理时保持 \(H_{cur}\) 和 \(Z_\Delta\) 可见
  • 联合优化图像预测损失 \(\mathcal{L}_{\text{img}}\)、动作损失 \(\mathcal{L}_{\text{act}}\) 和几何转移损失 \(\mathcal{L}_{\text{geo}}\)，几何损失权重随训练步数逐渐增加

05数据集与资源

  • LIBERO：单臂仿真基准，包含 Spatial、Object、Goal、Long 四个套件，每套件 10 个任务
  • LIBERO-Plus：鲁棒性基准，覆盖物体布局、相机视角、机器人初始状态、语言指令、光照、背景、观测噪声七个扰动维度
  • RoboTwin 2.0：50 个双臂桌面操作任务，包含 Full 和 Clean-to-Random 设置
  • InternData-A1：机器人策略预训练数据集，用于 RoboTwin Clean-to-Random 设置
  • 模型骨干：FLUX.2 [klein] base 4B，视觉 token 网格如 LIBERO 为 14×28（两视角共 N=392 个空间查询）
  • 训练资源：具体 GPU/TPU 数量未在提供的 HTML 中明确列出，训练配置见附录 A

06评估与结果

  • LIBERO 标准套件：F² 平均成功率 98.5%，与 ImageWAM (98.4%) 及领先方法相当，接近性能上限
  • RoboTwin 2.0 Full：F² 在干净场景 94.90%、随机场景 95.12%，平均 95.01%，均高于 ImageWAM 及对比方法（如 Flex-π 94.55% 平均）
  • LIBERO-Plus 鲁棒性：F² 总体成功率 84.5%，较 ImageWAM (81.6%) 提升；在机器人状态和相机扰动上分别提升 8.7 和 5.4 个百分点
  • RoboTwin Clean-to-Random：F² 干净场景 87.84%、随机场景 67.06%，平均 77.45%，高于对比方法中最高平均
  • 真实世界任务：六个操作任务上 F² 平均任务得分 85.8%，超过 ImageWAM 15.6 个百分点、π₀.₅ 2.3 个百分点
