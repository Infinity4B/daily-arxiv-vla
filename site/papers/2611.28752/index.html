VTLA-RL: Learning Visuotactile Policies for Load-Adaptive Grasping

02论文概述

  • 提出 VTLA-RL，用于学习负载自适应抓取的视觉触觉策略
  • 解决物体质量变化难以从视觉判断、初始抓取易滑移、固定条件下演示数据覆盖不足的问题
  • 核心思路：混合真实与仿真演示初始化，共享视觉编码器处理触觉图像历史和 RGB，统一动作空间联合生成运动和双侧力目标，随后仅用仿真交互进行两阶段多任务 RL 后训练，并直接部署到真实机器人

03核心贡献

  • 提出一种负载自适应抓取的视觉触觉策略：结合触觉历史、共享视觉编码器、统一运动-力动作接口，通过混合演示初始化和仿真 RL 提升抓取，无需测试物体质量标签和持续真实演示监督
  • 在模拟和真实机器人上系统比较两种触觉表示（TacImage 和 TacField）与三种 RL 后训练路线（VTLA-RL、RL Token、DSRL），并评估负载变化和放置扰动
  • 验证完整方法优于监督初始化，揭示不同表示和 RL 路线在真实硬件上的增益差异，为任务相关的表示与训练选择提供经验依据

04方法描述

  • 使用 π0.5 作为 VLA 主干，两个 224×224 RGB 视图；TacImage 将每指 8 帧触觉图像拼接并共享预训练 RGB ViT，无需单独触觉编码器；TacField 使用因果 TCN 将触觉阵列历史映射为单个前缀 token
  • 动作空间 13 维：末端执行器位置(3)、旋转向量(3)、夹爪(1)、双边接触力目标(每指 3 维：法向+两个切向，单位牛顿)；一个流动作专家联合生成运动与力目标，由 Tabero 风格混合力-位控制器执行
  • Sim-Real 对齐：通过 3DGS 重建、Taxim 和 FOTS 触觉仿真、以及跨域对齐分辨率/通道/时序/坐标/历史窗口等，使仿真和真实观察与控制一致
  • 多阶段多任务 RL：从混合数据 SFT 检查点出发，使用 PPO+GAE 更新动作专家 LoRA 和价值头；阶段 1 随机位置，阶段 2 随机质量与摩擦；稀疏成功奖励；基于任务成功率的动态权重（Hebero 风格）平衡多任务优化
  • 部署使用 FAST：20 Hz 触觉反馈的异步滚动推理，新动作块与旧目标线性融合，实现 100 Hz 低层命令，无需额外微调或在线 RL

05数据集与资源

  • 未使用公开数据集；自采集遥操作真实演示每任务 30 条轨迹，与等量 Tabero 风格仿真回放按 1:1 混合用于 SFT 初始化
  • RL 后训练仅使用仿真交互：128 个并行环境，两个任务各半，每阶段 200 epochs；物体质量随机范围为 Cola 150–250g、Vitasoy 100–600g，位置随机 ±2 cm；评估扩展到 ±6 cm 扰动
  • 模型基于 π0.5 的视觉-语言-动作主干，论文未明确披露总参数量；TacImage 复用预训练 RGB ViT，TacField 使用轻量因果 TCN
  • 训练硬件：8 张 RTX PRO 6000D GPU；真实与仿真评估均使用 RTX 4090；真实机器人平台为 xArm 手臂 + Xense 触觉传感器 + 定制混合力-位夹爪

06评估与结果

  • 评估环境：模拟 128 并行环境（Task A 可乐罐、Task B 维他奶纸盒，含干扰物饼干盒）；真实机器人（xArm + Xense + 混合力-位夹爪）；真实测试质量层位调整为 Task A 150/550/700g、Task B 100/500/650g，并在触觉传感器上覆膜降低摩擦以诱发滑移
  • 主要指标：成功率（SR，%），每个任务随机种子 50 次仿真试验、真实机器人各条件 10–20 次试验；平均抓取力（AG，N）
  • 与 Tabero Gentle/Firm 基准相比，Adaptive (Ours) 在全部质量层位表现高且稳定（仿真 Task A: 98/98/96；Task B: 96/94/98）
  • 平均抓取力分析显示 RL 前后 AG 变化仅 -1.9% ~ +2.8%，表明成功增益来自力与几何的合理使用而非单纯增大夹持力
  • 在模拟中比较三种 RL 路线与两种表示，VTLA-RL(Img) 总体最优（平均约 96.7%），Field 表示在高负载层位退化明显（如 A T3 仅 20%）
  • 真实机器人结果显示：固定位置 Img 达 100%，随机位置 65%；Field 初始化更强但 RL 增益较小（固定 95%→95%，随机 45%→55%）；质量层位测试中 VTLA-RL 全拼 100/95/70，优于 RLT、DSRL、无 FAST 和无 RL 变体，且在高负载 T3 优于无触觉 PiRL†（70% vs 25%）
  • 消融证实 RL 后训练显著提升成功率（Img：83%→97%；Field：58%→76%），FAST 对 Field 提升更为关键；无触觉输入 PiRL† 平均 74%，低于 Img 全拼 97%
