Card 02 论文概述

论文概述

  • 论文研究 视觉-语言-动作（VLA）策略 在长尾任务分布下的性能退化问题，重点关注共享策略中的 head-task action bias。
  • 作者发现：当尾部任务所需的视觉证据不足时，策略会更多依赖数据丰富头部任务所强化的动作模式，导致尾部任务表现下降。
  • 提出 Evidence-Guided Counterfactual Learning（ECL），无需额外训练数据或区域级标注，在部署时不引入额外计算。
Card 03 核心贡献

核心贡献

  • 重新审视尾部任务失败的经典解释，通过玩具实验表明：任务特定视觉 grounding 不足时，尾部任务预测会回退到 头部任务动作偏置。
  • 提出 ECL：利用指令相关与动作相关信号定位决策关键视觉证据，构造反事实观测，并通过反事实监督增强任务指令、视觉证据与动作之间的关联。
  • 设计 频率感知反事实监督：根据任务演示数量自适应调整监督强度，对尾部任务施加强正则、对头部任务减弱约束。
  • 在 LIBERO-Core-LT 的两种 VLA 策略以及两个真实机器人平台上验证方法有效性，取得一致的宏平均性能提升，尤其改善尾部任务。
Card 04 方法描述

方法描述

  • 关系感知反事实分支：结合指令相关注意力 \(\alpha_j^L\) 与动作相关注意力 \(\alpha_j^A\)，以乘积 \(r_j=\alpha_j^L\alpha_j^A\) 选择 top-K 视觉 token，默认选择比例为 10%。
  • 反事实构造：保持语言指令不变，对选中的视觉 token 进行掩码，得到 \(I^-=\operatorname{Mask}(I,R)\)，并与原始观测共享同一策略前向。
  • 反事实监督：定义事实预测 \(z^+=f_\theta(I,L)\)、掩码预测 \(z^-=f_\theta(I^-,L)\) 与反事实动作效应 \(z^{\mathrm{effect}}=z^+-\lambda z^-\)，其中 \(\lambda\) 默认取 0.3。
  • 训练目标：\(\mathcal{L}_i=\mathcal{L}_{\mathrm{BC}}+\mu\mathcal{L}_{\mathrm{mask}}+r_i\mathcal{L}_{\mathrm{CF}}\)，其中 \(r_i\) 根据任务稀有度在 0 到 1 之间取值，尾部任务获得更强的反事实监督。
  • 部署方式：仅使用事实策略进行推理，掩码分支、对比输出和任务频率权重均不参与部署阶段动作生成。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO-Core-FULL、LIBERO-Core-LT，以及用于初始化 MiniVLA 的 LIBERO-90 预训练 checkpoint。
  • 仿真基准：LIBERO-Core 的 10 个操作任务，使用 7-DoF Franka Panda 机械臂进行闭环评估。
  • 真实世界平台：AGILEX PIPER 与 xArm6，各包含 6 个演示频率不均衡的操作任务。
  • 模型：MiniVLA 和 π0.5 两种 VLA 策略。
  • 训练资源：论文未明确说明具体 GPU/TPU 型号与数量；ECL 会因构造反事实样本和额外前向传播带来额外训练开销。
Card 06 评估与结果

评估与结果

  • 仿真评估：在 LIBERO-Core-LT 上比较 FULL、LT、APA 与 ECL，指标为任务成功率与宏平均成功率。
  • 仿真结果：MiniVLA 宏平均成功率从 40.8% 提升至 53.0%；π0.5 从 40.3% 提升至 47.2%。
  • 对比 APA：MiniVLA 从 44.8% 提升至 53.0%；π0.5 从 41.7% 提升至 47.2%。
  • 真实机器人结果：AGILEX PIPER 上 MiniVLA 从 17.3% 提升至 25.7%，π0.5 从 21.0% 提升至 27.3%；xArm6 上 MiniVLA 从 19.3% 提升至 26.0%，π0.5 从 24.0% 提升至 30.7%。
  • 尾部任务表现：ECL 相比 APA 在 AGILEX PIPER 上平均提升尾部任务成功率约 9.0%，在 xArm6 上约 4.3%。
  • 上下文级长尾鲁棒性：在 Long-Tailed Context（LTC） 设置下，仿真平均成功率从 34.7% 提升至 37.6%，真实世界从 28.5% 提升至 34.3%。
