02论文概述

  • 论文针对流匹配视觉-语言-动作（VLA）模型的推理效率问题，特别是动作专家在迭代去噪过程中被反复评估导致的延迟瓶颈
  • 提出 MambaAct，一种高效的 Mamba 动作专家，用于替换流匹配 VLA 中的 Transformer 动作专家
  • 在保留预训练 VLM 骨干和标准流匹配公式的前提下，大幅降低动作专家的参数量和推理延迟，同时保持或提升策略性能

03核心贡献

  • 提出 MambaAct，将动作专家替换确立为流匹配 VLA 的互补效率优化方向，无需额外预训练或蒸馏即可将 Transformer 动作专家替换为紧凑的 Mamba 专家
  • 证明 Mamba 能够实现动作专家的高倍压缩：MambaAct 动作专家参数量仅为 π₀.₅ 的约 10 分之一（29.7M vs 311.5M），并在 LIBERO 上平均成功率提升 1.08 个百分点
  • 通过受控消融实验，分析 Mamba 动作混合器和条件接口对性能-效率权衡的影响
  • 展示 MambaAct 可与 VLM 深度缩减结合，并成功迁移至 SmolVLA，验证了动作专家替换在不同流匹配 VLA 骨干上的通用性

04方法描述

  • 保留预训练 VLM 前缀：使用 π₀.₅ 的 PaliGemma 骨干（SigLIP 视觉编码器 + Gemma 语言编码器），冻结或联合微调
  • Context Compressor：将 VLM 输出的大量 token 压缩为少量（K=64）上下文 token，包括视觉段池化、语言段池化和可学习查询的全局摘要，形成紧凑条件向量 z
  • 门控 FiLM 调制：每个 Mamba 块通过一个 MLP 从 z 生成 scale、shift 和 residual-gate 参数，对 Mamba 输出进行调制，实现视觉语言条件注入
  • 动作与时间输入：噪声动作块投影到 H 个 token，流时间 t 经 MLP 编码后逐块注入（加性偏置）
  • Mamba 混合器：使用 SISO Mamba3 沿动作 token 维度建模序列依赖，4 个块，宽度 512，状态大小 64
  • 速度预测与训练：输出头预测流速度，损失为 flow-matching 均方误差；零初始化调制参数，门控残差初始乘子 0.2

05数据集与资源

  • 数据集：LIBERO（Spatial、Object、Goal、LIBERO-10 四个套件，共 40 个任务）、LIBERO-Plus（10,030 个测试实例，7 类扰动）、真实世界任务（UR5 机器人上的 Tube Placing 和 Nut Pouring，各 112 条演示）
  • 模型参数量：MambaAct 动作专家 29.7M，原 π₀.₅ 动作专家 311.5M；总模型从 3.62B 降至 2.96B
  • 训练资源：单张 NVIDIA H100 GPU，30,000 步，batch size 16，AdamW 优化器，余弦学习率 5e-5→5e-6，bf16 精度，梯度检查点
  • 推理资源：LIBERO 延迟在 H100 上测量；真实世界使用 NVIDIA RTX 5090 GPU，30Hz 控制频率

06评估与结果

  • 评估基准：LIBERO 四个套件（50 trials/task），LIBERO-Plus 官方协议（单次 rollout/instance），真实世界任务（28 ID + 52 OOD trials）
  • 评估指标：任务成功率（LIBERO、LIBERO-Plus 分类成功率；真实世界归一化成功率），延迟（Prefix、Denoise、E2E），模型参数量
  • LIBERO 结果：平均成功率从 π₀.₅ 的 96.72% 提升到 97.80%（+1.08个百分点，三个微调种子），同时 Denoise 延迟降低 64.8%（160.26→56.40 ms），E2E 延迟降低 52.9%（228.6→107.6 ms）
  • LIBERO-Plus 结果：MambaAct 在整体成功率和多个扰动类别上保持或超过 π₀.₅ 基线，展现鲁棒性
  • 真实世界结果：在 Tube Placing 和 Nut Pouring 任务中，MambaAct 在 ID 和 OOD 场景下与 π₀.₅ 性能相当，同时真实世界 Denoise 延迟降低约 58.8%
  • 对比与消融：与 SnapFlow、Shallow-π、CLP、LightVLA 等高效 VLA 方法相比，MambaAct 在速度与成功率之间取得有竞争力的权衡；消融证明 Mamba 混合器和 FiLM 条件接口对性能的必要性
