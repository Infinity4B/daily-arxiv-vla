02论文概述

  • 提出 ActMem，一个上下文记忆框架，用于解决视觉-语言-动作（VLA）模型在记忆依赖的机器人操作中的不足。
  • 现有记忆增强 VLA 要么仅检索过去观测而不进行推理，要么在共享上下文中同时处理历史与当前感知，导致当前视觉细节被历史挤压。
  • ActMem 将“记忆推理”（从历史中推断该做什么）与“感知接地”（根据当前视图决定如何做）在单一视觉-语言骨干中解耦，符合认知科学中记忆与感知分离的原则。

03核心贡献

  • 提出 VLA 记忆分离原则：明确区分“经历过的”与“感知到的”，记忆负责推理历史以决定任务，感知负责指导当前动作执行。
  • 设计记忆推理架构：利用 Latent Memory Chain-of-Thought (Memory CoT) 保存历史条件子任务推理的隐藏状态，作为流匹配动作专家的条件；Perception Attention 使动作专家直接关注当前视图的视觉特征。
  • 实现高效推理方法：Efficient Memory CoT Inference 复用历史 KV 缓存和上一决策的子任务草稿，在不改变输出的前提下将长历史下的推理延迟降低至 0.33–0.52 秒。
  • 跨记忆类型验证性能：在 RoboMemArena、MIKASA-Robo 及真实世界任务中取得最优结果，覆盖外源性、内源性和无痕迹记忆。

04方法描述

  • 使用 Qwen3-VL 作为视觉-语言骨干，将带时间戳的历史帧视频、当前腕部相机视图和语言指令编码为统一上下文。
  • 骨干自回归地推断当前子任务（subtask），并将该子任务 token 的最终层隐藏状态（连同 token 嵌入和 M-RoPE 位置）作为 Latent Memory CoT 条件。
  • Perception Attention 以门控交叉注意力形式插入流匹配 DiT 的选定层（第3、7、11、15层），让动作表征直接关注当前视图的上下文视觉特征，门控参数初始化为零以平滑训练。
  • 动作专家使用 流匹配 生成 16 步动作块，训练时联合优化子任务预测交叉熵损失和流匹配回归损失。
  • Efficient Memory CoT Inference 利用投机解码原理，以上一子任务为草稿在并行前向中验证，接受匹配前缀，仅在需要时进行逐 token 解码，避免重复编码完整历史。

05数据集与资源

  • 仿真基准：RoboMemArena（26 个任务，4 大类：转移、遮挡、计数、序列执行）和 MIKASA-Robo（ShellGame、Intercept、RememberColor-3/5/9，共 5 个任务）。
  • 真实世界任务：Cup-and-Block、Tissue Counting、Cabinet Search、Scissor Retrieval，覆盖外源性、内源性和无痕迹记忆。
  • 模型骨干为 Qwen3-VL（视觉-语言模型），基于 starVLA 框架，包含 16 层流匹配动作专家。
  • 训练资源：8 张 NVIDIA RTX PRO 6000 GPU，全局 batch size 64，训练 60k 迭代（消融实验 40k 迭代）。
  • 推理配置：预测 16 步动作块，10 步流匹配积分，执行前 10 步后重新规划。

06评估与结果

  • RoboMemArena：ActMem 达到 71.1% 任务成功率（TSR） 和 80.8% 完成成功率（CSR），分别超过最强基线 7.5 和 8.7 个百分点；在遮挡和序列类别上优势最大。
  • MIKASA-Robo：平均成功率 73.8%，优于所有对比方法；在 Intercept（85%）和 RememberColor-9（67%）上提升明显。
  • 真实世界：平均成功率 68.8%，比最强记忆增强 VLA（SimpleMemVLA）高 10.0 个百分点，在四个任务上均取得最佳。
  • 消融实验：移除历史、仅用 10 秒历史、使用纯文本子任务或全 token 条件、移除 Perception Attention 都会显著降低性能，证明各组件必要性。
  • 推理效率：标准推理延迟随历史长度从 0.87s 增至 1.42s；Efficient Memory CoT Inference 降至 0.33–0.52s，比标准推理快 2.1–2.8 倍，且输出不变。
