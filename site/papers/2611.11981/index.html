02论文概述

  • 论文提出 Thermo-VLA，一种面向机器人操作的热感知视觉-语言-动作（VLA）模型，旨在解决现有方法将热图像作为普通视觉输入、缺乏温度相关关系推理的问题。
  • 通过设计 ThermoRes Encoder，将热观测分解为冷、热属性表示，并以语言条件残差方式注入 RGB token，实现温度驱动的目标选择与连续操控。
  • 在 Unitree G1 双足人形机器人上构建六个真实世界操作任务，覆盖基础 RGB 接地、温度感知、温度接地、相对温度排序及排除推理等能力。

03核心贡献

  • 构建真实世界热感知机器人操作基准，包含四个温度相关任务和两个 RGB 任务，共收集 1,307 个专家演示。
  • 提出 Thermo-VLA 框架及核心组件 ThermoRes Encoder，利用双分支属性分解和门控残差注入将温度信息与 RGB 表示协同融合。
  • 实验证明 Thermo-VLA 在所提基准上取得最佳总体性能，在四个温度相关任务上平均成功率 0.86，较直接 RGB-热输入的 π0.5 基线高出 18 个百分点。
  • 在未见物体、属性重分配、光照变化和桌布更换等泛化场景下保持平均成功率 0.78，展现出最强的泛化能力。
  • 进一步将残差调制机制迁移至色彩属性（RGBRes Encoder），在仿真和真实机器人实验中均获得一致性提升，表明该方法具有超越温度属性的潜力。

04方法描述

  • 双分支属性分解：将热图像按背景参考进行校准，分解为互补的 cold 和 hot 属性视图，分别使用共享的 SigLIP 热编码器和 RGB 投影器转换为与 RGB token 同维度的属性 token。
  • 门控残差注入：首先通过文本门控跨注意力（Text-Gate Cross-Attention）以语言指令为查询、冷/热 token 为键值，动态生成冷、热分支的权重 α 和 β；然后以残差方式将加权温度 token 注入头部 RGB token，形成冷/热增强的 RGB 表示。
  • 动作生成：温度增强后的视觉 token 与文本 token、离散机器人状态拼接构成多模态前缀，输入 Gemma 骨干，并采用 flow-matching 机制生成连续动作块，动作维度为 8（7 个手臂关节 + 1 个手部开合）。
  • 残差公式可表达为 y = x + f(a; l)，其中 x 为 RGB 表示，a 为属性观测，l 为语言条件；谱分析表明残差呈近似低秩结构，支持低维子空间建模。

05数据集与资源

  • 构建六个真实世界操作任务：任务 I（位置引导瓶选择）、任务 II（温度引导瓶选择）、任务 III（身份引导物体选择）、任务 IV（温度引导物体选择）、任务 V（温度感知咖啡服务）、任务 VI（异常动物笼移除），共收集 1,307 个专家演示（各任务 99–340 个）。
  • 模型在 Unitree G1 双足人形机器人平台上进行训练与评估，配备头戴 RGB 和热成像相机，以及手腕 RGB 相机。
  • 基线模型为 π0.5（VLA），Thermo-VLA 在其基础上引入 ThermoRes Encoder；具体模型参数量和训练 GPU 资源未在论文 HTML 中明确说明。
  • 额外仿真与真实任务：任务 VII 基于 LIBERO 仿真环境（Franka 机械臂颜色选择），任务 VIII 为真实双机械臂彩色杯选择任务，用于验证 RGBRes Encoder（颜色残差）。

06评估与结果

  • 比较方法包括 ACT、π0.5（RGB-only）、π0.5(RGBT)（直接融合 RGB 与热图像）以及 ThermoAct。
  • 在六项真实操作任务上，Thermo-VLA 与 π0.5 和 ThermoAct 在 RGB-only 任务（I 和 III）上保持竞争性表现；在温度相关任务上优势显著，例如 Task II 成功率达 1.00，Task IV 平均 0.86，Task VI 实现 1.00 的成功率。
  • 四个温度相关任务的平均成功率为 0.86，比 π0.5(RGBT) 高出 18 个百分点，比 ThermoAct 提升更为明显。
  • 泛化实验：未见物体设置下平均成功率 0.79，光照变化下 0.76，未见桌布下 0.79，四种泛化设置总体平均 0.78，均优于对比方法。
  • 消融实验表明，移除门控残差注入在 Task VI（小型未见目标）上成功率从 0.85 降至 0.60；移除双分支分解导致场景扰动下性能下降；当热残差置零时，温度相关任务成功率均接近 0.5，说明温度残差主要用于目标选择的温度调制。
  • 颜色迁移实验（RGBRes）在四个测试中平均成功率从 0.572 提升至 0.775，验证残差调制机制对非温度属性的通用性。
