02论文概述

  • 论文提出 AgentWorld，一个面向自动驾驶的智能体中心视觉-语言-动作（VLA）世界模型，旨在解决现有 VLA 世界模型在像素级未来帧生成中遭遇的规划瓶颈
  • 核心问题：现有 VLA 世界模型生成大量与驾驶决策无关的密集视觉 token，导致计算开销大且规划性能提升有限
  • AgentWorld 用一组离散的、物理可解释的智能体 token 表示世界状态，每个 token 动态绑定到周围交通参与者，捕捉其语义身份、3D 几何、运动状态和交互上下文

03核心贡献

  • 揭示现有 VLA 世界模型的瓶颈：大量用于未来帧生成的视觉 token 与规划无关，仅有少量 token 编码规划关键因素
  • 提出智能体中心潜在状态作为面向规划的世界建模表示，将驾驶场景抽象为随时间演化的交互智能体，显式编码几何、运动、语义和交互
  • 设计 AgentWorld 模型，通过离散智能体 token 实现推理与规划，并采用显式几何接地、推理导向的监督微调（SFT）和智能体导向的强化学习（RL）三阶段训练
  • 在开放式和闭环基准上验证有效性，实现更优的规划性能、更充分的视觉证据利用和可解释的智能体中心世界状态

04方法描述

  • 智能体 token 接地：将每个特殊 token <agent_i> 初始化为可学习查询，通过多模态路由锚定模块分别融入离线 4D 几何特征（VGGT 风格）和 2D 视觉特征，用独立的门控机制控制各模态贡献，经多层交叉注意力融合得到接地后的查询
  • 物理接地目标：在训练阶段使用轻量级智能体头预测类别/存在性、3D 边界框和未来轨迹，通过匈牙利匹配与真实智能体对齐，使 token 隐藏状态具备物理可验证性
  • 策略学习：接地后的智能体 token 作为 MLLM 输入的一部分（<perception> 字段），模型输出结构化的推理（<think>）、高层动作（<action>）和未来航点（<answer>）。先进行推理导向的 SFT，再用 GRPO 进行智能体导向的强化学习，奖励函数包括格式、感知、动作、轨迹和交互安全等成分

05数据集与资源

  • 数据集：nuScenes（开放环路评估）、Bench2Drive/CARLA（闭环仿真评估）
  • 模型基础：基于 Qwen2-VL 和 Qwen2.5-VL 系列（例如 Qwen2-VL-2B），参数规模约 2B
  • 训练资源：使用 4 × 80GB NVIDIA A800 GPU
  • 训练分为三个阶段：物理接地 SFT、推理导向 SFT、智能体导向 RL

06评估与结果

  • 评估环境：nuScenes 验证集（开源规划、3D 感知、动作预测）和 Bench2Drive 闭环仿真（驾驶分数、成功率、效率、舒适度）
  • 主要指标：轨迹 L2 误差、碰撞率、mAP、NDS、动作类别 F1、驾驶分数、成功率、效率、舒适度
  • 关键结果：

- 在 nuScenes 开放环路上，AgentWorld 在无额外 ego-state 输入下已超越多数 VLA 基线；加入 ego-status 后取得最优平均 L2 误差和碰撞率（如 ST-P3 协议下 L2 0.25m，碰撞率 0.07%）

- 感知任务中，AgentWorld 达到 mAP 0.318、NDS 0.416，优于对比检测器

- 动作预测中，AgentWorld 在转向、车道保持、加减速等多类别上取得最佳 F1，总体优于 VLA-World

- 闭环规划中，AgentWorld 的驾驶分数 81.17、成功率 61.36%、舒适度 54.39 均为对比方法中最高，效率也接近最佳

- 消融实验表明，移除 4D 几何或 2D 视觉接地均导致性能下降，SFT 和 RL 两个阶段都不可少
