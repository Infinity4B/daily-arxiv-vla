DRIFT: A Residual Flow Adapter for Decoding Continuous Outputs in Vision-Language Models

02论文概述

  • 现有基于自回归离散解码的视觉语言模型（VLM）不适用于需要精确连续输出的任务（如事件时序定位、机器人操控）：离散token化会引入量化误差、丢失序结构、忽略细粒度变化，且完全替换离散接口会牺牲预训练的可扩展性与零样本迁移能力
  • 本文提出DRIFT（Decoding via Residual Flow Adapter）通用框架，通过结合基预测器的粗估计与基于flow matching的生成式细化模块，将生成建模问题从学习全局输出分布转化为建模局部残差分布，大幅简化优化过程
  • 研究目标是在感知（视觉 grounding）与规划（机器人操控）两类连续输出任务上验证DRIFT的通用性与有效性，证明其可适配多类VLM架构并取得优于回归、生成式基线的性能

03核心贡献

  • 提出DRIFT通用适配框架，无需修改预训练VLM的原有架构，即可为其赋予精确连续解码能力，适配视觉-语言-动作、时序视频 grounding、空间 grounding等多类任务
  • 设计残差式flow匹配细化模块，以基预测器的粗输出为强先验初始化分布，通过可学习门控与跳连接结合粗预测与细化结果，将生成式建模的复杂度从全局分布学习降为局部残差学习，显著提升优化效率
  • 从统计视角理论证明残差细化可严格降低预测误差，相比直接应用flow matching具有更快的收敛速度与更高的预测精度
  • 在Libero、Simpler WidowX、Charades-STA、ActivityNet Captions、RefCOCO系列等多类基准上验证框架通用性， consistently 超越回归与生成式基线，在VLA、TVG任务上达到state-of-the-art性能

04方法描述

  • DRIFT由两个核心组件构成：一是基预测器g(·)，可复用VLM原有的token解码器、MLP回归头等（对应DRIFT-Tokenizer、DRIFT-MLP两种变体），提供连续输出的粗估计；二是残差flow细化模块，基于flow matching学习速度场，将以粗估计为中心的高斯分布$\mathcal{N}(\hat{y}, \sigma \boldsymbol{I})$逐步Transport至目标条件分布$p(y\|z)$，而非从标准零均值高斯分布开始生成
  • 速度场采用目标预测参数化，通过跳连接结合基预测器输出与细化模块输出，可学习门控向量$\alpha$自适应平衡两者的贡献；训练时采用以粗估计为中心的线性插值桥状态，损失函数为标准flow matching损失与基预测器MSE损失（若基预测器可学习）之和，联合训练时对基预测器应用梯度停止，避免模型忽略粗先验
  • 推理时从以粗估计为中心的高斯分布采样初始化，通过10-20步的ODE求解即可得到最终预测，支持多次采样平均进一步降低偏差
  • 核心创新为残差式flow匹配范式，将生成建模的起点从无信息的噪声分布替换为VLM预训练得到的强粗先验，大幅降低建模难度，同时保留生成式方法对不确定性与多模态分布的建模能力

05数据集与资源

  • 核心数据集：

- 机器人操控（VLA）任务：LIBERO训练集、OXE数据集的Bridge与Fractal划分（训练）；Libero-Spatial/Object/Goal/Long、Simpler WidowX（测试）

- 时序视频 grounding任务：TimeLens-100K（训练）；Charades-STA、ActivityNet-Captions（测试）

- 空间 grounding任务：RefCOCO系列数据集（RefCOCO、RefCOCO+、RefCOCOg，训练测试一体化）

- 世界动作模型验证：Libero基准套件（测试）

  • 模型规模：基VLM采用Qwen3-VL-2B（20亿参数）、OpenVLA-7B（70亿参数）、PaliGemma-3B（30亿参数）、ET-Chat、FastWAM等，DRIFT适配器仅包含速度场模块、可学习门控与缩放向量，参数量远小于基模型，整体训练采用LoRA微调策略降低开销
  • 训练资源：原文未明确提及具体GPU数量、型号等硬件配置，仅说明采用LoRA适配器对VLM的视觉编码器与大语言模型进行微调，联合训练DRIFT组件
