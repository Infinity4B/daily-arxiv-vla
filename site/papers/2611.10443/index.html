02论文概述

  • 论文提出 SPARK-VLA（Spatial Representation distillation and Knowledge routing for Vision-Language-Action Models），一种增强预训练 VLA 3D 空间理解的框架。
  • 解决的问题：现有 VLA 常依赖显式 3D 输入或在单一视觉通路中注入空间知识，前者增加推理负担，后者可能破坏预训练视觉-语义表示。
  • 提出“保留-专化-路由”思路：冻结原始视觉通路，通过 3D 专家蒸馏训练并行 LoRA 空间分支，再用知识路由器选择性融合通用与空间 token。

03核心贡献

  • 提出 SPARK-VLA 框架，推理时无需额外 3D 传感器或专家，同时保留原视觉通路的通用语义能力。
  • 设计 注意力响应蒸馏 方法，从冻结的 3D 专家（如 VGGT）向 LoRA 空间分支传递几何知识，避免直接修改原视觉表示。
  • 提出 动作驱动知识路由器，利用动作损失梯度生成无标注的 token 重要性监督，实现指令条件下的通用/空间 token 选择。
  • 以 0.5B 语言模型和约 53M 可训练参数 在 LIBERO、LIBERO-Plus、CALVIN 和真实世界操纵中取得强性能，展示高参数效率与泛化能力。

04方法描述

  • 双分支视觉编码：冻结原始视觉编码器（仅使用 DINOv2）输出通用特征 Z_v，同时用 LoRA 适应分支输出空间专化特征 Z_p。
  • 空间表示蒸馏：从冻结 3D 专家 VGGT 提取 key/value，与空间分支的 query 计算注意力响应，用 ℓ1 损失对齐两类注意力响应，传递空间知识。
  • 知识路由：路由器由线性投影、视觉-文本交叉注意力和 MLP+Sigmoid 组成，对每个视觉 token 预测门概率；按 top-k 选择后进行位置感知融合，送入 LLM。
  • 梯度监督与训练目标：以动作损失对门概率的负梯度 ReLU 作为 token 重要性，结合动量移动平均生成伪标签；使用 focal BCE、budget 正则和熵正则训练路由器。总损失为动作损失（ℓ1 回归）+ 空间蒸馏损失 + 路由器损失。

05数据集与资源

  • 使用数据集：LIBERO（Spatial/Object/Goal/Long 四个任务套件）、LIBERO-Plus（七类扰动的泛化基准）、CALVIN（长时程语言条件操纵）及真实世界操纵环境。
  • 模型骨干：Prismatic VLM 搭配 Qwen2.5-0.5B 语言模型，视觉编码器使用 DINOv2，3D 专家使用 VGGT。
  • 可训练参数量约 53M，语言模型规模 0.5B；原始视觉通路和 3D 专家均冻结。
  • 训练资源细节（GPU/TPU 类型与数量）在给出的正文部分未明确说明，需参见论文附录或代码仓库。

06评估与结果

  • 评估环境包括 LIBERO 四个任务套件、LIBERO-Plus 七类扰动、CALVIN 长时程任务序列及真实机器人操纵。
  • 主要指标：任务成功率（SR）、CALVIN 的连续完成子任务数 / 平均长度（Avg. Len）。
  • 在 LIBERO 上，SPARK-VLA 取得 Spatial 99.6%、Object 99.6%、Goal 98.0%、Long 96.6%、平均 98.5%，在 tiny-scale（<1B）模型中达到最优水平，并与 7B 级大模型相当。
  • 在 LIBERO-Plus 上，SPARK-VLA 总成功率 78.6%，在 tiny-scale 模型中显著优于 VLA-Adapter（59.0%），在光照、背景、噪声、布局等扰动下表现突出。
  • 在 CALVIN 和真实世界操纵中，SPARK-VLA 以极小参数量取得有竞争力的长时程和样本效率表现，具体 CALVIN 数值见论文表 3。
