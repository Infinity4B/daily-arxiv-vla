Card 02 论文概述

论文概述

  • 提出论文核心模型 GAWM（Geometry-Aware World Model），一个紧凑的多任务世界-动作模型（World-Action Model, WAM），在冻结 DINOv3 编码器的潜在空间中预测未来观测
  • 针对的问题：现有 WAM 大多基于十亿参数级的视觉-语言或视频生成骨干（如 5B 参数的 Wan 2.2 视频生成器），训练成本高、推理延迟大，难以部署在机载计算资源有限的机器人上
  • 研究目标：证明在封闭任务集上，小于 100M 参数的紧凑策略无需 VLM 或视频生成器，也能从“前瞻”（foresight）能力中获益，实现高成功率与低延迟
Card 03 核心贡献

核心贡献

  • 提出 GAWM，一个面向反应式控制（reactive control）的紧凑 JEPA 风格世界-动作模型：任务条件化的轻量预测器预测冻结编码器的潜在 token，动作解码器直接从预测结果回归动作块
  • 在不使用 VLM 和视频生成器的情况下，仅用少于 100M 参数的多任务策略在 RoboTwin 2.0 上超越十亿参数级 WAM，并在真实双臂机器人上的动作预测误差优于微调后的十亿参数 VLA
  • 消融实验表明：在训练数据或训练时间受限时，潜在世界模型带来显著性能提升
  • 分析显示预测结果编码了未来场景的空间布局，且动作解码器按时间顺序关注预测 token
Card 04 方法描述

方法描述

  • 视觉编码：使用冻结的 DINOv3 ViT-S/16 编码器（融合第 7、9、11 层特征），每个相机视角通过带 64 个学习查询的适配器压缩为 64 个 token
  • 任务条件化潜在预测器：以任务编码（task code，由各任务示教计算得到，沿用 LiLa-WAM）而非动作为条件，用双向 Transformer 并行预测两个未来时刻（h₁=H/2 与 h₂=H）的 token；以残差更新方式输出预测（零初始化输出投影，初始预测静态场景）
  • 预测监督：仅训练时使用的 patch 解码器将预测 token 映射为未来帧的稠密 patch 特征，与冻结编码器特征做余弦损失；目标来自冻结编码器因而不会塌缩，无需 SIGReg 等正则化，使预测天然具备几何感知能力（无需深度或 3D 监督即可捕获空间布局）
  • 动作解码器：采用 ACT 风格（TurboVLA 设计），动作查询对包含当前 token、两个预测、状态 token 和任务 token 的记忆做注意力，MLP 直接回归整个动作块（ℓ₁ 损失、确定性回归、无迭代采样或搜索）
  • 推理特点：预测器不基于动作条件化，无需搜索候选动作序列；推理时丢弃 patch 解码器，只处理当前帧，推理成本低
Card 05 数据集与资源

数据集与资源

  • LIBERO：4 个任务套件（Spatial、Object、Goal、Long）共 40 个任务；Standard 设置 1,693 条示教，Extended 设置共 6,585 条轨迹（1.03M 帧）
  • RoboTwin 2.0：50 个双臂任务（Aloha-AgileX 平台），混合协议下每任务 50 条干净 + 500 条域随机化示教，共 27,071 条示教，头/前相机 320×240，14 维绝对关节目标
  • 模型规模：GAWM-S 基于 DINOv3 ViT-S/16（21.6M，冻结）；LIBERO 配置共 38M 参数（2 层 adapter/预测器/解码器，宽度 384），RoboTwin 2.0 配置共 77M 参数；任务代码由示教计算
  • 训练资源：LIBERO 在 8 张 GPU 上训练 80k 步（batch 160）；RoboTwin 2.0 在 32 张 NVIDIA RTX PRO 5000 GPU 上训练 765k 步（batch 128），AdamW 优化器
Card 06 评估与结果

评估与结果

  • 基准：LIBERO（4 套件×10 任务，每任务 50 个初始状态共 2,000 回合）、RoboTwin 2.0（50 个双臂任务，每设置 100 回合×50 任务）、真实双臂机器人
  • 指标：成功率（Wilson 95% 置信区间）、动作预测误差、推理延迟、参数量
  • RoboTwin 2.0：GAWM-S（77M）在 clean/randomized 设置分别达到 93.9% / 93.1%，超越十亿参数 WAM（如 10.9B 的 LingBot-VA 92.93/91.55、11.9B 的 Fast-WAM 91.88/91.78）
  • LIBERO：38M 参数达到 95.6% 平均成功率（Extended 数据），高于 3.2B 参数的 π₀（94.2%）
  • 真实机器人：在held-out示教上，GAWM-S 的动作预测误差低于微调后的十亿参数 VLA，且推理延迟显著更低
  • 消融：在数据量（1/4 示教）或训练步数受限时，世界模型带来大幅增益；预测确实编码了未来场景的空间布局
