KeyMemVLA: Subtask-Guided Key Memory for Long-Horizon Robotic Manipulation

02论文概述

  • 论文提出 KeyMemVLA，面向长时程、依赖记忆的机器人操作任务，解决当前观测中历史证据缺失和任务阶段歧义问题
  • 核心目标是在有限记忆预算下，只保留能 指示任务进度 或 为后续决策保留证据 的历史信息
  • 通过子任务引导的关键记忆选择与在线进度推断，将稀疏关键帧记忆、当前子任务预测和动作生成统一到同一个 VLA 框架中

03核心贡献

  • 提出 子任务引导的关键记忆构造：依据“进度指示”和“决策证据保留”两条准则选择关键子任务及关键帧
  • 构建共享骨干的 VLA 策略，联合学习子任务预测、动作预测和关键帧预测，实现在线稀疏记忆写入与子任务条件控制
  • 引入新基准 KMBench，包含 8 个任务，覆盖记忆引导选择、多线索保留、计数记忆和证据推理四类记忆需求
  • 在 RMBench、RoboTwin-MeM、KMBench 和真实机器人任务上验证有效性，并通过消融和表征分析说明关键记忆与显式任务进度语义的作用

04方法描述

  • 基于 Qwen-OFT 和 Qwen3-VL 骨干，采用 OFT 的动作块预测和连续动作回归
  • 定义关键记忆 \(M_t\)，保留按时间顺序组织的关键帧图像；输入上下文包括指令、视觉锚点（初始帧 + 最近若干帧 + 当前帧）和关键记忆
  • 设计 子任务预测头（SPH），在每一步重新预测当前子任务文本，用于条件化动作生成
  • 设计 关键帧预测头（KPH），通过交叉注意力和门控残差融合预测未来关键帧写入位置，并使用时间软目标进行监督
  • 训练目标联合优化动作 L1 损失、子任务交叉熵损失和关键帧 BCE 损失；在线推理时根据 KPH 分数选择写入位置，并通过时间过滤和 FIFO 淘汰保持记忆预算

05数据集与资源

  • 使用 RMBench（9 个任务，含 5 个 M(1) 和 4 个 M(n)）、RoboTwin-MeM（8 个双机械臂任务）、KMBench（8 个任务，50 demonstrations/任务，共 400 条）以及自建真实机器人数据集（4 个任务，50 demonstrations/任务，共 200 条）
  • 模型骨干为 Qwen3-VL，采用 Qwen-OFT 架构；论文未明确披露总参数量和训练所用 GPU 数量
  • 真实机器人推理使用 Flexiv Rizon4s 机器人和单张 NVIDIA A100 GPU；论文报告 KeyMemVLA 平均推理延迟为 640 ms、GPU 显存占用为 10.20 GiB

06评估与结果

  • RMBench：KeyMemVLA w/o KPH 总体成功率为 68.22%，在 M(n) 任务上为 62.50%，优于 EventVLA 的 54.00%；完整 KeyMemVLA 总体为 64.56%
  • RoboTwin-MeM：KeyMemVLA 平均成功率为 92.63%，较 EventVLA 的 75.20% 提升 17.43 个百分点，在 7/8 个任务上取得最优结果
  • KMBench：KeyMemVLA 平均成功率为 68.88%，较 EventVLA 的 47.13% 提升 21.75 个百分点；计数类任务收益最大，Two-Bin Count 从 35% 提升到 97%，Conveyor Color Count 从 10% 提升到 57%
  • 真实机器人：KeyMemVLA 平均成功率为 47.5%，显著高于 MemER（25.0%）和 π0.5（2.5%）；其中 Find Block 从 20% 提升到 50%，Press Button 从 20% 提升到 60%
  • 消融实验：移除 KPH 后，RoboTwin-MeM 和 KMBench 平均成功率分别下降 61.00 和 47.13 个百分点；移除 SPH 分别下降 30.50 和 5.13 个百分点，验证了关键帧记忆和显式进度语义的有效性
