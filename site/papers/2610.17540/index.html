TacitVLA: Reasoning Vision-Language-Action Models Without Reasoning Latency

02论文概述

  • 提出 TacitVLA，证明动作策略无需在推理时等待或条件化于生成的推理文本，也能从推理监督中获益，因为推理监督本身已提升了骨干网络的表示质量。
  • 解决的问题是：现有推理型 VLA（如 embodied chain-of-thought）在动作前必须自回归解码推理文本，导致严重延迟（生成推理文本占单次调用延迟的 53%–70%）。
  • 在四个基准上开展受控研究，覆盖操作与自动驾驶、记忆与非记忆任务，验证"学习生成推理已足够"这一假设。

03核心贡献

  • 受控实验：在相同序列、数据、提示和优化器下，仅改变动作专家对推理 token 的注意力掩码，证明从不条件化于当前推理的动作专家与条件化版本性能相当。
  • TacitVLA 方法：在记忆任务上以异步方式在动作执行窗口内生成推理条目，实现"Explicit Reasoning 的精度、No Reasoning 的延迟"。
  • 延迟改进：记忆任务上延迟比 Explicit Reasoning 低最多 1.7×，非记忆任务上低最多 3.4×；同时相比 No Reasoning 提升成功率最多 +17.1%。
  • 绝对性能突破：RoboMME Counting 达 82.7%（此前最佳 66.8%），RMBench 达 77.5%（此前最佳 56.5%），LIBERO-Plus 达 72.9%，PhysicalAI-AV 闭环场景得分 52.5%。

04方法描述

  • 架构为 Mixture-of-Transformers：视觉语言骨干生成推理文本，flow-matching 动作专家去噪生成动作块（action chunk）。
  • 关键创新在于注意力掩码：Explicit Reasoning 的动作专家关注 $c_t$ 与 $r_t$；TacitVLA 的动作专家仅关注 $c_t$，屏蔽对推理 token 的注意力（式 2、式 3）。
  • 训练损失为动作流匹配损失与骨干交叉熵损失（推理文本 + 分词动作 $\tilde{a}_t$）的加权和（式 1），两者共享同一训练序列。
  • 延迟机制：非记忆任务不生成 $r_t$；记忆任务在动作执行期间异步生成推理条目。TacitVLA 延迟为 $T_{\text{action}}+\max(0, T_{\text{reason}}-T_{\text{exec}})$（式 4）。
  • 推理可通过两条路径影响动作：交叉熵训练提升骨干表示（路径一）和动作专家直接关注 $r_t$（路径二）；TacitVLA 仅保留路径一。

05数据集与资源

  • RoboMME：16 任务记忆基准，含四个计数任务，使用 FrameSamp 感知记忆与子目标标注；骨干为 PaliGemma ($\pi_{0.5}$)，总参数约 3.7B。
  • RMBench：长程操作记忆基准，使用其中四个任务（各 100 例）；骨干为 RynnBrain-2B，约 2.6B 参数。
  • LIBERO 与 LIBERO-Plus：标准操作基准及分布外扰动测试（10,030 例）；骨干 RynnBrain-2B，约 2.5B 参数。
  • PhysicalAI-AV：私有 380 万驾驶事件语料，开放环 1,434 段验证 + AlpaSim 闭环 441 场景；骨干 Qwen3-VL-2B，约 3.9B 参数。
  • 训练资源：八卡 H100 GPU 节点，延迟在单张 H100 上计时。

06评估与结果

  • 评估环境为四个基准的官方协议与案例，机器人基准成功率为三次评估种子的均值 ± 标准差，闭环驾驶为每场景三次 rollout 均值。
  • 主要指标：任务成功率（%）、场景得分、每次调用延迟。
  • RoboMME：Counting 上 TacitVLA 89.5 vs Explicit 86.7 vs No Reasoning 79.0（甚至高于人类参考 88.5）；全 16 任务上 TacitVLA 48.1 超越最佳已发表结果 44.5。
  • RMBench：四任务均值 TacitVLA 77.5 vs Explicit 77.0 vs No Reasoning 60.4，超越 WLA-0 的 56.5；Press Button 任务 TacitVLA 达 74.3（No Reasoning 仅 7.7）。
  • LIBERO-Plus：TacitVLA 72.9，Explicit Reasoning 73.5，No Reasoning 67.6。
  • PhysicalAI-AV：闭环公开划分场景得分达 52.5%。
