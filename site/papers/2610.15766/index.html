Card 02 论文概述

论文概述

  • 提出 SurgiCLAW，一种面向高精度手术机器人微操作的可解释原子技能（atomic-skill）智能体框架，用于脑机接口柔性电极植入这一代表性高精度手术任务。
  • 核心思路是将语义决策与高精度控制解耦：让多模态大语言模型（MLLM）只负责术中视觉理解、结构化解释和原子技能选择，把物理执行交给可验证的确定性控制程序。
  • 解决的问题：直接端到端迁移 VLA 范式到手术机器人存在三大局限——局部精度无法满足手术误差容限、大模型输出不透明难以被临床医生审查、以及高精度手术数据稀缺。
Card 03 核心贡献

核心贡献

  • 提出 SurgiCLAW 分层原子技能智能体，将 MLLM 限制在术中视觉理解、结构化决策解释与原子技能选择，并通过安全解析器（safety parser）连接到确定性控制器，实现高层语义决策与底层精确执行的分离。
  • 提出多 MLLM 协同数据生成方法：通过视觉与状态扰动、多模型候选生成、基于规则的预验证和跨模型验证，从有限的机器人图像与状态记录中规模化生成高质量的"状态–技能"训练样本。
  • 设计三种奖励（动作正确性、操作前置条件、输出格式合法性），并用GDPO（group reward-decoupled normalization policy optimization）优化策略，系统性地开展离线评估、原子子任务、真实机器人闭环和消融实验。
  • 在固定测试集上达到 94.6% 技能选择准确率与 93.0% Macro-F1；在 50 次真实机器人闭环植入试验中取得 88.0% 任务成功率。
Card 04 方法描述

方法描述

  • 分层架构与动作接口：输入为 $x_t=\{I_t,s_t,q_t\}$（显微图像、机器人状态、操作查询），输出为 $y_t=\{r_t,c_t,f_t\}$，使用固定的 、、 字段编码，其中 think 部分为可审查的决策依据。
  • 原子技能集合：模型只能在 7 个动作中选择——ADJUST_EXPOSURE、ADJUST_FOCUS、E_STOP、SPATIAL_REGISTRATION、RESTART_CAMERA、ALIGN_NEEDLE、INSERT；每个技能由 $\langle n_k,P_k,C_k,T_k\rangle$（名称、前置条件、执行程序、完成判据）定义。
  • 安全解析器：校验字段完整性、函数唯一性与合法性，以及前置条件 $P_k(s_t,I_t)$ 是否满足；非法、多个功能或高风险状态下的运动请求永不派发给机器人，构成 observe–reason–verify–execute–observe 闭环。
  • 数据生成与划分：原始 5,000 个"状态–技能"样本按原始 ID 分组（种子 7）划分为 4,000/500/500，组内独立做六倍增强，得到 24,000/3,000/3,000 共 30,000 条结构化样本；用 DeepSeek-VL2、Qwen3-VL-Flash、ChatGPT-5.5 三个 MLLM 生成结构化理由（temperature 0.7，top-p 0.9，最大 512 tokens）。
  • 交叉验证与人工审核：采用 leave-one-generator-out 方式让模型只对他人生成的候选打分（亮度一致性、状态一致性、理由质量、函数正确性权重 0.30/0.25/0.20/0.25），要求均分 ≥1.6 且验证分歧 ≤0.4；人工抽查 300 例合格 299 例（99.7%）。
  • 训练流程：先以 Qwen3-VL-4B-Instruct 为基座做 SFT，再用 GDPO 做强化优化；三个二值奖励按 0.55/0.35/0.10 加权（先组内独立归一化再加权，最后做 minibatch 级归一化），裁剪系数 $\epsilon_c=0.1$，KL 系数 $\beta=0.01$。
Card 05 数据集与资源

数据集与资源

  • 数据集：脑机接口柔性电极植入任务的自建"状态–技能调用"数据集，由 5,000 个手工采集样本经扰动增强扩展至约 30,000 条结构化训练样本。
  • 测试集：固定增强测试集 3,000 条，其中含明确安全前置条件的样本 2,529 条用于安全性评估；测试集不参与训练、超参选择和奖励设计。
  • 模型规模：基座模型 Qwen3-VL-4B-Instruct（约 4B 参数），对比模型包括 Qwen2.5-VL-3B/7B、Qwen3-VL-4B/30B-A3B/32B/235B-A22B-Thinking、DeepSeek-VL2、Llama-4-Maverick-17B-128E、InternVL3.5-241B-A28B、MiniCPM-o-2.6、SurgVLM-7B、SurgVidLM 等。
  • 训练资源：8 张 NVIDIA A800-SXM4-80GB GPU；LoRA（rank 8，$\alpha=16$）应用于所有线性层；全局 batch 16、单卡微批 1、最大序列长度 8192、学习率 $1\times10^{-5}$（cosine 调度、0.03 warmup、5 个 epoch），bfloat16 + FSDP2 + 梯度检查点，每 250 步验证。
  • 机器人平台：UR5 机械臂 + 植入头，两台 $2\times$ 显微相机（MD65-2T26X 镜头，$2048\times2048$），音圈驱动插入针，KOHZU XA04A-R102 位移台（0.5 μm 分辨率，$\pm0.3$ μm 重复性），KOHZU SA07A-RM02 电极台；实测 2.4 mm 视场，图像平面比例 0.001171875 mm/px。
Card 06 评估与结果

评估与结果

  • 评估设置：离线七分类技能选择评估（准确率、Macro-P/R/F1、安全违规率）＋真实机器人 50 次闭环植入试验（成功率、平均阶段数、人工接管率、不安全提议率，采用 Wilson 95% 置信区间和双侧 McNemar 检验）＋模型侧消融＋控制器级子任务验证。
  • 离线结果：SurgiCLAW 达到 94.6% 准确率 / 93.0% Macro-F1，较最强 SFT 通用模型高 5.5/6.5 个百分点，较 Qwen3-VL-4B-Instruct + SFT 高 11.6/11.9 个百分点；安全违规率降至 0.5%（13/2,529），而 4B 和 32B SFT 模型分别为 3.2% 和 1.9%；仅提示词的通用 VLM 准确率仅 14.2%–38.4%。
  • 真实机器人结果：SurgiCLAW 完成 44/50（88.0%，Wilson 95% 区间 76.2–94.4%），较 Qwen3-VL-4B + SFT 提升 22 个百分点且阶段数减少 19.8%、接管率从 20.0% 降至 4.0%（McNemar $p<0.05$）；较 32B + SFT 提升 12 个百分点但未达统计显著（$p=0.070$）；不安全提议率仅 0.5%（1/194）。
  • 消融结果：去掉结构化理由使准确率/Macro-F1 下降 6.4/6.6 个百分点；仅 SFT（w/o GDPO）为 83.0%/81.1%，加入 GDPO 提升至 94.6%/93.0% 并将安全违规从 3.2% 降至 0.5%；去掉动作正确性奖励主要损害类别选择，去掉前置条件奖励安全违规率最高，去掉格式奖励主要降低召回。
  • 控制器级验证：各确定性控制器在 40 次固定扰动测试中成功率介于 90.0%–100.0%；空间配准 TRE 为 $0.347\pm0.126$ mm，针尖对齐误差 $0.91\pm0.42^{\circ}$，插入误差 $0.015\pm0.006$ mm，安全停止成功率 100%。
  • 局限与结论：作者将结果定位为可行性验证而非临床有效性证据——评估仅覆盖单一高精度任务、使用体模与离体大鼠脑组织，闭环配对试验数量有限，且重复对齐失败和物理插入仍是主要瓶颈。
