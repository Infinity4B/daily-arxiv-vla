Cycle WAM: Coupling Action and Video through Cycle Consistency

02论文概述

  • 提出 Cycle WAM，将视频和动作视为同一交互的两种配对模态，通过循环一致性学习两者之间的对应关系
  • 旨在解决现有世界动作模型（WAM）仅共享骨干但无法保证预测动作与视觉后果一致的问题，从而更充分利用预训练视频先验
  • 模型同时支持前向动力学、逆向动力学和策略执行，并在 LIBERO-Pro、DROID 和真实机器人任务中验证

03核心贡献

  • 从视频-动作对应关系角度研究 WAM 学习，提供理论分析说明双向转换和循环一致性如何互补
  • 提出 Cycle WAM 统一训练框架，在视频-动作协同训练基础上增加 Bidirectional Conversion 和 Cycle reconstruction
  • 在 LIBERO-Pro 上取得可比方法中的最好平均性能，并在 DROID 上显著超越 DreamZero
  • 通过与 UWM 对比，刻画 Cycle WAM 的前向动力学和逆向动力学能力，展示更清晰的视觉预测细节

04方法描述

  • 视频-动作协同训练：基于 DreamZero 式 5B WAM，从 Wan2.2-TI2V-5B 初始化，联合预测未来视频和机器人动作，使用原生 flow-matching 目标
  • 双向转换：视频到动作学习逆向动力学，动作到视频学习前向动力学，并与联合生成任务按概率混合训练
  • 循环重建：引入可微的“视频→动作→视频”循环；使用一步动作估计和原生视频 flow loss，梯度通过共享 WAM 回传以强化跨模态一致性
  • 分阶段训练：协同训练、双向转换、循环重建与联合生成混合；推理时联合生成可直接输出动作进行机器人控制

05数据集与资源

  • 使用 LIBERO-40/90 进行训练，共 5652 个 episode、848036 个帧索引窗口起点
  • 控制评估使用 LIBERO-Pro，迁移评估使用 DreamZero-DROID 14B 模拟器场景，并包含真实机器人实验
  • 模型：DreamZero-style 5B WAM，从 Wan2.2-TI2V-5B 初始化；协同训练 27000 步，双向转换 5000 步，循环阶段 3000 步
  • 训练使用 LoRA 适配器，秩和缩放均为 32；论文未明确列出 GPU/TPU 数量

06评估与结果

  • LIBERO-Pro 四个条件（Spat-T、Spat-S、Goal-T、Goal-S）中，Cycle WAM 平均成功率为 17.8%，优于 DreamZero 的 13.5% 和 UWM 的 6.3%
  • 在 DROID 三个模拟场景中，Cycle WAM 总成功率为 59/60（98.3%），优于无 Cycle 变体（58/60）和 DreamZero（52/60）
  • 逆向动力学评估中，Cycle WAM 旋转 RMSE 为 0.20、运动余弦相似度为 0.85；UWM 分别为 0.23 和 0.83，但 UWM 总体动作 MSE 更低
  • 前向动力学评估中，Cycle WAM 的 PSNR 为 15.92、SSIM 为 0.63、Frame FID 为 96.02，均优于 UWM
  • 真实机器人 5 个场景中，Cycle WAM 完成 3/5 个场景，DreamZero 完成 0/5 个场景；论文指出控制改进并非在所有条件下均一致
