03论文概述

  • 论文提出 WiTac（Wrist-Informed Tactile Representations），一个预训练的触觉编码器，在动作生成之前将触觉信号与腕部视觉深度融合
  • 核心洞察：相似的触觉接触在不同手部、物体和目标配置下需要不同的纠正动作，单独的指尖触觉形变信息存在空间歧义，而腕部相机可以提供解读接触所需的空间参考
  • 解决的问题：现有 VLA 策略中触觉与视觉信号分离注入，导致局部触觉未被周围视觉几何信息所“接地”（grounded），无法形成保留触觉细节的连续接触表征

04核心贡献

  • 提出 WiTac，一个预训练接触编码器，通过物理与视觉联合监督，在动作生成前将触觉历史、手部运动学和腕部观测融合为手指级接触 token
  • 在两个 VLA 骨干网络（GR00T N1.7 和 π₀.₅）和四个真实世界接触密集型任务上验证冻结 WiTac 表征的效用，所有任务上的成功率均超过纯视觉策略和无腕部触觉编码（WiTac-NW）
  • 通过表征分析证明 WiTac 提供更准确的接触描述符、更强的任务-接触联合判别能力、触觉噪声下更低特征漂移，以及更准确的动作方向读出
  • 消融实验证明表征预训练、掩码视觉恢复和注入前融合三个组件均对任务成功有显著贡献

05方法描述

  • 腕部信息接触编码：接收十指 240×240 触觉形变图的八帧历史、双腕部相机 RGB 图像、机器人状态，利用前向运动学获取各手指在腕部坐标系下的位姿，输出每手指一个接触 token（10×768 维）；使用 SharpaWave 空间触觉编码器与因果时间编码器，通过交叉注意力查询腕部 DINOv3 patch 特征形成接触 token
  • 预训练目标（五项自监督任务，无任务成功标签）：接触状态与历史重建（接触面积、形变强度、2D 中心、多步形变/运动历史）、掩码视觉恢复（通过十 token 瓶颈强迫保留腕部视觉上下文）、动作条件 wrench 响应预测（预测未来指尖力/力矩变化）
  • 门控接触注入：冻结 WiTac 编码器，通过轻量级门控交叉注意力接口（门控值范围 [0.05, 1]）将接触 token 注入 VLA 策略的动作专家，同时保留策略原生的视觉、语言和状态输入；训练时使用动作预测损失加接触门 BCE 监督
  • 创新点：与将触觉与视觉分开供应给策略的方法不同，WiTac 在策略注入前深度融合触觉与腕部视觉，形成接地化 visuotactile 接触 token

06数据集与资源

  • 预训练数据集：SharpaDex v1.0，近 300 小时同步灵巧操作数据（含触觉、腕部图像、机器人状态、指尖力/力矩）
  • 机器人平台：Sharpa North 机器人，配有两个 Sharpa Wave 灵巧手，65 维关节命令动作空间（每臂 7 关节、每手 22 关节、头颈 2 关节、下肢 5 关节）
  • 每个评估任务通过外骨骼遥操作收集 200 条演示用于策略训练（四个评估任务均不在预训练数据中）
  • 使用 DINOv3（冻结）提取腕部视觉特征；具体 GPU/训练资源细节在附录中描述

07评估与结果

  • 评估环境：Sharpa North 机器人 + 双 Sharpa Wave 灵巧手，四个双手接触密集型任务：电池插入、碗壁擦拭、USB 重插、开柜门；每任务 20 次试验
  • 主要指标：闭环成功率、接触重建误差、任务-接触联合 macro-F1、噪声下特征漂移/动作 MAE、动作方向余弦相似度
  • 关键结果：

- GR00T 骨干：WiTac 平均成功率 66.3%，比纯视觉基线（37.5%）高 +28.8%，比 WiTac-NW（47.5%）高 +18.8%，也超过独立触觉策略 FTP-1（40.0%）和 T-Rex（50.0%）

- π₀.₅ 骨干：WiTac 将平均成功率从 43.8%（基线）提升至 58.8%（+15.0%），比 WiTac-NW（51.3%）高 +7.5%

- USB 重插任务中，无腕部触觉使成功率从 10% 降至 5%，而 WiTac 提升至 40%（+35%）

- 对比相同预训练数据下的 VT-MUSE 联合表征，WiTac 平均高出 16.3%

- 表征分析：接触重建更准确、任务-接触 macro-F1 提升 1.83–10.14%、触觉噪声下特征漂移降低 35.6–44.1%、动作 MAE 降低 7.35–22.76%（GR00T）、动作方向余弦相似度在所有任务上最高

  • 消融结果：去除表征预训练使平均成功率从 66.3% 降至 53.8%；去除掩码视觉恢复降至 58.8%；分离注入（而非联合融合）降至 50.0%，证实注入前融合触觉与腕部视觉的关键作用
