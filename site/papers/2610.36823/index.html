02论文概述

  • 论文提出 TAPESTRY（Tokenizing Actions as Video Patches in a Shared Transformer Policy），一种将预训练视频扩散 Transformer 改造为机器人策略的“世界动作模型”（World Action Model）
  • 核心问题：如何将视频生成模型中蕴含的物理交互先验迁移到机器人控制中，同时避免推理时昂贵的视频生成，或从头训练动作头导致的先验利用不足
  • 核心洞察：有用的动力学先验存在于视频骨干网络的权重中，而非生成的像素里，因此推理时无需生成完整视频

03核心贡献

  • Action-as-VAE-patch 动作分词：将每个动作时间步视为视频 VAE 潜空间中的单个 patch，复用视频 VAE 的 patchify 卷积并匹配其潜变量的逐 token 均值与方差，动作通路仅新增 1280 个参数
  • 三目标联合训练：单一预训练视频扩散骨干在三个扩散目标上共同训练——视频扩散、视频+动作联合扩散（采用耦合扩散时间步与非对称注意力掩码）、纯动作扩散
  • 单步推理机制：在 zero-terminal-SNR 的 v-prediction 调度下，单步 DDIM 从纯噪声直接生成动作块，并分析解释了多步推理反而引入高频抖动的“频域失配”机制
  • 真实双臂机器人部署：在 20 自由度双臂平台上验证对 novel objects、novel motion primitives 和组合多步任务的泛化能力

04方法描述

  • 以 CogVideoX-2B 视频扩散 Transformer 为预训练骨干，将机器人动作映射为视频 VAE patch token：线性投影 W → affine-free LayerNorm → 复用骨干共享的 patchify 卷积 φ，使动作 token 与视频 token 统计分布一致
  • 联合训练三个扩散目标：video diffusion（机器人+人类视频潜变量）、joint video+action diffusion（共享扩散时间步 + 非对称注意力掩码，动作可关注视频但视频不关注动作）、action-only diffusion（以干净图像潜变量为条件去噪动作）
  • 推理时仅使用动作通路：单次前向传播，从纯噪声经一步 DDIM 直接输出动作 token 序列，无需采样视频 token 或 VAE 解码器
  • 高频抖动分析：自然视频 f95 ≈ 2.0 Hz，而动作块 f95 ≈ 0.35 Hz，视频预训练模型在低噪声区间会错误地合成高频细节，单步推理在 t=T 处规避该失配区域

05数据集与资源

  • 机器人视频数据：DROID、BridgeData v2、AgiBot-World
  • 人类/互联网视频数据：Ego4D、Epic Kitchens、SSv2、Panda-70M
  • 动作标注数据：三个目标任务的室内双臂遥操作演示 + 无指令自由游戏数据（20 维动作空间）
  • 骨干模型：CogVideoX-2B（2B 参数），冻结 3D-VAE 与 T5-XXL 文本编码器，最多支持 3 路相机输入
  • 训练资源：32 张 H200 GPU，75k 预训练步 + 25k 微调步

06评估与结果

  • LIBERO 任务泛化（learning-from-video 协议，仅 LIBERO-90 有动作标签）：平均成功率 76%，超过 Cosmos Policy 与 DreamZero（均 70%）和 AMPLIFY（61%）；从零训练消融降至 58%，隔离出预训练骨干带来 18 个百分点收益
  • 真实双臂操作（YAM 平台，Toolbox/Oven/Corn 三任务）：域内成功率 93±5%，远超从头训练的 Diffusion Policy（50±9%，p<0.001）；三个 OOD 条件（透明玻璃炉门放置、倾倒未见高尔夫球、Lego 置于回旋镖）上达 67±12%，且是唯一完成 novel object composition 任务的方法
  • 推理效率：单张消费级 RTX 5090 上，16 步动作块生成仅需 84 ms、9 GB 显存，比优化后的 DreamZero（5B 模型，3.7 s/块）快约 44×
  • 消融实验：绕过 patchify 卷积 φ 导致训练发散；去掉 affine-free LayerNorm 降至 33%；完全去掉视频扩散损失为 0%；分离的视频/动作目标仅 36%，验证三目标共享骨干训练的必要性
