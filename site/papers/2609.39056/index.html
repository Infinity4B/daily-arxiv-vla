Card 02 论文概述

论文概述

  • 论文聚焦世界-动作模型（World-Action Models, WAMs）的量化推理问题，WAMs 通过共享权重处理视频、本体感觉、动作等异构语义流的迭代去噪生成过程

  • 提出 SteerQuant，一个 4-bit 后训练量化框架，通过动作影响引导的通道缩放与流特定激活调制，在固定位宽和保持共享权重的前提下显著降低 WAMs 的推理开销
Card 03 核心贡献

核心贡献

  • 揭示 WAMs 中不同语义流对量化误差的容忍度不同：匹配的局部数值误差在不同层、不同流、不同去噪步骤下可产生显著不同的动作偏差和任务成功率
  • 提出 SteerQuant 框架，利用 Action-Impact Stream Map 指导共享通道缩放（Shared-Weight Error Routing）和流特定激活调制（Stream-Specific Activation Modulation），保留每层一个静态量化权重矩阵和固定 4-bit 位宽
  • 开发 Rudder 低比特推理引擎，将通道缩放、流增益与输出补偿融合进量化与 GEMM 内核，减少额外 kernel 启动和内存流量
  • 在 Cosmos-Policy、FastWAMJoint、Cosmos-Edge 三个 WAMs 上验证，W4A8/W4A4 下 LIBERO 成功率接近全精度，RoboLab 上优于同精度基线，并实现最高超 FP 的加速比
Card 04 方法描述

方法描述

  • Action-Impact Stream Map：利用 Rademacher 投影高效估计每个层-去噪步-语义流的局部量化误差对最终动作的 RMS 一阶影响，避免显式存储稠密 Jacobian
  • Shared-Weight Error Routing：为每个线性层学习共享正对角缩放矩阵 $\mathbf{D}_\ell$，以 map 推导的重要性权重加权，最小化跨流跨步的重构误差；缩放折叠进量化权重，保持单一权重矩阵
  • Stream-Specific Activation Modulation：在权重固定的基础上，为每个流和去噪步学习增益 $\gamma_{s}$ 与共享阈值 $c$，联合优化并加约束（阈值界、增益界、对数增益归一化），以适应流间动作影响随步骤的变化
  • Rudder 推理引擎：第一个内核将通道缩放和流增益融合进激活量化；第二个内核基于 CUTLASS 执行 INT4 GEMM，并在 epilogue 中完成反量化、逆增益补偿与偏置相加，仅传递整数激活和行缩放

Card 06 评估与结果

评估与结果

  • 对比基线：W4A8 下对比 SmoothQuant、PTQ4DiT、Q-DiT；W4A4 下对比 QuaRot、Atom、SVDQuant；全精度模型作为参考
  • 主要指标：闭环任务成功率（SR）、标准化动作 RMSE、去噪延迟、相对 FP 加速比、峰值 GPU 内存、打包权重存储
  • LIBERO 成功率：W4A8 下 Cosmos-Policy 平均 SR 98.6%、FastWAMJoint 98.1%；W4A4 下分别为 98.3% 和 98.4%；相比各自 FP 参考模型平均成功率降低不超过 0.8 个百分点
  • RoboLab 成功率：W4A8 下 Cosmos-Edge 达 14.67%，W4A4 下达 17.33%，均优于所有同精度基线（最佳基线分别高 1.00 pp 和 1.33 pp）
  • 效率结果：W4A4 下加速比最高为 2.229×（Cosmos-Policy），FastWAMJoint 1.859×，Cosmos-Edge 1.690×；峰值 GPU 内存减少 24.7%–72.2%，权重存储减少 31.3%–73.4%
  • 真实机器人：W4A8 部署获得 1.35× 端到端推理加速，平均任务分数 82.41% 高于 BF16 的 75.93%（单个电池插入任务分数略有下降，但整体平均更高）
