RePlan-VLA: Progress-Aware Replanning for Long-Horizon Vision-Language-Action Models

02论文概述

  • 提出 RePlan-VLA，一个与 VLA 模型无关的框架，将 VLA 的短时程操控能力扩展为可靠的长时程任务执行，无需对底层 VLA 进行微调
  • 解决长时程机器人操作中，VLA 模型难以同时协调进度跟踪、动作生成、错误恢复，导致小错误传播为下游失败的问题
  • 通过将长时程指令分解为短时程子任务，结合视觉进度监控、失败诊断和自适应重规划，实现闭环执行与恢复

03核心贡献

  • 提出 VLA 无关框架 RePlan-VLA，将任务分解、进度监控、失败诊断和重规划从单一 VLA 策略中解耦，保持底层 VLA 冻结
  • 训练了一个基于视觉语言模型（VLM）的进度估计器，在操作原语级别进行视觉进度估计和失败诊断，并生成自然语言反馈以指导重规划
  • 在 RoboCasa365 组合任务上将平均成功率从 40.6% 提升到 62.5%，在 CALVIN ABCD→hardD 上将平均完成子任务数从 3.58/5 提升到 4.10/5
  • 在真实 Franka Research 3 机器人上验证了框架的实际部署能力与失败恢复能力

04方法描述

  • 使用 Qwen3-VL-8B 作为少样本规划器 VLM（planner VLM），将长指令分解为有序子任务，并映射为 go_to 和 move_to 两个操作原语
  • 使用 SAM3 边界框检测 对场景观察进行视觉接地，并由 LLM 指令验证器确保子任务指令符合冻结 VLA 的语言接口
  • 基于 LoRA 微调 Qwen3-VL-8B 得到进度估计器 VLM，结合时序采样观察、任务指令与子任务上下文，输出连续进度值、失败解释与是否重规划标志
  • 底层冻结 Awomo-0.5I（仿真）或 π0.5-DROID（真机）VLA 策略只负责执行当前子任务；失败时根据完成历史、失败子任务和诊断反馈生成新的剩余子任务序列

05数据集与资源

  • 使用 RoboCasa365 的 Composite-Seen 与 Composite-Unseen 分割，共 16 个任务，每个任务 5 个回合
  • 使用 CALVIN ABCD→hardD 中的 100 个具有挑战性的五步指令序列（另有章节表述为 50 个序列）
  • 进度估计器训练 80,000 步，在单张 NVIDIA H100 GPU 上使用 BF16 混合精度与 AdamW
  • LoRA 超参：r=16、α=32；进度预测头维度 1024；有效 batch size=8；学习率 head=10^-4、LoRA=10^-5；梯度裁剪 1.0
  • 执行时每 50 环境步评估一次进度，时序窗口为 5 帧、间隔 10 步；go_to/move_to 完成阈值分别为 0.8 和 0.65

06评估与结果

  • 在 RoboCasa365 上 RePlan-VLA 取得平均成功率 62.5%（Seen 68.8% / Unseen 56.3%），比最强基线 Awomo-0.5I 的 40.6% 高 21.9 个百分点
  • 在 CALVIN ABCD→hardD 上平均完成子任务数 4.10/5，超过最强基线 XR-0 的 3.58/5；完整 5 任务成功率为 58%，略低于 XR-0 的 60%
  • 消融实验表明：SAM3 边界框视觉接地、指令验证、完成历史/失败子任务/失败解释等重规划上下文、少样本及场景观察规划策略、细粒度进度估计均显著影响性能
  • 运行时分析显示平均每步耗时约 0.58 s，进度估计约 2.35 s/次、重规划约 3.56 s/次，每个回合平均重规划约 1.34 次
