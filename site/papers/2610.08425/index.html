Card 02 论文概述

论文概述

  • 论文提出 MIM-VLA，一种基于电机反馈（gripper motor feedback）的视觉-语言-动作（VLA）架构，将夹爪的电流、位置、速度及信号有效性编码为 128 维交互 token（τ），用于显式建模接触后的物理响应。
  • 核心动机：现有 VLA 策略主要依赖视觉外观推断抓取动作，但外观无法完全决定物体接触后的物理反应；视觉相似的物体可能有不同硬度，仅靠关节位置无法区分自由闭合、接触、稳定握持与持续压缩。
  • 方法不依赖额外触觉阵列、力/力矩传感器或标定力估计，直接利用智能夹爪已提供的电机遥测数据，且保持原有的位置控制接口。
Card 03 核心贡献

核心贡献

  • 提出纯电机交互表示（Motor Interaction Module, MIM）：基于时序夹爪遥测与人工审核的接触/相位标签进行预训练，无需标定力传感。
  • 实现夹爪专用集成方式：仅条件化 SmolVLA 的夹爪动作通路，保留预训练视觉-语言主干、手臂通路和位置控制接口不变。
  • 设计共享 token 接口，同时支持闭环夹爪自适应与高层证据条件化比较/解释（通过 Material Explain Module, MEM），并在三种互补的真实世界场景中验证。
Card 04 方法描述

方法描述

  • MIM 编码器：使用 GRU 对因果窗口内的夹爪位置、速度、电流、一阶差分、电机状态位、有效性掩码和时序信息进行编码，输出 128 维交互 token τ；故意保持"纯电机输入"以避免外观捷径。
  • 预训练监督：使用二元接触标签和五种交互相位标签（idle、closing、squeeze、hold、opening）进行辅助头监督；视频仅用于标注生成，不输入编码器。
  • MEM 模块：每个候选物体的 MIM token 序列经 Temporal Summary Module（注意力/均值/最大/最后状态四路池化）生成摘要 token，供 selector VLM 比较并输出结构化选择、相对位置/电流响应及自然语言解释。
  • SmolVLA 集成：冻结视觉-语言主干，新增专用夹爪专家（初始化为预训练动作专家），非对称注意力掩码允许交互 token 关注原始观测上下文但阻断反向路径；最终输出仍为位置命令而非电流/力命令。
Card 05 数据集与资源

数据集与资源

  • MIM 预训练集：360 个交互 episode，覆盖 18 个物体（每个 20 episode），包含人工审核的接触与相位标注。
  • 抓取策略训练集：197 个策略 episode，加上 43 个无接触基线和 3 个高力诊断负样本，共 243 episodes / 65,512 个因果样本（30 Hz，2 秒 200×12 电机历史窗口）。
  • 选择管线训练集：Experiments 1 & 2 共 1,200 个 probe–compare–select 训练 episode。
  • 硬件平台：6-DoF OMY F3M 从臂 + Dynamixel 双指夹爪 + 腕部 Intel RealSense D405；遥测通过 ROS 2 和 Zenoh 传输。
  • 训练资源：单张 RTX 5090，batch size 64；受控对比实验统一取 10,000 次更新后的检查点。
Card 06 评估与结果

评估与结果

  • 评估设置：三个真实世界任务——实验1 跨外观硬度比较（7 对已见 + 3 对未见物体）、实验2 外观匹配物理消歧（3 对真实物体 vs 软复制品）、实验3 易碎物体轻柔抓取（8 个已见 + 3 个未见物体）；每对/每物体 20 次试验，每个策略均对比 vanilla SmolVLA、raw-current 基准及 TA-VLA-inspired 时序电流基准。
  • 材料选择准确率（13 对物体）：MIM-VLA 75.0%（195/260），vanilla SmolVLA 仅 48.8%，raw-current 仅 29.2%。
  • 未见过跨外观对：MIM-VLA 58.3% vs 35.0%（vanilla）vs 23.3%（raw-current）；外观匹配任务达到 68.3%。
  • 轻柔抓取变形指标（SAM 2 掩码面积减少率，越低越好）：已见可变形物体 14.2%（对比 SmolVLA-flow 31.4%、TA-VLA-inspired 24.0%）；未见可变形物体 12.5%（对比 28.0%、20.8%）。
  • 无损伤抓取成功率：已见可破损物体 50.0%（20/40），未见生鸡蛋 30.0%（6/20），显著优于基线（15.0% 和 5%）。
  • 消融研究：MEM 摘要 token 容量 K=4 在离线评估中取得最佳选择准确率（99.5%）、解释一致性（90.0%）和交换一致性（93.8%），为默认配置。
