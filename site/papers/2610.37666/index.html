ThinkWorld: World Imagination Reinforces Chain-of-Dynamics Reasoning

02论文概述

  • 论文提出 ThinkWorld，一个视觉-语言-动作（VLA）学习框架，将动作推理建立在世界动力学（world dynamics）之上，并通过世界想象（world imagination）的强化学习加以增强
  • 解决的核心问题：VLA 模型的泛化能力受限于动作标注机器人演示数据的多样性与覆盖范围；人类视频虽然提供更广泛的行为与环境经验，但缺乏可执行的动作标注，存在“可扩展数据”与“显式动作接地”之间的权衡
  • 核心思想：将每个“动作思考”表示为 Chain-of-Dynamics（CoD，动力学链）——一系列离散运动 token，捕捉连接当前世界与未来状态的中间动力学，作为跨本体（embodiment）的通用动作表示；通过预测每个 CoD 引导的未来并与观测结果对比进行强化，使无动作标注的视频也能提供直接监督

03核心贡献

  • 提出 ThinkWorld 框架：为人类与机器人提供统一的 VLM 原生动作推理接口，并结合内部世界想象机制
  • 提出基于后果的强化学习（consequence-grounded RL）：根据 CoD 与观测未来的一致性给予奖励，使动作推理能从无动作标签的视频中学习
  • 证明框架可从无标注人类视频的规模化数据中获益，实现人到机器人的技能迁移：机器人仅需原子技能的机器人监督，即可执行人类视频中演示的完整组合任务
  • 在仿真与真机实验中验证了对未见任务和环境的强泛化能力（如 OOD 条件下的真机操作）

04方法描述

  • 两阶段训练框架：

- 阶段一（SFT）：用 FAST 风格运动分词器将机器人动作与人类手部运动统一分词为离散运动 token 空间，接地 CoD 推理；同时通过可学习的未来查询（future queries）在冻结的 DINOv3 特征空间中预测未来视觉表征（而非 RGB 像素），联合优化 CoD 交叉熵损失与未来预测损失

- 阶段二（RL）：采用 GRPO 算法，以“想象未来”与“观测未来”之间的运动增强特征相似度作为奖励，采样多个候选 CoD 并奖励预测最匹配观测结果的方案；仅更新 VLM，动作专家保持冻结

  • 关键创新点：未来预测仅作为训练时奖励信号（部署时丢弃），将观测到的世界变化直接转化为动作推理的监督信号，无需动作标注或在线执行候选动作
  • 连续控制由独立动作专家执行，使用受 CoD 与未来预测目标塑造的 VLM 表征（流匹配 flow matching 训练）

05数据集与资源

  • 训练数据（总计约 769K 轨迹、3.9 亿帧、4276 小时）：

- 人类自我中心数据：EgoDex、EgoVerse

- 机器人演示：MolmoAct2-DROID/BimanualYAM、Bridge/RT-1、BC-Z、RoboCOIN

- 辅助 VQA 数据：Pixmo-Cap、RoboPoint、RoboVQA 等

  • 模型规模：Qwen3-VL-2B 作为 VLM 主干（总参数约 2.9B），动作专家来自 MolmoAct2（36 层 Transformer），目标编码器为冻结的 DINOv3 ViT-H/16+
  • 训练资源：SFT 预训练使用 128 块 NVIDIA H100，RL 预训练使用 64 块 H100；本体特定后训练分别使用 32 和 64 块 H100

06评估与结果

  • 仿真基准：LIBERO 与 LIBERO-PRO（含物体、位置、语义、任务、环境等分布偏移）

- LIBERO 平均成功率 97.3%（Spatial 98.2 / Object 98.8 / Goal 97.8 / Long 94.2），优于 OpenVLA、π₀、π₀.₅、MolmoAct、VLA-JEPA 等基线

- LIBERO-PRO 平均 55.6%，在任务与环境偏移下分别达 31.9% 和 60.9%，超过 VLA-JEPA 约 11.1 和 19.9 个百分点

  • 真机评估：双臂 YAM 系统（三相机 RGB 输入），在杯挂、颜色匹配、物体分拣等任务的 OOD 设置下取得最高成功率，优于 Diffusion Policy、MolmoAct2、LaWAM
  • 技能组合实验：人类演示“open → put-left → close”可引导模型组合原子机器人技能并在单次 rollout 中执行完整任务
  • 消融实验：从 Qwen 基线（40.1%）逐步加入历史帧（40.7%）、未来预测（50.4%）、CoD（54.4%）、世界想象 RL（55.6%），各组件均有一致贡献；CoD 在高动态区域的未来预测余弦相似度达 0.62（其他条件为 0.54–0.55）
