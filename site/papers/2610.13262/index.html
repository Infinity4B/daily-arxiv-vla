Dual-Stream Memory for Vision-Language-Action Policies

论文概述

  • 论文提出面向视觉-语言-动作（VLA）策略的双流记忆（Dual-Stream Memory）框架，将长程操作中"执行状态跟踪"与"历史视觉证据回溯"两类需求分配给互补的表示。

Card 03 核心贡献

核心贡献

  • 提出任务无关的 Gated DeltaNet（GDN）压缩器，由进度预测与动作条件特征重建双重监督，将执行上下文与可重建的视觉历史压缩进单个时间 token。
  • 将任务条件的证据访问形式化为阈值检索（Threshold Retrieval），配合共享的时间与空间监督，使保留帧数随可用证据自适应变化而非固定 top-k。
  • 提出线性多尺度融合（Linear Multi-Scale Fusion），在每帧仅 16 个空间 token 的预算内融合粗、中、细三个尺度的特征。
  • 设计两阶段训练流程：第一阶段预训练时间压缩器，第二阶段冻结 GDN 并联合优化检索器与策略。
  • 在 RoboMME 十六任务上取得 49.22% 平均成功率（对比 FrameSamp+Modul 的 44.51%），在四类真实机器人任务上达到 62.5%（对比 37.5%）。
Card 04 方法描述

方法描述

  • 双流架构：时间流将 stride=3 的前视图历史经 DINOv3 类 token 投影至 512 维，通过 6 层 GDN 得到单一时间 token c_t；空间流用冻结的 SigLIP 定位并编码任务相关帧。
  • 循环执行上下文：进度头预测归一化执行进度 p_t=(t−d_e)/max(T_e−d_e−1,1)，使用 SmoothL1 损失（β=0.1）；辅助 Retrospector（4 层因果 Transformer + 最多 16 个动作）在动作条件下重建过去特征。
  • 压缩目标：L_C = L_progress + L_feat + 0.25·L_anchor + 0.09·L_SIGReg，其中 SIGReg 为草图各向同性高斯正则，防止表示坍缩；预训练后移除辅助头。
  • 阈值检索：以任务目标（MiniLM 编码）为查询，对每帧 patch 打分并经 log-sum-exp 得到帧 logit ℓ_i；推理时保留 ℓ_i > 0.6 的帧，按时间顺序保留且不固定帧数。
  • 多尺度融合：将 SigLIP 的 16×16 特征池化为 8×8、4×4、2×2，保留 16 个基础槽位，各与四个细子节点及粗父节点融合（P_4 初始化为单位阵、其余为零），映射为 1024 维策略 token；每帧贡献 16 个 token，空间记忆库共 16·m_t 个 token。
  • 策略集成：基于 RoboMME π_0.5 栈（Gemma 前缀 + 流匹配动作专家），动作专家通过交叉注意力读取空间记忆库与时间 token，门控 g_l = σ(α_l) 初始化为 0.01。
Card 05 数据集与资源

数据集与资源

  • RoboMME 基准：十六个任务，覆盖 Counting、Permanence、Reference、Imitation 四个套件；检索语料含 6,400 个 episode 与 131 个任务目标。
  • 真实机器人数据：Piper 双臂平台，每任务采集 100 条演示（共 400 条），任务为 Pick×3、Swing×2、RePick、Shell。
  • 骨干模型：DINOv3（时间压缩，后两层可训练）、冻结的 SigLIP So400m/14（N=256，16×16 patch）、冻结的 MiniLM（任务编码）、π_0.5 策略。
  • 训练配置：第二阶段 80,000 步、批大小 64、学习率 5×10⁻⁵、10,000 步 warmup；策略视觉编码器冻结；NativeMEM 基线用 30,000 步 tokenizer 训练 + 60,000 步策略训练。
  • 每个评估 seed 每任务 50 个 episode，seed 取 {0, 7, 42}。
Card 06 评估与结果

评估与结果

  • 主要指标：任务成功率 TSR（Task Success Rate, %）；辅以时间/空间 Hit@1 与 AP 评估证据定位。
  • 组件对比（Table I）：GDN 使 Counting 套件均值提升 +6.94 pp（StopCube +15.33）；阈值检索使 Permanence 提升 +4.22 pp（ButtonUnmaskSwap +7.11）；线性多尺度融合使 Reference 提升 +4.50 pp（VideoPlaceOrder +12.00）。
  • RoboMME 全基准（Table II）：完整模型总体均值 49.22%，优于 FrameSamp+Modul（44.51%）、NativeMEM（20.54%）与无记忆 π_0.5（17.93%）；十六个任务中十四个改善，四个套件均值全部提升（Reference +8.98、Counting +5.61、Permanence +2.64、Imitation +1.61）。
  • 记忆与检索分析：进度头在 46,800 个有效帧上 MSE 0.03430；时间与空间 Hit@1 分别为 96.88% / 95.00%，AP 分别为 96.53% / 92.24%；动作条件历史重建在 48 个展示槽位中标注出 38 个匹配、10 个不匹配。
  • 真实机器人（Table III）：平均 TSR 62.5%，比 FrameSamp+Modul（37.5%）高 25.0 pp；Pick×3 从 26.7% 升至 80.0%（24/30），Swing×2 从 36.7% 升至 93.3%（28/30）；RePick 仅 36.7%，Shell 从 53.3% 下降至 40.0%。
  • 局限：增益并非可加（Counting、Permanence 低于其单组件版本）；杯子交换任务暴露持续性身份跟踪仍是未解决需求，未来方向是将有界检索与显式跨帧身份传播相结合。
