02论文概述

  • 论文提出 Holo-M，据作者所述是首个面向人形机器人全身移动作业（loco-manipulation）的离散 VLA（视觉-语言-动作）模型，通过在语言模型词汇表中扩展动作 token 来原生利用语言模型的序列建模能力。
  • 针对人形机器人全身动作空间的高维性、异质性和实时推理需求，论文解决了三个核心问题：tokenization（动作空间如何离散化）、training（如何融合异构数据源）、real-time inference（如何避免长序列自回归解码延迟）。
  • 在 SIMPLE 人形机器人移动作业基准上，Holo-M 在 generalist 和 specialist 两种评估模式下均取得最高成功率，显著超越所有基线模型。

03核心贡献

  • 提出统一动作 tokenizer（unified action tokenizer），将人形机器人动作空间分解为四个身体部位专用 tokenizer——末端执行器（EEF）、身体（body）、手部（hand）、运动学（kinematics），共享一个离散词汇表，支持跨 embodiment 和跨数据源训练。
  • 提出 FAST-RVQ tokenization 方法，结合 DCT 时域压缩与残差向量量化（RVQ），生成固定长度 token 序列，实现低重建误差（验证集上 0.0068）。
  • 提出分组离散扩散解码（grouped discrete diffusion decoding）：每个身体部位内部 token 并行解掩码，跨部位保持自回归条件依赖，将顺序解码深度从 208 步降至 32 步（加速约 6.5 倍）。
  • 通过将动作 token 加入语言词汇表，避免了连续动作专家模型所需的知识隔离（knowledge insulation）问题，动作与语言由同一序列模型生成。
  • 发布全部代码和模型权重。

04方法描述

  • 使用 Qwen3-VL-2B 作为视觉-语言骨干模型，冻结视觉编码器，优化语言骨干用于动作 token 预测。
  • 动作 chunk 为 30 步（30Hz，1 秒），动作空间维度 96（EEF 48、body 29、hand 14、kinematics 5），对应 208 个动作 token。
  • 条件上下文顺序为 图像 → 任务指令 → setup 信息（embodiment 与数据源）→ 量化状态 token（256 bin）。
  • 训练采用四阶段流水线：Stage I 跨 embodiment 自回归预训练（EgoDex + Humanoid Everyday）→ Stage II 人形机器人后训练（SIMPLE）→ Stage III 分组离散扩散微调 → Stage IV 任务特定微调。
  • 推理时通过置信度驱动的解掩码（confidence-based de-masking）并行生成每个身体部位的 token，固定 8 次扩散迭代。

05数据集与资源

  • EgoDex：人类第一视角操作视频数据集，829 小时 / 338k 轨迹，194 个任务，提供 RGB 和手部姿态，用于自回归预训练。
  • Humanoid Everyday（HE）：Unitree G1 人形机器人子集，31 小时 / 10.3k 轨迹，260 个任务，提供 RGB 和动作，用于预训练。
  • SIMPLE：人形机器人移动作业仿真基准，100 万条轨迹，24 个训练任务，提供 RGB、状态和动作，用于后训练与评估。
  • 骨干模型为 Qwen3-VL-2B；真实部署使用 Unitree G1-comp + 两个 Dex3 灵巧手 + RealSense 相机，单块 RTX 5090 运行。

06评估与结果

  • 基准评估使用 SIMPLE 六个代表性任务（XMovePick、BendPick、Handover、Mobile P&P、Grasp、XMoveBendPick），覆盖三个域随机化等级（Level 0/1/2），每组合 10 次 rollouts。
  • Generalist 评估（单模型，无任务微调）：Holo-M 总体成功率 143/180，Holo-M AR 消融版 138/180，均显著领先主要基线 Ψ0（114/180）、ACT（79/180）、DreamZero（38/180）、π0.5（28/180）。
  • Specialist 评估（逐任务微调）：Holo-M 总体成功率 163/180，超过最强基线 Ψ0（154/180）和 Holo-M AR（157/180）；在最长任务 Mobile P&P 上相对 Ψ0 提升近 40%。
  • 消融实验中，预训练数据带来 2.6 倍成功率提升：No Pretraining（53/180）→ HE only（119/180）→ EgoDex + HE（138/180）。
  • 真实世界部署：Tabletop Grasp 任务 10/10 成功率，Move Pick 任务 8/10 成功率；8 步去掩码推理延迟约 476.8±16.9 ms。
