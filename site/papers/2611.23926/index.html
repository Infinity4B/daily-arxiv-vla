GTI: Grounding Task Intent Throughout Long-Horizon VLA Manipulation

论文提出 GTI（Grounding Task Intent） 框架，解决长时程 VLA 操作中全局任务意图难以持续对准当前可执行上下文的问题

论文作者均来自 上海交通大学（Shanghai Jiao Tong University），中国

01研究单位

  • 论文作者均来自 上海交通大学（Shanghai Jiao Tong University），中国
  • 作者包括 Tianqi Gong、Haochen Niu、Yusheng Zhao、Lantao Zhang、Haoyu Liu、Rendong Ying、Peilin Liu

02论文概述

  • 论文提出 GTI（Grounding Task Intent） 框架，解决长时程 VLA 操作中全局任务意图难以持续对准当前可执行上下文的问题
  • 核心思想是利用当前观测与执行历史定位活跃子任务及其执行阶段，并为同一子任务生成阶段特定的视觉里程碑（K1 交互/接触状态 和 K2 局部完成状态）
  • 通过本地语言指令和阶段视觉目标共同条件 VLA 执行器，并在持续异常时进行局部恢复与意图再对齐

03核心贡献

  • 提出 GTI 持续任务意图接地框架，从当前观测和执行历史中定位活跃子任务与执行阶段，并在持续异常后恢复与意图一致的执行上下文
  • 设计 结构化规划器 + 阶段条件视觉接地 机制：生成 K1/K2 阶段视觉目标，并与局部语言指令共同条件 VLA
  • 提出基于 VLA 动作潜特征的 异常监测与局部恢复 模块，通过回滚、重观测和阶段重评估保持子任务意图；保留 K1/K2 缓存，支持失败后重新接地
  • 在 RoboCasa365、VLA-Arena Horizon-Long 和真实 PiPER 机器人上开展完整系统对比、匹配视觉接地消融和部署敏感性测试

04方法描述

  • 记忆式意图定位：使用 Qwen2.5-VL-3B-Instruct 作为规划器，输入全局指令、当前三视角图像和已完成子任务历史，输出技能、物体、目标位置、来源、阶段五个字段；采用字段并行 token 解码，语义切换需两次稳定确认
  • 阶段条件视觉接地：适配 Wan2.2-TI2V-5B-Diffusers，以当前观测、局部指令和阶段为条件生成 K1（接触关系建立）或 K2（局部完成）视觉里程碑；训练使用重复目标监督 [当前帧, K, K, K, K] 保留原生视频时序接口，仅监督未来目标潜位置
  • 执行器适配：VLA 保留原生动作参数化，将预测的里程碑作为第四幅视觉输入，与物理相机视图共同送入共享视觉编码器，如 GR00T 使用 Eagle，π0/π0.5 使用 PaliGemma
  • 异常监测与恢复：采用 LSTM-MLP（1024-256、LSTM-256、MLP、dropout 0.1）对 VLA 最终去噪动作潜特征建模并预测异常概率；持续异常触发 8 步 +z 回滚、4 步稳定和 60 步冷却，重观测后重新评估阶段并复用或重新生成里程碑；恢复触发需连续两个策略 chunk 超动态阈值，每个子任务最多恢复一次

05数据集与资源

  • 数据集与基准：RoboCasa365（18 个 seen atomic、16 个 seen composite、16 个 unseen composite，含 ID 和 cross-scene OOD）；VLA-Arena Horizon-Long（L0+L1 用于适配，L2 作为 held-out；L0 视为原子任务，L1/L2 视为复合任务）；真实机器人 AgileX PiPER 6R 上的柜子搜索/放置、彩椒-香蕉互换、猕猴桃搜索/放置任务
  • 模型规模：规划器 Qwen2.5-VL-3B-Instruct（约 3B 参数）、视觉接地模型 Wan2.2-TI2V-5B-Diffusers（约 5B 参数）、执行器包括 GR00T N1.5、π0.5、π0
  • 训练数据规模：RoboCasa 规划器使用 89,260 个原子状态和 215,934 个复合状态；视觉接地使用 148,790 条 K1/K2 记录；VLA-Arena 规划器来自 728 条 L0/L1 演示，视觉接地 4,317 条 K1/K2 记录；真实机器人使用 1,000 条成功遥操作演示并构建 3,000 条 K1/K2 记录
  • 训练资源：执行器接口适配使用 单 GPU，配置为 per-device batch 8、gradient accumulation 4（有效 batch 32），RoboCasa 共 20,000 次更新；VLA-Arena 训练 1 个 epoch，共 115,198 帧；真实机器人执行器训练 15,000 步
  • 训练配置：规划器冻结视觉编码器，使用 LoRA rank 16、学习率 1e-4、训练 2 个 epoch；视觉接地模型同样使用 LoRA rank 16、学习率 1e-4，训练 4-12 个 epoch
  • 评估设置：模拟实验使用种子 7、42、142 平均；RoboCasa 每任务每种子 50 次试验；VLA-Arena 每个任务 50 episodes，对应 L0/L1/L2 共 500/250/250 episodes；真实机器人每个条件 30 次试验

06评估与结果

  • 离线意图定位精度：RoboCasa 上 Exact-4 为 90.30%、Exact-5 为 79.55%；VLA-Arena 上 Exact-4 为 85.13%、Exact-5 为 83.36%；阶段字段在 VLA-Arena 上准确率达 94.95%
  • 离线视觉接地质量：RoboCasa Atomic 与 Composite 的 PSNR 分别为 18.12 dB 和 17.57 dB；VLA-Arena L0/L1 分别为 19.53 dB 和 20.25 dB；人工诊断 700 个样本中 K1 正确率 90.1%、K2 正确率 83.0%、几何/空间关系正确率 72.0%
  • VLA-Arena 主结果：GTI+π0.5 总体成功率为 47.6%，优于 Global-FT π0.5 的 43.8% 和 ForeAct+π0.5 的 45.2%；在难度更高的 L1/L2 上分别提升 +8.0 / +6.0 个百分点
  • 多种执行器验证：GTI+π0 总体成功率为 45.3%，对比 π0 Global-FT 的 42.2% 和 ForeAct+π0 的 43.6%，总体提升 +3.1 个百分点
  • 消融结果：Global instruction 总体 43.8% → Planner language 44.3% → Planner+phase text 44.8% → Planner+Single-K2 44.9% → K1/K2 w/o recovery 47.0% → GTI 47.6%，显示 K1/K2 阶段目标和局部恢复均带来增益
  • RoboCasa 结果：GR00T 在 seen composite ID/OOD 上的成功率由 14.6% / 12.1% 提升至 31.8% / 20.4%
  • 真实机器人结果：三项任务的平均全任务成功率由 21.7% 提升至 59.2%
  • 主要性能增益集中在 L1/L2 等长时程多阶段复合任务，原子任务 L0 上的提升相对有限，与框架设计目标一致
