WorldContact: A Contact-Centric World Model for Scalable Robot Learning

arXiv 原文 ↗ 中文翻译 ↗

提出 WorldContact，一种以接触为中心的世界模型，用于可变形物体操作，从有限的高质量交互轨迹中高效生成额外训练数据

02论文概述

  • 提出 WorldContact，一种以接触为中心的世界模型，用于可变形物体操作，从有限的高质量交互轨迹中高效生成额外训练数据
  • 解决机器人策略适应新物体和任务时交互数据获取成本高昂的问题，特别是在可变形物体（如购物袋）操作场景下
  • 通过使用比源数值模拟器更大的时间步长进行动力学预测，实现 10倍 加速的状态推演生成

03核心贡献

  • 提出 WorldContact 接触中心世界模型，编码局部几何和运动信息来预测机器人动作下的物体动力学
  • 设计数据生成流水线，将预测轨迹渲染为观测模态并与条件动作配对，用于策略微调的数据扩展
  • 在 16个购物袋操作任务 上验证，实现 10倍 更快的状态推演生成，并提升真实机器人提袋成功率（65% → 95%）

04方法描述

  • Contact-Centric Vertex Tokenizer：将空间接触、拓扑接触、可控接触和环境接触四类信息编码为顶点令牌
  • Hierarchical Token Encoder：通过自注意力和二部图令牌合并策略，将顶点令牌逐层压缩为全局令牌，实现长距离信息通信
  • Global Token Decoder：通过交叉注意力使顶点令牌查询全局上下文，并输出顶点级状态修正
  • 训练策略：采用自回归推演训练，梯度通过所有推演步骤传播；引入可微拓扑投影改善长时间推演稳定性
  • 使用比源模拟器大 20倍 的时间步长，直接预测大间隔的状态变化

05数据集与资源

  • 自构建数据集：16个购物袋操作任务（碰撞、抓取、提升、放置、释放等），每任务25条训练轨迹（共400条）
  • 物体离散化：购物袋 20,274 顶点，球体951顶点，立方体465顶点，夹爪1,114采样点，桌面16,900采样点
  • 源模拟器：SimWeaver，物理时间步0.002s；WorldContact时间步0.04s
  • 模型规模：约 2.00M 参数（1,999,759）
  • 训练资源：8张 NVIDIA H100 GPU
  • 微调基础模型：预训练 Pi05 检查点

06评估与结果

  • 对比基线：RoboCraft、RoboCook、AdaptiGraph
  • 主要指标：Position MSE、Velocity MSE、Penetration Rate
  • 关键结果：WorldContact 在位置MSE（0.0002）、速度MSE（0.0002）、穿透率（0.35%）上全面优于基线方法（RoboCraft分别为0.0598、0.0106、13.88%）
  • 计算效率：在单张 H100 GPU 上实现 10倍 加速（0.4s/s vs 0.04s/s）
  • 真实机器人实验：仅用源数据微调成功率为 65%（13/20），使用WorldContact扩展数据后成功率达 95%（19/20）
  • 消融实验验证了接触中心令牌化器和层次令牌压缩的有效性
