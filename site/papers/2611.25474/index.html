02论文概述

  • 提出 TuringPAI，一个面向设备端物理 AI 的模型家族，包含 TuringPAI-VL（视觉语言基础模型）、TuringPAI-Drive（自动驾驶 VLA）和 TuringPAI-Embodied（机器人操作 VLA）
  • 核心目标是在有限的车载计算资源（如 NVIDIA Orin-X）下，实现空间关系理解、动态环境感知以及从视觉观测到动作的高效转换
  • 解决现有 VLM 在处理多相机、多帧高分辨率输入时序列冗余大、计算成本高、缺乏显式几何与时间监督的问题

03核心贡献

  • 提出 HybridViT-MLQ 架构：结合卷积局部聚合与 Transformer 全局建模，通过多尺度潜查询（MLQ）在同一视觉 Transformer 内融合空间特征和观测历史，显著减少语言模型输入 token 数
  • 构建面向物理 AI 的训练数据混合：在通用图文数据基础上，加入几何感知（深度、3D 定位）、跨视角关联（像素对应、相机姿态）和时序理解（多帧驾驶、机器人操作）监督，提升模型的空间与动态推理能力
  • 训练 TuringPAI-VL（0.65B）基础模型，在保持通用多模态能力的同时，在深度估计、相对位姿估计等几何感知任务上大幅超越 Qwen2-VL-2B 和 InternVL3-1B
  • 展示 TuringPAI-Drive 在自动驾驶中的有效部署：使用 MLQ 将视觉 token 压缩后，开环轨迹预测的所有 ADE/FDE 指标保持在完整 token 基线的 1.2% 以内，驾驶质量成本接近，并在单颗 Orin-X 上实现 12 Hz 轨迹生成
  • 验证跨领域泛化：TuringPAI-Embodied 基于同一基础模型在 LIBERO 四个套件上取得 96.8% 的平均成功率，证明共享视觉语言基础能够支持驾驶和操作两大物理 AI 任务

04方法描述

  • HybridViT：卷积前端将图像划分为 128×128 区域，以总步长 32 生成 4×4 特征网格，拼接后投影得到 patch token，相比 patch-size-16 的 ViT，token 数减少为四分之一；混合注意力 Transformer 负责全局建模
  • Multi-scale Latent Queries (MLQ)：从卷积特征通过多尺度池化初始化粗到细的查询网格，使用统一的 3D RoPE（扩展 DINO 风格 2D RoPE 到时间维）编码空间和时间位置；非对称注意力掩码确保查询聚合 patch 和先前查询，但 patch 不反向聚合查询，只有更新后的查询特征传给语言模型
  • 视频输入组织为四帧窗口，查询层次仅由当前帧初始化，但聚合窗口内所有帧的 patch 证据；语言模型输入 token 数固定为 N_q，与帧数无关（实验中 N_q ≈ 0.3N，T ∈ {1,4}）
  • 部署优化：卷积前端支持在 Orin-X 上的 DLA 与 GPU 异构执行；使用 XPeng Native Runtime (XNRT) 实现 BF16+INT8 混合精度推理，相比 TensorRT FP32+INT8 快 3.69 倍
  • 训练采用两阶段：先对齐视觉编码器与冻结的语言模型，再联合训练全部参数并加入 logit 蒸馏；整个过程使用原生动态分辨率

05数据集与资源

  • 训练数据：通用图文对齐语料、几何监督数据（深度、3D 框、相机姿态、跨视图对应，构建方法参考 VLM3）、多视图 QA 与视频数据、XPeng 内部驾驶数据集（298,000 小时，35M clips，覆盖高速、城市、泊车等场景）、机器人操作多帧数据
  • 模型规模：TuringPAI-VL 视觉编码器 HybridViT-MLQ 为 156M，语言模型为 Qwen2.5-0.5B，总参数约 0.65B；下游 VLA 在此基础上添加任务头（驾驶轨迹头或操作动作专家）
  • 训练资源：使用 H800 GPU 训练，Stage 1 消耗 1,640 H800 GPU-hours，Stage 2 消耗 9,870 H800 GPU-hours
  • 推理硬件：全部分部署和延迟评估均在单颗 NVIDIA Orin-X SoC 上进行；驾驶模型通过 XNRT 实现混合精度加速，机器人操作模型推理阶段（CNN patch 嵌入后）总和为 168.3 ms

06评估与结果

  • 通用多模态理解：TuringPAI-VL 在 RefCOCO 平均 80.91（高于 InternVL3-1B 的 77.88），ChartQA 76.96、DocVQA 80.52、MathVista mini 54.20 等指标上表现突出；视频理解上 MVBench 61.95、MLVU 51.50、LongVideoBench 45.60，均优于 InternVL3-1B
  • 空间感知与推理：NYU Depth V2 绝对相对误差 0.146（Qwen2-VL-2B 为 0.70）；7-Scenes 相对位姿 AUC@30° 19.99（Qwen2-VL-2B 为 2.03）；在 4 个 3D 目标定位基准上直接输出 3D 框，mAP（IoU 0.15）从 20.00 到 39.55，而参考模型无法产生有效分数
  • 自动驾驶开环轨迹预测：在 436k 帧验证集上，HybridViT-MLQ 相比完整 token 的 HybridViT，6s 横向 ADE 降低 1.2%，横向 FDE 降低 1.1%，纵向仅微增 0.5%/0.4%；所有 ADE/FDE 指标变化不超过 1.2%，yaw 误差和 miss rate 略有改善
  • 驾驶质量仿真：使用 XPeng 内部 CCES 套件，五个类别（Compliance, Comfort, Efficiency, Safety, Navigation）的成本比率均在 0.991–1.004 之间，整体驾驶质量几乎无损失；其中后碰撞风险、异常减速、限速不足等指标成本显著降低
  • 设备端部署：TuringPAI-Drive 在单颗 Orin-X 上通过 XNRT 实现 12 Hz 轨迹生成；XNRT BF16+INT8 比 TensorRT FP32+INT8 快 3.69 倍（均使用 QAT），满足车载实时性要求
  • 机器人操作：TuringPAI-Embodied 在 LIBERO 四个套件上取得 96.8% 平均成功率，接近已发表的 OpenPI π₀.₅ 结果；模型推理各阶段总延迟 168.3 ms（Orin-X 上），支持实时操作任务
