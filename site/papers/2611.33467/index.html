SplatWAM: Splatting World Action Models for Real-Time 3D Imagination

01研究单位

  • Locus Robotics：Oscar Mendez

02论文概述

  • 提出 SplatWAM，一种直接在紧凑的 3D 高斯原语上学习动作条件动力学的新型生成式世界模型
  • 解决现有像素/潜变量世界模型无法直接表示真实 3D 场景演化、视角不一致及渲染慢的问题
  • 实现从无位姿 RGB 视图出发，预测可渲染、可探索的未来 3D 场景状态，并同时支持策略控制

03核心贡献

  • 紧凑且几何接地的 3D 状态：SplatWAM-𝒯 将可变数量的未定位视图映射到固定数量的高斯 token，作为策略输入时最多比像素基线高 24.8 个百分点
  • 高斯空间中的直接生成动力学：SplatWAM-𝒟 直接学习动作条件的高斯状态转移，无需单独的潜变量编解码阶段；在单张 RTX 5090 上以约 80 FPS 执行 rollout，且任意预测状态可从任意视角渲染
  • 预测与控制共享主干：SplatWAM-𝒫 在 SplatWAM-𝒟 上添加 agent token 和 flow-matching 动作头，联合优化预测与控制；在 OGBench Scene 上超越 LPWM，匹配 HIQL，在 LIBERO 上无需机器人预训练即可与大规模 VLA 竞争
  • 高斯专用动力学设计：引入 3D 位置嵌入、可微分渲染监督和 log-Euclidean 协方差参数化，显著提升长时程 rollout 质量

04方法描述

  • SplatWAM-𝒯：采用 VGGT 骨干网络编码无位姿视图，通过固定查询 token 解码出 N 个高斯原语（位置、旋转四元数、尺度、不透明度、颜色），使用摄影测量损失、几何损失（深度/法线蒸馏）和正则化损失训练
  • SplatWAM-𝒟：基于 diffusion forcing 的因果 Transformer，逐帧独立加噪，采用 x-prediction 缓解误差累积；使用 shortcut forcing 目标、动作 dropout（CFG）和可渲染损失
  • 高斯专用动力学：使用训练集平均位置的 3D 正弦嵌入作为位置先验；渲染预测帧与目标帧的 2D 一致性损失辅助监督；将协方差从四元数-尺度因子化转为 6 维 log-Euclidean 坐标，消除表示歧义
  • SplatWAM-𝒫：在 𝒟 上附加轻量策略头，agent token 与当前帧世界 token 交叉注意力、自回归历史注意力，并读取目标 token（OGBench 用高斯目标状态，LIBERO 用 CLIP 文本 token）；使用 flow-matching 生成 k 步动作 chunk

05数据集与资源

  • OGBench：使用 Scene 和 Cube play 数据集训练 tokenizer 和世界模型；在 5 个官方的 goal-conditioned 任务评估控制
  • LIBERO：在 Spatial、Object、Goal 和 90 四个套件上预训练 tokenizer，保留 Long 套件做分布外评估；世界模型和策略按 OpenVLA 协议在每个套件演示上训练
  • 模型规模：SplatWAM 约 1B 参数（对照 WorldVLA ~7B、OpenVLA ~7B）
  • 推理硬件：单张 RTX 5090 上实现约 80 FPS 的 rollout 渲染速度

06评估与结果

  • 表示质量（OGBench Scene，2 个上下文视图）：SplatWAM-𝒯 仅用 2K 高斯取得 AbRel 0.055、Normal 37.9°，优于 pixelSplat（100K 高斯）、AnySplat（~370K）和 C3G（2K）
  • 动作条件 rollout（OGBench Scene）：SplatWAM-𝒟 在 H=16/32 的输入视图 PSNR 分别达 24.57/24.15，新视角 PSNR 23.37/23.02，FPS 83.8/83.9；对比 iVideoGPT（20.56/19.28 PSNR，11.0 FPS）、Cosmos3-Edge（25.30/23.73 PSNR，18.9 FPS）和 GWM（19.57/17.91 PSNR，54.6 FPS）
  • 控制性能：跨 8 个任务套件，模型无关的高斯 token 策略比像素策略最多高 24.8 pp；SplatWAM-𝒫 在 OGBench Scene 上超过 LPWM 12 pp，匹配 HIQL 且无需学习价值函数
  • LIBERO 语言条件控制：约 1B 参数的 SplatWAM 超过约 7B 的 WorldVLA 和机器人预训练 OpenVLA，并在无大规模机器人预训练时与 OpenVLA-OFT 持平
