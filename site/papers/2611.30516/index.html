02论文概述

  • 论文提出 JEPA-ICL，一个视觉-语言-动作（VLA）框架，将预测性规划与演示学习相结合
  • 核心问题：机器人如何在自身执行进度与演示进度存在 embodiment、外观和执行速度差异的情况下，有效利用演示经验
  • 通过“进度对齐的潜在计划”（progress-aligned latent plans）同时支持动作生成和演示阶段定位，使机器人能够从相关上下文中学习

03核心贡献

  • Markov 监督的潜在规划：通过循环预测子任务剩余阶段的有序 JEPA 未来状态，在中间检查点和子任务完成点进行监督，使计划保留剩余过程
  • 进度对齐的演示上下文：利用潜在计划定位演示中相关阶段，并通过 memory tokens 读取独立的 JEPA 监督内容特征，将进度对应与内容检索分离
  • 规划与演示联合学习：将未来预测、演示对齐和动作监督结合起来训练共享策略，使策略在有/无演示上下文的条件下都能运行
  • 在多个基准（Imitator Game、LIBERO、LIBERO-Plus 和真实机器人）上验证了方法的有效性

04方法描述

  • 使用 VLA backbone（如 Qwen3-VL 或 π0.5）并引入四类查询 token：plan queries、future queries、action queries 和 memory tokens
  • 潜在世界模型：以当前 JEPA 状态为起点，在 plan 条件下通过单个 Markov 转移逐步预测剩余子任务中 \(K=4\) 个有序检查点的特征
  • 使用 frozen V-JEPA 2.1 编码器提取世界状态特征，监督采用 patch 加权 L1 损失
  • 进度对齐检索：小型 indexer 网络嵌入 plan，通过余弦相似度匹配演示帧；用 contrastive、soft-DTW order 和 cycle 损失训练对齐
  • 内容特征：future queries 预测固定偏移后的 JEPA 特征，演示帧的内容特征通过 memory adapter 转换为 memory tokens，供动作生成使用
  • 训练目标包含 \(\mathcal{L}_{\text{action}} + \beta \mathcal{L}_{\text{plan}} + \gamma \mathcal{L}_{\text{future}} + \lambda \mathcal{L}_{\text{align}}\)，演示计划和特征由周期性更新的 policy copy 缓存

05数据集与资源

  • 数据集：Imitator Game（C15 和 C45 两种预训练规模）、LIBERO、LIBERO-Plus（七种扰动维度）、真实世界双手机器人任务（gear assembly）
  • 模型 backbone：Qwen3-VL 用于仿真主实验，π0.5 用于真实机器人部署
  • 未明确说明模型参数量和具体训练硬件（GPU/TPU）配置；论文附录包含详细实现参数，但正文未披露

06评估与结果

  • 评估环境和协议：Imitator Game（C15/C45 预训练，见任务/未见任务 + 微调）、LIBERO（四个 suite 的成功率）、LIBERO-Plus（七种扰动维度零样本评估）、真实机器人 gear assembly
  • 主要指标：成功率（Success Rate, SR）、子任务成功率（Sub-SR）、七维扰动下的宏平均成功率
  • Imitator Game：C15 预训练下 seen-task 成功率达 80.0%，比 Zero-WAM（68.0%）高 12 个百分点；C45 未见任务经每任务 10 条演示微调后达 85.5%
  • LIBERO：无上下文平均成功率 97.6%，优于无人类视频预训练的 VLA-JEPA 变体（96.1%），在 Spatial、Goal、Long 子套件上取得最佳
  • LIBERO-Plus：无演示平均成功率 73.2%（VLA-JEPA 变体为 62.9%）；加入演示上下文后提升到 75.2%，在七维扰动中有五维达到最佳或次佳
  • 真实世界：gear assembly 任务中 JEPA-ICL 使用部署场景演示成功率达 80.0%，而 π0.5 基线为 40.0%；训练场景演示的帮助小于部署场景演示，验证了进度对齐上下文的有效性
