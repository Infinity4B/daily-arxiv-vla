02论文概述

  • 论文针对具身智能机器人中 VLM（视觉语言模型）与 VLA/WAM（视觉语言动作/世界动作模型）的互补性问题：VLM 擅长高层推理但难以精确控制，VLA/WAM 控制精准但缺乏泛化与记忆能力。
  • 提出通过 策略 harness（Policy Harness） 连接 VLM 推理与底层控制，但 harness 设计空间巨大且测试成本高昂，现有工作多基于少量配置。
  • 研究目标是通过大规模受控实验揭示 harness 设计规律，提供可迁移的设计指南与参考配方 X-Harness。

03核心贡献

  • 发布大规模基准研究，覆盖 8 个仿真基准、267 个任务、6 个 VLM、15 个 VLA/WAM checkpoint，超过 47 万次 rollout，并公开评估套件与日志。
  • 总结出 7 条经验性设计指南（Takeaways），涵盖感知接地、代码结构、VLA/原语路由、代码进化与测试时 VLM 调度等关键决策。
  • 提出参考配方 X-Harness，验证指南可组合性，无需权重更新即可在记忆、推理、域迁移等任务上将基座策略提升最高 +42.8 个百分点。
  • 系统比较了多种 harness 组件（如动作层级、上下文感知、调用时机、代码模板形式），并揭示各组件对 VLM 与 VLA 能力的条件依赖性。

04方法描述

  • 将 policy harness 分解为五个组件：Context（指令、视频、任务备注）、Tools（感知工具、运动原语、VLA 作为工具）、Policy code（自由形式 Python 或符号模板）、Pre-test evolution（基于训练失败的代码修订与回归选择）、Run-time tier（Offline / Semi-online / Full-online）。
  • 设计 7 项受控研究：从 VLM 出发研究动作层级、上下文感知、调用时机、代码形式；从 VLA 出发研究 harness 适用场景、代码进化、测试时 VLM 参与方式。
  • 采用 一因子一变量消融 与匹配种子的大规模仿真 rollout，结合配对 bootstrap 显著性检验（α=0.05）确保结论可靠。
  • 关键创新点包括提出 能力感知路由（根据 VLA 强弱与任务需求自动切换 VLA 调用、3D 原语或逻辑控制）以及 Semi-online 多轮救援 机制（仅在失败信号时触发 VLM，保留已进化代码的闭环优势）。

05数据集与资源

  • 使用 8 个仿真基准：RoboMME、LIBERO（含 LIBERO-PRO 四种域迁移）、ManiSkill3、RoboTwin 2.0、RoboCasa365、RoboDojo、SimplerEnv、VLABench，共 267 个任务。
  • 评估 6 个 VLM：Gemini 3.8 Flash、Claude Sonnet 5.5、Claude Opus 5.5、Gemini 4 Argon、GPT-6 Astra、Gemini 3.5 Flash-Lite，外加两个本地量化 Qwen3.6 模型用于边缘部署验证。
  • 评测 15 个 VLA/WAM checkpoint：包括 6 个 π0.5 fine-tune、3 个 MME-VLA 变体、π0、RLDX-1、XR-1、DM0.5、WALL-OSS-1.0-lite、Awomo-0.5I 等。
  • 训练与评估资源：使用云端 VLM API 及 GPU 进行仿真 rollout，共记录 489,380 次 rollout，覆盖 4,025 个配置单元。

06评估与结果

  • 评估环境：8 个仿真基准，每个配置至少 20 个测试 episode，训练与测试种子分离（如 LIBERO 训练用 30–39，测试用 10–29）。
  • 主要指标：任务成功率、点变化、VLM 等待调整步频、token 消耗等；显著性检验使用 paired bootstrap + Holm 校正。
  • 关键结果：

- VLM 直接输出 3D 位姿失败率高，委托 VLA 子目标并结合 2D 目标标记可显著提升（Flash 在 RoboMME 上从 17.3 提升到 51.9）。

- 提供完整视频历史、任务备注与预提取感知结果可修复大量感知失败，相机深度准确度对 3D 原语代码影响显著（+16.4 点）。

- 预写闭环代码运行速率提高至 16.7–25 Hz，远高于在线 VLM 调用（0.5–10 Hz），且成功率高。

- 代码形式需匹配 VLM 能力：模板对弱模型有帮助（Flash +7.6 点），强模型自由形式更优（Opus −3.0 点）。

- 在 18 个 VLA-基准配对中，harness 在记忆、推理、域迁移任务上带来最大增益，在强 VLA 的标准任务上保持或接近原性能。

- 4–8 轮带回归检查的代码进化可将成功从 50.3 提升至 91.7，且弱模型获益更多。

- Semi-online 多轮救援匹配 Full-online 成功率，但 token 用量减少 42%，且经进化的闭环代码能承受物体位移与视觉干扰。

- X-Harness 在全部 8 个基准上实现显著提升，例如 VLABench 上从 25.5 提升至 68.3（+42.8），RoboDojo 上从 19.6 提升至 31.1（+11.4），且对更强基座（Awomo-0.5I）同样有效。
