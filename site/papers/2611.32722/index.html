AG-WAM: Attention-Guided World Action Model for Accurate and Efficient Robot Manipulation

02论文概述

  • 论文面向机器人操作中的 World Action Models（WAMs），目标是在统一模型中同时预测未来视频观测与机器人动作，为控制提供预测上下文
  • 指出现有 WAM 的注意力分配大多隐式学习，缺少面向动作相关信息的显式引导，导致动作生成精度与效率受限
  • 提出端到端框架 AG-WAM，以显式注意力引导为统一原则，在不使用外部插件模块的情况下显著提升机器人操作精度与推理效率

03核心贡献

  • 提出显式注意力引导作为 WAM 的统一原则，构建端到端框架 AG-WAM
  • 设计 CAPA（Content-Adaptive Predictive Attention）：内容自适应预测视频 token 保留索引，减少冗余 token，集中计算于任务相关信息
  • 设计 GPVA（Guidance-Point Visual Attention）：结合 2D 外观和 3D 几何先验，将视觉注意力显式引向交互相关区域
  • 设计 SCTA（State-Conditioned Text Attention）：依据演化执行状态引导文本注意力，并通过 FiLM 调制动作特征
  • 在三个公共机器人操作基准上以不使用私有具身训练数据取得 SOTA，同时实现 1.45× 推理加速

04方法描述

  • 整体基于 Wan2.2-5B 的流匹配联合视频-动作扩散架构；RGB 经 VAE 编码后 patch 化，指令由冻结 T5 encoder 编码，动作经 MLP 映射为 token
  • CAPA 利用观测视频时空特征和帧间差分，经深度可分离 3D 卷积与 MLP 预测下一 chunk 的 token 保留分数，结合随机采样保留固定比例 token；采用代理梯度解决离散选择的不可微问题，推理时仅对保留 token 去噪并缓存 KV
  • GPVA 将任务目标表示为指导点，2D 分支预测像素高斯热图，3D 分支预测相对偏移与不确定性；经可学习门控融合为注意力 logit 偏置，显式引导动作查询关注交互区域
  • SCTA 从历史视频与动作 token 聚合执行状态，并联合全局任务摘要查询指令 token，生成 FiLM 的 scale/shift 作用于动作流；额外引入区间约束熵损失防止文本注意力过于分散或过度集中

05数据集与资源

  • 使用三个公共机器人操作基准：LIBERO-X、LIBERO-Plus、RoboTwin-2.0
  • 骨干模型为 Wan2.2-5B（约 5B 参数），指令编码器为冻结 T5 encoder
  • 训练资源细节在提供的论文节选中未明确列出；作者强调不使用私有具身训练数据

06评估与结果

  • 评估指标为任务成功率（%），覆盖多个难度等级和泛化设置
  • LIBERO-X：AG-WAM 平均成功率 50.2%，显著优于基线 44.0% 和 LingBot-VA 42.3%；各难度 L1-L5 分别为 79.2% / 69.0% / 44.3% / 33.5% / 24.8%
  • LIBERO-Plus：AG-WAM 总体成功率 95.1%，超越此前最佳 ZimaBlue 91.5% 和 Qwen-RobotManip-Context 91.4%
  • RoboTwin-2.0：AG-WAM 总体成功率 97.14%，Clean 设置为 97.06%，优于 Kairos 96.90% 等方法
  • 推理效率：相比基线实现 1.45× 加速，在保持高精度的同时显著降低计算负担
