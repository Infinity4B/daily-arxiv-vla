From Game Generation to Game Playing: Fully Automated Ability Training for Vision-Language-Action Models

论文提出一个全自动框架，通过自动生成游戏环境和专家演示来训练视觉-语言-动作（VLA）模型，解决游戏指令跟随任务中人类演示数据收集成本高昂的问题。

02论文概述

  • 论文提出一个全自动框架，通过自动生成游戏环境和专家演示来训练视觉-语言-动作（VLA）模型，解决游戏指令跟随任务中人类演示数据收集成本高昂的问题。
  • 核心目标是仅用少量合成数据替代大规模人类游戏演示和在线强化学习，训练出能跨游戏引擎泛化的游戏策略。
  • 模型 Script2Play 基于 Qwen3.5-4B 后训练，仅使用 150.3 小时 合成 Minecraft 和 Roblox 游戏数据，不含任何人类游戏演示。

03核心贡献

  • 设计自动化、技能条件化的游戏生成框架，通过工具型编码代理从自然语言规范构建可执行游戏环境、多样化指令任务和状态验证器。
  • 引入纯合成、数据高效的编程专家监督管线，利用特权模拟器状态合成经过验证的键盘鼠标演示，无需人类游戏数据或强化学习。
  • 仅用 150.3 小时 脚本教师数据，Script2Play 在 OpenHA、OmniGameArena 等公开基准上超越使用数千小时人类游戏数据训练的策略。
  • 通过共享 VLM 骨干的对比实验，证明程序化监督在固定模型架构下仍优于人类游戏和 RL 训练管线。

04方法描述

  • 使用 LLM 驱动的编码代理从技能规范生成游戏场景、任务验证器和程序化教师，游戏需通过五个自动审计门（静态检查、可解性、非平凡性、引擎一致性、视觉检查）才能进入训练数据。
  • 程序化教师利用特权状态（角色位姿、目标坐标、碰撞几何等）规划动作，但仅通过标准键盘鼠标接口执行，不绕过物理引擎。
  • 教师以 200ms 控制间隔生成动作，仅保留验证成功的轨迹进行行为克隆。
  • 学生模型 Script2Play 从预训练 VLM 后训练，输出动作 chunk 为文本格式（鼠标位移 + 四个 50ms 按键组），训练时冻结视觉编码器和投影层。

05数据集与资源

  • 合成数据：Minecraft 26.9 小时（31,494 个验证片段）和 Roblox 123.4 小时（41 个生成游戏，覆盖战斗射击、跑酷、物体交互等六类技能）。
  • 基座模型：Qwen3.5-4B；对比实验使用 Qwen2.5-VL-7B 固定骨干。
  • 训练资源：8 块 H200 GPU，bfloat16 精度，全局批大小 384，学习率 2e-5。
  • 评估基准：OpenHA（Minecraft 指令跟随）、OmniGameArena（UE5 游戏迁移）、ViZDoom（战斗技能迁移）。

06评估与结果

  • OpenHA：Script2Play 平均成功率 69.6%，超过最强现有训练策略 Game-TARS MoE-mini（64.5%）5.1 个百分点。
  • OmniGameArena：Script2Play 平均得分 0.640，在五个单人游戏中排名第一，且未在训练中使用任何 UE5 游戏数据。
  • ViZDoom：展示跨引擎战斗技能迁移，细节见论文表 4（HTML 截断）。
  • 在共享骨干对比实验中，脚本教师监督比人类游戏和 RL 训练管线表现更优，证明合成监督的有效性。
