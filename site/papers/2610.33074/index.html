论文概述

Card 03 核心贡献

核心贡献

  • 提出 AGQ 矩阵级位宽分配方法，结合来自 W4 探针的动作敏感性先验与实测的权重恢复成本，在显式存储预算下优化每个矩阵的位宽。
  • 设计校准与执行流水线，包括 逐通道量化器学习、分组无损编码、逐块恢复，有效降低量化误差以及常驻和临时权重存储。
  • 在 LIBERO 闭环任务上验证 AGQ 有效性：W3 达到 92.7% 成功率，W2.5 达到 70.5%，显著优于 AWQ、GPTQ 和 QVLA 等基线。
  • 提出非对称配置 W1.5\*（W4 视觉 + W1.5 语言），实现 6.10 倍完整模型压缩，同时保留 25.5% 任务成功率。
Card 04 方法描述

方法描述

  • 动作引导位分配：对每个权重矩阵，通过仅将该矩阵量化到 W4 并保持其他参数为 BF16，计算动作偏差作为敏感性 \(S_i\)；同时利用 W4 与 BF16 的执行时间差测量权重恢复成本 \(C_i\)；归一化后加权得到优先级 \(\rho_i\)，在存储预算约束下使用二次罚函数求解每个矩阵的离散位宽（1–4 位）。
  • 逐通道校准：对 W2–W4，学习逐通道裁剪边界，计算量化步长和零点，并通过块重构最小化量化块输出与 BF16 块输出之间的均方误差；对 W1 则学习通道幅度并固定符号。
  • 位依赖的分组编码与执行：对 W2/W3/W4 使用联合 Huffman 编码（将多个相邻权重组为符号），W1 保持原始打包；编码后的权重常驻 GPU，在块进入时进行解码和融合解包/反量化，退出时释放临时 BF16 权重，从而约束临时缓冲区大小。
Card 05 数据集与资源

数据集与资源

  • 使用数据集：LIBERO 四个套件（Spatial、Object、Goal、Long）
  • 评估模型：OpenVLA-OFT
  • 校准资源：部分权重在 A100 GPU 上校准；所有评估在 RTX 3090 GPU 上进行
  • 实验规模：10 个配置，每个配置运行 600 个闭环 episodes（每套件 150 个），总计 6000 个 episodes
  • 模型存储参考：BF16 完整模型为 15.457 GB；AGQ 的 W1.5\* 配置量化后为 2.656 GB，配合无损编码降至 2.534 GB
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 闭环任务，使用 RTX 3090，每次推理预测 8 个动作，延迟测量排除观察预处理和动作后处理
  • 主要评估指标：总体及分套件任务成功率、完整模型存储、峰值 GPU 内存、平均推理延迟
  • 关键实验结果：

- W3：AGQ 成功率 92.7%，比 AWQ（91.5%）、GPTQ（89.0%）、QVLA（37.4%）分别高 1.2、3.7、55.3 个百分点

- W2.5：AGQ 成功率 70.5%，而 AWQ、GPTQ、QVLA 均为 0.0%

- W2：AGQ 成功率 35.0%，AWQ 和 GPTQ 均为 0.0%

- W4：AGQ 成功率 97.7%，超过 BF16 的 96.9%

- W1.5\*（W4 视觉 + W1.5 语言）：成功率 25.5%，完整模型压缩率 6.10×，峰值 GPU 内存从 16.082 GB 降至 3.537 GB（降低 78.0%）

- 延迟：未编码 W4–W1.5\* 配置为 243.6–254.4 ms（BF16 为 187.3 ms）；W1.5\* 加无损编码后为 310.4 ms，W2.5 加编码后为 473.9 ms，表明存储压缩与解码成本需联合权衡
