Verifying Test-State Identity in Paired Evaluation of Vision-Language-Action Models

针对视觉-语言-动作（VLA）模型在仿真基准中的配对评估，指出仅匹配任务、种子和回合编号并不足以保证两个策略经历了相同的测试状态。

01研究单位

  • 独立研究者：作者 Rafiqul Islam（无机构归属）

02论文概述

  • 针对视觉-语言-动作（VLA）模型在仿真基准中的配对评估，指出仅匹配任务、种子和回合编号并不足以保证两个策略经历了相同的测试状态。
  • 提出一个评估完整性框架，包含不变量 I1–I5、来源日志、可选场景指纹和自动化检查器，用于验证配对比较中测试状态身份的真实性。
  • 在 LeRobot 0.6.1 + LIBERO 环境下使用仿真控制器（非真实 VLA）进行受控实验，展示特定向量化重置条件下相同回合索引可能对应不同的初始状态。

03核心贡献

  • 提出评估完整性框架 I1–I5，覆盖身份一致性、结果对比下的一致性、执行一致性、执行模式声明和来源完整性。
  • 开发自动化检查器（evaluation_integrity.checker），输出每条不变量的 PASS/FAIL/SKIPPED 状态、证据详情和配对分数，并支持场景指纹比对。
  • 在 LeRobot/LIBERO 上使用仿真控制器完成受控特征化：混合视野 Sync 发散（Evidence A）、同步视野独立任务对照（Evidence B）、Async 批量大小敏感性（Evidence C）。
  • 给出实用建议：在配对统计前记录解析后的初始状态身份并运行完整性检查，避免仅依赖回合编号。

04方法描述

  • 定义五个可检查的不变量：I1（身份一致性）、I2（结果对比下的一致性）、I3（执行一致性）、I4（执行模式声明）、I5（来源完整性）。
  • 实现命令行检查器，支持 JSON/JSONL 日志输入、条件标签（--condition）、参考标签（--reference）、重复键检测，并给出 any_skipped 和 fully_checked 标志。
  • 在混合视野 Sync 实验中，单个向量环境内偶数槽提前终止（T=8）、奇数槽延后终止（T=40），观察到第二波初始状态 ID 为 [20,5,22,7] 而非连续 [4,5,6,7]。
  • 采用同步视野独立任务作为对照（Evidence B）和 Async+Freeze 批量大小映射比较（Evidence C），分离不同执行模式的影响。

05数据集与资源

  • 使用 LIBERO 的 libero_spatial 和 libero_object 两个任务套件，种子 {0,1}，批量大小 {1,2,4,8}，每单元 10 个回合（Evidence B 共 16 个 Sync 单元）。
  • 模型规模和参数量：未训练或使用真实 VLA 模型；控制器为仿真控制器（emulated early/late 和 mixed-horizon），用于隔离 harness 行为。
  • 训练/运行资源：原始完整 harness 审计使用 NVIDIA RTX 2060 6GB GPU（记录于 results/frozen_phase2/environment.json）；CPU 复现脚本 minimal_repro.py 只需数秒、无需 GPU。
  • 软件栈：LeRobot 0.6.1、Gymnasium 1.3.0、LIBERO、robostats 0.1.0（引用中注释了 0.2.0 可用）。

06评估与结果

  • 评估环境：LeRobot 0.6.1 + LIBERO 的 Sync（NEXT_STEP autoreset）和 Async（FreezeAfter）模式，批量大小 1–8。
  • 主要评估指标：每条不变量的 PASS/FAIL/SKIPPED 状态、pairing_fraction、coverage、raw_id_mismatches、scene_fingerprint 匹配数，以及合成 McNemar 检验的 p 值。
  • Evidence B（同步视野对照）：16 个 Sync 单元、160 对样本，指纹和初始状态 ID 不匹配均为 0。
  • Evidence A（混合视野 Sync）：测量到第二波初始状态 ID [20,5,22,7]，与期望 [4,5,6,7] 不一致，支持重置/索引耦合机制。
  • Evidence C（Async 批量大小敏感性）：Async+Freeze 在 bs=2 和 bs=4 时相对 bs=1 出现 12 个 I3 不匹配；bs=8 因挂起/不完整而标记为 N/A；Sync 模式各批量大小映射一致。
  • Evidence D（合成 McNemar 说明）：正确初始状态配对 p=0.109，错误按回合索引配对 p=3.05×10⁻⁵，说明错误配对可大幅改变统计显著性。
