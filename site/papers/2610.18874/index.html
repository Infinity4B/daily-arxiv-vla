ChunkAct: Action Chunking for Agentic Robotics

2026-10-13 · 原文 · 翻译 · 2610.18874

论文提出 ChunkAct，将动作分块（action chunking）引入智能体机器人（agentic robotics），以解决现有 LLM 智能体在机器人操控中效率低下的问题。 现有方法中，LLM 规划器每执行一个原语（primitive）都需要进行一轮完整推理，导致 LLM 调用次数和输入 token 随原语数量线性甚至二次增长，成本高昂。 ChunkAct 让规划器一次调用启动一个由多个原语组成的动作块，该块自主执行，仅在失败时返回控制；同时离线将记忆编译进动作块，实现测试时无记忆读取。

Card 02 论文概述

论文概述

  • 论文提出 ChunkAct，将动作分块（action chunking）引入智能体机器人（agentic robotics），以解决现有 LLM 智能体在机器人操控中效率低下的问题。
  • 现有方法中，LLM 规划器每执行一个原语（primitive）都需要进行一轮完整推理，导致 LLM 调用次数和输入 token 随原语数量线性甚至二次增长，成本高昂。
  • ChunkAct 让规划器一次调用启动一个由多个原语组成的动作块，该块自主执行，仅在失败时返回控制；同时离线将记忆编译进动作块，实现测试时无记忆读取。
Card 03 核心贡献

核心贡献

  • 提出 ChunkAct，据称是首个让 LLM 智能体在每次调用中提交由链式感知与控制原语组成的动作块、而非单个原语的机器人操控方法。
  • 离线将记忆编译为可泛化的动作块，使测试时无需访问显式记忆，并将 LLM 保留给真正需要推理的决策。
  • 在 LIBERO-Pro 上，相比之前最优的智能体机器人方法，任务成功率提升 5.0 个百分点，同时减少 2.9× LLM 调用、4.4× 输入 token 和 2.3× 输出 token。
  • 在 LIBERO-Plus 上展现出强零样本迁移能力，整体成功率超过最强基线 11.0 个百分点。
Card 04 方法描述

方法描述

  • 离线动作块构建：将记忆按任务类别分区，分解为类型化子目标（如 transport、fixture），把同一类型的记忆条目合并并编译为统一的可执行动作块，按对象类别参数化。
  • 编译保留程序性知识：保留阶段顺序、每个阶段的原语分配、阶段级参数、失败回退策略和验证标准；丢弃不可观测的坐标和特权状态，几何量从当前场景的实时感知中重新估计。
  • 在线动作块触发：测试时规划器用单次工具调用启动动作块；指令被解析为有序类型化子目标，每个子目标选择对应块；规划器接口简化为目标定位和块启动。
  • 自主执行与类型化退出：动作块内部链接各阶段，成功阶段自动决定下一阶段；失败时返回类型化退出（typed exit），包含失败阶段、错误原因、错误日志、机器人状态和新观测。
  • 规划器角色转变：从逐步执行者变为子目标选择器和失败处理器；仅在需要理解任务、场景和响应失败时被调用，使 LLM 计算量随决策数而非原语数增长。
Card 05 数据集与资源

数据集与资源

  • 主要评估数据集为 LIBERO-Pro，包含 Spatial、Object、Goal、LIBERO-10 四个套件在指令重定向（T）和位置交换（S）扰动下的组合，共 8 个组合，每个组合 10 个任务、10 个种子，合计 800 个 episode。
  • 额外评估数据集为 LIBERO-Plus，沿 7 个扰动轴（物体布局、相机视角、机器人初始状态、语言、光照、背景、传感器噪声）变化，共 10,030 个变体；实验在每个任务每个扰动轴下运行单个种子。
  • 规划器使用 GPT-5.6-sol，高推理努力设置，运行于 Codex，每个 episode 预算为 100 次 LLM 调用。
  • VLA 原语使用 π_RLinf（RLinf 微调的 π_0.5 检查点），分割模型使用 SAM 3。
  • 论文未明确说明训练所用的 GPU/TPU 等具体计算资源。
Card 06 评估与结果

评估与结果

  • 评估基准为 LIBERO-Pro 和 LIBERO-Plus；主要指标包括任务成功率（TSR）、规划器调用次数、输入 token 数和输出 token 数。
  • 在 LIBERO-Pro 上，ChunkAct 达到 83.8% 整体成功率，超过 Harness VLA 的 78.8%，提升 5.0 个百分点；同时 LLM 调用从 24.2 降至 8.3，输入 token 从 2.2M 降至 0.5M，输出 token 从 8.5k 降至 3.7k。
  • 在关闭推理时，ChunkAct 仍保持 80.0% 成功率，而 Harness VLA 降至 56.0%；仅运行编译后的动作块、无 LLM 规划器时，成功率为 57.5%，表明 LLM 主要贡献于失败恢复。
  • 在 LIBERO-Plus 零样本迁移中，ChunkAct 整体成功率 83.9%，超过最强先前方法 11.0 个百分点，并在 7 个扰动维度中的 6 个领先。
  • 定性分析显示，一个 22 秒的 LIBERO-Pro episode 中规划器仅调用 8 次：开始启动动作块，物体滑落后根据类型化退出重新定位并再次触发，最终由动作块自主完成任务。
