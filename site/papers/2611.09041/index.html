DobotTrack: Target-Grounded Vision-Language-Action Learning for Embodied Person Tracking

02论文概述

  • 论文提出 DobotTrack，一个面向语言引导具身行人跟踪的目标接地视觉-语言-动作（VLA）框架
  • 针对具身跟踪中目标识别易受遮挡、干扰物和外观变化影响，以及历史视觉信息压缩效率低的问题
  • 通过目标中心辅助监督与身份感知的历史视觉压缩，提升移动代理在单视角下持续跟踪指定行人的能力

03核心贡献

  • 提出 DobotTrack，一个基于 InternVL3 的目标接地 VLA 框架，系统研究五种辅助任务，并采用互补的掩码与边界框监督
  • 提出 Q-identity 模块，利用目标接地预测在紧凑历史 token 中保留身份判别性外观与空间线索，将 8 帧视觉 token 从 2048 压缩到 368
  • 构建真实世界行人跟踪数据集，包含 126 个 episode、596,323 个掩码标注帧，并开发从目标掩码自动推导边界框和视觉-空间分类标签的标注流程
  • 在 EVT-Bench 上，0.8B 参数模型平均成功率达 77.9%，比 OmTrackVLA 高 16.9 个百分点

04方法描述

  • 基于 InternVL3 视觉-语言骨干，输入外观描述指令与 8 帧 RGB 观测窗口，一次前向预测目标掩码、边界框、可见性及 8 个未来路径点
  • 采用 掩码监督（SAM2 解码器）和 边界框监督 作为辅助任务，促进共享骨干对目标外观和空间位置的显式建模
  • 提出 Q-identity：对每个历史帧，先通过目标条件自注意力融入目标区域特征，再通过全图交叉注意力聚合场景上下文，最终输出每帧 16 个紧凑 token
  • 训练目标联合轨迹回归、分割损失（BCE/Dice/IoU/目标存在性）和边界框损失（SmoothL1/GIoU/可见性），训练时对输入框进行扰动并冻结视觉编码器
  • 在线推理中缓存当前帧框和可见性预测，在后续步骤指导历史帧的目标区域选择，实现因果一致的压缩

05数据集与资源

  • 仿真数据来自 EVT-Bench，基于 Habitat 3.0、HM3D 和 Matterport3D 场景，包含约 180 万序列样本，STT:DT:AT 比例为 1:2:1
  • 真实世界数据由四足机器人采集，约 10.2 小时，覆盖室内、室外和公共场所，包含 126 个跟踪 episode 和 596,323 个掩码标注帧
  • 模型为 0.8B 参数，输入分辨率 448×448，每帧 256 个视觉 token，Q-identity 每历史帧保留 16 个 token
  • 训练使用 8 张 NVIDIA B300 GPU，全局 batch size 256（每 GPU 32），约 28,000 优化步，AdamW + BF16 混合精度

06评估与结果

  • 在 EVT-Bench 的 STT、DT、AT 三种设置下评估，指标为成功率（SR↑）、跟踪率（TR↑）和碰撞率（CR↓）
  • DobotTrack 在 STT/DT/AT 上分别取得 SR 90.2% / 72.5% / 70.9%，平均 SR 77.9%
  • 相比仅轨迹训练的基线，DobotTrack 在 DT 上 SR 从 55.9% 提升至 72.5%，AT 从 52.4% 提升至 70.9%
  • 消融实验表明 掩码+边界框监督 与 目标条件压缩 同时使用时效果最佳，且 Q-identity 在 16-token 预算下优于等量池化压缩
  • 在 NVIDIA Jetson Orin Nano 上，将输入 token 从 2048 降至 256 可使推理延迟降低约 52%，验证了压缩对端侧部署的价值
