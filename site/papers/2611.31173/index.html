02论文概述

  • 提出 EmboEagle，一个用于长时程机器人操作的闭环代理框架，旨在解决世界-动作模型（WAM）物理误差累积和无状态 VLM 监督高延迟、缺乏 3D 空间持久性的问题
  • 框架统一了子任务条件 WAM 控制、潜在空间自适应监督和记忆引导的几何恢复，实现选择性高层次监督和物理修正
  • 在 RMBench 和 LIBERO-Mem 基准上取得领先成功率，并通过真实世界任务验证了有效性

03核心贡献

  • 闭环代理架构：提出 EmboEagle，整合子任务条件 WAM 执行、解耦 VLM 任务编排、持久几何记忆以及强制修复后验证
  • 潜在空间自适应 VLM 调用：通过从 WAM 动作令牌转换和子任务语义中蒸馏教师决策，训练轻量级路由门控，无需辅助视觉编码器即可实现选择性监督
  • 边界感知 WAM 适应：开发两阶段流匹配适应方案（Video DiT LoRA + Action DiT 全量微调），在子任务边界截断动作监督，并采用校准固定范围损失
  • 记忆引导的几何恢复：设计结构化内存（初始参考、抓取绑定、工具痕迹）和九种参数化恢复基元，使 VLM 能输出可执行的物理修正动作

04方法描述

  • 子任务条件 WAM 适应：从预训练 Long-WAM 初始化，对 Video DiT 添加 LoRA 适配器进行流匹配微调，随后冻结视频分支并全量微调 Action DiT；在子任务边界使用有效动作掩码和固定范围校准损失
  • 自适应 VLM 调用：路由门控为轻量 MLP，输入为 WAM Action Expert 前后块的动作令牌潜在差值（Δf_t）和子任务嵌入，输出调用概率；使用加权二元交叉熵损失训练，训练数据来自完整逐块教师监督的蒸馏
  • 记忆引导的几何恢复：VLM 响应解耦为诊断状态（ongoing/achieved/abnormal）和离散路由动作（continue/update/recovery/assist）；控制器维护结构化 JSON 内存（refs、held、last_tool），执行参数化恢复技能（lift、home、release、bind、grasp_point 等），每次干预后强制触发 VLM 验证

05数据集与资源

  • 数据集：RMBench（9 个双机械臂任务，包含 M(1) 和 M(n) 两类）、LIBERO-Mem（10 个单臂任务，包括放置、计数、排序/空间推理）、两个真实世界任务（垃圾分类、面包烤制）
  • 模型规模：未明确给出参数量；基于 Long-WAM 预训练检查点（RoboTwin2.0 和 LIBERO 检查点），高 VLM 使用 GPT-6-Astra，路由门控为轻量 MLP
  • 训练资源：4 块 NVIDIA H100 80GB GPU；Video DiT LoRA 训练 10k 步，Action DiT 全量微调 30k 步；视觉历史窗口 48 步，动作块长度 H=32

06评估与结果

  • 评估环境：在 RMBench 和 LIBERO-Mem 上使用全任务成功率进行评估；真实世界实验对比 VoLoAgent
  • 主要指标：任务成功率、VLM 调用次数、效率-成功率权衡
  • 关键结果：

- RMBench 平均成功率 91.3%，超过最强基线 MaP-WAM 8.0 个百分点；LIBERO-Mem 平均 90.6%，超过最强基线 ActMem-VLA 9.8 个百分点

- 真实世界任务中，相同 WAM 执行器权重下，EmboEagle 在垃圾分类（45% vs 32%）和面包烤制（67% vs 51%）上均优于 VoLoAgent

- 自适应门控相比逐块 32 步监督减少 74.2% 的 VLM 调用（3.93 vs 15.26 次），成功率仅下降 2.4 个百分点；消融实验表明恢复模块和辅助模块对任务完成至关重要
