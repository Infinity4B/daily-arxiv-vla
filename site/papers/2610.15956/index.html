Card 02 论文概述

论文概述

  • 论文研究Lights-Out（无灯）工业环境下的无 RGB 导航问题，传统 VLA 模型依赖可见光观测，在关灯工厂中不可用。
  • 提出使用空间音频（Spatial Audio）定位目标方向、深度（Depth）感知局部障碍几何的互补方案：音频指示"去哪里"，深度指示"能否安全通过"。
  • 目标是训练一个可在无可见光环境下可靠导航的具身智能体，并系统评估其在递增声学干扰下的鲁棒性。
Card 03 核心贡献

核心贡献

  • 提出 DarkNav-Bench：基于 Unity 与 IndustryNav 扩展的无 RGB 工业导航基准，包含 24 个工业场景与四级递进声学难度（Clean ⊂ Prop ⊂ DN ⊂ LN）。
  • 提出 ADAPT 框架：通过轻量级空间音频适配器（SAA，来自 SPUR）增强 LMM 的方向感知能力，并进行多模态动作监督微调，实现音频-深度联合推理。
  • 提出 TARS（Transition-Aware Reward Shaping）：在位置–朝向图上定义姿态感知的最短动作势函数，弥补传统测地线奖励对原地旋转不敏感的缺陷。
  • 设计骨干共享 Actor–Critic 与有界动作历史（最近 8 步动作）机制，无需额外记忆模块即可提供时序上下文。
  • 实验证明 ADAPT 在已见与未见场景、全部声学难度下均超越训练型导航基线与零样本多模态模型。
Card 04 方法描述

方法描述

  • 采用三阶段训练流程：① 空间音频适配（SAA）→ ② 多模态监督微调（SFT）→ ③ 基于 PPO 的闭环强化学习。
  • SAA：在音频编码器上附加 SPUR 适配模块，并通过辅助方位角回归头（DoA）将音频表征锚定到声源方向，损失为 L_dir（Eq.10）。
  • 多模态 SFT：以专家轨迹（oracle 规划器）为监督，模型以文本形式预测离散动作，仅对动作 token 计算负对数似然损失 L_sft。
  • TARS：定义势函数 Φ(s) = −N(s)，其中 N(s) 为从状态 s 到目标区域的最少可执行动作数（含前进与旋转），转移奖励为 r_TARS = γΦΦ(s_{t+1}) − Φ(s_t)（γΦ=1）。
  • 总奖励 r_t = r_slack + r_TARS + 1_succ · r_succ，成功奖励按 SPL 加权，鼓励路径效率。
  • 有界动作历史：以纯文本形式拼接最近 8 步动作，不引入额外可训练参数；训练与推理使用同一接口。
  • 动作空间为离散四元组：{a_fwd, a_left, a_right, a_stop}。
Card 05 数据集与资源

数据集与资源

  • DarkNav-Bench：共 24 个工业场景，其中 10 个 seen（含 1200 训练 + 300 测试 episode）与 14 个 unseen（仅 300 测试 episode）。
  • 数据规模：12000 训练 episodes、3000 seen 测试 episodes、4200 unseen 测试 episodes。
  • 声学噪声使用真实机器录音数据集 MIMII 构建扩散背景场，通过 SNR 控制干扰强度。
  • 基础模型：Qwen2.5-Omni-7B。
  • 训练硬件：NVIDIA H200 GPU。
Card 06 评估与结果

评估与结果

  • 评估环境：DarkNav-Bench 四个递进难度（Clean / Prop / DN / LN），分别测试已见与未见的工业场景。
  • 评估指标：SR（成功率）、SPL（路径长度加权成功率）、SNA（动作数加权成功率）、FDG（最终距目标距离，越低越好）。
  • 基线方法：训练型 MAGNet、SAVi、SoundSpaces；零样本 LMM 型 Qwen 2.5-Omni、Qwen 3-Omni（含 oracle 与非 oracle 两类）。
  • 已见场景结果：Clean 下 SR 97.70%、LN 下 SR 67.40%，全面领先基线。
  • 未见场景结果：Clean 下 SR 90.60%，LN 下仍保持 60.00%，显著优于最佳基线（MAGNet LN 仅 1.71%）。
  • 消融实验（LN 设置）表明：SAA 与 TARS 互补增益明显，二者结合效果最佳；动作历史在无 TARS 时增益尤为突出。
