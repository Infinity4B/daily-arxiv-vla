Card 03 核心贡献

核心贡献

  • 提出RoboTwin-Phys系统基准，在RoboTwin 2.0基础上引入13个连续采样的物理属性，结合任务自适应的物理域设计，为物理条件多样性提供标准化评估框架
  • 发布RoboTwin-Phys Training Set v1，包含5000余条兼容RoboTwin官方格式的专家演示，每个样本附带13维物理真值参数，支持物理属性估计、条件感知建模等下游任务
  • 建立物理鲁棒性系统评估协议，对5类代表性WAM和VLA模型开展评估，揭示现有模型在物理条件变化下的显著性能下降，证明物理多样性是现有基准未覆盖的独立鲁棒性维度
Card 04 方法描述

方法描述

  • 基准设计遵循三个核心原则：物理有效性（采样参数对应真实可实现的物理环境）、连续多样性（物理属性在合理范围内连续变化而非离散Few-shot案例）、可组合性（物理变化可与原有视觉、布局随机化独立或联合使用）
  • 共定义13个物理属性，覆盖场景几何、传感配置、物体质量、材料属性、质量分布、关节阻尼六类维度，在每个episode初始化时采样并保持整个rollout固定
  • 针对9个对物理敏感的任务设计专属物理域，避免不合理的参数组合（如锤子质心偏移超出物体本身范围），确保基准评估的是物理多样性而非人工诱导的失败案例
  • 通过专家预规划验证采样物理条件下的任务可行性，排除不可行的episode作为基准实例，保证评估场景的物理合理性

数据集与资源

  • 基准基于RoboTwin 2.0的50个双臂操作任务构建，训练数据集为RoboTwin-Phys Training Set v1，包含5000+专家演示

Card 06 评估与结果

评估与结果

  • 评估环境为RoboTwin 2.0仿真平台，设置三种评估协议：Clean（无任何随机化，标称环境）、Official Random（保留原有视觉和布局随机化，物理参数为标称值）、Physical Random（保留原有随机化，额外按协议采样13个物理属性）
  • 评估指标为任务成功率（百分比），每个任务使用100个rollout episode进行评估
  • 关键实验结果：所有5个模型在Physical Random设置下均出现大幅性能下降，Fast-WAM从91.88%降至44.24%，Motus从88.66%降至39.60%，FACT从88.40%降至39.14%，π₀.₅从82.74%降至31.60%，Galaxea-VLA从93.70%降至37.82%
  • Clean与Official Random下WAM模型性能差距极小，证明物理条件变化是不同于视觉/布局随机化的独立鲁棒性挑战，现有模型的视觉鲁棒性无法迁移到物理维度
  • 任务级分析显示部分任务（如beat_block_hammer、pick_diverse_bottles、move_stapler_pad）在所有模型下均表现极差，而grab_roller、shake_bottle等任务相对鲁棒，说明物理条件引发的失败是结构化的，与接触动力学、质量分布等物理因素强相关
