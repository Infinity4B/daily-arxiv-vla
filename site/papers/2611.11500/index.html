02论文概述

  • 提出 ForeAct，一种将预训练视频世界模型重新用作单次传递表示骨干的机器人操作模型，实现低延迟控制。
  • 解决视频中心世界动作模型推理成本高、缺乏显式空间结构，以及显式几何建模需要额外模块和计算成本的问题。
  • 目标是在不进行额外大规模预训练的情况下，同时利用场景几何和交互动态，实现高效、几何感知的动作学习。

03核心贡献

  • 提出 ForeAct 框架：利用预训练视频世界模型在扩散端点对当前观测的干净潜在进行一次前向传递，提取动作特征，避免未来帧合成和迭代去噪。
  • 引入紧凑的未来几何 token 接口：可学习 token 与视觉 token 通过双向自注意力交互，并接收下一帧相对深度监督，部署时无需深度输入或外部几何骨干。
  • 在 LIBERO、SimplerEnv-Bridge 和 六个真实世界操作任务上分别取得 96.6%、63.5% 和 74.4% 的成功率，且未使用额外的大规模机器人预训练。
  • 通过系统消融验证单次传递干净潜在表示、双向注意力交互和下一帧深度监督的互补贡献。

04方法描述

  • 以预训练 Cosmos-Predict2-2B Video2World 模型作为共享潜在世界骨干，在固定扩散端点 \(t_{\text{diff}}=0\) 处理当前观测的干净视觉潜在，得到观测锚定的视觉 token。
  • 将一组可学习未来几何 token 与视觉 token 拼接，通过双向自注意力联合更新；几何 token 由下一帧相对深度目标（由 MoGe-3 离线生成）监督。
  • 几何读出包括投影、坐标条件映射和 VAE 特征注入，解码为下一帧相对深度；该读出头仅在训练时使用，推理时移除。
  • 动作专家为 16 层 DiT-B（隐藏维度 1024），使用条件流匹配预测动作块；总训练损失结合动作损失和加权几何损失（\(\lambda_{\text{geo}}=0.01\)，深度梯度缩放 0.01）。

05数据集与资源

  • 仿真基准：LIBERO（四个套件，每套件 10 个任务，共 500 个演示）和 SimplerEnv-Bridge（WidowX 机器人，BridgeData V2 演示）。
  • 真实世界：6 个桌面操作任务，使用 Franka Emika Panda 机械臂和 Intel RealSense D435i RGB 相机。
  • 模型规模：约 2.1B 参数（基于 Cosmos-Predict2-2B 骨干 + 动作专家 + 几何读出）。
  • 训练资源：LIBERO 在 4 个 GPU 上训练 100K 步（批量大小 48）；SimplerEnv-Bridge 在 8 个 GPU 上训练 50K 步（批量大小 96）。学习率分别为骨干 \(1\times10^{-5}\)，动作专家和几何读出 \(1\times10^{-4}\)。推理在单个 NVIDIA H20 GPU 上进行。

06评估与结果

  • 评估环境：LIBERO、SimplerEnv-Bridge（固定随机种子，重复三次取均值）以及 6 个真实世界任务（每任务 15 次试验，共 90 次）。
  • 主要评估指标：任务成功率（平均成功率）。
  • 关键实验结果：

- LIBERO 平均成功率 96.6%（Spatial 98.4%，Object 98.8%，Goal 97.2%，Long 91.8%），超过多数基线（如 DepthVLA 94.9%、GeoPredict 96.5%），与 Fast-WAM 和 Cosmos Policy 差距分别为 1.0% 和 1.9%。

- SimplerEnv-Bridge 平均成功率 63.5%，排名第一；其中 Spoon on Towel 87.5%，Eggplant in Basket 100.0%。

- 真实世界成功率 74.4%（67/90），优于 π0（57.8%）和 FastWAM（64.4%）。

- 推理延迟 168 ms（批量 1），低于 Cosmos Policy 和 FastWAM，在精度-延迟权衡中表现优异。

- 消融实验：单次传递干净潜在优于扩散噪声状态（94.3% vs 93.2%）；加入几何 token 和深度监督后提升至 96.6%；双向注意力优于单向（96.6% vs 94.9%）；8 个几何 token 和下一帧深度监督为最佳配置。
