02论文概述

  • 提出 PhysPPF，一种在紧凑物理 token 空间中进行统一时空建模的视觉-语言-动作（VLA）框架，用于机器人操作。
  • 解决复杂操作任务中既需要精确 3D 接触又需要长时域协调的挑战；现有方法通常分别增强空间感知或时序推理，缺乏统一建模。
  • 通过结合空间物理表示（WWH）与时间状态演化（PPF），指导动作生成，提升接触丰富和长时域任务的表现。

03核心贡献

  • 提出 PhysPPF VLA 框架，在紧凑物理 token 空间中统一 3D 空间感知与时间状态演化。
  • 设计 WWH（What-Where-How）表示，将 3D 工作空间结构、任务可达性和局部接近线索分解为紧凑物理 token，仅通过训练时教师监督学习，避免推理时 3D 编码开销。
  • 开发 PPF（Past-Present-Future）时间建模，维护有界过去记忆，通过非对称世界模型联合推断现在和未来状态，并利用并行门控分支注入动作专家，避免跨时间干扰。
  • 在 SimplerEnv、CALVIN、LIBERO 三个基准上验证，相对 StarVLA 基线分别提升 +17.2、+29.3（5 子任务成功率）、+3.5 个百分点。

04方法描述

  • WWH 空间表示：将 3D 感知分解为三类物理 token：*what*（场景级几何与障碍）、*where*（指令条件化可达性）、*how*（度量深度与表面法线接近线索）；使用可学习查询经由 Transformer 与多级 VL 特征交互，输出紧凑物理 token。
  • 训练时教师监督：利用冻结的 VGGT、GLOVER++、Metric3D 教师模型仅通过轻量解码器在训练期间对齐几何场和可达性热图，推理时不使用教师和解码器。
  • PPF 时间建模：维护一个有界双时间尺度记忆（局部缓存 + 全局状态），通过相似性合并压缩冗余准静态步骤；使用非对称掩码因果自注意力，使现在查询仅关注当前观测和过去记忆，未来查询额外单向关注现在查询，实现因果推理。
  • 并行门控条件化：在流匹配 DiT 动作专家中，通过三个平行的门控残差交叉注意力分支分别注入过去、现在、未来物理 token，可学习门控标量平衡三者，避免单注意力 softmax 下的竞争干扰。

05数据集与资源

  • 使用三个机器人操作基准：SimplerEnv（WidowX 机器人，四个任务：Put Spoon、Put Carrot、Stack Block、Put Eggplant）、CALVIN（ABC→D，5 个子任务序列）、LIBERO。
  • 主干网络为 StarVLA（3B 参数）作为基线；PhysPPF 在其上增加世界模型与动作专家，总体参数规模仍为 3B 级别（作者声称参数开销适度）。
  • 训练和评估使用的具体 GPU/TPU 类型及数量在提供的 HTML 片段中未明确给出。

06评估与结果

  • 在 SimplerEnv 的四个 WidowX 操作任务上，PhysPPF 平均成功率达到 79.7%，相比基线 StarVLA 的 62.5% 提升 +17.2 个百分点；各任务分别取得 Put Spoon 93.8%、Put Carrot 62.5%、Stack Block 75.0%、Put Eggplant 87.5%。
  • 在 CALVIN ABC→D 基准上，PhysPPF 在 5/5 子任务成功率上相对 StarVLA 提升 +29.3 个百分点（摘要数据），展现出显著的长时域协调优势。
  • 在 LIBERO 基准上，PhysPPF 相对 StarVLA 提升 +3.5 个百分点，验证了方法在不同操作任务上的泛化性。
  • 与现有空间、历史感知和世界模型 VLA 方法相比，PhysPPF 在保持适度推理延迟和参数开销的同时取得最优性能。
