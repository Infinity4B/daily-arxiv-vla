Card 03 核心贡献

核心贡献

  • 保留接收 token 的光谱迁移：学习到的连续光谱残差通过每个 token 自身的归一化伪彩参考进入，保持预训练编码器、动作解码器与原生 token 宽度不变；在 86 个留出采集会话上类别平衡准确率（bAcc）从 0.812 提升至 0.883，配对会话增益 0.071 [0.050, 0.107]，第二个骨干网络复现该增益（0.812 → 0.914）。
  • 超越类别压缩的连续增强：在五组会话分组测试中，连续状态与后验类别码状态对类内光谱形状的恢复分别为 R² = 0.802 / 0.337；学习残差相对无标签映射也在类别 bAcc（0.865 / 0.773）与解码器 KL（0.048 / 0.062）上更优。
  • 光谱内容与组合方式的交互效应：在 86 个采集上，“自 token 相加”相对“池化替换”使冻结解码后的目标特异性恢复增量约翻倍（交互项 0.0171 [0.0121, 0.0228]）；图像不相交测试显示在相近识别率下，参考固定探针复用率 0.701 对 0.590。
  • 共同扰动预算下的校准收益：在相同位移允许量下，base-fine 以更小的扰动尾部达到与原投影消融相当的识别率，将“投影”带来的操作点收益与单纯识别增益分离。
  • 系统性消融与诊断：提供类别码/残差位置控制、类别匹配光谱交换、等位移校准、检查点与读出敏感性、骨干网络与失败案例分析等完整证据链。
Card 04 方法描述

方法描述

  • 总体框架：冻结 VLA 的视觉骨干与动作解码器，仅在可视化 token 连接处训练一个轻量光谱分支与辅助头，推理时丢弃辅助头。
  • 伪彩参考与目标支撑：传感器覆盖 900–1700 nm，固定波段 [119, 60, 0] 通过冻结骨干与投影器得到后投影嵌入 Z^base ∈ R^{256×4096}；将目标掩码区域池化到 16×16 网格得到占用权重 m_it，经非仿射 LayerNorm 定义参考网格 G_it 与池化基态 B_i。
  • 光谱细残差：将目标的 120 个原始波段与 16 个 NMF 坐标拼接，经瓶颈映射（隐层宽度 r）得到 u_i；通过减去其在 B_i° 上的投影得到近似正交残差 D̃_i，再归一化并缩放到 ρ‖B_i°‖₂（ρ = 0.1） 得到 D_i。
  • 组合与注入：按式 (8) 将残差以掩码加权方式注入每个目标 token：Ĝ_it(q) = (1−m_it)G_it + m_it LN_ε(G_it + qD_i)（q > 0），q = 0 时严格退化为参考 G；非目标 token 保持不变。
  • 创新点：与“池化替换”不同，相加方式在注入分支与跳连分支中均使用 token 自身的参考；结合投影（定义基互补方向）、范数控制与验证集校准的注入尺度 q ∈ U(0,4) 共同约束执行扰动。
  • 训练目标：类别监督的加权交叉熵（共享头 h_c 分类参考态与采样尺度态、独立头 h_f 监督残差本身）+ 0.1 倍 T₀ 参考项 + 1e-4 残差平方均值惩罚；仅用类别标签监督适配器。
  • 执行状态选择：定义相对位移 d_i(q) 与验证均值 d̄_val(q)，在共同位移预算 b 下最大化验证效用 U = bAcc + 0.25·Pair 选择注入尺度；另有等均值校准与信息匹配校准变体。
Card 05 数据集与资源

数据集与资源

  • 数据集：SpectralWaste 语料，原始划分 514/167/171（训练/验证/测试）源图像；取至少 100 像素的四连通目标分量得到 2,295 个物体，划分为 1,392/442/461；主评估采用留一会话的 86 个采集会话、2,291 个物体。
  • 类别：6 类运行性物体类别（film、basket、cardboard、video tape、filament、bag）；四状态代理由类别派生（cardboard→0；film/filament/bag→1；basket→2；video tape→3）。
  • 预处理：立方体从 224 波段线性重采样至 120 波段，图像缩放至 224²，保留原始物体均值光谱，不做逐图像辐射归一化；目标外像素置零。
  • 模型规模：以 OpenVLA（7B 参数） 为冻结骨干，另用 SpatialVLA（8,194 动作坐标）做第二骨干验证；视觉 token 为 256×4096；base-fine 与基条件直接映射器的隐层宽度为 64/32，映射器参数量 271,184 / 275,024。
  • 训练/推理环境：PyTorch 2.6.0、CUDA 12.4、Transformers 4.40.1，bfloat16、批大小 4、无 KV 缓存、缩放点积注意力；选择阶段 12 个内层训练 epoch，重拟合 60 epoch。文中未明确给出 GPU/TPU 的数量与型号。
Card 06 评估与结果

评估与结果

  • 评估环境与基准：以 留一采集会话（leave-one-session-out） 为主估计量，86 个会话各评估一次；固定图像划分作为独立敏感性诊断。对照包括伪彩基线、高锚点直接替换（要求验证余弦 ≥ 0.94）、无正交化消融、光谱-only 重定向器、固定映射替换与池化替换。
  • 主要评估指标：池化 token 类别平衡准确率（类别 bAcc）、token 代理 bAcc、伪彩参考余弦、类内光谱恢复 R² 与夹角、四状态解码器 logit bAcc（refitted 与 reference-fixed / base-fixed FP）、参照态到改动态的 KL 散度、扰动 P95 尾部。
  • 关键实验结果：

- 跨会话识别：基线 0.812 → SPECTRA-VLA 0.883（+0.071 [0.050, 0.107]）；代理 bAcc 0.860 → 0.916；高锚点直接替换仅 0.814（余弦 0.991），说明“参考相似度高”并不等于获得光谱增益。

- 光谱内容：连续表示类内恢复 R² = 0.824，显著优于类别后验 0.374 与硬类别码 0.333（ΔR² = 0.450 [0.398, 0.504]）；留出会话上为 0.802 vs 0.337。

- 组合方式：相同残差与尺度下，自 token 相加相对池化替换在冻结解码器 logit 上复用外部类别探针为 0.701 vs 0.590；类别匹配交换显示自 token 组合约使目标特异性恢复增量翻倍。

- 解码器扰动：学习残差相对于无标签映射降低平均解码器 KL（0.048 vs 0.062）并提升类别 bAcc（0.865 vs 0.773）；等位移校准下 base-fine 与原投影消融识别率相当但扰动尾部更小。

- 消融与稳健性：去除正交化的“无正交化”变体在部分单元格识别略高（0.893），但在共同位移预算下未获得同等扰动优势；召回在六类中的五类提升，仅 filament 从 0.859 微降至 0.848；逐会话删除均保留正向类别增益（0.068–0.078）；全光谱相对伪彩三波段优势为 0.886 vs 0.835（配对 CI [0.032, 0.075]）。
