Card 03 核心贡献

核心贡献

  • 提出 VLALagBench 基准，系统性地评估 VLA 推理延迟对任务成功率的影响，涵盖任务类型、物体速度、执行模式（同步/异步）和 VLA 策略五个因素
  • 揭示延迟敏感性的两个关键机制：观测滞后（stale observations）损害高精度任务，机器人暂停（robot pauses）破坏连续运动任务
  • 对比同步执行与两种异步执行（lazy 和 continuous）的权衡：异步执行通过重叠推理与动作执行恢复部分成功率，但代价是更高频率的推理请求
  • 开发实证模型（基于观测滞后和空闲时间的线性速度调整模型），从有限校准数据预测任务成功率，实现算法-系统协同设计
  • 展示不同推理系统（机载 GPU、边缘服务器、共享服务器、云端）最优执行模式与执行时域配置各不相同
Card 04 方法描述

方法描述

  • 基准在 LIBERO + MuJoCo 上构建，遵循四大设计原则：静态场景零延迟下高成功率、多样化运动目标交互、精确可控的目标轨迹且不改变接触物理、多个公开权重的 VLA 模型可复现
  • 设计四个运动目标任务：Release（放入移动篮子）、Set-down（放到移动盘子上）、Grasping（抓取移动柜子上的碗）、Articulated manipulation（拉动移动柜子的抽屉），目标以 0.001–0.2 m/s 恒速沿近似椭圆闭合路径运动
  • 定义三种执行模式：同步执行（每 H 个动作后暂停 L 步推理）、惰性异步执行（最少推理频率、零空闲）、连续异步执行（最高推理频率、最低观测滞后 H=L）
  • 延迟注入机制：将推理延迟转换为模拟器控制步数（20 Hz 下 100 ms = L=2 步）
  • 实证模型：S_X(v) ≈ S_0(λ_X·v)，其中 λ_X = 1 + a·(s̄_X−s̄_0)/s̄_0 + b·I_X/H_X，系数 a、b 分别刻画对观测滞后和机器人暂停的敏感度，按策略-任务对分别拟合
Card 05 数据集与资源

数据集与资源

  • 主基准：LIBERO（MuJoCo 模拟器）上的四个改造任务；次基准：DynamicVLA 的 DOM 基准（Isaac Sim）用于跨模拟器验证；另有真实机器人实验
  • 评估三个 VLA 策略（官方公开权重）：π0.5（chunk 大小 K=10）、GR00T N1.7（K=16）、MolmoAct2（K=10）；跨模拟器验证使用 DynamicVLA
  • 每个成功率基于 200 次 rollout，每回合 600 个动作预算，20 Hz 控制频率，执行时域 H=5
  • 推理延迟扫描范围 0–250 ms（50 ms 步长）
  • 系统部署场景涵盖 Jetson AGX Thor（机载，72.8 ms 延迟）、RTX 4090 + WiFi 7（边缘，37.8 ms）、H100 + 5G（共享服务器，42.9 ms、限 5 req/s）、H100 慢速云（217.9 ms 延迟）
Card 06 评估与结果

评估与结果

  • 评估覆盖五个维度（任务类型、目标速度、策略、执行模式、延迟），0–250 ms 延迟、200 rollout/配置
  • 发现 1：目标速度 0.1 m/s 时，100 ms 延迟使 Set-down 成功率从 71.5% 降至 40.5%（保留 57%），而 Grasping 仅从 86.5% 降至 74.0%（保留 86%）
  • 发现 2：Set-down 需要 3 cm 放置精度（Release 容差 12.2 cm），对观测滞后敏感；Release 和铰链物体操作对机器人暂停敏感（200 ms 延迟使 π0.5 平均接近速度降低 34%）
  • 发现 3：异步执行在 200 ms 时将 π0.5 的 Release 成功率从 48.5% 恢复到 81.5%；50 ms 时连续异步使 Set-down 成功率从 51.5% 提升至 70.0%（甚至超过零延迟同步基线）
  • 发现 4：最优策略取决于任务和目标速度；如 π0.5 对初始位置鲁棒（Set-down 93.5%），而 GR00T N1.7 仅 56.0%
  • 预测模型：跨任务和执行模式 RMS 误差 5.7%（π0.5），跨策略为 5.7–7.8%；少量校准数据下中位 RMS 误差 7.7%；中间执行时域（H=2/3/4）预测误差 2.8–3.3%
  • 配置选择：使用 System A 的测量数据为 Systems B–D 预测最优配置，预测配置与实测最优配置全部匹配，预测误差 2.5–4.6%
