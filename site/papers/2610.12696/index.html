Spa-Bench: A Real-Robot Benchmark for Spatial Grounding in Vision-Language-Action Models

论文关注视觉-语言-动作模型（VLAs） 在真实物理场景中的空间 grounding 能力，即如何将语言中的空间描述（属性、位置、数量、关系）映射为合适的机器人动作。

02论文概述

  • 论文关注视觉-语言-动作模型（VLAs） 在真实物理场景中的空间 grounding 能力，即如何将语言中的空间描述（属性、位置、数量、关系）映射为合适的机器人动作。
  • 现有基准通常将空间理解嵌入整体任务成功率中，难以区分失败是源于空间 grounding 错误，还是物体识别、运动执行等问题。
  • 论文提出 Spa-Bench，一个真实机器人基准，通过六项桌面任务、ID/OOD 空间配置和四种诊断条件，系统评估 VLAs 的空间 grounding 可靠性。

03核心贡献

  • 提出 Spa-Bench，包含六项真实机器人桌面任务，覆盖属性、关系和场景结构三类空间 grounding 轴，并支持 ID 与 OOD 物理配置的对比评估。
  • 设计 withheld-cell 控制评估协议，确保 OOD 配置中涉及的物体、空间概念和动作均在训练中出现，仅保留概念-参数组合为 OOD，从而减少物体和运动不熟悉作为失败解释。
  • 引入四种诊断条件：直接操作控制、提示改写、跨任务物体、无干预场景，分别探测物理执行、措辞敏感性、物体-任务关联和动作门控能力。
  • 评估五个微调 VLA 策略（VLA-0、MolmoAct2、π0.5、GR00T-N1.7 F-LLM、GR00T-N1.7 F-FT），并发布 4,092 个 SO-101 机器人回合，包括 1,200 个人类遥操作演示和 2,892 个真实机器人评估 rollout。

04方法描述

  • 六项任务：Object State、Relative Size、Relational Placement、Referential Description、Ordinal Position、Counting，均使用相同的 SO-101 机器人、工作空间、容器和抓放动作族。
  • 核心变化在于场景 grounded 规则：决定操作哪个物体、放置在哪里、或是否需要动作。
  • Withheld-cell 设计：将训练支持表示为概念-参数矩阵，观测单元用于 ID 评估，保留单元用于 OOD 评估，确保 OOD 组合中的各个组件在训练中均出现过。
  • 评估协议：每个完全评估的策略完成 900 次物理 rollout，包括 20 次 ID、50 次 OOD、20 次匹配直接操作、20 次提示改写、20 次跨任务物体、20 次无干预（部分任务有调整）。
  • 模型适配：统一使用 6 维机器人状态和中间、手腕两个 RGB 视图，训练 12 个 epoch，全局批次大小 96，采用各模型原生预处理和微调流程。

05数据集与资源

  • 数据集：Spa-Bench 包含 1,200 个人类遥操作演示（每任务 200 个），总计约 5.7 小时，612,733 帧，同步机器人状态、动作、语言指令和五个 RGB 相机视图（评估仅使用中间和手腕视图）。
  • 物体：27 个可移动物体实例，涵盖 11 个形态家族。
  • 模型规模：GR00T-N1.7 为 3B 参数版本；VLA-0 基于 Qwen2.5-VL-3B-Instruct；π0.5 和 MolmoAct2 为更大规模 VLA 架构。
  • 训练资源：4 个 NVIDIA GH200 Grace Hopper Superchips，每设备批次大小 24，全局批次 96，训练 12 个 epoch。

06评估与结果

  • 评估环境：真实 SO-101 机器人，固定光照和相机位置，无人工干预，二值任务成功作为主要指标。
  • ID 与 OOD 对比：三个完全评估的策略 ID 成功率 67.5%–73.3%，OOD 成功率降至 40.7%–52.0%。
  • 匹配场景诊断：直接操作指令在相同场景下成功率达 81.7%–89.2%，比 OOD 空间指令高 28.3–40.0 个百分点。
  • 提示改写：改写后空间指令成功率下降，而直接指令影响因模型而异，表明空间 grounding 失败并非仅由措辞导致。
  • 任务级失败分析：所有策略在 OOD Counting 任务中全部失败（几乎均不动作）；Ordinal Position 多为选错物体；Object State 多为同类物体错选；Relational Placement 多为接近目标后空间结果错误。
  • 动作门控：无干预成功率整体仅 20.0–23.8%，但在 Counting 目标已满足时达 80–85%，表明策略能静止，但无法可靠判断是否需要动作。
