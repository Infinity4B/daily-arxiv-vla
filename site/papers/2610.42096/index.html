CausalWAM: Learning the Causes of Actions in World Action Models

02论文概述

  • 提出 CausalWAM (CWAM)，解决世界动作模型（WAM）中“动作生成只依赖部分潜变量，而场景预测需要全部潜变量”的纠缠问题。
  • 目标是从演示数据中分离出 动作相关潜变量（action-relevant latent variables） 和 干扰变量（nuisance variables），确保动作仅由动作原因驱动。
  • 论文证明：在支持稀疏性约束下，动作相关潜变量可被块级可逆恢复，状态到动作的依赖结构可识别到潜变量置换，且无需时间依赖、干预或额外域/任务标签假设。

03核心贡献

  • 理论证明无稀疏约束时，仅拟合演示数据只能保证估计动作机制的支撑不小于真实支撑，无法防止干扰变量混入动作路径（Proposition 1）。
  • 在支持稀疏性约束下，证明状态到动作的依赖结构可识别到潜变量置换（Theorem 1）。
  • 证明紧凑状态 $C_t$ 是真实动作相关块 $s_{t,I_A}$ 的可逆函数，与干扰变量分离（Theorem 2），且允许动作相关变量与干扰变量之间存在统计依赖。
  • 提出 CWAM 方法：在预训练 WAM（Cosmos 3）动作头上增加稀疏路由路径，保持世界建模目标不变。
  • 在合成数据和真实机器人上验证理论，并展示稀疏路由提升闭环成功率。

04方法描述

  • 估计原则：在联合 rectified-flow 目标 $\mathcal{L}_{WAM}$ 之外加入动作机制稀疏正则 $\mathcal{L}_{sparse}$，总目标为 $\mathcal{L}_{total}=\mathcal{L}_{WAM}+\mathcal{L}_{sparse}$。
  • 骨干模型：使用 Cosmos 3 Nano 的 Mixture-of-Transformers (MoT) generator，对视频 latent 和动作 chunk 联合去噪，保留原有世界建模训练。
  • 动作相关路由器：在 generator tower 后，每个动作隐藏状态对干净上下文 token 进行 softmax 路由，使用位置/模态/chunk进度关系偏置；设置 $d_r=512$、8 个注意头，路由信号通过初始较小的门 $g$ 残差注入动作头。
  • 稀疏正则：对 top-k 路由权重施加 $\mathcal{L}_{sparse}=\lambda \mathbb{E}_i[1-\sum_{j\in T_k(i)}w_{ij}]$，其中 $\lambda=0.01$，在训练 $10^3$ 步后逐步加入。
  • 紧凑状态 $C_t$：由任意动作 query 的 top-k 路由质量覆盖的干净上下文 token 组成，作为部署时使用的动作相关状态。

05数据集与资源

  • 合成数据：按论文公式生成，$n=20$ 个潜变量，$\|I_A\|=4$ 个动作相关变量；潜变量通过带噪声坐标观测，隐藏 regime 驱动动作机制和干扰-相关耦合。
  • 真实数据/基准：RoboCasa365（17 个任务）、LIBERO（40 个任务）、真实 Franka R3 机器人。
  • 模型：Cosmos 3 Nano 骨干 + MoT generator；路由器维度 $d_r=512$，8 注意头，稀疏系数 $\lambda=0.01$。
  • 训练资源：论文主要正文未明确列出 GPU/TPU 型号与数量。

06评估与结果

  • 合成评估：使用 held-out linear probes 测量 $C_t$ 到动作相关潜变量的 $R^2$，以及干扰变量的 $\Delta_{nuis}$；通过 head ablation 检查仅保留选中坐标或仅删除选中坐标对动作 MSE 的影响。
  • 合成结果：CWAM 带稀疏性选中的坐标解码动作相关潜变量与 dense 全状态相当，干扰变量解码与真实块相当；zeroing selected coordinates 会破坏 fitted head，表明 $C_t$ 捕获动作相关块而非干扰变量。
  • 真实机器人/benchmark：在 RoboCasa365、LIBERO 和 Franka R3 上，稀疏路由路径相比匹配的 Cosmos 3 baseline 提升 aggregate closed-loop success。
  • 在 CWAM 最强的四个 RoboCasa365 任务上，仅使用 routed tokens 也能保留大部分成功率；可视化显示 routing mass 大多落在被操作物体及其目标上。
