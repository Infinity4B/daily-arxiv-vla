Sparse-WAM: Accelerating World Action Models via Action-Guided Sparse Imagination

2026-09-30 · 原文 · 翻译 · 2609.38984

论文提出 Sparse-WAM，一种无需训练（training-free）的框架，通过动作引导的稀疏想象（Action-Guided Sparse Imagination）加速世界动作模型（World Action Models, WAMs）的推理。 WAM 在去噪过程中反复处理稠密的未来帧 tokens，计算开销巨大；现有token剪枝方法主要关注视觉保真度，未利用动作相关性来决定保留哪些未来帧 token。 核心观察是：连续去噪步骤之间，动作 token 对未来帧 token 的注意力（action-to-future attention）具有显著的空间分布重叠，可据此复用 token 选择，降低推理成本。

论文概述

  • 论文提出 Sparse-WAM，一种无需训练（training-free）的框架，通过动作引导的稀疏想象（Action-Guided Sparse Imagination）加速世界动作模型（World Action Models, WAMs）的推理。

Card 03 核心贡献

核心贡献

  • 揭示了连续去噪步骤间 action-to-future 注意力存在显著空间重叠，为跨步骤复用 token 选择提供依据。
  • 提出 Sparse-WAM，利用时序对齐的 action-to-future 注意力选择帧特定核心区域（frame-specific core tokens）和共享空间锚点（shared spatial anchor tokens），并保留全部观测与动作 tokens。
  • 设计 Pilot 高效执行引擎，通过轻量注意力分析（lightweight attention profiling）与跨步骤选择复用（cross-step selection reuse）降低稀疏推理的开销。
  • 在 LIBERO、RoboLab-120、LIBERO-Plus 和真实机器人任务上验证有效性，实现约 1.8×–2.0× 加速且任务性能几乎无损。
Card 04 方法描述

方法描述

  • 在线动作引导 token 选择：基于 action-to-future 注意力，按帧分组评分，聚合高质量层（通过帧对齐注意力质量和空间熵筛选）得到空间分数，选取每帧 top-K 核心 tokens 与跨帧共享的稳定锚点。
  • Pilot 引擎：在完整去噪步骤中从稠密前向计算中提取注意力分数，避免额外前向；默认仅首个去噪步骤做完整计算，后续稀疏步骤复用选择结果与缓存的速度预测。
  • 稀疏执行：将选定未来 tokens 与观测、动作 tokens 打包为紧凑序列；对未选区域使用缓存的全步预测与当前预测按掩码合并，继续参与采样更新，动作预测每步重新计算。
  • 训练无关：无需任何模型训练或微调，可直接应用于现有 WAM 推理流程。

Card 06 评估与结果

评估与结果

  • 对比基线：ToCa、WorldCache、SpecPrune-VLA、C³ache。
  • LIBERO：Sparse-WAM 实现 1.98× 加速，平均成功率 98.45%，仅比稠密推理低 0.30 个百分点；FLOPs 降至稠密模型的 49.65%。
  • RoboLab-120：Cosmos 3 Edge 实现 1.85× 加速、成功率 23.00%；Cosmos 3 Nano Policy 实现 1.81× 加速、成功率 35.50%，均为加速变体中最高。
  • 真实世界：在 FastWAM-Joint 上实现 2.08× 加速，平均成功率 75.00%（稠密为 77.78%）。
  • 消融实验：核心 tokens + 稳定锚点组合优于单独任一策略；提高剪枝比率（28.89%→68.89%）可提升加速至 2.36×，但成功率相应下降，体现效率与控制的权衡。
