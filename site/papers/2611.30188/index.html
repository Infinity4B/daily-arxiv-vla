02论文概述

  • 论文针对 世界动作模型（WAM） 在困难/分布外场景中快速退化、缺乏自我评估的问题，提出 Judgment-in-the-Loop (JiL) 框架
  • JiL 将快速 WAM（System 1）与基于 GPT-6-Astra 的基础模型智能体（System 2）结合，通过校准置信度实现按需接管
  • 目标是在保持 WAM 速度的同时接近 System 2 的可靠性，并通过知识固化使 System 1 最终能在无 System 2 调用的情况下独立运行

03核心贡献

  • 提出 JiL 双系统框架，统一 WAM 的速度优势与智能体的可靠性，大幅减少智能体调用次数，并能进化为独立运行的 System 1
  • 设计非侵入式 judgment token 与 cross-fitted temporal-difference (TD) learning，仅用二元成功/失败信号训练，在 1.6 ms/chunk 内输出校准成功概率且不改变动作预测
  • 证明 competence shrinkage law（能力收缩律），揭示修复–侵蚀权衡，指导 mastered-skill anchoring 与动态置信度门控，实现无侵蚀的能力缺口修复与自我进化
  • 在 Fast-WAM、LingBot-VA、Kairos 以及 RoboTwin 2.0、LIBERO-Plus、真实机器人任务上验证，JiL 在 30% 智能体调用预算下全面超越基线

04方法描述

  • 非侵入式校准自评估：在冻结 WAM 的最终去噪步加入带因果掩码的 judgment token 和 token-gated adapters（LoRA），读取内部 video–action 特征；Fast-WAM 上仅 13M 可训练参数（r=16），不改变动作输出
  • cross-fitted TD supervision：将 rollout 场景分为 2 折，用折外 TD(λ) 预测器生成多步价值目标，并计算 out-of-fold G_k^(λ) 训练统一预测器；利用 binary log-loss 的严格 proper scoring 性质恢复真实条件成功概率
  • 自适应 System 1 & 2 接管：按 chunk 评估 q_θ(o_k, a_k^base)，低于阈值 τ 时调用 GPT-6-Astra（System 2），置信度恢复到 τ_back 以上时返回 WAM；阈值直接控制调用预算与成功率之间的权衡
  • 能力缺口固化：冻结基础策略 π_base，将 System 2 接管轨迹 D_help 与 mastered-skill anchor 数据 D_own/D_replay 混合（如 1:1:2），训练独立修复专家 π_rep
  • 动态置信度门控与持续自演化：冻结 π_base 和 q_base，仅在低置信度状态切换到 π_rep，避免破坏已有技能；每轮仅更新 π_rep，并用 cross-fitted TD 训练系统级判断器

05数据集与资源

  • RoboTwin 2.0：完整 50 个任务，clean-only 训练，报告 Clean 与 Random 条件的平均值
  • LIBERO-Plus：全部套件，包含七类扰动家族，报告 Hard/Mastered/All 条件下的成功率
  • 真实机器人操作：真实世界 manipulation 任务
  • 模型：Fast-WAM、LingBot-VA、Kairos（原生 WAM），System 2 为 GPT-6-Astra；judgment token 约 13M 参数，修复专家共享 5B 视频 backbone
  • 训练资源：基于 NVIDIA A800 GPU，单 chunk 判断延迟 1.6 ms；动态门控部署额外占用 1.7–2.0 GB BF16 VRAM

06评估与结果

  • 主实验：在 RoboTwin 2.0 与 LIBERO-Plus 全量基准上，JiL System 1 & 2 在 30% 智能体调用预算下全面优于 Galbot-Astra、Spotter、CALL-Astra 等双系统基线
  • Fast-WAM/RoboTwin 2.0：Hard 成功率从 3.1%（Base WAM）提升到 60.2%（JiL S1&2），All 从 39.8% 提升到 74.5%；Standalone（0% 调用）Hard 42.4%，All 63.4%
  • LingBot-VA：RoboTwin 2.0 Hard 从 19.8% 提升到 70.4%，LIBERO-Plus Hard 从 22.2% 提升到 68.9%；Standalone 分别达到 55.6% 和 54.8%
  • 校准与效率：判断器能预测动作质量且校准优于基线；JiL 在 30% 预算下将 Fast-WAM 失败率降低 57.6%，对比随机调用仅降低 16.3%
  • 能力固化与自我进化：一轮 consolidation 后，独立 WAM 在零智能体调用下成功率提升 +13.1% 至 +24.7%；在更强大的 Kairos 原生 WAM 上同样有效
