02论文概述

  • 论文针对视觉-语言-动作（VLA）模型中感知表示（视觉-语言）与动作表示（连续控制）之间的“感知-动作表示鸿沟”（perception–action representation gap），提出显式中间表示框架 PAIR。
  • PAIR 通过一个 Masked Action Autoencoder 从专家动作中学习动作结构，并结合 Bridge Module 从视觉-语言上下文提取任务特征，形成 Bridge Tokens 注入动作解码器，为动作生成提供动作感知的起点。
  • 在多个模拟基准和真实世界任务上验证了该方法能够显著提升连续动作 VLA 模型的标准操作、零样本泛化、长程执行和物理控制性能。

03核心贡献

  • 刻画了连续动作 VLA 中感知到动作的隐式过渡问题，指出现有方法主要依赖最终动作损失，导致中间表示未被显式建模。
  • 提出 PAIR 框架，包括 Masked Action Autoencoder、Bridge Module、跨空间对齐 和 Bridge Injection，学习感知派生的 Bridge Tokens。
  • 在 LIBERO、LIBERO-Plus、CALVIN 及真实世界任务上展示了一致增益，两种骨干模型 OpenVLA-OFT 和 VLA-Adapter 均受益。
  • 表示分析证明 Bridge Tokens 同时保留任务语义和动作结构，且能在 Action Expert 精化之前线性解码出连续动作信息。
  • 消融实验识别出早期注入（entrance injection）和动作对齐（action alignment）为关键设计选择。

04方法描述

  • Masked Action Autoencoder（MAAE）：对专家动作块进行随机掩码和加噪，用自注意力编码生成 Action Latent Tokens，通过 \(\ell_1\) 重建损失学习动作的时间与可执行结构，训练后冻结。
  • Bridge Module：使用 \(H\) 个可学习查询，通过交叉注意力从视觉-语言表示 \(\mathbf{H}_{VL}\) 中提取任务相关信息，并经自注意力协调形成 Bridge Tokens。
  • 跨空间对齐：用余弦相似度损失将投影后的 Bridge Tokens 与 Action Latent Tokens 逐时间槽对齐，将动作结构迁移到感知表示中。
  • Bridge Injection：在 Action Expert 入口处，通过输入相关的门控机制（\(\tanh\) 门 + 投影）将 Bridge Tokens 添加到初始 Action Tokens，提供一个动作感知的起始状态。
  • 训练分为两阶段：先训练并冻结自编码器，再联合优化 VLA 策略和桥模块；推理时移除自编码器，仅由桥模块生成 Bridge Tokens。

05数据集与资源

  • 模拟基准：LIBERO（Spatial / Object / Goal / Long 套件）、LIBERO-Plus（零样本 OOD 泛化，7 类分布偏移）、CALVIN ABC→D（长程多任务执行，1,000 条任务链）。
  • 真实世界：UFACTORY UF850 机器人，7 个任务（物体放置、积木放置、杯子堆叠、按钮按压、擦板、倒水、抽屉装载），共 293 条演示轨迹，每任务 30–51 条。
  • 训练资源：4 张 NVIDIA RTX 6000 Ada Generation GPU。
  • 评估规模：LIBERO 每个任务 50 次 rollout；CALVIN 每次评估 1,000 条任务链；真实世界每个方法每任务 20 次试验。

06评估与结果

  • LIBERO：VLA-Adapter 平均成功率从 97.3% 提升至 98.4% ± 0.3%，四个套件均提升。
  • LIBERO-Plus：VLA-Adapter 总体成功率从 59.1% 提升至 64.2% ± 0.4%，七个 OOD 类别全部改善（相机视角 +8.1，机器人初始状态 +7.8，噪声 +6.7 等）。
  • CALVIN：OpenVLA-OFT 平均完成序列长度从 4.28 提升至 4.40 ± 0.04；VLA-Adapter 从 4.42 提升至 4.53 ± 0.03，五任务成功提升 3.9/3.7 个百分点。
  • 真实世界：OpenVLA-OFT 平均成功率从 51.4% 提升至 65.0%，七个任务全部提升（倒水 +20，物体放置 +15，抽屉装载 +15 等）。
  • 消融研究：入口注入优于末尾（97.4%）、中间（97.9%）和全层注入（97.6%）；对齐损失权重 \(\lambda_{\mathrm{align}}=0.1\) 最优（98.4%），无对齐时降至 97.2%。
  • 表示分析：Bridge Tokens 任务识别准确率达 87.8% ± 4.5%，动作聚类准确率达 91.5% ± 2.2%；在 Action Expert 前即达到动作解码 \(R^2=0.878\)，基线最终层仅 0.844；RSA 0.878，邻居重叠 80.4%，表明其保留了动作几何关系。
