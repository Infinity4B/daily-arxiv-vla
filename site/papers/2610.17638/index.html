Card 02 论文概述

论文概述

  • 论文研究 World Action Models（WAMs） 中生成式视觉表示如何组织与动作相关的信息，重点关注此前未被解释的 高范数空间离群 token（high-norm spatial outliers） 现象。
  • 核心问题是：这些高范数离群值是纯粹的数值伪影，还是真正参与机器人动作生成的功能性表征？
  • 目标是设计一种新的世界模型架构，将非空间表征能力从空间 token 中解耦，从而提升机器人操作策略的性能与鲁棒性。
Card 03 核心贡献

核心贡献

  • 首次在 WAM 中发现持续存在的 高范数空间离群 token，并证明其与动作相关的表征角色已部分脱离其标称空间位置（经归一化和 K/V 投影后幅度差异被消除，但动作相关性依然保留）。
  • 提出 RegisterWAM，向世界模型引入可学习的 非空间 register token，并将其直接作为 Action DiT 的视觉条件接口。
  • 引入 观测流匹配（observation FM）损失监督，发现单独加 register 不足以消除空间离群；二者结合可将高范数响应从空间 token 转移到 register 中。
  • 提出 带噪观测流匹配（noised-observation FM）损失监督，将当前场景建模转化为从损坏输入中恢复的辅助去噪任务，即使用于无 register 的设定也能改善动作学习。
  • 在 LIBERO-Plus、RoboTwin 2.0 及真实世界任务上验证有效性，且不依赖额外具身预训练数据或额外基础模型（代码已开源：https://github.com/Z1zyw/RegisterWAM）。
Card 04 方法描述

方法描述

  • 基于 FastWAM 设定：Video DiT 产生空间表征，经由视觉 K/V 缓存条件化 Action DiT；输入分辨率对应 7×14 网格，即 N=98 个空间 token。
  • 用 最大/中位数范数比 度量离群强度，用 masked-token action sensitivity（遮蔽某 token 后预测动作的 L2 变化）度量动作相关性。
  • RegisterWAM 架构：在视觉序列上追加 M 个可学习 register token，与空间 token 经同一自注意力层联合更新，register 无显式图像位置对应。
  • 只用 register 状态构建动作条件的 K/V 缓存（register-only conditioning），降低迭代动作去噪时处理的视觉上下文量。
  • 观测 FM 损失：在零噪声水平 σ=0 下对稠密干净观测 token 输出施加标准流匹配损失，register 不受监督。
  • 带噪观测 FM 损失：构造 x_σ=(1−σ)x+σε，用同一 Video DiT 处理，提供辅助去噪任务；通过注意力掩码隔离该分支，梯度只更新 Video DiT，而非作为额外条件流。
  • 训练目标：L = λ_a·L_action + λ_v·(L_obs + L_future) + λ_n·L_noised-obs，所有视觉损失均排除 register token。
  • 推理：Video DiT 只运行一次构建 register K/V 缓存，Action DiT 在迭代去噪中复用，无需迭代视频生成。
Card 05 数据集与资源

数据集与资源

  • 评测数据集：LIBERO-Plus（7 类分布偏移：Camera、Robot、Lang.、Light、Backg.、Noise、Layout，完整测试集 10,030 条 episode）、RoboTwin 2.0、LIBERO（仅用于训练）。
  • 真实世界平台：天机（Tianji）双臂三摄像头平台，含 3 个 ID 任务（电池插入、碗杯堆叠、瓶子交接放置）和 3 个 OOD 变体（改变桌面高度、蓝色桌布、增加干扰盘），每设置 20 次试验。
  • 世界模型骨干：Wan2.2（Video DiT）与 FLUX.2 4B（ImageWAM 迁移实验）。
  • 策略：Action DiT，10 步去噪。
  • 关键超参：默认 8 个 register、带噪观测噪声水平 σ=0.5、动作损失权重 λ_a=0.2。
  • 论文未明确报告具体 GPU/TPU 数量与训练时长。
Card 06 评估与结果

评估与结果

  • LIBERO-Plus：RegisterWAM 在完整测试集取得 81.64% 总体成功率，超过 FastWAM（51.5%）、Faster-WAM（73.6%/75.0%）及 PILOT（81.0%），且不使用具身策略预训练与额外几何/语义教师模型；在语言、光照、背景偏移上得分最高；消融用 20% 子集上得 82.52%。
  • RoboTwin 2.0：clean 92.9%、randomized 93.0%、平均 93.0%，略优于 FastWAM（91.9%）与 Faster-WAM（92.6%）。
  • 真实世界：相对 FastWAM 将平均任务得分从 0.3483 提升到 0.5238（6 个设置中 5 个提升，蓝色桌布偏移下两者均为 0）。
  • 消融实验：基线 76.29% → 加带噪观测 FM 至 78.59% → 再加 register 与观测 FM 至 82.52%；register 数量 4/8/16 对应 78.49%/82.52%/81.03%；噪声水平 σ=0.25/0.5/0.75 对应 76.14%/82.52%/80.98%。
  • 迁移至 ImageWAM：使用相同设计将 LIBERO-Plus 平均成功率从 83.10% 提升到 85.42%（+2.32 个百分点）。
