Sparse Feature Policy Unlearning Mitigates State Hallucination in Vision-Language-Action Models

02论文概述

  • 本文研究 Vision-Language-Action (VLA) 模型 在机器人操作中出现的 状态幻觉（state hallucination） 问题，即 VLA 模型持续按照未实际达成的机器人-物体状态执行动作的失败模式。
  • 作者通过注意力分析和稀疏自编码器机制解释，发现状态幻觉与任务相关视觉区域注意力减弱相关，并对应着可区分的稀疏特征激活模式。
  • 基于这些分析，提出 SOUL（Sparse feature pOlicy UnLearning）方法，通过选择性地遗忘与幻觉相关的策略知识、保留与成功行为相关的特征，来缓解状态幻觉并维持操作能力。

03核心贡献

  • 首次将 状态幻觉 定义为 VLA 中一种重复出现的失败模式（包括抓取/搬运/放置幻觉），并建立了系统的分类标注体系（CS/HF/NF）。
  • 通过 注意力分析 和 稀疏自编码器（SAE）机制解释，揭示状态幻觉伴随注意力分散到背景区域、以及可区分的稀疏特征激活模式，为后续干预提供可解释基础。
  • 提出 SOUL 稀疏特征策略遗忘方法，以幻觉关联特征和成功关联特征为显式的遗忘/保留目标，对 VLA 策略参数进行选择性修改，而非仅在推理时干预。
  • 在 OpenVLA 和 π₀.₅ 两种主流 VLA 架构、多个仿真基准和真实 Franka 机器人上验证了方法的有效性，显著降低幻觉率并提升任务成功率。

04方法描述

  • 使用 Top-k 稀疏自编码器（SAE） 分解 VLA 视觉 token 的残差流激活，在 4096 维潜在空间中以 k=100 个活跃特征进行稀疏表示。
  • 定义 特征关联分数（如 s^hall、s^succ、s^sep），基于 CS、HF、NF 三类 rollout 的区域级特征激活最大值来量化特征与幻觉/成功行为的关联，进而构建遗忘集 F 和保留集 R。
  • 提出 特征引导的遗忘目标：在 HF 样本上最小化遗忘特征激活的平方（L_forget），在 CS 样本上最大化保留特征激活（L_retain），最终联合优化 L_unlearn = L_forget + λ_r·L_retain。
  • 使用 LoRA 适配器 进行参数高效微调，保持预训练模型权重冻结，仅优化适配器参数；SAE 编码器在遗忘过程中保持冻结。
  • 创新点在于将机械可解释性与策略遗忘相结合，通过语义区域引导的特征选择（region-guided）实现更精准的空间定位，而非全局或单 token 级别的特征选择。

05数据集与资源

  • 仿真基准：LIBERO-Plus（包含光照/背景干扰的物体操作任务）、RoboCasa（多样化厨房场景）。
  • 真实环境：7-DoF Franka Research 3 机械臂，含 50 次 rollout 的多样化视觉条件评估。
  • 模型：OpenVLA（自回归架构，分析语言骨干层 0, 8, 16, 24, 31）和 π₀.₅（flow-matching 架构，分析 PaliGemma 骨干层 0, 5, 11, 17）。
  • SAE 配置：潜在维度 4096，活跃特征 k=100，辅助重建特征 k_aux=512。
  • 训练资源：基于公开预训练模型初始化，使用 LoRA 进行参数高效优化，未明确给出 GPU 型号和数量。

06评估与结果

  • 评估基准：LIBERO-Plus（OpenVLA）、RoboCasa（π₀.₅）及真实 Franka 机器人；以 pick-and-place 任务为受控测试场景。
  • 主要指标：幻觉率（Hall. ↓）、幻觉失败率（Hall. failure ↓）、总体成功率（Overall success ↑）、清洁成功率（Clean success ↑），以及抓取/搬运/放置各阶段的幻觉率。
  • 关键结果：

- 仿真环境中，SOUL 将平均幻觉率从 55.0% 降至 33.5%（降低 21.7%p），幻觉失败率从 48.6% 降至 29.5%（降低 21.5%p），清洁成功率从 27.5% 提升至 52.2%（提升 22.1%p）。

- Gradient Ascent 基线虽然能降低部分幻觉率，但严重破坏任务成功率（如 LIBERO-Plus 上 clean success 降为 0），而 SOUL 在缓解幻觉的同时保持了已有的操作能力。

- 真实机器人评测中，SOUL 平均提升清洁成功率 20%p、降低幻觉失败率 22%p，验证了方法在物理环境中的有效性。

- 行为保持与纠正：SOUL 保留了 89% 原本成功的任务执行和无幻觉事件，同时将 40% 失败任务转为成功、纠正 78% 的幻觉事件。

- 消融实验 表明：区域引导的特征选择优于全局和 token 级选择；保留目标（L_retain）和聚合分数（s^agg）对于维持成功行为和实现最佳平衡都不可或缺。
