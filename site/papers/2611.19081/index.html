RoboCoEvo: Expanding Robot Capabilities through Agent-Policy Co-Evolution

arXiv 原文 ↗ 中文翻译 ↗

针对 MLLM 智能体与机器人基础模型（VLA）能力提升彼此解耦、难以相互促进的问题，提出失败引导的联合进化框架 RoboCoEvo。

02论文概述

  • 针对 MLLM 智能体与机器人基础模型（VLA）能力提升彼此解耦、难以相互促进的问题，提出失败引导的联合进化框架 RoboCoEvo。
  • 通过“策略引导的智能体进化 + 智能体引导的策略能力扩展”形成闭环：智能体从策略失败中提炼可复用的检测与恢复程序用于生成纠正数据；策略后训练吸收纠正行为并暴露新失败，驱动下一轮智能体更新。
  • 在 BEHAVIOR-1K、RoboTwin 2.0、RoboCasa 三个基准上验证，实现多轮持续性能提升。

03核心贡献

  • 提出 Failure-Mode-Centric Agent–Policy Co-Evolution：以失败模式为中心的联合进化机制，将智能体知识细化与策略后训练耦合为递归反馈循环。
  • 提出 Policy-Guided Agent Evolution：按失败模式组织故障，为每个模式生成可执行检测器和恢复程序，并随策略更新不断修订或新建。
  • 提出 Agent-Guided Policy Capability Expansion：利用失败条件增强扩展纠正数据，使策略将智能体恢复行为内化为端到端能力。
  • 实现并验证显著性能提升与数据效率：在三个基准上使用强基线策略仍能持续提升，且纠正数据比无目标演示更高效、无需人类干预。

04方法描述

  • 系统框架：每轮包括（a）当前策略 rollout 采集与失败模式识别；（b）检测器与恢复程序生成/修订；（c）纠正经验生成；（d）策略后训练；更新后的策略 rollout 进入下一轮。
  • 失败模式定义：将同一子任务停滞且失败模式相同的失败归为一类；探测器实现为有限状态机，输出预防状态和纠正状态。
  • 恢复程序生成：采用 code-as-policy 方法，将恢复程序实现为基于场景状态的有限状态机，组合导航/操作技能与运动规划；恢复程序在留存验证集上需达到至少 70% 恢复成功率。
  • 失败条件增强：在模拟器中扰动已观测失败状态的机器人/物体状态，生成保留同一失败模式的额外初始状态，扩大单个失败产生的恢复轨迹。
  • 策略后训练：将纠正经验与原始演示按 1:1 采样比例混合，进行 DAgger 式微调，缓解灾难性遗忘。
  • 创新点：失败模式共享检测/恢复程序；失败条件增强降低 rollout 数量与仿真成本；闭环修订使纠正经验始终针对当前策略的残余弱点。

05数据集与资源

  • BEHAVIOR-1K：使用前 6 个长程、双臂移动操作任务；基础策略为 RLC（2025 BEHAVIOR Challenge 第一名方案）。
  • RoboTwin 2.0：全部 50 个双臂桌面操作任务；基础策略为 π0.5。
  • RoboCasa：选取 10 个代表性厨房操作任务；基础策略为 XR-1。
  • 智能体模型：GPT-6 Astra，高推理模式。
  • 训练与采集：BEHAVIOR-1K 每任务采集 50 条 rollout 并采样 20 个失败；RoboTwin 2.0 与 RoboCasa 每任务采集 200 条 rollout；官方测试不使用采集 seed。
  • 评估设置：RoboTwin 与 RoboCasa 每任务 50 个测试实例；BEHAVIOR-1K 每任务 20 个实例运行两次；使用官方检查点或自行复现模型。
  • 训练资源：消融中记录 GPU 小时与智能体 token 成本；论文未明确给出各 VLA 模型的具体参数量。

06评估与结果

  • 总体性能：两轮后 BEHAVIOR-1K 平均 Q-score 从 0.40 提升至 0.56，成功率从 0.23 提升至 0.34；RoboTwin 成功率从 0.79 提升至 0.93；RoboCasa 成功率从 0.79 提升至 0.91。
  • 持续提升：两个轮次在所有基准上均带来提升，第一轮提升幅度通常大于第二轮，说明通过策略更新与再暴露缺陷可实现递归改善。
  • 失败模式分析：在 RoboTwin 上，目标失败模式发生后的自主恢复比例从 0.18 升至 0.54，由目标失败模式导致的失败比例从 0.19 降至 0.06；BEHAVIOR-1K 上自我恢复比例从 0.28 升至 0.56。
  • 第二轮程序修订：第一轮检测/恢复程序直接用于第一轮策略失败时，检测成功率从 94%–97% 下降至 54%–72%；修订后恢复至 93%–96%，恢复成功率提升至 71%–83%。
  • 消融实验（picking up trash）：完整 RoboCoEvo 将 Q-score 从 0.633 提升至 0.84；仅成功演示仅达 0.642；逐失败恢复降至 0.267；共享失败模式程序提升至 0.758；加入失败条件增强最终达 0.84，并显著降低 GPU 小时和 agent token 消耗。
