AgentMoT: An Agentic Mixture-of-Transformers for End-to-End Autonomous Driving

02论文概述

  • 提出 AgentMoT，一种面向端到端自动驾驶的智能体混合 Transformer 模型，将代理推理和系统调度内置于统一的驾驶模型中。
  • 解决驾驶模型如何选择使用哪些能力（直接动作、视觉语言动作、世界动作预测）、何时委派技能，以及何时根据执行反馈重新考虑任务决策的问题。
  • 通过相对能力原则和双循环演化，使模型在闭环驾驶中动态选择计算通路、工具和调用时机。

03核心贡献

  • 统一多范式驾驶架构：将直接动作（A）、视觉语言动作（VLA）和世界动作模型（WAM）三条原生通路整合到共享代理专家的混合 Transformer 中，并学习选择计算、委派任务和重考虑决策。
  • 双重闭环演化机制：内环利用闭环经验训练路由器、代理任务决策和自调度器；外环通过失败归因和技能修复持续优化技能与执行反馈。
  • 执行反馈驱动的自调度：引入唤醒请求、强制请求和双视图查询，实现事件触发的代理调用与证据补充，减少冗余调用并提升紧急场景响应。
  • 领先的基准性能：在 Bench2Drive v0.0.3 和 v0.0.4 上取得最先进的驾驶得分（94.48 / 92.33）和成功率（85.45% / 82.73%），并在所有五个官方能力组中领先。
  • 计算效率优势：完整模型相比固定最强大通路和固定间隔代理调用减少约 50.5% 的每控制周期计算时间。

04方法描述

  • 混合 Transformer 架构：以 BEV 编码器融合 RGB 与 LiDAR 特征，通过代理专家、世界专家和动作专家构建 A、VLA、WAM 三条通路；Router 从 BEV tokens 和上下文选择计算通路。
  • 代理推理与任务决策：代理专家 G 基于驾驶上下文和技能-目标菜单选择原生驾驶或技能；使用 LoRA 适配器共享视觉语言骨干，支持任务适配器后训练。
  • 自调度与执行反馈：执行层生成唤醒请求（普通、强制），自调度器学习是否调用代理；强制请求直接调用 G，支持双视图查询补充后视证据。
  • 双循环演化训练：开环初始化后，内环采用 one-step offline RL（Router）、任务适用性监督（G）和加权交叉熵（自调度器）；外环由 GPT 归因失败并驱动编码代理修复技能与反馈规则。
  • 相对能力原理：将额外计算或干预的收益减去成本作为选择依据，指导通路选择、技能委派和重考虑决策的学习。

05数据集与资源

  • 评测数据集：Bench2Drive v0.0.3 和 v0.0.4（各 220 条评测路线），基于 CARLA 0.9.15 模拟器。
  • 训练数据：Router 使用 264 条开发路线的配对通路上计划；代理后训练和自调度使用 476 条闭环 episode（按路线划分训练/验证）；训练路线与评测路线分离。
  • 模型规模：视觉语言骨干为 Qwen3-VL-2B；Router 参数量约 0.84M（两组 5 成员集成）；代理任务适配器 rank 64。
  • 训练资源：论文未明确说明训练硬件；推理延迟测量使用 NVIDIA RTX 5090 GPU。

06评估与结果

  • 评估环境：CARLA 0.9.15 闭环仿真，Bench2Drive v0.0.3 / v0.0.4 官方 220 路线，训练与评测路线不重叠。
  • 主要指标：驾驶得分（DS）、成功率（SR，DS=100 的路线百分比）、五项官方能力（超车、汇入、紧急刹车、让行、交通标志）分别评测。
  • 总体性能：AgentMoT 在 v0.0.3 上 DS 94.48、SR 85.45%；在 v0.0.4 上 DS 92.33、SR 82.73%，均领先所列模型。
  • 能力维度：五项能力平均 SR 在 v0.0.3 为 89.48%，v0.0.4 为 84.79%，每项能力均最高。
  • 学习路由收益：技能禁用时，学习路由达 DS 89.70 和 SR 73.64%，比最强固定通路（WAM）高 1.79 DS 和 4.09 个百分点 SR。
  • 消融实验：去掉双视图查询 DS 降 3.26、SR 降 10%；去掉事件触发唤醒 DS 降 2.52、SR 降 5%；使用开环代理 DS 降 1.11、SR 降 5%。
  • 计算效率：完整模型每控制周期总计算 103.57 ms，相对固定 WAM + 固定间隔代理减少 50.51%；Router 选择 A / VLA / WAM 的比例为 54.84% / 10.52% / 34.65%。
