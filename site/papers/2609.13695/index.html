02论文概述

  • 针对分块视觉-语言-动作(VLA)策略在执行中产生的操作空间 jerk 问题，提出 GROOVE 在线调节器，在原始三维末端执行器(EEF)路径周围搜索几何校正区域
  • 无需重新训练策略或进行额外的 VLA 推理，仅通过一次 VLA 查询后的在线优化实现动作调节
  • 使用已交付命令作为边界条件，联合优化整个动作块，同时减少块内 jerk 和跨重规划边界的 jerk，并限制累积路径偏差

03核心贡献

  • 提出在原始三维 EEF 路径周围的方向校正区域几何搜索框架，包含立方体参考和13个等体积方向约束集，在参考相对偏差限制下保护候选选择
  • 实现基于 delivered commands 历史条件的全块二次规划(QP)优化，在每一步设置平移和旋转边界约束，无需额外 VLA 推理或访问策略内部结构
  • 在 LIBERO 仿真基准和 UR5e 物理机器人上验证，在所有评估方法中实现最大的保留集 jerk 减少（平移 33.02%，旋转 43.42%），同时保持或提高任务成功率（95.75% vs 93.75%）

04方法描述

  • 构建14个约束集：1个立方体参考（k=0）和13个方向约束集（k=1,...,13），方向集覆盖三个坐标轴、六个面对角线和四个体对角线，每个方向集在一个轴上收紧、另外两个轴上放宽，保持体积与参考立方体相等
  • 生成候选动作块：对每个约束集求解全块 QP，最小化命令二阶差分（jerk）和命令幅度，以最后两个已交付命令作为边界条件，将6H个组件联合优化，确保严格凸性
  • 选择与执行：计算每个候选的平移偏差分数 B_k（L1范数累积）和 jerk 分数 P_k（二阶差分L2范数平均），仅接纳满足 B_k ≤ ρ_B max(B_0, 10^-12) 且 P_k < P_0 的候选，选择具有最小 P_k 的候选执行前 C 个命令，保持原始夹爪命令不变

05数据集与资源

  • 数据集: LIBERO 仿真基准（包含 LIBERO-Spatial、LIBERO-Object、LIBERO-Goal 和 LIBERO-10 共40个任务）
  • 模型: 冻结的 π_0.5 (OpenPI pi05_libero) 和 GR00T N1.7 策略，动作预测范围 (H,C) 分别为 (10,5) 和 (16,8)
  • 求解器: OSQP（绝对和相对容差 10^-6，最多4000次迭代，可行性容差 10^-5）
  • 硬件: UR5e 机械臂，搭配 125 Hz 记录器捕获 TCP 位姿、速度、关节速度和电流

06评估与结果

  • 评估环境: LIBERO 400对匹配保留集（100 per suite）和 UR5e 物理机器人50对匹配实验（每任务25对，共100次尝试）
  • 评估指标: 平移/旋转 EEF 或 TCP jerk 减少率、任务成功率、关节电流 slew、执行时序和延迟
  • 关键实验结果:

- 在 LIBERO 保留集上，GROOVE 实现平移 jerk 减少 33.02%（95% CI: [31.02, 34.97]），旋转 jerk 减少 43.42%（95% CI: [41.38, 45.36]），整体成功率 95.75%（原始执行为 93.75%）

- 在 UR5e 物理机器人上，TCP 平移 jerk 减少 16.39%，旋转 jerk 减少 19.49%，关节电流 slew 减少 29.09%

- 在所有对比方法（RTC、SEAM、POTR、重叠集成、LiPo-QP adapter）中实现最大的 jerk 减少，且在统计上显著优于基线
