Card 02 论文概述

论文概述

  • 论文研究推理增强型 VLA（视觉-语言-动作）策略中，链式思维（CoT）能否作为运行时安全接口，系统性地定义了 可修正性（correctability） 与 可操作性（actionability） 两个评估维度：前者衡量不可靠推理能否在生成过程中被检测并改善，后者衡量推理修正能否产生预期方向的行为变化。
  • 提出 TRUST（Token-level Reward for Utility-Steered Chain-of-Thought），一个离线训练的价值模型，仅利用观测和部分推理前缀预测推理最终正确性，实现对冻结 VLA 策略的 token 级监控与选择性推理引导。
  • 关键发现：推理正确性的提升并不自动带来具身行为表现的提升；在 Alpamayo 1.5 自动驾驶策略中推理修正可转化为行为改善，而在 DeepThinkVLA 操作策略中推理虽被纠正但封闭循环任务表现基本不变。
Card 03 核心贡献

核心贡献

  • 定义并操作化了 correctability（可修正性） 与 actionability（可操作性） 两个评估轴，用于评估 CoT 作为运行时安全接口的效用。
  • 提出 TRUST 离线价值模型：从部分推理前缀预测最终推理正确性，支持 token 级监控和选择性推理时引导（gated value-augmented sampling），无需访问策略权重或隐藏状态，策略全程冻结。
  • 在 Alpamayo 1.5（自动驾驶）与 DeepThinkVLA（操作）两个域上进行了闭环评估与推理替换分析，证明推理修正可提升行为（可操作时）也可能因策略对修正响应弱而无法改变任务表现。
  • 通过制动意图（braking-intent）和抓取意图（grasp-intent）层面的行为分析，解释了不同任务级结果差异的成因。
Card 04 方法描述

方法描述

  • TRUST 价值函数：定义为给定观测和当前推理前缀时，完整推理最终被判定为正确的概率 V^πθ(o, r≤t) = Pr(Y=1\|o, r≤t)，用带标量价值头的因果多模态 transformer 近似，通过 trace 归一化的二元交叉熵训练。
  • 离线数据构建：对同一场景采样 M=6 条推理（高温），通过规则过滤退化样本、矛盾挖掘（self-contradiction mining）保留含冲突声明的场景，再交由 VLM 法官（Claude Opus 5）标注正确性。
  • 推理时监控：当 Vφ(st) < δ 时标记前缀可能导向错误推理，δ 通过验证集平衡准确率校准；监控仅需每 token 一次标量读出。
  • 推理时引导：采用门控值增强采样（VAS），在 gated 前缀上对 top-K（K=10）候选 token 用价值模型重新加权采样，β 控制引导强度，引导后的推理仍通过策略原有的 reasoning-to-action 通路生成动作。
  • 价值模型采用 LoRA（rank=128） 训练，分别使用 Qwen3-VL-4B-Instruct（Alpamayo 1.5）与 PaliGemma-2-3B（DeepThinkVLA），与策略共享 tokenizer。
Card 05 数据集与资源

数据集与资源

  • 自动驾驶离线训练：49,303 条驾驶推理轨迹；操作离线训练：47,298 条操作推理轨迹，场景划分训练/验证/测试集。
  • 闭环驾驶评估：AlpaSim 模拟器中的 PhysicalAI-Autonomous-Vehicles-NuRec 数据集 public_2601 套件，共 888 个片段；挑战性子集按基线最大轨迹误差 >30m 定义（N=300）。
  • 闭环操作评估：LIBERO-Plus 数据集，共 1,509 个 episode（390 goal / 365 spatial / 377 object / 377 long）；标准 LIBERO 上 DeepThinkVLA 已接近饱和故不采用。
  • 推理正确性评测：驾驶 n=730 条留出轨迹，操作每类声明 n=996 条轨迹。
  • 硬件资源：Alpamayo 1.5 使用 H100 GPU，DeepThinkVLA 使用 A100 GPU。
Card 06 评估与结果

评估与结果

  • Alpamayo 1.5 监控效果：TRUST 以 88.9% 准确率预测法官判罚，真实阳性率 86.4%、真实阴性率 89.7%；标记 28.6% 的轨迹（底层错误率 24.1%），采用偏保守的干预策略。
  • Alpamayo 1.5 引导效果：推理正确性从 75.9% 提升至 90.0%，优于同等算力的 Best-of-4 基线（85.9%）；错误轨迹恢复率 76.1% 显著高于 Best-of-4 的 46.0%。
  • Alpamayo 1.5 闭环结果：挑战性子集上碰撞率从 15.33% 降至 10.67%（相对降低 30.4%），最大轨迹误差从 67.33m 降至 59.56m（降低 11.5%），ADE@2.5s/5.0s 分别降低 11.3%/11.2%，碰撞+近距离接触率降低 18.0%；全数据集上最大轨迹误差降低 5.9%。
  • 制动意图可操作性：挑战性子集上制动声明数量从 2,701 增至 6,066，伴随总速度降幅从 -8.4 m/s 增至 -24.0 m/s，平均超速从 +2.57 降至 +2.27 m/s，证明推理修正确实改变了驾驶行为。
  • DeepThinkVLA 监控与引导：监控准确率 85.4%（TPR 83.6%，TNR 86.6%）；抓取状态正确性从 69.3% 提升至 90.2%，动作选择正确性从 68.8% 提升至 85.9%，均优于 Best-of-32；空间声明与物体识别变化不显著。
  • DeepThinkVLA 闭环结果：LIBERO-Plus 上总体任务成功率仅从 78.86% 变为 78.26%，四个套件均无显著变化；虽翻转 145/1,509 个 episode 结果（68 失败转成功、77 成功转失败），但修正与行为间无明确关系。
  • 推理替换分析（DeepThinkVLA）：注入 ground-truth 推理（89%）与乱码（90%）、无 CoT（91%）的成功率差异不显著，所有成对置信区间包含零；动作确实依赖推理（夹爪命令分歧 18.6%-26.7%），但动作移动方向与断言内容无关，说明策略对推理修正的响应不可预测。
  • 限制：正确性度量依赖 VLM 法官的规则；价值模型在离线（未引导）rollout 上训练，激进引导可能引发分布偏移（增加约 81% 推理延迟）。
