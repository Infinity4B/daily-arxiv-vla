Fly as Instructed: Refining World-Action Policies for UAV Vision-Language Navigation

02论文概述

  • 论文提出面向无人机视觉-语言导航的世界-动作学习框架，解决现有世界-动作模型在指令跟随、任务进度跟踪和安全避障方面的不足。
  • 研究目标是通过集成三种互补机制，提升无人机在复杂环境中遵循自然语言指令完成顺序多阶段任务的可靠性。
  • 具体要解决的问题包括：动作策略依赖视觉捷径导致语言响应不足、多阶段指令执行缺乏持续进度追踪与及时终止、避障策略缺少对预测动作路径与运动响应的反馈。

03核心贡献

  • 提出语言条件动作接口及定向后训练方法，增强动作专家对指令语义变化的响应能力，并用配对文本干预验证效果。
  • 设计循环指令消耗接口，通过视觉与执行历史预测已完成指令需求，在冻结的动作执行器内持续重加权完整指令，并触发任务级停止。
  • 提出高斯场景安全后训练，利用成功绕行示范模仿和可微分路径几何反馈进行低秩适配，并通过梯度约束保留通用任务性能。
  • 构建统一闭环评估套件，包含 521 个测试回合，并开源模型框架，在仿真中取得的最高综合导航成功率。

04方法描述

  • 动作专家基于 Wan 视频表征和 12 层 Transformer，接收 RGB 历史帧、本体状态和指令特征，通过文本交叉注意力和 DiM 动作混合器进行一步去噪生成四步动作序列。
  • 指令消耗模块使用循环 GRU 头预测每个指令 token 的满意度，通过软掩码在动作专家的交叉注意力中降低已完成 token 的对数，实现进度引导的动作生成和停止判断。
  • 安全适配在重建的高斯场景中进行低秩适配训练，采用持续探索、导出过滤、自模仿学习和可微分几何反馈（含间隙损失、工作空间惩罚和导航势），并通过梯度范数上限与 KL 约束保持通用导航能力。
  • 推理阶段动作专家支持直接一步去噪，无需显式未来视频生成，显著降低部署成本。

05数据集与资源

  • 评估使用 UAV-Flow、FLIGHT 等数据集的子任务和复合指令，构建 521 个闭环测试回合（181 个一般任务、170 个安全任务、170 个进度任务）。
  • 模型参数量为 815.28M，是相比基线最轻量的模型。
  • 训练与评估延迟在 RTX 5880 Ada 上测量，真实飞行演示在 RTX 5070 上运行，使用 10 Hz 轨迹更新和 50 Hz 底层控制。

06评估与结果

  • 在统一 521 回合测试集上，Full System 达到 83.7% 目标到达率、77.0% 正确停止率、0.648 nDTW、79.8% 顺序完成率、76.6% 安全到达率和 86.8% 碰撞自由率，均大幅领先世界 VLN 等基线。
  • 语言指令跟随评估中，本方法在 500 条指令上取得 80.6% 指令成功率，并在语义对比和释义配对指标上分别达到 56.4% 和 38.2%，优于 Pi0-UAV、WorldVLN 和 OpenVLA-UAV。
  • 模块消融实验表明安全适配器将安全子集 SFR 从 30.6% 提升至 78.2%，指令消耗头将进度子集 OC 从 24.1% 提升至 81.2%，两者结合保留各自增益且通用任务到达率升至 84.0%。
  • 推理效率方面，本模型动作头延迟中位数 30.55 ms、完整模型延迟 91.84 ms，比 FastWAM 动作头快 2.75 倍，且参数减少 54.8%。
  • 六次室内外真实飞行演示验证了障碍通过、箱上着陆、绕树飞行等任务的自主执行能力。
