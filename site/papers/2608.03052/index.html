Card 03 核心贡献

核心贡献

  • 首次在统一框架下系统比较了五种代表性的本体感知状态接口（离散状态提示 sp、VLM 前缀 vp、动作前缀 ap、状态专家 se、特征调制 fm），解决了此前不同系统间设计不可比的困境
  • 揭示了状态表示形式（离散 vs 连续）、历史长度（1–96 帧）和注入位置（VLM 侧 vs 动作侧）对闭环控制性能的影响规律，发现不存在任务无关的最佳接口
  • 证明了短状态历史（如 K=8 帧）能提升性能，但长原始历史可能因冗余或陈旧信息而损害控制精度，尤其在精密操控任务中
  • 发现状态注入的偏好随历史长度动态变化：单帧状态时 VLM 侧占优，而短历史时优势转向动作侧
  • 提供了可复用的评估协议和可验证的设计指南，包括配对任务自助法统计检验和槽位匹配的时序控制实验
Card 04 方法描述

方法描述

  • 基础模型：采用 π₀.₅ 作为测试平台，包含 Vision-Language Model (VLM) 骨干网络和 flow-matching action expert，固定动作表示、数据管道和优化方案
  • 状态表示：原始状态为 16 维向量（末端执行器位置与四元数、基座位置与四元数、双夹爪关节位置）；除离散提示（sp）仅使用当前帧外，连续接口均通过两层投影器（Swish 激活）将每帧映射为连续 token（VLM 前缀维度 2048，动作侧维度 1024）
  • 五种状态接口：

- State Prompt (sp)：将状态量化为 256 个 bin 并序列化为约 66 个文本 token，直接加入 VLM 语言提示，无额外可训练参数

- VLM Prefix (vp)：将连续状态 token 插入 VLM 双向前缀（约 4.26M 额外参数），参与多模态上下文建模后间接影响动作生成

- Action Prefix (ap)：将状态 token 插入动作专家因果前缀（约 1.08M 额外参数），直接参与动作去噪过程中的速度场预测

- State Expert (se)：添加专用状态处理流（约 199.30M 额外参数），与动作模块进行序列建模和信息交换

- Feature Modulation (fm)：通过交叉注意力读取状态，预测每特征缩放因子 γ 与偏移 β，持续调制动作特征（约 123.84M 额外参数）

  • 控制变量设计：固定骨干网络、训练数据、动作表示和评估协议，仅改变状态接口、历史长度和注入位置
Card 05 数据集与资源

数据集与资源

  • 数据集：RoboCasa365 仿真平台，包含多样化厨房场景、机器人初始配置、物体实例和操作任务；视觉输入包含左/右外置相机与腕部相机的三视角观测
  • 任务设置：

- 原子任务：45 个，按操控语义分为三类（A：重排与抓取放置，15 个；B：关节物体交互，15 个；C：旋钮/开关/设备精密控制，15 个）

- 复合任务：20 个（ lifelong_learning_phase2 设置），每集链式执行 2–3 个原子子目标，评估分布内复合控制能力

  • 模型规模：基于 π₀.₅，各接口额外参数量分别为：sp (0), vp (4.26M), ap (1.08M), se (199.30M), fm (123.84M)
  • 训练资源：文本中未明确指定 GPU/TPU 具体型号；提及 se 和 fm 因硬件分配限制，训练样本曝光度略低于其他接口，故不做容量匹配声明
Card 06 评估与结果

评估与结果

  • 评估环境：RoboCasa365 仿真器，闭环节点评估（closed-loop rollouts）；原子任务每任务 50 次 rollout，复合任务每任务 25 次 rollout，固定种子 schedule 控制环境随机性
  • 主要指标：任务成功率 (Success Rate, SR)，仅当环境定义的成功条件在回合内满足时计为成功；复合任务需完成所有子目标
  • 关键实验结果：

- RQ1（状态效用与接口）：所有状态接口在 45 个原子任务宏平均上均优于无状态基线（54.6%），sp 达到 57.7%（+3.1%，95% 置信区间 [0.2, 6.1]）。但无任务无关最优接口：A 类任务 sp 最优（68.7%, +7.0%），B 类任务 vp 最优（68.8%, +6.1%），C 类任务 se 最优（42.8%, +3.3%）

- RQ2（时序深度）：短状态历史（K=8 帧）能提升性能，但长原始历史（>8 帧）会损害性能（尤其 C 类任务）。8 帧历史是实用的操作点；复合任务验证了历史收益可迁移到长时程控制；收益源于真实时序内容而非额外槽位

- RQ3（注入位置）：单帧状态（K=1）时，状态 favors VLM 侧（vp 表现更优）；短历史（K=8）时，优势显著转向动作侧（ap/se/fm）

- 计算成本：各接口边际计算成本差异显著。sp 训练成本最高（1114 GFLOPs/sample），se 推理成本最低（0.7 GFLOPs/10-step）；se 与 fm 以远低于 sp 的计算代价达到相近的宏平均性能（57.6%）
