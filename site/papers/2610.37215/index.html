02论文概述

  • 论文提出 Retrieve to Act (R2A)，一个测试时扩展框架，将 VLA 策略的分布外鲁棒性问题重新表述为纯几何运动基元检索问题
  • 针对的核心问题：Vision-Language-Action (VLA) 模型虽具备良好的语义泛化能力，但在执行时对 OOD 视觉扰动（如相机视角、光照、背景变化）极其脆弱，导致灾难性执行失败
  • 现有测试时方法仅关注抑制虚假视觉线索，忽略了策略自身训练经验中蕴含的丰富且未受损的运动学先验

03核心贡献

  • 提出 R2A 框架：将成功训练演示组织为离线时空运动基元图，绕开脆弱的视觉特征，实现基于几何的测试时经验检索
  • 设计运动基元图构建方法：节点编码纯运动学几何（关节姿态、状态、逐帧变化），边捕获时空转换（时间边 + 跨任务空间边），完全与视觉像素解耦
  • 提出基于扩散的初始状态矫正模块：将 OOD 初始机器人状态投影回训练流形，修复视觉-本体感觉接地失效问题
  • 提出查询依赖的 GNN 检索器：动态定位机器人当前执行在图中的位置，检索结构兼容的未来运动基元
  • 通过逐维门控机制将检索到的几何先验与冻结 VLA 的预测动作自适应融合，在不微调基础策略的情况下实现显著鲁棒性提升

04方法描述

  • 运动基元图构建：节点编码演示片段的运动学信息（关节角、关节位移、夹爪状态、位置编码），边分为时间边（同一演示内近未来节点连接，Δ∈{2,4,6,8}）和空间边（跨任务末端执行器位姿几何距离低于阈值），完全摒弃视觉特征
  • 初始状态矫正：使用条件扩散模型 M_φ 建模有效初始关节配置分布，以任务指令为条件迭代去噪，将 OOD 初始状态投影回训练流形，并通过刚性矫正轨迹物理过渡机器人
  • 查询依赖 GNN 检索：构建运动学查询 Q_t（拼接 VLA 姿态预测、历史状态和已执行动作），通过查询条件化的消息传递动态定位执行进度；边缘化推断任务分布和进度估计，结合 Top-K 重排序，以温度加权融合生成参考运动 A_ref
  • 动作协调：学习的逐维门控矩阵 S_t 作为残差校正（A_exec = A_π + S_t ⊙ (A_ref − A_π)），仅修正空间位姿、保留夹爪指令；训练时注入查询噪声以模拟感知扰动，提升 OOD 恢复能力
  • 训练目标：GNN 采用 BCE 损失 + 排序损失的对比学习范式；协调模块采用 MSE 损失并注入查询噪声模拟扰动；整个框架按 VLA → GNN → 协调 MLP 的顺序训练，基础策略全程冻结

05数据集与资源

  • 仿真基准：LIBERO-Plus（7 类扰动：相机、机器人初始状态、语言、光照、背景、噪声、布局）、RoboTwin2.0-Plus
  • 真实世界部署：Aloha 硬件平台
  • 评估的 VLA 架构：GR00T N1.7、π0.5（Physical Intelligence）、StableVLA；对比基线包括 OpenVLA、OpenVLA-OFT、NORA、WorldVLA、UniVLA、π0、π0-FAST、RIPT-VLA、VLA-JEPA
  • R2A 模块本身轻量（GNN + 扩散模型 + 协调 MLP），无需微调基础策略；论文未明确披露具体 GPU 训练资源与参数量

06评估与结果

  • 评估环境：LIBERO-Plus 七类系统化扰动（相机视角、机器人初始状态、语言指令、光照、背景纹理、传感器噪声、物体布局）及 RoboTwin2.0-Plus 基准与真实世界 Aloha 部署
  • 主要评估指标：任务成功率
  • 关键结果：在 LIBERO-Plus 上，GR00T N1.7 平均成功率从 77.1% 提升至 89.0%（+11.9%），StableVLA 从 78.1% 提升至 89.5%（+11.4%），π0.5 从 85.9% 提升至 90.4%（+4.5%）；单类别最大提升达 +49.1%（机器人初始状态扰动）
  • 在 RoboTwin2.0-Plus 上，π0.5 平均成功率从 56.8% 提升至 66.2%（+9.4%），其中机器人初始状态扰动类别提升高达 +41.7%
  • 真实世界 Aloha 任务上实现最高 +40% 的成功率提升，且增强后的策略超越 VLA-JEPA、StableVLA、π0.5 等近期强基线，验证了运动基元检索在无需修改底层策略情况下的鲁棒性增益
