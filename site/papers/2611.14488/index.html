Is Your Robot's Memory Just a Clock? Temporal Shortcuts in Memory-Augmented VLA Policies

01研究单位

  • 作者 Chubin Zhang 与 Bo An（通讯作者）均来自 Nanyang Technological University（南洋理工大学）

02论文概述

  • 论文研究记忆增强型 视觉-语言-动作（VLA） 策略中“按时间填充记忆”的设计缺陷：时间流逝会被误认为任务进展
  • 通过在 RoboMME 计数任务中注入 null events（暂停、腕部空摆、空抓），发现策略会因“未发生任何有效事件”而提前停止，作者称其为 phantom progress
  • 论文目标是揭示该现象的原因，并验证不同修复策略（改变数据 vs 改变记忆索引）的有效性

03核心贡献

  • Phantom progress 现象：短暂的 null events 会使按时间填充记忆的 VLA 策略提前停止，且损害仅通过记忆路径产生；通过 visible/hidden 对比和时间戳缩放可区分策略是在追踪事件还是时间
  • 时间捷径位于记忆索引：失败根源于时间捷径，而非仅时间戳；即使移除时间编码，null frames 仍占用记忆槽位，脆弱性取决于记忆如何被索引
  • 诊断指导修复：训练时注入停留（pause augmentation）不能消除失败且损害计数能力；而 事件索引（event index） 在测试阶段无需重训练即可恢复大部分成功
  • 跨策略验证：在 RoboMME 发布的多种记忆设计中，脆弱性跟随索引方式：按时间索引的帧采样策略崩溃，按像素变化或子目标索引的策略表现不同

04方法描述

  • 在 RoboMME 的两个计数任务 PickXtimes 和 SwingXtimes 上，注入三类 null events：pause（静止 100 环境步/5秒）、wrist fidget（腕部 ±0.3 rad 摆动）、air-grasp（空抓后返回原姿态）
  • 使用 visible vs hidden 对照：两种条件下物理事件相同，但 hidden 条件不让事件帧进入记忆、时间戳也不前进，用于隔离记忆的影响
  • 通过 时间戳缩放（对记忆帧时间戳乘以因子 s）在无 null events 时干预时钟速度，观察策略是早停还是额外重复
  • 训练 Clock 与 NoClock 两个模型，二者基于 π0.5 并按 RoboMME 配方训练 30k 步，唯一差异是是否使用时间编码
  • 提出 event index：在测试时检测“世界返回先前状态”的片段并折叠为单帧，重新计算时间位置，使记忆只随事件推进而不重训练

05数据集与资源

  • 主要基准：RoboMME 模拟环境，重点关注 PickXtimes 和 SwingXtimes 两个计数任务
  • 真实数据：Open X-Embodiment 中的两个真实遥操作数据集，以及 stanford_hydra、FMB、LIBERO-10 等用于分析“时间预测任务进展”现象
  • 模型：基于 π0.5 的 MME-VLA 系列，包含 FrameSamp-Modul/Expert/Context、TokenDrop、MemER-style、Text sub-goals、TTT 等发布策略；另评估 SimpleMemVLA 和 LTM-π
  • 记忆规模：FrameSamp 系列保持 32 帧，按整段 episode 均匀采样，并附正弦时间戳
  • 训练资源：论文未明确披露 GPU/TPU 类型、数量及模型参数量

06评估与结果

  • 评估协议：每个条件运行 50 个配对 rollouts，采用精确双侧 McNemar 检验；失败分为 early stop（提前按按钮）和 extra（多做重复）
  • 主要结果：两次 5 秒暂停使 PickXtimes 成功率从 47/50 降至 16/50，使 SwingXtimes 从 44/50 降至 10/50；腕部空摆造成类似损害，隐藏事件后成功率基本恢复
  • 时间戳缩放：快时钟（s=1.5）使 PickXtimes 成功率从 47 降至 18 且全部为早停；慢时钟（s=0.5）导致策略做额外重复
  • NoClock 在暂停下成功率仍降至 21/50 和 14/50，证明即使去掉时间戳，null frames 占据记忆槽位仍造成损害
  • 记忆设计对比：时间索引的 FrameSamp 系列在 null events 下崩溃；TokenDrop 对静止暂停损害较小，但受腕部空摆影响更大；子目标索引记忆不受影响；LTM-π 在暂停下从 50/50 降至 7/50
  • 修复效果：pause augmentation 未能消除失败并损害无事件情况下的计数；事件索引在测试时不重训练至少使 null events 下的成功率翻倍，SwingXtimes 空抓从 13/50 提升到 43/50，但对微停顿等短暂随机中断恢复有限
