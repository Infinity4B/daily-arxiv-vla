02论文概述

  • 论文提出 APS-VLA，一个面向视觉-语言-动作（VLA）模型的高效视觉 token 剪枝框架，核心目标是在保持预训练 VLA 骨干网络冻结的前提下降低推理延迟。
  • 要解决的问题是：机器人 VLA 策略需要处理密集视觉 token，导致推理延迟高；现有剪枝方法主要依赖静态或启发式线索，难以动态保留任务关键视觉信息。
  • APS-VLA 从机器人演示轨迹中学习视觉 token 选择，通过动作监督和未来视觉监督两种互补信号训练轻量选择器，并在部署时仅使用硬选择与打包操作。

03核心贡献

  • 提出从演示轨迹中学习视觉选择：动作监督对齐剪枝后策略输出与完整输入策略及专家动作；动作条件视觉转移预测进一步利用未来观测监督所选表征。
  • 设计 Decision Influence Estimator（DIE）：轻量模块融合视觉上下文、语言指令和机器人本体感知，对单个视觉 token 打分，并在固定预算下执行硬选择。
  • 实现模块化即插即用框架：训练时冻结 VLA 骨干，部署时删除未来预测器和稠密教师分支，保留原始动作生成流程。
  • 在 OpenVLA-OFT、π0.5 和 XR-1 三个 VLA 架构、LIBERO 与 RoboCasa365 仿真及真实机器人任务上验证加速效果与成功率保持能力。
  • 真实世界实验中实现 1.47× 推理加速，平均成功率 61%，与未剪枝基线 60% 接近。

04方法描述

  • 使用冻结的视觉编码器/投影器得到视觉 token 表示，由可学习选择器 \(S_\theta\) 根据当前观测、指令和本体感知生成 token 分数。
  • 训练目标包括：动作监督损失 \(L_{act}\)（剪枝后动作与完整输入动作、演示动作的 L1 损失）和视觉转移预测损失 \(L_{pred}\)（从剪枝后的当前视觉摘要和演示动作预测未来视觉特征）。
  • DIE 融合每个 patch 的视觉特征、相机/位置嵌入、视觉条件（均值/最大池化）、指令嵌入和本体感知 MLP，通过两层 MLP 输出分数。
  • 采用预算约束的可微门控：用 Laplace CDF 将分数转换为门控值，并逐视图求解阈值以满足固定 token 预算；训练时用黑色参考图像混合门控特征以稳定梯度。
  • 部署时对每个相机视图执行 TopK 硬选择，保留原顺序并打包为紧凑视觉序列，交给冻结策略的原生动作生成器；未来观测、演示动作和辅助预测器仅用于训练。

05数据集与资源

  • 使用 LIBERO 四个子套件：Spatial、Object、Goal、Long；OpenVLA-OFT 接收两个相机视图共 512 个视觉 token。
  • 使用 RoboCasa365 评估 π0.5 与 XR-1 策略；覆盖已见原子任务、已见组合任务和未见组合任务。
  • 真实世界实验包括五个双机械臂任务：Close Drawer、Close Microwave、Red Cube into Bowl、Fold Clothes、Clear Toys and Wipe Table。
  • 剪枝预算：LIBERO 上分别测试 50%、75%、87.5% 剪枝率（保留 256、128、64 token）；RoboCasa365 上使用 256 和 128 token 预算。
  • 骨干模型包括 OpenVLA-OFT（7B）、π0.5 和 XR-1；选择器为轻量 DIE 模块。
  • 训练配置：AdamW，学习率 \(10^{-4}\)，batch size 8，训练 5,000 updates；默认未来预测 horizon \(h=8\)，辅助损失权重 \(0.1\)。论文提供部分未明确列出具体 GPU/TPU 型号。

06评估与结果

  • 评估指标包括任务成功率、模型推理延迟（包含视觉编码、选择打包、语言骨干和动作预测）和推理加速比。
  • LIBERO 结果：未剪枝基线平均成功率 97.00%、延迟 107.95ms；APS-VLA 在 50% 剪枝下成功率 96.58%、延迟 81.39ms、加速 1.33×；75% 剪枝下成功率 95.75%、延迟 68.75ms、加速 1.57×；87.5% 剪枝下成功率 93.92%、延迟 66.21ms、加速 1.63×。
  • APS-VLA 在 LIBERO 上成功率和延迟平衡优于或接近 FastV、VLA-Cache、VLA-ADP、VLA-ACL、SAFE-Pruner、VLA-Pruner、LightVLA 等代表性剪枝方法。
  • RoboCasa365 结果：π0.5 上 APS-VLA 成功率为 A-S 39.15%、C-S 6.71%、C-U 1.21%，延迟 51.50ms，加速 1.37×；XR-1 上成功率为 A-S 79.77%、C-S 55.67%、C-U 30.97%，延迟 142.93ms，加速 1.52×。
  • 真实世界结果：平均推理延迟从 137.25ms 降至 93.25ms，加速 1.47×；平均成功率 61%，未剪枝基线为 60%。
  • 消融实验：加入未来视觉监督后，在 256/128/64 token 预算下成功率分别提升 1.41/1.17/1.17 个百分点；对齐的未来目标相比打乱目标在训练 2,000 步后动作误差降低 37.8%，证明时间对应关系对未来监督信号至关重要。
