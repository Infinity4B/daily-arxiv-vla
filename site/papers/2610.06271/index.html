VLA-ZO: Fast Zeroth-Order Adaptation for Vision-Language-Action Models

arXiv 原文 ↗ 中文翻译 ↗

02论文概述

  • 论文研究 VLA（Vision-Language-Action）模型在部署时面对分布偏移（如相机视角变化）的适配问题，指出传统一阶适配（反向传播）会超出部署平台的内存预算，而零阶（ZO）优化虽然只需前向传播、内存接近推理水平，但梯度估计需要大量扰动查询，导致 naive ZO 适配耗时过长。
  • 论文提出 VLA-ZO 框架，通过将适配限制在动作侧（action side）、冻结昂贵的视觉-语言前缀（prefix），并在扰动查询和优化步骤之间复用前缀条件状态（conditioning states），结合调度感知预取（schedule-aware prefetch），显著加速 ZO 适配。
  • 核心目标：在保持推理级内存占用的前提下，让 ZO 适配足够快，使更大的查询预算（query budget q）变得实际可行，从而逼近一阶适配的性能。

03核心贡献

  • 动作侧 ZO 适配（Action-Side Adaptation with Frozen Prefix）：将 ZO 适配限制在动作专家（action expert）上，冻结视觉-语言前缀，在相同 rank 下仅需 1.25M 可训练参数（对比视觉侧 4.71M），却可匹配甚至超越视觉侧 ZO 的平均成功率（58.2% vs 56.6%）。
  • 步内状态复用（Within-Step State Reuse）：在一个优化步内，所有 2q 个扰动探针共享同一前缀状态，将每次更新的前缀计算从 2qB 次降至 B 次，加速上限为 (c_pre + c_suf)/c_suf。
  • 跨步状态复用（Across-Step State Reuse）：对单次演示轨迹中的 N 个不同观测，每个条件状态只需计算一次并缓存复用，将前缀执行次数从 2qBT 降至最多 N 次。
  • 调度感知预取（Schedule-Aware State Prefetch）：利用固定采样种子可预知下一 minibatch 的特性，将缓存加载、批次组装与 H2D 传输与当前 2q 次探针计算重叠，在 q ≥ ⌈c_ld/(2c_suf)⌉ 时完全隐藏缓存 I/O 延迟。
  • 显著的端到端加速：在 LIBERO 相机视角偏移基准上，VLA-ZO 在 q=16 时实现 25.59× 加速、在 q=64 时实现 32.54× 加速（相对 naive ZO），并将平均任务成功率从 48.27%（零样本）提升至 58.17%（q=16） 和 63.58%（q=64）。

04方法描述

  • 将 VLA 策略分解为视觉-语言前缀 f_φ（冻结）和动作专家 g_ψ（可适配），动作损失通过零阶有限差分估计梯度：∇̂L(λ) = (1/q) Σ_j [ (L(λ+εz_j) − L(λ−εz_j)) / (2ε) ] · z_j。
  • 采用 LoRA 适配器：动作侧 LoRA 作用于动作专家每个自注意力块的 query 和 value 投影，对比视觉侧 LoRA（作用于视觉编码器 FFN 投影）在匹配设置下实现更优的效率与性能。
  • 提出三级成本模型：C_naive → C_within（步内复用）→ C_across（跨步缓存复用）→ C_prefetch（预取隐藏加载延迟），逐步消减前缀相关的计算开销。
  • 缓存策略：将完整条件状态（π_0.5 中的前缀注意力键值 + padding mask；OpenVLA-OFT 中的 action-token 隐藏状态）存储在磁盘，仅将当前和下一批次所需状态驻留加速器，支持惰性填充与单步前瞻预取。
  • 数学等价性保证：复用不改变目标函数与有限差分估计器，前提是（1）所有扰动参数位于复用边界之后，（2）缓存状态包含前缀传递给动作专家的完整信息，（3）冻结前缀在固定输入下是确定性的。

05数据集与资源

  • 基准：LIBERO 全部 40 个任务（LIBERO Spatial、Object、Goal 及 LIBERO-10 套件）。
  • 模型：π_0.5（Black et al., 2025a）和 OpenVLA-OFT（Kim et al., 2025）。
  • 适配数据：遵循 DART 的 scene-wise one-shot 协议，每个场景使用 1 条目标域演示轨迹（共 5 条），目标任务上收集、同域未任务上评估。
  • 训练资源/内存对比：π_0.5 一阶适配在 batch size 16/64 下峰值内存为 20.27/54.69 GiB，ZO 前向仅为 12.74/27.71 GiB（内存差距从 1.59× 扩大到 1.97×）。测试环境涉及 3 种相机偏移（Small/Medium/Large）和复合偏移（Medium + 模糊/光照变化）。

06评估与结果

  • 评估设置：每个任务 40 个初始状态（共 1,600 个 episode），排除用于学习率选择的索引 0–9；对比基线包括未适配策略、FLA†（ZO-SGD）和 DART†（ZO-SGD）。
  • 主要指标：任务成功率（%）和端到端适配时间（秒）/加速比。
  • 相机视角适配（π_0.5，q=16）：VLA-ZO 平均成功率 58.17%（零样本 48.27%，FLA† 56.56%，DART† 54.21%），适配时间从基线 ZO 的 38,487s 降至 1,504s。
  • 相机视角适配（q=64）：VLA-ZO 平均成功率提升至 63.58%（Medium 从 59.81% 升至 66.38%，Large 从 26.19% 升至 36.81%），适配时间从 153,220s 降至 4,709s（32.54× 加速）。
  • 执行消融（q=16）：+步内前缀复用达到 15.56× 加速（2,474s），+跨步前缀复用达到 17.00× 加速（2,264s），+调度感知预取（VLA-ZO）达到 25.59× 加速（1,504s），且各变体成功率几乎不变，验证了复用的数学等价性。
  • 复合视觉偏移（View+Noise、View+Light）：VLA-ZO 在 q=64 时达到 55.8%（View+Noise）/ 60.8%（View+Light） 平均成功率，优于零样本（49.2%/49.0%）及 FLA/DART 基线，同时保持约 1.5–4.7 千秒的极短适配时间。
  • 泛化性：方法同样适用于 OpenVLA-OFT 模型，表明动作侧状态复用机制在多种 VLA 架构上可迁移。
