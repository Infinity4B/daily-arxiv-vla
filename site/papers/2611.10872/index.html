DreamVLA: From Generated Human Motions to Humanoid Vision-Language-Action Policies

02论文概述

  • 提出 DreamVLA 框架，利用生成的人体运动轨迹引导仿真中的强化学习，将仿真生成的交互轨迹用于训练人形机器人视觉-语言-动作（VLA）策略。
  • 解决传统 VLA 训练依赖大量人工遥操作演示的问题，通过生成式运动模型和 RL 专家在仿真中自动产生任务演示，避免为新任务收集特定遥操作数据。
  • 核心挑战在于将运动学意图转化为可重复的物体交互，并将专家能力蒸馏到仅依赖视觉和语言输入的 VLA 策略中。

03核心贡献

  • 生成式演示框架：通过 DreamControl 生成任务条件的人体运动参考，结合 SONIC 骨干上的残差 RL 训练专家，在仿真中自动收集自然、类人的交互演示，无需任务级人工遥操作。
  • 基于 DAgger 的 VLA 蒸馏方法：提出参考条件恢复 DAgger 程序——在 VLA 失败后，从学习者状态重启 RL 专家并沿用相同参考后缀，仅聚合成功的恢复轨迹，以解决离线模仿留下的分布偏移。
  • 四任务仿真研究与受控消融：在平台拾取、开抽屉、按按钮、行走并拾取四个任务上，系统消融 DAgger 迭代次数、残差 RL 的作用以及生成数据集规模的影响。

04方法描述

  • 参考生成：使用 DreamControl 中的 OmniControl 在文本和时空约束下生成人体运动，经 OmniRetarget 重定向至 Unitree G1，并利用 HumanoidMimicGen 增强接触点。
  • 残差 RL 专家：在 SONIC 预训练骨干上学习残差 token 修正，将生成运动编码的标称 token 与残差相加，再解码为机器人控制命令；专家同时观测人体参考、物体参考和机器人状态。
  • 成功轨迹收集：成功满足任务成功谓词的专家 rollout 导出为 LeRobot 格式数据集，包含同步图像、本体感觉、动作、时间戳和语言指令。
  • 蒸馏与 DAgger：先离线微调 GR00T VLA，然后迭代进行参考条件恢复 DAgger——失败的学习者轨迹中随机采样状态，复用相同参考后缀启动专家，仅保留成功的恢复片段加入数据集，再进行下一轮微调。

05数据集与资源

  • 数据集：全部为仿真生成数据，初始数据集由 200 条成功专家轨迹构成，DAgger 每轮增加 200 条成功恢复轨迹，最多至 800 条；导出为 LeRobot v3 格式。
  • 模型：微调预训练的 GR00T VLA 骨干（具体参数量未在论文中明确说明）；专家策略为残差 RL 训练的 SONIC token 接口模型。
  • 机器人：仿真中的 Unitree G1 人形机器人。
  • 仿真环境与训练资源：使用模拟环境（具体仿真器名称未明确提及，但参考了 Isaac-GR00T 数据准备指南）；训练 GPU/TPU 等硬件资源未在论文中报告。

06评估与结果

  • 评估基准：四个模拟交互任务——平台拾取、开抽屉、按按钮、行走并拾取；每项任务用 100 次随机环境 rollout 报告成功率。
  • 评估指标：任务成功率、专家成功率、学习器相对专家的性能差距、MPJPE（平均每关节位置误差）。
  • DAgger 迭代消融：离线初始化（0 轮）在拾取和行走拾取上为 0%，经过 3 轮 DAgger 后拾取成功率升至 54%，开抽屉 60%，按按钮 69%，行走拾取 18%；匹配数据量的纯离线对比（800 条）在拾取上仍为 0%，证明纠正性聚合的价值。
  • 残差 RL 有效性：残差 token RL 在四任务上的专家成功率分别为 88.6%、74.0%、81.0%、75.95%，显著优于标称 SONIC（拾取 0%）和绝对 token RL（所有任务均接近 0%）。
  • 数据规模扩展：生成参考数从 10 增至 200 时，开抽屉成功率从 13% 提升至 51%，按按钮从 0% 提升至 59%，但拾取和行走拾取仍保持 0%。
