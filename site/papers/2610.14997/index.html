02论文概述

  • 论文提出 FreeBar，一种面向异步 VLA（Vision-Language-Action）执行的免训练实时推理插件，用于解决异步执行中"已执行动作流"与"新生成动作块"之间的边界错位问题。
  • 异步执行虽能重叠推理与执行、实现连续控制，但推理时的观测与执行时的物理状态存在时间错位，导致轨迹抖动甚至任务失败。
  • 现有方案要么需要重新训练/改架构（训练类方法），要么依赖 VJP 梯度校正导致推理开销剧增（如 RTC），FreeBar 旨在以极低的推理代价实现稳健对齐。

03核心贡献

  • 提出 FreeBar，将动作块对齐建模为基于控制障碍函数（CBF）启发的动作空间约束，以闭式解代替昂贵的 VJP 反向传播，实现免训练、即插即用的实时推理。
  • 设计渐进式障碍收紧（Progressive Barrier Tightening）机制，在生成早期保留生成灵活性，随去噪推进逐渐收紧至已执行动作，兼顾早期生成自由度与末端对齐精度。
  • 提出基于时域的梯度式时间约束（Horizon-wise Graded Temporal Constraint）：近端动作硬对齐、中段动作软约束、远端动作不约束，平衡短期连续性与长时域适应性。
  • 在 Kinetix、RoboCasa 及真实机器人平台上跨多个 VLA 主干验证，相对朴素异步执行平均提升成功率 10%–15%，推理延迟相比 RTC 降低 45% 以上。
  • 展现跨延迟环境、跨基础策略、跨超参数的强鲁棒性，且推理开销极小（模拟中仅 +7.7%）。

04方法描述

  • 针对流式（flow-based）VLA，将迭代生成表示为 dx_t/dt = v_θ(x_t, t, c)，在生成时估计干净动作块 x̂_1 = x_t + (1-t)v_θ。
  • 定义加权时间一致性得分 B(x̂_1) 与相应引导方向 g = ∇B（g_i = -w̃_i(x̂_1,i - ā_i)），直接由动作空间差异解析获得，无需通过 VLA 动作头反向传播。
  • 借鉴 CBF 投影思想，对基础速度做最小修正：ṽ = v_θ + λg，满足约束 g^T ṽ ≥ b(t)，其中 b(t) = αE_w(x̂_1)/(1-t)；一维 QP 得到闭式解 λ = max((b(t) - g^T v_θ)/(\|\|g\|\|² + ε), 0)，并限制修正幅度（GR00T 上限为 10）。
  • 提供 Lyapunov 式能量衰减解释：E_w(t) ≤ E_w(0)(1-t)^α，硬约束误差随生成收敛至零。
  • 时域权重：硬约束区间 w_i = 1（0 ≤ i < d），软约束区间 w_i = exp(-β(i-d+1)/(h_s-d))（d ≤ i < h_s），远端 w_i = 0；结合有效性掩码得 w̃_i = m_i w_i。
  • 整体推理流程（Algorithm 1）：构建时域权重 → 采样初始化 → 每步计算速度 v_k、干净估计 x̂_1、梯度 g、障碍目标 b_k、投影系数 λ，并更新 x_{t_{k+1}}。

05数据集与资源

  • Kinetix 基准：12 个高动态仿真任务（抛掷、接取、平衡等），动作块预测时域 H=8，采用 4 层 MLP-Mixer 架构训练 32 个 epoch，测试延迟 d∈[0,4]。
  • RoboCasa 基准：11 个长时域操作任务；GR00T 预训练 80k 步 + 目标任务微调 60k 步；π0 训练 75k 步、batch size 64。
  • 真实世界任务：传送带操作（天工 TianGong 人形机器人，双臂 7-DOF）与 Whack-a-Mole（Franka Emika 7-DOF 机械臂）。
  • VLA 主干：GR00T、π0、π0.5。
  • 计算资源：仿真计时使用单张 RTX A100 GPU；真实实验使用单张 NVIDIA RTX 4090 GPU，控制频率 30 Hz。

06评估与结果

  • 评估环境与基准：Kinetix（动态仿真）、RoboCasa（11 个操作任务）、真实机器人平台；对比对象包括朴素异步执行（Naive）、RTC、非时域 CBF 消融，以及时间集成/动作平滑/块边界插值等轻量基线。
  • 主要指标：任务成功率（%）、Whack-a-Mole 30 秒内命中次数、每个动作块的推理延迟、运动学（腕关节速度/加速度）平滑度。
  • Kinetix 结果：执行时域 h=7 时 FreeBar 达 81.0%（RTC 79.0%、Naive 71.0%）；延迟 d=4 时 FreeBar 68.3% vs RTC 61.4%，明显缓解高延迟下预测-执行错位。
  • RoboCasa 结果：GR00T 主干下 FreeBar 在 d=3 达 71.4%（Naive 68.6%、RTC 70.0%、CBF 68.0%）；π0 主干下 d=2 达 36.5%，且在其他方法失效时仍提升性能。
  • 推理效率：仿真中 FreeBar 开销仅 +7.7%（CBF +10.1%、RTC +98.0%）；真实传送带任务中 π0 仅需 86 ms、π0.5 93 ms（RTC 分别为 133/150 ms），相比 RTC 降低 45% 以上。
  • 真实世界结果：传送带任务（π0，h=6）成功率达 90.0%；Whack-a-Mole（π0，h=8）命中 13.04 次；运动学上 RTC 存在高频振荡，FreeBar 轨迹显著更平滑。
  • 鲁棒性：在 [0.1, 50] 的修正强度范围内，FreeBar 均值更高、标准差更低；传送带任务均值超 RTC 达 17–19 个百分点，Whack-a-Mole 命中率提升 33%、标准差下降 41%。
