BiCAT: Bimanual Coordination Action Tokenization

01研究单位

  • 论文作者均来自 新加坡国立大学（National University of Singapore）

02论文概述

  • 提出 BiCAT（Bimanual Coordination Action Tokenization），一种针对双臂机器人动作分词的 tokenizer，通过共享跨臂运动表示和跨臂注意力显式建模双臂协调。
  • 解决现有动作分词器将双臂拼接为单一向量、导致共享运动模式未被利用且跨臂依赖纠缠在每个 token 中的问题。
  • 目标是在动作分词器层面捕捉双臂协调结构，以提升双臂视觉语言动作（VLA）模型的控制性能。

03核心贡献

  • 提出 BiCAT：一个 per-arm 动作分词器，共享镜像手臂的运动表示，并在离散瓶颈两侧（编码端与解码端）通过对称跨臂注意力和联合解码交换伙伴上下文。
  • 在模拟基准 RoboTwin 2.0 的十个任务上超过八个基线，平均成功率比最强基线高 17.6 个百分点；在真实世界三个平台的六项任务中成功率显著超过 FAST 和 OAT。
  • 通过消融实验证明，分词器内的跨臂交互与策略中的按臂分块预测（两阶段解码）联合必需，缺一不可，才能超越联合分词方法。
  • BiCAT 仅需每动作块 40.5 ms 的推理延迟，明显低于逐 token 解码基线。

04方法描述

  • 将右臂动作通过实施例特定的符号向量镜像映射到左臂坐标系，并在两臂间共享通道归一化，构建规范动作空间（canonical action space）。
  • 使用共享的因果时间编码器（两段因果卷积 + 因果自注意力）对各臂动作序列编码，得到隐表示。
  • 通过对称的因果跨臂注意力在双臂流之间交换伙伴上下文，使每臂 token 条件化于对侧臂，且保持流独立。
  • 使用共享的有限标量量化（FSQ）将特征离散化为统一词汇（K=1920），两臂共享同一码本。
  • 联合解码器以时间对齐的双臂量化向量为输入，通过 Transformer 并行重建完整双臂动作块。
  • 策略训练采用半自回归预测：先并行生成左臂全部 token，再基于左臂 token 生成右臂全部 token（两个块）。

05数据集与资源

  • 模拟数据集：RoboTwin 2.0（50 个任务，2500 条演示），选取 10 个任务（2 单臂、4 松耦合、4 紧耦合）进行系统评估。
  • 真实世界数据集：自采双臂操作数据，覆盖六项任务、三个本体（Bimanual SO-101、Unitree G1、Bimanual YAM）。
  • BiCAT tokenizer 参数量：7.40M（所有对比 tokenizer 中最小）。
  • VLA 主干网络：模拟中使用 PaliGemma 2-3B，真实机器人中使用 Molmo2-ER。
  • 硬件：模拟实验在 H200 GPU 上进行（延迟测量）。

06评估与结果

  • 模拟评估：RoboTwin 2.0 十个任务，每任务 100 次 rollout，指标为成功率；对比八个基线（Bin、FAST、QueST、OAT(sing/pow2)、M²Tok、NAC、ActionCodec）。
  • BiCAT 十任务平均成功率最优，比最强基线提升 17.6 个百分点；在单臂任务上增益仅 1.5 点，紧耦合任务增益达 21.3 点。
  • 真实世界结果：六项任务共 150 次试验，BiCAT 成功 113 次，对比 OAT 成功 74 次。
  • 延迟：BiCAT 策略生成每个动作块仅需 40.5 ms，远低于逐 token 基线（如 Bin 451.7 ms）。
