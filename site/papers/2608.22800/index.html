核心贡献

  • 引入TTS，一个使用人类视频减少机器人数据依赖的闭环长时序模仿学习系统，通过基于观测的监控和重规划提高执行可靠性
  • 提出结构化的规划-控制连接方式，将高级子目标表示为实例绑定三元组并转换为连续轨迹先验供低级执行使用，使任务进度明确且可验证

Card 04 方法描述

方法描述

  • TTS采用三层架构：Task Planner将人类视频转为离散可验证三元组；Track Predictor将三元组编译为连续实体对齐轨迹；Action Policy使用预测轨迹作为物理先验生成动作
  • Task Planner包含Relation Predictor（结合轻量级Transformer预测器LTP和LoRA微调VLM分支）和Graph-Guarded Next Triplet Generator（使用GPT-4o并用时序图约束提议）
  • 使用Grounding-DINO和SAM2进行实例检测，三元组将对象对和空间关系绑定到具体物理实例
  • Track Predictor在无动作视频上预训练，采用多模态掩码轨迹预测任务，通过三元组转移先验条件化减少外观敏感性
  • 闭环执行包含guard评估和重规划机制，每5步检查关系状态，违反时重新定位到初始节点
Card 05 数据集与资源

数据集与资源

  • 三个真实世界任务：Dynamic Scale Balancing (DSB)、Sequential Stacking (SS)、Diverse Pick-and-Place (DPP)
  • 每个任务收集30个机器人演示和50个人类演示，各5个轨迹标注
  • 硬件：7自由度Franka机械臂，两个1280×720 Intel RealSense D435i摄像头（第三视角和眼在手视角）
  • 训练资源：两张NVIDIA A100 GPU，PyTorch实现，CUDA 11.8
  • Action Policy运行频率15 Hz
Card 06 评估与结果

评估与结果

  • 基线方法：FT-Pi0.5（端到端VLA）、SeeDo（QA驱动层次化）、PALO（语义规划层次化）
  • 主要指标：成功率（Seen、Perturbed、Unseen三种设置）
  • TTS在7个设置中实现74.8%平均成功率，最佳基线SeeDo仅为30.4%
  • 在DPP任务Seen设置中TTS达84.6%，SS任务Seen设置达83.3%，DSB任务Seen设置达78.6%
  • 扰动测试中（DSB添加/移除重量、DPP抓取后移除目标），TTS分别保持60.0%和80.0%成功率
  • 消融实验证明各组件必要性：移除Track Predictor成功率大幅下降，仅Action Policy基线在所有任务上失败
  • LTP+VLM组合的Relation Predictor在准确率（98.4%）和延迟（32.2秒）间取得良好平衡
