02论文概述

  • 论文针对基于视觉的控制策略（包括视觉-语言-动作模型）在执行任务时推理计算成本高、执行速度受限的问题，提出一种在控制层面加速任务执行的方法
  • 研究目标是在不修改底层策略学习过程的前提下，通过异步推理与控制框架实现快速、平滑且稳定的机器人运动
  • 论文将不连续模型预测转换为连续目标位置的生成问题，并引入基于预测方差的适应度动作跳过机制来进一步加速执行

03核心贡献

  • 提出 控制感知命令生成（Control-Aware Command Generation, CAC） 方法，将策略输出的不连续期望位置序列转化为满足加速度约束的平滑目标位置序列
  • 设计 异步推理与多线程控制架构，将控制循环与推理循环分离，有效容忍推理延迟，提高控制频率
  • 提出 基于方差的自适应动作跳过机制，根据预测动作的方差动态调整执行速度，在动作可靠时跳过步骤加速，在不可靠时减速跟踪更新
  • 通过实验证明所提框架在不修改策略模型的情况下，显著提升执行速度并保持任务成功率，适用于 ACT（84M参数）和 OpenVLA-OFT（7B参数）等非扩散/非流匹配模型

04方法描述

  • 将模型推理得到的动作序列视为期望关节位置，通过跟踪控制问题生成满足加速度约束的目标位置序列，核心更新公式为：目标位置增量 = 期望位置增量 + 反馈修正项（带饱和函数）
  • 采用前馈-反馈控制结构，前馈项跟踪期望位置变化，反馈项使用饱和函数修正跟踪误差，类似滑模控制，保证误差在有限时间内收敛
  • 使用多线程分离控制循环与推理循环，控制线程周期性检查新动作块，推理线程异步生成动作序列；每个观测和动作块带时间戳
  • 根据同一时间步多次预测的方差计算动作可靠性，当方差低于阈值时跳过当前命令（时间步+2），否则正常更新（时间步+1），实现自适应执行速度

05数据集与资源

  • 使用 ACT（Action Chunking Transformer） 模型，参数量为 84M
  • 使用 OpenVLA 模型（7B 参数）并基于 OpenVLA-OFT 方法进行微调
  • 真实机器人实验基于 ALOHA 平台，包含三个任务：盒子交接、箱子堆叠、笔存放
  • 每个任务使用 50 次演示训练，3 个随机种子，每个种子重复测试 10 次
  • 训练和推理在配备 Intel Xeon w5-2455X CPU 和 NVIDIA RTX A5000 GPU 的工作站上进行

06评估与结果

  • 评估环境为真实 ALOHA 双臂机器人，使用离散速度、加速度、jerk 等指标衡量运动平滑性
  • 主要评估指标：任务成功率、任务执行时间、最大加速度、最大 jerk
  • 在 ACT 实验中，ACT +CAC +Async +Adaptive 将任务执行时间缩短至 53%–63%（相对同步执行），其中笔存放任务成功率从 30% 提升至 83%
  • 在 OpenVLA-OFT 实验中，异步执行将推理等待时间从每次约 18.5 秒降至不足 0.8 秒，任务执行时间从 49.0 秒降至 44.7 秒，同时成功率和同步模式相当
  • 消融实验表明，仅使用异步推理而不加 CAC 会导致加速度和 jerk 增大，可能产生振动；均匀跳过动作会导致运动精度下降甚至任务失败
