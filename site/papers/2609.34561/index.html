Card 02 论文概述

论文概述

  • 针对传统神经运动解码依赖稀缺配对神经-动作数据的瓶颈，提出BrainVLA框架，利用预训练视觉-语言-动作（VLA）模型的动作先验知识提升解码性能与数据效率
  • 通过构建VLA兼容的多模态数据集，补充神经运动数据缺失的视觉观察和语言指令模态，建立适配神经运动任务的VLA策略
  • 设计语言介导的神经-语言对齐方法，使神经活动能够通过语义表征引导VLA策略生成可执行动作，在跨会话因果滚动解码协议下验证框架有效性
Card 03 核心贡献

核心贡献

  • 首次提出将预训练VLA模型引入神经运动解码领域，为缓解配对神经-动作数据稀缺问题提供全新解决思路
  • 设计语言介导的神经-语言对齐方案，通过将神经表征与语言表征对齐，捕捉神经活动中的潜在运动意图，搭建神经信号与VLA策略的语义接口
  • 构建适配VLA训练要求的VLA兼容数据集，同时定义任务级成功评估指标，补充传统轨迹解码指标的不足
  • 在两种不同动作维度的公开神经运动数据集上验证框架性能，在解码精度、任务成功率和训练数据效率上均显著优于现有基线方法
Card 04 方法描述

方法描述

  • 整体框架分为四个核心模块：任务适配的VLA策略、神经编码器、神经-语言对齐模块、脑条件动作策略
  • 任务适配阶段：以开源OpenVLA-OFT为backbone，冻结VLA主干参数，通过LoRA微调、优化专属动作头和本体感觉投影器，将VLA适配到目标神经运动任务的动作空间，实现参数高效的领域适配
  • 神经编码器设计：将神经活动建模为异步尖峰事件序列，通过可学习潜在查询的交叉注意力将变长神经输入压缩为固定尺寸表征，再经多层自注意力块细化，捕捉神经群体的时序交互信息
  • 神经-语言对齐训练：将神经表征与VLA语言token的表征分别均值池化并L2归一化，采用对称多正样本对比损失进行对齐，使神经表征能够捕捉对应运动意图的语义信息
  • 因果滚动推理：推理时移除语言指令输入，对齐后的神经表征直接替代语言条件输入VLA策略，仅依赖历史神经活动、模型自身预测演化出的视觉观察和本体感觉生成动作，模拟真实脑机接口的闭环解码场景
Card 05 数据集与资源

数据集与资源

  • 使用的公开神经运动数据集：Dataset 1（人类受试者神经活动 paired 7-DoF机械臂动作，来自Collinger等人、Wodlinger等人公开数据）、Dataset 2（非人灵长类神经活动 paired 2-DoF手指控制动作，来自Nason等人公开数据）
  • 模型规模：基于7B参数的OpenVLA-7B作为VLA主干，通过LoRA实现参数高效微调，无需更新完整VLA主干参数
  • 训练与推理资源：推理延迟测试使用NVIDIA RTX PRO 6000 Blackwell Server Edition GPU，D1单次8步动作块查询耗时0.064s，D2单次查询耗时0.045s
Card 06 评估与结果

评估与结果

  • 评估环境与基准：采用跨会话设置与因果滚动解码协议，对比基线包括Wiener滤波器、RNN、CycleGAN+WF、POYO、NDT2、NoMAD、SPINT、NDT3等主流神经解码方法
  • 主要评估指标：动作预测R²、任务成功率（SR）
  • 关键实验结果：1. BrainVLA在D1上的解码R²达0.65±0.11、任务成功率0.77±0.10，在D2上的解码R²达0.46±0.05、任务成功率1.00±0.00，显著优于所有基线方法，实现跨会话的零样本迁移；2. 在低数据 regimes 下仍保持优异性能，数据效率远高于POYO和LSTM基线；3. 组件消融验证了VLA任务适配、神经-语言对齐、视觉观察和完整VLA策略的关键作用，模态消融表明神经意图、视觉状态、本体感觉三者具有互补贡献；4. 维度级分析发现视觉主要支持平移维度控制，神经活动更多贡献腕部旋转和手指控制相关维度的解码精度
