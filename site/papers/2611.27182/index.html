02论文概述

  • 提出 TRIP（Tripwire）：一种免训练、事件驱动的机器人智能体执行框架，让智能体为正在运行的策略编写并更新自己的中断程序（tripwire）。
  • 解决回合制 harness 在策略执行期间智能体“失明”的问题：人类可能中途进入机器人路径或移动目标物体，而智能体无法及时重新决策。
  • tripwire 是一段轻量、有状态的 Python 程序，与策略并行运行，可调用紧凑 VLM 感知场景、结合深度与几何信息，决定是否中断当前调用并将控制权交还智能体。

03核心贡献

  • 提出 TRIP：免训练、策略无关的 harness，智能体通过编写和更新状态化 tripwire 来编程自身中断；tripwire 在执行中查询紧凑 VLM，并结合深度、记忆和计时器进行判断。
  • 构建 RoboHD 基准：基于 RoboCasa365 的 42 个任务、168 个场景，加入反应式人类化身，包含空间、物体状态、任务状态和感知四类扰动，任何人机接触均视为失败。
  • 在 三个 VLA（GR00T、REKI-2B、Xiaomi-Robotics-1）和一个 WAM（PatchWAM） 上系统评估 TRIP，显示其显著提升安全性且不损失任务成功率。
  • 在真实机器人 UFACTORY xArm 7 上验证 TRIP，在人类挡住手臂和移动目标物体两种干扰下仍能成功完成任务。

04方法描述

  • 事件驱动控制：智能体每次选择执行调用（策略执行或直接动作）并附带一个 tripwire；tripwire 在每个控制步检查观测，返回 false 继续执行，或返回触发原因（如“人距离 0.6 m，正在接近”）停止调用并唤醒智能体。
  • 可编程 tripwire：tripwire 是 Python 函数 w(o_t, m_t) -> (m_{t+1}, z_t)，具有内部记忆，可调用 vlm(question, images) 按需进行视觉问答，并结合深度、机器人姿态、计时器和历史记忆决定是否触发。
  • 有界执行与沙箱：限制 import、代码长度、VLM 查询次数、时间和内存；运行错误或超时会安全中断并唤醒智能体。
  • 智能体工具：包括观测检查、策略执行、直接动作、tripwire 编程和记忆检查；智能体在触发后重新评估场景，更新 tripwire 并继续任务。
  • RoboHD 扰动模拟：人类化身按空闲、接近、等待、行动、离开五阶段反应式行动，使用动作捕捉数据驱动；接触检测采用胶囊-边界盒几何判定。

05数据集与资源

  • RoboHD：168 个场景，来自 42 个 RoboCasa365 任务，每个任务对应 4 种扰动类型；其中 36 个场景来自 target split，132 个来自 pretrain split。
  • 底层策略：3 个 VLA（GR00T N1.5、REKI-2B、Xiaomi-Robotics-1 (XR)）和 1 个 WAM（PatchWAM），均使用 RoboCasa365 数据训练并保持冻结。
  • 智能体模型：默认 GPT-6.1-sol；消融中测试了 GPT-6 Astra。
  • tripwire VLM：Qwen3.5-9B（关闭思维链），约每秒查询 2 次。
  • 训练资源：仿真控制频率 20 Hz；真实机器人策略使用一块 RTX 4090，另用一块 RTX 4090 运行 Qwen3.5-9B；真实机器人策略为 π0.5 单任务策略，用 100 条遥操作数据通过行为克隆训练。

06评估与结果

  • 主要指标：有人的成功率（任务成功且无接触）、无人的成功率、安全性（在可无人生存场景中无接触的比例）。
  • 模拟结果（168 场景）：以最强策略 Xiaomi-Robotics-1 为例，TRIP 将有人成功率从策略单独运行的 20.8% 提升至 38.7%（agentic harness 为 31.0%）；安全性从 61.3% 提升至 81.3%，将人机接触率减半；无人时的成功率为 73.2%，与 agentic baseline 73.8% 相当。
  • 消融实验：固定 tripwire（智能体首轮编写后不再更新）安全性降至 61.3%；预定义 tripwire 安全性最高 86.0% 但成功率仅 16.1%；更换智能体为 GPT-6 Astra 成功率 38.1%、安全性 73.8%。
  • 调用效率：TRIP 的智能体工具调用为 19.4 次/分钟，agentic baseline 为 30.3 次/分钟；每回合观察调用 TRIP 10.1 次 vs baseline 28.7 次。
  • 真实机器人：在挂马克杯和挂毛巾两个任务上，TRIP 在“挡住手臂”和“移动目标”两种干扰下共 40 次试验中成功 25 次，而 agentic harness 成功 5 次、策略单独运行成功 1 次；tripwire 单次检查平均延迟 0.24 s，智能体回合平均 4.3 s。
