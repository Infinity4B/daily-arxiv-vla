Card 03 核心贡献

核心贡献

  • 形式化了 VLA 策略中的模态纠缠问题，并characterize了两种状态依赖的失败模式： nuisance sensitivity（对任务无关传感器的扰动敏感）和 single-modality insufficiency（无法仅依靠单个有用传感器完成任务）
  • 提出了 Evidence-Gated Regularization (EGR)，一种模态无关的训练目标，利用每帧、每传感器的任务相关性证据来门控两种状态条件一致性目标（不变性和充分性），推理时无额外开销
  • 构建了基于 BEHAVIOR-1K 的模态纠缠基准，包含 47 个技能片段（11 个导航 + 36 个操作）和两套评估套件（推理诊断和 rollout 执行）
  • 在模拟和真实机器人实验中验证了 EGR 的有效性，在传感器损坏和物理干扰物条件下显著提升了任务成功率
Card 04 方法描述

方法描述

  • 证据评分（Evidence Score）：为每个传感器在每个时间步计算 [0,1] 范围内的任务相关性分数。视觉证据基于实例分割计算焦点物体和交互物体的可见面积比；触觉证据基于接触检测或任务特征相似度
  • 证据门控正则化：使用两个阈值（τ_low, τ_high）将证据分数映射为门控权重：

- 不变性损失 L_inv：当证据较低时，惩罚对低证据传感器扰动引起的动作变化，缓解 nuisance sensitivity

- 充分性损失 L_suff：当证据较高时，惩罚仅保留该传感器与完整传感器输入之间的动作差异，缓解 single-modality insufficiency

  • 高效训练：通过重要性采样（importance sampling）将每步额外前向传播次数从 2\|M\|降低到 2，保持估计的无偏性
Card 05 数据集与资源

数据集与资源

  • 模拟基准：基于 BEHAVIOR-1K 构建，包含 47 个 curated 技能片段（11 个导航任务 NAV + 36 个操作任务 MAN），覆盖 12 个任务
  • 真实机器人平台：

- 双臂视觉平台：两台 Kinova 机械臂 + 三个 RGB 摄像头

- 视觉-触觉平台：MELFA ASSISTA 单臂 + 一个 RGB 摄像头 + 两个 GelSight 触觉传感器

  • 基础模型：π₀.₅（Vision-Language-Action 模型）
  • 训练资源：使用 importance sampling 将训练 overhead 降低到每步仅 2 次额外前向传播
Card 06 评估与结果

评估与结果

  • 评估环境：

- Suite 1：推理-only 诊断，测量每帧动作偏差（Δ），无需执行 rollout

- Suite 2：基于 rollout 的执行评估，测量任务成功率（SR）、末端执行器接触率（EC）和最小距离（Dist）

- 四种 corruption regime：Clean、NoUseless（仅损坏无用传感器）、UsefulOnly（仅保留有用传感器）、SingleUseful（仅保留单个有用传感器）、RealDistractor（物理干扰物）

  • 模拟结果（Suite 2）：

- MAN 任务：Full modalities 成功率从 12.5% → 16.4%（+31%）；NoUseless 从 9.4% → 16.5%（+75%）；UsefulOnly 从 2.8% → 6.1%（+120%）

- NAV 任务：SingleUseful 成功率从 15.5% → 37.3%（+141%）

- 动作偏差（Δ）在 EGR 下显著降低（NAV SingleUseful：31.4% → 15.8%；MAN UsefulOnly：158.5% → 121.8%）

  • 真实机器人结果：

- 双臂平台：RealDistractor 条件下成功率从 30% → 85%（+183%）；NoUseless 从 52.5% → 90%（+71%）

- 触觉平台：RealDistractor 从 55% → 70%（+27%）；SingleUseful 从 40% → 90%（+125%）
