SANA-Robot: Efficient World Action Model with Hybrid Memory

02论文概述

  • 提出 SANA-Robot，一个 4.5B 参数的世界动作模型（WAM），能够在边缘设备上实时运行，并具备分钟级长期记忆。
  • 解决现有 WAM 的两大问题：视频预测带来的高延迟无法满足实时控制，以及缺乏有效长期记忆导致无法处理依赖历史信息的操作任务。
  • 通过统一模型同时支持策略、前向动力学模型（FDM）和逆动力学模型（IDM），并实现高成功率与实时异步控制。

03核心贡献

  • 混合记忆恒定成本：结合线性注意力（Gated DeltaNet）维护固定大小全局状态与滑动窗口 softmax 注意力传播历史信息，在保持恒定推理速度的同时实现整集记忆。
  • 统一世界动作模型：一个网络通过动态噪声水平完成 FDM、IDM 和 Policy 三种角色，同时预测未来视频与动作。
  • 全栈训练与推理基础设施：提出多模态序列打包与任务均衡排序、chunk-causal teacher forcing、以及记忆相位异步执行（memory RTC），支持变长整集训练和 30Hz 实时控制。
  • 高效的实时部署优化：通过融合内核、CUDA graphs、前缀缓存和低比特 GEMM（FP8/NVFP4），将单请求延迟降低至 115–135ms，实现边缘设备闭环控制。
  • 大规模多源数据管道：整合 23 个数据集、19.4K 小时过滤后数据，涵盖真实机器人、UMI、仿真和人类第一视角视频。

04方法描述

  • 基于 Sana-Video 2 构建混合线性扩散 Transformer，堆叠 8 个块，每块含 3 层 Gated DeltaNet (GDN) 和 1 层 softmax 注意力。
  • 使用统一的 token 序列排列多视角视频、本体感知、未来视频和动作，并通过 mRoPE 将不同模态对齐到统一的物理时间坐标。
  • 训练采用 flow matching，对视频和动作 token 分别施加不同噪声水平，实现 FDM、IDM 和 Policy 的统一学习。
  • 混合记忆：GDN 层以固定大小循环状态压缩全局历史，softmax 层通过滑动窗口关注首帧和最近 chunk，两者结合覆盖长时依赖且不增加单步成本。
  • chunk-causal teacher forcing：在训练中一次前向/反向通过训练窗口内所有 chunk，提高训练效率和内存一致性。
  • 记忆 RTC：在异步执行中为每个相位维护独立记忆，保证部署时的 chunk 结构与训练一致。

05数据集与资源

  • 预训练数据来自 23 个数据集，包括 ABC-130K、MolmoAct2-BimanualYAM、FineART、AgiBotWorld、RoboCOIN、DROID、RoboMIND、HyEmbodied-UMI、InternData-A1、BEHAVIOR-1K、EgoDex、EgoVerse 等。
  • 原始数据 23.8K 小时，过滤后 19.4K 小时，生成 133M 训练 chunks。
  • 模型参数量：4.5B，基于 Sana-Video 2 初始化。
  • 训练资源：使用 64 块 GB300 GPU 进行预训练。

06评估与结果

  • 评估基准：RoboDojo、RoboTwin 2.0、LIBERO-Plus / LIBERO-Pro / LIBERO-Max、WorldArena 以及真实机器人任务。
  • 主要指标：成功率、记忆维度得分、延迟（每动作 chunk）、异步控制频率。
  • 在 RoboDojo 记忆维度上，SANA-Robot 在约 5B 中等规模模型中取得最佳性能。
  • 在 LIBERO-Plus、LIBERO-Pro、LIBERO-Max 上达到最高成功率。
  • 作为世界模拟器，在 WorldArena 排名第二，并在 DROID 上表现出与真实环境相似的行为。
  • 真实世界部署中，在 RTX 5090 上使用 FP8 GEMM 延迟为 135ms/chunk，使用 NVFP4 GEMM 为 115ms/chunk。
  • 实现 30Hz 闭环实时异步机器人控制，优于 π0.5 和 OpenWAM-α 等基线。
