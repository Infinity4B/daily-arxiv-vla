02论文概述

  • 针对机器人操作中固定视角导致任务相关信息遮挡、无法观测的问题，现有视觉-语言-动作（VLA）模型缺乏跨 changing viewpoints 推理与主动获取信息的能力，该问题在动态、杂乱的移动操作场景中更为突出
  • 论文提出ActiveScale框架，从模型、数据、硬件三个维度协同设计，解决主动感知在机器人操作中的三个核心挑战：现有VLA无相机姿态推理与运动预测能力、未有效利用人类活动中的自然相机运动信号、现有主动感知研究局限于静态环境且缺乏统一研究基础设施
  • 研究目标是构建端到端的主动感知机器人学习方案，提升机器人在需要主动调整视角的操作任务中的成功率

03核心贡献

  • 提出姿态锚定的时序VLA（pose-grounded temporal VLA），通过历史帧和可学习相机token实现跨视角关联与场景理解，在5个真实世界主动感知操作任务上达到最优性能
  • 提出人类-机器人中期训练方案，使用超过1000小时的第一视角人类数据和机器人数据进行训练，规模是此前相关工作的5倍以上，为将人类操作与主动视角先验迁移到机器人策略提供可扩展路径
  • 开发主动感知移动操作平台（AMP），支持单操作员通过统一遥操作接口协调主动视角控制、双臂操作与底盘移动，实现规模化主动感知相关演示数据收集

04方法描述

  • 模型架构：基于π₀.₅ VLA扩展设计，将输入从单帧图像扩展为包含历史帧的视频序列，为每帧前添加可学习的相机token，通过轻量级预测头预测相机的3D平移、四元数姿态与视场角，实现跨视角观测关联；采用块因果注意力机制，保证历史帧的相机token仅能访问过去与当前帧信息，后续 token 可访问全部有效历史块
  • 训练流程：采用两阶段训练策略，第一阶段为人类-机器人中期训练，以1:1的比例混合采样人类第一视角数据与机器人数据，人类数据以头相机轨迹提供主动视角监督、手腕轨迹提供操作监督，统一优化子任务预测、FAST动作离散化预测、流匹配连续动作预测、相机姿态预测四类损失；第二阶段为任务特定后训练，仅使用AMP收集的遥操作数据，优化流匹配动作损失与相机姿态损失，适配具体任务与机器人本体
  • 硬件平台：AMP基于改良的AgileX Cobot-Magic移动机器人搭建，新增第三个搭载相机的6自由度机械臂实现独立主动视角控制，采用Meta Quest 2头显与双手柄作为单操作员遥操作接口，可同时控制主动视角、双臂操作与底盘移动
  • 核心创新：首次将相机姿态监督与时序建模结合到VLA中实现主动感知，提出超大规模人类-机器人协同训练方案，搭建支持单操作员协调多模态控制的主动感知移动操作平台

05数据集与资源

  • 人类数据集：大规模第一视角室内操作数据集EgoLive与EgoVerse，用于中期训练提供主动视角与操作先验
  • 机器人数据集：AgiBot World、RoboCOIN以及自主收集的AMP遥操作数据集，用于中期训练与任务后训练
  • 模型规模：基于π₀.₅架构，采用3B参数的PaliGemma作为视觉-语言骨干，搭配轻量级基于Transformer的动作专家，整体为轻量级可部署的VLA模型
  • 训练资源：训练阶段使用NVIDIA H100 GPU，推理部署阶段在单张RTX 4090上可实现264.5Hz的动作块生成吞吐量，通过异步执行满足30Hz的实时控制频率要求

06评估与结果

  • 评估环境与基准：在5个真实世界主动感知操作任务上评估，分为遮挡驱动操作类（Bag、Drawer、Table）与主动搜索定位类（Pot、Box）两类场景，以π₀.₅为直接对比基线，采用与基线一致的后训练与评估协议
  • 评估指标：严格任务成功率（SR，要求所有任务阶段完成且满足最终状态约束）、任务进展（TP，各阶段完成度的加权平均值，覆盖所有rollout）
  • 关键实验结果：完整两阶段ActiveScale pipeline相比直接后训练的π₀.₅，平均任务成功率从30.0%提升至70.0%，平均任务进展从41.6%提升至78.4%，在需要主动调整视角的Table、Bag等任务上提升最为显著
  • 消融实验结果：人类-机器人中期训练可提升下游任务性能，仅添加历史帧的模型效果不稳定，添加姿态锚定相机token后所有任务的SR与TP均稳定提升，验证了相机姿态建模的有效性
  • 效率结果：单张RTX 4090上生成50步动作块的吞吐量达264.5Hz，通过异步执行可完全满足30Hz的实时控制需求
  • 平台验证：AMP平台支持单操作员完成同时协调主动视角控制、双臂操作与底盘移动的多阶段移动操作任务，验证了其作为数据收集平台的有效性
