HuRo: Robotizing Human Videos for Scalable VLA Pretraining

02论文概述

  • 本研究围绕大规模人类视频用于VLA（视觉-语言-动作）策略预训练展开，旨在解决真实机器人预训练数据稀缺、人类视频与机器人存在具身差距（观测与动作双重不匹配）的核心问题，探索异构人类视频经机器人化转换后作为可扩展预训练监督信号的可行性。
  • 论文提出了HuRo数据集构建pipeline，可将不同来源、不同标注水平的以自我为中心的人类视频转换为对齐的机器人观测与动作轨迹，自动补全缺失的相机参数、手部姿态、语言指令等中间信号，生成适用于VLA预训练的统一格式数据。
  • 通过真实机器人操作任务的实验，验证了机器人化预训练的规模效应、视觉机器人化的作用以及端到端预训练的优势，为低成本获取大规模机器人预训练数据提供了有效方案，相关代码与数据集已公开。

03核心贡献

  • 设计了系统性的人类视频机器人化pipeline，同时实现动作重定向与视觉转换，支持异构来源的人类视频自动处理，可补全缺失的中间信号，生成对齐的机器人观测-动作对。
  • 构建了大规模HuRo预训练数据集，包含约63万条机器人化episode、1.42亿帧处理后视频，总时长约1317小时，来自Ego4D、EPIC-Kitchens、EgoDex、EgoVerse、Ego10K五个公开人类视频数据集，规模是此前同类工作的10倍以上。
  • 验证了机器人化预训练的清晰规模效应：预训练规模越大，下游真实机器人操作的分布内（ID）与分布外（OOD）完成率持续上升，ID完成率从68.1%提升至88.4%，OOD完成率从34.9%提升至72.2%，全规模预训练效果超过π0.5、GR00T N1.6等现有机器人基础模型。
  • 证明了视觉机器人化的关键作用：保留人类观测、仅使用重定向动作监督的no-overlay版本OOD完成率仅为55.7%，远低于带视觉机器人化的全HuRo版本（72.2%），甚至不如10%规模的HuRo预训练效果。
  • 验证了端到端VLA预训练的优势：同时使用视觉与动作监督的预训练方式，在操作任务上的表现大幅优于仅使用视觉迁移的方式，且相比视频生成预训练baseline（I2V+IDM）扩展性更好，相同预算下效果更优。

04方法描述

  • 整体采用三阶段机器人化pipeline完成人类视频到VLA预训练数据的转换：人类视频标注、动作转换、视觉转换。
  • 人类视频标注阶段：通过droidcalib/AnyCalib估计相机内参，100DoH检测手部区域、BOT-SORT做时序跟踪，HAWOR估计MANO格式的手部姿态，DROID-SLAM（排除手部区域）+MoGe-2获取度量尺度的相机轨迹，GeoCalib对齐世界坐标系与重力方向，最后将视频切分为片段后用Qwen3.5生成语言指令，并通过验证步骤过滤无手部操作的无效片段。
  • 动作转换阶段：使用PyRoKi工具做运动重定向，先估计片段级的相机世界坐标系到机器人基坐标系的变换（3D平移+yaw旋转），联合优化该变换与机器人关节位形匹配手部运动与自我视角目标，再优化全时序关节轨迹并加入时序平滑约束，最终将关节轨迹转换为策略状态序列，以相邻时刻的状态差作为动作标注（aₜ = sₜ₊₁）。
  • 视觉转换阶段：先用SAM2+Detectron2分割人体区域，再用ProPainter修复背景得到去除人体的帧，最后用Isaac Sim渲染目标机器人，叠加到修复后的帧上，得到机器人化的观测图像，与状态、动作、语言指令共同组成最终的HuRo数据集episode。
  • VLA策略训练基于GR00T-N1.6-3B架构，VLM主干编码机器人化RGB图像与语言指令得到视觉-语言嵌入，动作头预测40步的动作块，动作包含左右手腕相对姿态（3D平移+6D旋转）与左右手关节绝对目标，采用flow-matching目标训练，预训练80k步、微调30k步。
  • 核心创新点是首次系统实现了异构人类视频的联合观测-动作机器人化，支持不同标注水平的视频源自动转换，为大规模VLA预训练提供了低成本的可行路径。

05数据集与资源

  • 使用的源人类视频数据集：Ego4D、EPIC-Kitchens、EgoDex、EgoVerse、Ego10K
  • 构建的HuRo数据集：包含约63万条机器人化episode、1.42亿帧处理后视频，总时长约1317小时（30fps），来源占比为EgoDex 56%、EgoVerse 27%、Ego4D 10%、Ego10K 6%、EPIC-Kitchens 2%。
  • 模型规模：VLA策略基于GR00T-N1.6-3B，参数量为3B。
  • 训练资源：由RLWRLD提供计算资源与ALLEX人形机器人平台，使用Isaac Sim进行机器人渲染，预训练采用全局batch size 2048，微调采用batch size 128。

06评估与结果

  • 评估环境与基准：在ALLEX双臂灵巧人形机器人平台上开展真实世界实验，包含4个操作任务（Apple Pick-and-Place、Cup Stacking、Cup-Noodle Handover、Microwave Loading）；对比基准包括无预训练（No PT）、仅视觉预训练（PT Visual Only）、现有机器人基础模型π0.5、GR00T N1.6，以及视频生成预训练baseline I2V+IDM。
  • 主要评估指标：任务完成率，其中Apple Pick-and-Place采用二元成功分数，其余任务采用阶段式部分完成分数，同时评估分布内（ID）与分布外（OOD，引入空间/视觉偏移）表现。
  • 关键实验结果：

- 规模效应：随着HuRo预训练规模从0%提升至100%，下游任务平均完成率从51.5%提升至80.3%，ID完成率从68.1%升至88.4%，OOD完成率从34.9%升至72.2%，全规模预训练效果超过π0.5与GR00T N1.6参考模型。

- 视觉机器人化价值：no-overlay版本（保留人类观测、仅使用重定向动作监督）的ID完成率（89.4%）与全HuRo版本（88.4%）接近，但OOD完成率仅55.7%，远低于全HuRo版本，甚至不如10%规模的HuRo预训练效果（59.5%）。

- 端到端预训练优势：仅视觉迁移的预训练方式相比无预训练提升有限，而端到端视觉+动作预训练在Diverse Pick-and-Place任务上ID完成率达61.1%、OOD完成率达50.0%，能执行更符合演示的准确操作姿态，泛化性显著更优。

- 相比视频生成预训练的优势：在相同预训练帧预算（0.7M、3.5M、7.0M帧）下，HuRo始终优于I2V+IDM baseline，0.7M帧的HuRo即可超过7.0M帧的I2V+IDM，且HuRo的OOD性能随规模持续提升，而I2V+IDM在3.5M帧后OOD性能不再增长。
