GRID-UAV: Geometry and Ray-depth Integrated Decision-making for Unmanned Aerial Vehicles

  • 作者包括 Anas Anwarul Haq Khan、Amrin Kareem、Muhammad Umer Sheikh、Biplab Banerjee、Muhammad Haris Khan

02论文概述

  • 研究 UAV 视觉-语言-动作模型（VLA） 在长距离飞行中如何有效利用 3D 信息；现有 2D 图像编码器缺少 3D 结构，直接注入深度特征在长航程上无显著收益（成功率 42.5% vs 42.6%）
  • 提出 GRID-UAV，一种仅使用前视与下视 RGB 相机的策略，结合 显式 3D 提升（explicit 3D lifting）与 隐式几何对齐（implicit alignment）
  • 解决两个互补失败模式：无法到达目标（T1，途中碰撞）与到达后无法完成任务（T2，如悬停不降落）

03核心贡献

  • 通过失败分析分离 T1（未到达目标） 与 T2（到达未完成），揭示显式 3D 提升减少 T1 但增加 T2，隐式对齐相反，二者互补
  • 提出 GRID：对单目深度进行射线校正的 3D 反投影，统一前视/下视相机到 UAV 体坐标系，并将傅里叶编码的位置特征注入视觉 token；训练时与冻结的 VGGT 多视角几何模型对齐，推理零额外开销
  • 在 TravelUAV 三个测试子集上均取得最高成功率，相对现有最优方法的提升为 9.5%（Seen）、17.1%（Unseen Object）、25.4%（Unseen Map）
  • 证明直接添加深度特征对长航程导航无效，而显式 3D 提升可显著提高成功率（42.6% → 46.6%）

04方法描述

  • 基础策略基于 OpenVLA-7B，使用 DINOv2 和 SigLIP 编码前/下视图，Llama-2 7B 经 LoRA 微调，输出量化飞行动作/LAND
  • 显式分支：采用细调到航拍视角的 Metric Depth Anything V2-Large 预测距离图；每个 token 取 4 个深度样本并沿归一化视射线反投影到 UAV 体坐标系，避免广角畸变
  • 使用傅里叶特征编码（L=8，S=40m）和可学习 MLP 将 3D 位置投影到 token 宽度，残差加入视觉 token；分支仅增加 5.2M 可训练参数（占总参数 0.07%）
  • 隐式分支：训练时冻结 VGGT，将其最后一层特征双线性重采样到策略的 16×16 token 网格，与 LLM 第 24 层视觉 token 隐藏状态通过余弦损失对齐（λ=0.5），并与动作交叉熵联合训练；推理时丢弃 VGGT 和对齐头

05数据集与资源

  • 数据集：TravelUAV 的 UAV-Need-Help 任务；训练集采用 AeroVLA 整理版本，含 7,611 条轨迹、410k 帧、11 个环境；测试集 3,005 个 episode（Seen 1,418 / Unseen Object 629 / Unseen Map 958），路线平均 256m、最长 1.1km
  • 模型规模：基础 OpenVLA-7B（约 7B 参数）；显式 3D 分支新增 5.2M 可训练参数；隐式对齐头约 12.6M 参数，推理时移除
  • 训练资源：4 块 A100 (40GB) GPU；所有策略统一训练设置与超参数

06评估与结果

  • 评估基准：TravelUAV 三个测试分割及 Easy/Hard 子集；指标包括 SR（成功率）、OSR（Oracle 成功率）、NE（导航误差）、SPL
  • 采用配对 McNemar 检验和 bootstrap 置信区间，所有方法在相同起点、headless GPU 环境下评估；AeroVLA 使用作者发布 checkpoint 复现
  • GRID 在全部测试子集上取得最优 SR：Seen Full 48.03%（AeroVLA 43.86%），Unseen Object Full 56.76%（AeroVLA 48.49%），Unseen Map Full 42.69%（AeroVLA 34.03%）
  • GRID 整体成功率从 41.7% 提升到 48.2%，并在所有子集上相对 SOTA 显著提升（p<0.05），除了 Seen Hard 子集
  • 消融显示：直接深度特征无提升（42.5% vs 42.6%）；显式 3D 提升优于深度特征（46.6%）；显式+隐式结合比仅隐式显著提高到达率（61.5%→69.5%，p<0.001），比仅显式显著提高完成率（57.7%→61.4%，p<0.05）
  • 计算成本：显式分支仅增加一次冻结深度前向传播，隐式分支仅训练时使用，推理时无额外参数与计算
