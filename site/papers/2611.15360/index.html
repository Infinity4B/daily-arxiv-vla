01研究单位

  • 论文作者来自 NEXTAI Research Institute, Chery Group（奇瑞集团 NEXTAI 研究院）

02论文概述

  • 提出 CARE-Drive，一种面向端到端自动驾驶的视觉-语言-动作（VLA）框架，通过物理上可解释的位置和航向修正来细化轨迹
  • 针对现有轨迹细化方法缺乏物理量专业化与交互建模的问题，将细化过程分解为位置残差修正和基于修正位置的航向生成
  • 在 NAVSIM v1 基准上验证了方法的有效性，通过分阶段训练和耦合交替优化提升规划性能

03核心贡献

  • 提出 CARE-Drive 世界-动作框架，整合未来监督表示学习与分阶段轨迹细化，在 NAVSIM v1 上取得 88.8 PDMS
  • 设计物理上可解释的 位置专家 和 航向专家，分别输出有界 XY 残差和相邻角度增量，并实现位置到航向的条件耦合
  • 引入 未来 token 辅助任务，通过预测未来潜在特征增强 backbone 的场景演化理解能力，带来显著的性能提升
  • 采用 分阶段交替优化策略（backbone 模仿学习 → 航向 SFT+RL → 位置 SFT+RL → 航向自适应），相比联合训练显著提升规划精度
  • 提出 难度加权模仿学习 与 安全门控进度奖励，进一步优化训练过程，增强安全与进度之间的平衡

04方法描述

  • 使用 Qwen3-VL-2B 作为 backbone，包含未来 query 和 action query，通过因果注意力传递未来场景信息
  • 未来 token 辅助任务：冻结的 V-JEPA 2.1 ViT-G 编码器提供未来图像特征监督，backbone 学习预测潜在未来特征
  • 位置专家：自回归 Transformer 接收共享 action 特征和基础轨迹，预测有界 XY 残差（每个轴 401 个类别，分辨率 0.025m/0.015m）
  • 航向专家：以修正后的 XY 位置和共享特征为条件，生成相邻角度增量（量化到 0.1 度），通过累积重建航向序列
  • 训练采用 分阶段课程：backbone 模仿学习 → 航向 SFT 和两阶段 RL → 位置 SFT 和两阶段 RL（含安全门控进度奖励）→ 最终航向自适应
  • 强化学习使用 GRPO 启发的 clipped 目标，结合 batch 级 RMS 校准和 KL 正则化

05数据集与资源

  • 使用 NAVSIM v1 数据集，训练场景约 92,772 个（专家训练使用 92,614 个），测试集为 12,146 个场景的 navtest 划分
  • backbone 为 Qwen3-VL-2B（约 20 亿参数），位置和航向专家各约 78.42M 参数，合计约 156.84M 额外参数
  • 训练资源：16 块 Ascend 910 加速器，完整训练流程约 19 小时

06评估与结果

  • 评估环境：NAVSIM v1 非反应式仿真，使用传感器观测和自车状态预测未来轨迹
  • 主要评估指标：PDM Score (PDMS)，综合安全性、行驶进度和舒适性
  • 关键实验结果：

- CARE-Drive 取得 88.837 PDMS，相比同一 backbone 未细化轨迹（86.462）提升 2.375 点

- 在 VLM/VLA 方法中排名第三，仅次于 Uni-World VLA (89.4) 和 CoWorld-VLA (90.0)，超过 AutoVLA (88.026)

- 消融研究表明：分阶段训练优于联合训练（88.837 vs. 85.651/83.671）；未来 token 辅助任务带来 2.49 点提升；难度加权模仿学习带来 0.6 点提升；安全门控进度奖励在 λ=1 时最优（88.840）
