03论文概述

  • 论文提出 Agentic-Teacher，一个自主数据引擎，用于失败驱动的 VLA（视觉-语言-动作）模型后训练，无需人类专家提供纠正性演示
  • 核心问题：编码智能体能否自主识别 VLA 失败轨迹的因果帧、生成成功的修复演示，并将纠正行为蒸馏回模型本身
  • 解决 DAgger 类方法依赖人工监控和干预、纠正性数据收集难以规模化的问题，同时应对“任务成功不等于有效监督信号”的挑战

04核心贡献

  • 提出 Agentic-Teacher 自主数据引擎，将 VLA 弱点识别、局部修复专家构建和训练数据筛选连接起来，无需人类逐个诊断失败、编写修复程序或提供纠正动作
  • 开发针对 VLA 学习的轨迹适配方法（噪声注入、空闲帧去除、流匹配损失过滤），解决代码策略数据覆盖有限、时间冗余和基础策略不兼容问题
  • 在 LIBERO、MetaWorld、RoboCasa 三个仿真基准上验证有效性：π₀ 在 LIBERO-10 上成功率从 79.4% 提升至 87.8%，MetaWorld-10 上从 80.4% 提升至 90.6%，三个 RoboCasa 任务上从 0% 提升至 30.0%
  • 修复采样效率显著优于 RL 基线：每任务 400 次尝试内平均产生 139 条成功轨迹，而 PPO 为 0 条

05方法描述

  • 失败诊断：智能体分析 VLA 失败 rollout，定位因果帧（causal frame localization），并按失败模式聚类（抓取、运输、放置失败等），利用成功轨迹作为参照
  • 智能体代码策略探索：编码智能体（GPT-5.6 Sol，reasoning effort 设为 high）使用感知与控制工具（SAM3 分割、Contact-GraspNet 抓取提议、PyRoki 运动学逆解）合成闭环代码策略，通过执行反馈迭代修订，并积累可复用技能库
  • 轨迹适配流水线：(1) 时间相关动作噪声注入以扩大状态-动作覆盖；(2) 去除空闲帧（保留夹爪切换帧，阈值为 1mm 平移、3mrad 旋转、0.1mm 手指位移）；(3) 基于冻结基础模型流匹配损失过滤不兼容轨迹
  • 策略更新：保留的修复轨迹与 VLA 前缀拼接，结合成功的 VLA rollout 进行流匹配目标的监督微调，更新后的模型独立运行、无需智能体辅助

06数据集与资源

  • 评估基准：LIBERO-10、MetaWorld-10、三个 RoboCasa 任务
  • 基础模型：π₀（VLA 流匹配模型），各基准分别使用对应预训练 checkpoint（如 RLinf π₀ MetaWorld SFT、π₀ human300 multitask step 75,000）
  • 智能体：GPT-5.6 Sol（reasoning effort=high）；工具包括 SAM3、Contact-GraspNet、PyRoki
  • 训练资源：每个基准使用 4 张 GPU（FSDP 或 DDP 并行），全局 batch size 32–64，训练步数 5,000–20,000 步

07评估与结果

  • 评估设置：每任务 50 次评估 rollout，基线收集 50 次基础策略 rollout 并选取失败轨迹进行修复
  • LIBERO-10：π₀ 平均成功率从 79.4% 提升至 87.8%（RFT 基线仅 81.4%）
  • MetaWorld-10：从 80.4% 提升至 90.6%（RFT 基线为 85.2%）
  • RoboCasa：三个任务从 0% 提升至 30.0%（RFT 因基线无法产生成功轨迹而不适用）
  • 轨迹适配消融：原始代码策略轨迹训练成功率为 0%，完整流水线达 95.0%（LIBERO 上噪声注入 81.0% → 空闲帧去除 89.0% → 流匹配过滤 95.0%）
  • 采样效率：每任务 400 次尝试内产生平均 139 条成功轨迹，而 PPO 基线为 0；多数失败模式（如 moka 壶手柄错位 22%→0%）经后训练被消除
  • 局限：长时序任务末端仍有残余错误（如黄油接近阻挡 8%→2%）；修复能力受技能库覆盖限制；物理机器人上的轨迹重放成本较高
