02论文概述

  • 提出 A2I-VLA，一个融合 力觉（wrench）与触觉（tactile） 的两阶段 视觉-语言-动作（VLA） 模型，用于接触丰富的机器人操作。
  • 解决现有 VLA 方法中 视觉-语言语义特征与物理量测特征之间存在表示鸿沟 的问题，避免直接拼接导致的训练冲突。
  • 在真实机器人任务上，将基线 π0.5 的平均成功率从 70.00% 提升到 95.00%。

03核心贡献

  • 提出 A2I-VLA 两阶段框架，系统性将力觉与触觉反馈引入 VLA 动作生成。
  • 设计 第一阶段的语义-物理对齐与层次化多模态融合，通过未来力/力矩预测与动作预测联合学习任务相关的力-触觉表示。
  • 设计 第二阶段的门控交叉注意力桥模块，让物理特征自适应地引导动作专家输出。
  • 在 环轴插入、黑板擦拭、以太网接头插入 三个真实接触丰富任务上验证有效性，显著优于 π0.5 和 ForceVLA。

04方法描述

  • Stage I（力-触觉表示学习）：并行使用冻结的 π0.5 语义编码器（提取视觉-语言-状态特征）和 MLP 物理编码器（分别编码六维力/力矩与二值触觉），用共享查询的交叉注意力和方差正则化实现 语义-物理对齐。
  • 层次化多模态融合网络：语义与物理特征通过可学习模态嵌入后拼接，再经 4 层 Transformer 融合；每层保留触觉和力觉 token，并用注意力选择器生成物理描述符。
  • 物理感知损失：拼接各层描述符，用两个 MLP 头分别预测 未来力/力矩序列 与 未来动作序列，与真值计算 L2 损失。
  • Stage II（力-触觉特征集成）：将 Stage I 学到的物理编码器和融合网络作为特征提取器，提取各层触觉与力觉特征；门控交叉注意力桥 以动作专家输出为查询，分别聚合触觉和力觉特征，并经可学习门控融合后加入动作特征。
  • 训练策略：Stage II 先只训练桥模块（基础 VLA 与特征提取器冻结），再联合微调；融合时线性层零初始化以保持初始输出不变。

05数据集与资源

  • 使用 自采集真实机器人操作数据，未公开命名数据集；平台包含 UR10 机械臂、GoPro 鱼眼相机、Intel RealSense D405 相机、六轴力/力矩传感器、两块触觉传感器。
  • 任务为 环轴插入、黑板擦拭、以太网接头插入；物体随机放置，训练数据通过遥操作设备采集。
  • 输入包括两路 RGB 图像、语言指令、机器人状态、六维力/力矩（wrench）和二值触觉值。
  • 模型骨干基于 π0.5 VLA；论文未明确给出参数量。
  • 训练资源：8 块 A100 GPU，AdamW 优化器；Stage I 训练 1 万迭代，batch size 512，学习率最高 1e-4；Stage II 训练 5 万迭代，batch size 64，学习率 5e-5。

06评估与结果

  • 评估环境：三个真实接触丰富任务，每个 checkpoint 20 次真实机器人试验，取最后 5 个 checkpoint 中最高成功率。
