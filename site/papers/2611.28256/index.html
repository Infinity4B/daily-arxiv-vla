02论文概述

  • FlowPAC 是一个面向 视觉-语言-动作（VLA）模型 的高效推理框架，目标是在不损失控制性能的前提下大幅降低端到端推理延迟和内存占用
  • 论文要解决的问题是：现有视觉 token 剪枝和动作缓存等训练免费加速方法通常采用静态资源分配，与动态机器人交互不匹配，导致控制性能下降和硬件效率低下
  • 核心思路是利用 任务感知的光流（task-aware optical flow） 作为共享物理信号，同时指导视觉 token 的保留位置与动作专家计算的刷新时机

03核心贡献

  • 提出 方向感知轨迹传播（DATP），将指令条件语义相关性与有符号光流结合，将视觉 token 重要性沿预测轨迹向未来交互区域传播，避免剪掉未来关键区域
  • 提出 流条件动作块刷新（FCAR），根据语义加权的双视图运动幅度动态调整动作专家的重算预算，在稳定阶段复用残差、在动态阶段增加刷新，且不改变原始流匹配轨迹
  • 提出 局部性感知连续 token 选择（LACT），通过连续块选择和延迟物理打包减少 KV-cache 碎片化，在相同预算下显著降低打包内存访问次数
  • 在 LIBERO 基准上验证 FlowPAC 在保留 30% 视觉 token 的情况下实现 2.13× 端到端加速，同时基本保持成功率（95.80%），并将 KV cache 压缩 2.75×

04方法描述

  • DATP：先计算连续观测间的稠密光流并聚合为 patch 级运动向量，再以指令条件语义相关性加权估计运动中心和主导方向，沿方向传播多步形成未来关键区域走廊，最终与瞬时语义分数、运动幅度融合得到 token 选择分数
  • LACT：将视觉 token 分组为对齐的连续块，优先选择高分数区域的完整块，剩余预算由相邻高分数块填充，从而在精确保持预算的同时强制空间局部性；延迟到指定层再执行物理打包，保留早期视觉-语言交互并缩短后续 prefix 和 KV cache
  • FCAR：将双视图语义加权运动幅度映射为当前 episode 内的因果经验百分位数，据此线性插值得到刷新预算，并沿去噪轨迹均匀分布刷新点；在刷新点正常计算并缓存 attention 和 FFN 残差，在复用点跳过计算并重用最近残差
  • 联合推理：每次控制查询时，DATP 计算一次语义和运动证据并共享给 LACT 和 FCAR，两个分支分别优化空间（prefix 长度和 KV）与时间（动作去噪计算）维度

05数据集与资源

  • 使用 LIBERO 基准的官方 π0.5 模型检查点，包含 Spatial、Object、Goal、Long 四个 suite，共 40 个任务，每个任务 50 次试验（共 2000 个 episode）
  • 原始模型为 π0.5 流匹配 VLA 模型，采用两个主动相机视角（全局和腕部）和 10 步流匹配求解器
  • 所有实验在 单张 NVIDIA A100-PCIE-40GB GPU 上运行，BF16 精度，batch size 为 1，使用 CUDA 事件计时
  • 对比基线包括 FastV、VLA-ADP 和 VLA-Cache，在匹配的 70%、50%、30% 控制比例下进行比较

06评估与结果

  • 成功率：FlowPAC 在 70%、50%、30% 保留率下分别达到 97.15%、96.15% 和 95.80% 平均成功率，其中 30% 保留率下相比 FastV 和 VLA-ADP 在 LIBERO-Long 上优势明显（92.2% vs 71.2% 和 83.2%）
  • 端到端延迟：FlowPAC 在 30% 保留率下将 P50 延迟从 306.19 ms 降至 143.45 ms（2.134× 加速），P95 延迟从 313.89 ms 降至 147.51 ms（2.128× 加速），显著优于视觉路径基线最多 1.09× 的加速
  • KV cache：视觉 prefix 的 live KV state 从 17.02 MiB 降至 6.19 MiB，实现 2.75× 压缩
  • 组件消融：FCAR 单独使用时刷新仅 27.5% 的动作专家块，达到 96.10% 成功率和 152.43 ms 延迟（2.01× 加速）；加入 DATP 和 LACT 后进一步降低延迟至 144.42 ms 并提高成功率至 97.15%，验证空间和时间组件的互补增益
