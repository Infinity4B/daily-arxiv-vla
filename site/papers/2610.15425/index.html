Card 03 核心贡献

核心贡献

  • 提出 Hierarchical Subtask Execution（HSE）：一种诊断执行框架，通过 planner、trigger、policy 的共享模块接口，将长程失败分解为子任务排序错误、边界时序错误和下游执行失败等可分离模式。
  • 提出 RoboCombine 基准：专注于无组合训练轨迹的技能重组，训练仅使用孤立原子任务轨迹，评估未见有序组合，并提供 ordered success 与 transition conversion 等细粒度指标。
  • 识别 start state gap：原子训练使用规范起始状态，而组合执行中下游子任务从 handoff states 启动，这一不匹配是原子技能无法自动转化为可靠顺序执行的关键瓶颈。
  • 提出 Pose Robust Task Initialization（PRTI）：一种轻量级原子任务后训练策略，通过从成功原子轨迹的后期片段采样任务有效初始状态，扩展起始状态覆盖，同时保持 atomic-only 训练边界。
  • 在仿真和真实机器人上验证：PRTI 显著提升组合执行成功率，且不需要任何组合技能训练轨迹。
Card 04 方法描述

方法描述

  • HSE 诊断框架：将组合命令分解为原子子任务队列，一次仅激活一个原子指令，当 handoff cue 触发时替换下一个子任务的条件指令；通过控制 subtask queue、handoff cue 和 atomic VLA model 三个因素，实现受控诊断。
  • HSE 评估模式：包括 Pred（预测队列与预测 cue）、Ordered（真实队列与预测 cue）、Oracle（真实队列与真实 cue）和 Enhanced（真实队列与真实 cue，替换原子策略）。
  • RoboCombine 构建：基于 RoboTwin 原子任务，训练限制为孤立原子轨迹，测试为两阶段有序组合；评估 ordered success、第一/第二子任务成功率和 transition conversion。
  • PRTI 后训练：构建辅助池，从成功原子轨迹的后期片段中提取对象姿态、末端执行器姿态和接触配置；对每个目标技能采样任务有效子集，混合 canonical 原子轨迹与 PRTI 轨迹（1:1），仅以目标原子指令为条件进行后训练。
  • 创新点：将层级框架从“解决方案架构”转变为“测量接口”，并发现无需组合演示即可通过扩展原子起始状态覆盖来缓解 handoff 执行失败。

Card 06 评估与结果

评估与结果

  • 评估环境与基准：仿真使用 RoboCombine 与 oracle HSE 诊断轨道，真实机器人使用 Order HSE 模式在线触发 handoff；对比方法包括 Full-Inst FT、Random、Reset、Base 和 PRTI。
  • 主要评估指标：ordered success（SR_ord）、第一/第二子任务成功（SR_1 / SR_2）以及 transition conversion（Conv_{1→2}）。
  • 全指令微调结果：在已覆盖组合集 A 上达到 40.0%，在部分重叠集 B 上 15.0%，在不相交集 C 上 4.4%，B 和 C 平均仅 7.7%，表明有限组合监督难以泛化到未见组合。
  • HSE 诊断结果：Motus 在各执行模式下取得最高聚合 ordered success，Oracle-HSE 19.7%、Ordered-HSE 17.4%、Full-Inst 10.0%；第一子任务成功不能可靠转化为下游执行，且转换率具有 pair-specific 特征。
  • PRTI 仿真结果：在 oracle HSE 下，PRTI 达到 18.16% ordered success，显著高于 Random 4.21%、Reset 9.47% 和 Base 2.63%；nonzero-task coverage 为 89.47%，transition conversion 为 39.88%。
  • 真实机器人结果：Oracle-HSE+PRTI 在多个物理多阶段任务上提升了 mean progress，例如任务 1-8-6 下达到 0.66，高于 Full-Inst-FT 0.62、Order-HSE 0.34 和 Oracle-HSE 0.44，表明仿真结论可迁移至真实执行。
