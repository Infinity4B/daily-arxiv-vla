$A^3$-VLA: Automatic Perception-Guided Attention Alignment for Robot Manipulation

02论文概述

  • 提出 A³-VLA 框架，旨在解决视觉-语言-动作模型（VLA）在机器人操作任务中因动作预测目标缺乏细粒度任务感知监督，导致视觉注意力漂移到任务无关区域、操作性能和泛化能力受限的问题。
  • 核心思想是从操作过程本身自动提取任务特定视觉引导：利用交互时刻的视觉变化生成目标物体和机器人的候选伪区域，无需人工标注。
  • 通过两个互补的辅助目标（注意力分配和对比学习）在微调时显式引导 VLA 聚焦于任务关键区域，从而提升动作预测与任务理解的一致性。

03核心贡献

  • 提出 A³-VLA 框架，自动从示范轨迹的交互过程中推导任务特定视觉引导，消除手动标注需求。
  • 设计两个互补训练目标：注意力权重分配损失（语言到图像、状态到图像）和对比表示对齐损失，显式引导 VLA 的视觉焦点保持在目标物体和机器人区域。
  • 在 VLABench、RoboTwin 2.0 和真实世界厨房操作任务上验证，在多个 VLA 骨干（π0、OpenVLA-OFT、π0.5）上一致取得显著提升，平均成功率提升 6.5%–25.2%。
  • 方法为模型无关框架，推理时无额外计算开销，可无缝适配现有 VLA 模型。

04方法描述

  • 启发式区域提议：利用交互时刻前后图像块的变化差异提取候选目标物体区域（低交互前变化、高交互后变化）和机器人区域（全程高变化），并通过 SAM2 进行时序一致性细化，生成高召回伪区域。
  • 注意力权重分配引导：对语言 token 到图像 patch 的注意力施加目标区域注意力质量下界约束（L_l2i），对状态 token 到图像 patch 施加机器人区域注意力质量下界约束（L_s2i），软性引导聚焦。
  • 对比学习引导：以语言指令表示为锚点，拉近目标区域视觉表示，推远非目标区域表示（L_cl），在表示空间中强化语言-视觉语义对齐。
  • 联合训练：总损失为 L = L_FM + λ1(L_l2i + L_s2i) + λ2 L_cl，其中 L_FM 为流匹配动作生成损失，λ1、λ2 为损失权重。

05数据集与资源

  • 使用的数据集：VLABench（5 个任务套件：Chemistry Tube、Fruit、Poker、Toy、Mahjong，每个 500 条演示）、RoboTwin 2.0（4 个任务：Beat Block Hammer、Click Bell、Move Playingcard Away、Place Burger & Fries，每个 100 条演示）、自建真实世界厨房操作数据集（5 个任务，每个 80 条演示）。
  • 模型骨干：π0、OpenVLA-OFT、π0.5；论文未显式列出参数量，A³-VLA 为模型无关框架。
  • 训练资源：8 块 NVIDIA H200 GPU 服务器。

06评估与结果

  • 评估环境：VLABench（每个任务测试 50 episodes）、RoboTwin 2.0（每个任务测试 100 episodes）、真实世界厨房环境（每个任务评估 20 次）。
  • 主要评估指标：成功率（SR）；真实世界任务额外记录 任务进度（TP）。
  • 关键实验结果：在 VLABench 上，A³-VLA 相比骨干平均成功率提升：π0 从 0.47 到 0.64，OpenVLA-OFT 从 0.16 到 0.40，π0.5 从 0.41 到 0.67；在 RoboTwin 2.0 上同样一致提升，例如 π0 从 0.42 到 0.52；真实世界平均 SR 从 π0 的 0.55 提升到 0.76，平均 TP 从 0.67 提升到 0.87。
  • 消融实验表明各损失组件（L_l2i、L_s2i、L_cl）均有贡献；在纹理和高斯噪声扰动下，A³-VLA 鲁棒性显著优于基线。
