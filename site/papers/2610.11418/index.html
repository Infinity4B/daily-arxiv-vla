Experience-Guided Initiation Search for Learned Skills in Skill Composition

02论文概述

  • 针对冻结的学到的技能（如Vision-Language-Action, VLA策略）在新环境部署时启动配置确定困难的问题展开研究：技能组合场景中上游技能的启动配置不仅影响自身执行，还会传递给下游技能，上游单独成功不代表组合任务成功；通过大量目标环境rollout估计启动配置可靠性成本极高，直接复用历史经验又可能因环境变化失效。
  • 提出EVIS（经验引导与行为验证的启动搜索）框架，核心思路是将历史执行经验作为候选提案的参考，同时通过少量目标环境的行为验证来判断候选是否可靠，在有限目标交互预算下寻找可靠的启动配置。
  • 在单技能和两阶段操作任务上对EVIS进行评估，验证其可降低目标环境交互成本、提升小预算下可靠候选的发现效率。

03核心贡献

  • 将启动配置明确为冻结 learned 技能任务级规划的可执行接口，研究如何在尽可能少的目标环境rollout下，为新环境找到可靠的启动配置。
  • 提出EVIS框架，通过经验引导提案、行为验证、行为引导恢复搜索三个模块解耦历史经验与目标环境决策：历史经验决定优先搜索哪些候选，目标环境的行为证据决定是否信任该候选、是否需要继续搜索。
  • 在RoboCasa365仿真环境、冻结预训练VLA策略上的实验表明，EVIS可减少目标环境交互次数，提升小交互预算下可靠候选的发现效率。

04方法描述

  • EVIS包含三个核心模块：① 经验引导提案：从历史执行数据构建多个评分假设（包括上下文特定的高斯过程分类器、检索加权预测器、全局池化预测器，多阶段任务额外构建局部可行性、条件延续、全序列完成的独立假设），通过百分位排名消除不同假设的量纲差异，交错排序生成候选提案队列，优先评估多假设共同认可的高排名候选。② 行为验证与预算返回：对产生成功的候选进行m-of-n资格验证，达到要求成功数则接受，失败数超过阈值则拒绝，否则继续验证，预算耗尽则放弃返回。③ 行为引导恢复搜索：当历史提案被拒绝或不足时，利用目标侧已积累的观测，通过假设分歧度、几何覆盖扩展、局部成功邻域探索、正则化目标评分修正等方式继续搜索未评估的候选。
  • 创新点在于分离历史经验的“引导搜索顺序”和“决定候选可靠性”两个角色，避免直接将历史预测作为目标环境的决策依据，同时通过有限的目标交互验证适配环境变化。

05数据集与资源

  • 使用的仿真数据集为RoboCasa365，包含不同厨房布局、视觉风格、初始化设置的多样化环境，分为历史环境（提供构建历史假设的经验）和未见目标环境（用于评估）。
  • 使用的策略为冻结的预训练RLDX-1-FT-RC365 Vision-Language-Action (VLA) 策略，策略参数在整个评估过程中保持固定，未提及具体参数量。
  • 未明确说明专项训练所采用的GPU/TPU等计算资源，评估在RoboCasa365仿真环境中进行。

06评估与结果

  • 评估环境与基准：在RoboCasa365的未见目标环境上评估，单技能任务为OpenDrawer，两阶段组合任务为OpenDrawer→DrawerUtensilSort、OpenDrawer→ChooseMeasuringCup；对比基线包括固定消耗全部预算的EVIS-Fixed B20、仅用5次历史查询的History Reuse B5、无视历史经验的Sobol低差异序列基线Scratch-Sobol B20。
  • 主要评估指标：平均查询数（Mean Queries，越低越好）、确认成功率（Confirmed SR，越高越好）、可靠率（Reliable Rate，目标环境中返回的可靠候选占比，越高越好）、错误接受数（False Accepts，越低越好）、可靠精度（Reliable Precision，返回候选中可靠候选的占比，越高越好）、恢复率（Recovery Rate，进入恢复阶段后能找到可靠候选的比例，越高越好）。
  • 关键实验结果：① 单技能任务中，EVIS平均仅需8.125次查询，较固定预算B20降低59.4%的目标交互，确认成功率与B20持平（76.7%），高于历史复用B5的70.8%。② 多阶段任务中小预算优势显著，预算为10时，EVIS在两个两阶段任务的可靠率分别为41.7%、58.3%，远超Scratch-Sobol的8.3%、16.7%，预算提升后优势逐渐缩小。③ 行为验证模块可消除所有错误接受的候选，将两个任务的可靠精度从41.7%、8.3%提升至100%。④ 恢复搜索机制可将历史复用被拒绝后的最终可靠率从8.3%提升至41.7%，优于Sobol回退的33.3%，且平均查询数更低。
