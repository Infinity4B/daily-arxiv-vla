02论文概述

  • 论文提出 XGenAct，一个几何增强的世界动作模型（World Action Model, WAM），将 RGB 观测、机器人动作、度量深度、表面法线和功能角色分割统一表示为 RGB 视频，通过确定性编解码器进入同一潜空间。
  • 现有世界动作模型主要关注时间维度上的 RGB 未来预测，缺乏对三维空间结构的显式建模；已有方法通过专用头或分支引入空间监督，导致架构碎片化且覆盖不全。
  • XGenAct 采用一个视频扩散 Transformer 和一个共享目标，在训练中采样多种“感知+动作”任务模板，无需引入模态专用网络头即可完成跨任务的时空预测与机器人控制。

03核心贡献

  • 几何增强的图像空间：将深度、表面法线、功能角色分割等结构化感知信号编码为 RGB 视频，与 RGB 观测和机器人动作共享统一的视频生成接口。
  • 无需专用头的可扩展任务接口：任务模板（Task Templates）与条件规划（Conditioning Plans）使所有感知与动作任务共享冻结的 VAE、DiT、输出头和流匹配目标，无模态专用头或辅助损失。
  • 跨任务生成提升机器人控制：在 RLBench 留出任务上，结构化几何与语义生成训练将闭环成功率较纯 RGB 训练最高提升 28.75 个百分点，同时保持未来 RGB 生成能力。
  • 外部基线对比显著领先：在五项未见过的 RLBench 任务上，平均成功率达 52%，为最强基线（π₀.₅ 与 VLANeXt，均为 26%）的两倍。

04方法描述

  • 基于 Action Images 公式和 Wan2.2-TI2V-5B 视频扩散骨干；7 自由度机器人动作被投影到多视角并渲染为 RGB 视频，VAE 保持冻结，仅微调扩散 Transformer。
  • 确定性编解码器（无学习参数）将度量深度（幂变换+RGB 立方体路径映射）、表面法线（直接线性映射到 RGB）、功能角色分割（固定颜色编码）转换为视频 VAE 可接受的 3 通道视频。
  • 每个训练样本选择一个感知模态 m，组成模板 Πₘ = [m⁽¹⁾, a⁽¹⁾, m⁽²⁾, a⁽²⁾]（两个相机视角），并用三种条件计划（联合预测、策略预测、逆动力学预测）控制观测与生成位置。
  • 所有模态、模板和条件计划共用同一个流匹配目标函数，仅改变潜序列内容与预测位置，无需额外损失或手动调权。

05数据集与资源

  • 训练数据：RLBench（16 任务，3960 个 episode，512² 分辨率，4 视角）+ ManiSkill3（7 任务，1750 个 episode，重渲染官方演示）。
  • 模型规模：Wan2.2-TI2V-5B（约 5B 参数的视频扩散 Transformer），冻结视频 VAE，仅微调 DiT。
  • 训练资源：未明确列出 GPU 数量与型号；报告优化器配置为有效批次大小 4、学习率 5×10⁻⁷，模型在 4000 步进行评估。

06评估与结果

  • 评估基准：5 项 RLBench 留出任务（close microwave、toilet seat down、reach target、close drawer、close laptop），每任务 20 次试验，闭环滚动评估（receding-horizon 重规划）。
  • 外部基线（8 个）：π₀.₅、Evo-1、VLANeXt（VLA），MolmoAct（深度令牌 VLA），PAD-Depth、UWM（像素空间 WAM），LaWAM、VLA-JEPA（潜空间 WAM）。
  • 主表结果：XGenAct 平均成功率 52%，每任务均超过 10%；三个任务上取得最佳成绩（close drawer 100%、close microwave 60%、close laptop 40%）；PAD-Depth 与 UWM 仅分别达到 12% 与 14%。
  • 通感菜单消融（8 个菜单模型）：任何带感知流的菜单都优于纯 RGB（32.5%），最佳 RGB+N+S 达 61.25%；分割对分离操作物最有帮助（close microwave 95%、meat on grill 70%），法线对薄板旋转任务最有效（toilet seat down 40%）。
  • 未来感知质量（模拟器回放）：直接生成深度（AbsRel 0.28–0.33）优于生成 RGB 后交给冻结专家（0.41–0.43）；分割 mIoU 直接生成（0.42–0.49）约为 RGB→CLIPSeg 路线（0.22–0.24）的两倍；法线两者相当（0.76–0.77 余弦相似度）。
