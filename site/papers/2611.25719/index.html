02论文概述

  • 论文研究世界动作模型（WAM）的对抗鲁棒性；WAM 同时预测未来视频帧和动作，其“想象未来”通常被视为安全信号。
  • 提出 SteerTrace：一种针对 WAM 的目标式通用攻击，同时通过干预度量追踪攻击效应在模型内部的传递路径。
  • 核心问题：能否用一个固定、跨任务共享的对抗扰动将执行动作推向攻击者指定目标，并在模型中找到承载该攻击效应的 token、神经元和残差方向。

03核心贡献

  • 提出首个针对 WAM 的目标式通用扰动，使用单个 \(\ell_\infty\) 有界扰动将执行动作推向攻击者选择的目标动作。
  • 揭示攻击路径：未受限攻击主要通过“想象未来”token 传递；在 preserve 变体下，攻击路径更多转移到当前帧 token。
  • 定位关键神经元：在视频专家的 FFN 层中，仅恢复 0.36% 的神经元即可移除 72–96% 的目标攻击效应。
  • 定位残差子空间：残差位移方向 2–16 只占 11–18% 的能量，但移除这些方向可消除 96–99% 的目标效应。
  • 建立以签名目标效应 T 为核心的干预量化框架，用于衡量不同组件对攻击效应的必要性（necessity）与充分性（sufficiency）。

04方法描述

  • 威胁模型：攻击对象为冻结的 WAM；攻击者拥有白盒访问权限，使用训练数据帧优化一个固定的通用扰动 \(\delta\)，满足 \(\\|\delta\\|_\infty \le 4/255\)，跨所有帧、相机视角和任务共享。
  • 攻击优化：损失放在完整的 flow-matching Euler 采样器输出上，而非单一速度场回归；目标损失将执行动作拉向 \(a^\star\)，可选的未来保持损失 \(\mathcal{L}_{\text{fut}}\) 惩罚被攻击后想象未来与干净预测的偏差。
  • 机制分析：

- Token 组修补：分别对当前帧 token \(\mathcal{C}\) 和未来 token \(\mathcal{F}\) 的 K/V 进行恢复或注入，测量目标效应变化。

- 神经元归因与修补：使用一阶梯度估计（激活变化 × 梯度）对视频专家 FFN 神经元打分，并修补 top-k 神经元。

- 残差子空间消融：对残差位移 \(\Delta\) 进行 PCA，移除或保留特定方向带（如方向 2–16），观察目标效应残余比例。

05数据集与资源

  • 数据集：LIBERO（Spatial、Object、Goal、Long 四个套件，各 10 个任务）和 RoboTwin（50 个任务）。
  • 模型：共攻击 8 个 WAM，涵盖四个家族：FastWAM、FastWAM-Joint、Faster-WAM、LingBot-VA，以及 OpenWAM 的四个变体（mutual、action\_sees\_video、video\_sees\_action、isolated）。
  • 攻击超参数：扰动预算 \(\epsilon = 4/255\)；preserve 变体的未来损失权重在 LIBERO 上为 \(\lambda = 1\)，在 RoboTwin 上为 \(\lambda = 0.1\)。
  • 训练资源：论文未披露具体 GPU/TPU 数量及模型参数量；攻击在冻结模型上仅优化一个图像扰动。

06评估与结果

  • 评估环境：LIBERO 和 RoboTwin；主要指标包括任务成功率（SR）、目标方向位移（TDS）、未来相对偏差（D_fut）和感知距离（LPIPS）。
  • 基线对比：与干净查询、同预算高斯噪声、BadWAM 进行对比；噪声和 BadWAM 几乎不产生目标方向上的动作位移。
  • 攻击有效性：标准攻击在 8 个 WAM 上使任务成功率接近 0，并产生显著的目标方向位移（TDS 较大）。
  • Token 路径分析：在动作专家关注未来 token 的 5 个模型中，恢复未来 token 可移除标准攻击 61–94% 的目标效应；preserve 变体下，在 3 个模型中恢复当前帧 token 可移除 87–99% 的效应，而未来 token 仅移除 9–15%。
  • 神经元分析：在 6 个模型中，恢复视频专家第 10–29 层约 0.36% 的 FFN 神经元即可移除 72–96% 的目标效应；该关键神经元集合随攻击路径变化而改变。
  • 残差方向分析：移除残差位移方向 2–16 可在 7 个模型中消除 96–99% 的目标效应，尽管这些方向仅占约 11–18% 的位移能量。
