02论文概述

  • 论文针对 视觉-语言-动作（VLA）模型 在实时机器人控制中因连续处理视觉观测而导致的高计算成本问题，提出一种无需训练的 尺度自适应 token 剪枝方法。
  • 核心观点：感知信息本身足以指导 token 选择，但前提是感知表征的语义尺度必须与场景演化的语义结构相匹配；固定尺度会导致遗漏决策关键信息。
  • 提出 TauPrune-VLA，通过一个“感知温度” τ 动态调整保留的感知表征尺度，并利用相邻帧间感知语义的时序稳定性实现异步剪枝，从而降低剪枝开销。

03核心贡献

  • 提出 TauPrune-VLA，一种训练无关的 token 剪枝方法，通过单一感知温度 τ 实现尺度自适应的感知 token 选择，加速 VLA 推理。
  • 证明基于感知的 token 剪枝的有效性取决于感知表征是否在每一步决策时以适合场景语义结构的尺度进行解读；解决了以往方法依赖内部注意力、担心感知信息不足的问题。
  • 设计了异步流水线剪枝机制：利用当前帧计算保留索引并应用于下一帧，使 token 选择与推理并行，进一步降低剪枝额外开销。
  • 引入感知-动作温度调制：利用核谱熵和核纯度等感知语义趋势，结合机器人状态变化与动作幅值在线调节温度 τ。
  • 在多个 VLA 模型（OpenVLA-OFT、π₀.₅、CogACT）和仿真基准（LIBERO、SIMPLER）上验证，最高实现 1.86× 推理加速，同时保持接近基线的任务成功率；并在两台真实机器人平台上验证有效性。

04方法描述

  • 问题建模：将 token 剪枝形式化为在预算 K 下选择索引子集 I，使动作预测差异最小化；从感知角度，期望保留子集的 token 分布近似完整集合。
  • 感知语义尺度分析：通过聚类和 PCA 观察发现语义结构在相邻帧间相对稳定，主要变化为簇的位移和缩放；不同决策阶段对感知尺度的需求不同。
  • 流水线异步剪枝：在第 t 步对视觉特征执行感知 token 选择，得到保留索引 I_t，并在第 t+1 步应用到新 token 序列上；默认在第二个 decoder 层后剪枝。
  • 感知 token 选择：使用 chord 距离定义表示残差，并推导局部表示增益 δ_i(j\|S) 和全局表示增益 G(j\|S)；引入温度 τ 作为幂平均指数，得到调整后的全局增益 G_τ(j\|S)，通过贪心选择最高增益 token 直至满足预算 K。
  • 温度在线调制：从视觉特征构建高斯核矩阵并计算核谱熵 H_t 和核纯度 P_t；根据两者的变化方向确定温度更新方向 u_t ∈ {1, -1, 0}；使用近期运动强度 m_{t-1} 调节步长；目标温度 τ̂_t = clip(τ_base + β m_{t-1} u_t)，再通过指数平滑得到 τ_t（α=0.5，τ_base=0.25）。

05数据集与资源

  • 仿真数据集：LIBERO（四个任务套件：Spatial、Object、Goal、Long）和 SIMPLER（Visual Matching 和 Variant Aggregation，含 PickCan、MoveNear、Drawer、DrawerApple 任务）。
  • 真实机器人平台：Aloha 双机械臂平台（执行 PickBanana 和 FoldCloth 任务）和 TIANJI Marvin M6（执行 PickCable 任务）。
  • 模型：OpenVLA-OFT、π₀.₅、CogACT（均为开源 VLA 模型，参数量通常超过 2B）。
  • 训练资源：方法无需训练；所有实验评估在 NVIDIA A40 GPU 上进行。
  • 剪枝设置：默认剪枝比例为 75%，感知 token 选择在第二个 VLM 层执行。

06评估与结果

  • 评估基准：在 LIBERO 和 SIMPLER 仿真环境中测试任务成功率、计算量（TFLOPs）和推理延迟；基线包括 Vanilla、FastV、VLA-Cache、VLA-Pruner、DivPrune、MMTok、VLA-ADP、SAFE-Pruner、SpecPrune-VLA 等。
  • 主要指标：任务成功率（%）、FLOPs（T）、推理延迟（ms）和相对 Vanilla 的加速比。
  • 关键结果：

- 在 OpenVLA-OFT 上，TauPrune-VLA 平均成功率 97.10%（Vanilla 96.85%），FLOPs 从 3.97T 降至 1.56T，延迟从 122.57ms 降至 65.82ms，加速 1.86×。

- 在 π₀.₅ 上，平均成功率 96.70%（Vanilla 97.20%），FLOPs 从 1.99T 降至 1.27T，延迟从 67.04ms 降至 38.87ms，加速 1.72×。

- 在 SIMPLER Visual Matching 上，TauPrune-VLA 平均成功率 75.35%（Vanilla 74.93%），且延迟显著降低。

- 在真实机器人平台上，TauPrune-VLA 能够在保持任务成功率接近基线的同时实现持续执行，验证了实际部署的可行性。
