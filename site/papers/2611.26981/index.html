ViewDreamer: A Robot World Model beyond Fixed Camera Setups

02论文概述

  • 提出 ViewDreamer，一个能够处理可变数量相机（1–4 路）的机器人世界模型，预测多视角一致的未来视频
  • 解决现有视频生成模型固定相机布局或独立生成各视角导致跨视角不一致的问题
  • 核心思路：将单视角生成与跨视角交互解耦，通过共享槽令牌实现跨视角信息交换

03核心贡献

  • ViewDreamer：首个面向可变相机集合的跨视角一致世界模型，解耦单视角生成路径与跨视角交互
  • Cross-View Slot Agreement (CSA)：训练期对齐目标，利用 DINOv2 和 VGGT-Ω 使几何与语义相似区域共享槽；View-Count Curriculum (VCC) 从单视角渐进到多视角训练
  • RoboView-Bench：多视角世界模型评测基准，覆盖 1–4 个相机；ViewDreamer 在该基准上取得最佳保真度并提升跨视角一致性
  • 将 ViewDreamer 作为 世界-动作模型 (WAM) 和 动作条件世界模型 (AC-WM) 的初始化，提升分布外泛化和相机鲁棒性

04方法描述

  • 基于预训练单视角视频生成器 Wan2.2-5B，共享 DiT 块逐视角处理，每块后插入 Cross-View Interaction (CVI) 模块
  • CVI 通过 READ-MIX-WRITE 机制将各视角 token 聚到共享槽（K=4），进行空间-时间注意力后写回，计算量与视角数线性增长
  • CSA 监督最后一个块的 READ 注意力，使同一区域的跨视角补丁共享槽、不同区域不共享；VCC 按二项分布逐步增加训练视角数
  • 训练目标为 flow matching 速度预测 MSE，结合 CSA 损失，λ_CSA=0.1

05数据集与资源

  • 训练数据：AgiBotWorld-Beta、Galaxea、RoboCOIN、RoboMIND、RoVid-X 共 2,990,654 条 5 秒片段，涵盖 14 种机器人形态，最多保留 3 个视角
  • 模型：底座 Wan2.2-5B（约 5B 参数），CVI 增加 86.8M 参数（<2%），槽数 K=4，槽宽 256，4 个注意力头
  • 训练资源：128 块 NVIDIA B200 GPU，全局批大小 1024，训练 32K 步；消融实验 20K 步、批大小 256
  • 采样：40 步 Euler，引导尺度 5，shift 5；输入 81 帧 640×480 @16 FPS，DiT token 网格 21×15×20

06评估与结果

  • 多视角生成：在 RoboView-Bench（500 个留出四相机 episode）上，3 视角和 4 视角下均取得最佳 SSIM、LPIPS、FID、FVD，3 视角 CVC 最佳；4 视角 CVC 稍逊于 Cosmos3-Nano，但 FVD 低 4 倍以上
  • 动作条件生成：在 RoboTwin 2.0 三视角 Clean (IID) 和 Random (OOD) 上，ViewDreamer 的 EWMScore 最高，且从 Clean 到 Random 性能下降最小
  • 策略迁移：基于 FastWAM-Joint 初始化，在 LIBERO-Plus、RoboTwin 2.0、RoboDojo 及真实 Franka 机器人上均优于基线，分布外场景提升最大
  • 消融：CVI、CSA、VCC 每个组件均改善策略成功率和几乎所有生成指标；CVI 优于全跨视角注意力且计算成本更低
