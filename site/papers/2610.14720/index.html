02论文概述

  • 论文研究 World Action Models (WAMs) 中预测未来包含动作诱导变化和环境驱动变化，直接评估整体未来不能完全反映候选动作带来的未来变化。
  • 从因果视角构建 Structural Causal Model (SCM)，揭示候选动作与未来评估之间的后门路径，提出用干预/后门调整来表征动作相关未来变化。
  • 提出 CAG-WAM，通过配对动作条件未来与环境未来的评估差定义 causal action gain (CAG)，并用于训练和推理阶段的机器人操作策略优化与动作修正。

03核心贡献

  • 从因果角度形式化 WAM 动作评估，构建 SCM，描述动作诱导变化与环境驱动变化如何共同影响未来评估，并识别后门路径。
  • 提出 CAG-WAM，包含 Future-Conditioned Action Model (FC-AM) 和 Paired-Future World Model (PF-WM)，用 CAG 表征候选动作相对环境演化的未来变化。
  • 训练阶段将 CAG 作为 GRPO 的优势项，使策略更新反映每个候选动作的未来变化；推理阶段在 CAG 低于阈值时利用预测未来信息进行动作修正。
  • 在 RoboCasa 和 LIBERO 多个基准上验证方法有效性，取得领先或极具竞争力的成功率。

04方法描述

  • FC-AM 采用 flow-matching 与 DiT 骨干，根据当前观测和任务指令生成 K 个候选动作块，并可在推理时接收未来反馈进行二次生成。
  • PF-WM 是动作条件视频世界模型，对每个候选动作预测动作条件未来，并从同一当前观测预测环境未来。
  • 两个未来由同一未来评估器 V 评估，定义 CAG 为 G_t^i = Y_t^i - Y_t^env，正值表示动作条件未来优于环境未来。
  • 因果分析中，SCM 的后门路径为 A_t ← O_t → E_{t+1} → O_{t+1} → Y_t；干预 do(A_t=a) 切断 O_t → A_t，实现后门调整。
  • 训练使用 CAG 作为优势的裁剪 GRPO 目标；推理在 G_t^init < δ 时构造未来反馈 Z_fb = Z_init + γ(Z_init − Z_env)，重新生成修订动作并按 λ 与初始动作融合。

05数据集与资源

  • 使用 RoboCasa 基准，覆盖 24 个任务、7 类操作技能：Pick&Place、Door、Drawer、Knob、Lever、Button、Insertion。
  • 使用 LIBERO 基准，包含四个任务套件：Spatial、Object、Goal、Long。
  • 实现基于公开的机器人策略和世界模型代码库；训练时使用 K=8 个候选动作。
  • 学习率：RoboCasa 为 5×10⁻⁵，LIBERO 为 3×10⁻⁶。
  • 推理超参数：δ=0.05，γ=1.0，λ=0.30；模型参数量与具体训练 GPU/TPU 资源在提供的文本中未明确说明。

06评估与结果

  • 评估指标为任务成功率；对比方法包括 Diffusion Policy、DP3、GR00T N1、FPV、Octo、OpenVLA、UniVLA、UVA、Video Policy、Cosmos Policy-Predict2/2.5、LingBot-VA 等。
  • RoboCasa：CAG-WAM 平均成功率 74.2%，优于 Cosmos Policy-Predict2.5 的 71.5%；分项：Pick&Place 60.8、Door 92.0、Drawer 96.0、Knob 52.0、Lever 84.0、Button 92.0、Insertion 51.0。
  • LIBERO：CAG-WAM 平均成功率 99.8%，Spatial 99.5%、Object 100.0%、Goal 100.0%、Long 99.6%，优于或接近 Cosmos Policy-Predict2.5（平均 98.3%）和 LingBot-VA（平均 98.5%）。
  • 案例研究表明，无未来修正时中间滑动会导致抓取不准确和任务失败；启用未来修正后，策略可在滑动后调整动作并恢复完成任务。
