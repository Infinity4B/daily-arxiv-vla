ThinkWAM: Rethinking Latent Futures for Action Refinement

02论文概述

  • 提出 ThinkWAM，一个潜空间世界-动作模型，通过提案-重思-修正循环在动作执行前建立策略与未来预测之间的双向反馈
  • 解决的核心问题：初始动作块可能存在缺陷，而传统的未来预测不依赖于动作提案，无法反映所提议动作将引起的视觉表征变化，因而对执行前的动作修正帮助有限
  • 设计目标是在全部预测保持在潜空间的前提下，让“预测的未来”与“动作提案”相互修正，从而提升机器人操作的泛化性与成功率

03核心贡献

  • 提出 proposal–rethink–refine 架构：策略先提出完整动作块，用该提案通过学习的潜空间残差修正多视距未来潜表征，再将修正后的潜表征注入同一 ActionDiT 动作头的第二遍推理，生成最终可执行动作块
  • 提出受预测编码启发的具身引导观测-动作记忆（affordance-guided observation-action memory）与近精细、远粗糙的多视距预测方案
  • 在 LIBERO-Plus（无需 OOD 微调）、RoboTwin 2.0 随机设定、RoboCasa24 及真实世界操作任务上展现强泛化能力，同时保持较低推理延迟
  • 诊断分析表明提案条件化的修正确实同时改变了预测的未来表征与动作轨迹，验证了修正后的未来表征对最终动作的改进作用

04方法描述

  • 基于冻结的 V-JEPA 2.1 ViT-L 视觉编码器、Qwen2.5-0.5B 语言骨干与 ActionDiT（流匹配扩散 Transformer）动作头构建
  • Proposal：语言-动作特征与具身引导记忆构成第一遍动作上下文，ActionDiT 生成完整初始动作块 A⁽⁰⁾
  • Rethink：紧凑的潜空间残差模型读取提案与当前视觉 token，对基础未来潜表征进行残差修正，用专家未来特征与基础预测之差监督
  • Refine：修正后的潜表征经归一化与视距特定映射后，扩展第一遍上下文，复用同一 ActionDiT 权重进行第二遍推理，生成精修动作块 A⁽¹⁾
  • 具身引导记忆：可学习记忆槽交叉注意力聚合视觉与动作历史，affordance 解码器以接触热图（BCE+Dice 损失）监督，按确定性加权摘要写入记忆残差
  • 近精细、远粗糙预测：时间 JEPA 预测器在视距 H={7,15,31} 上分别分配 (288,144,72) 个查询 token，近视野保留细节、远视野降低预测负担
  • 端到端训练，联合优化两遍流匹配损失、JEPA 余弦距离损失、残差 SmoothL1 损失与 affordance 损失

05数据集与资源

  • 仿真基准：LIBERO、LIBERO-Plus、RoboTwin 2.0（Clean/Random）、RoboCasa24
  • 真实世界评估：Galaxea A1Z 机器人平台，涵盖三个分布外（OOD）条件
  • 模型组件：冻结 V-JEPA 2.1 ViT-L 编码器、Qwen2.5-0.5B 语言骨干、ActionDiT 动作头；整体模型规模约 1.5B 参数
  • 模型权重与代码开源于 GitHub 和 Hugging Face

06评估与结果

  • 评估环境：LIBERO、LIBERO-Plus、RoboTwin 2.0（Clean/Random）、RoboCasa24 仿真基准与 Galaxea A1Z 真机三个 OOD 条件
  • 主要评估指标：任务成功率（%）与每动作块两遍推理平均延迟
  • 关键结果：LIBERO 98.70%、LIBERO-Plus 84.76%（无 OOD 微调）、RoboTwin 2.0 Clean/Random 85.75%/65.85%、RoboCasa24 65.17%，优于或接近 π0.5、FastWAM、ImageWAM、ForeWAM、JEPA-WAM、V-JEPA Policy 等基线
  • 真实世界：三个 OOD 条件平均成功率 64.4%；推理延迟为 LIBERO 153.48 ms、RoboTwin 164.61 ms、Galaxea A1Z 101.2 ms
  • 消融实验表明重思机制与具身引导提供互补增益；诊断显示提案条件化的修正同时改变预测未来与动作轨迹，证明修正后的未来表征确实改善了最终动作
