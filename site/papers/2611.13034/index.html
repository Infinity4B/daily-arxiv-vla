01研究单位

  • MMLab @ SIAT（作者：Delin Zhao, Zhengrong Yue, Junlin He, Yali Wang）

02论文概述

  • 提出 RoboACE（Robot Adversarial Co-Evolution）框架，通过对抗性协同进化实现机器人自我改进
  • 解决固定实践源导致机器人难以发现新弱点的问题，使练习选择程序和执行软件同时可修订
  • 在 LIBERO 家族基准上验证，最终部署显著优于初始部署和现有系统

03核心贡献

  • 提出 RoboACE 框架，联合演化课程 harness（选择练习）和执行 harness（组织执行），围绕冻结基础模型
  • 设计交替更新协议：课程侧固定执行时提出挑战，执行侧固定课程时测试修订，确保公平比较
  • 引入 Strategic Advisor 进行长程战略审查，识别重复失败和停滞模式，提出调查方向
  • 在四个 LIBERO-family 面板（LIBERO, LIBERO-Plus, LIBERO-PRO, LIBERO-X）上实现最先进成功率
  • 通过案例研究展示课程修订改变证据使用、执行修订澄清技能基础、战略审查连接跨局部修订的失败

04方法描述

  • 使用两个 harness：课程 harness（选择练习条件）和执行 harness（组织规划、代码技能和预训练控制）
  • 交替更新：课程阶段使用先前能力证据提出挑战，执行阶段在固定任务快照上评估和修订
  • 外部优化器基于证据安装修订，独立代理在运行时做决策；所有基础模型权重保持冻结
  • 使用 Experience Consolidator 将执行结果转化为能力概况，反馈给课程侧
  • 引入 Strategic Advisor 定期审查长期历史，提供战略指导但不直接安装更改

05数据集与资源

  • 开发使用 LIBERO 底部条件，评估使用 LIBERO、LIBERO-Plus、LIBERO-PRO、LIBERO-X 四个面板（每个 200 条件）
  • 使用 GPT-6.1 (Terra) 作为高层 LLM，SAM 3 用于分割，π0.5 作为 VLA 控制器
  • 无 LLM 或 VLA 权重训练/微调；每个 episode 预算 8000 环境控制步骤（20 Hz，6 分 40 秒仿真时间）

06评估与结果

  • 评估在四个 LIBERO-family 面板上，使用环境原生任务谓词，成功率（%）为指标
  • 最终部署成功率：LIBERO 99.0%，LIBERO-Plus 94.5%，LIBERO-PRO 74.0%，LIBERO-X 30.5%
  • 相比初始部署提升：LIBERO +35.5 个百分点，LIBERO-Plus +30.0 个百分点，LIBERO-PRO +15.0 个百分点，LIBERO-X +11.0 个百分点
  • 相比直接 π0.5 控制：LIBERO-PRO +13.5 个百分点，LIBERO-X +19.0 个百分点
  • 相比最强代理基线：LIBERO +1.5 个百分点，LIBERO-Plus +4.5 个百分点，LIBERO-PRO +13.5 个百分点，LIBERO-X +18.0 个百分点
