ACRO: Actor-Critic Rollout Orchestration

02论文概述

  • 论文提出 ACRO，一种 Actor–Critic rollout 编排层，用于在固定 VLA 策略执行过程中决定何时继续、何时干预，以提升任务成功率。
  • 解决的问题：VLA 单次执行结果具有随机性，可能未充分发挥策略潜力；现有方法（动作选择、外部编排器）未直接确定何时中断执行以及中断后恢复到何处。
  • 研究目标：在不重新训练 VLA 的前提下，通过评估执行前景并进行物理干预（回退到有利状态再让策略继续），实现更可靠的任务完成。

03核心贡献

  • 将 rollout 编排形式化为比较“继续当前动作”与“物理干预后从新状态恢复策略”的任务成功概率优势。
  • 提出 ACRO，使用共享的 Q/V Critic 决定何时干预，并通过 Trajectory Retraction 选择并到达有希望的继续点。
  • 在 SimplerEnv Bridge、RoboCasa 和真实机器人上验证：在相同物理执行预算（包含回退运动）下，固定 VLA 策略的任务成功率显著提升。
  • 展示 Critic 训练成本低（少量 rollout 即可），且随着执行预算增长，ACRO 可通过 renewed attempts 获得更多成功。

04方法描述

  • Actor–Critic 编排：Critic 从策略 rollout 中学习 Q 和 V，估计任务完成概率；Q 用于检测当前执行可能失败，V 用于选择重新进入目标。
  • 生存分析建模：将 Q/V 参数化为分段常数风险率，使用删失时间-成功损失（censored time-to-success loss）训练，同时纳入成功和未完成执行。
  • 干预触发：基于最近 Q 值的逻辑回归分类器预测执行是否会失败，当分数超过阈值时激活 Actor。
  • Value-Guided Repositioning：在当前执行轨迹中选取 V 最高的已记录状态作为目标，通过 Trajectory Retraction 将路径 shortcut 并保持在已访问位置附近（偏差 ≤ 2cm），移动机器人后交由 VLA 重新观测并继续。
  • 测试时循环：在剩余预算内可重复干预，所有物理步骤（包括回退）计入执行预算。

05数据集与资源

  • 使用的模拟环境与策略：GR00T N1.7 在 SimplerEnv Bridge，π0.5 在 RoboCasa，以及真实机器人上的 π0.5。
  • Critic 训练数据：SimplerEnv 使用 1,230 条无干预 rollout（780/150/300 划分），RoboCasa 使用 1,200 条（720/180/300 划分）。
  • 模型规模与参数量：论文未明确给出 VLA 或 Critic 的参数量；Critic 为轻量 GRU（SimplerEnv 宽度 64，RoboCasa 宽度 128）。
  • 训练资源：论文未明确说明 GPU/TPU 型号与数量，仅提供训练超参数（AdamW，学习率 10^-3，batch size 32 等）。

06评估与结果

  • 评估环境：SimplerEnv Bridge（300 步预算，240 trials）、RoboCasa（各任务注册限制，600 trials）、真实机器人（60 trials，pick-and-place、cube stacking、button pressing）。
  • 主要指标：任务成功率 (%)，物理执行预算内完成情况，所有回退运动计入预算。
  • 关键结果：

- SimplerEnv Bridge：成功率从 49.6% 提升至 60.0%（+10.4 个百分点）。

- RoboCasa：成功率从 60.7% 提升至 68.0%（+7.3 个百分点）。

- 真实机器人：成功率从 43.3% 提升至 65.0%（+21.7 个百分点）。

  • 对比基线：Base VLA、RoboMonkey（动作选择）、CycleVLA（外部 VLM 恢复），ACRO 在总体成功率上均优于这些基线。
  • 额外发现：Critic 仅需少量 rollout（8 seeds 每任务，96 条）即可达到 76.7% 成功率；随着执行预算增加，ACRO 成功任务数持续增长（test-time scaling）。
