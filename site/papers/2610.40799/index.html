Card 02 论文概述

论文概述

  • 提出 CaPtain，一个开放的 Code-as-Policy (CaP) 机器人智能体后训练流水线，将小型开源视觉语言模型（VLM）转化为独立的 CaP 智能体
  • 解决现有 CaP 系统依赖闭源前沿模型或冻结的视觉-语言-动作模型（VLA）的问题，这些方案无法对操纵决策本身进行端到端训练
  • 在 CaPtain-Harness 执行环境中，先通过监督微调（SFT）对齐模型与接口，再利用模拟器中的多轮强化学习（RL）优化闭环操纵与恢复行为
Card 03 核心贡献

核心贡献

  • 提出 CaPtain 流水线，将小型开源 VLM（Qwen3.5-4B）通过 SFT+RL 训练成独立 CaP 智能体，并发布 SFT 数据、训练代码和模型权重
  • 设计 CaPtain-Harness，一个可移植的执行环境，仅暴露 22 个低层感知、几何测量和受保护运动原语，并返回结构化文本回执
  • 提出 模拟器批评家（simulator critic），读取策略不可见的特权物理状态，将状态转移转化为密集的逐请求信用分配，解决多轮 VLM 智能体的信用分配难题
  • 进行全面的评估，证明 RL 增益在三个扰动测试套件上持续存在，4B 模型以极低成本超越多个前沿模型智能体，并实现跨基准、跨具身和真机零样本迁移
Card 04 方法描述

方法描述

  • CaPtain-Harness：ReAct 风格循环，策略在每步请求中生成 Python 代码调用低层 API，获得文本回执和图像；包含持久 Python 会话、上下文管理、压缩机制和自验证成功判定
  • SFT 阶段：使用 GPT-6 Astra 在 harness 内生成合成轨迹，采用与部署时完全相同的多轮格式进行监督微调；监督智能体生成的推理和代码 token，并以 0.2 概率遮盖历史坐标强制模型依赖当前图像
  • RL 阶段：使用 模拟器批评家，从特权物理状态（36 个特征）预测成功概率，用集成 MLP 在线协同训练；逐请求信用定义为状态价值变化量，结合 GAE 和分组相对优势；采用 SAO 风格单遍更新、双面 token 掩码和 KL 正则
  • 训练时每个起始状态随机采样 4 次 rollout，每 4 轮累积梯度后更新策略；测试时移除批评家，策略仅基于相机图像和文本回执动作
Card 05 数据集与资源

数据集与资源

  • 训练仅使用 LIBERO 的 40 个原始任务，评估于 LIBERO、LIBERO-PRO、LIBERO-Plus、LIBERO-MAX 及零样本迁移基准 RoboTwin 2.0、RoboDojo、SimplerEnv、CaP-Bench
  • 基础模型为 Qwen3.5-4B（40 亿参数，指令微调版本），微调所有语言模型权重，冻结视觉塔
  • SFT 数据由 GPT-6 Astra 在 harness 内生成
  • 训练基础设施：异步 rollout 服务器，梯度累积 1024 个 episode 后进行一次优化器更新；具体 GPU/TPU 数量及算力开销见论文附录
Card 06 评估与结果

评估与结果

  • 评估环境为 CaPtain-Harness，温度 1，最多 60 个请求、150 个物理动作、1080 秒；报告 host success（基准谓词）和 strict success（额外要求 finish()）
  • CaPtain-4B 在 held-out LIBERO 上从零样本 0% 提升至 SFT 后 55.4%，RL 后 73.8%；strict success 从 52.1% 提升至 67.5%
  • 在 LIBERO-PRO（3 个短程套件）达到 78.5%，超越前沿模型智能体 K1（77.2%）、WAA（75.6%）、ASPIRE（71.7%）
  • RL 增益在扰动套件上持续：LIBERO-PRO（3 套件）+19.0、LIBERO-Plus +17.6、LIBERO-MAX Dynamic +21.2、Base +18.8；所有七个 LIBERO-Plus 扰动维度均显著改善
  • 零样本迁移：SimplerEnv WidowX 83.3%，CaP-Bench 75.0（超越前沿模型及同基准 RL 训练的 7B 编码器），真机任务成功；RoboTwin 2.0 22.6%，RoboDojo 0.8%（受限于双臂协调和陌生臂运动学）
