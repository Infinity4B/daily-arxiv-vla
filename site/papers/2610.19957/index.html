Card 02 论文概述

论文概述

  • 世界动作模型（WAMs）联合预测未来视觉状态与机器人动作，但处理密集的未来帧 token 带来大量推理延迟，成为实际部署的关键瓶颈。
  • 论文提出 CF-Prune，一个免训练（training-free）框架，可在预训练 WAM 中剪除未来帧 token，加速推理而无需重新训练。
  • 核心洞察：未来视觉预测在 WAM 中主要作为动作生成的中间参考，无需保留高保真视频合成所需的全部视觉细节，因此大量未来帧 token 是冗余的。
Card 03 核心贡献

核心贡献

  • 重新审视 WAM 中未来帧的辅助作用，从动作预测视角形式化 token 剪枝问题，揭示传统视频生成中未被考虑的冗余性。
  • 提出 CF-Prune，无需额外训练，利用未来帧 token 相对于动作与指令 token 的信息集中度，在噪声初始潜变量阶段识别冗余 token。
  • 设计基于熵的阶段识别机制，通过跨视角（腕部 vs 第三人称）与时间维度（早期 vs 后期动作）的注意力熵对比，识别精度敏感阶段并选择性放宽剪枝。
  • 在 RoboLab、RoboCasa 仿真基准及真实世界操作任务上验证，在保持甚至提升操作性能的同时实现一致的推理加速。
Card 04 方法描述

方法描述

  • 指令基础的空间先验：利用观测 token 到指令 token 的注意力，在初始去噪步识别与任务相关的空间区域（因动作和未来帧 token 此时噪声过大，观测 token 无扩散噪声，更适合作为空间先验）。
  • 基于动作的视觉相关性：计算动作 token 对视觉区域的注意力权重；腕部相机视角的未来帧使用逐帧 action-to-future 注意力，第三人称视角因背景固定则统一使用 action-to-observation 注意力。
  • 层选择：通过归一化注意力熵选择指令评分层（ℓ_inst=11）与动作评分层（ℓ_act=23），仅在首次策略查询时选择并固定，避免重复计算；熵在层间和任务间保持一致。
  • 空间平滑：将聚合注意力分数重塑为 2D 空间图，应用 5×5 高斯模糊，使相关性扩散到相邻 patch，鼓励空间连续的 token 选择。
  • 动作-指令互补选择：给定剪枝率 α，先按动作相关性保留 top (1-α)/2 的 token，再在剩余 token 中按指令相关性保留 (1-α)/2，融合两种互补信号。
  • 基于熵的阶段识别：定义熵对比分数 C = C_view + C_temp（视角与时间熵差），当 C > τ 时判定为精度阶段，禁用剪枝；否则为粗粒度阶段正常剪枝。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboLab（64 个 Simple、39 个 Moderate、17 个 Complex 操作任务，每任务 10 次 rollout）、RoboCasa（每类选一个代表任务，各 100 次 rollout）。
  • 真实世界任务：Franka Emika Panda 平台上的三个桌面操作任务（按下紧急按钮、方块拾取放置、方块堆叠），每任务 25 次 rollout。
  • 基础模型：Cosmos3（RoboLab 使用 Cosmos3-Nano-Policy-DROID，基于 DROID 数据集预训练，无需额外训练；RoboCasa 微调 Cosmos3-Nano 16,000 步，batch size 1,024；真实世界使用 LoRA 微调）。
  • 训练/推理资源：所有延迟测量在 NVIDIA RTX A6000 GPU 上完成；真实世界每任务采集 60 条成功演示。
Card 06 评估与结果

评估与结果

  • 评估环境：RoboLab、RoboCasa 仿真基准及真实世界 Franka 机械臂任务。
  • 对比方法：Dense 基线、SpecPrune-VLA（适配 WAM，Obs-only 70% 与 Obs+future 25% 两种变体）、SP-VLA（同上两种变体）、Sparse VideoGen。
  • 主要指标：成功率（Success Rate）、粗粒度阶段加速、平均推理加速、FLOPs 减少。
  • 关键结果：

- 35% 剪枝：在三个平台上实现 1.19–1.27× 平均加速，同时成功率提升（RoboLab +1.3 个百分点，RoboCasa +4.0 个百分点，真实世界 +5.4 个百分点至 90.7%）。

- 50% 剪枝：在两个仿真基准上实现 1.29–1.33× 平均加速，总体成功率与 Dense 基线差距在 1.0 个百分点以内（RoboLab 35.7% vs 36.5%，RoboCasa 64.0% vs 65.0%）。

- 消融实验：动作-指令互补选择（35.3%）优于仅指令（34.0%）与仅动作（30.8%），且动作优先优于指令优先（34.3%）；阶段识别将成功率从 35.3% 提升至 37.8%，仅 31.4% 的调用被判定为精度阶段；高斯平滑将成功率从 36.0% 提升至 37.8%。

- 对比结果：仅观测 token 剪枝加速有限；扩展到未来帧会带来更大性能下降；Sparse VideoGen 因 profiling 开销导致速度甚至慢于 Dense 基线（0.97×）。
