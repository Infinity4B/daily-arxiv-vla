PRISM: Primitive Routing via In-context Skill Mixing for Retentive VLA Adaptation

02论文概述

  • 论文提出 PRISM，面向视觉-语言-动作（VLA）模型在下游机器人操作中的 技能保留 和 长时程组合。
  • 核心问题：标准微调将所有任务吸收进同一共享参数更新，既无法定位可复用技能的参数级位置，也无法在长轨迹中按阶段调用对应技能，导致灾难性遗忘和组合任务必须端到端重新训练。
  • 观察到技能结构是潜在存在的：每个技能的 LoRA 更新占据可区分的低维子空间，组合任务 LoRA 约 56% 的 Frobenius 能量落在这些技能子空间内，而随机旋转对照约 0%。

03核心贡献

  • 结构性发现：每技能低秩更新张量张成一个接近 N 维、语义聚类的可复现子空间；组合任务 LoRA 与技能子空间高度对齐（56% vs 随机旋转 ≈0%）。
  • 提出 PRISM 框架：将可复用技能参数化为 primitive bank 中的独立低秩 action-expert 适配器，并配有技能特定残差、逐 chunk 的 VLM 条件路由器 和确定性动作派生标签器。
  • 训练策略：组合训练阶段冻结所有 primitive，仅更新视觉编码器、语言 LoRA、技能残差、路由器、共享动作投影和时间 MLP，从构造上保护已学技能。
  • 实验验证：在 RoboCasa365 上实现 56.43% 原子技能成功率和 20.00% 组合任务成功率，显著优于标准 π0.5-LoRA 两阶段微调（17.86% / 17.50%）；并在 AgileX PIPER 真实机器人上验证。

04方法描述

  • Primitive Bank：每个原子技能有其自己的 rank-32 LoRA action-expert 适配器，技能间参数不重叠，Phase 1 后冻结。
  • 技能残差：组合训练中为每个技能添加 rank-10 的可训练残差，C_i 随机初始化、D_i 零初始化，提供额外的组合适应容量。
  • 前缀条件路由器：在每个 action chunk 边界读取 VLM 前缀，经 LayerNorm + 两层 MLP + softmax 输出技能混合权重，用于跟踪任务进展。
  • 确定性动作派生标签器：利用任务身份和夹爪事件（开/关）生成逐帧技能标签，为路由器提供交叉熵监督，无需人工逐轨迹标注。
  • 激活空间组合：路由器混合注意力投影和完整技能 FFN 输出，避免参数空间混合 LoRA 因子产生的跨技能乘积。
  • 两阶段优化：Phase 1 使用 one-hot routing 和 flow-matching 目标学习原子 primitive；Phase 2 冻结 primitive，训练残差、路由器、视觉编码器、语言 LoRA 等，目标为 flow-matching 损失 + 0.05×路由交叉熵。

05数据集与资源

  • RoboCasa365 原子数据集：3016 条人类演示，涵盖 28 个任务：Pick & Place（18 任务，1939 演示）、Turn Lever（3 任务，322 演示）、Close（7 任务，755 演示）。
  • 组合任务：415 条演示，包括 LoadDishwasher、SnackSorting、ThawInSink、WashLettuce 四个跨技能组合任务。
  • Phase 2 训练集：组合演示 + 每原子任务 20 个 replay episodes（共 560 episodes），总计 975 episodes / 454,758 frames。
  • 模型主干：π0.5 VLA（视觉编码器 SigLIP + 语言模型 Gemma + action expert）；每 primitive rank 32，每残差 rank 10，动作 chunk 长度 H=10，执行 5 步后重规划。
  • 训练资源：论文未明确列出 GPU/TPU 类型及数量。

06评估与结果

  • 评估环境：RoboCasa365 仿真；原子 SR 为 28 个原子任务的宏平均（每任务 20 次试验），组合 SR 为 4 个组合任务的宏平均（每任务 100 次试验）。
  • 主要结果：PRISM 原子 56.43%、组合 20.00%；π0.5-LoRA 两阶段微调原子 17.86%、组合 17.50%；π0.5-LoRA + replay 原子 49.82%、组合 10.25%。
  • 原子保留：标准两阶段 LoRA 使原子成功率从 48.04% 降至 17.86%（-30.18 点）；PRISM 从 Phase 1 的 50.71% 提升至 56.43%（+5.72 点），且 primitive 参数保持不变。
  • 消融实验：确定性运动学标签器（20.00）优于 Qwen2.5-VL（11.25）和 MLP（13.75）；VLM 前缀输入（20.00）优于仅视觉（10.25）和仅状态（7.50）；激活空间软混合（20.00）优于 one-hot（10.50）、参数空间软混合（15.50）和动作空间软混合（13.50）。
  • 真实机器人：在 AgileX PIPER 上验证了两个原子技能和一个组合技能，使用每任务 20 次演示和 20 次 rollout，论文展示了成功的组合任务 rollout。
