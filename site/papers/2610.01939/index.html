02论文概述

  • 论文提出 PyRUA-Lean（Python for Lean Robot-Use Agents），一种交互式代码执行框架，用于 VLM 机器人智能体，通过反馈驱动的基元组合（feedback-driven primitive composition）与选择性观察（selective observation）减少推理时的 token 开销。
  • 核心问题：VLM 智能体在通过视觉反馈和动作基元控制机器人时，反复的模型调用和冗余观察会产生大量 token 消耗，论文旨在探索如何让 VLM 智能体组合机器人基元，在保证任务完成率的同时降低 token 消耗。
  • 论文在 700 个模拟任务实例上，将 PyRUA-Lean 与使用相同 GPT-6 Astra 规划器和底层机器人基元的工具调用（tool-calling）基线进行对比，验证了"更少 token、更好动作"的核心假设。

03核心贡献

  • 提出交互式机器人基元组合接口：PyRUA-Lean 基于 RPent 的机器人栈构建，支持反馈驱动基元组合、持久程序状态（persistent program state）和选择性观察传递。
  • 三个机器人基准上的全面评估：在 700 个模拟实例上，PyRUA-Lean 相对工具调用基线将整体成功率提升约 14%（63.1% → 71.7%）；在两者均解决的实例上，LLM 调用减少 49%，输入 token 减少 65%。
  • 效率增益与局限性的分析：通过轨迹和消融实验识别出 LLM 调用次数减少是 token 节省的主要来源；该收益在无 VLA 策略或操作指南时依然存在，但在 VLA 主导的任务上有所缩减；同时展示了几何计算与脚本化恢复等能力。

04方法描述

  • 执行模型：机器人以 Python 对象 robo 暴露，其方法调用基元并返回结构化结果（如物体位置、运动结果）；VLM 通过 python(code) 工具与机器人交互，每个代码单元（cell）执行后返回反馈供 LLM 重规划。
  • 反馈驱动组合：单个代码单元可组合多个基元、执行条件分支和局部重试（如接近物体、仅在成功时抓取、失败后重试），在单元内部完成中间协调，无需额外 LLM 调用；还可进行任务相关几何计算（如从世界坐标图推算碗的底座高度）和定义辅助函数。
  • 选择性观察与上下文管理：基元结果保留在运行时而不逐条加入对话；只有代码中显式输出的内容和通过 robo.show 请求的相机图像才返回给 VLM；持久命名空间跨单元保留中间数据，控制进入上下文的新信息量。
  • 创新点：将中间执行步骤"下沉"到代码运行时，同时保留 LLM 级重规划能力；与工具调用基线相比，PyRUA-Lean 在依赖前序结果的操作上无需额外 VLM 往返。

05数据集与资源

  • LIBERO-PRO：4 个扰动套件共 40 个任务，使用 π0.5 VLA 策略
  • RoboTwin 2.0：50 个双臂任务，使用 LingBot-VLA 策略
  • RoboCasa365 Target50：50 个任务（含原子与复合任务），使用 RLDX-1 策略
  • 每个任务 5 个环境种子，每个智能体各跑一次，共 700 个配对任务实例、1,400 个 episode
  • 分割模型：SAM 3；规划器：GPT-6 Astra（高推理强度）；运行环境：Codex CLI（对话接近 272K tokens 时自动压缩）
  • 另设 RoboDojo 试点：3 个任务，PyRUA-Lean 达 26.7% 成功率，工具调用仅 3.4%

06评估与结果

  • 评估设置：LLM 调用预算为每 episode 40 次（RoboCasa365 复合任务为 100 次），时间为 2 小时；成功率按各基准自身成功判据在全部实例上统计。
  • 主要结果（表 2）：整体成功率 63.1% → 71.7%（+8.6 个百分点，约 14% 相对提升）；LIBERO-PRO 83.0% → 94.0%，RoboTwin 2.0 60.0% → 69.2%，RC365 原子任务 78.9% → 86.7%，复合任务 34.4% → 39.4%。
  • 效率指标（共同解决实例）：LLM 调用从 17.0 降至 8.7（减少 49%）；输入 token 从 788k 降至 276k（减少 65%）；每 episode 估计费用从 $1.63 降至 $0.74（部分受缓存折扣影响）。
  • Token 节省分解：LIBERO-PRO 上 4.48× 的 token 比率由 2.55× 更少调用和 1.76× 更少每调用 token 组成；主要来自 LLM 调用频率降低，而非每轮 prompt 变小。
  • 消融实验（表 3）：移除 VLA 策略或操作指南后，PyRUA-Lean 在相同任务实例上仍保持更高成功率和更低输入 token；RoboTwin 2.0 无 VLA 时成功率 68.8% vs 工具调用 42.8%；单一"按需返回图像"修改无法复现收益（LIBERO-PRO 上成功率反而从 83.0% 降至 68.5%）。
