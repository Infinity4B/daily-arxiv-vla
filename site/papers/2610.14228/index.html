论文概述

  • 提出潜在世界-动作模型（Latent World-Action Model），将 GUI 世界建模的预测目标从"全屏像素重建"转向"潜在空间中的动作诱导未来信息"，服务于动作选择。

Card 03 核心贡献

核心贡献

  • 重新审视 GUI 世界建模，将预测目标从全屏重建改为潜在空间中的动作诱导未来信息，直接用于动作选择。
  • 提出潜在 GUI 世界-动作模型：一个 LoRA 微调的 LMM 共享表征，同时支撑动作头（action head）做候选动作打分和转移头（transition head）做动作条件未来预测。
  • 提出动作感知对比学习目标（action-aware contrastive objective），以当前状态与记忆库中其他转移的未来状态作为负样本，显式缓解 identity shortcut，促使表征编码动作特有的变化。
  • 首次将潜在未来预测引入 GUI 动作选择，在离线/在线、分布内/分布外设置中全面超越像素空间世界模型与基座智能体。
  • 相比像素空间世界模型，成功率相对提升最高 31.9%（离线） 与 40.6%（在线），推理延迟最高降低 98.9%。
Card 04 方法描述

方法描述

  • 使用 LoRA 适配的 LMM（Qwen3-VL-8B-Instruct） 作为共享潜在世界模型，将当前截图 $s_t$、任务目标 $g$、交互历史 $\mathcal{H}_t$ 与候选动作集合 $\mathcal{A}_t$（随机打乱顺序放入同一 prompt）编码为共享隐表征 $h_t$。
  • 动作头：轻量线性层将每个候选动作的隐表征 $h_t^k$ 映射为标量分数，经 softmax 得到候选分布 $p_t$，用交叉熵对齐 ground-truth one-hot 标签（$\mathcal{L}_{\mathrm{Action}}$）。
  • 转移头：轻量网络将同一 $h_t$ 映射为下一状态潜在表征 $\hat{z}_{t+1}$，目标由目标编码器 $\bar{\phi}$ 编码真实下一截图 $s_{t+1}$ 得到的 $z_{t+1}$ 提供监督。
  • 动作感知对比损失（$\mathcal{L}_{\mathrm{Transition}}$）：对所有表征做 $\ell_2$ 归一化，以 $\hat{z}_{t+1}^k$ 为锚点，$z_{t+1}$ 为正样本，负样本集 $\mathcal{N}=\{\tilde{z}_t\}\cup\widetilde{\mathcal{B}}$ 包含当前状态表征与 FIFO 记忆库中的其他转移未来；温度 $\tau$ 控制分布锐度。
  • 联合优化：$\mathcal{L}=\mathcal{L}_{\mathrm{Action}}+\lambda\,\mathcal{L}_{\mathrm{Transition}}$，使未来状态监督直接塑造动作打分所用的共享表征。
  • 推理阶段：丢弃转移头，共享骨干与动作头单次前向完成候选动作评分，绕过传统"Render-and-Re-Perceive"两阶段流程。
Card 05 数据集与资源

数据集与资源

  • 离线数据集：AndroidControl（大规模 Android 交互轨迹）、AITZ（带详细动作标注的移动交互轨迹）。
  • 分布外（OOD）数据集：GUI-Odyssey（跨应用、长时程 GUI 导航基准）。
  • 在线基准：AndroidWorld（真实应用中执行动作并按任务完成度评估的交互式基准）。
  • 智能体骨干：GPT-5.6、Gemini 3.6 Flash、GUI-Owl-7B、Qwen3-VL-8B、Qwen3-VL-32B；所有基座智能体遵循 M3A 设置（输入截图 + 无障碍树）。
  • 世界模型基线：Code2World（预测可渲染代码/HTML）、Diffusion2Image（扩散模型生成未来截图）。
  • 训练配置：LoRA rank $r{=}16$、scaling $\alpha{=}32$、dropout $0.05$（作用于所有 attention 与 MLP 投影）；AdamW 优化器，学习率 $4\times10^{-5}$，有效 batch size 8，训练 3 个 epoch；$\lambda{=}1.0$，$\tau{=}0.07$。
  • 训练资源：单张 NVIDIA A6000 GPU，训练时长约 8 小时。
Card 06 评估与结果

评估与结果

  • 离线指标（步级）：Type（动作类型是否正确）、Grounding（点击坐标是否落在标注点 14% 屏宽半径内）、SR（类型与参数均正确）；另报告 Tokens/Task 与 Run Time。
  • 在线指标（任务级）：AndroidWorld 上的 Easy / Medium / Hard / Overall SR，以及 Tokens/Task、Mean Steps、Run Time。
  • 离线结果：所有 backbone 上动作类型预测一致提升（AndroidControl +0.9~+4.3 分，AITZ +0.3~+4.9 分）；八个 backbone–数据集设置中七个步级 SR 提升，最高 +4.8 分；而像素空间基线在每个离线设置中都使 SR 下降，最多下降 8.6 分。
  • 在线结果：五个 backbone 上 Overall SR 均为最高，相对基座智能体提升 +4.5~+12.5 分；Hard 任务提升 +5.6~+11.1 分；Code2World 需约基座 2.1~4.1× 运行时间，Diffusion2Image 需约 4.5~18.2×。
  • OOD 泛化：在 GUI-Odyssey 上，潜在方法在 GUI-Owl-7B 与 Qwen3-VL-8B 上均取得最高 SR，而两个像素空间世界模型均低于基座。
  • 模块消融（AndroidWorld）：加入动作头 SR 由 27.68 → 36.36；加入点式余弦回归转移头升至 38.18（+1.82）；再换为动作感知对比目标升至 40.18（+2.00），相对基座总提升 +12.50 分。
  • 效率与定性分析：相比基线显著降低推理延迟（最高 98.9%）；t-SNE 可视化显示（在按当前状态聚类去除混淆后）本方法形成最清晰的动作特定未来表征结构；identity shortcut 严重程度随 GUI 转移幅度增大而上升，本方法显著抑制该趋势并保持稳定 SR。
