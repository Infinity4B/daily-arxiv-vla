Card 02 论文概述

论文概述

  • 提出 TRACE，一个面向人形机器人行为基础模型（BFM）的高效跨本体迁移学习框架，在保留预训练运动表征的同时将反馈控制专门化到目标机器人。
  • 解决的核心问题：将预训练全身控制器迁移到新本体时，存在运动学不匹配（关节布局、连杆几何、传感器/执行器数量差异）与动力学不匹配（质量分布、执行器与接触动力学差异），而从头为每个本体训练 BFM 代价过高。
  • 目标是在极小的目标端训练预算下完成跨本体验证，并保持与预训练模型共享的运动指令接口，以支持遥操作与下游 VLA 策略。
Card 03 核心贡献

核心贡献

  • 提出 TRACE 跨本体迁移框架，结合运动学与动态响应预对齐，以及两阶段低秩训练，解耦参考编码器蒸馏与控制优化。
  • 引入定向运动数据筛选策略：在质量筛查后平衡运动类别，并提升指令特征空间中的分散度，在固定数据预算下提升跟踪成功率。
  • 实现 SONIC 控制器从 Unitree G1 到差异显著的 Unitree H2 的低成本迁移，在 PHUMA 基准上取得 96.08% 跟踪成功率。
  • 在实体 H2 上验证了高动态动作跟踪与 VR 全身遥操作演示采集，并将采集数据用于 VLA 策略后训练以实现自主任务执行。
Card 04 方法描述

方法描述

  • 四阶段框架：跨本体预适配（Stage 1）→ 运动数据集策划（Stage 2）→ 参数高效微调（Stage 3）→ 目标机器人部署（Stage 4）。
  • 运动学先验注入：将运动学先验注入参考、本体感知与动作投影层，由配对重定向姿态估计线性映射，并以基于雅可比的先验正则化（M0 = (J_t^0)† D_{s→t} J_s^0）；输入投影使用右乘、动作投影使用左乘。
  • 动作尺度对齐：定义 P_act = S_t^{-1} M*_{s→t} S_s，统一源与目标的归一化动作到物理关节偏移的换算。
  • 关节动力学对齐：基于源控制器的标称自然频率 ω_n 与阻尼比 ζ，用反射执行器惯量 I_{t,j} 与被动阻尼 d_{t,j} 初始化目标 PD 增益。
  • 数据策划：重定向与质量筛查（拒绝不连续、关节限位/速度越界、非预期碰撞、不合理加速度与抖动、接触异常）；十大类别帧预算均衡；基于冻结 SONIC 参考编码器 128 维片段描述符（时序均值与标准差）计算分散度分数 s_i 做指令空间选择。
  • 参数高效微调：在目标 Robot 参考编码器与控制解码器线性层插入 LoRA（W_eff = W_b + (α/r_L) BA，r_L=32），A 用 Kaiming 均匀初始化、B=0；源编码器（Robot/Human/Hybrid）与 FSQ 算子冻结。
  • 指令潜变量对齐：对目标与源 Robot 编码器的 FSQ 前潜变量 z 和量化 token c 施加 smooth-L1 蒸馏损失 L_align，防止指令语义漂移并保持多任务接口兼容。
  • PPO 控制微调：按混合比例采样源参考分支与目标分支的量化 token 作为指令，PPO 更新控制解码器 LoRA 参数与动作采样方差，梯度在 token 输入处截断。
  • 两阶段课程：第一阶段在均衡分布上强化全局位置与末端执行器跟踪奖励以建立稳定跟踪；阶段切换时合并 LoRA 并重置零输出分支；第二阶段自适应优先采样失败频繁或误差大的运动片段，强化末端跟踪奖励并加入地形交互与鲁棒性正则。
Card 05 数据集与资源

数据集与资源

  • 迁移适配集：从 BONES-SEED 中筛选的 10M 运动帧。
  • 评估基准：PHUMA 基准，使用 67,953 条未参与 H2 适配训练的运动，参考动作分别重定向到各机器人。
  • 预训练模型基线：SONIC（Unitree G1，原训练约 21,000 GPU 小时）。
  • 训练配置：12,288 个并行环境、rollout 长度 24 步、batch size 1,536，LoRA 秩 r_L = 32。
  • 计算资源：单张 RTX PRO 6000 GPU，约 8 小时完成迁移训练，GPU 小时成本不足从头训练 SONIC 的 0.1%。
  • 下游 VLA 模型：在 GR00T-N1.7 上做后训练。
Card 06 评估与结果

评估与结果

  • 收敛效率（前 3k 迭代，统一运动采样分布）：TRACE 在少量迭代内收敛并达到稳定 completion 与奖励水平；Direct Finetune（全参数微调）收敛显著更慢；Scratch（无预训练）在 3k 迭代预算内无法得到可用跟踪策略。
  • PHUMA 运动跟踪：TRACE/H2 成功率 96.08%，与 SONIC/G1 的 97.59% 相差仅 1.51 个百分点；局部位置误差 E_loc 为 55.81 mm（H2）对比 27.81 mm（G1）；速度与加速度误差分别为 7.536 与 2.394（H2）。成功率阈值按身高比例缩放（G1: 0.250 m，H2: 0.3447 m，身高比 1.820/1.320）。
  • 消融结果：去掉预适配使 SR 从 96.08% 降至 87.29%、E_loc 升至 72.88 mm（三项消融中降幅最大）；去掉数据策略 SR 降至 93.80%、增加 2.28 个百分点；去掉两阶段课程 SR 降至 95.64%、E_loc 升至 62.47 mm。
  • 数据分布统计：增强筛选将特征标准差几何均值从 1.001 提升至 1.261，类别归一化熵从 0.789 提升至 0.976。
  • 两阶段课程（表 II）：相比单阶段基线，训练奖励提升 11.9%，根位置误差与全局足部误差分别降低 26.2% 与 25.9%，局部手部误差降低 9.7%，关节角误差降低 4.8%，critic 值损失降低 30.4%。
  • 实机与下游应用：在实体 H2 上完成下蹲、单膝跪、踢腿、单腿跳等动作，以及开门通过、玩具收纳、倒垃圾、搬椅子、踢足球等全身遥操作任务；5 项 VLA 任务各 20 次试验，成功率在 65%–90% 之间（物体搬移单臂 90%、双臂 75%，枕头拾取 80%，开门 65%，开垃圾桶 65%）。
  • 局限：验证仅覆盖单一本体对与单一预训练 BFM；未来将扩展到更多本体与开源 BFM，并探索无复用 critic 的高效适配以及引入 RGB、深度与触觉感知。
