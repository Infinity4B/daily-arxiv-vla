Card 03 核心贡献

核心贡献

  • 首次将动作 token 监督与专家到 VLM 的梯度路由两个因素解耦，进行独立的交叉实验（2×2 因子设计），控制数据、架构、优化和语义共训练不变
  • 发现两种动作学习信号（动作 token 监督与专家梯度）部分可互相替代：有动作 token 监督时，开环驾驶中绝缘与耦合性能接近；无监督时，耦合可将轨迹预测误差（ADE）降低约 25%
  • 闭环联合训练中，耦合训练将驾驶路线完成度提升约 17%（有动作 token）至 40%（无动作 token），并在两个机器人操作模型家族中均提升任务进度
  • 发现并发联合训练（concurrent training）从零开始同时训练 VLM 与专家是强而简单的起点，其绝对性能优于此前常用的 VLM-First 分阶段方案
  • 挑战了梯度绝缘作为 VLA 默认训练配方的地位，提出梯度路由应与动作监督和训练计划联合选择
Card 04 方法描述

方法描述

  • 基于 Mixture-of-Transformers（MoT）VLA 架构：自回归 VLM 与非因果流匹配（flow-matching）动作专家配对，专家在每一层注意力机制中读取 VLM 对应层的 K/V 缓存表示以生成连续动作块
  • 驾驶模型采用 Alpamayo VLA 架构：Qwen3-VL-2B-Instruct 主干 + 同宽度流匹配专家，专家预测 K 个未来控制对（加速度与曲率），经离散化独轮车模型积分得到轨迹
  • 联合目标为 ℒ = ℒ_CE + ℒ_flow：VLM 用交叉熵损失（VQA、驾驶推理链、可选的未来动作 token），专家用整流流匹配损失
  • 梯度路由通过 stop-gradient 实现：耦合（coupling）时流损失梯度经 K/V 接口更新 VLM；绝缘（insulated）时阻断梯度，前向计算完全相同
  • 训练计划包含三种：并发训练（VLM 与随机初始化专家同时训练）、VLM-First（模仿 π₀.₅/MolmoAct2，先训 VLM 100k 步再引入专家）、Expert-First（受 APT 启发，先在冻结 VLM 下训专家 100k 步）
  • 操作领域复现 π₀.₅（PaliGemma-3B + 流匹配专家，OpenPi 框架，FAST 动作 tokenization）和 MolmoAct2 两个模型家族，进行同样的 2×2 条件实验

Card 06 评估与结果

评估与结果

  • 开环驾驶：在 PhysicalAI-AV 数据集的 Public Golden（1,434 场景）与 OOD（273 场景）划分上评估 ADE（平均位移误差）；使用 95% clip-cluster bootstrap 置信区间
  • 闭环驾驶：在 AlpaSim 闭环仿真器中，827 个场景、每场景 5 次随机 rollout，指标为路线完成度（route progress）
  • 推理质量：用冻结的 Lingo-Judge 分类器评估生成的驾驶推理链质量
  • 开环结果：有动作 token 监督时，绝缘与耦合差异很小；无监督时，耦合将 ADE 降低约 26%（Public Golden）和 24%（OOD），且该模式跨三种训练计划一致
  • 闭环结果：并发训练中，耦合将路线完成度从 0.600 提升至 0.703（有 token，约 +17%），从 0.425 提升至 0.601（无 token，约 +41%）；并发耦合 + 动作 token 达到所有训练计划中最高性能（0.703）
  • 操作结果：π₀.₅ 复现中，无 FAST 时耦合将任务进度从 10.3% 提升至 32.9%（约 3 倍）；有 FAST 时从 19.5% 提升至 30.7%；MolmoAct2 呈现相同模式（无 FAST：14.5% → 36.5%）
  • 安全权衡：有动作 token 监督时，耦合的分阶段训练观察到更高的过失碰撞率，提示路由选择需结合安全指标评估
  • 结论：VLM 梯度绝缘的价值取决于动作监督、训练计划与评估设置，不应作为默认 VLA 训练策略；同时动作 token 监督与专家梯度是部分可替代的动作学习信号
