01研究单位

  • 论文作者来自上海交通大学并行与分布式系统研究所（Institute of Parallel and Distributed Systems, Shanghai Jiao Tong University）

02论文概述

  • 论文聚焦工业场景下的具身智能机器人，指出 Vision-Language-Action（VLA）模型的推理延迟直接影响机器人响应速度和运动平滑性，是部署中的关键瓶颈。
  • 现有VLA推理框架（如 FlashRT）未充分利用具身任务的跨执行相似性，也未针对 VLM 预填充与动作去噪两阶段的不同瓶颈分别优化，导致加速受限。
  • 论文发现重复执行同一任务时，不仅观测与轨迹相似，模型内部状态（FFN输入、神经元激活模式）也高度相似，据此提出rMuscle——一种受人类肌肉记忆启发的实时VLA推理框架。

03核心贡献

  • 发现重复执行相同任务时，FFN输入和神经元激活模式具有高相似性，为计算复用提供了机会。
  • 设计双阶段缓存推理系统：Context Cache 加速计算密集的 VLM 预填充，Action Cache 加速内存密集的动作去噪。
  • 提出三位一体的缓存管理机制：异步在线重构、滑动窗口预取、以及跨去噪步骤的掩码共享，有效控制缓存内存开销与访问延迟。
  • 在 π0.5、GR00T N1.6、X-VLA 三个模型、LIBERO 与 RoboTwin 两个仿真基准及物理机器人任务上全面评估，共 92 个任务，达到最高 1.29×（RTX 4090） 和 1.42×（Jetson Thor） 加速，同时保持原有成功率。

04方法描述

  • Context Cache（视觉令牌选择重算）：基于当前与参考 FFN 输入的 RMS 偏差，选择变化较大的视觉令牌进行重算，其余复用参考输出，注意力仍保持全序列稠密计算。
  • Action Cache（神经元稀疏更新）：利用参考执行中贡献度高的神经元掩码，仅加载并计算被选中神经元的权重，结合当前调用中的稠密锚点输出，通过差分更新保留全部神经元的贡献。
  • 组共享掩码：将连续去噪步骤分组，每组共享一个重要的神经元掩码，减少权重 gather 开销；锚点步执行稠密计算以建立当前激活基线。
  • 缓存管理：利用机器人物理执行窗口，异步在线重构缓存条目；基于时间局部性维护滑动 GPU 工作集；通过视觉特征与关节历史检索最相关的参考；视觉相似度低于阈值时回退到稠密执行。
  • 实现层面采用侧CUDA流将参考检索和权重 gather 与主流的 VLM 预填充重叠，进一步隐藏额外开销。

05数据集与资源

  • 数据集：LIBERO（40个任务，含Spatial/Object/Goal/Long套件）、RoboTwin（50个任务，clean设置）、物理机器人任务（ALOHA双臂协作拾放、DOBOT/Franka单臂装配线装箱）。
  • 模型：π0.5、GR00T N1.6、X-VLA；缩放实验中使用了 Gemma 系列（VLM/denoiser 从 2B/0.3B 到 7B/7B）。
  • 硬件：桌面端 RTX 4090（24GB） + Intel Core i7-11700，边缘端 Jetson Thor（128GB 统一内存）；分别使用 PyTorch 2.6.0/CUDA 12.4 和 PyTorch 2.8.0/CUDA 13.0。

06评估与结果

  • 评估环境：LIBERO 和 RoboTwin 各 100 条种子 rollout；物理任务各 50 次试验，30Hz 控制频率，30 动作 chunk；延迟包含在线检索和权重 gather，成功率为任务完成比例。
  • 主要指标：端到端推理延迟（换算为 Hz）、成功率（SR）、相对 SOTA 推理引擎的加速比。
  • 关键结果：

- RTX 4090 上，rMuscle 达到 π0.5、GR00T N1.6、X-VLA 的推理速率 28.1、51.0、35.7 Hz，较 FlashRT 分别加速 1.29×、1.20×、1.50×。

- Jetson Thor 上，对应速率 13.4、17.5、19.7 Hz，加速分别为 1.42×、1.23×、1.43×。

- 在 LIBERO 上，rMuscle 的平均成功率与 vanilla、DP-Cache 持平，且高于 NIRVANA（高出 0.3–1.1 个百分点）；在 RoboTwin 上成功率优于 DP-Cache 和 NIRVANA。

- 模型缩放实验中，加速比随模型增大而提升（RTX 4090 从 1.3× 到 1.6×，Jetson Thor 从 1.4× 到 1.9×），表明双阶段缓存在更大 VLA 模型上更具优势。
