DiffWAM: Learning World Action Model from Consecutive Visual Difference

提出 DiffWAM（Difference World Action Model），一种基于连续视觉差异的世界动作模型

02论文概述

  • 提出 DiffWAM（Difference World Action Model），一种基于连续视觉差异的世界动作模型
  • 解决现有 World Action Model 仅预测未来状态、难以区分任务相关变化与静态背景内容的问题
  • 通过联合学习未来状态预测、连续视觉差异预测和动作生成，强化世界表征对任务动态的建模能力

03核心贡献

  • 提出在 WAM 中联合未来状态与视觉差异建模，使世界表征同时捕获场景内容和任务相关动态
  • 设计 Mixture-of-Experts (MoE) 框架，包含共享 Observation Encoder 以及 World Expert、Diff Expert、Action Expert 三个专家
  • 采用结构化单向注意力掩码隔离专家通路，推理时可移除 World 和 Diff Expert，不引入额外推理开销
  • 在 LIBERO、RoboTwin 2.0 和真实世界操作任务上取得当前最优结果，并验证了训练效率提升
  • 提供两种训练配置 DiffWAM-S（小规模）和 DiffWAM-L（大规模），适应不同数据规模

04方法描述

  • 使用共享 Observation Encoder 将当前视觉潜变量编码为世界表征，并分别馈送给三个专家
  • World Expert 通过流匹配（flow matching）预测未来帧潜变量；Diff Expert 通过回归预测连续帧潜变量之差；Action Expert 通过流匹配生成动作序列
  • World 和 Diff Expert 在前 N-M 层共享参数，后 M 层独立（Latent Diff Block, LDB），其中 M 默认取 10
  • 训练目标为三项损失加权：世界流匹配损失、差异回归损失（平方误差）、动作流匹配损失
  • 提出两种训练配置：DiffWAM-S 冻结独立 LDB 参数以抑制小数据过拟合；DiffWAM-L 两阶段训练（先仅训练 Diff Expert，再联合训练所有模块）

05数据集与资源

  • 使用 LIBERO 基准（40 个单臂任务，四个套件：Spatial、Object、Goal、Long）
  • 使用 RoboTwin 2.0 基准（50 个双臂任务，含干净和随机场景两种评估条件）
  • 真实世界评估基于 ALOHA-AgileX 平台，包含 Place Pens、Store Block、Stack Cups 三个任务，约 1.1k 条演示轨迹
  • 模型总参数量约 7B，基于 Wan2.2-5B Transformer 架构，视觉编码器为预训练 VAE，文本编码器为 T5
  • 训练资源：论文未明确列出具体 GPU 型号，但模型规模大，需大规模训练

06评估与结果

  • LIBERO：DiffWAM-S 平均成功率 98.8%，超过 FastWAM 1.75 个百分点，在 Goal 和 Long 套件分别提升 1.2 和 6.0 个百分点
  • RoboTwin 2.0：DiffWAM-L 平均成功率 92.65%（Clean 93.28%，Random 92.02%），超过 FastWAM 1.55 个百分点
  • 真实世界：三个任务平均成功率 88.3%，较 FastWAM 的 73.3% 提升 15.0 个百分点
  • Clean-to-Random 泛化：仅用干净数据训练时，DiffWAM 在随机场景取得 5.27% 成功率（FastWAM 为 1.50%），平均指标提升 1.62 个百分点
  • 训练效率：DiffWAM 在 LIBERO 上达到 95% 平均成功率只需 6.9k 步，比 FastWAM 减少 28.1% 的优化步数
  • 消融实验验证独立 Diff Expert 比单纯增加差异损失更有效，且 LDB 深度 M=10 为最优配置
