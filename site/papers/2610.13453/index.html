Reflect-VLA: Internalizing Reflective Guidance via Dual-Path On-Policy Self-Distillation for Autonomous Driving

2026-10-09 · 原文 · 翻译 · 2610.13453

提出 Reflect-VLA，一种将 Reflective Guidance（反思性引导） 作为训练期特权信息、并通过 Dual-Path On-Policy Self-Distillation（Dual-OPSD） 将其规划收益内化到 VLA 模型中的训练框架。 论文要解决的问题：现有自动驾驶 VLA 的强化学习方法依赖标量轨迹奖励，只能衡量轨迹整体质量，无法指出具体规划错误（场景理解、行为选择还是轨迹执行），在长尾场景下多个异质失败原因被压缩成单一分数，导致优化方向不明。 核心思路：Reflective Guidance 虽能显著提升规划精度，但推理时需要初始轨迹与评估结果作为前提，无法单次前向直接使用，因此需将其收益迁移到模型的直接轨迹生成策略中。

Card 02 论文概述

论文概述

  • 提出 Reflect-VLA，一种将 Reflective Guidance（反思性引导） 作为训练期特权信息、并通过 Dual-Path On-Policy Self-Distillation（Dual-OPSD） 将其规划收益内化到 VLA 模型中的训练框架。
  • 论文要解决的问题：现有自动驾驶 VLA 的强化学习方法依赖标量轨迹奖励，只能衡量轨迹整体质量，无法指出具体规划错误（场景理解、行为选择还是轨迹执行），在长尾场景下多个异质失败原因被压缩成单一分数，导致优化方向不明。

Card 03 核心贡献

核心贡献

  • 构造 Reflective Guidance，将轨迹评估结果转化为结构化、轨迹特定的诊断与纠正建议，并仅作为训练期特权信息使用。
  • 提出 Dual-OPSD，一种轨迹质量感知的自蒸馏方法：对学生生成的高风险轨迹蒸馏教师密集 token 级纠正分布，对可靠轨迹则采用自模仿（self-imitation）加以保留。
  • 设计渐进式教师构建策略，结合 Driving-Knowledge Pretraining、Planning-and-Refinement SFT 与 Self-Refinement Rejection Sampling，支撑引导内化的稳定性。
  • 实现推理阶段无需显式引导、在线评估器或迭代修正的单次前向轨迹生成，同时相比 RL 减少 90% 以上训练时间。
Card 04 方法描述

方法描述

  • 将端到端驾驶规划形式化为条件自回归轨迹生成：输入为前视相机图像、导航命令、自车状态与历史轨迹，将绝对路点转为相对位移并离散化为特殊轨迹 token 输出。
  • 引导条件输入：$q^{\text{gui}}=(q^{\text{base}}, o^{\text{init}}, g)$，其中 $g$ 包含四个组成部分：Trajectory Verdict（轨迹总体评估）、Planning Diagnosis（主导失败原因诊断）、Expert Alignment（与专家轨迹的偏差关联）、Refinement Directive（高层纠正动作建议）。
  • 三阶段 SFT：驾驶知识预训练 → 规划与精炼监督微调（base 规划数据 + 引导条件精炼数据混合）→ 自精炼拒绝采样（仅保留验证有效且优于初始轨迹的样本）。

Card 05 数据集与资源

数据集与资源

  • 预训练数据：LingoQA、DriveGPT4、Senna、DriveLM、NuScenes-QA、NuInstruct、DriveLMM 等开源驾驶问答数据集。
  • 精炼数据由经典规划器输出与规则扰动构成候选轨迹集，经 NAVSIM evaluator（PDMS）与地图约束筛选得到。
  • 基础模型：Qwen3.5-0.8B / 2B / 4B。
  • 训练超参：预训练 2 epoch、batch size 1、学习率 $1\times10^{-5}$；第二轮微调 2 epoch、batch size 4、学习率 $4\times10^{-5}$；OPSD 2 epoch、batch size 2、学习率 $8\times10^{-6}$/$2\times10^{-6}$。
  • 训练硬件：8 张 NVIDIA H20 GPU。
Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1（PDMS）、NAVSIM v2（EPDMS）与闭环 Bench2Drive（DS、SR、Effi、Comf）。
  • NAVSIM v1：Reflect-VLA-0.8B/2B/4B 的 PDMS 分别为 89.3 / 90.0 / 91.5，较对应 RL 基线分别提升 0.5、0.8、0.3 分，其中 4B 取得最佳总体 PDMS。
  • NAVSIM v2：Reflect-VLA-4B 取得 EPDMS 91.2，在 DAC（97.9）、TLC（99.8）、EP（88.8）、TTC（98.6）、LK（97.9）、DDC（99.6）等多个子指标上具竞争力。
  • Bench2Drive：Reflect-VLA-4B 取得最佳 DS 80.15、Effi 212.20、SR 59.09%，优于 AutoVLA 等基线，说明引导内化在闭环交互场景中具有良好泛化性。
  • 引导有效性：教师相对无引导学生分别提升 6.1/5.3/4.8 PDMS；Dual-OPSD 后学生提升 3.0/2.6/3.1 PDMS，大幅缩小与教师的差距。
  • 训练效率：OPSD 相比 GRPO 显著更快，0.8B 从 5.3 降至 1.3 小时（约 4.1×），2B 提速 13.1×，4B 提速 13.9×，整体较 RL 减少 90% 以上训练时间。
  • 消融实验：预训练使 PDMS 从 88.1 升至 88.5；单独的拒绝采样略降至 88.4，但与 OPSD 结合后从 90.2 提升至 91.5；完整引导设计取得最佳 PDMS 93.2，其中 Expert Alignment 与 Planning Diagnosis 贡献最大。
