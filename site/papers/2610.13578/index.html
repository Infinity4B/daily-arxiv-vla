02论文概述

  • 论文提出 RARA（Retrieval-Anchored Representation Alignment），一种面向机器人操作的两阶段鲁棒策略微调方法，用于将预训练策略（如 VLA 模型）适配到仅有少量演示的新任务。
  • 核心问题是：直接微调预训练策略虽能在分布内（ID）表现良好，但会扭曲预训练阶段学到的表征，从而在分布外（OOD）场景（相机视角、背景、物体属性变化）下泛化能力下降。
  • 目标是在学习目标任务的同时，保留预训练知识，实现 ID 与 OOD 双重性能的提升。

03核心贡献

  • 提出 RARA 框架：利用与目标任务相关的预训练经验（检索到的演示）来引导表征学习，实现鲁棒策略微调。
  • 在两阶段流程中结合"对齐"与"锚定"：先对齐目标表征与检索演示的预训练表征，再在微调中限制检索演示表征的漂移。
  • 跨多种策略、仿真环境与真实机器人任务进行验证，同时评估目标任务性能与对未见条件的鲁棒性。
  • 通过大量消融研究，分离初始对齐与表征约束的各自作用，并分析源数据选择与网络层选择对适配效果的影响。

04方法描述

  • 两阶段框架：Stage 1 用多正样本对比损失将目标帧表征对齐到检索帧的预训练表征，并配合锚定损失；Stage 2 在目标演示上用行为克隆（BC）损失微调，锚定损失持续生效。
  • 检索机制：用冻结的 CLIP 文本编码器按指令相似度选取预训练演示（顶层 K 个），再用动作块（action chunk）的 DTW 距离匹配目标帧与检索帧，构造正/负样本对（借鉴 CLASS 的做法）。
  • 锚定层与锚定损失：选定某一中间层作为"锚定层"，锚定损失仅作用于检索到的预训练演示，比较适配策略与冻结预训练策略在相同帧上的表征差异，不拉回目标表征。
  • 投影器：使用可训练的两层 MLP 投影器将表征映射到 ℓ₂ 归一化嵌入空间计算对比损失，避免维度坍缩，仅在 Stage 1 使用，之后丢弃，推理时仅用微调后的策略。
  • 创新点：与权重正则、权重合并、冻结编码器对齐等方法不同，RARA 不限制架构或权重更新范围，而是以"任务相关的检索演示"作为表征锚点。

05数据集与资源

  • RoboTwin 2.0：约 2k 条多样技能预训练演示（覆盖更大工作空间、更多干扰物与背景），4 个单臂目标任务（如 Place Container、Move Pill Bottle），每个任务 50 条目标演示。
  • RoboCasa：5 个目标任务（如 Open Blender Lid、Close Fridge Drawer），每个任务 100 条演示；预训练使用 DROID（含 76k 条演示）。
  • 真实 Franka 机器人：4 个任务（如 Remove Pot Lid、Load Bread in Toaster），每个任务 50–80 条 VR 遥操作演示；预训练同样使用 DROID。
  • 策略模型：Diffusion Policy（在 RoboTwin 预训练数据上预训练，用于 RoboTwin）与 GR00T N1.7（基于 DROID 预训练的 VLA 模型，用于 RoboCasa 与真实机器人）。
  • 摘要中未明确给出 GPU/TPU 等具体训练硬件资源信息。

06评估与结果

  • 评估环境：RoboTwin 2.0、RoboCasa 两个仿真环境，以及真实 Franka 机器人，共 13 个任务。
  • 评估协议：每个任务在 ID 与 OOD 条件下评估；RoboTwin 每任务每设置 150 次 rollout，RoboCasa 50 次，真实机器人 10 次试验，每项实验重复 3 次，汇报成功率均值与标准差。
  • 对比基线：FT、Co-FT、STRAP、RETAIN、BlindVLA。
  • 主要指标：任务成功率（ID/OOD）、表征保留度（Rank、CKA、R²）、目标数据特征扭曲度（越低越好）。
  • 关键结果：

- 跨 13 个任务，RARA 将微调策略平均成功率提升 9.5 个百分点（ID） 与 13.6 个百分点（OOD），全面优于所有基线（图中摘要提到平均 ID 与 OOD 提升 11.6 点）。

- 表征分析（Table 1）显示 RARA 明显降低目标数据特征扭曲（如 ID 0.47 → 0.23，OOD 0.48 → 0.23），并保留更多预训练结构。

- 在 RoboTwin 与 RoboCasa 的多数任务上，RARA 在 ID 与 OOD 成功率上均取得最佳结果（如 RoboTwin 任务平均 ID 76.0、OOD 58.3）。
