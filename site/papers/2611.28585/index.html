02论文概述

  • 论文提出了 AsyncMixVLA，一个用于在异构 VLA 策略之间进行运行时异步切换的自适应推理框架，旨在解决动态环境中机器人策略因扰动物体移动而失效的问题。
  • 核心问题：当环境在任务执行中发生变化时，轻量级策略可能不可靠，而不同 VLA 策略表现出互补的失败模式，但同步切换会暴露新策略推理延迟或使用过时观测，导致机器人停顿或动作错误。
  • 目标：通过选择性切换到高计算量策略实现恢复，同时将推理延迟隐藏在与已提交动作重叠的执行中，并对齐上下文到预期接管状态，从而在保持响应性的前提下提升鲁棒性。

03核心贡献

  • 贡献点 1：互补性驱动的异构切换：表征了独立训练的 VLA-Adapter 和 OpenVLA-OFT 的互补失败模式，并引入了一个学习型“救援 vs 伤害”触发器，用于选择性升级到高计算量策略。
  • 贡献点 2：主动异步交接与上下文对齐：将 OpenVLA-OFT 的推理与 VLA-Adapter 已提交的动作执行重叠，并通过控制器校准的状态前推和动作一致性视觉 token 残差对齐本体感觉和视觉上下文，减少过时观测的影响。
  • 贡献点 3：端到端鲁棒性、响应性和泛化性：在 LIBERO-Long 增强基准上，扰动成功率从 69.5% 提升到 77.1%，总体成功率 84.9%，切换延迟中位数从 226.5ms 降至 0.1ms，且无需重训练或重校准即可泛化到三种未见扰动家族（75.1% 成功率）。

04方法描述

  • 使用两个互补的 VLA 策略：轻量级默认策略 VLA-Adapter 和高计算量恢复策略 OpenVLA-OFT，每个回合最多允许一次从 Adapter 到 OFT 的切换。
  • 采用两阶段连续学习干预触发器（V1-V2 级联）：V1 基于时序视觉变化、机器人状态和当前动作提出候选；V2 结合因果历史、V1 特征和视觉变化输出救援与伤害分数，通过差异定义干预效用，超过阈值即接受切换。
  • 切换接受后，当前 Adapter 动作块中未执行部分作为固定“已提交动作桥”继续执行，同时异步准备 OFT：使用控制器校准的本体感觉对齐（利用 LIBERO 控制器语义和校准增益）和动作一致性视觉对齐（通过冻结 OFT 的投影 token 接口，用轻量级预测器生成共享残差，以最小化预测上下文和真实上下文下 OFT 动作输出的 L2 差异）。
  • 初始接管执行 OFT 块的前 k=4 个动作（200ms），丢弃剩余动作，然后从新观测重新规划，以平衡预测上下文和新鲜观测。

05数据集与资源

  • 数据集：LIBERO-Long 基准的十个长期操作任务，并增强 mid-rollout 扰动（物体平移 5cm、旋转、目标位移、抓取后滑动等）。主评估集 238 回合（120 clean + 118 perturbed），另有 500 匹配扰动回合用于互补性表征，289 回合用于零样本泛化测试。
  • 模型规模：使用两个预训练的 VLA 策略：VLA-Adapter（轻量级）和 OpenVLA-OFT（OpenVLA 微调版本，高计算量）。具体参数量未在论文中明确列出，但两者均为独立训练的 VLA 模型。
  • 训练资源：所有时序实验在单个 NVIDIA RTX 3090 GPU 上进行，VLA-Adapter 和 OpenVLA-OFT 使用 BF16 推理，作为两个单工作服务共存于同一 GPU 分配中，异步测量包括 GPU 争用。

06评估与结果

  • 评估环境：LIBERO-Long 十任务基准，20 Hz 控制（T_ctrl=50ms），最多 520 环境动作，7 维动作，动作视野 H=8。扰动固定在特定回合中，所有方法共享种子、检查点、动作处理和视野。
  • 主要评估指标：总体、清洁和扰动任务成功率；Adapter 失败救援数和成功保留率；OFT 调用率；切换延迟（中位数和 p95）；无停顿切换比例。
  • 关键实验结果：AsyncMixVLA 达到总体成功率 84.9%，扰动成功率 77.1%，清洁成功率 92.5%；救援 17/45 Adapter 失败，保留 185/193 Adapter 成功；OFT 调用率 45.8%。相比同步切换，总体成功率相当（84.5% vs 84.9%），但切换延迟中位数从 226.5ms 降至 0.1ms，p95 从 363.8ms 降至 224.5ms。零样本泛化到三种未见扰动家族，总体成功率 75.1%（对比 VLA-Adapter 71.3% 和 OpenVLA-OFT 69.2%）。对齐消融显示视觉对齐和状态对齐结合使执行动作 L2 偏差最低（0.1676）。
