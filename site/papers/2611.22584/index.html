InteractVLA: Turning VLAs into Interactive Tools for Agentic Robotic Manipulation

02论文概述

  • 提出 InteractVLA 框架，将预训练的基于流（flow）的视觉-语言-动作（VLA）策略从仅接受语言指令的黑箱原语，转变为可被智能体几何引导和检查的交互式工具
  • 解决现有智能体操作系统在 VLA 调用失败时只能盲目重试或人工接管，无法在实际场景中灵活控制 VLA 行为的问题
  • 通过双向几何交互接口（前向几何引导 + 后向动作反馈），使智能体能够指明空间目标、诊断执行偏差并迭代完善操作策略

03核心贡献

  • 提出 InteractVLA 框架，集成三个关键组件：测试时几何引导（test-time geometric guidance）、软时间目标对齐（soft-time target alignment）和动作知情智能体精化（action-informed agentic refinement）
  • 证明将 VLA 变得几何可引导和可检查后，能够解锁有效的递归自我改进（RSI），使智能体逐步优化目标指定和运动修正
  • 在 LIBERO-Plus（99.4%）、RoboDojo（48.62%）和 RoboCasa365（89.4%）三个基准上取得当时最优性能，并在真实世界操作中一致提升成功率和效率
  • 相比语言单向调用的智能体-VLA 基线，显著降低 token 消耗和总执行时间，提升在线工具使用成功率

04方法描述

  • 测试时几何引导：通过可微的命令-姿态映射，将智能体指定的末端执行器目标（位置、姿态、夹爪状态）转换为对动作专家去噪过程的输入梯度，在单个流轨迹中重塑运动，并利用目标兼容置信度提前终止不兼容目标的生成
  • 软时间目标对齐：将到达时间视为潜在执行索引，使用 log-sum-exp 目标逐渐集中引导到最匹配的动作步，避免固定时间惩罚或均匀惩罚破坏原有接近轨迹的结构
  • 动作知情智能体精化：将生成的动作块、已执行前缀和未执行剩余部分连同校准相机重投影反馈给智能体，使智能体能够区分目标偏差与执行滑移，在重新调用引导 VLA 和局部调整运动片段之间选择轻量恢复路径
  • 三者构成正向“智能体→VLA”的几何引导和反向“VLA→智能体”的可解释反馈闭环，支持迭代式策略修正

  • 真实世界实验平台：Dexmal 双臂机器人，评估四个任务（桌面整理、扶正瓶子、倒水、移动方块）
  • 模型主干：预训练的 MR-0 基于流的 VLA 政策（未提及具体参数量）
  • 训练资源：论文未明确给出 GPU/TPU 等具体训练硬件信息，主要强调测试时框架和复用预训练模型

06评估与结果

  • 在线工具使用：在 LIBERO-Plus 上，将语言调用（Sol + VLA，93.1%）替换为 InteractVLA 后整体成功率提升至 98.3%；在 RoboDojo 上，由 18.0% 提升至 26.0%
  • 递归自我改进（RSI）：LIBERO-Plus 达到 99.4% 总体成功率，RoboDojo 达到 48.62%，RoboCasa365 达到 89.4%，均超过现有 SOTA 基线（如 HarnessVLA、RV-ICL、HexaShell 等）
  • 真实世界：InteractVLA 在四个任务上均取得最高任务得分和最低延迟；例如 Move Cube 得分从 86.7 提升到 97.6，执行时间从 165.2 秒降至 67.5 秒，API 调用减少 67%
  • 消融实验：软时间对齐优于固定末步、均匀对齐和硬最小误差对齐；增加动作块和重投影反馈持续提升性能，证明双向接口各组件均有效
