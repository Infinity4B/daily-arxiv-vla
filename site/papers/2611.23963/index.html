CoRA-VTLA: Contact-Guided Attention and Queryable Response Memory for Tactile Post-Training

01研究单位

  • 作者来自 大连理工大学、吉林大学、清华大学 以及企业单位 Enomind Technology

02论文概述

  • 论文提出 CoRA-VTLA 框架，通过触觉后训练将预训练视觉-语言-动作（VLA）模型适配到接触丰富的精密操控任务
  • 解决两个核心问题：单一触觉观测无法区分相似接触状态的不同响应历史；直接触觉融合导致动作专家视觉注意力分散、减少对接触区域的关注
  • 核心目标是使预训练 VLA 在接触后阶段能够根据触觉响应历史生成闭环纠偏动作

03核心贡献

  • 提出可查询动作-响应记忆（queryable action-response memory），通过状态条件检索历史接触响应以支持纠偏动作生成
  • 提出接触引导的注视监督（contact-guided gaze supervision），将触觉语义 token 的视觉注意力引导至投影的指尖接触区域
  • 设计响应预测预训练任务，利用任务演示中执行动作后的真实负载变化初始化动作侧触觉编码器
  • 在 MuJoCo 仿真、公开 UniVTAC 基准及真实机器人平台上完成系统性评估，验证方法在不同触觉模态和任务上的有效性

04方法描述

  • CoRA-VTLA 采用感知层和动作层的双层级结构：感知层通过接触引导的注视监督将触觉语义与视觉场景对齐；动作层利用 VLM 任务上下文、当前接触特征和检索到的历史响应生成动作块
  • 动作-响应记忆使用时间 Transformer 编码最近 16 步（约 0.8 秒）的接触响应（压力变化、腕力变化、相对初始腕力），以当前接触特征和机器人状态构建查询，通过注意力机制检索相关历史响应
  • 接触引导的注视监督将指尖压力激活区域投影到视觉 patch 网格，构建注视损失函数，强制触觉语义 token 在 VLM 特定层将注意力集中在投影接触区域
  • 语义分支预测接触、稳定性和负载变化三种属性，对词嵌入加权求和生成语义 token，为 VLM 提供触觉语义信息
  • 训练分两阶段：先在任务演示上使用响应预测预训练接触和记忆编码器，再进行联合后训练，优化视觉骨干、VLM、动作专家和全部触觉模块

05数据集与资源

  • 在 MuJoCo 仿真环境中构建三个任务：钉子插入、插头插入、旋钮操作；每个任务包含名义执行和受阻恢复演示
  • 在公开基准 UniVTAC 的 Insert Tube 任务上评估，使用光学触觉图像而非数值压力阵列
  • 在真实机器人平台执行三个任务：软纸杯堆叠、盖章、试管插入；机器人使用 UR5e 机械臂和 Robotiq 140 夹爪，指尖配备 Xuanya 电子皮肤
  • 基础模型为预训练的 π0.5 VLA；训练使用 50 个演示，不同模块使用不同学习率（视觉 2e-6，VLM 5e-6，动作专家 2.5e-5，触觉参数 7.5e-5）
  • 仿真评估使用 50 个未见场景每任务，共 150 次试验；真机评估每任务 50 次试验
  • 论文未披露模型具体参数量和训练所用 GPU/TPU 等硬件资源

06评估与结果

  • 在 MuJoCo 三个任务上平均成功率为 73.33%，显著优于直接触觉融合（50%）和基线（31.33%）；其中插头插入从基线 0% 提升至 76%
  • 在 UniVTAC Insert Tube 上达到 67% 成功率，优于 Direct（51%）和 Base（46%），并显著减少滑脱终止次数
  • 在真实机器人三个任务上平均成功率为 66.7%，高于最强基线 FTP-π0.5 的 44.7%；所有三个任务均取得最高成功率
  • 消融实验表明：移除记忆 token 使平均成功率降至 54%；移除响应预训练也降至 54%；移除注视监督降至 49.33%；移除语义分支同样降至 49.33%
  • 定性分析显示，注视监督使触觉语义 token 在接触区域的注意力份额从 2.77% 提升至 46.65%；在真实机器人接触区域注意力份额从 2.1% 提升至 7.5%
