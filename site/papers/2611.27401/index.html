Beyond Linear Decodability: Understanding and Improving Instruction Following in World Action Models

02论文概述

  • 研究世界行动模型（WAM）在测试时无法遵循自然语言指令的失败机制：模型倾向于执行训练时先验行为，忽略测试时的新指令。
  • 发现非遵循（NF）与遵循（IF）模型内部都编码了指令指定的目标信息，但 IF 模型中该信息的线性可解码性显著更强。
  • 提出线性可解码性监督（LDS）辅助训练目标，并引入先验-指令竞争机制解释模型行为，通过无训练干预提供因果证据。

03核心贡献

  • 提出 LDS：一种简单有效的辅助训练目标，通过细粒度 token 级线性头预测 instructed target 的 grounding 图，大幅提升 WAM 的指令遵循能力，且无需收集反事实演示。
  • 提出 先验-指令竞争机制：解释“编码但不控制”现象，认为先验标签 P 与指令标签 I 在中间表示中竞争，行为由胜者决定；通过增强 I 和转移 P 两种训练无关的表示干预因果验证该机制。
  • 构建 RoboTwin-IF 反事实基准，用于系统比较 NF 与 IF WAM 的内部状态，并支持 LDS 训练与评估。
  • 在 LIBERO-CF、LangGap、RoboTwin-IF 及真实机器人任务上验证 LDS 的一致有效性，并展示了对未见场景的泛化能力。

04方法描述

  • 基于 Wan 架构的 WAM：语言通过交叉注意力注入视觉表示，与自注意力内竞争注意质量的方式不同。
  • 线性可解码性监督（LDS）：在训练时从浅、中、深层各选一层，在第一个去噪步对这些层的 block 输出视觉 token 添加共享线性头，将每个 patch 细分为 4×4 网格，预测目标、其他候选对象、背景三类 logits；采用区域平衡的二元交叉熵损失。辅助头仅训练时使用，推理时丢弃。
  • 联合优化 flow-matching 损失和 LDS 辅助损失，仅需 grounding 标注，无需反事实动作或未来视频监督。
  • 机制分析：通过配对反事实指令得到指令标签 I 和先验相关分量 U，推导并实施增强 I 或转移 U 的表示干预。

05数据集与资源

  • LIBERO-CF：主要评估基准，包含 CF-Spatial、CF-Object、CF-Long、CF-OOD 子集。
  • RoboTwin-IF：本文构建的反事实基准，基于 RoboTwin2.0 合成，包含多物体场景和语言指令，用于探测与训练。
  • LangGap：额外评估指令遵循的数据集。
  • 模型：InternW0-Δ（主要 WAM）、OpenWAM（基线 WAM），以及 VLA 基线 OpenVLA-OFT 和 π0。
  • 训练资源：论文未在提供的片段中明确列出 GPU 数量或型号。

06评估与结果

  • 评估环境：LIBERO-CF 标准基准，以及 RoboTwin-IF、LangGap 和真实机器人任务；主要指标为成功率（SR）和 grounding 率。
  • LIBERO-CF 上，InternW0-Δ + LDS 达到 74.6% SR、89.2% grounding，相比最强基线分别提升 26.8 和 42.9 个百分点；OpenWAM 用 LDS 将 SR 从 5.1% 提升至 65.1%，grounding 从 14.4% 至 90.3%。
  • 无训练干预：增强指令标签 I 将 SR 从 3.8% 提升至 53.0%，转移先验标签 P 达到 50.8%（LIBERO-CF picking 子集），验证了竞争机制。
  • LangGap 上 InternW0-Δ + LDS 达到 71.4% SR，RoboTwin-IF 上达到 47.4% SR，并在真实机器人任务中表现出有效性。
  • 在 held-out 场景划分上表现强泛化，在完全未见场景中性能保持稳定。
  • 探测实验：IF WAM 的指令目标双向准确率从 51.5% 提升至 77.5%，证实线性可解码性增强。
