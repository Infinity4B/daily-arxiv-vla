Card 03 核心贡献

核心贡献

  • 提出了 Latent Spatiotemporal Reasoning 模块，使 VLA 模型能够在视觉表示空间中直接想象任务相关的未来场景演化，无需昂贵的像素级视频生成。
  • 引入了 Scene Gist Memory 机制，将推理衍生的场景与行为关联内化为紧凑的 Scene Gist Token，在推理时绕过显式未来推演，保留推理优势的同时显著降低延迟。
  • 在 LIBERO、LIBERO-Plus 和 VLABench 基准测试上进行了广泛实验，验证了框架在成功率与推理效率上的双重提升。
Card 04 方法描述

方法描述

  • 模型基于 PaliGemma 架构构建，包含视觉编码器、视觉-语言主干和动作专家。
  • Latent Spatiotemporal Reasoning Module 直接预测未来视觉潜变量表示（默认 K=10 步），利用潜变量 MSE 损失和余弦方向一致性损失进行监督训练。
  • Scene Gist Memory 包含 Gist Compressor 和 Gist Encoder：Compressor 将完整的推理增强表示压缩为单一向量，Encoder 则学习直接从当前上下文预测该向量。
  • 推理阶段直接使用预测的 Gist Token 指导动作生成，完全跳过潜变量未来推演、隐式动作推理器和压缩器路径。
Card 05 数据集与资源

数据集与资源

  • 使用的数据集：LIBERO、LIBERO-Plus、VLABench
  • 模型规模：视觉编码器为 SigLIP So400m/14，多模态前缀模型为 Gemma-2B，动作专家为 Gemma-300M
  • 训练资源：使用 8 张 NVIDIA H100 GPU 训练推理模块，4 张 NVIDIA A6000 GPU 训练 Gist Memory 模块
Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO (Spatial, Object, Goal, Long)、LIBERO-Plus (Camera, Robot, Language 等)、VLABench (In-dist., Category, Commonsense 等)
  • 主要评估指标：成功率、Intention Score (IS)、Progress Score (PS)、推理延迟
  • 在 LIBERO 基准上，Gist 策略达到 98.9% 的平均成功率，超越最强基线 ACoT-VLA (98.5%)。
  • 在 LIBERO-Plus Language 套件中，成功率达到 85.6%，比最强基线高出近 6%。
  • 使用 Gist 策略在单张 NVIDIA A6000 GPU 上的推理延迟仅为 169.5 ms/action chunk，相比 FastWAM-IDM 实现了 6.38 倍 加速，并分别比 FastWAM (1-step) 和 ImageWAM 快 1.78 倍 和 1.55 倍。
