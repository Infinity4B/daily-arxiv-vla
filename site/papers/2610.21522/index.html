Card 03 核心贡献

核心贡献

  • 提出两级在线策略蒸馏框架，通过在被学生诱导的环境状态和动作生成状态上施加教师监督，整合领域专精的基于流的 VLA 模型。
  • 在共享的 π0.5 学生模型上实现跨域能力整合，在 LIBERO、Meta-World、CALVIN 三个基准的所有聚合指标上超越 SFT 初始化、Action Loss OPD 与 Teacher-rollout SFT。
  • 通过匹配对照实验刻画了监督目标（速度 vs. 端点动作）与联合输入来源（学生诱导 vs. 教师诱导）各自的作用。
  • 学习曲线表明局部速度监督相比端点匹配具有持续优势，并给出套件级结果与领域权重对比，揭示迁移能力在任务间的分布规律。
Card 04 方法描述

方法描述

  • 从联合 SFT 初始化的共享学生 π0.5 出发，冻结各领域专家教师（π_LIBERO、π_MetaWorld、π_CALVIN），教师仅用于训练阶段。
  • 环境级在线监督：固定当前学生快照 θ̄_r，在各领域执行学生策略采集上下文 c ~ d_k^π，成功与失败回合均保留，由对应领域教师提供监督标签。
  • 流状态级在线监督（Velocity Loss）：在学生生成的动作流轨迹中间状态 x ~ q_{θ̄_r,τ}(·\|c) 上查询领域教师，令学生速度场 v_θ 回归教师速度 v_k^T，即式 (2) 的 MSE 目标。
  • 关键设计使用 stop-gradient（sg）：上下文、中间状态与教师目标在更新时均固定，梯度只作用于学生局部速度预测，不回传穿过采样轨迹或环境交互。
  • 实现上对所有非终止求解器节点进行监督，并对选定时间步取平均；各领域损失先平均再加权，避免动作维度差异隐式影响领域权重。
  • 训练循环为采集—标注—优化交替：每轮各领域采集相同回合数，累积加权领域损失梯度后执行一次 AdamW 更新，更新后的学生成为下一轮采集快照。

Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO（四套件平均成功率）、Meta-World MT50（等权任务成功率）、CALVIN（平均完成长度与 Len-5 成功率）。
  • 主要对比方法：共享 SFT 初始化 π_θ₀、Action Loss OPD（学生环境采集 + 最终动作块匹配）、Teacher-rollout SFT（教师诱导环境与流状态 + 局部速度目标）。
  • Velocity Loss OPD 在所有聚合指标上最优：LIBERO-40 75.70%、Meta-World MT50 60.6%、CALVIN 平均长度 4.362、CALVIN Len-5 72.9%。
  • 相对 SFT 初始化，绝对成功率提升为 LIBERO-40 +22.55%、CALVIN 五指令序列 +33.4%（Len-5 由 39.5% → 72.9%）、Meta-World MT50 +22.6%。
  • 相对 Action Loss OPD 与 Teacher-rollout SFT，绝对成功率提升为 LIBERO-40 6.4–9.5%、CALVIN 9.7–18.3%、Meta-World MT50 3.2–4.2%。
  • 与 Action Loss OPD 相比：LIBERO +9.50 分、Meta-World +4.20 分、CALVIN 平均长度 +0.618 条指令，且在每个更新后评估点均占优。
  • 与 Teacher-rollout SFT 相比：LIBERO +6.40 分、Meta-World +3.20 分、CALVIN 平均长度 +0.288 条指令；CALVIN Len-5 领先 9.70 分，而首条指令仅领先 0.90 分。
  • 序列长度分析显示：更长的 CALVIN 序列获益更大（领先幅度从首指令的 3.4 分扩大到五指令的 18.3 分）；LIBERO-10 相对 Teacher-rollout SFT 提升 13.8 分，远高于其他三个套件的 1.6–5.8 分。
  • 领域权重消融：主权重 (1/4, 1/4, 1/2) 在每个聚合领域指标上均优于等权 (1/3, 1/3, 1/3)，其中 LIBERO-10 高出 29.0 个百分点；等权则在 Spatial 与 Goal 上更好。
  • 局限性：学生仍低于各领域专家（如 LIBERO-10 为 46.4% vs. 专家 97.0%），跨域动作语义（如夹爪坐标位置）不一致；混合来源变体因额外积分路径成本未被评估；每种方法仅单次训练运行评估。
