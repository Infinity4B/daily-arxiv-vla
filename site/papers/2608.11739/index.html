02论文概述

  • 提出 Galaxea G0.5，一种将机器人推理与动作统一在单一自回归（autoregressive）流中的视觉-语言-动作（VLA）模型
  • 反对当前主流 VLM‑as‑encoder 范式，主张让 VLM 本身作为决策者，直接在同一个 Transformer 解码器中生成推理文字和动作 token
  • 解决 VLM 在 VLA 中被降级为条件编码器，导致其推理、语言理解等能力无法直接作用于动作生成的问题

03核心贡献

  • 设计了一种可学习的跨实施例动作分词器（ActionCodec），将不同机器人形态的异构动作映射到统一 token 词汇表，并支持稀疏预测（仅生成活跃的关节组）
  • 引入原生链式思考（Chain‑of‑Thought），将任务分解、物体定位、运动轨迹、动作提示等推理目标与动作 token 交织在同一自回归序列中训练，推理时可按需切换
  • 提出视觉记忆模块，通过因子化时空注意力在视觉编码器中注入多帧历史信息，提升长时序任务的鲁棒性
  • 在一个 2B 参数的 VLM（Qwen3.5‑2B）基础上进行大规模预训练，并在 7 个独立评估场景（真实机器人微调、DROID 零样本迁移、BEHAVIOR 长时程挑战、Pick‑and‑Place 语言跟随、LIBERO、RoboTwin 2.0、SimplerEnv）中取得领先结果

04方法描述

  • 基于 Qwen3.5‑2B 的 VLM，所有输入（多视图图像、任务指令、本体感知、实施例标识）和输出（推理文本、动作码）序列化为单一条目，使用下一个 token 交叉熵损失联合训练
  • 动作分词：将机器人按运动部件（左臂、右臂、下体等）分组，每组用残差向量量化（RVQ）编码为固定数量的离散 token，并加入时序对比损失以保持一致性
  • 原生 CoT：在训练时从 8 种 CoT 模板（无 CoT、子任务、边界框、轨迹、动作提示等）中随机采样，让模型学会在生成动作前产生可选的推理 token
  • 视觉记忆：在 ViT 中每 4 层插入分解的空间和时间注意力，融合多帧历史；训练时随机丢弃历史帧以防止过拟合
  • 推理时，自回归生成的动作码由 ActionCodec 解码为连续控制指令，并可选附加一个流匹配（flow‑matching）头用于加速推理

05数据集与资源

  • 预训练数据：覆盖 14 种机器人实施例 的异构操作数据集，统一映射到 27 维动作空间；同时混入大规模网络 VQA 数据以保持语言能力
  • 使用自动标注管线生成多粒度语义、物体边界框和末端轨迹等标注，用于 CoT 监督
  • 模型规模：基于 Qwen3.5‑2B，约 2B 参数
  • 训练资源：使用 AdamW 优化器，单阶段预训练至收敛，具体 GPU 数量未明确说明

06评估与结果

  • DROID 零样本迁移：在未见过的 Franka 环境和物体上，后训练 G0.5 平均成功率 82.5%，远超 π0.5‑DROID（57.5%）和 MolmoAct2‑DROID（52.0%）
  • 真实机器人微调：在 R1‑Lite/R1‑Pro 双手机器人上，G0.5 达到 76.7% 成功率，对比 π0.5 的 53.3% 和 GR00T‑N1.7 的 24.4%
  • 长时程 BEHAVIOR Challenge：使用单一策略，G0.5 在 50 项家庭任务中取得 31.4% 的任务成功分数，超过 π0.5（26.3%）和比赛冠军方案（26.1%）
  • 仿真基准：LIBERO 平均 98.9%，RoboTwin 2.0 平均 93.3%，SimplerEnv‑Bridge 平均 87.3%，均达到或超过现有最优方法
  • 语言跟随：在 Pick‑and‑Place 基准上，G0.5 的语言跟随率显著优于 VLM‑as‑encoder 基线
  • CoT 与动作头分析：零样本探针显示，使用 CoT 能提升长时程指令的 grounding 与执行，且自回归动作头比流匹配头更紧密地跟随 CoT 指导
