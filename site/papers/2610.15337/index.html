Card 03 核心贡献

核心贡献

  • 提出 CoLA（Coordination via Learned Adapters），在每台智能体的冻结 VLA 骨干之上训练三个模块：潜消息编码器、伙伴消息解码器、协调条件动作分块头，实现完全去中心化的执行。
  • 通过消息置零消融实验（同一架构、同一训练配方，仅令消息为零）因果隔离通信通道的贡献，证明通道只在任务相关信息私有于单一智能体时才必要。
  • 在遮挡托盘交接任务上，CoLA 达 76.0% 成功率，而消息训练全程置零版本仅 1.3%；在共享顶视摄像头的两臂/三臂任务上，移除消息无显著影响。
  • 验证跨骨干泛化性：在冻结 π0.5 骨干上 CoLA 达到与 LoRA 微调基线相当的整体成功率（37.3% vs 34.7%），但可训练参数仅为后者的一小部分。
  • 提出将通信选择本身视为多机器人 VLA 系统的独立设计问题：通道可在已部署 VLA 策略上直接添加，而无需重新训练骨干。
Card 04 方法描述

方法描述

  • 将多机器人协作操作形式化为带通信的 Dec-POMDP-Com（无奖励函数，遵循模仿学习惯例），智能体仅接收局部观测和伙伴消息，采用反应式策略（条件于当前观测与伙伴当前消息）。
  • 冻结骨干：每个智能体使用预训练 VLA（Octo-Base 或 π0.5），参数全程冻结；特征可一次性离线缓存，训练模块只能选择与传输骨干已编码的信息。
  • 潜消息编码器 φ_enc：两层 ReLU MLP，将局部表示压缩为 64 维消息向量；对骨干特征施加 stop-gradient。
  • 消息解码器 φ_dec：为每个有序配对（j→i）学习独立映射，不跨发送方共享，三臂任务中 B 通过不同权重分别读取 A 与 C 的消息。
  • 协调动作头：将自身表示与解码后的伙伴嵌入拼接为 z_i，通过 FiLM 条件的 1D 时序 U-Net 预测动作块噪声，另设二元夹爪 logit 头（因连续预测会产生近常数输出）。
  • 动作分块：K=10 步、以 50 Hz 控制率开环执行（每块 0.2 s），策略每块查询一次，推理速率 5 Hz；测试时使用 DDIM 10 步去噪。
  • 训练目标：行为克隆损失（扩散噪声预测均方误差）加夹爪 BCE 分类损失（λ=0.25）；梯度经由通信通道端到端流动，编码器仅由伙伴的损失训练。
  • 拓扑路由：N=2 为直接点对点，N=3 为全连接（六个有向通道），各智能体结构对称、无中心枢纽。
Card 05 数据集与资源

数据集与资源

  • 全部环境在 MuJoCo 中仿真，物理步长 2 ms（500 Hz），控制抽稀 10，控制率 50 Hz。
  • 控制 6-DoF Trossen ViperX 300 机械臂（平行夹爪），每臂动作为 7 维（6 关节目标位置归一化至 [-0.9, 0.9] + 夹爪指令）。
  • 每智能体观测 256×256 RGB 手腕相机图像 + 7 维本体感知状态（6 关节角 + 夹爪开度）；顶视变体额外共享固定顶视相机。
  • VLA 骨干：Octo-Base（93M 参数），以及 π0.5（base checkpoint，约 3.3B 参数）；两者均整体冻结。
  • CoLA 可训练参数：14.5M（Octo-Base）、16.9M（π0.5），其中通信通道仅占 0.33M / 0.83M。
  • 训练成本：利用离线特征缓存，CoLA 训练不足 1 GPU 小时，而相同优化器预算的微调基线需 2–49 GPU 小时。
Card 06 评估与结果

评估与结果

  • 任务：遮挡托盘交接（颜色标记仅 A 可见）、两臂交接（仅手腕 / 共享顶视两种变体）、三臂交接链（A→B→C，共享顶视）。
  • 评估协议：交接任务每策略在 200 episode 块上评估（种子偏移 0/1000/2000/3000/4000），报告均值 ± 标准差；遮挡托盘任务固定交接位置、仅随机化隐藏颜色，单种子 150 episode，报告 95% Wilson 置信区间。
  • 基线：独立去中心化策略（head-only / 全微调）、集中式策略（head-only / 全微调，作为特权参考）、消息置零的 CoLA、π0.5 上的 LoRA 微调基线。
  • 主要结果（Q1）：CoLA 在全部四个任务上优于所有去中心化基线——遮挡托盘 76.0% vs 22.7%；手腕交接 74.8% vs 43.8%；顶视两臂交接 90.6% vs 68.3%；三臂交接链 63.5% vs 20.5%；并在两臂交接上接近集中式全微调（90.6% vs 92.1%）。
  • 通道必要性（Q2）：消息置零使遮挡托盘从 76.0% 崩至 1.3%、手腕交接从 74.8% 降至 64.3%，但在共享顶视视角时无显著影响（90.6% vs 88.3%；63.5% vs 60.0%，均在种子间波动内）。
  • 通道内容探测：CoLA 在放置发生时选择正确托盘的比例为 85.7%，而 head-only 基线仅 26.4%（随机水平 33.3%）。
  • 团队规模与骨干泛化（Q3）：三臂时 CoLA 相对去中心化全微调的优势扩大至 31.9 个百分点（两臂仅 8.2）；在冻结 π0.5 上 CoLA 整体成功率 37.3% 与 LoRA 微调 34.7% 相当，而选择正确托盘为 71.8% vs 基线的 34.7%（后者放置臂从不见颜色标记，等同随机）。
