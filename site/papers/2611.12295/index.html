02论文概述

  • 论文提出一种用于多机器人协作的主动上下文共享框架，解决机器人自身视角部分可观测性问题，使机器人能够利用伙伴的互补观测进行决策。
  • 核心思想是让机器人选择和编码任务相关的信息进行共享，而非被动传输原始观测或通用视觉特征，从而在有限通信预算下支持紧密耦合的协作操作。
  • 采用两阶段训练范式：第一阶段进行任务导向的上下文压缩，第二阶段将紧凑上下文集成到预训练视觉-语言-动作（VLA）策略，并通过下游动作监督联合优化共享表征与策略。

03核心贡献

  • 提出主动上下文共享框架：两阶段训练，将每个机器人局部观测编码为紧凑的、任务条件的潜在表示，并集成到伙伴的动作策略中，通过下游动作监督联合优化。
  • 提出任务导向的多机位上下文编码：使用可学习查询聚合多相机视觉特征，结合任务指令生成固定预算的上下文 token；采用任务导向的未来预测和软任务进度对应学习，保留预测性视觉信息并促进任务间判别性和任务内时间连续性。
  • 提出联合上下文优化与协作策略学习：将压缩上下文通过投影集成到预训练 VLA 策略的前缀中，支持可变 token 预算和双向共享；接收方的动作监督反向优化发送方的编码器，使共享表征适应协作决策需求。
  • 进行真实世界双机器人实验验证：在两个核心任务（遮挡目标选择、交替领导者-跟随者标记检索）及三个定性任务上系统评估，与不共享、通用视觉特征共享等基线对比，并进行通信预算和组件消融分析。

04方法描述

  • 使用两阶段训练：Stage 1 训练上下文编码器（Encoder）将多相机视觉特征和语言指令压缩为 K 个潜在 token；目标包括任务导向未来特征预测（加权预测误差，权重来自视觉-语言模型计算的任务相关 patch 相似度）和软任务进度对比学习（基于任务身份和执行进度构建亲和矩阵，进行双向软标签对比损失）。
  • Stage 2 将上下文 token 通过投影模块映射到 VLA 策略隐藏空间，作为附加条件与本地观测、任务指令、本体感受状态一起输入策略；策略输出动作序列。
  • 联合优化时，下游动作损失通过共享 token 反向传播到发送方的编码器，同时保留 Stage 1 辅助目标，实现表征与策略协调优化；对称双向共享，无需预先定义主从角色。
  • 视觉和文本编码器保持冻结；未来预测解码器和对比投影头仅用于训练，推理时丢弃，仅交换上下文 token。

05数据集与资源

  • 论文未使用公开数据集，使用自收集的真实机器人演示数据，涵盖遮挡目标选择、交替领导者-跟随者标记检索等任务；训练时将双机器人演示整合为统一数据集。
  • 机器人平台为两台 Astribot S1 机器人（双机协作操作）。
  • 模型基于预训练 VLA 策略 π0.5（具体参数量未披露）；上下文编码器 token 预算默认 K=32，每个 token 维度 1152（FP32 4字节），据此计算通信成本。
  • 训练资源未在论文中明确提及（无 GPU/TPU 细节）。

06评估与结果

  • 评估环境为真实世界双机器人协作任务：遮挡目标选择（18 次试验）和交替领导者-跟随者标记检索（48 次试验，覆盖所有颜色组合和双向领导角色），另有三个定性任务（冰箱补货、盒子组装、毯子折叠打包）。
  • 主要指标包括目标箱选择准确率、颜色匹配准确率（双向）、正确触发率、序列成功率以及归一化过程得分（Process Score）。
  • 遮挡目标选择：Ours-Joint 达到 88.9% 准确率，显著优于 No Sharing（38.9%）和 Generic SigLIP（72.2%），且仅用 32 个 token（对比 SigLIP 160 token，通信量降低 80%）。
  • 交替领导者-跟随者：Ours-Joint 和 Generic SigLIP 均达到 100%（颜色匹配、触发、序列成功率全满分），No Sharing 仅 16.7%/33.3% 颜色匹配、0% 序列成功；Ours-Joint 以 32 token 匹配 SigLIP 160 token 性能。
  • 消融实验：移除对比学习目标导致 Process Score 从 100% 降至 68.9%，移除未来预测降至 96.7%，表明任务进度对比学习在该任务中贡献更大。
  • 联合优化 vs 冻结上下文：Ours-Frozen 为 83.3%，Ours-Joint 为 100%，证明下游动作监督进一步提升了共享表征质量。
  • 通信预算实验：K=4/16/32 时 Process Score 分别为 90.5%、97.6%、100%，说明任务相关信息可高度压缩，且 32 token 是匹配高带宽参考的最小预算。
