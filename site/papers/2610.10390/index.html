Card 03 核心贡献

核心贡献

  • 提出 GeoCoTDrive，一个显式的几何思维链框架，用于 VLA 端到端自动驾驶，通过"2D 推理 → 局部 3D 检索 → 轨迹生成"的流程桥接语义推理和几何规划。
  • 提出 规划相关接地（planning-relevant grounding），一种新的区域级接地任务，聚焦于直接影响自车规划决策的局部关键线索，超越了传统语义目标检测式接地。
  • 构建 PlanningGrounding，一个 VQA 风格的半自动标注数据集，包含 146K 条规划相关接地标注，覆盖 5 个规划相关类别，并含 0.6K 人工精修测试样本。
  • 引入自回归几何检索机制，根据模型预测的接地区域从几何基础模型中采样局部化 3D 特征，以几何 token 形式插入自回归上下文，条件化轨迹生成。
Card 04 方法描述

方法描述

  • 模型流程：先用 VLM 自回归生成规划相关 2D 边界框（ℬ={b_i}），每个框对应一个决策关键线索；然后利用这些框从几何基础模型提取的稠密特征图 G=f_geo(I) 中采样局部几何特征。
  • 几何检索：在每个接地框内构造 K 个规则网格采样点，通过双线性插值提取特征，经 MLP 对齐头 f_align 投影到 LLM 隐藏空间，形成几何 token Z_B，插入到接地输出后的自回归上下文中。
  • 训练目标：使用标准自回归语言建模目标 L_AR，在教师强制下对接地响应和轨迹响应进行监督；采用两阶段训练，阶段 I 更新视觉编码器和 LLM 进行完整 QA 训练，阶段 II 冻结视觉编码器并联合优化 LLM 与几何对齐头。
  • 基座模型：nuScenes 和 Bench2Drive 采用 LLaVA-1.5-7B（遵循 OmniDrive/ORION 设置）；NAVSIM 采用 Qwen2.5-VL-3B；轨迹解码在 nuScenes/NAVSIM 用自回归文本解码，在 Bench2Drive 用扩散规划头。
  • 几何基础模型：使用冻结的 DepthAnythingV3（稠密单目深度）和 VGGT（3D 感知潜在表示）作为几何特征提取器。
Card 05 数据集与资源

数据集与资源

  • PlanningGrounding：自建的 VQA 风格接地数据集，146K 标注，覆盖 5 类规划相关区域：critical-object（关键目标）、road-boundary（道路边界）、conflict-area（冲突区域）、occluded-unknown-area（遮挡未知区域）、dense-object-area（密集目标区域）。
  • 原始驾驶数据来源：nuScenes、NAVSIM、Bench2Drive 三个基准数据集。
  • 标注方式：使用 Gemini-3.1 大模型进行半自动标注，经自动格式校验和人工验证。
  • 基座 VLM：LLaVA-1.5-7B、Qwen2.5-VL-3B。
  • 几何基础模型：DepthAnythingV3、VGGT（冻结权重）。
  • 代码已开源：https://github.com/TabGuigui/GeoCoTDrive
Card 06 评估与结果

评估与结果

  • nuScenes 开放环规划（遵循 OmniDrive 协议）：GeoCoTDrive 在 L2 误差（1s/2s/3s）为 0.14/0.29/0.53m，碰撞率 0.00/0.07/0.27%，交叉率 0.37/1.44/4.25%，碰撞率和交叉率平均表现优于对比方法，安全性指标显著领先。
  • NAVSIM 闭环规划（navtest，非反应式模拟）：GeoCoTDrive 使用 Qwen2.5-VL-3B 基座，PDMS 达 87.6，超过 Qwen 基线（85.9）、AutoVLA（80.5）等，且在 NC（98.4）、DAC（95.6）、EP（81.6）等子项上取得最佳结果。
  • Bench2Drive 闭环规划：GeoCoTDrive 取得 Driving Score 78.68、Success Rate 55.42，优于 ORION（77.74/54.62）和 SpaceDrive（78.02/55.11）。
  • PlanningGrounding 接地评估：GeoCoTDrive 在 R@0.3/0.5/0.7 为 56.82/42.73/21.04，AP 39.89，mIoU 38.93，全面优于 LLaVA-1.5-7B、Qwen2.5-VL-3B 和 OmniDrive 基线。
  • 消融实验：① 相比全局几何 token 融合，GeoCoT 检索局部化几何先验带来更一致的规划提升；显示"接地区域条件化"的几何比全局注入更有效。② 使用 PlanningGrounding 标注优于使用感知标签（perception labels），尤其在碰撞率等安全指标上。③ 可视化分析显示，GeoCoT 的几何 token 响应更聚焦于决策关键区域，而全局融合的响应分散。
