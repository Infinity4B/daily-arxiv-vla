Card 02 论文概述

论文概述

  • 视觉-语言-动作 (VLA) 模型在新的工作空间中提升性能仍需要昂贵的、针对特定环境的动作标注数据（如人类遥操作）。

  • 系统通过重建环境、利用大语言模型生成符号目标和成功标准，并使用任务与运动规划 (TAMP) 生成可行的机器人轨迹，最终渲染为图像-动作对用于策略微调。
Card 03 核心贡献

核心贡献

  • 提出一种可扩展的数据收集框架，将部署工作空间的短视频和语言指令转换为机器人训练数据，无需任务特定的人类演示。
  • 通过测量模拟和真实机器人策略性能之间的相关性，验证了重建的工作空间作为数据源的有效性。
  • 证明了随着生成数据量的增加，真实世界策略性能得到提升，且这一过程无需额外的人力演示，数据扩展成本远低于人类遥操作。
Card 04 方法描述

方法描述

  • 流程分为四个阶段：数字孪生重建、基于 TAMP 的演示合成、演示增强、渲染与数据集构建，最后进行策略微调。
  • 数字孪生重建：使用 COLMAP 和 3D Gaussian Splatting 重建场景，通过机器人外观自动恢复 SIM(3) 变换以对齐到机器人坐标系，并使用 SAM3 和 TRELLIS 分解资产。
  • 演示合成：使用 GPT-4o-mini 将指令转换为预定义的符号目标和成功标准。使用 cuTAMP 进行基于 GPU 并行的轨迹规划，结合 GraspGen 进行抓取采样，并用 cuRobo 进行无碰撞运动规划。
  • 演示增强：采用 MimicGen 风格的增强方法，直接从计划中读取子任务边界，对物体位姿进行随机化并应用物理合理性过滤器。
  • 渲染：通过 Gaussian Splatting 重放记录的状态，渲染固定相机和腕部相机的 RGB 观测图像，并写入 LeRobot 数据集格式。
Card 05 数据集与资源

数据集与资源

  • 使用 xArm7 机器人和 Intel RealSense D435i 相机（固定外部视角和腕部视角）。
  • 评估任务为 BlockIntoBowl 和 FruitPacking。
  • 评估的策略模型包括 SmolVLA, $\pi_{0.5}$ 和 Diffusion Policy。
  • 对比了 100 条人类遥操作数据和 1000 条 DREAM 自动生成数据。
  • 训练资源：策略训练使用 NVIDIA GB200 GPUs，其他计算阶段使用 3 张 NVIDIA RTX A6000 GPUs (48GB)。
Card 06 评估与结果

评估与结果

  • 评估指标包括任务成功率（15次试验）、有效轨迹比率、规划成功率、增强接受率以及人力时间对比。
  • Sim-to-Real 相关性：重建模拟器保持了策略排名，BlockIntoBowl 上的 Pearson 相关系数为 r=0.98，FruitPacking 上为 r=0.99，平均最大排名违反 (MMRV) 为 0.000。
  • 数据扩展性：DREAM 具有固定初始成本（36-95分钟）和极低的边际成本，当数据量超过 73-168 条时，生成成本低于人类遥操作。
  • 性能表现：在 BlockIntoBowl 任务上，$\pi_{0.5}$ 使用 1000 条生成数据达到 93.3% 成功率，优于 100 条遥操作数据的 86.7%；SmolVLA 达到 80.0% 对比 73.3%。在 FruitPacking 任务上，$\pi_{0.5}$ 达到 86.7% 对比 80.0%。
