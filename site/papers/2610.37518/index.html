02论文概述

  • 提出 World Dreamer v5-lite，一个面向多机器人协作的世界动作模型，解决了现有多数 VLA 和 world-action 模型仅针对单机器人的局限
  • 核心问题是：多机器人共享工作空间时，观测分布在不同相机视角、机器人形态各异、且单个机器人的视角常常不完整，简单拼接多视角无法建立空间对应关系
  • 模型以共享世界状态 φ 为中心，将来自多个标定相机的观测特征统一组织在工作空间坐标系中，供所有机器人查询读取，实现“多对一、一对多”的信息流动

03核心贡献

  • 提出多机器人操作框架 World Dreamer v5-lite：由预训练视频编码器提取的标定多视角特征构成共享世界状态 φ，所有机器人读取同一状态；每机器人一个可学习查询，通过姿态感知注意力交换信息
  • 提出共享世界状态 φ 构建方法：利用相机内外参将图像 patch 特征放置到 3D 工作空间坐标，写入 XY/XZ/YZ 三个正交平面，采用可见性门控更新，状态尺寸不随相机数量增加而变化
  • 提出遮挡视角协同训练策略：在训练中同时从两条视觉分支（VLM 场景前缀和 φ）中隐去选定的相机视角，但保留所有机器人的动作监督，鼓励机器人利用队友共享的观测
  • 设计分离式动作流解码器：每个机器人保持独立动作流，仅通过查询进行位姿感知的信息交互，兼容异构机器人形态
  • 实验上在 RoboFactory 达到 74.0% 平均成功率（超最强基线 23.7 个百分点），真实机器人任务达 78.8%（超最强基线 13.8 个百分点）

04方法描述

  • 视觉-语言条件化：以 Qwen3-VL 为 VLM 骨干，指令与当前图像形成共享前缀，每机器人槽位跟随一个可学习查询（共享查询嵌入 + 槽位嵌入），一次前向传播即可为所有机器人提供场景上下文和场景前缀 KV 缓存
  • 视频编码器：因果视频 VAE + 预训练视频模型编码器处理 T_o=3 个观测隐变量步长；训练时附加 T_f=2 个加噪未来步长用于辅助视频流预测（前缀非对称注意力掩码防止观测 token 关注未来），推理时无需视频生成
  • 共享世界状态构建：有深度时将 patch 映射到测量点，无深度时沿视线取 S=8 个候选点；特征与几何嵌入融合后通过加权双线性散射写入 XY/XZ/YZ 三个正交平面（G=16、C_f=256），并用可见性门控更新避免擦除暂时不可见区域
  • 动作解码器：基于条件流匹配，L=36 层，每层按“读取-解码-通信”顺序执行三个模块：Field Injection Block（查询交叉注意力读取 φ，并偏向自身相机位置）、Scene Decoder Block（动作流因果地条件于 VLM 场景前缀 KV 缓存）、Agent Interaction Block（用相对位姿描述子 P_ij ∈ R^10 经 MLP 生成注意力偏置，实现位姿感知的机器人间查询交换）；动作流训练采用流匹配，动作块长度 H=30
  • 遮挡视角协同训练：随机屏蔽某机器人全部相机或随机视角子集（在 VLM 和状态构建两条视觉路径中同步屏蔽），但保留所有机器人的动作监督，迫使模型利用其他机器人的共享观测
  • 训练目标：L = 0.5·L_act + 0.2·L_future + λ_field·L_field，包含加权的流匹配速度误差、未来视频隐变量预测损失和场重建损失；推理仅需 5 步 Euler 积分，无需视频生成

05数据集与资源

  • 预训练语料：超过 10,000 小时交互轨迹，涵盖 20 种模拟机器人类型、RoboFactory 轨迹及 LeKiwi/OpenArm 真实机器人轨迹；单臂与双臂配置、超过 60 种任务类型
  • 评估基准：RoboFactory（Place Food 双机器人、Camera Alignment 三机器人、Take Photo 四机器人，各 100 个场景配置）；RoboCasa365（365 个家庭任务、2,500 个厨房场景，官方 Human300 数据集微调，50 个评测任务分 Atomic-Seen / Composite-Seen / Composite-Unseen 三组）；4 个真实机器人任务（2 个 LeKiwi 双机任务 + 2 个 LeKiwi+OpenArm 异构任务，各 100 次试验）
  • 模型配置：VLM 骨干初始化自 Qwen3-VL；解码器宽度 d=1024、L=36 层、动作块长度 H=30、世界状态 φ ∈ R^(3×16×16×256)；使用 DeepSpeed ZeRO Stage 2、bfloat16 精度训练（原文截断部分未提供具体 GPU 数量与总参数量）

06评估与结果

  • 评估环境与基准：多机器人协作基准 RoboFactory（2-4 个智能体任务）、家庭任务基准 RoboCasa365（50 个任务，含零样本 Composite-Unseen）、真实机器人任务（同构 LeKiwi 团队与异构 LeKiwi+OpenArm 团队）
  • 评估指标：任务成功率；RoboFactory 与真实任务取任务的无权平均，RoboCasa365 取 50 个任务的整体平均
  • 基线：Diffusion Policy、ACT、π₀.₅、Fast-WAM、Global/Local GauDP；RoboCasa365 上对比 PatchWAM、ABot-M0.5、PRTS、RLDX-1、GigaWorld-Policy 0.1 等（结果取自官方排行榜）
  • RoboFactory 结果：平均成功率 74.0%，比最强基线 π₀.₅（50.3%）高 23.7 个百分点；三个任务分别 94%/78%/50%，全面领先
  • RoboCasa365 结果：总体 58.08%（Atomic-Seen 80.8%、Composite-Seen 60.0%、Composite-Unseen 30.6%），比最佳基线 PatchWAM（47.6%）高 10.48 个百分点
  • 真实机器人结果：四个任务平均 78.8%（block transfer 88%、cap unscrewing 70%、starfruit bagging 76%、block passing 81%），比最强基线 π₀.₅（65.0%）高 13.8 个百分点；在同构与异构机器人团队上均验证了有效性
