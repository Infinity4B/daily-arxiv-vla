02论文概述

  • 提出EgoGenesis，一个以自我为中心的世界-动作模拟器，旨在生成可控、高质量的机器人操作视频，解决真实自我中心操作数据收集成本高、场景/动作/形态多样性稀缺的问题
  • 针对现有自我中心视频生成器的两类几何失效问题：无明确几何约束时会出现不受控的相机运动和末端执行器轨迹偏离，动作条件生成时会出现场景/物体漂移，无法同时实现可控的相机与末端执行器轨迹、稳定的场景和物体一致性
  • 生成的视频-动作对可用于扩充真实操作数据集，提升下游具身世界-动作模型（WAM）的泛化性能

03核心贡献

  • 提出Online Anchored Projective Memory (OAPM)，一种带在线刷新机制的锚定投影式3D场景记忆，通过不可变的第一帧锚定槽和可定期更新的近期状态槽，维持自回归生成过程中的场景稳定性
  • 提出Action-3D Rotary Position Embedding (A3D-RoPE)，将相机感知的末端执行器/骨架度量3D几何信息注入骨架到视频的交叉注意力，实现动作对齐的精确视频控制
  • 验证了EgoGenesis生成的轨迹作为数据增强手段，可显著提升下游WAM在单臂和双臂真实机器人操作任务上的分布外泛化性能

04方法描述

  • 整体基于预训练视频生成先验构建分块式自回归DiT模型，包含三个条件流：加噪视频块、3D场景记忆、动作控制条件，同时接入文本和图像编码器提供任务与外观上下文
  • OAPM创新点：维护两个3D场景槽，不可变的第一帧锚定槽$\mathcal{M}_a$保留稳定场景先验，可定期刷新的近期状态槽$\mathcal{M}_r^b$跟踪当前交互状态；生成每个视频块前，用预训练VGGT-$\Omega$编码两个槽的特征，通过门控交叉注意力让隐藏状态同时读取稳定锚和最新交互状态，避免场景漂移
  • A3D-RoPE创新点：将骨架或末端执行器关节栅格化到视频潜在patch网格，通过相机轨迹反投影得到锚定帧的度量3D坐标；仅对骨架覆盖的有效动作patch的Q、K通道施加3D旋转变换，背景token保持不变，将动作几何信息注入交叉注意力
  • 训练采用两阶段策略：第一阶段6k步SFT使用预处理的记忆槽，第二阶段6k步自回归训练使用生成的最新帧作为近期记忆槽

05数据集与资源

  • 训练数据集：源平衡的210K剪辑训练语料，来自EgoDex、AgiBot、RoboTwin、Real-world Ego、DexJoCo五个数据源
  • 评估数据集：保留的held-out基准，包含机器人夹爪、末端执行器轨迹、人手骨架三类条件，所有视频统一标准化为81帧、16FPS、832×480分辨率
  • 模型规模：基于Wan2.2-5B-Control视频生成模型构建的自回归DiT模型
  • 训练资源：模型训练使用8块NVIDIA A100 GPU，下游真实机器人推理和World Action Model训练测试使用8块NVIDIA H100 GPU

06评估与结果

  • 评估环境：对比基线包括通用视频生成模型（Wan2.1-14B-InP、Wan2.2-5B-Control、Cosmos3-Nano）、自我中心专用视频模型（EgoHOI、Mask2IV、EgoSim-14B、RynnWorld-TeleOp）；下游评估覆盖4个双臂、4个单臂真实机器人操作任务
  • 主要评估指标：生成质量侧包括PSNR（↑）、SSIM（↑）、LPIPS（↓）、关键点误差Kpt.Err（↓）、物理合理性Phys.Faith（↑）、主体一致性、背景一致性；下游任务侧采用任务成功率（SR），分为分布内（ID）和分布外（OOD）评估
  • 关键实验结果：

- 生成质量上，EgoGenesis在7项指标中的6项位列第一，PSNR达21.8609，Kpt.Err低至0.0501，Phys.Faith达0.8278，在视觉保真度、动作对齐、物理合理性上全面优于所有基线

- 消融实验验证了双组件的独立增益：仅添加OAPM的近期槽即可将PSNR从20.4135提升至21.8609，LPIPS从0.2533降至0.2399；A3D-RoPE在80帧长时序rollout中，深度误差相对RoPE降低79.30%，相机误差降低78.26%

- 数据增强效果：仅需400条EgoGenesis生成轨迹扩充400条真实轨迹，即可将单臂任务OOD成功率从77%提升至84%，双臂任务从53%提升至70%，分布内到分布外的性能损失分别从7、19个百分点降至4、6个百分点
