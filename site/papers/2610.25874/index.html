02论文概述

  • 论文提出 Vision-Language-Delta-Action (VLDA)，面向机器人操作任务，用紧凑的 Delta 表示任务相关的状态变化，作为视觉语言理解与动作生成之间的可执行过渡接口。
  • 针对现有 VLA 直接学习 observation-to-action 映射导致语义到动作学习负担过重，以及 WAM 预测完整未来状态浪费容量的问题。
  • 目标是在训练时利用未来观察信息，在部署时仅依赖当前观测和语言指令，提升长时程一致性、鲁棒性和泛化性。

03核心贡献

  • 提出 VLDA 新范式：将完整未来状态预测重构为紧凑的可执行 Delta 过渡建模。
  • 设计统一 Delta 学习目标：Local Transition Filter (LT-Filter) 关注稀疏、任务相关的局部状态变化；Global Transition Anchor (GT-Anchor) 保持 Delta 与未来整体变化趋势一致。
  • 提出 Delta-Driven Action Refinement (DDAR)，包含 Delta-Seeded Action Flow (DSAF) 和 Delta-to-Action Manifold Grounding (DAMG)，将 Delta 注入动作去噪过程，形成 understanding-transition-execution 闭环。
  • 在开源框架 LoongForge 中实现统一两阶段训练，并验证其优于直接动作预测与完整未来状态建模方法。

04方法描述

  • 将动作生成分解为 \(p(\mathbf{A}_t\mid s_t,l)=\int p_\theta(\Delta_t\mid\mathbf{h}_t)\,p_\phi(\mathbf{A}_t\mid\mathbf{h}_t,\Delta_t)\,d\Delta_t\)，由 World Expert 预测 Delta，Action Expert 基于 Delta 和上下文生成动作。
  • 使用 Conditional Flow Matching 建模 Delta 和动作；Delta 生成采用 x-prediction 参数化，视觉编码使用在线编码器 \(E_{\mathrm{on}}\) 和 EMA 教师编码器 \(E_{\mathrm{ema}}\)。
  • LT-Filter：从当前与未来观测中提取密集视觉特征，选择 Top-K 个变化最剧烈的空间 token，投影到紧凑 Delta 空间；采用 Sinkhorn 熵正则化传输实现置换不变的集合匹配损失。
  • GT-Anchor：对当前和未来视觉特征做自适应池化，构造全局粗粒度迁移锚点，将预测 Delta 上投影后与锚点进行集合匹配，保持全局一致性。
  • DDAR：DSAF 将 Delta 聚合为动作空间偏置，形成有偏的动作流初始化，并引入 Delta 前缀 token 参与动作去噪；DAMG 通过 InfoNCE 对比学习将 Delta token 与真实动作 token 对齐，增强 Delta 的可执行性。
  • 采用两阶段训练：阶段一学习 Delta 过渡表示，阶段二进行 Delta 驱动的动作细化。

05数据集与资源

  • 使用 LIBERO、RoboTwin 2.0 和扩展的 LIBERO-Plus 模拟基准；LIBERO-Plus 覆盖七类扰动维度（相机、机器人、语言、光照、背景、噪声、布局）和四类任务套件（空间、物体、目标、长程）。
  • 真实世界平台包括 GALAXEA R1 Lite、AgileX Cobot Magic 和 ALOHA 平台。

  • 训练资源：未在提供片段中披露 GPU/TPU 具体型号与数量；使用 LoongForge 开源框架及分布式训练基础设施。

06评估与结果

  • 在 LIBERO-Plus 上以零样本设定进行 10,030 次 rollouts，并与 OpenVLA、UniVLA、WorldVLA、DreamVLA、GuidedVLA、π0、π0.5 等基线比较。
  • 主要评估指标为任务成功率（%），报告跨扰动维度和任务套件的平均成功率。
  • 关键结果：VLDA 平均成功率达到 84.5%，显著优于 GuidedVLA 75.4%、DreamVLA 69.9%、OpenVLA-OFT 69.6%、π0.5 73.6% 等基线。
  • 细分结果中，VLDA 在 Language 84.0%、Light 96.0%、Background 95.5%、Noise 89.4%、Spatial 89.6%、Object 89.8% 等维度表现突出；在 Robot 75.3%、Camera 72.4% 等维度也保持较强性能。
  • 论文还包含消融实验，验证 Transition Paradigm、LT-Filter、GT-Anchor、DSAF 和 DAMG 等组件的贡献；真实世界实验用于评估跨平台泛化与长时程一致性。
