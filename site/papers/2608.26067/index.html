Card 02 论文概述

论文概述

  • 提出 StreamPI，一个流式多模态时序建模框架，旨在为单帧范式的 Vision-Language-Action（VLA）模型赋予时间推理能力，解决现有模型（如 π0.5）无法利用历史观测、空间感知精度不足的问题
  • 核心思路是将每个（视觉观测，语言指令）对视为原子时间单元，通过指令锚定建模保持任务目标的持续感知，同时利用 LLM 的长度外推能力实现零新增参数的时序扩展
  • 针对训练与真实部署之间的同步/异步失配问题，引入随机间隔流式训练策略，提升模型对帧率波动的鲁棒性
Card 03 核心贡献

核心贡献

  • 提出 StreamPI 流式多模态时序建模框架，将（图像，文本）对作为原子时间单元，结合指令锚定建模实现任务执行期间持续的语义锚定
  • 提出 随机间隔流式训练策略（Random-Interval Streaming Training），通过帧间间隔随机化弥合同步训练与异步真实机器人部署之间的差距
  • 利用 LLM 长度外推能力，无缝继承 π0.5 全部预训练权重，不引入任何额外参数，同时支持灵活的单帧与多帧推理
  • 引入 KV-Cache 流式推理机制，通过缓存历史帧的 Key&Value 表示，使推理计算开销与时间尺度无关
  • 在真实机器人任务（记忆依赖与精确感知场景）及 LIBERO、CALVIN 仿真基准上全面超越 π0.5 基线
Card 04 方法描述

方法描述

  • 指令锚定时序建模：将每个时间步的输入构造为原子时间单元 u_t = (V_t, l_t)，单元内部采用双向注意力实现图像与文本的跨模态融合，单元之间采用因果注意力建模时序依赖，防止长时程中的指令遗忘
  • 参数无关时序扩展：通过重构注意力掩码实现层次化注意力模式，仅扩展输入序列并分配扩展位置嵌入，完全保留预训练模型的视觉-语言表征
  • 随机间隔采样：训练时在基础帧间隔 δ̄ 上添加均匀随机扰动 ε~U(-Δ,+Δ)，暴露模型于多样化的时间间隔分布
  • 时间掩码策略：随机掩码最早 k 帧（k∈{0,...,T-1}），模拟流式推理的增量观测模式
  • 流式推理：仅编码新到达的帧，通过跨注意力查询缓存的历史表示，避免对过去帧的重复计算，支持长时程操作
Card 05 数据集与资源

数据集与资源

  • 评估基准：LIBERO（含 Spatial、Object、Goal、Long 四个任务套件，每套 10 个任务、每任务 50 次试验）及 CALVIN 基准（最多连续 5 个任务的长序列操作）
  • 自建真实机器人评测任务：记忆依赖任务（Shell Game、Rolling Object Grasping）与精确感知任务（Pen Insertion into Narrow Bottle、Cup Insertion into Cup Sleeve）
  • 基础模型：π0.5 预训练 VLA 模型，完全微调且不引入新参数
  • 训练资源：8 张 NVIDIA H100 GPU；LIBERO 基准 batch size 256、30k 迭代；真实机器人任务 batch size 128、50k 迭代
  • 流式帧数：训练时 T=3/5，帧间隔 δ~U[3,7]；推理时仿真 δ=5，真实部署 δ~U[3,7]
Card 06 评估与结果

评估与结果

  • 真实机器人操作：StreamPI 在记忆依赖任务上大幅提升——Rolling Object Grasping 成功率提升 +36.6%、Cup Hiding and Retrieval 提升 +33.3%；在精确感知任务上 Pen Insertion into Narrow Bottle 提升 +26.7%、Cup Insertion into Cup Sleeve 提升 +32.0%
  • LIBERO 仿真基准：StreamPI（T=5）在四个套件上平均成功率 98.3%，较 π0.5（96.9%）平均提升 1.4%；其中 LIBERO-Long 提升最显著（+2.6%），LIBERO-Goal 提升 2.8%，充分验证长时程记忆与多帧感知的有效性
  • CALVIN 长序列基准：StreamPI（T=5）平均序列长度 4.547，显著优于 π0.5（4.313）和 MemoryVLA（4.090），在第 5 个子任务上仍保持 85.0% 的成功率（π0.5 为 79.5%，MemoryVLA 为 69.4%），展示了出色的长时程抗误差累积能力
  • 消融研究：双向帧内注意力与因果帧间注意力均贡献显著（T=5 时因果帧内注意力在 LIBERO-Long 上降 5.6%）；随机间隔训练较固定间隔在 T=3 和 T=5 下分别提升 1.1% 和 1.3%；T=5 训练的模型在 T=3 推理时仅轻微退化，在 T=1 时仍优于 π0.5 基线，体现良好的跨流形泛化能力
