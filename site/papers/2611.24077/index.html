02论文概述

  • 提出 AeroRSI，一个面向空中视觉语言导航（aerial VLN）的递归自我改进框架，让无人机策略从自身失败中迭代学习。
  • 解决现有 VLA 模型在闭环飞行中频繁失败的问题，这些失败需要动作级修复，但人类标注代价高昂、规则规划器不可靠、强化学习无法提供可执行的动作监督。
  • 核心思想：让失败策略通过自身后续飞行来评判候选修复动作，将弱监督（采样动作和规则提议）转化为可靠监督。

03核心贡献

  • 识别闭环飞行中自我改进的三个挑战：动作价值依赖后续飞行、首次失败掩盖后续失败、失败策略难以采样所需修复动作。
  • 证明让策略自我判断修复可将采样动作和规则提议转化为可靠监督，且验证的修复在后续回合保持有效。
  • 揭示递归必要性：新失败在已修复位置之后出现，且规则提议学到的动作会进入策略采样分布。
  • 提出 AeroRSI，包含三个模块：AFA（自适应失败锚定）、CVR（延续验证修复）、RRL（保持性修复学习），在 TravelUAV 上达到 SOTA，无需额外人工标注或推理成本。

04方法描述

  • AFA：在每个失败回合中按指数间隔放置探针，记录失败前多个时间尺度的状态，根据失败分布采样锚定，覆盖不同失败类型。
  • CVR：对每个锚点构建候选组（原始动作、策略采样动作、基于深度和目标的规则提议），通过从恢复的状态执行候选并让当前策略继续飞行来估计 Q 值，只有通过再现检查和确认检查的候选才被接受为验证修复。
  • RRL：通过交叉熵最大化验证修复动作的似然，同时加入行为保持项（在成功飞行状态上模仿当前策略输出）和修复重放（回放上一轮修复），防止策略漂移。

05数据集与资源

  • 数据集：TravelUAV，基于 AirSim 和 Unreal Engine 的空中 VLN 基准。
  • 训练集：7,611 条路线、11 个场景；测试集：Seen 1,418 条、Unseen Object 629 条、Unseen Map 958 条。
  • 模型：2B 参数 VLA（基于 Qwen3-VL-2B），使用 LoRA 微调。
  • 训练资源：论文未明确列出具体 GPU/TPU 硬件，但提到补充材料包含每轮成本。

06评估与结果

  • 评估环境：TravelUAV 测试集，指标包括导航误差（NE）、成功率（SR）、oracle 成功率（OSR）、路径加权成功率（SPL）和碰撞率（CR）。
  • AeroRSI (SFT init.) 三回合将总体 SR 从 46.4% 提升到 67.5%，碰撞率从 38.64% 降至 19.10%；优于 AeroDPO 基线 10.6 个百分点。
  • AeroRSI (DPO init.) 进一步提升总体 SR 至 69.9%，证明与偏好优化互补。
  • 消融实验表明：未验证的规则提议或采样动作效果差于验证版本；只看前两步的验证不如完整延续；缺乏行为保持或递归更新都会降低性能。
