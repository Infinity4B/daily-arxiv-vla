SLA: Scaling Spatial-Language-Action Model via Continual Pre-training

02论文概述

  • 论文提出 SLA（Spatial-Language-Action Model），一种通过持续预训练扩展空间-语言-动作模型的机器人基础模型
  • 旨在解决现有 VLA 模型主要继承 2D 视觉表示、缺乏 3D 空间理解的问题，将隐式空间对齐应用于持续预训练和下游后训练
  • 从预训练 π0.5 策略初始化，联合优化动作预测和中间视觉嵌入与冻结 3D 感知模型空间表示的对齐

03核心贡献

  • 提出 SLA 框架，在持续与后训练阶段采用外部空间监督对齐 VLA 视觉嵌入，增强空间智能
  • 构建并统一异构机器人演示数据集（约 170 万条轨迹、14,330 小时），支持跨本体、任务和场景的空间学习
  • 引入 自适应层选择 机制，通过特征依赖门控聚合多层 VLA 视觉嵌入，适应异构数据
  • 设计 OmniVGGT 作为外部 3D 感知模型，利用可用的相机标定和深度注释，处理不完整几何监督
  • 提出 状态丢弃 概率训练策略，防止对轨迹过拟合并鼓励依赖视觉线索

04方法描述

  • 模型架构基于预训练 π0.5 VLA 策略，通过外部冻结 3D 模型（OmniVGGT）生成空间表示作为对齐目标
  • 训练目标包含动作生成损失和空间对齐损失（余弦相似度），权重 α 控制对齐强度
  • 自适应层选择：为每个 token 学习 sigmoid 门控，聚合多个 Transformer 层的视觉嵌入，替换人工选择单层
  • 状态丢弃：训练时随机省略 proprioceptive 状态 token，迫使策略依赖视觉观测；所有辅助模块（外部 3D 模型、投影器、门控）仅在训练阶段使用，推理时保持原始架构

05数据集与资源

  • 持续预训练使用六个公开机器人数据集：InternData-A1、AgiBotWorld-Beta、RoboCasa365-Pretrain、RoboCOIN、DROID、MolmoAct，共约 1,713.9K 条轨迹、14,330 小时
  • 下游基准包括 LIBERO-Plus、RoboTwin 2.0、RoboCasa-Panda、RoboDojo-Real 及真实世界部署条件 A–H
  • 模型参数量未在论文中明确披露，基础模型为 π0.5；持续预训练使用 48 块 NVIDIA H100 GPU，耗时约 110 小时

06评估与结果

  • LIBERO-Plus：加权成功率 87.4%，在 7 个扰动维度上均优于 π0.5 基线
  • RoboTwin 2.0：Clean2Random 72.3%，平均 79.2%，比 π0.5 提升 26.3 和 20.9 个百分点
  • RoboCasa-Panda：每任务仅 50 条演示下平均成功率 68.4%，优于使用更多演示的对比方法
  • RoboDojo-Real：跨三个本体单策略总体成功率 33.9%，超过 π0.5 的 12.8%
  • 真实世界 8 个部署条件下平均成功率 83.8%，较 π0.5 提升 24.0 个百分点；数据扩展实验表明两阶段空间对齐均优于单阶段替代方案
