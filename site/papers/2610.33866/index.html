Card 02 论文概述

论文概述

  • 提出 Speech-π₀.₅，一个直接以语音指令为输入的音频-语言-动作（Audio-Language-Action）模型，将原始语音直接映射为机器人动作命令
  • 解决现有视觉-语言-动作（VLA）模型依赖键入文本、以及传统“ASR + VLA”流水线引入高响应延迟和转录误差的问题
  • 目标是在保证任务成功率的前提下，显著降低语音到动作的响应延迟，并提升对未见口音的鲁棒性
Card 03 核心贡献

核心贡献

  • 提出跨模态投影（Cross-Modal Projection），将语音帧级特征压缩为固定数量的 VLM token，绕过 ASR 文本解码，实现延迟的大幅降低
  • 提出分割 LoRA（Split LoRA）适配，在骨干网络中使用独立的音频 LoRA 和任务 LoRA 按 token 位置路由，避免语音适配与任务学习相互干扰
  • 提出两阶段训练：先进行语音-语言对齐蒸馏，再进行机器人任务训练，并使用不对称学习率防止灾难性遗忘
  • 在 LIBERO 基准上实现约 3 倍的响应延迟降低，同时在未见口音下保持较高任务成功率，显著优于单 LoRA 基线
Card 04 方法描述

方法描述

  • 基于 π₀.₅ 模型，使用冻结的 Whisper-large-v3 作为语音编码器，提取约 1500 帧的帧级隐藏状态
  • 跨模态投影：通过两层 MLP（GeLU 激活）将语音特征投影到 VLM token 空间，再用带 32 个可学习查询向量的交叉注意力池化压缩为 32 个音频 token，替代自回归 ASR 解码器
  • 分割 LoRA：在 18 层 Gemma-2B 骨干网络的每一层中，配置两个 rank-16 的 LoRA 适配器——音频 LoRA（激活于音频位置）和任务 LoRA（激活于文本/动作位置），通过位置路由保持两条适配路径独立
  • 两阶段训练：阶段 1 利用原始 π₀.₅ 在真实文本输入下的输出进行 MSE 蒸馏，训练投影层和音频 LoRA，冻结动作专家；阶段 2 在机器人演示数据上优化 LoRA 模块和投影层，使用 flow matching 动作损失，其中音频 LoRA 采用更小的学习率
Card 05 数据集与资源

数据集与资源

  • 基准数据集：LIBERO-Spatial 和 LIBERO-Object（各含 10 个任务，每个任务 50 条轨迹，每种条件 n=500）
  • 训练语音：Piper TTS（22 个 VCTK 说话人），生成约 10 万条机器人领域指令，覆盖约 30 种声音
  • 评估语音：Azure Neural TTS 的 10 种未见口音（用于 held-out 测试）
  • 模型基础：π₀.₅（包含 18 层 Gemma-2B 骨干），语音编码器为 Whisper-large-v3
  • 训练/推理资源：延迟测试在 H100 GPU 上以 batch=1 进行，共运行 100 次
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO-Spatial 和 LIBERO-Object 各 500 次试验；响应延迟在 H100 上单 batch 测量 100 次取均值
  • 主要指标：任务成功率（%） 和 首个动作响应延迟（ms）
  • 任务成功率：Speech-π₀.₅ 在训练语音上 Spatial 为 89.2%，Object 为 86.0%；在未见口音上 Spatial 为 85.4%，Object 为 84.8%
  • 鲁棒性对比：单 LoRA 基线在训练语音上 Spatial 为 69.0%，Object 为 69.0%；在未见口音上 Spatial 为 68.4%，Object 骤降至 38.0%，表明分割 LoRA 显著增强了口音泛化能力
  • 延迟结果：传统 ASR 流水线总延迟为 324.4 ms（Whisper 解码 216.7 ms + π₀.₅ 推理 107.7 ms），Speech-π₀.₅ 为 109.1 ms，实现约 3 倍加速
  • 参考精度：ASR 流水线 + π₀.₅（文本 oracle）的成功率为 Spatial 95.6%、Object 95.0%，Speech-π₀.₅ 略低但无需显式文本转录
