DECOWAM: Decoupled Whole-Body World-Action Model for Legged Mobile Manipulation

针对足式移动机械臂操作中的动态视角与多速率动作耦合难题，提出解耦世界-动作建模框架

02论文概述

  • 针对足式移动机械臂操作中的动态视角与多速率动作耦合难题，提出解耦世界-动作建模框架
  • 开发DECOWAM模型，将基座运动、机械臂动作和相机自我运动通过显式语义接口分离，实现参数高效的联合视觉预测与全身控制
  • 构建ARMDOG真实机器人数据集，提供同步的视频流、14维全身状态/动作和语言指令，填补足式移动操作数据空白

03核心贡献

  • 形式化解耦世界-动作建模问题，基座控制、机械臂操作和相机自我运动通过显式、语义对齐的接口输入
  • 实现DECOWAM四模块解耦架构：残差适配器、动作等价未来瓶颈、基座-机械臂对抗因子分解、基座速度条件视频预测
  • 构建ARMDOG数据集，包含1,487集质量过滤 episode、343,550帧同步数据（约321.3分钟，15Hz），覆盖四足基座与6-DoF机械臂操作
  • 仅用25.95M可训练参数即实现参数高效适配，相比FastWAM基座将动作MSE降低21.7%，帧MSE降低15.0%

04方法描述

  • FastWAM骨干网络：基于Wan-2.2视频扩散模型，耦合ActionDiT动作专家分支，联合预测8帧未来RGB与48步14维动作块
  • 两阶段参数高效适配：第一阶段全参数微调50k步对齐ARMDOG域；第二阶段冻结骨干，仅优化残差适配器及解耦模块（25.95M参数）
  • 动作等价未来瓶颈：教师-学生知识蒸馏，将特权未来潜变量信息压缩为64维因果可用瓶颈，提供未来等价控制信号
  • 基座-机械臂因子分解：将动作上下文映射为两个16维潜变量，通过梯度反转层（GRL）实现对抗解耦，分离导航尺度基座命令与操作尺度机械臂命令
  • 自我运动感知视频条件：将归一化基座速度$(v_x, v_y, \omega_z)$作为显式条件注入视频分支token，显式建模相机 ego-motion
  • 采用条件流匹配（conditional flow matching）联合训练视频与动作专家，Stage 2总损失包含视频重建、动作重建、瓶颈蒸馏和解耦损失

05数据集与资源

  • ARMDOG数据集：足式移动操作真实机器人数据集，完整语料库含1,487集、343,550帧RGB数据（约321.3分钟，15Hz）；当前训练快照217集/56,041帧，涵盖Bottle Pick&Place（56%）、Place Block（39%）等任务
  • 机器人平台：四足基座（16个腿部关节）+ 6-DoF机械臂 + 1-DoF夹爪，配备RGB-D相机与IMU
  • 模型规模：FastWAM骨干共6,725.44M参数（全参微调时6,020.75M可训练），DECOWAM Stage 2仅需25.95M可训练参数（128-D WAN适配器、64-D未来瓶颈、16-D基座/臂潜变量）

06评估与结果

  • 评估环境：固定23集box_val回放协议（8个任务文件夹，4,323帧），以及真实机器人闭环试验（每种方法79次试验）
  • 评估指标：视频质量（帧MSE、PSNR、SSIM、LPIPS），动作预测（MSE、MAE、平均L2误差）
  • 关键结果：

- 相比FastWAM 50k检查点，帧MSE降低15.03%，动作MSE降低21.71%，PSNR提升0.222dB

- 在WAM参考模型中全面领先，相对Motus帧/动作MSE降低83.1%/89.3%，相对X-WAM降低66.6%/91.5%

- 动作预测接近专用VLA（X-VLA），A-MSE低69.9%，同时额外预测8帧384×320未来RGB视频

- 真实机器人上实现最高全身协调能力与基座位移鲁棒性，任务完成率与最强基线相当
