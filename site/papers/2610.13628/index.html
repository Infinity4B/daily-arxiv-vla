Card 02 论文概述

论文概述

  • 论文提出 JitterVLA，一个用于评估 VLA 驱动机器人操作中运动质量的配对重放基准
  • 核心问题是：VLA 策略输出稀疏目标，且目标到达机器人控制器时存在延迟和不规则性，因此合理的预测动作仍可能产生靠近人类时的突然运动
  • 现有补救措施在不同数据流、延迟和指标上评估，难以公平比较；JitterVLA 通过固定命令源与延迟实现、只改变控制器来隔离控制器影响
Card 03 核心贡献

核心贡献

  • 提出一种配对重放基准与协议：在同一命令源和同一延迟实现下比较不同控制器，差异可归因于控制器而非随机输入
  • 构建从受控合成到达、20 人人类运动、三个 VLA 管线（838 episodes）与实测网络轨迹，到真实 UR3 的评估层级
  • 发现一致的jerk–tracking 权衡：插值在全部来源上降低 jerk 并提高跟踪误差；不确定性关联随动作表示不同而符号相反；熵门控在部分输入上失败
  • 进行有限 UR3 物理验证：插值在全部六组探索配对中降低加速度计导出的 jerk 3.0–14.0%；位置导出指标未复现对比，形成零结果
  • 计划发布代码、变换后的 VLA 流、20 人手部轨迹窗口和延迟轨迹，支持在人类中心研究前进行筛查
Card 04 方法描述

方法描述

  • 配对重放：每个控制器接收相同 episode、person 或 synthetic reach，以及相同延迟 realization；统计在 episode、person 或 seed 上配对
  • 时序管线：使用一张 RTX 5090 测量的 VLA 推理服务时间进入单 worker FIFO 队列；再加入零延迟、Gamma 分布延迟（均值 0–400 ms）或 12 小时实测 LAN/互联网/HTTPS 轨迹延迟
  • 被控对象：通用三轴点质量模型（3 kg、临界阻尼阻抗、20 ms 力滞后、3000 N/s 力率上限、1 ms 步长），并非 UR3 模型
  • 控制器：B0 stepped、B2 线性插值、A2 熵门控刚度插值、B3 Ruckig jerk-limited；另设 8 个固定刚度常增益网格
  • 评价指标：99th-percentile（p99）与 RMS jerk、tracking RMSE，以及 LDLJ 和 SPARC；统计区间为 95% 单位 bootstrap（5000 次重采样）
  • 证据层级：冻结分析、计划复现、事后稳健性检查、探索性硬件跟踪，结果按标签分开报告
Card 05 数据集与资源

数据集与资源

  • 合成到达：10 个 synthetic reaches
  • 人类运动：3D-ARM-Gaze 数据集，来自 20 人
  • OpenVLA / BridgeData V2：80 个原始 episodes / 200 个新抽取 episodes
  • pi0-FAST / DROID：80 / 199 episodes
  • pi0.5 / DROID：80 / 199 episodes
  • 真实机器人：UR3 CB3 控制器，125 Hz，30 + 30 runs
  • 总计 69,988 次配对重放
  • 推理服务时间在单张 RTX 5090 上测量；论文未训练新 VLA 模型，也未报告模型参数量
Card 06 评估与结果

评估与结果

  • 评估环境覆盖合成到达、人类运动、三个开源自 VLA 管线的开环预测，以及真实 UR3；基准主对象为通用点质量模型，绝对 jerk 值不是硬件预测
  • 主要指标：p99 jerk、tracking RMSE、LDLJ、SPARC
  • 关键结果：插值在全部来源降低 p99 jerk；人类 200 ms 均值延迟下从 615 m/s³ 降至 106 m/s³（降低 83%），跟踪误差从 9.91 cm 增至 11.87 cm，约 2.0 cm 跟踪成本
  • 复现结果：效果在 598 个新 episodes 上保持；B2−B0 的 jerk 降低方向在所有来源和三个实测轨迹下均保持
  • 时序发现：是时序不规则性而非平均延迟驱动 stepped-goal jerk；固定 0/200/400 ms 延迟对 p99 jerk 影响很小，而 200 ms 延迟扩展使其升高
  • 不确定性关联：OpenVLA 中 token entropy 与 successive goal step 弱负相关（ρ=-.065，新抽取 -.089）；pi0-FAST 中 chunk entropy 与 chunk-boundary jump 正相关（ρ=.221，新抽取 .217），两者方向均复现
  • 熵门控效果：在 pi0-FAST 上 A2 相对 B2 降低 p99 jerk 208 m/s³（新抽取 199），跟踪成本 +0.18 cm；在 OpenVLA 上未帮助
  • UR3 结果：加速度计导出的 jerk 在全部六组探索配对中降低 3.0–14.0%；位置导出指标未解析对比，v1.2 冻结协议中位置指标为零结果
  • 限制：主结果基于通用点质量模型和开环 VLA 预测；三个管线在模型、数据集、动作表示、熵定义和跳变事件上不同，不构成受控模型比较；UR3 研究规模小，加速度计未标定；未测量舒适度、偏好、信任和感知安全
