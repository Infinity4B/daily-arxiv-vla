RoboOS-NeXT: A Unified Memory-based Framework for Lifelong, Scalable, and Robust Multi-Robot Collaboration

02论文概述

RoboOS-NeXT是一个统一的基于内存的多机器人协作框架，旨在实现终身适应性、可扩展协作和鲁棒调度。该框架的核心是Spatio-Temporal–Embodiment Memory (STEM)，它将空间场景几何、时间事件历史和机器人配置文件集成到一个共享表示中。通过采用大脑-小脑框架，高级大脑模型通过检索和更新STEM进行全局规划，而低级控制器在本地执行动作。这种认知、执行和内存的闭环实现了动态任务分配、容错协作和一致状态同步。

03核心贡献

  • 提出了RoboOS-NeXT，一个基于内存的多机器人协作框架，构建在STEM之上，将空间、时间和实例化维度集成到统一表示中
  • 设计了Brain-Cerebellum-Memory层次循环，通过STEM连接全局推理与技能执行，为多机器人协作提供了原则性基础
  • 在餐厅、超市和家庭等多样化任务中评估RoboOS-NeXT，并在真实世界演示中展示其在异构机器人上的有效性

04方法描述

RoboOS-NeXT的核心方法包括：

  1. Spatio-Temporal–Embodiment Memory (STEM)：

- 时间内存：维护附加仅、时间有序的列表，记录状态增量、暂存任务上下文和工具调用跟踪

- 空间内存：建模场景为根类型多分支树（全局场景->区域->载体），每个载体锚定对象级图

- 实例化内存：为每个机器人维护档案，包括定位、能力、资源、传感器状态和可用性

- 组织为队列-树-图-代理结构，支持跨维度交互

  1. Brain-Cerebellum-Memory框架：

- 全局任务分解：大脑模型使用检索增强生成过程查询共享空间内存，生成结构化推理跟踪和工作流图

- 拓扑子任务分配：监控器基于有向无环图中的拓扑依赖关系动态调度和分配子任务

- 分布式子任务代理：为每个子任务部署专用机器人代理，自主编排工具选择

- 动态内存更新：随着机器人在子任务执行过程中感知和行动，增量更新时间内存和空间内存

05数据集与资源

  • 数据集：在三个领域（餐厅、超市、家庭）各实例化200个任务的模拟设置
  • 训练资源：

- 高级推理由RoboBrain-2.0多模态大语言模型驱动，增强用于时空推理

- 低级执行包含基于SLAM的导航模块和基于扩散策略的操纵模块

  • 真实机器人平台：Unitree G1人形机器人、Agilex双臂机器人和Realman单臂机器人

06评估与结果

  • 评估环境：

- 三个领域（餐厅、超市、家庭）的模拟设置

- 真实世界协作演示场景

  • 评估指标：

- 成功率(SR, %)：在步骤预算内成功完成的任务比例

- 边际成功率(MSR, %)：在终身或课程序列中每个序列的最终任务上测量的成功率

- 平均每任务执行步骤(AEST, #)：完成任务所需的平均步骤数

- 每步成功率(SS, %/#)：任务成功率与平均步骤数之间的比率，反映每步实现平均准确性
