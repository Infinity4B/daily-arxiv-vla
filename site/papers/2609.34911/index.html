Don't Throw Away the Tail: Action Upcycling for Policy Acceleration

02论文概述

  • 提出 Action Upcycling，一种无需训练（training-free）的算法，通过重用策略原本会丢弃的动作块尾部（tail）来减少策略调用次数，提升推理效率
  • 解决 action chunking 中执行 horizon（h）的选择难题：短 horizon 保持环境反应性但增加策略调用频率，长 horizon 降低反应性，需在两者间权衡
  • 基于关键实证观察：被丢弃的动作与其重新规划版本在速度平滑时高度相关（Pearson 相关系数 0.89–0.98），且两者误差随尾部动作的速度波动（velocity fluctuation）增长

03核心贡献

  • 揭示被丢弃动作与其 replanned 版本的强相关性，并证明只要动作速度保持平滑，两者就保持接近，为重用 tail actions 提供理论基础
  • 提出 Action Upcycling 算法，利用累积速度波动信号（velocity fluctuation）自适应决定可重用的 tail actions 数量，无需访问模型内部结构或抽取额外样本
  • 在四种策略（三种 VLA 和一种 World Action Model）、三个仿真基准以及真实机器人任务上验证，consistently 减少策略调用 1.2–1.7 倍且不损失成功率
  • 证明该方法可与 few-step sampling 和 streaming action decoding（如 FlashVLA）等加速方法正交结合，实现高达 6.7 倍的总加速

04方法描述

  • 速度波动信号：定义 $c_k$ 为执行 horizon $h$ 之后尾部动作速度的累积 L2 变化（$c_k = \sum_{j=h+1}^{k} \\|v_j - v_{j-1}\\|_2$），作为运动平滑程度的度量；$c_k$ 非递减，在速度波动时上升
  • 自适应执行 horizon：设置阈值 $\tau$，当 $c_k \leq \tau$ 时继续执行 tail actions，执行长度 $h_{\text{exec}} = \max_{c_k \leq \tau} k$；阈值 $\tau$ 通过简单搜索在预构建的信号池 $\mathcal{C}$ 中确定，无需额外交互
  • 训练免费：完全基于单次前向传播产生的动作块计算信号，无需额外 rollouts、demonstrations 或成功标签，计算开销可忽略
  • 通用性：适用于任何分块策略（chunked policy），包括 SmolVLA、$\pi_{0.5}$、GR00T 和 FastWAM（World Action Model），无需修改模型架构或重新训练

05数据集与资源

  • 仿真基准：LIBERO（四任务套件）、LIBERO-Plus（七种扰动维度）、RoboTwin 2.0（50 个双手操作任务，含干净和随机设置）
  • 真实世界数据：在 YAM arm（6-DoF 单臂机械臂，带线性夹具）上收集 424 个遥操作 episodes，涵盖 8 个任务（4 个 pick-and-place + 4 个 long-horizon 抽屉任务），使用俯视摄像头和手腕摄像头，30 Hz 记录绝对关节位置
  • 模型规模：使用公开预训练 checkpoint，包括 SmolVLA、$\pi_{0.5}$、GR00T N1.7/N1.6 和 FastWAM；$\pi_{0.5}$ 预测 horizon $H=50$，GR00T N1.6 预测 $H=16$
  • 训练资源：$\pi_{0.5}$ 用 20,000 steps（batch size 64），GR00T N1.6 用 10,000 steps（batch size 32）；真实世界微调保持官方训练配置，使用 YAM arm 物理平台

06评估与结果

  • 评估指标：成功率（success rate）、每回合策略调用次数（calls per episode）、单次调用延迟（latency in ms）、每回合推理时间（inference time in s）
  • 仿真结果：在所有 12 种策略-基准组合上，Action Upcycling 将策略调用减少 1.2–1.7 倍，同时匹配或提升成功率（如 $\pi_{0.5}$ 在 LIBERO 上从 96.9% 提升至 97.9%，在 LIBERO-Plus 上从 83.7% 提升至 86.5%）
  • 对比基线：优于 attention-based 的 AutoHorizon（需访问模型内部 attention 权重）和 sampling-based 的 AAC（增加调用延迟），在 LIBERO 和 LIBERO-Plus 上取得最高成功率和最短每回合推理时间
  • 组合加速：与 few-step sampling（$N=2$）结合可达 2.8 倍总加速；与 FlashVLA（streaming action decoding）结合可达 6.7 倍总加速（单次延迟从 136ms 降至 31ms，调用减少 1.51 倍）
  • 真实世界验证：$\pi_{0.5}$ 成功率从 72/80 提升至 77/80，调用从 48.3 降至 34.0（1.42 倍减少），每回合时间从 24.9s 降至 21.5s；GR00T N1.6 成功率从 34/40 提升至 35/40，调用从 90.6 降至 71.0，每回合时间从 28.0s 降至 24.9s
