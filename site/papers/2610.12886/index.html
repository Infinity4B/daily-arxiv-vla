LeapBot-JAC: Joint Action Chains for World Action Models

2026-10-09 · 原文 · 翻译 · 2610.12886

Card 03 核心贡献

核心贡献

  • 动作角色分配（Action-role allocation）：将固定动作 token 预算重构为稀疏参考预测与密集执行预测，把“监督跨度”与“实际执行前缀”解耦。
  • 共享专家联合生成（Shared-expert joint generation）：结合演示控制标签监督、物理时间对齐和有向跨链注意力访问，且不新增任何动作参数，同时保留宿主原有的可见性约束。
  • 双宿主实证验证：在 FastWAM 与 LeapBot-WA 两个宿主上，将 LIBERO 成功率提升至 98.3%；LIBERO-Plus 零样本总分分别提升 16.9 与 4.2 个百分点。
  • 系统性消融：三项 FastWAM 消融（跨链可见性方向、参考监督权重、参考步长）刻画了 JAC 对各设计要素的敏感度。
  • 真实部署评估：除仿真基准外，还通过 RoboTwin 与两个真实世界任务验证可部署性。
Card 04 方法描述

方法描述

  • 目标构造与边界填充：固定规则 π 生成有序索引集合 \(I_R\)、\(I_A\)，满足 \(\|I_R\|+\|I_A\|=B\)。执行链为连续索引 \(I_A=\{0,\dots,n_A-1\}\)，参考链为稀疏采样 \(I_R=\{0,s,\dots,(n_R-1)s\}\)。默认 \(B=32\)、\(n_R=n_A=16\)、\(s=3\)、\(\lambda_R=0.2\)；LIBERO/LIBERO-Plus 用 \(K=10\)，RoboTwin 用 \(K=16\)。越界索引被 clamp 到最后一个有效动作并标记为 padding。
  • 共享生成与时间对齐：沿用宿主的连续生成参数化（线性 flow matching）。两条链共享同一噪声水平 σ，但使用独立高斯噪声样本 \(\epsilon_R, \epsilon_A\)，输入为 \(X_\sigma=[R_\sigma; A_\sigma]\)，由同一动作专家 \(f_\theta\) 同时预测 \([\hat v_R; \hat v_A]\)。两链共享输入/输出投影、时间嵌入、Transformer 层与每次前向。
  • 物理时间位置编码：位置向量 \(p=[0,3,\dots,45; 0,1,\dots,15]\)。对使用 RoPE 的宿主，执行 token \(i\) 与参考 token \(j\) 的相对偏移为 \(3j-i\)，而非拼接槽位偏移 \(j-(16+i)\)；不引入额外的链身份嵌入。
  • 有向可见性掩码：\(M_{\rm JAC}=M_{\rm host}\land M_{\rm role}\)，其中 \(M_{\rm role}\|_{R,A}=\begin{bmatrix}1&0\\1&1\end{bmatrix}\) —— 允许 A 读取 R，阻断 R 直接读取 A（仅增加一个 \(16\times16\) 零块），其余边继承宿主可见性。
  • 训练目标：各链损失按有效 token（排除 padding）与动作维度做平均，共享宿主时间步权重 \(w(\tau)\)；总损失 \(\mathcal{L}=\mathbb{E}[\ell_A+\lambda_R\ell_R]+\mathcal{L}_{\rm host,world}\)。注意 \(\lambda_R=0\) 并不等价于基线，因为执行损失仍会经由参考表示反向传播。
  • 推理：两链从 \(\sigma=1\) 联合积分到 0，仅对 \(\hat A\) 做逆变换，并只执行其前 \(K\) 个控制后重新规划；推理阶段无演示尾部 padding 掩码。

数据集与资源

Card 06 评估与结果

评估与结果

  • 对比基线：复现的 FastWAM、LeapBot-WA 基线与各自 JAC 变体；外部参考包括 \(\pi_0\)、\(\pi_{0.5}\)、Motus、LingBot-VA、LAWA、ImageWAM。文内对比固定动作 token 总数为 32。
  • 主要指标：LIBERO 四套件成功率与其均值；LIBERO-Plus 总分（聚合全部测试 episode）；RoboTwin 2.0 的 Clean/Random 及其均值；括号内数值为相对各自复现基线的绝对百分点变化。
  • 关键结果：

- LIBERO：FastWAM 与 LeapBot-WA 加 JAC 后均达到 98.3%，分别由 97.0% 和 97.3% 提升而来。

- LIBERO-Plus（零样本）：FastWAM 由 53.5% → 70.4%（+16.9pp）；LeapBot-WA 由 73.1% → 77.3%（+4.2pp）。

- RoboTwin 2.0：宿主基线与 JAC 均以 \(K=16\) 重新评估以保证执行链长度一致，作为额外双臂操作部署验证。

- 消融（LIBERO）：G1 跨链可见性（方向性）、G2 参考监督权重、G3 参考步长，验证动作角色组织在固定预算下是有效的设计选择。

- 计算开销：JAC 保持动作参数量、每步 token 数与动作专家前向次数不变，并保留宿主世界更新；结构等价不直接等同于运行时等价，具体时延与显存开销在 4.4 节讨论。

  • 局限：主要结论基于单一训练种子对比；方向性掩码只阻断直接 \(A\rightarrow R\) 注意力，间接反向路径是否被排除需满足附录 A.9 条件（方向性不等价于统计独立）。
