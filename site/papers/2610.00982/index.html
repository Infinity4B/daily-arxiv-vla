Divide-and-Remember: Recursive Action-Relevant Memory for Long-Horizon VLA Policies

02论文概述

  • 论文针对视觉-语言-动作（VLA）模型在长时程操作任务中面临的记忆问题（memory problem），即当前观测不足以决定动作、需要依赖历史信息的情况。
  • 现有记忆方法（如感知记忆、潜在记忆）依靠人工设计的规则决定记住什么，在不同任务上效果不一致；论文从 POMDP 与信息论出发，将"记住什么"形式化为一个优化问题。
  • 论文提出 Divide-and-Remember (D&R)，一种在预训练 VLA 令牌空间中端到端学习、优化动作相关条件互信息的递归记忆方法。

03核心贡献

  • 从信息论角度证明最优记忆最大化条件互信息 I(a_t; m_t \|o_t)，即保留历史中与当前动作相关、且当前观测缺失的信息，并统一了现有各类记忆方法的理论视角。
  • 提出 D&R 递归记忆方法：将全历史选择递归分解为对 2K 令牌的 top-K 选择子问题，使固定大小、轻量级的选择器支持无界历史，且缓解训练部署的离线-在线不匹配问题。
  • 所有递归块共享一个选择器 f_ψ，由策略的 flow-matching 动作损失（即互信息的变分下界）端到端训练，无辅助损失或人工规则。
  • D&R 在 RoboMME 基准的 16 个长时程操作任务上，在仅 64 令牌预算下取得 SOTA 平均成功率 38.6%，并在全部四类任务套件上一致提升；真实机器人实验同样验证了性能提升。
  • 开源代码、模型权重与可视化结果（dnr-memory.github.io）。

04方法描述

  • 记忆被形式化为预算化令牌选择问题：m_t = M(H_t) 为从全部历史令牌中选择至多 K 个的映射，在预训练令牌空间中保持空间细节且可精确回溯。
  • 递归结构：当令牌跨度超过 K 时，左对齐切分，子问题递归求解，并将相邻两个 K 令牌集合并后再次调用选择器，逐级过滤至根节点。
  • 选择器 f_ψ：输入 2K 个候选令牌，经过 M-RoPE 位置编码和 N 层 Transformer 自注意力/FFN 块，线性头输出选择分数，用 top-K + sigmoid 松弛（straight-through estimator）保持可微，训练时添加 Gumbel 噪声探索。
  • 记忆通过自适应 LayerNorm 与交叉注意力调制到 π0.5 的动作专家中。

05数据集与资源

  • 数据集：RoboMME 基准，16 个长时程操作任务（6 类功能特征：Motion-Centric、Time-Sensitive、Short-/Long-Horizon Video、Dynamic Scene-Change、Event-Salient）
  • 模型：基于 π0.5 骨干（冻结 SigLIP 编码器 + Gemma VLM + 动作专家），D&R 额外加入选择器模块
  • 记忆预算：64 个令牌
  • 训练：80k 步，batch size 64（TTT 基线为 16），多任务训练

06评估与结果

  • 评估设置：每任务 50 集（共 800 集），环境种子与训练不重叠，最大 horizon 1,300 步；结果取最后 3 个 checkpoint × 3 个随机种子（共 9 次运行）的平均值
  • 对比基线：感知记忆（FrameSamp、TokenDrop）、潜在记忆（HAMLET、RB-VLA）、参数记忆（TTT），均基于 π0.5 构建且共享 64 令牌预算
  • 关键结果：D&R 平均成功率 38.6%，优于最佳潜在记忆 32.2%，优于无记忆策略 π0.5（17.9%）
  • D&R 在每类记忆需求上均取得领先，包括累积计数、跟踪被遮挡物体、回溯早期时刻、复现演示序列等；真实机器人实验中亦取得最高成功率。
