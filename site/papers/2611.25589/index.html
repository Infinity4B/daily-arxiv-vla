GraF-VTA: Neuro-Symbolic Trajectory Generation from Vision and Temporal Logic via Graph-Based Fusion

02论文概述

  • 论文提出 GraF-VTA，一个基于图的神经-符号框架，从视觉观测和信号时序逻辑（STL）生成机器人轨迹。
  • 解决机器人规划中视觉观测与 STL 规格的视觉基础（grounding）问题，以及执行过程中模型失配、扰动和跟踪误差导致的规划偏差。
  • 通过结合结构化任务表示、因果观测历史和闭环轨迹生成，扩展了 Vision-TL-Action (VTA) 框架，支持从视觉、STL 规格和机器人状态端到端地生成满足时序逻辑约束的轨迹。

03核心贡献

  • 提出统一框架 GraF-VTA，支持 STL 语法树图和可选 DFA 图条件化，通过双向逻辑-视觉融合实现视觉基础，同时保留时序约束。
  • 引入动作前缀执行与重规划机制，利用因果时间金字塔保留当前观测细节并压缩历史帧，为多阶段任务提供近期执行上下文，提高对执行误差的鲁棒性。
  • 在五个仿真环境（Linear, Dubins, PointMaze, AntMaze, Panda）开展开放回路和闭环评估，验证了框架的有效性。
  • 消融实验表明观测记忆和双图条件化对部分有序任务有显著增益，并且双视图观测提供互补信息。

04方法描述

  • STL 图编码：将 STL 公式解析为语法树，为每个节点（操作符或原子谓词）构造特征向量（包含节点类型、谓词标签、对象槽位、时间边界等），使用多层图神经网络（GNN）编码节点嵌入。
  • 可选 DFA 嵌入：将 STL 编译为确定性有限自动机（cDFA），使用预训练的 RADE 编码器获得冻结的自动机嵌入，作为全局条件补充时序转移结构。
  • 因果时间金字塔视觉编码：使用共享的 ResNet18 提取多视图图像特征，根据观测年龄分配 token 预算（当前帧保留全部 token，旧帧进行空间平均池化压缩），并添加空间位置、视图身份和年龄的正弦位置编码。
  • 双向逻辑-视觉融合：STL 标记与视觉标记通过双向交叉注意力相互条件化，利用有效性掩码处理填充符号和不可用观测，最后进行掩码平均池化得到全局条件向量。
  • 条件流匹配轨迹生成：使用 Temporal U-Net 作为速度场，通过条件流匹配目标训练，从高斯噪声采样，经 ODE 求解器（欧拉法）积分得到归一化计划并解码为实际轨迹。

05数据集与资源

  • 使用的数据集：五个机器人仿真环境：Linear 和 Dubins（基于 ZoneEnv）、PointMaze 和 AntMaze、Franka Panda 机械臂；每个环境包含 128 个 STL 规格任务。
  • 模型规模：节点特征维度为 256，视觉编码器为 ResNet18，未明确提供总参数量。
  • 训练资源：每个训练作业运行在 NVIDIA A100 Tensor Core GPU 上，使用 PyTorch 和 PyTorch Geometric 实现。

06评估与结果

  • 评估环境和基准：在五个仿真环境中进行开放回路和闭环评估；开放回路对比 TeLoGraF 和 Vision-TL-Action (VTA)；闭环对比适应后的 S-MSP 和 Logic-VLA；消融实验包括无记忆、标准两帧记忆、金字塔两帧记忆和双图变体。
  • 主要评估指标：Success@K（最佳 K 个候选轨迹中 STL 鲁棒性严格大于 0 的任务百分比），以及按任务类别（单目标、多目标、顺序、部分有序）划分的 STL 满足率。
  • 关键实验结果：

- 开放回路：GraF-VTA 在 Linear、Dubins、PointMaze、Panda 四个环境上，在 K≥16 的所有预算下 Success@K 均优于 TeLoGraF 和 VTA；在 K=1024 时，Linear 和 Dubins 分别超出 TeLoGraF 20.31 和 19.53 个百分点。

- Panda 消融：金字塔记忆将 Success@256 从无记忆的 53.91% 提升至 62.50%，且推理时间仍低于 VTA。

- 闭环 Dubins 评估：GraF-VTA 达到 64.06% Success@1024，显著优于 S-MSP（12.50%）和 Logic-VLA（27.34%）。

- 闭环整体优势：除 AntMaze 外，闭环执行在各环境上较开放回路提高 Success@1024，例如 Linear 从 46.88% 提升至 67.19%，Panda 从 48.44% 提升至 67.97%。
