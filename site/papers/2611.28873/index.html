02论文概述

  • 研究机器人学习中的动作分词器在大规模、多具身数据上的扩展问题，提出 Neural Action Tokenizer (NAT)
  • NAT 是一种因果神经动作分词器，将动作块编码为短 token 序列，并支持边生成 token 边执行动作的流式推理
  • 在 49k 小时、156 个数据集的混合动作语料上训练，解决现有神经分词器仅在小型数据集上训练、难以泛化到未知机器人具身的问题

03核心贡献

  • NAT 达到最优神经动作分词效果：在未见过的机器人具身上，NAT 的平均成功率优于 FAST、OAT、ActionCodec 和 NAC
  • 通用流式动作分词器：在真实机器人、手持夹爪（UMI）、仿真和人类手部数据上训练；因果解码器支持即时执行，时间有序 token 支持无需重训练的动作前缀条件化
  • 仅用人类手部数据即可学习有效动作空间：人类数据训练的 NAT 接近使用全部数据训练的 tokenizer，表明机器人数据可能并非必需
  • 支持视觉-语言-动作模型（VLA）预训练：通过 NAT token 在 1.8k 小时机器人数据上进一步预训练 VLA，在四个仿真基准上提升平均成功率
  • 流式动作头与动作 token 对比：NAT token 可更快产生首批动作，并且在部分基准（如 LIBERO）上与流匹配动作头成功率相当

04方法描述

  • NAT 基于 Neural Action Codec (NAC) 改造：编码器采用 SEANet 堆叠的一维卷积 + LSTM，将动作块展平后下采样为潜在向量
  • 量化器使用 多尺度有限标量量化（multi-scale FSQ） 替代 RVQ，按多个时间尺度进行残差量化，生成粗到细的 token
  • 解码器采用 Vocos 风格 卷积、自注意力和 ConvNeXt 块，并改为因果结构（仅左侧填充、窗口注意力、逐潜在归一化），支持流式解码
  • 不同动作维度按臂分组并零填充到固定宽度 D̄=7，每个组独立 token 化后拼接；训练目标为动作重建的均方误差
  • 策略为自回归 Transformer 解码器，冻结 NAT 后以 next-token 预测训练；推理时按潜在向量逐步解码动作，支持实时分块将正在执行的动作作为 token 前缀冻结

05数据集与资源

  • 动作语料：约 49k 小时（5.5B 动作帧），来自 156 个数据集，涵盖真实机器人遥操作、仿真机器人、UMI 手持夹爪、人类手部动作四类来源
  • 评估基准：LIBERO-Long、Meta-World、RoboMimic、RoboCasa 四个仿真基准
  • 分词器参数量：神经分词器约 63M；策略模型约 162M 或 280M
  • 词汇表大小：51,200 tokens；每个动作块约 28 tokens（FAST 平均 29.8）
  • 训练资源：论文未明确给出 GPU/TPU 等硬件资源
  • 发布资源：NAT 分词器权重可通过 Hugging Face 获取；项目网站为 https://www.ahadjawaid.com/nat

06评估与结果

  • 在四个仿真基准的跨具身策略上，NAT 平均成功率 47.0%，超过 FAST 43.4%、ActionCodec 40.9%、OAT 36.6%、NAC 29.0%、Diffusion Policy 35.9%
  • 在 LIBERO-Long 单独策略中，NAT 达到 77.9%，显著高于 FAST 的 66.2%
  • 仅使用人类手部数据训练时，NAT 成功率为 74.4%（全数据 NAT 为 77.9%），而 OAT/NAC 等下降 18–33 个百分点
  • 架构消融：FSQ 优于 RVQ（69.3% vs 60.5%）；线性输出头与 ISTFT 相当；因果结构仅比非因果低 1.7 个百分点；4 个尺度（28 tokens）提供最佳成功率
  • NAT 在 LIBERO 上表示一秒动作仅需 9 tokens，而 FAST+ 需要 24、逐维分箱需要 140
  • NAT token 在部分基准（如 LIBERO）上与流匹配动作头成功率相当，且可更早产出首批动作；实时分块降低相邻块连接处的动作跳变
