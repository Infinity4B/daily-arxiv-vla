02论文概述

  • 针对现代视觉-语言-动作（VLA）模型中固定执行视野（horizon）导致的效率与精度权衡问题，提出基于动作专家内部交叉注意力动态的自适应动作分块方法
  • 观察到随着预测视野延长，动作到观察的交叉注意力分布越来越分散且熵值上升至平台期，该现象与更高的动作预测误差显著相关
  • 利用这一无需训练的内在信号实现动态截断机制，在推理时自适应调整执行视野，无需修改模型架构或增加额外采样

03核心贡献

  • 表征了基于流的VLA策略中动作到VLM注意力的视野级分散现象，证明持续高熵饱和与增加的离线动作误差相关，可作为感知接地性降低的实证指标
  • 设计了完全无训练的动态截断机制，通过检测交叉注意力熵的持续高值平台期来自适应调整执行视野，零架构修改成本
  • 在多种SOTA VLA模型（π₀.₅ 和 X-VLA）及仿真、真实环境中的广泛验证，显示在保持高效闭环控制的同时提升平均任务成功率

04方法描述

  • 统一交互框架：将VLA中的动作生成统一为交叉注意力检索过程，动作查询从VLM提供的感知键中提取信息，适用于解耦式（如π₀.₅）和耦合式（如X-VLA）架构
  • 注意力分散与熵动态：

- 定性观察：早期动作token稀疏关注语言token，后期动作token注意力分散到广泛视觉区域

- 量化：定义交叉注意力权重熵，沿层轴聚合后归一化得到概率分布 p_{i,j}，计算熵值 ℰ_j = -Σ p_{i,j} log p_{i,j}

- 熵作为精度代理：验证高熵与动作预测MSE显著正相关（Pearson r=0.187, Spearman ρ=0.432），高熵区间MSE是低熵区间的10.4倍

  • 自适应动作分块：

- 对熵序列应用移动平均滤波（窗口大小k=5，LIBERO上π₀.₅使用k=3）

- 检测高熵平台期：要求窗口内最小熵 ≥ η·log N（η=0.95）且平均一阶变化绝对值 < τ（τ=0.01）

- 检测到平台期时动态缩短执行视野 H_e = min(𝒞) + k，否则执行完整预测视野 H_p

05数据集与资源

  • 仿真数据集：

- RoboTwin 2.0：包含10个代表性任务（Place phone stand, Place fan, Move can pot, Place dual shoes, Place bread basket, Hand over block, Stack blocks two, Blocks rank rgb, Stack blocks three, Put bottles dustbin），按平均episode长度分为短、中、长视野类别

- LIBERO：包含Spatial、Object、Goal、Long四个任务套件

  • 真实世界任务：Hang Mug（挂 mug）、Stack Cups（叠杯子）、Pen Tidying（整理笔）
  • 模型配置：

- π₀.₅：预测视野 H_p=50，每任务使用50条Aloha Agilex演示微调40,000步（batch size 32）

- X-VLA：预测视野 H_p=30，使用开源预训练模型（200个VLM token）

  • 训练资源：单块 NVIDIA A100 GPU

06评估与结果

  • 评估环境：RoboTwin 2.0仿真、LIBERO仿真、真实机器人平台（ARX R5双臂机器人+ARX X5主端，双腕部鱼眼相机+头部RGB相机，控制频率60Hz，图像20Hz），每个配置3个随机种子，每任务100次rollout（真实世界20次）
  • 主要指标：任务成功率（Success Rate, SR）、平均执行视野长度、推理延迟
  • 关键实验结果：

- RoboTwin 2.0（π₀.₅）：平均成功率 62.9%，优于所有固定分块基线（最佳固定chunk=10为61.6%），平均执行视野仅18.11步

- RoboTwin 2.0（X-VLA）：平均成功率 79.0%，优于最佳固定分块（76.1%），无需模型特定阈值设计

- LIBERO：平均成功率 97.25%，优于最佳固定基线Fixed-6（94.88%），在LIBERO-Long上提升4.5个百分点

- 真实世界任务：平均成功率 61.7%，优于最佳固定配置（chunk=20,30，47.5%）和最佳自适应基线SA（55%）

- 效率分析：推理延迟仅 0.2725秒，比多采样方法MS（0.2956秒）更低，比固定分块（0.2661秒）仅增加约6ms，满足高频闭环控制需求
