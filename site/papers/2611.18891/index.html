Bring Back Language to Actions: Restoring VLM capabilities in VLA Models via Parameter Merging

arXiv 原文 ↗ 中文翻译 ↗

论文针对 视觉-语言-动作模型（VLA） 在微调过程中出现的 灾难性遗忘 问题：VLA 在获得动作预测能力的同时，大幅丧失原有 视觉-语言模型（VLM） 的语义理解和视觉定位能力

02论文概述

  • 论文针对 视觉-语言-动作模型（VLA） 在微调过程中出现的 灾难性遗忘 问题：VLA 在获得动作预测能力的同时，大幅丧失原有 视觉-语言模型（VLM） 的语义理解和视觉定位能力
  • 提出一种 事后、轻量级的参数合并方法，在不重新训练源模型的情况下，将 VLM 与其微调得到的 VLA 融合，同时保留动作预测和视觉语言能力
  • 核心思想是提取 VLA 与 VLM 的 任务向量，通过 奇异值分解（SVD） 将其分解为多个正交方向，并为每个方向学习独立的混合系数，实现对两种能力的精细权衡

03核心贡献

  • 提出一种 基于 SVD 分解的逐分量参数合并方法，为任务向量的每个奇异分量学习标量混合系数，仅需优化少量参数，两个源模型完全冻结
  • 通过消融实验证明 逐分量（per-component）系数 在同时恢复语言能力和保留动作能力方面 显著优于全局或逐层（per-layer）系数
  • 对微调方向进行多尺度结构分析，揭示 语言恢复所需的奇异方向远少于动作保留，为 VLM-VLA 融合提供了新的见解
  • 在 两种不同架构的 VLA（自回归 π0-FAST 和流匹配 π0.5）上验证方法的通用性，一致优于现有合并基线

04方法描述

  • 定义任务向量 Δ = θ_VLA - θ_VLM，并对其进行 SVD 分解，得到按重要性排序的奇异方向和奇异值
  • 将合并模型表示为 VLM 权重 + 每个奇异分量的加权和，每个分量对应一个可学习系数 α_k^(l) ∈ [0,1]，由 SVD 控制每个方向的保留程度
  • 优化目标为复合损失函数：包含 语言生成负对数似然损失、动作预测损失（自回归为 NLL，流匹配为条件流匹配损失）、以及分别向 VLM 和 VLA 输出分布靠拢的 KL 正则项
  • 使用 Adam 优化器 通过梯度下降直接优化混合系数，源模型权重和 SVD 分解结果均保持冻结

05数据集与资源

  • 模型：使用 PaliGemma-3B 作为 VLM；两个 VLA 变体为 π0-FAST（自回归动作 token 化）和 π0.5（流匹配连续动作解码），均由 PaliGemma 在机器人演示数据上微调得到
  • 训练数据：从 LIBERO 数据集 构建两个互补数据集：动作数据集 D_act（用 VLA 自身预测的动作块重新标注专家演示）和语言数据集 D_text（用 PaliGemma 为观测帧生成场景描述）
  • 评估数据集：COCO（图像描述）、VQAv2（视觉问答）、EQA（具身推理，包括物体状态、空间关系、属性识别三个子类）、LIBERO-Spatial/Goal/Object 以及 RoboCasa（厨房任务）
  • 训练资源：仅优化少量标量混合系数，源模型冻结，训练开销极低，未报告具体 GPU 配置

06评估与结果

  • 视觉语言能力：在 COCO 上 Ours_π0.5 达到 ROUGE-L 29.5、BERTScore 87.8、VQAv2 48.7，接近纯 VLM 水平；Ours_π0Fast 也显著恢复语言能力，远超固定系数基线
  • 具身推理：在 EQA 上 Ours_π0.5 达到 物体状态 32.3、空间 17.3、属性识别 19.5，整体优于所有合并基线；AdaMerging 在物体状态上略高，但动作性能崩溃
  • 机器人操作：在 LIBERO 三个套件上 Ours_π0.5 成功率达到 89.3/88.1/93.3，几乎追平纯 VLA 性能；Ours_π0Fast 达到 61.2/73.1/79.8；而 Model Soup、DARE、SLERP 等基线成功率基本为 0
  • 关键对比：所有现有合并基线（Model Soup、DARE、SLERP、AdaMerging）要么动作性能完全崩溃，要么语言恢复不足；本方法在 语言-动作双轴权衡空间的上部区域 取得最佳平衡
