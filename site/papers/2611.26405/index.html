02论文概述

  • 论文提出 TacInno，用于解决视觉-语言-动作（VLA）模型中触觉输入收益不一致的问题。
  • 核心观点：触觉变化中很大一部分可以从视觉观测和已执行动作预测，因此直接作为输入或预测目标会引入冗余，导致模型对触觉依赖不足。
  • TacInno 将视觉和动作无法解释的接触动态定义为 触觉创新（tactile innovation），并仅将其作为训练监督信号，而不在部署时增加额外模块。

03核心贡献

  • 通过 tactile-off 测试 证明现有视觉-触觉策略对触觉输入依赖有限，并将其归因于触觉信号的冗余性，提出 触觉创新 概念。
  • 提出 TacInno tokenizer：在视觉观测和已执行动作的条件下，将未来触觉变化压缩为 16 位离散编码，作为触觉创新的代理。
  • 提出 TacInno-VLA 策略：通过辅助编码预测损失学习触觉创新，编码仅作为训练目标，部署时移除 tokenizer 和辅助预测头。
  • 在 UniVTAC 六个仿真任务上平均成功率达 87.5%，比最强视觉-触觉基线高 10.7 个百分点；在四个真实世界任务上平均成功率达 70.5%，高 9.0 个百分点。
  • 消融实验验证视觉与动作条件、多帧编码、注意力掩码和编码预测损失的贡献。

04方法描述

  • TacInno tokenizer 采用编码器-解码器结构的时空 Transformer，并引入向量量化（VQ），将未来触觉观测窗口压缩为 4 个 token、每个 token 16 个取值的离散编码。
  • Tokenizer 的编码器和解码器同时以视觉观测和已执行动作作为条件，使编码保留视觉和动作无法解释的接触动态；时间注意力保持因果性。
  • TacInno-VLA 基于预训练 VLA π0.5 构建，在动作专家中插入本征状态 token、由轻量触觉编码器得到的 60 个触觉 token，以及 4 个可学习的编码查询 token。
  • 采用块状注意力掩码：编码查询可关注前缀、本征状态和触觉 token，但动作 token 不能关注编码查询，从而保证编码预测损失通过共享触觉表示影响动作预测。
  • 训练目标为流匹配损失、接触状态预测损失和触觉创新编码预测损失的加权组合；部署时只保留带 60 个触觉 token 的 VLA，不再需要 tokenizer 和辅助头。

05数据集与资源

  • 仿真数据集：UniVTAC 基准中 6 个接触丰富任务，包括 Insert Hole、Insert Tube、Lift Bottle、Lift Can、Pull-out Key 和 Put Bottle。
  • 仿真环境：Isaac Sim，使用两个由 Taxim 渲染的视觉-触觉传感器；每个任务 100 个演示，前 50 个训练策略，前 90 个训练 tokenizer，90–99 用于分析。
  • 真实世界数据：4 个任务，包括擦白板、插插头、扶起易拉罐和拧瓶盖，使用 Franka FR3 和 Xense 视觉-触觉传感器，通过 GELLO 以 30 Hz 采集 50 个演示，前 45 个训练。
  • 模型基础：策略基于 PaliGemma VLM 主干 + Gemma 300M 动作专家 的 π0.5；触觉 token 编码器为轻量 Transformer，视觉特征使用 DINOv2。
  • 论文未明确给出 GPU/TPU 型号、具体训练时长及显存配置。

06评估与结果

  • 仿真评估：TacInno-VLA 平均成功率 87.5%，超过 SimpleTouch（76.8%）、N0-VTLA（75.3%）、FTP-1（74.2%）、FTP-π0.5（60.2%）、π0.5（47.5%）和 UniVTAC-ACT（40.5%），并且是唯一在每个任务上均达到至少 75% 的方法。
  • 真实世界评估：TacInno-VLA 平均成功率 70.5%，高于 SimpleTouch（61.5%）和 FTP-1（58.5%）；消融设置如无编码损失（47.5%）、无触觉输入（51.5%）和 tactile-off（40.0%）均明显更低。
  • 消融实验（两个抓取任务平均）：完整 TacInno-VLA 为 83.0%；去除视觉/动作条件降至 62.0%，仅视觉条件为 69.5%，两帧编码为 76.5%，无注意力掩码为 68.0%，无编码损失为 76.0%，无触觉输入为 25.5%。
  • 触觉依赖分析：在 Lift Can 上，tactile-off 使 TacInno-VLA 成功率从 88% 降至 0%，Lift Bottle 从 78% 降至 4%；动作误差上，手臂动作误差增加 156%，夹爪动作误差增加 238%。
  • 触觉创新分析：在六个仿真任务上，视觉和动作无法解释的触觉变化平均占 37%；编码解释的比例在接触开始前和初始滑动时达到峰值。
