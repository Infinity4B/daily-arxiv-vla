EWAM: Emergent Depth-Wise Specialization in a Unified Embodied Model -- From Semantic Understanding through Visual Foresight to Action

2026-09-30 · 原文 · 翻译 · 2609.39973

论文提出 EWAM（Emergent Depth-Wise Specialization in a Unified Embodied Model），一个以动作（action）为中心的统一具身模型，旨在解决现有 VLA（视觉-语言-动作）模型与 WAM（世界-动作）模型在策略内部各管一块、动作计算偏向单一专家的问题。 通过非对称联合注意力机制，让 action token 在每一层都能读取语义（VL）、当前视觉、预测未来帧与动作信息，同时保持感知专家各自的独立角色。 论文发现并验证了一种自发涌现的深度方向专门化（emergent depth-wise specialization）：浅层主要关注 VL 语义特征、中间层关注预测未来帧特征、深层则以动作自注意力为主导，形成"语义理解 → 视觉预视 → 动作生成"的内部有序加工链。

Card 03 核心贡献

核心贡献

  • 提出了 EWAM 统一具身模型，采用动作中心化的非对称联合注意力（Action-Centric Asymmetric Attention），使动作流成为唯一的跨模态信息整合接口，同时保留 VL 专家与视频专家的独立源头身份。
  • 首次系统刻画了涌现的深度方向专门化现象：跨任务复现的"语义→预视→动作"注意力交接（handoff），且在不同去噪步骤间保持稳定；通过 checkpoint 追踪、层定向干预与反事实未来特征注入，证明了该组织是学习得到的、且对动作生成具有因果功能影响。
  • 提出了子任务感知后训练（Subtask-Aware Post-Training），通过语义子任务预测与相位索引回归，显著提升长时程任务的完成率。
  • 建立了人类第一视角视频学习新流程：将异构人类语料统一到相机相对末端执行器动作空间，支持跨具身预训练与真实机器人协同训练。
Card 04 方法描述

方法描述

  • 模型包含三个层对齐的专家流：VL 专家（基于 Qwen3-VL-2B 初始化，编码指令与当前图像）、视频专家（基于 Wan2.2-TI2V-5B 初始化，处理当前条件帧与噪声未来帧）、动作专家（嵌入噪声动作块）。
  • 注意力掩码设置为：动作查询可读 {视频、动作、VL} 全部键，而视频流仅读视频、VL 流仅读 VL，确保动作流是唯一跨模态读取者。
  • 视频与动作输出采用联合流匹配（Joint Video–Action Flow Matching）训练，推断时在同一前向过程中协同去噪，使不断演化的未来视觉特征直接参与动作计算。
  • 后训练阶段引入子任务相位划分：将长时程示范划分为语义相位，附加文本子任务标签与归一化相位索引监督（自回归子任务解码器 + 相位索引 MLP 头）。

Card 06 评估与结果

评估与结果

  • RoboTwin 2.0 清洁到随机（C2R）评估达到 72.1%，域内（in-domain）平均 92.9%，均超过现有 VLA、WAM 及混合基线。
  • LIBERO 仿真基准平均成功率 98.8%。
  • 三个真实机器人本体上均取得一致性能；人类视频预训练将保留机器本体成功率从 40.1% 提升至 66.9%；第一视角协同训练在场景变化下将真实机器人成功率从 10% 提升至 60%。
  • 因果验证实验（训练期结构消融、固定 checkpoint 深度干预、同任务反事实未来特征注入）确认了深度方向专门化对策略行为的实际依赖关系；子任务相位监督在仿真与真实长时程任务中均进一步改善任务完成率。
