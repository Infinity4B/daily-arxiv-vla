02论文概述

  • 提出 DexForesight 框架，解决灵巧操作中需要同时感知手部与场景动态的问题
  • 核心思想：在训练阶段利用动作条件空间世界模型从离线深度、运动学手部几何和演示轨迹中学习空间预见，再将其隐式地转移到策略潜在空间，使部署时仅依赖 RGB、语言和机器人状态即可具备预测性表征

03核心贡献

  • 提出 DexForesight，通过查询对齐将冻结世界模型的预测性特征注入策略潜变量，实现隐式空间预见，部署时无需世界模型执行、深度重建或显式未来生成
  • 开发一个动作条件空间世界模型，利用约 370 小时、60 个任务、5 个类别的演示数据，结合离线深度与运动学手部几何，同时预测 3D 手部点云位移和视觉特征变化，覆盖被遮挡手指的运动
  • 在 11 个 DexJoCo 仿真任务和 三个真实机器人任务（Close Box、Insert Battery、Screw On Lid）上验证，总体成功率分别达到 60.5% 和 58.3%，分别超越最强基线 9.6 和 8.3 个百分点

04方法描述

  • 空间世界模型以 RynnBrain 为骨干，输入多视角 RGB、语言、机器人状态历史，以及通过 Point-BERT 编码的手部几何点云和通过 OmniVGGT 编码的离线深度特征
  • 深度采用跨层融合策略：在骨干的多个层后通过交叉注意力注入几何 token，并利用 Attention Residuals 的跨层聚合机制进行路由，使模型学习如何组合不同层的深度信息
  • 使用 K=4 个未来时隙对演示动作进行条件化，生成动作条件世界查询；两个预测专家分别预测手部点云位移（Hand Flow Expert）和 DINOv3 视觉特征残差（Visual Dynamics Expert），并采用未来时域 dropout
  • 世界模型训练完成后冻结，将策略 VLM（仿真用 GR00T N1.7，真实机器人用 QwenVLA）中的策略查询与世界查询进行对齐，使用 token 损失和关系损失，对齐后的查询作为额外的条件 token 输入动作专家，辅助动作生成

05数据集与资源

  • 真实机器人数据：约 370 小时演示，涵盖 60 个任务、5 个类别（空间排列、装配与接触、旋转与关节、可变形物体、工具使用）；其中 100 小时子集使用 StereoAnyVideo 离线估计深度
  • 仿真数据：11 个 DexJoCo 任务（单臂和双臂），深度由 MuJoCo 直接渲染，无需立体深度估计
  • 模型组件：世界模型骨干基于 RynnBrain，视觉特征提取使用 DINOv3，深度编码使用 OmniVGGT，手部几何编码使用 Point-BERT；策略分别基于 GR00T N1.7（仿真）和 QwenVLA（真实机器人）

06评估与结果

  • 仿真：在 11 个 DexJoCo 任务上，DexForesight 总体成功率 60.5%，相比最强基线 Fast-WAM 的 50.9% 提升 9.6 个百分点，相比 GR00T N1.7 的 49.4% 提升 11.1 个百分点；单臂成功率 76.3%，双臂 41.6%
  • 真实机器人：三个任务总体成功率 58.3%，对比 WLA 50.0%、GR00T N1.7 48.3%、Cosmos3 30.0%、Fast-WAM 10.0%；推理时间仅增加 3.0 ms（1.3%）
  • 线性探针实验显示，冻结的 DexForesight 策略特征对未来手部运动预测误差低于基线，0.54 秒时预测误差从 13.59 mm 降至 10.01 mm，降低 26.3%，证明隐式空间预见成功转移
  • 消融实验表明：去除离线深度导致仿真成功率下降 10.8 个百分点（真实机器人下降 15.0 个百分点）；将跨层融合替换为上下文深度 token 导致大幅下降；用未来动作目标替代手部点云位移监督也导致下降，验证各组件重要性
