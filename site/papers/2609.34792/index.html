D$^2$-VLA: Dual-Memory Dual-Frequency Vision-Language-Action Model For Long Dynamic Manipulation

02论文概述

  • 解决长期动态操作中机器人需要记忆已不在视野内的任务线索（如空间配置、颜色提示、呈现顺序），同时对移动物体保持快速响应的挑战
  • 现有 Vision-Language-Action（VLA）策略依赖最新观察且为"无记忆"和"频率耦合"设计，刷新视觉上下文需要另一次昂贵的 VLM 前向传播
  • 提出 D2-VLA（Dual-Memory Dual-Frequency VLA），在预训练 VLA 的 KV-cache 接口上联合设计记忆访问和更新频率，实现持久记忆与快速控制的统一

03核心贡献

  • 揭示 VLM 与动作专家之间的时间不对称性：VLM 需要更广泛的历史上下文进行语义推理，而动作专家主要关注包含运动信息的最近观察 token 子集
  • 设计 Dual-Memory 方法，使 VLM 和动作专家能够基于独立的在线注意力统计从完整存储的 KV block 中选择性读取历史 token，在保留相关上下文的同时降低冗余计算
  • 开发 Dual-Frequency 机制，结合周期性 VLM 更新（慢速路径）与轻量级门控视觉适配器、快速记忆缓冲（快速路径），使动作专家能够在两次 VLM 刷新之间进行快速重规划而无需重新运行完整 VLM
  • 引入 DOMINO-Long 基准，包含 10 个要求长期保留任务相关信息并与动态物体交互的多阶段操作任务，在仿真和真实机器人评估中取得一致性能提升

04方法描述

  • Causal Temporal Modeling: 采用 block-wise causal KV caching，将观察按时间间隔分组为 block，组内使用双向注意力、组间使用因果注意力，允许增量编码当前观察并重用历史 KV 状态
  • Dual-Memory (Asymmetric History Selection): VLM 和动作专家分别使用 Read_VLM 和 Read_act 操作符，基于各自的在线注意力统计从完整存储的历史 KV block 中选择相关视觉 token，保留指令 token，实现组件特定的历史读取视图
  • Dual-Frequency (Multi-Rate Visual Conditioning):

- 慢速路径：每 V=75 环境步执行一次完整 VLM 前向传播，生成当前 block 的完整 KV 并存入慢记忆队列 Q_slow（容量为 4 个 block）

- 快速路径：每 E=25 步使用 Dynamic Feature Adapter（包含 Enc_ψ、Pool_ψ、全块残差预测器 F_ψ 和层-wise 门控 G_ψ）将当前图像特征融入最新的慢速锚点 KV block，生成 refined KV block 存入快记忆队列 Q_fast（容量为 2 个 block）

- 动作专家根据当前步数选择从慢记忆或快记忆读取历史 KV 进行动作生成

05数据集与资源

  • DOMINO-Long: 10 个多阶段操作任务，500 个演示（每任务 50 个），共 227,208 条观察-动作记录，平均 episode 长度 454.4 步（201–911 步），要求早期观察的线索在后期决策中使用
  • DOMINO: 35 个动态操作任务，基于 RoboTwin 2.0 和 SAPIEN 构建，使用 Aloha-AgileX 机器人本体
  • LIBERO-Long: 10 个多阶段操作任务
  • RoboTwin 2.0: 50 个双臂操作任务
  • 真实世界: Unitree G1D 平台，8 个长期任务（4 静态 + 4 动态）
  • 模型规模: 基于 π0.5 Base，包含 PaliGemma-3B VLM 和共享 flow-matching expert，新增 full-block visual KV adapter
  • 训练资源: AdamW 优化器，每批次 40 个 anchor groups，DOMINO 上训练 75K 更新，DOMINO-Long 和真实世界上训练 50K 更新

06评估与结果

  • 评估环境: DOMINO/DOMINO-Long 动态仿真（Aloha-AgileX）、LIBERO-Long、RoboTwin 2.0、Unitree G1D 真实机器人平台
  • 主要指标: Complete-task Success Rate (SR)（完整任务成功率）、Manipulation Score (MS)（操作质量分数）
  • 关键实验结果:

- DOMINO: SR 29.3%（对比 π0.5 的 9.6% 和 PUMA 的 17.2%），MS 40.6

- DOMINO-Long: SR 60.0%（对比基线 35.4% 和 20.6%）

- LIBERO-Long: SR 97.5%

- RoboTwin 2.0: SR 74.3%

- 真实机器人: 在 8 个长期任务（4 静态 + 4 动态）上成功率全面优于 π0.5 和 MemoryVLA

- 推理时 VLM 预填充、慢速去噪和快速去噪均保留 70% 历史视觉 token，使用独立评分，保留指令 token、当前去噪 block 和完整存储 KV
