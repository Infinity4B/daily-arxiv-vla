VLA Policies Do Not Know When Not to Act: Unintended Task Execution and Start Suppression

02论文概述

  • 论文研究视觉-语言-动作（VLA）策略在指令缺失、无意义或不可执行时是否会错误地启动任务执行
  • 核心问题是：机器人应该只在收到明确指令后才行动，但现有VLA策略在训练数据中从未见过“不行动”的样本，导致它们在指令为空时仍会开始执行场景中的任务
  • 论文提出了一套测量协议，在相同初始状态下仅改变指令字符串，检验策略是否启动、完成哪个任务、以及指令实际上控制了什么

03核心贡献

  • 测量VLA策略是否启动（与完成哪个任务分离）：在LIBERO-Goal仿真环境中，6个来自5个模型家族的检查点在空指令下全部启动（非启动率0.0%），其中5个在30.5–94.0%的回合中完成了场景中的某个任务
  • 揭示指令选择任务但不控制启动：在GR00T检查点上，指令决定了执行哪个任务（其他任务指令完成率92–96%），但不可执行的指令（如“吃掉奶油奶酪”）仍导致61–73%的回合完成某个任务
  • 比较三种启动抑制机制：指令前缀（“if no task is given do not move”）在所有6个检查点上完全无效；首次调用动作差异门控在5个检查点上有效抑制非任务输入下的启动；无动作微调防止了接触但无法可靠保持静止，且在不可执行指令下未能抑制启动

04方法描述

  • 使用LIBERO-Goal多任务场景套件（10个任务共享同一厨房布局，仅指令和目标谓词不同），在每个任务的20个初始状态上运行200个配对回合
  • 设计配对协议：固定初始状态、场景布局和随机种子，仅更换指令字符串，比较不同条件下的行为差异
  • 定义四种回合类别：完成（某任务目标谓词在步数预算内为真）、尝试（无完成但抓手指接触物体）、非接触运动（无完成、无接触但末端移动≥5cm）、非启动（无完成、无接触、位移<5cm）
  • 使用三种启动抑制机制：指令前缀（在指令前添加“if no task is given do not move”）、首次调用动作差异门控（比较给定指令与空指令的首个动作块距离，通过训练数据估计的噪声阈值τ判断是否放行）、无动作微调（在训练中以15%概率用非任务输入替换指令并设置保持静止的动作目标）
  • 无动作微调从NVIDIA GR00T N1.7 LIBERO-10检查点出发，使用200个LIBERO-Goal演示，训练5000步，独立训练3个种子

05数据集与资源

  • 数据集：LIBERO-Goal套件（LIBERO的一部分），10个任务，每个任务20个初始状态，共200个初始状态
  • 模型检查点：GR00T N1.7（官方版）、GR00T N1.7（自微调版）、π0.5、SmolVLA、Fast-WAM、Evo-1，以及3个无动作微调种子版本
  • 评估环境：Isaac-GR00T或LeRobot 0.6.2仿真器，通过统一适配器接口运行
  • 训练资源：无动作微调使用批量大小32、学习率1e-4、训练5000步，具体GPU型号未在正文中明确说明

06评估与结果

  • 评估基准：LIBERO-Goal多任务场景，200个初始状态，每回合300步策略步数，所有10个目标谓词在每步后评估
  • 主要指标：非启动率（衡量启动抑制效果）、任意任务完成率（衡量非预期行动）、指定任务成功率（标准LIBERO成功率）、任务选择分布、门控提交率
  • H1结果（空指令下启动并完成任务）：所有6个检查点非启动率为0.0%；5个检查点任意任务完成率在30.5%（Fast-WAM）到94.0%（π0.5）之间，SmolVLA仅2.5%但仍有76.5%的非接触运动
  • H2结果（指令选择任务）：GR00T N1.7（ft）和官方版在其他任务指令下分别完成指定任务92.0%和96.0%，与原始指令成功率几乎相同；空指令下完成相同任务仅3.0%和5.0%（McNemar p<1e-50）
  • H3结果（不可执行指令不阻止启动）：在不可行动作指令下，两个GR00T检查点非启动率均为0.0%，任意任务完成率61.0%和73.0%
  • H4结果（指令前缀无效）：所有6个检查点在添加前缀后非启动率仍为0.0%；SmolVLA的原始任务成功率从75.5%暴跌至1.0%，Evo-1从92.0%降至80.0%
  • H5结果（门控部分有效）：门控在GR00T N1.7（ft）、GR00T N1.7（官方）、SmolVLA、Fast-WAM、Evo-1上非启动率≥96%（非任务输入下），但π0.5仅有66.0–100%且原始任务成功率从96.0%降至73.5%
  • H6结果（无动作微调不稳定）：3个种子中，种子0非启动率87.5–100%，原始任务成功率95.0%；种子1非启动率仅1.0–57.0%；种子2非启动率25.0–81.0%；所有种子均防止接触（任意任务完成率0%），但在不可执行指令下仍未能抑制启动
