论文概述

Card 03 核心贡献

核心贡献

  • 提出 RoboBRIDGE 通用编排框架，策略无关（policy-agnostic），无需重训练或修改骨干模型即可赋予策略失败恢复、长时序一致性和跨域鲁棒性
  • 两阶段监控（Two-phase Monitoring）：轻量级成功检查 + 失败诊断，触发四级分层恢复策略（retry → regenerate → replan → re-perceive）
  • 反应式规划与异步感知（Reactive Planning with Asynchronous Perception）：感知与执行解耦为并发线程，仅在环境偏离当前计划时触发重规划，避免执行停滞
  • 原始技能微调（Primitive Skill Fine-tuning）：将操作分解为域不变基元（move、grip、rotate 等），每个基元配备专用 LoRA 适配器，降低域偏移敏感性
  • 在 LIBERO、RoboCasa 仿真及多机器人平台真实环境中，跨三种 VLA 骨干验证均取得一致提升
Card 04 方法描述

方法描述

  • 两阶段监控：Phase 1 用 VLM 周期性进行轻量成功检查（输出成功标志与置信度）；Phase 2 在高置信度失败时停机并由诊断模型推断根因，按计算开销递增选择分层恢复策略
  • 异步感知：感知线程持续将最新检测结果写入线程安全缓冲区（生产者-消费者架构）；执行线程在每个基元完成后比较计划观测与最新观测的散度（基于物体 3D 位置欧氏距离 + 物体集合对称差），超过阈值则保留高层动作序列、仅重生成后续基元技能
  • 基元技能微调：冻结 VLA 骨干，为每个基元训练专用 LoRA 适配器；控制器切换采用两级解析器——存在对应适配器则使用，否则回退到所有适配器的平均
  • 动作执行：输出 7-DoF 增量动作（平移/旋转/夹爪），以笛卡尔速度命令下发，支持 IK 求解器路径与失败回退，实现跨机器人运动学接口兼容
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO（Object/Spatial/Goal/Long 四个任务套件）、RoboCasa（24 个原子任务，每任务 50 条人类示教，共 1,200 条，SpaceMouse 遥操作采集）
  • 真实机器人平台：Franka Emika Research 3（搭载 Omron 移动底座）、UR7e
  • VLA 骨干模型：SmolVLA、π₀.₅、GR00T-N1.5-3B
  • 训练配置（GR00T-N1.5-3B）：LoRA rank 128、alpha 256、dropout 0.1，作用于 DiT 动作头与视觉投影层；AdamW + bf16，batch size 64，500 epochs，学习率 5×10⁻⁵
  • 模块组件：Perceptor 使用 Florence-2；Planner 与 Phase-2 Monitor 使用 Claude Opus 4.6；Phase-1 监控为约 5Hz 的轻量失败检测器，不阻塞控制回路
Card 06 评估与结果

评估与结果

  • 评估指标：成功率（SR），仿真中由模拟器判定，真实环境中以无人工干预完成任务目标为准
  • LIBERO 结果（w/o → w/RobBRIDGE）：LIBERO-Object +5.3%（4.7%→10.0%）、LIBERO-Spatial +1.1%（72.4%→73.5%）、LIBERO-Goal +1.2%（54.1%→55.3%）、LIBERO-Long +9.4%（10.6%→20.0%），长时序任务提升最显著
  • RoboCasa 平均提升：SmolVLA +3.5%（3.4%→6.9%）、π₀.₅ +2.5%（3.4%→5.9%）、GR00T-N1.5 +5.6%（4.2%→9.8%）；排除 PnP 任务后提升更明显（如 GR00T-N1.5 达 6.2%→14.7%）
  • 真实世界实验在多个机器人平台和任务上，在本体与环境变化下均取得鲁棒增益，验证了失败感知监控与恢复机制的有效性
