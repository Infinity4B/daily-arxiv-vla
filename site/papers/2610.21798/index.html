论文概述

Card 03 核心贡献

核心贡献

  • 从跨具身迁移视角研究人类到机器人的学习，关注在丢弃具身特定运动后，哪些任务进展结构仍应保持可迁移性。
  • 提出 CBST 方法，将共享的候选操作结构因果模型（SCM）与学习到的上下文因果束结合，保留与效果相关的条件和依赖关系，用于条件化机器人 WAM。
  • 在 LingBot-VA 和 Cosmos Policy 等 WAM 上系统评估 CBST，分析人类视频预训练、上下文特定因果选择及其对机器人控制的影响。
  • 明确区分任务意图/边界状态与具身特定运动细节，避免直接复现人类运动轨迹，也避免仅保留任务意图而丢失实现条件。
Card 04 方法描述

方法描述

  • 将连续执行过程组织为时间扩展的子任务，避免机器人逐步复现人类动作；用语义变量（任务条件 X、操作尝试 I、物体状态变化 D、局部效果 Y）描述局部任务过程。
  • 定义候选操作 SCM：人类与机器人共享任务级变量语义与候选依赖关系的假设空间，但具身特定的结构函数 $f_D^e$、$f_Y^e$ 可以不同。
  • 采用自然束（natural beam）特化的因果束条件：保留的父节点赋值须维持当前机制的实际输出（sustenance），且投影机制对保留输入保持非平凡响应性（responsiveness）；并需满足跨机制兼容性。
  • 定义因果子任务表示 $\sigma=(Y(u),\mathcal{C}_u,\mathcal{R}_u)$，即局部效果、保留父节点及其实际取值、以及投影局部机制中保留的父子关系。
  • 架构：ResNet18–GRU 视觉-时间编码器 + 语义预测头估计任务级变量 → 学习到的选择器在因果束约束下联合选择兼容的父节点子集 → 确定性渲染器将任务指令、可行目标与子任务信息转成语言条件 → 条件化冻结的 WAM 生成动作块与未来观测预测。
  • 训练目标：人类视频动作类别分类预训练损失 $\mathcal{L}_h$；机器人适应目标 $\mathcal{L}_{\mathrm{robot}}=\mathcal{L}_{\mathrm{sem}}+\lambda_m\mathcal{L}_{\mathrm{mech}}+\lambda_b\mathcal{L}_{\mathrm{beam}}+\lambda_{\mathrm{size}}\mathcal{L}_{\mathrm{size}}$。
  • 关键创新点：机制一致性损失 $\mathcal{L}_{\mathrm{mech}}$ 鼓励预测父变量在固定参考机制下复现标注输出；束损失允许存在多个可接受子集，尺寸正则项表达紧凑性偏好而非额外有效性条件；WAM 与文本编码器全程冻结。
Card 05 数据集与资源

数据集与资源

  • 人类视频预训练：Something-Something V2（SSv2），验证集含 24,777 个视频片段，预训练 3 个 epoch。
  • 机器人仿真基准：RoboTwin 2.0（Easy / Hard 设置）、LIBERO（含 LIBERO-Long）、RoboCasa（每任务 50 或 300 条演示）。

  • 模型主干：ResNet18–GRU 视觉-时间编码器；冻结的 WAM 主干为 LingBot-VA 与 Cosmos Policy（Predict2.5）。

Card 06 评估与结果

评估与结果

  • 评估方式：在官方成功判定标准下报告任务成功率（%），跨任务平均；对比基础 WAM 与代表性已发表策略（使用官方报告分数）。
  • RoboTwin 2.0：LingBot-VA + CBST 达 94.00%（Easy）/ 92.54%（Hard），优于 LingBot-VA 的 92.93% / 91.55%；亦超过 Motus（88.7 / 87.0）、$\pi_{0.5}$（82.7 / 76.8）等基线。
  • LIBERO-Long：CBST 配合 LingBot-VA 达 98.60%（基线 98.5±0.5），配合 Cosmos Policy（Predict2.5）达 97.33%（基线 96.6%）。
  • RoboCasa：Predict2.5 + CBST 在每任务 50 条演示下达 72.44%，高于主干 71.1%，并优于 GR00T-N1.5（64.1）、Video Policy（66.0）、FLARE（66.4）等。
  • 消融实验（RoboTwin Easy）：完整 CBST 94.00%；无人类视频预训练 92.80%；打乱帧序 92.94%；仅状态条件 92.82%；完整结构条件 93.42%；随机选择 92.56%；去除 $\mathcal{L}_{\mathrm{mech}}$ 93.18%。
  • 人类视频预训练分析：有序时序预训练 SSv2 验证 top-1 准确率 25.88%，高于打乱帧序的 22.15%，表明时序顺序对人类视频表征及下游机器人控制均有实用收益。
