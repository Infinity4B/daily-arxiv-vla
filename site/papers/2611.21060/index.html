02论文概述

  • 提出 MetricHand，一个面向度量世界空间（metric world space）4D 手部重建的几何感知流匹配（geometry-aware flow matching）框架
  • 解决现有自我中心视角（egocentric）方法依赖弱透视（weak-perspective）逐帧估计再提升至世界坐标所导致的深度歧义问题——该近似忽略了近距离下随关节变化的深度变化，使平移、朝向与关节姿态误差相互耦合，并在遮挡下进一步恶化
  • 核心洞察：将手-物体交互（HOI）区域深度先验编码为与手部关节关联的表示，同时为度量定位和遮挡鲁棒姿态估计提供共享几何条件

03核心贡献

  • 提出 MetricHand 框架：将 HOI 深度先验的空间结构和度量尺度与手部拓扑（21 个关节锚点）关联，为度量定位和遮挡鲁棒姿态估计提供共享几何条件
  • 提出几何感知的时序流匹配公式：结合质量感知条件（observation quality）与跨窗口重叠记忆（memory queue），联合生成世界空间平移、全局朝向、MANO 关节姿态与形状
  • 在 HOT3D、ARCTIC、DexYCB、HO3D 上取得最先进的手部重建结果，并在未见过的真实世界 HOI4D 视频上实现零样本（zero-shot）泛化

04方法描述

  • 多编码器架构：可训练的 WiLoR 初始化编码器提取手-物体外观特征；冻结的单目几何模型（Metric3D v2 / MoGe-2）提供全帧度量深度；冻结 DROID-SLAM 估计相机相对运动
  • RGB-D 融合：深度编码器处理归一化对数深度、有效性掩码与空间梯度，通过空间门控残差注入 RGB 特征图；Metric Head 在视线射线和对数深度坐标系中细化粗略 MANO 平移，实现度量世界坐标系下的粗估计
  • 拓扑感知采样：以 21 个投影关节为锚点，采用可变形采样（deformable sampling），注意力中加入图像距离、对数深度和反投影表面距离的几何偏置，使每个关节 token 保留支撑证据的空间组织
  • 观测质量建模：学习的质量分数区分离可得性与可靠性，将可靠内容与占位符加权混合，无需显式质量标注
  • 时空记忆队列：FIFO 队列按时间戳、手、关节身份索引，通过空间注意力和跨窗口时序注意力让被遮挡关节从可见关节及历史观测中检索上下文
  • 几何条件引导的流匹配生成：DiT 风格模块在每个积分步读取条件，采用修正流（rectified flow）线性路径与 3 步 Euler 积分，训练目标包含流匹配损失、度量/平移损失、姿态损失与时序加速度损失

05数据集与资源

  • 数据集：HOT3D、ARCTIC（移动自我中心相机）、DexYCB、HO3D，零样本评估使用 HOI4D
  • 手部表示：MANO 参数化模型（15 个局部关节旋转、10 维形状参数）
  • 基础模型：WiLoR 初始化的可训练外观编码器；冻结的单目几何深度模型（Metric3D v2 / MoGe-2）；冻结的 DROID-SLAM 估计相机运动
  • 训练资源：原文（截断部分）未明确说明具体 GPU/TPU 配置

06评估与结果

  • 评估环境：遵循 HaWoR 的 observed-track 评估协议，在 HOT3D 和 ARCTIC 的相同有效观测帧上共享协议比较
  • 评估指标：相机空间 MPJPE、RA-MPJPE、PA-MPJPE、WristErr（手腕定位误差）、绝对世界空间 MPJPE（ABS-W-MPJPE）、W-MPJPE、WA-MPJPE、世界空间加速度误差
  • 关键结果（相对 HaWoR）：

- 相机空间 MPJPE 分别降低 49.3%（8.60mm）和 52.9%（17.54mm）

- 绝对世界空间 MPJPE 分别降低 28.7%（20.58mm）和 21.7%（120.86mm）

- 手腕定位误差分别降低 48.5% 和 37.9%

- 世界空间加速度误差降低 44.2%（3.11 m/s²）和 64.3%（4.39 m/s²），验证时序一致性显著提升

  • 消融实验：移除拓扑感知采样使 ARCTIC MPJPE 从 17.54 升至 38.91mm；移除记忆队列使 HOT3D MPJPE 从 8.60 升至 15.42mm；几何条件仅在粗估计或仅第一步使用时性能显著下降，证明全程几何条件化的必要性
