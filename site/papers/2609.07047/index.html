Card 03 核心贡献

核心贡献

  • 引入 MEMOBench 基准，首个具有过程级记忆操作注释的机器人操控记忆基准，涵盖30个任务和1,500个演示
  • 定义可执行检查点（executable checkpoints）及记忆存储、更新、压缩率，实现记忆失败的精确定位
  • 评估标准与记忆增强的 VLA策略，揭示当前策略常能存储信息但难以更新和压缩记忆
  • 利用检查点语言进行受控记忆对齐，验证注释监督可提升不同记忆操作性能
Card 04 方法描述

方法描述

  • 采用双层记忆分类法：任务类型层（时间记忆、空间记忆、物体记忆、程序记忆）和记忆操作层（Storage存储、Update更新、Compression压缩）
  • 检查点注释：每个检查点包含粗到细的语言描述、模拟器谓词（predicate）和互斥的操作标签，谓词直接可在模拟器中验证
  • 记忆对齐目标：基于检查点语言提供三种训练监督——语义记忆对齐（Semantic）、对比记忆对齐（Contrastive）和帧级记忆对齐（Framewise）
  • 总损失函数结合动作损失与对齐损失：$\mathcal{L}_{\mathrm{total}}=\mathcal{L}_{\mathrm{action}}+\lambda\mathcal{L}_{\mathrm{align}}$
Card 05 数据集与资源

数据集与资源

  • 数据集规模：30个任务、1,500个训练演示、1,500个评估episode、4,200个检查点实例（来自84个模板）
  • 检查点分布：1,750个Storage实例、1,600个Update实例、850个Compression实例
  • 平台：基于 LIBERO/robosuite 栈实现，使用BDDL任务规范
  • 评估模型：$\pi_0$、$\pi_{0.5}$、OpenVLA-OFT、MemoryVLA、HiF-VLA 及 RoboMME Memory Module
  • 训练资源：所有模型在MEMOBench上微调，重规划间隔$k \in \{5, 20, 35, 50\}$
Card 06 评估与结果

评估与结果

  • 评估设置：30个任务、50个评估episode、1,200步时间 horizon、10步稳定化、基于种子7
  • 关键结果：最强记忆模块基线（$\pi_{0.5}$ + RoboMME Memory Module）平均成功率仅 31.9%，高存储率常伴随弱更新和压缩能力
  • 模型表现：MemoryVLA在部分指标上表现较好（如step=5时平均MUR达35.9%），但整体记忆操作能力仍显著不足
  • 记忆对齐：使用检查点语言进行语义、对比和帧级对齐可带来 modest gains，不同目标对不同记忆操作有益
  • 一致性验证：盲法重标注研究显示操作标签具有较高一致性，Fleiss' $\kappa=0.799$
