Card 03 核心贡献

核心贡献

  • 提出 RAP-WAM 框架，通过未来监督的动作表示与预测排练适配视频先验；记录的帧塑造动作生成特征，排练使策略暴露于自身预测误差产生的观测。
  • 设计动作响应驱动的时空信用机制：动作响应、当前预测误差和历史误差先验共同指导视觉监督，同时空间池化同一响应以分配未来动作步的监督强度。
  • 将执行引导的后训练与任务特定策略保留整合，利用评估反馈优化示范采样并保留互补的任务专家，无需单独评分网络或部署时探测。
  • 提供理论分析（附录 C），包括扰动响应的局部雅可比解释、信用重分配恒等式，以及"响应与预测误差不一定一致"的证明。
  • 在 42 个 RoboDojo 任务与 15 个真实机器人任务上系统验证方法，并公开诊断协议与执行证据。
Card 04 方法描述

方法描述

  • 未来监督动作接口：在视频-动作预测器中附加 K=16 个可学习查询 token，通过余弦对齐损失将查询表示对齐到记录的未来视频潜变量，并设置方向性注意力掩码（禁止动作 token 直接读取视频 token key）。
  • 耦合动作投影（CAP）：将最终动作 token 特征通过紧凑 MLP 与时间调制头之和预测动作流匹配速度，零初始化新增分支避免初始扰动。
  • 预测排练：对相邻示范块，用无梯度生成的第一块未来视频/动作替换第二块初始观测（可选状态替换），保留记录目标进行监督；将重复出现的误差累积为空间先验 P（网格 14×14，衰减 ρ=0.9）。
  • 响应派生的时空信用：在同一噪声水平下对动作输入加扰动 δ∼N(0, τ²I)，计算响应 S 与误差 E，通过归一化组合得视觉损失权重 W=1+α_P·N(P)+α_S·N(S)+α_E·N(E)，并空间池化响应得到动作步权重 w_j。
  • 后训练与策略选择：智能体根据执行证据提出干预，回放策略由 50% 自然回放、20% 任务平衡、15% 失败边界、15% 后期进度窗口组成；按 SR/Score 评估保留任务专家，不平均策略参数。

数据集与资源

  • 仿真评估基准：RoboDojo，共 42 个任务，覆盖 Generalization、Precision、Long-Horizon、Memory、Open 五类能力。
  • 真实机器人评估：15 个真实机器人任务。

  • 训练超参数示例：τ=0.1，λ_z=0.5，λ_a=0.3，λ_q=0.1，p_P=0.5，λ_c=1。
Card 06 评估与结果

评估与结果

  • RoboDojo 42 任务：RAP-WAM base 平均 SR 12.85%、Score 17.86；加入 refinement 后提升至 SR 15.62%、Score 20.59（分别提高 2.77 个百分点与 2.73 分）。
  • 能力分组增益：Precision 从 16.51%→21.03%，Memory 从 7.00%→9.33%，Generalization 从 7.50%→10.50%，Long-Horizon SR 从 32.50%→36.50%（Score 45.12→48.43）。
  • 真实机器人：15 个任务上完整系统达到 89.00% 任务宏平均成功率，超过最强基线 37.67 个百分点。
  • 信用信号诊断：315 个窗口中 45.21% 的 response-top20 位置落在 error-top20 之外，说明动作响应提供了预测误差之外的信息；归一化系数重分配中位数份额 P 为 5.47%、S 为 2.22%、0.5E 为 1.14%。
  • 局限：Open 任务成功率仍为 0.75%，random-Generalization 仍为 0，表明场景迁移鲁棒性尚未解决。
