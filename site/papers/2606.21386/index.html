VLA-FAIL: Efficient Task Failure Detection for Finetuned Vision-Language-Action Models

02论文概述

  • 针对视觉-语言-动作模型（VLA）真实世界部署中的任务失败检测需求，解决现有方法需昂贵动作采样、架构普适性差、依赖失败回滚数据的核心痛点
  • 提出VLA-FAIL轻量级失败检测框架，无需失败数据或外部模型，结合内部特征偏移与动作计划一致性两个互补信号，实现早期可靠的失败检测
  • 通过真实世界与仿真大规模实验验证框架的跨任务鲁棒性，同时提出AUCPDT指标平衡检测准确性与时效性

03核心贡献

  • 提出VLA-FAIL轻量级运行时失败检测框架，无需失败数据或外部模型，计算开销极小，适配主流VLA架构
  • 设计LLMD（最后一层token-wise马氏距离）检测器，通过固定先验噪声适配flow matching类VLA，消除动作采样随机性对特征的干扰，可检测动作看似正常但状态分布偏移的早期失败
  • 设计ACC（动作块一致性）检测器，利用滚动时域控制的重叠动作块，通过速度归一化的不一致性度量检测 erratic 行为的失败
  • 提出AUCPDT阈值无关评估指标，联合评估检测精度、召回率与检测延迟，解决传统指标无法兼顾检测时效性的问题
  • 在6个真实世界任务和LIBERO-Plus仿真基准上的大量实验证明，VLA-FAIL跨任务鲁棒性强，频繁 outperforms 计算成本高数倍的基线方法

04方法描述

  • VLA-FAIL采用双信号级联框架，同时监测LLMD（内部特征分布偏移）与ACC（动作块时序一致性），任一信号超过校准阈值即触发失败警报
  • LLMD创新点：针对flow matching类VLA，采用固定的随机高斯先验噪声计算无噪声的最后一层特征，在微调数据集上预计算每个token位置的均值与正则化协方差矩阵，推理时采用token-wise马氏距离的最大值作为OOD得分，可与动作生成并行计算，消除采样随机性对特征分布的干扰
  • ACC创新点：利用滚动时域控制下相邻时间步动作块的重叠区域，仅使用末端执行器3维绝对位置计算速度归一化的平均绝对误差，通过指数移动平均（α=0.9）平滑得分，捕捉持续的动作不一致性，仅需单步动作采样即可计算
  • 检测阈值采用时间常数共形预测带在无失败的校准数据上确定，无需依赖失败数据，适配时长差异较大的任务场景

05数据集与资源

  • 真实世界任务：6个多样化机器人操纵任务（Blocks、Stack T、Cups、Kitchen、Drawer、Mixer），每个任务约80条策略回滚，覆盖高精度、多模态演示、长时序多阶段、语言条件等不同场景
  • 仿真数据集：LIBERO-Plus大规模仿真操纵基准
  • 评估的VLA模型：π₀.₅（3.6B参数，基于PaliGemma VLM，每层跨注意力融合视觉-语言与动作特征）、X-VLA（0.9B参数，基于Florence-2-Large VLM，仅用最终编码器特征条件化动作专家）
  • 基线方法：ACE（动作分布熵）、STAC（重叠动作块分布散度）、Diff（扩散损失评估，需32个动作样本）
  • 训练与推理硬件：RTX 5090 GPU，VLA-FAIL检测器无额外计算开销，可与VLA推理并行执行

06评估与结果

  • 评估环境：覆盖真实世界与仿真场景，包含不同难度、不同模态、不同任务时长的多样化任务
  • 评估指标：PR（Precision-Recall AUC，阈值无关的检测准确性）、PDT（Penalized Detection Time，平衡检测准确性与检测延迟）、AUCPDT（联合精度、召回与检测时间的阈值无关指标）
  • 关键实验结果：

1. LLMD与ACC擅长检测不同类型的失败模式，仅两者的组合VLA-FAIL在几乎所有任务上保持鲁棒性能，单模块仅部分任务表现优异

2. VLA-FAIL在多数任务上PR与PDT指标优于或匹敌计算成本高数倍的基线方法，如Diff、STAC需32次动作采样，无法满足实时控制需求

3. 在高精度（Blocks、Stack T）、长时序（Kitchen、Drawer）任务上表现突出，例如Kitchen任务下X-VLA的PR达1.00，PDT仅0.20

4. 检测器计算开销极低，可与VLA推理并行，满足真实世界实时控制要求
