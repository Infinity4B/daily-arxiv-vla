论文概述

  • 针对视觉-语言-动作（VLA）自动驾驶模型，指出现有方法将稠密视觉观察直接映射到稀疏监督（语言指令/轨迹），导致关键场景信息被压缩或丢弃

Card 03 核心贡献

核心贡献

  • 提出Think Densely, Act Sparsely驾驶范式，从原理上解决 VLA 框架中的稠密信息丢失问题
  • 提出高效可解释的潜在专家认知链（Latent Expert Cognitive Chain），注入紧凑任务特定 token，渐进式内化视觉、语义和几何知识
  • 设计三个轻量密集感知头，分别对齐 DINOv3 特征、SAM3 语义分割和 DepthAnything3 深度
  • 提出混合轨迹规划形式：离散运动原语检索 + 连续偏移细化，提升轨迹鲁棒性与精度
  • 在多个自动驾驶基准上验证了方法的一致性和显著性能提升
Card 04 方法描述

方法描述

  • 采用 Qwen2.5-VL-7B 作为视觉-语言主干，输入多视角图像与任务语言指令
  • 在每视角视觉 token 后注入三组紧凑潜在 token：、、，每组 n=8
  • 从 VLM 第 4、10、18、28 层提取对应 token 的隐藏状态并跨层聚合，实现浅层到深层的层次化表示
  • 三个密集感知头：表示头用 MSE 对齐 DINOv3 特征；语义头用加权交叉熵预测 6 类驾驶相关语义；几何头用带掩码 Smooth L1 预测深度
  • 联合损失：交叉熵 + λ2*DINO + λ3*SAM + λ4*DEPTH，权重 λ1=1、λ2=0.5、λ3=0.5、λ4=1.5
  • 轨迹预测采用 2048 个运动原语 + 连续偏移细化
Card 05 数据集与资源

数据集与资源

  • 数据集：NuInstruct、DriveLM、OmniDrive（语言/感知任务）；nuScenes-Plan（开环规划）；NAVSIM-v1/v2 navtest（闭环规划）
  • 基础模型：Qwen2.5-VL-7B
  • 专家模型：DINOv3（ViT 840M 参数，预训练于 LVD-1689M）、SAM3、DepthAnything3（DA3NESTED-GIANT-LARGE，1.4B 参数）
  • 训练配置：学习率 5×10⁻⁵，训练 5 个 epoch，每个专家 latent token 数 n=8，8 张 NVIDIA H200 GPU
Card 06 评估与结果

评估与结果

  • NAVSIM-v1 闭环规划：PDMS 达 89.81，比 AdaThinkDrive 高 +2.31，比 VGGDrive 高 +1.05
  • NAVSIM-v2 navtest：EPDMS 达 89.44，比 VGGDrive 高 +0.94
  • NuInstruct：MAP 提升 +32.10（6.15→38.25），Accuracy 提升 +9.31（47.71→57.02），Average 达 43.52
  • DriveLM：Accuracy 提升 +15.46（64.35→79.81），Average 提升 +6.82（54.59→61.41）
  • 消融实验显示依次加入 DINOv3、SAM3、DepthAnything3 分别带来 +0.58、+0.24、+0.50 PDMS 增益
