02论文概述

  • 论文提出 MorphAct，一个上下文参数化（contextual parameterization）框架，使机器人策略能够随交互上下文变化而"形态改变"（morph），动态调整有效权重。
  • 针对的核心问题是：现有 VLA 策略在不同操作（operation）间共用一组固定参数，而不同操作偏好相互冲突的参数更新方向，导致共享参数难以同时适配各操作。
  • 论文通过原子任务（atomic-task）诊断实验揭示参数冲突现象，并据此设计一种共享的参数生成机制来缓解该冲突。

03核心贡献

  • 通过操作级诊断实验，识别出参数冲突是扩展机器人学习跨环境、跨交互的主要挑战之一。
  • 提出 MorphAct，其表示耦合（representation-coupled）生成器为视觉–语言模块与动作模块产生上下文相关的参数更新，并仅通过原生动作目标联合训练。
  • 在三个 VLA 骨干、两个仿真基准和四个真实世界任务上展示成功率提升。
  • 消融实验支持上下文生成与表示耦合两个关键设计的有效性。

04方法描述

  • 两个耦合生成器：$G_v$ 从多模态嵌入生成视觉–语言更新，$G_a$ 生成动作模块更新，二者通过策略的计算依赖关系耦合。
  • 表示耦合：动作侧参数生成以经过适配的 VLM 表示 $h_t$ 为条件，同时 $C_t$ 保留动作模块的原生条件路径，二者来自同一次适配后的 VLM 前向。
  • 结构化低秩合成：采用 HY-WU 的结构化合成原语，为两个模块使用不同的目标布局，生成 $A_{j,t}$、$B_{j,t}$ 低秩因子，避免显式构造稠密更新。
  • 联合训练：仅优化生成器参数与状态投影等，冻结主干；生成因子是可微中间输出，通过原生动作目标（条件流匹配）端到端训练。
  • 上下文级适配、块级复用：每个重规划步骤生成一次更新，并在整个动作块（action chunk）预测中复用，无需测试时优化。

05数据集与资源

  • 诊断实验：RoboCasa365 的 65 个原子任务，使用预训练的 π0.5 检查点。
  • 仿真基准：LIBERO（Spatial、Object、Goal、Long/LIBERO-10）、Meta-World（MT50 全部 50 个任务）。
  • 真实世界任务：Sort Letters、Sort Hardware、Deliver Water、Cabinet Storage，每任务 50 次物理 rollout。
  • 骨干模型：X-VLA、π0、π0.5。
  • 训练时生成器参数以 FP32 存储，内部注意力与前馈层支持 BF16；使用 AdamW、学习率 warmup、余弦衰减与全局梯度裁剪。
  • 推理成本：相比共享 LoRA，端到端动作块延迟增加约 18.00%–21.00%。

06评估与结果

  • 评估方式：闭环任务成功率（closed-loop task success）为主要指标。
  • LIBERO：X-VLA 从 93.05% → 97.20%（+4.15），π0 从 94.15% → 96.65%（+2.50），π0.5 从 96.85% → 98.60%（+1.75）；Long 提升最大。
  • Meta-World：平均成功率 X-VLA 55.54% → 63.11%（+7.57），π0 50.75% → 67.05%（+16.30），π0.5 48.70% → 64.42%（+15.72）。
  • 真实世界：四个任务均提升，增益 +8.00 至 +14.00 个百分点，Sort Hardware 从 8.00% → 22.00%。
  • 消融（X-VLA + LIBERO）：固定条件（Constant/Task-ID）显著低于 MorphAct；仅适配单模块（VLM-only 43.50%、Action-only 81.00%）低于双模块；使用适配后特征耦合相比未适配特征将均值从 86.00% 提升至 97.20%（+11.20）。
