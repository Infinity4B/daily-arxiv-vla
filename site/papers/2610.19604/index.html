ForceBench: Benchmarking Force Integration for Robotic Manipulation

02论文概述

  • 论文提出 ForceBench，一个用于评估机器人操作中六轴腕力集成设计的仿真基准。
  • 旨在解决现有力感知系统因任务、演示和控制设置差异而难以可靠比较力集成设计的问题。
  • 在统一协议下比较无力基线和六种力集成设计，并通过真实世界实验验证主要发现。

03核心贡献

  • 提出统一基准 ForceBench，包含八个任务、1,600个同步多模态演示以及任务级和类别级评估指标。
  • 在共享VLA骨干上对观测条件、辅助预测监督和时间力表示进行系统比较研究。
  • 在五个真实世界任务中进行800次试验评估八个系统，验证仿真主要趋势并揭示任务相关权衡。

04方法描述

  • 基于 Isaac Lab / Isaac Sim 构建，使用 Franka 机械臂和并联夹爪，在桌面和家庭环境中执行任务。
  • 八个任务分为三类：物理属性推断（Weight Sort、CoM Sort）、阻力依赖交互（Faucet Turn、Faucet Direction、Stove Turn、Stove Press、Drawer Pull）、接触丰富装配（Nut Thread）。
  • 力集成设计包括 Token Fusion、Prompt Fusion、Cross-Attention、Token Fusion + Pred、Temporal Prompt、Dual-Path Fusion，均在共享 π0.5 骨干上实现。
  • 观测包括外部和腕部RGB图像（224×224）、机器人状态（7维）、任务指令、六轴力/力矩；控制频率15Hz，物理仿真频率60Hz。
  • 采用任务特定脚本专家收集演示，仅保留成功轨迹；评估使用共享种子并行展开。

05数据集与资源

  • 仿真数据集包含 1,600 个成功演示（每个任务200个）。
  • 仿真任务数量为 8 个；真实世界评估使用 5 个任务。
  • 模型骨干为 π0.5（共享VLA骨干），未明确参数量；额外比较 π0、ForceVLA、ForceFlow。
  • 训练设置：仿真主实验10,000 steps，batch size 32；真实世界10,000 steps，batch size 64。
  • 仿真评估每个任务-方法对200 episodes，共 16,000 episodes；真实世界每个任务-方法对20 trials，共 800 trials。
  • 未明确说明GPU/TPU等训练硬件资源。

06评估与结果

  • 仿真中 Prompt Fusion 取得最高平均成功率 35.31%，比无力基线 23.25% 提高12.06个百分点；Dual-Path Fusion 为35.13%。
  • Dual-Path Fusion 在物理属性推断领先（85.75%），Prompt Fusion 在阻力依赖交互领先（20.80%）；Prompt Fusion 在Nut Thread上最高（34.00%）。
  • 预测监督将 Token Fusion 从23.56%提升至26.25%，但收益集中在特定任务。
  • 真实世界中 Prompt Fusion 和 Dual-Path Fusion 平均成功率 63.00%，基线 40.00%；仅Prompt Fusion在所有五个任务上均有提升。
  • 时间设计在装配任务上低于无力基线，说明收益与局限随任务类别变化。
