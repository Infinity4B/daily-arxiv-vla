02论文概述

  • 提出 VLA-Δ，一个将「当前状态与未来状态之间的物理状态变化」作为显式学习目标的通用视觉-语言-动作（VLA）框架
  • 针对的问题：现有 VLA 大多直接将观测映射到演示动作，缺乏对中间物理状态变化的显式监督，容易过拟合观测—动作对应关系，出现提前闭合夹爪、抓取失败后仍继续移动等物理动力学理解不足的失败
  • 现有中间推理/未来预测方法（Reasoning VLA、WAM、Latent-WAM）只监督高层任务语义或未来视觉外观，很少监督物理状态转移本身（物体位姿、空间关系、机器人-物体接触如何变化）

03核心贡献

  • 提出 VLA-Δ 框架，以物理状态转移为显式学习目标，同时建模任务语义与视觉运动变化，为连续动作生成提供更直接的监督
  • 构建约 484 小时、2400 万帧 的机器人演示数据集，并开发完整的自动化数据标注流水线，生成大规模多层级物理状态转移标注
  • 设计三重监督信号：Structured Transition Slots（结构化转移槽）、Optical Flow（光流）、Future-State Difference Text（未来状态差异文本），共同塑造统一的转移表示
  • 在 LIBERO 与 RoboTwin 上取得对比方法中最高成功率，真实机器人实验中 超越 π0.5
  • 监督信号仅在预训练阶段使用，下游微调只用动作学习目标，推理时不产生额外开销

04方法描述

  • 整体架构沿用 GR00T N1 的视觉-语言主干 + 动作专家设计，VLM 使用 Qwen3-VL-2B-Instruct，动作专家为 9 层 Diffusion Transformer
  • 引入可学习的 Physical State Difference Queries，与上下文序列一同输入 VLM 主干，读出 Query 位置隐状态得到物理状态转移表示 Z_t
  • Structured Transition Slots：9 类预定义语义监督目标（任务进度、任务阶段、目标位置、夹爪位置、运动与相对位移、可交互物位置、夹爪状态转移、接触转移、障碍风险），通过轻量预测头直接预测，使 Query 形成软性语义分工
  • Dense Optical Flow：用轻量光流解码器读取最后 N_flow 个差异 Query 的隐状态，监督同视角相邻帧的稠密二维位移，损失含全像素项与运动像素加权项
  • Future-State Difference Text：用 VLM 原生自回归目标生成自然语言差异描述（任务进度、空间位移、接触转移、物理约束），通过注意力掩码约束文本位置只能关注 Query 与前序文本，强制视觉语言信息经由 Query 传递
  • 动作专家通过交叉注意力接收 Z_t，结合独立编码的机器人本体状态，用 Flow Matching 从高斯噪声生成连续动作块
  • 联合预训练目标：L = λ_Text·L_Text + λ_slot·L_slot + λ_flow·L_flow + λ_act·L_act；下游微调仅优化 L_act
  • 自动化标注流水线：统一为 LeRobot v3 轨迹格式，用 Qwen3.8 做阶段切分与关键帧选取及语义标注，用 SAM 3 生成包围盒与分割掩码，用 UniDepth V2 估计深度，用 MegaFlow 离线估计稠密光流，GPT-5.6 复核复杂/冲突标注，并进行分层人工审计

05数据集与资源

  • 预训练数据集：约 484 小时、2400 万帧 机器人演示，来源为 DROID、MolmoAct、RH20T
  • 模型规模：VLM 为 2B（Qwen3-VL-2B-Instruct），视觉-语言模型权重由 ZR-0_base 初始化；动作专家为 9 层 Diffusion Transformer
  • 评测基准数据：LIBERO（40 个任务）、LIBERO-Plus（Language / Light / Background / Layout 四类扰动）、RoboTwin 2.0（Clean 与 Random 设置）
  • 真实机器人平台：AgileX PiPER 6-DoF 双臂机器人，每个任务 40 个独立回合，共 200 次试验
  • 训练使用 GPU/TPU 等具体算力资源在所提供的 HTML 原文中未明确说明

06评估与结果

  • 评估环境：仿真基准 LIBERO / LIBERO-Plus / RoboTwin 2.0 + 真实机器人实验；主要指标为任务成功率（Success Rate）
  • LIBERO：VLA-Δ 平均成功率 98.4%，为所有对比方法中最高（对比 π0.5 的 96.9%、GR00T-N1.7 的 97.0%、VLA-Adapter 的 97.3%、ZR-0 的 97.8%）
  • LIBERO-Plus：四类扰动下均保持较高成功率；Language 扰动下达到 89.0%，比 π0.5 的 82.6% 高出 6.4 个百分点，说明差异文本带来的显式语义降低了对语言表层变化的敏感度
  • RoboTwin 2.0：Clean 设置 90.06%、Random 设置 89.74%，均超越所有对比方法；比最强基线 ZR-0 分别高出 1.36 与 1.76 个百分点；从 Clean 到 Random 仅下降 0.32 个百分点（ZR-0 为 0.72，Motus 为 1.50）
  • 在 RoboTwin 的 BlocksRankingSize（渐进式空间重排）与 HangingMug（旋转、重抓、悬挂、多阶段接触转移）任务上取得最高成功率，验证多层级状态转移建模的有效性
  • 真实机器人：五项任务（避障、长程执行、精细操作、空间推理、环境泛化）平均成功率 68.0%；避障任务 42.5% 为对比方法最高，空间推理与精细操作也最高，长程与环境泛化列第二，总体优于 π0.5 约 5.5%
  • 消融实验（LIBERO 40 任务）：

- 基线（密集 VLM 特征）95.70%；加入 Query 机制提升 0.55 个百分点至 96.25%；仅用动作监督预训练提升有限

- Query + Difference Text → 97.20%；Query + Structured Slots → 96.90%；Query + Optical Flow → 97.35%

- 完整 VLA-Δ（三者全开）→ 98.40%

  • 表征分析：t-SNE 显示有 Structured Transition Slots 监督时 7 组 Slot Query 形成更紧凑、边界更清晰的聚类，且该结构在仅用动作目标微调后仍然保留；Query 注意力热图显示完整模型更集中于目标物体、夹爪、接触区域，而无转移监督的模型注意力更弥散、偏向无关背景
