02论文概述

  • 论文提出 TrajWAM，一种轨迹条件世界动作模型，用于提升视觉-语言驾驶规划能力。
  • 核心问题：驾驶记录仅提供已执行轨迹对应的未来观测，大量备选轨迹查询缺失标签，如何利用轨迹查询与观测未来共同改进驾驶策略。
  • 通过在共享规划器表征上添加辅助 BEV 未来学习，并联合事实重建与未标注轨迹分离，实现原生直接输出 waypoint。

03核心贡献

  • 提出 Trajectory-conditioned auxiliary training：外部 waypoint query 条件化共享 future-query 状态，将 BEV 监督与驾驶策略耦合。
  • 提出 joint learning from factual and unlabeled trajectory queries：事实重建锚定已执行轨迹的观测结果；单侧分离损失训练读出模块响应轨迹查询变化。
  • 通过 closed-loop gains supported by matched training controls：全量 Bench2Drive 220 路线评估验证规划性能；双种子控制量化轨迹条件、分离和正确查询配对的贡献；规划-预测联合诊断关联重建质量与查询响应。
  • 实测性能：在 Bench2Drive Base Set 上达到 91.53 DS 和 75.45% SR，超过 schedule-matched planning-only 基线 5.31 DS，多成功 9 条路线。

04方法描述

  • 基于 Qwen2.5-VL-3B 驾驶规划器，输入包含历史前视帧、当前六相机环视、自车状态、路线指令及固定 future-world query tokens。
  • 提出 Logged and Noisy Trajectory Queries：对已执行轨迹构建事实查询；通过前向距离缩放（0.7–1.3）和侧向高斯噪声（σ=2）生成扰动查询。
  • 使用 Trajectory Address + Latent FiLM：ActionEncoder 将轨迹坐标映射到 VLM 隐藏维度，FiLM 以缩放+偏移方式调制 shared future-query 状态；FiLM 投影零初始化，保持初始恒等变换。
  • 使用 DINOv3-aligned prediction：冻结 DINOv3 ViT-L/16 教师提取 BEV 目标特征（CLS+有效 patch tokens）；学习投影 V 输出 DINO 空间预测。
  • 损失包括：token-level 规划交叉熵、事实重建 MSE、以及单侧分离 hinge loss；训练中梯度路由到 ActionEncoder、latent FiLM 和最后 4 层 planner layers；推断时旁路辅助预测分支，直接生成 waypoint 并交由 PID 控制。

05数据集与资源

  • 数据集：Bench2Drive，Phase II 使用 226,656 条训练样本；全部 220 路线 Base Set 用于闭环评测。
  • 基础模型：Qwen2.5-VL-3B 规划器；DINOv3 ViT-L/16 作为冻结未来特征教师。
  • 训练资源：8 张 A100 GPU，BF16，有效 batch size 64，AdamW + cosine decay + 10% warmup，训练 24 epochs；规划层学习率 2e-5，TrajWAM 模块学习率 2e-4。
  • 推理资源：原生推理在 RTX 5090 上，中位生成时间约 3.5086 秒（对照组 DeepSight 约 3.4926 秒）。
  • 多种子评测使用 seeds 42 和 43；220 路线正式评测使用 seed 42。

06评估与结果

  • 评估基准：Bench2Drive Base Set 全部 220 条路线，报告官方 Driving Score (DS)、严格 Success Rate (SR)、Efficiency 和 Smoothness；多能力评测覆盖 Merging、Overtaking、Emergency Brake、Give Way、Traffic Sign。
  • TrajWAM 取得 91.53 DS 和 75.45% SR，超过 SparseDriveV2 的 89.15 DS 和 DynVLA 的 72.73% SR；Efficiency 171.41，Smoothness 15.27。
  • 相较 schedule-matched planning-only FT（86.22 DS / 71.36% SR），TrajWAM 提升 5.31 DS 和 4.09 个百分点，SR 对应多成功 9 条路线。
  • 组件消融：Base Planner（unconditioned future FT）85.34 DS / 73.18% SR；加入 trajectory conditioning 的 TrajWAM w/o separation 提升至 89.34 DS / 74.55% SR；再加入 separation 达 91.53 DS / 75.45% SR。
  • 多种子 120 路线固定子集：TrajWAM 均值 88.45 ± 0.34 DS，显著高于 planning-only FT 均值 82.90、TrajWAM w/o separation 86.40；正确轨迹配对相较 shuffled pairing 提升 4.25 DS。
  • 多能力表现：Merging 75.00%（最高），Give Way 50.00%（并列最高），Overtaking 82.22%（第二），Traffic Sign 77.37%（第二），Emergency Brake 65.00%；五能力均值 69.92%，整体第二、仅比 DeepSight 低 0.28 个百分点。
  • 预测诊断：trajectory conditioning 将未来 MSE 从 0.03110 降至 0.02985；正确配对训练的执行轨迹查询收益 MSE 为 6.00e-5，高于 shuffled pairing 5.70e-5。
