AgenticRoboRL: Bringing Coding-Agent Post-Training to Agentic Robotics

02论文概述

  • 论文提出 AgenticRoboRL 框架，将编码智能体的后训练方法引入智能体机器人领域，通过 SFT 和多轮强化学习提升机器人规划器自身的能力
  • 现有工作主要通过改进机器人 harness 和外部记忆来提升系统性能，但依赖强大的闭源模型作为规划器，且不提升规划器本身的能力
  • 论文要解决的核心问题：如何在不同执行机制的机器人 harness（VLA 技能调用 vs. 控制代码生成）之间，建立统一的规划器后训练流程

03核心贡献

  • AgenticRoboRL 是首个面向智能体机器人系统的通用后训练框架
  • 提出“先 SFT 后 RL”的训练方案：先用成功轨迹做监督微调初始化规划器，再用多轮 RL 优化，仅更新规划器而保持执行组件（VLA、感知、运动控制器）固定
  • 设计轻量级 harness 专属适配器，将记录的规划器模型调用与回合结果关联，无需共享底层动作表示即可支持不同 harness
  • 实验结果强劲：9B 规划器在 LIBERO-PRO 上无外部记忆时成功率从 18.1% 提升至 71.0%，接近 Codex (GPT-5.5) 带外部记忆的 72.1%
  • 承诺开源框架和训练好的规划器检查点

04方法描述

  • 训练配方分两阶段：监督微调（SFT）使用教师智能体（Qwen3.8-27B）的成功轨迹，将其转换为适应学生上下文的训练样本；多轮强化学习（RL）通过记录的规划器交互与回合结果关联进行优化
  • 关键技术创新：将共享 RL 接口放在模型调用边界而非底层动作边界，录制代理捕获每次请求的上下文、生成的 token ID 和 rollout 对数概率
  • harness 专属适配器是无可学习参数的转换代码，为每个回合报告任务、初始状态标识、尝试索引、奖励和有效性标志（区分任务失败与基础设施故障）
  • 采用留一法优势估计、双裁剪 PPO token 损失，任务成功作为唯一奖励（无中间奖励或长度惩罚）
  • 策略版本化回合：固定权重下收集回合、构建训练样本、更新规划器；训练器校验渲染提示词与记录的提示词 token 一致性，不匹配样本权重为零

05数据集与资源

  • 学生规划器：Qwen3.5-9B；教师模型：Qwen3.8-27B（提供教师轨迹并作为大模型性能参照）
  • 评估环境：LIBERO-PRO（800 回合，8 个评估套件）、LIBERO-Plus（10,030 个配置实例）、LIBERO 原始四个套件
  • 两个 harness：RPent（Harness VLA 发布的 VLA 调用 harness）和 CaP-X（控制代码生成 harness）
  • 数据划分：教师演示和 RL rollout 在初始状态 11–44 收集，评估用初始状态 1–10，状态 45–49 作验证集
  • 训练超参：SFT 用 AdamW，学习率 10⁻⁵，batch 64 目标回合，训练 1 epoch；RL 学习率 10⁻⁶，batch 128 个选中响应，每轮收集 384 个回合（RPent 共收集 2,304 回合、26,052 个响应、206 个优化步）

06评估与结果

  • 评估指标：任务成功率（%），LIBERO-PRO 每格聚合 100 回合（10 任务 × 10 初始状态）
  • LIBERO-PRO 结果：9B 规划器从 18.1%（原始）→ 65.1%（SFT）→ 71.0%（SFT+RL），无外部记忆；接近 Codex (GPT-5.5) 带记忆的 72.1%；超越原 27B 无记忆规划器（57.9%），也超越独立 VLA（50.0%）；RL 相对 SFT 的提升具统计显著性（符号检验 p=0.001）
  • LIBERO-Plus 鲁棒性结果：原 9B 规划器 19.2% → SFT 66.7% → RL 72.2%（无需额外训练）；在非 LIBERO-Plus 训练的方法中总体成功率最高
  • 跨 harness 泛化：在 CaP-X harness 上，后训练将成功率从 2.7% 提升至 28.5%，证明框架不局限于 VLA 技能调用机制
  • RL 相比 SFT 在 LIBERO-PRO 配对回合上净赢 47 回合（赢 121 / 输 74，p=0.001）；LIBERO-Plus 上净增 548 个成功回合
