02论文概述

  • 论文提出 Embodied Vision-Language Model（eVLM） 范式，将操作（manipulation）与认知（cognition）统一到一个共享的扩散 VLM 中，而不是把动作处理作为外部附加模块。
  • 现有 VLA 常通过离散动作 token 或独立动作专家等方式造成表征解耦或计算/参数解耦，破坏物理误差几何并导致梯度冲突。Concertina 解决的核心问题是如何在保持 VLM 架构、原生预训练范式和视觉语言泛化的前提下，让模型原生输出精确的连续动作轨迹。

03核心贡献

  • 提出 eVLM 范式：动作直接在 backbone 的连续隐藏空间中表示、生成和监督，保留 VLM 的架构、训练范式与泛化能力。
  • 提出 Concertina 架构：将 horizon-\(H\) 轨迹表示为 \(H\) 个连续 latent action token，采用块级 causal-bidirectional 拓扑与 packed teacher forcing；动作接口仅占 0.21% 参数，无需外部动作专家、tokenizer 或 codec。
  • 提出 Action Interface Audit 评估方法：包括 EGC、TCA（NLR）、ASCR 三类指标，用于审计不同 VLA 中动作表征、轨迹耦合和参数容量的位置。
  • 在大规模闭环基准上取得 state-of-the-art 结果：regular LIBERO 平均成功率 98.15%，LIBERO-Plus 总体 85.9%，CALVIN ABC–D 平均完成链长 4.142。

04方法描述

  • 使用 BARD-VL 初始化共享扩散 VLM；每个控制时间步采用完整动作向量，通过 position-wise encoder \(E_\phi\) 映射为单个连续 latent action token，再通过 position-wise decoder \(D_\psi\) 恢复物理控制坐标。
  • 块级生成拓扑：将 horizon 分为多个 action block，块间保持因果顺序，块内双向并行重建；训练时把条件前缀、corrupted 动作和 clean teacher-forced 动作打包到同一序列，单次前向传播即可监督所有块条件分布。
  • 训练目标采用 block-stratified corruption 和 physical-coordinate reconstruction loss：对有效维度计算 Smooth-\(L_1\) 回归或 gripper BCE，并按 mask 概率进行逆重加权，梯度端到端更新 \(E_\phi\)、\(F_\theta\)、\(D_\psi\)。
  • 推理采用 risk-guided blockwise decoding 和滑动窗口闭环执行；position-wise 接口自身不产生跨时间耦合，所有轨迹级依赖都由共享 VLM backbone 的中后期层计算。

05数据集与资源

  • 主要基准数据集：regular LIBERO、LIBERO-Plus、CALVIN ABC–D。
  • 预训练使用多具身 mixture，规模为 80.2M frames；下游在 LIBERO 和 CALVIN 上微调。
  • 模型总参数量为 4.46B，其中动作接口仅占 0.21%，无外部动作专家或独立 trajectory generator。
  • 训练资源：使用 8 GPUs；预训练全局 batch size 为 1,536，LIBERO 微调全局 batch size 为 448。

06评估与结果

  • 评估环境：常规 LIBERO 四个套件共 2,000 条 episode；LIBERO-Plus 共 10,030 个扰动任务；CALVIN ABC–D 在 unseen environment D 上评估 1,000 条五步指令链。
  • 主要指标：LIBERO 使用成功率（%）；CALVIN 使用平均完成链长（AvgLen）和 SR@\(k\)。
  • 关键结果：regular LIBERO 平均成功率 98.15%（Spatial 99.0%、Object 100.0%、Goal 98.8%、LIBERO-10 94.8%）；LIBERO-Plus 总体 85.9%（8,615/10,030），比 EFFVLA 高 +6.1、比 OpenVLA-OFT 高 +16.3。
  • CALVIN ABC–D 平均完成链长 4.142，SR@1 为 98.6%，SR@2 为 93.8%，优于共享 backbone 的扩散策略 LLaDA-VLA。
  • Action Interface Audit 显示：均匀离散 bin 的单 token 错误导致 25.14× 物理误差跨度；FAST 式压缩 token 在单 token 编辑下出现 77.9%–82.2% 结构解码失败；外部动作专家 ASCR 为 16.51%–35.10%，而 Concertina 仅为 0.21%，且跨时间耦合集中于 VLM backbone 中后期层。
