VFlash: Fast, Accurate Visual Planning via Flash Primitive Decoding

02论文概述

  • 提出 VFlash，一个面向物理 AI 任务（机器人、自动驾驶）的快速、准确视觉规划解码框架。
  • 解决自回归视觉语言模型（VLM）逐 token 生成视觉基元（点、边界框、轨迹）导致的低效率问题，难以在固定延迟预算下支持高空间细节。
  • 通过 Flash Primitive Decoding 并行预测完整视觉基元，在提升解码速度的同时保持或超越自回归目标的空间精度。

03核心贡献

  • 提出 Flash Primitive Decoding (FPD)：将草稿预测块与视觉基元的已知结构（类型、维度、长度）对齐，允许一个前向传播预测整个基元（几十到上百 token）。
  • 发现轻量级扩散草稿模型可以在空间精度上超越其自回归目标 VLM，打破“自回归解码是质量上限”的假设。
  • 设计两种对齐原则：边界对齐（每个块覆盖一个完整基元）和位置对齐（每个位置有固定角色，支持并行约束解码）。
  • 支持多种视觉基元类型：边界框、变长 2D/3D 轨迹、密集 3D 运动预测，并可扩展到文本 token 坐标表示。
  • 在多个基准上验证有效性，包括下游任务（MolmoSpaces 平均成功率 70.2% vs 基线 62.6%），以及约 25× 生成加速（3D 点运动预测）。

04方法描述

  • 基于 DFlash 的块扩散草稿架构：冻结目标 VLM，利用其隐藏层特征训练一个浅层非因果 drafter，预测完整视觉基元。
  • 训练：使用标注的视觉基元（而非目标 VLM 的续写）作为标签，最小化加权交叉熵；每个完整基元作为一个训练块，支持特殊 token 和固定宽度文本数字网格两种坐标表示。
  • 推理：解码文本时采用常规 speculative decoding（token 级验证）；当检测到基元起始 token 后，根据 schema 确定块长度 B(s)，一次性并行预测整个基元，通过结构验证和逐位置约束直接接受，无需 token 级一致性。
  • 若不满足验证条件，则回退到受限的自回归生成（仅用于边界框），普通文本仍保持验证解码以无损保持目标分布。

05数据集与资源

  • 数据集：ShareRobot-Bench、VABench-V（2D 轨迹）；COCO、Dense200（边界框）；InternA1、AgiBot、MolmoBot（3D 机器人轨迹）；PointMotionBench（含 HOT3D、WorldTrack、DAVIS，密集 3D 运动预测）；MolmoSpaces（下游操作任务）。
  • 模型：基础 VLM 为 Qwen3-4B（4B 参数） 搭配 MoonViT 视觉编码器；VFlash drafter 为 5 层浅层扩散模型；密集运动任务使用 MolmoMotion-AR 作为目标模型。
  • 训练资源：未在摘要中明确列出具体 GPU 型号，但论文提及在 NVIDIA Jetson Thor、DGX Spark、H100 平台上进行部署和延迟评估。

06评估与结果

  • 评估基准：上述数据集，使用指标如 DFD、HD、RMSE（2D 轨迹）；F1、BPS（边界框）；ADE、FDE、SR@5、SR@10（3D 轨迹）；ADE、FDE、PWT（密集运动）；任务成功率（MolmoSpaces）。
  • 关键结果：

- 2D 轨迹：VFlash 在所有六个误差指标上均优于其 AR 目标；在 VABench-V 上相对先前最佳模型 LoHo-Manip 降低约 40% 误差。

- 3D 轨迹：3D-only 目标下 ADE 降低 18–49%，2D+3D 目标下降低 28–61%；AgiBot 数据集上 5cm 准确率从 50% 提升至 73%（3D-only）。

- 密集 3D 运动：DAVIS 上 ADE 降低 27%、FDE 降低 19%；单次生成速度约为 AR 的 25 倍。

- 边界框：带 AR 回退的 VFlash 在保持平均 F1 与 AR 相当的同时，解码速度提升 2.6–2.8 倍；直接模式在 Dense200 上 BPS 达 22.66。

- 下游应用：在 MolmoSpaces 四个任务套件上，条件于 VFlash 计划的 world action model 平均成功率为 70.2%，高于基线 62.6%；机器人操作管道在 Jetson Thor 和 DGX Spark 上推理延迟降低约 80%。
