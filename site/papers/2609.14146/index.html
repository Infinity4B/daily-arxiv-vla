When Faster VLA Deployment Changes Closed-Loop Behavior: Task Success-Latency Analysis of SmolVLA Across PyTorch and ONNX Variants

02论文概述

  • 本文针对视觉-语言-动作（VLA）模型部署中的核心矛盾展开研究：更快的部署配置虽然能降低推理延迟，但可能改变闭环控制下的任务行为，且现有评估常混淆开环数值一致性与闭环任务成功率
  • 研究以HuggingFaceVLA/smolvla_libero为对象，在NVIDIA RTX 2060 6GB平台上，对比PyTorch+AMP与ONNX Runtime CUDA Execution Provider两种部署配置，在LIBERO Spatial和Object任务集上评估任务成功率与延迟的权衡
  • 同时探究静态语言上下文宽度这一部署接口约束对闭环行为的影响，揭示部署全链路变量（框架、运行时、接口定义）对任务表现的耦合影响

03核心贡献

  • 实证证明更快的ONNX+CUDA-EP部署配置无需保持LIBERO Spatial任务的闭环成功率（下降约30个百分点），而Object任务成功率维持相近水平
  • 通过16/24/32 token的静态语言上下文宽度消融实验，证明语言宽度是测试栈中Spatial任务成功率差距的重要贡献因素
  • 通过图级审计发现，工具链请求的INT8精度标记并未实际执行算子级INT8量化，请求的INT8与FP16导出文件为字节相同的FP32图
  • 提供证据证明开环数值一致性不保证闭环任务成功率，包括300集配对rollout结果和开环相似度~0.98但闭环成功率0%的早期适配器案例

04方法描述

  • 实验平台为Linux工作站，搭载NVIDIA RTX 2060 6GB（Turing架构）GPU，软件栈包括MuJoCo 3.3.2、LeRobot 0.6.1、tether 0.12.0、ONNX Runtime GPU 1.22.0，无物理机器人及Jetson边缘设备参与
  • 设置多组部署配置对比：(1) PyTorch+AMP baseline；(2) 通过tether导出的默认宽度16的ONNX CUDA EP配置（分别请求FP16、INT8精度）；(3) 调整静态语言上下文宽度为24、32的ONNX导出配置
  • 配套验证手段包括：开环动作一致性检查（余弦相似度、最大绝对差）、导出ONNX图的精度与结构审计、相同控制循环下的配对闭环rollout实验
  • 核心创新在于不提出新模型或量化方法，聚焦部署全链路（框架转换、运行时、接口约束）对闭环行为的影响，揭示传统仅关注延迟或开环一致性的部署评估的不足

05数据集与资源

  • 评估数据集：LIBERO Spatial和Object任务集，各包含10项机器人操作任务，采用MuJoCo 3.3.2仿真环境，固定动作步长、随机种子等协议参数
  • 基础模型：HuggingFaceVLA/smolvla_libero，由SigLIP视觉塔、SmolLM2语言骨干、10步流匹配动作专家组成，输出7-DoF动作序列
  • 计算资源：仅使用个人硬件的NVIDIA RTX 2060 6GB GPU，无雇主资源、物理机器人或边缘设备参与实验

06评估与结果

  • 评估环境与设置：主评估每任务10集、每套任务集100集，配对rollout每任务30集、每套300集，固定随机种子seed=42，报告Wilson 95%置信区间及配对McNemar统计检验结果
  • 核心评估指标：LIBERO闭环任务成功率（%）、推理p50/p99延迟（ms）、进程级峰值GPU内存（MB）、开环动作余弦相似度与最大绝对差
  • PyTorch+AMP baseline达成Spatial 70.0%、Object 88.0%的闭环成功率，p99延迟1181ms，峰值内存2208MB
  • 默认宽度16的ONNX CUDA EP配置将p99延迟降至601ms（请求FP16）/532ms（请求INT8），但Spatial成功率骤降至41.0%/40.0%，Object成功率维持89.0%
  • 图审计证实请求的INT8导出文件与FP16导出文件字节完全相同，无INT8量化算子，两者延迟差异无法归因于INT8量化
  • 将静态语言上下文宽度扩展至24时，Spatial成功率恢复至75.0%，与PyTorch baseline无统计学显著差异（双比例χ²检验p=0.53），p99延迟仅小幅升至587.7ms，Object成功率维持90.0%左右
  • 300集配对rollout复现了Spatial/Object的成功率差异模式（PyTorch Spatial 56.7% vs ONNX 33.0%，Object 73.3% vs 74.0%），且开环余弦相似度~0.98的适配器仍出现0%闭环成功率，证明开环数值一致性无法等价于闭环任务表现
