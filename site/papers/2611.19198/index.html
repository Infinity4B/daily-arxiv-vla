Self-Calibrating Vision-Agent-Action: Deploying Pick-and-Place to New Robot Cells without Demonstrations or Fine-Tuning

提出 Vision-Agent-Action (VAA) 框架，在不使用机器人演示或微调的情况下，实现拾取放置任务向新机器人单元的迁移

02论文概述

  • 提出 Vision-Agent-Action (VAA) 框架，在不使用机器人演示或微调的情况下，实现拾取放置任务向新机器人单元的迁移
  • 针对部署到新单元时面临的硬件变化（夹具、基座坐标系、摄像头位姿/镜头、光照、物体外观等）导致 VLA 性能大幅下降的问题
  • 通过受控实验诊断出 夹具变化 和 基座坐标系旋转 是造成 VLA 迁移失败的主导因素

03核心贡献

  • 对 8 个公开的 LIBERO 微调 VLA 模型进行受控因子诊断，确定夹具和指令坐标系变化为 VLA 迁移损失的主导因素
  • 提出 自校准 VAA 流水线，结合指令映射测量、摄像头几何与镜头畸变估计、基于实测深度的抓取规划
  • 在 18 个含夹具或基座框架变化的单元上，VAA 达到 268/360 (74%) 成功率，显著优于最强 VLA 的 76/360 (21%)
  • 通过配对消融实验验证自校准包、镜头估计和实测深度各自的作用
  • 在 LIBERO-Goal 两步链条 任务中，VAA 在变化单元上完成 54/60 条链，而四个评估的 VLA 完成 0 条

04方法描述

  • 自校准单元建模：机器人通过执行小幅运动测量 TCP 位移，建立指令通道到末端运动的映射矩阵 J；同时测量指尖开合宽度和稳定时间
  • 摄像头与镜头几何估计：利用指尖在多个位姿下的观测，结合运动学先验估计内参 K、外参 [R\|t] 以及径向畸变系数 k₁（以桌面平面度为约束）
  • 语义理解与几何执行分离：使用预训练 VLM（Qwen3.8, 27B）标注物体提案，使用预训练 LLM（Qwen3, 30B instruct）解释指令选择目标和目的地
  • 深度抓取规划：利用物体自身三维点云选择夹取位置，由实测夹具开度约束可行抓取几何，并通过实测深度完成闭合伺服与放置验证
  • 校准复用：初始校准后通过约 90 步的漂移检查决定是否复用单元模型或重新校准

05数据集与资源

  • 使用 LIBERO-spatial 数据集（10 个任务 × 2 个初始状态，共 20 个回合/单元）进行改变单元评估
  • 使用 LIBERO-Goal 进行两步链条任务评估
  • VAA 使用 RGB-D 摄像头 与本体感知；VLA 基线仅使用 RGB 图像
  • 评估的 VLA 基线包括 X-VLA、π0.5、π0、GR00T N1.7、OpenVLA、SmolVLA、τ0 和 VLA-JEPA
  • 所有实验在 模拟环境 中进行；VAA 的初始校准成本为每单元 2.2–6.5 千仿真步，后续漂移检查约 64–86 步

06评估与结果

  • 在 18 个包含夹具或基座框架变化的设计单元上，冷冻 VAA 成功 230/360 (64%)，精炼 VAA 达 268/360 (74%)，最强 VLA（X-VLA）仅 21%
  • 在 5 个整体开发压力测试单元上，VAA 实现 68/100 成功，最强 VLA 仅 10/100
  • 配对消融（表 III）显示：复用训练设置校准导致成功降至 22/60；无镜头估计降至 32/60；用单目深度替代实测深度降至 20/60；全系统为 50/60
  • 在两步链条任务中，VAA 在变化单元上完成 54/60 条链，VLA 完成 0 条；在训练设置上 VAA 完成 16/20，VLA 完成 0
  • 失败分析显示剩余 VAA 失败主要集中在 离目标放置 (41)、重新抓取失误 (19) 和 抓取失误 (27) 等接触/放置阶段
