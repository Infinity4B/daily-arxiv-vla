02论文概述

  • 论文针对接触密集型机器人操作中的"阶段依赖性感官冲突"问题：在非接触阶段（定位、对准、接近）视觉与本体感觉最为关键，力反馈多为噪声；而在接触之后，力反馈变得至关重要，视觉细节和与演示进度相关的机器人状态反而可能成为捷径。
  • 提出 DEFT-VLA（Dual-Expert Force-specialized Training for Vision-Language-Action Manipulation），将力专用化局部化到真正需要力反馈的接触阶段，同时保留任务适配的基础专家处理视觉主导行为。
  • 目标是回答两个问题：能否把力专用化限制在接触关键阶段而不破坏视觉主导策略？在该专家内部能否同时抑制视觉与本体感觉捷径，使力反馈真正"有用"而非仅"可用"？

03核心贡献

  • 提出阶段专用双专家 VLA 框架：保留一个任务适配的基础专家用于非接触行为，并在接触阶段演示数据上单独训练一个力感知接触专家。
  • 提出接触局部化力关注课程（contact-localized force-attending curriculum），包含视觉模糊抑制与状态 token 掩码，以减少接触期的视觉与本体感觉捷径。
  • 基于 π₀.₅ 构建共享多模态 VLM 前缀与两个独立动作专家，接触专家额外接收力 token，并采用学习式滞回路由（阈值进入/退出 + 连续稳定决策）自动切换专家。
  • 在三个真机接触密集型任务上验证，整体成功率相比最强基线提升 20–40 个百分点，增益集中在接触阶段。
  • 提供握持高度泛化实验与状态 token 掩码消融，证明掩码对减少本体感觉捷径的重要性。

04方法描述

  • 架构基础：基于 π₀.₅ 构建，包含共享多模态 VLM 前缀（图像 token、语言 token、序列化状态 token）与两个独立参数的动作专家；两专家均通过原逐层注意力读取共享前缀，仅接触专家额外输入力信息。
  • 两阶段训练：先用完整演示将 π₀.₅ 适配到目标任务，得到任务适配 VLM 与基础专家；随后冻结二者，从基础专家初始化接触专家，仅用接触阶段数据更新接触专家及其力输入模块。
  • 力 token 构造：将最近腕部力/力矩历史 \(\mathcal{F}_t^C\) 归一化后展平并线性投影为力 token \(z_t^F\)，与动作 token 拼接到接触专家后缀中；基础专家后缀不含力 token。
  • 接触数据筛选：以力阈值 \(\delta_{task}\) 并结合时间邻域 \(\mathcal{W}_t=\{t-m,\ldots,t+n\}\) 标注接触阶段，构建接触数据集 \(\mathcal{D}_C\)，保留接触起止过渡上下文。
  • 自动专家路由：轻量阶段估计器对冻结 VLM 图像 token 做注意力池化、用 MLP 编码机器人状态、用因果 GRU 处理力历史，拼接后经融合 MLP 与 sigmoid 输出；采用不同进入/退出阈值与连续稳定判定避免频繁切换，切换时丢弃并重生成未执行的动作块。
  • 课程策略：早期对输入图像施加强高斯模糊（\(\sigma_s=\sigma_{max}\lambda_s\)），同时以概率 \(p_s=p_{max}\lambda_s\) 对状态 token 做伯努利掩码（替换为词汇表索引 0 的 token 嵌入）；\(\lambda_s\) 先保持、再线性衰减至 0，逐步恢复完整观测。
  • 创新点：不同于 ForceVLA 的单策略内 FVLMoE 路由与 FACTR 的全局课程，DEFT-VLA 在参数独立的双专家之间切换，并将课程严格局部化到接触专家。

05数据集与资源

  • 机器人平台：Elephant Robotics Mercury B2 双臂机器人，控制频率 15 Hz
  • 传感器：3 个 Intel RealSense D435 相机（2 个臂载近距离视角 + 1 个外部第三人称视角）；每个腕部配备六轴力/力矩传感器
  • 自采演示数据：移液枪枪头装配 130 条演示；双臂移液吸取、白板擦拭各 50 条演示

  • 训练设置：接触专家与阶段估计器训练 30,000 步，批大小 8

06评估与结果

  • 评估方式：三个真机任务（移液枪枪头装配、双臂移液吸取、白板擦拭），每方法每任务 20 次真机试验；物体随机放置且各方法共享同一组测试位置
  • 评估指标：整体任务成功率、非接触阶段成功率、接触阶段成功率（以前序阶段成功为条件）；吸取任务额外测量吸取体积 MAE（相对于 1000 μL 参考，越低越好）
  • 对比基线：π₀.₅、π₀.₅ + Force Token、π₀.₅ + Force Token + Global FAC、DEFT-VLA w/o 接触局部化 FAC、DEFT-VLA 完整版
  • 主要结果：DEFT-VLA 在三任务整体成功率最高，分别为 70%、50%、90%，比各任务最强基线高 40、20、20 个百分点；接触阶段成功率为 93.3%（14/15）、50%（10/20）、90%（18/20）
  • 消融发现：直接添加力 token 或全局施加 FAC 效果不稳定，全局 FAC 使非接触成功率降至（吸取）35%、（擦拭）50%；引入接触局部化 FAC 后接触成功率大幅提升（25%→93.3%、30%→50%、55%→90%）而保持非接触性能接近
  • 状态 token 掩码消融（枪头装配）：无接触局部化 FAC 为 20%，仅视觉课程无状态掩码为 15%，完整方法达 70%，比无状态掩码高 55 个百分点
  • 泛化实验：在未见过的握持高度下，DEFT-VLA 在两项移液任务上均达 50% 成功率，基线最多仅 10%（除 w/o FAC 变体在吸取得 40%）
  • 失败模式：基线常出现插入力不足、枪头脱落、反复插拔；DEFT-VLA 剩余失败主要源于反复按压或专家切换时机不当；吸取任务取得最低体积误差 104.0 μL
