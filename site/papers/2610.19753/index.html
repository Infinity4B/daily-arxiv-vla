Card 02 论文概述

论文概述

  • 论文研究双臂灵巧操作（bimanual dexterous manipulation） 中的动作表示问题，目标是在视觉-语言-动作（VLA）模型框架下为双臂高自由度臂-手系统设计更合理的动作空间结构。
  • 现有双臂 VLA 策略通常在每个控制时间步将右手与左手的臂-手动作直接拼接为单个动作向量，导致双手之间的交互关系隐含在同一向量中，双手身份与跨手结构未被显式表达。
  • 论文提出 Coordi-π，将左右两侧臂-手动作拆分为独立动作 token 并组织成交错序列，同时显式编码手别身份与时间同步关系。
Card 03 核心贡献

核心贡献

  • 提出 Coordi-π 结构化动作表示框架：将左右两侧臂-手动作表示为独立 token 并按 R₀, L₀, R₁, L₁, …, R_{H-1}, L_{H-1} 交错排列，使双臂结构在动作序列中显式暴露，支持 token 级跨手交互。
  • 引入可学习的手别嵌入（hand-identity embedding），在共享动作格式与共享投影的前提下显式区分左右两侧动作 token。
  • 提出序列位置–控制时间步分解式 RoPE（sequence–control-timestep factorized RoPE），将位置编码拆分为序列位置子空间与控制时间步子空间，使同一控制步的左右动作共享时间坐标但保留各自序列位置，从而显式编码双手时间同步。
  • 在 DexJoCo 五个双臂灵巧操作任务上取得 SOTA，rand-obj 平均成功率由 π₀.₅ 的 31.9% 提升至 51.3%，rand-full 由 18.3% 提升至 32.3%。
  • 在四个真实世界双臂灵巧操作任务上一致优于 π₀.₅。
Card 04 方法描述

方法描述

  • 基于 π₀.₅ VLA 架构构建，仅修改动作专家内部的动作表示，保留原 flow-matching 训练目标。
  • 交错动作表示：对 h = 0,…,H-1，令 z_{2h} = a^R_{t+h}、z_{2h+1} = a^L_{t+h}，H 步动作块由 2H 个单侧 token 表示，动作视野（horizon）不变。
  • 手别嵌入：h_i = f_in(z_i) + e_{h(i)}，其中 h(i)=R 当 i mod 2 = 0，否则为 L；e_R 与 e_L 为可学习向量，初始化为零，同侧所有 token 共享，输入/输出投影均共享。
  • 分解式 RoPE：为每个 token 定义序列坐标 s_i = i 与控制时间步坐标 τ_i = ⌊i/2⌋；查询/键向量按 d_seq = d_ctrl = d_head/2 均分子空间，分别以 s_i 与 τ_i 施加 RoPE；动作 token 间注意力使用分解 RoPE，涉及上下文 token 的注意力保留原始位置编码。
  • 关键动机：R_h → L_h 与 L_h → R_{h+1} 在序列上均为相邻对（Δs = 1），但时间关系不同（Δτ = 0 与 Δτ = 1），单一序列位置 RoPE 无法区分；分解 RoPE 使同一控制步的动作共享时间坐标，显式表达同步。
  • 推理与解码：将生成的单侧 token 去交错，按共享控制时间步配对重组为联合双臂命令 â_{t+h} = [â^R_{t+h}; â^L_{t+h}]。
Card 05 数据集与资源

数据集与资源

  • 数据集/基准：DexJoCo 的全部五个双臂灵巧操作任务——Hanoi、Photograph、Unlock iPad、Assembly、Microwave。
  • 随机化设置：rand-obj（随机物体摆放与桌面高度）与更难的 rand-full（额外随机第三人称相机位姿、光照与桌面纹理）。
  • 真实世界任务：在真实双臂灵巧平台上评估 Photograph、Hanoi、Assembly、Microwave 四个任务。
  • 观测与动作空间：3 路 224×224 RGB 视图、语言指令、46 维本体感知状态；动作视野 H = 30；单侧 22 维臂-手动作，每控制步 44 维双臂命令；Coordi-π 内部表示为 2H = 60 个单侧动作 token。
  • 训练资源：4 张 A100 GPU，训练 40k 次迭代，batch size 32，固定训练随机种子 42。
  • 模型基础：以 π₀.₅ 为基座 VLA，Coordi-π 与所有消融变体均使用同一基座。
Card 06 评估与结果

评估与结果

  • 评估协议：遵循 DexJoCo 标准协议，每个「方法–任务–设置」组合使用三个评测种子（0、1、2），每种子 50 个回合，共 150 个评测回合；报告三种子平均成功率与样本标准差。ACT、DP-T、DP-C、GR00T N1.5、π₀.₅ 直接采用 DexJoCo 已发布结果，DP3 在同协议下复现。
  • 评估维度：性能、消融贡献、双臂协调性（超出任务完成的协调质量）、鲁棒性与真实世界表现。
  • 主要指标：任务成功率（Success Rate）；协调性指标 RCS（右侧协调分）、TCS（时间协调分）、BCS（双臂协调总分 Bimanual Coordination Score，0–100，越高越好）。
  • 主结果：rand-obj 下平均成功率 51.3%（DP-T 33.5%，π₀.₅ 31.9%），较 π₀.₅ 提升 19.4 个百分点，在五个任务上均为最优或并列最优；rand-full 下由 18.3% 提升至 32.3%。
  • 单任务增益：Hanoi 由 15.3% → 48.7%，Unlock iPad 由 12.0% → 52.0%（这两类任务需要互补手部角色与有序跨手交互）；Microwave 由 70.0% → 76.7%（增益较小）；Assembly 仍普遍困难，Coordi-π 仅 7.3%，说明精确接触与插入是超出动作表示层面的瓶颈。
  • 消融结果（rand-obj 平均成功率，均基于交错表示）：仅交错 39.7 → 加手别嵌入 42.4 → 加分解 RoPE 44.3 → 完整 Coordi-π 51.3，说明三项设计具有互补贡献。
  • 协调性结果：在 Hanoi、Photograph、Unlock iPad、Assembly 等任务上 Coordi-π 的 RCS/TCS/BCS 多数优于 π₀.₅ 与 DP3，例如 Hanoi BCS 86.32、Photograph BCS 74.58、Unlock iPad BCS 75.80、Assembly BCS 61.39，表明性能提升伴随双臂协调质量改善。
  • 真实世界：在四个真实双臂灵巧任务上 Coordi-π 一致优于 π₀.₅。
