VITAL: From Visual Motion to Precise Action

2026-10-14 · 原文 · 翻译 · 2610.20604

论文研究面向自动驾驶的 world-action models，目标是把视觉预测能力转化为精确的驾驶动作。 现有方法通常将视频专家与动作专家耦合，但动作专家学习的是仅由轨迹坐标定义的表示，与视觉动态之间存在表示鸿沟。 论文提出 VITAL（Vision-Induced Tokens for Action Learning），直接从视觉运动构造动作目标，并用残差编码补足视觉运动脚手架留下的厘米级轨迹误差。

Card 02 论文概述

论文概述

  • 论文研究面向自动驾驶的 world-action models，目标是把视觉预测能力转化为精确的驾驶动作。
  • 现有方法通常将视频专家与动作专家耦合，但动作专家学习的是仅由轨迹坐标定义的表示，与视觉动态之间存在表示鸿沟。
  • 论文提出 VITAL（Vision-Induced Tokens for Action Learning），直接从视觉运动构造动作目标，并用残差编码补足视觉运动脚手架留下的厘米级轨迹误差。
Card 03 核心贡献

核心贡献

  • 提出 VITAL 动作 tokenizer，把视觉运动脚手架与归一化度量残差配对，兼顾视觉 grounding 与细粒度轨迹精度。
  • 提出残差强化学习后训练方法，在冻结基础策略与编解码器的前提下，仅对残差坐标做有界修正，推理时无需额外去噪、候选搜索或奖励评估。
  • 在 NAVSIM v1 navtest 上以单步 flow 评估达到 90.8 PDMS，比十步结果仅低 0.13 分，端到端推理速度提升 3.29×。
  • 同一策略不重新训练即可在 NAVSIM v2 navtest 上达到 91.1 EPDMS，在 navhard 上达到 38.6 EPDMS。
  • 实验表明，仅用视觉重建会留下明显度量误差；加入残差后可将重建 ADE/FDE 从 123.6 mm / 221.6 mm 降至 0.3 mm / 0.5 mm，PDMS 从 92.1 提升至 94.7。
Card 04 方法描述

方法描述

  • 问题设定为基于上下文 c（观测、自车状态、导航指令）的视觉条件动作规划，驾驶实现基于 SimWAM 的视频/动作架构；训练使用 recorded future images，部署时只使用当前上下文。
  • 视觉轨迹脚手架：用视觉编码器 E_v 从记录的图像序列提取运动 token，再由解码器 D_v 映射为轨迹坐标，得到视觉运动码 z_v\* 与轨迹脚手架 τ_v\*；驾驶中采用五帧视觉骨干、四个 64 维运动 token，解码器在轨迹网格上积分预测的车体系速度与偏航率。
  • 配对度量残差：残差定义为 **e\* = vec(τ − τ_v\*)，用训练集拟合均值 μ、正交 PCA 基 U 与对角尺度 S，得到归一化残差码 z_r\*；最终解码为 D(z_v,z_r)=D_v(z_v)+unvec(μ+Mz_r)，其中 M=US。驾驶中形成 4×76 的动作接口，每个 1 秒区间贡献 12** 个残差系数。
  • 联合 flow matching：动作专家从部署可用的 h(c) 联合预测视觉 token 与残差 token，训练目标为加权 flow matching；视觉与残差坐标的权重设为 1:2，当前帧 key/value adapter 可训练，视频基础模型冻结，注意力隔离防止动作查询访问未来视频 token。
  • 解码运动监督：总损失为 **L_IL = L_FM^a + λ_v L_FM^v + λ_d ℓ_τ(D(ẑ_v, sg[ẑ_r]), D(z_v\*, z_r\*))，其中 stop-gradient 只阻断解码损失经 ẑ_r** 的梯度。
  • 单步推理：一次 Euler 更新 ẑ^(1)=ε+v_θ(ε,0,h(c)) 即产生可执行轨迹 τ_IL，无需生成未来图像；解码与残差运算使用 FP32 保持度量精度。
  • 结构保持的残差策略精炼：冻结动作生成器、视觉条件与 codec，学习残差 actor q_φ∈R^k；将平滑轨迹扰动投影到残差解码空间，并用径向 limiter Π_C 约束更新，驾驶中允许最大位置/朝向位移为 1 m / 0.2 rad。奖励优化以 contextual bandit 形式进行，使用困难上下文池 H 与高得分锚点 A，部署时只执行一次确定性修正。
Card 05 数据集与资源

数据集与资源

  • 使用 NAVSIM 基准，报告 NAVSIM v1 navtest、NAVSIM v2 navtest 与 reactive navhard 上的结果。

Card 06 评估与结果

评估与结果

  • 主要评估指标包括 PDMS、EPDMS、ADE、FDE，覆盖碰撞避免、道路合规、通行效率与舒适性。
  • NAVSIM v1 navtest：VITAL 单步达到 90.8 PDMS，与其十步分数相差 0.13 分，端到端推理速度提升 3.29×。
  • NAVSIM v2 navtest：不重新训练达到 91.1 EPDMS；navhard 上达到 38.6 EPDMS。
  • 与仅用轨迹训练的自编码器相比，在相同动作训练预算下，单步设置提升 5.1 PDMS。
  • 重建诊断：仅视觉重建得到 123.6 mm ADE 与 221.6 mm FDE，高频速度能量占比仅 0.1%；加入由真值编码的残差后，ADE/FDE 降至 0.3 mm / 0.5 mm，PDMS 从 92.1 提升至 94.7，残差高频占比达到 61.4%。
  • 消融与推理扫描显示，在固定策略、推理种子、解码器与残差 actor 的情况下，额外 action-flow 评估主要影响数值积分代价，单步即可得到接近十步的规划分数。
