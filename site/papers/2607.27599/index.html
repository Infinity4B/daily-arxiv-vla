World Action Planner: Generalizable Decision-Making with Action-Conditioned World Models

01研究单位

  • Harvard University（哈佛大学）
  • 作者：Xiangcheng Zhang、Yilun Du

02论文概述

  • 论文提出 World Action Planner (WAP)，一种结合视觉语言模型（VLM）推理能力与动作条件世界模型物理 grounding 的机器人规划系统。
  • 旨在解决端到端模仿学习策略（如 VLA、WAM）难以泛化到新场景、新布局和新任务的根本性问题。
  • 系统通过 VLM 提出初始动作计划，并基于世界模型的想象 rollout 进行迭代优化与搜索，实现测试时对新任务的泛化决策。

03核心贡献

  • 提出姿态-图像条件（pose-image conditioned）机器人世界模型，在新动作、新场景及跨机器人 embodiment 泛化上显著优于现有方法。
  • 提供理论分析，证明在 tabular 设置和线性函数逼近下，基于模型的规划在多任务泛化上优于模仿学习（模仿学习次优差距随任务数线性增长 Ω(\|C\|/K)，而模型方法为 Õ(1/√K)）。
  • 提出 World Action Planner 规划系统，通过世界模型想象实现系统化的动作提议、优化与搜索，在组合任务、新布局和零样本泛化场景中大幅超越 π₀.₅、cosmos-policy 等 SOTA 策略。
  • 提出"策略即工具"范式，将模仿学习策略（如扩散策略）作为模块化工具集成进规划框架。

04方法描述

  • 姿态-图像条件化：通过正向动力学预计算未来机器人关节位置，渲染为姿态骨架图像，经视频模型 VAE 编码后与视频 token 拼接为统一序列；相比低维动作向量条件化具有更好的泛化性。
  • 多视角预测：将第三人称与腕部视角拼接成 2×2 网格，使模型推断机器人关节的相对 3D 位置。
  • 采用 diffusion-forcing 与 flow-matching 目标训练，历史帧加独立噪声、未来帧加均匀噪声、姿态图像保持无噪声。
  • WAP 规划流程（Algorithm 1）包含四个阶段：

- Agent Action Proposal：VLM 生成 MOVE/ROTATE/GRASP/RELEASE 等动作原语，通过多视角三角化获得 3D 目标位置。

- Global Optimization：基于世界模型想象 rollout，VLM 提供语义反馈修正动作（如避免碰撞）。

- Local Search：网格搜索候选动作，VLM 对想象结果排序选择最优。

- Policies as Tools：在精细操作阶段调用扩散策略完成抓取等动作。

05数据集与资源

  • 数据集：LIBERO（LIBERO-90/Long/Spatial/Object）、RoboCasa、MimicGen、DexMimicGen、Robosuite。
  • 世界模型骨干：Wan-T2V-1.3B 视频生成模型，微调 10K 步，全局 batch size 64。
  • 视频设置：21 帧历史（7 FPS）预测 20 帧未来（20 FPS），4 视角 2×2 网格（每视角 224px），20 步扩散采样。
  • 每任务 100 条训练轨迹（含高斯噪声扰动增广），10 条评估轨迹；新布局实验中仅用 5 条专家演示（基线使用 40+ 条）。
  • VLM 代理：Gemini 3.0 Flash。

06评估与结果

  • 世界模型评估：在 PSNR/LPIPS 指标上对比 WPE、IRA-Sim、Ctrl-World，分布内平均提升 11.4%，泛化设置平均提升 16.8%；跨 embodiment（动作维度 7/12/14/24 混合训练）同样优于统一动作空间、embodiment-aware 编码器等方法。
  • 组合任务泛化（LIBERO-Long，每任务 50 次试验）：WAP 成功率 72/68/78/70，远超 π₀.₅（4/0/0/0）、cosmos-policy（全 0）、SAILOR（18/0/8/2）、GPC-RANK（10/0/0/0）及 vision-language planner（56/28/46/32）。
  • 新布局泛化（LIBERO-Object，改变物体位置）：WAP 成功率 88/86/90/66/84/78，而 VLA/WAM 基线几乎全为 0，展现强空间泛化能力。
  • 关键发现：端到端 VLA 模型在完成第一个子任务后因缺乏状态转换演示而停滞，WAP 通过 VLM 推理提出桥接动作解决该问题；世界模型想象还能检测碰撞等物理风险并优化动作安全性。
  • 系统还在零样本泛化场景及消融实验（对比 Best-of-N 采样等）中验证了各组件的有效性。
