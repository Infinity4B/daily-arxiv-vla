MiniWAM: Learning Compact Future Targets for Efficient World-Action Modeling

2026-10-08 · 原文 · 翻译 · 2610.12194

论文提出 MiniWAM，一种高效的世界-动作模型（World Action Model, WAM），其核心思想是用紧凑的未来预测表征替代高维的原始视觉未来特征，从而大幅降低世界-动作协同训练的计算成本。 作者设计了 PRISM（Predictive Representations via Inverse Spatiotemporal Modeling），即通过逆时空建模学习预测性表征，将特权当前-未来视觉过渡压缩为紧凑的目标表示，解决了传统 WAM 需要预测密集视频 VAE 或 DINO 特征的高昂开销问题。 实验表明，仅 0.25B 参数的 MiniWAM 在 LIBERO、LIBERO-Plus 和 RoboTwin 2.0 基准上可与显著更大的 WAM 和 VLA 模型竞争，验证了“有效世界建模无需预测原生视觉未来”这一论断。

Card 03 核心贡献

核心贡献

  • 提出 PRISM 表征学习框架：通过逆动力学监督与特征重建相结合，学习控制相关且保留状态信息的紧凑过渡表征，同时压缩空间与时间维度。
  • 设计 两阶段训练范式（MiniWAM）：第一阶段使用特权当前-未来过渡学习 PRISM 编码器并冻结，第二阶段以 PRISM 目标联合预测动作与未来状态，将“表示什么”与“如何预测”分离。
  • 实现 65× 的未来 token 压缩：相比直接预测原生未来特征（WAN2.1 VAE 或 DINOv3），PRISM 将未来预测 token 数量大幅减少，同时将世界-动作训练速度提升最高 8 倍以上。
  • 通过跨骨干（VAE vs DINOv3）的受控实验验证：学习得到的紧凑目标始终优于原生未来特征预测，证明效益并非来源于选择更强的视觉编码器，而是来源于目标的表征结构本身。
  • 深入的分析实验（CKA 对齐、跨骨干检索）证明 PRISM 表征在全局与局部尺度上建立了更一致的过渡几何结构，该结构直接反映了行为相似性（动作 RMSE、夹爪一致性等）。
Card 04 方法描述

方法描述

  • PRISM 编码器（Transition Encoder） 以轻量 3D 卷积网络实现，将当前特征 \(x_t\) 与未来特征 \(X_t^+\) 沿时间维度排列，通过步长卷积逐步压缩为紧凑时空网格 \(L_t \in \mathbb{R}^{T_L \times H_L \times W_L \times D_L}\)，并参数化为对角高斯分布。
  • Stage 1 学习目标：联合优化三项——逆动力学目标（以干净 PRISM 表征预测被扰动的动作，强制控制相关信息经过瓶颈）、特征重建目标（轻量解码器重建原生未来特征）、弱 KL 正则化。
  • Stage 2 世界-动作协同训练：冻结 PRISM 编码器，MiniWAM 使用 Mixture-of-Transformers (MoT)，包含世界专家与动作专家两个扩散 Transformer（DiT），二者通过混合自注意力交换信息；采用 Flow Matching 作为训练目标，独立地对世界 token 和动作 token 进行扩散/去噪。
  • 推理阶段：PRISM 编码器与未来观测均不再需要，仅从当前观测、指令与本体感觉出发，通过世界与动作专家联合迭代去噪生成动作块，并以滚动时域方式执行。
Card 05 数据集与资源

数据集与资源

  • LIBERO：40 个语言条件操作任务，含 Spatial/Object/Goal/Long 四个套件，用于受控世界建模目标对比。
  • LIBERO-Plus：LIBERO 的鲁棒性扩展，包含相机视角、机器人初始状态、语言指令、光照、背景、观测噪声、物体布局等扰动，用于分布偏移下的鲁棒性评估。
  • RoboTwin 2.0：50 任务双机械臂操作基准（Aloha-AgileX 机器人），在干净与随机化条件下评估，并额外提供手腕视角以增大视觉预测负载。
  • 模型规模为 0.25B 参数；视觉骨干使用冻结的 WAN2.1 VAE（生成式特征）和 DINOv3（判别式特征）。
  • 训练硬件使用全局 batch size 256 的匹配 GPU 集群进行效率基准测试。
Card 06 评估与结果

评估与结果

  • 在控制对比中，PRISM 在 VAE 特征下将 LIBERO 成功率从原生共训练的 92.8% 提升至 94.8%，在 DINOv3 特征下从 93.2% 提升至 97.2%；LIBERO-Plus-2K 提升幅度分别达 6.3 和 13.2 个百分点。
  • 训练效率方面，Stage-2 吞吐量提升最高 4.6 倍（LIBERO/H16 VAE），总训练预估加速最高 8.46×（RoboTwin 2.0/H32 VAE），Stage-2 单独计算最高可达 10.48×。
  • 与 SOTA 对比：0.25B MiniWAM 在 LIBERO 上达到 97.2%，接近 6B 规模 Fast-WAM（95.8%）和 DreamWAM（96.9%）；在 LIBERO-Plus 上以 73.6% 超越 Fast-WAM（71.0%）；RoboTwin 2.0 达到 46.1%，超过 Fast-WAM 与 AHA-WAM。
  • 消融实验显示：在不同瓶颈容量下，逆动力学+重建组合始终优于单独任一目标，加入逆动态监督平均提升约 4.6 个百分点；瓶颈越小性能下降，但组合目标始终优于纯重建。
  • 表征分析：PRISM 在未见过的 LIBERO-90 任务上显著提升跨骨干 CKA 对齐（腕部视图 within-task CKA 从 0.249 升至 0.705），并提升跨骨干邻域检索的 Jaccard@5 一致性（主视图 0.170→0.512 ）、降低动作 RMSE 和提高夹爪一致性。
