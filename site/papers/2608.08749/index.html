OnEvoMemory: Evolving Memory through Online Robot Rollouts for Pretrained Robot Policies

02论文概述

  • 针对长程机器人操作中现有记忆机制依赖外部模型或预定义规则、无法自适应选择适配任务的经验的问题，提出OnEvoMemory值引导记忆模块，用于增强预训练机器人策略的长程任务执行能力
  • 该方法通过离线专家演示初始化记忆先验，再利用包含成功与不成功轨迹的在线机器人rollout迭代优化记忆选择逻辑，帮助策略识别任务阶段转换、避免重复执行已完成的子任务
  • 研究目标是验证该记忆机制是否可以在不修改预训练策略的前提下，提升长程机器人操作的成功率

03核心贡献

  • 提出包含短期原始缓冲区、精英经验库、转换库的分层记忆架构，分别用于存储近期上下文、高价值经验、显著价值转换事件
  • 开发可学习的值引导记忆写入机制，无需依赖固定时间窗口或人工设计的写入规则，即可自动识别任务相关的经验
  • 提出在线记忆进化方案，利用成功和不成功的机器人rollout优化记忆模块，同时冻结底层预训练策略，保留其原有操作能力

04方法描述

  • 基于QwenOFT预训练VLA策略实例化，维护三组件分层记忆$\mathcal{M}_t=\{\mathcal{M}_t^S,\mathcal{M}_t^E,\mathcal{M}_t^T\}$，分别存储近期上下文、高价值经验、显著转换事件
  • 采用动作条件的值估计器为每个经验计算写入得分，引导经验自动写入对应记忆库，无需人工预设规则
  • 记忆读取时结合短期缓冲区的近期经验，以及长期库的语义相似+最近写入的TopK结果，通过门控交叉注意力注入到当前动作查询中，辅助策略决策
  • 离线阶段重放专家演示初始化记忆并训练读写模块，在线阶段仅更新值估计器和记忆相关模块，预训练策略全程冻结，实现记忆的在线进化

05数据集与资源

  • 评估数据集：LiberoLong-10（10个长程机器人操作任务）、RMBench（2个长程任务：SwapBlocks、SwapT）
  • 基座模型：QwenOFT预训练VLA策略，全程冻结，仅训练记忆相关模块与值估计器
  • 训练资源：在线适应阶段，LiberoLong-10每个任务收集20条rollout轨迹，RMBench每个任务收集10条rollout轨迹，未对预训练策略进行更新

06评估与结果

  • 评估基准：LiberoLong-10平均任务成功率、RMBench两个子任务的单独成功率
  • 主要评估指标：任务执行成功率（%）
  • 关键实验结果：

- LiberoLong-10平均成功率：基座VLA为86.2%，加入离线初始化后提升至88.6%，经一轮在线进化后进一步提升至90.2%

- RMBench两个任务基座VLA成功率为0%，离线初始化后SwapBlocks和SwapT成功率分别达10.0%和8.0%，在线进化后进一步提升至14.0%和10.0%

- 记忆机制对任务阶段转换场景的提升尤为明显，能帮助策略避免重复执行已完成的子任务；负向rollout可提供纠错监督，修正过高评估的经验，优化记忆选择逻辑
