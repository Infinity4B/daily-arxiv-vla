01研究单位

02论文概述

  • World Action Models (WAMs) 通过迭代视频 rollout 生成未来视频来条件化机器人动作，但导致部署延迟比当前仅策略高 3.3 倍至 9.6 倍
  • 现有高效方法（Fast-WAM、PFD）通过移除测试时未来读取来降低延迟，但与保留未来读取的 rollout-based 策略存在 1.6–2.0 个百分点的性能差距
  • 本文提出 Rift（Rollout-free Imagination via Future Tokens），通过一次 backbone 前向传播生成完整的 future K/V cache，在无需迭代视频生成的情况下实现与 rollout-based 方法相当的成功率

03核心贡献

  • 提出配对闭环干预协议（paired closed-loop intervention protocol），通过记录和重放 action-independent 的 future cache，直接测量动作专家对 future read 的依赖程度
  • 识别出未来缓存的两大特性：动作专家对 future value 的内容和空间时间位置高度敏感；对于 Joint 和 Cosmos-2，一次 final-clean K/V cache 几乎可以保持原始执行性能（EE-ADE 仅 1.7–1.9cm，成功率 97.9–98.2%）
  • 设计并验证了 Rift 框架，使用学习的 anticipation tokens 在一次前向传播中构建完整的 future-position K/V cache，在保持 rollout 级别成功率的同时将延迟降低至接近 current-only 水平

04方法描述

  • Rift 保持 Fast-WAM-Joint 的架构和未来读取接口，用可学习的 anticipation tokens $E \in \mathbb{R}^{m \times d}$ 替换 rollout 产生的未来 token，继承其时空索引
  • 通过一次 VideoStack prefill，将第一帧 token $f_0(o)$ 与 anticipation tokens 拼接后输入，生成每层的 future-position K/V cache $\mathcal{C}_\phi(o,l) = \{(K_E^{(\ell)}, V_E^{(\ell)})\}_{\ell=1}^L$
  • 训练采用双前向传播机制：原生视频流损失 $\mathcal{L}_{\text{vid}}$ 保持动态监督；部署匹配的前向传播使用干净第一帧训练动作专家 $\mathcal{L}_{\text{act}}$，并对未来帧加入轻度扰动以增强鲁棒性
  • 引入条件流匹配损失 $\mathcal{L}_{\text{FM}}$ 作为分布辅助目标，替代直接 L2 回归以处理多模态未来分布；使用停止梯度的线性探针损失 $\mathcal{L}_{\text{probe}}$ 提供确定性未来潜变量监督
  • 部署时仅需一次 cache prefill 和标准动作去噪流程，完全移除视频扩散、VAE 解码和迭代生成过程

05数据集与资源

  • LIBERO：包含 40 个任务的基准，涵盖 Spatial、Object、Goal 和 Long 四个套件
  • RoboTwin 2.0：包含 50 个双臂操作任务，提供干净场景和域随机化场景两种评估设置
  • 模型规模：基于 Wan2.2-5B 视频 backbone（50 亿参数）
  • 训练数据：LIBERO 使用 2,500 干净场景和 25,000 随机化演示训练 20k 步；RoboTwin 2.0 训练 30k 步
  • 硬件：延迟测试使用单块 A800 GPU

06评估与结果

  • 评估设置：LIBERO 每方法每种子 2,000 trials（3 个随机种子，每任务 50 集），RoboTwin 2.0 每任务 100 trials
  • 主要指标：任务成功率（SR）、末端执行器平均位移误差（EE-ADE）、每动作块延迟（ms）
  • LIBERO 结果：Rift 达到 98.8% 成功率，与 rollout-based 的 Joint（98.4%）、IDM（98.6%）和 LingBot-VA（98.5%）处于同一水平，但延迟仅 247.9ms，比 Fast-WAM-Joint（780.2ms）降低 68.2%，比 LingBot-VA（2270.3ms）降低 89.1%
  • RoboTwin 2.0 结果：Rift 在干净/随机化场景分别达到 92.9% 和 92.6%，优于 PFD（92.5%/92.1%）和 Fast-WAM-Joint（91.0%/91.1%），为所有评估方法中的最高值
  • 消融实验：验证了 anticipation token 监督策略的有效性，以及 token 数量（LIBERO 196 个，RoboTwin 2.0 240 个）对性能的影响
