02论文概述

  • 针对 GPT-6 Astra 在机器人控制中展现出强泛化能力、但其训练方法几乎未公开的问题，探索如何以可复现的方式训练 视觉语言模型（VLM） 作为机器人操作基础模型
  • 提出 nanoAstra，将机器人行为表示为 由可复用、参数化动作基元组成的语义步骤，并结合 能力保持的监督微调（CP-SFT） 进行训练
  • 在超过 5,000 小时机器人数据与通用 VQA 数据上训练 nanoAstra-9B，零样本操作成功率显著优于现有 VLA、WAM 和同类 VLM，并通过流式推理提升执行效率

03核心贡献

  • 构建数据管线，将超过 5,000 小时异构机器人演示数据转化为 VLM 可用的监督格式，组织成语义步骤并配备稠密进度描述
  • 提出 CP-SFT 和联合数据配方，通过机器人专属系统提示约束输出空间，在获得操作能力的同时尽量保留 VLM 预训练能力
  • 在 RoboTwin 2.0 随机化基准上取得 17.8% 零样本成功率，超过现有 VLA/WAM 与同规模 VLM 基线
  • 实现 流式推理执行，将机器人推理等待时间占比从 35.0% 降至 6.9%，提升闭环控制效率
  • 为将 VLM 训练为具身基础模型提供了可复现的路径和初步证据

04方法描述

  • 语义动作建模：将密集采样控制步组织为语义步骤，使用动作基元（如 move x +5.0、gripper open），并配合显式进度描述，减少对轨迹细节的依赖
  • 数据管线五阶段：数据过滤、坐标系与相机对齐、子任务分割与稠密字幕、语义步骤构建、与通用视觉语言数据混合
  • CP-SFT：使用机器人专属系统提示定义具身、坐标约定和可执行动作空间，将操作监督限制在结构化响应空间中，降低对通用能力的干扰
  • 训练目标：在标准交叉熵基础上加入改进的 Wasserstein 数字 Token 损失，包含小数位加权、符号监督和仅数字归一化，提升动作数值精度
  • 联合训练：机器人数据与通用视觉语言数据混合，约 62.7% 训练 token 来自机器人数据、37.3% 来自通用 VQA 数据

05数据集与资源

  • 机器人数据来源：ABC-130K、AgiBot、HiFi-UMI、HY-UMI，处理后保留约 5,310.5 小时、818K episode、14.9M 语义动作训练样本
  • 通用视觉语言数据：来自 Honey-Data-V2，共 1.55M 样本，覆盖 VQA、grounding、图表理解、具身推理等任务
  • 训练总 token 量：约 3.65B token，其中机器人数据 2.29B（62.7%），通用 VLM 数据 1.36B（37.3%）
  • 模型规模：nanoAstra-9B，初始化自 Qwen3.5-9B，全参数微调 9B 视觉语言模型
  • 训练资源：56 张 H20 GPU，训练 1 个 epoch，使用 AdamW、峰值学习率 \(1\times 10^{-5}\)、最大序列长度 8192 token、bf16 混合精度和 DeepSpeed ZeRO-2
  • 推理资源：在单个 NVIDIA RTX 4090 和单个 NVIDIA H20 GPU 上评估推理效率

06评估与结果

  • RoboTwin 2.0 零样本随机化基准：nanoAstra-9B 成功率 17.8%，显著优于 LingBot-VLA-2.0（10.8%）、Qwen3.8-27B w/ thinking（10.8%）、Qwen3.5-397B-A17B w/ thinking（9.0%）以及所有评估的 WAM 模型
  • RoboDojo Open 基准：nanoAstra-9B 成功率 4.75%、得分 5.06，为表格中最高，明显超过未微调 Qwen3.5-9B（0.25%）和 Qwen3.5-35B-A3B（0.75%）
  • 推理效率：H20 上 nanoAstra 推理延迟 1.69s，对应运动时间 2.66s，推理/运动比 0.64，推理短于运动执行；RTX 4090 上推理延迟 3.89s，推理/运动比 1.36
  • 流式执行：采用流式推理后，机器人空闲时间占比从 35.0% 降至 6.9%，每轮等待时间从 2.1 步降至 0.2 步，成功率不受损失
  • 能力保持：最终检查点 MMMU 53.1%、ERQA 41.0%、CV-Bench-2D 81.6%、CV-Bench-3D 87.6%；其中 CV-Bench-2D 与初始差距仅 0.6 个百分点，其余基准保持大部分能力
  • 训练过程：训练损失最终 EMA 约 0.35；VQA 准确率在训练初期下降后逐步恢复并趋于稳定，表明联合训练能够部分缓解灾难性遗忘
