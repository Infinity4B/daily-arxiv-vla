Card 02 论文概述

论文概述

  • 论文研究扩散驱动视觉-语言-动作模型（diffusion driving VLAs）在推理时反复执行骨干网络导致的高延迟问题

  • 提出场景自适应读出与解码框架，根据场景分配计算量，在保持或提升规划质量的同时减少不必要的解码
Card 03 核心贡献

核心贡献

  • 系统分析扩散 VLA 中轨迹表示随网络深度与解码阶段的变化，揭示深度-解码解离以及最优读出层和解码深度在不同场景间的异质性
  • 提出场景自适应读出 MoE，场景条件门控根据输入动态加权组合来自晚期层带（L21–L29）的轨迹预测
  • 提出场景自适应解码策略，根据场景判断是否提前终止、执行部分本机解码或完整本机解码，自适应分配去噪预算
  • 在两个扩散驾驶 VLA（dVLM-AD 和 Fast-dDrive）及 Waymo E2E、nuScenes 两个基准上验证方法的有效性和通用性
Card 04 方法描述

方法描述

  • 在冻结的扩散骨干首次前向传播后，从晚期层带（L21–L29）中提取轨迹 token 表示，各层专属读出头结合单步 argmax 草稿生成候选轨迹
  • 使用场景条件门控 MoE，输入轨迹槽和视觉 token 的平均池化特征、自车历史、导航指令、单步草稿及候选轨迹统计信息，通过 softmax 融合候选轨迹
  • 引入潜在编辑器对表示进行多步残差精修（R=12），补偿直接读出可能产生的几何不一致，并设置固定参考层（L27）辅助分支以稳定输出
  • 场景自适应解码通过解码门控评分与阈值决定是否进入回退解码；回退解码增量执行本机去噪，利用阶段级读出探针和一致性阈值 ε 选择最早可用阶段或运行至本机完成，最终平均读出轨迹与本机轨迹
Card 05 数据集与资源

数据集与资源

  • 数据集：Waymo End-to-End (WOD-E2E) 和 nuScenes 自动驾驶数据集
  • 模型：扩散驾驶 VLA dVLM-AD 和 Fast-dDrive（扩散骨干保持冻结，仅训练轻量读出头、潜在编辑器、门控和阶段级探针）
  • 推理环境：单张 NVIDIA A6000 GPU，batch size 1，延迟单位为 ms/scene
  • 训练硬件和模型参数量在正文中未明确给出
Card 06 评估与结果

评估与结果

  • 评估指标：RFS（Rater Feedback Score，越高越好）、ADE@3s/5s（越低越好）、L2 位移误差（nuScenes，1s/2s/3s）以及端到端延迟
  • WOD-E2E 验证集：dVLM-AD RFS 从 7.187 提升至 7.745（+0.558），Fast-dDrive 从 7.911 提升至 8.121（+0.210）
  • WOD-E2E 测试集：dVLM-AD RFS 7.486→7.557（+0.071），ADE@3s 1.337→1.294，ADE@5s 3.241→3.130；Fast-dDrive RFS 7.823→7.881（+0.058），ADE@3s 1.254→1.196，ADE@5s 2.907→2.681
  • 端到端加速：dVLM-AD 延迟从 31,385 ms/scene 降至 5,208 ms/scene（6.0× 加速）；Fast-dDrive 从 3,146 ms/scene 降至 1,135 ms/scene（2.8× 加速）
  • nuScenes：两种骨干的平均 L2 误差均下降（dVLM-AD 0.41→0.39；Fast-dDrive 0.32→0.29）
  • 消融实验表明，早期读出带来主要 RFS 提升和大幅延迟下降，场景自适应 MoE 进一步改善性能，场景自适应解码带来额外收益但会增加一定延迟
