02论文概述

  • 论文提出 ActTune，一个面向视觉-语言-动作（VLA）模型的能量高效推理框架，目标是在保持任务成功率的同时，降低 GPU 每次成功任务的平均能耗，并将推理延迟增幅控制在 10% 以内
  • 核心思路是将动作感知的层间精度分配（weight/activation 量化配置）与负载相关的 GPU 工作点选择（频率-功率上限组合）联合优化，适用于机器人在线控制场景
  • 解决的关键问题是：单纯降低单次推理能耗可能因数值误差导致任务失败或推理变慢，反而增加每次成功任务的总能耗；论文通过动作条件化精度选择与 GPU DVFS 自适应协同来应对这一矛盾

03核心贡献

  • 实证刻画：系统性地揭示量化敏感度随动作类别、Transformer 层位置以及权重/激活精度而变化，并证明不同数值精度偏好不同的 GPU 最优工作点
  • 动作感知精度与 GPU 工作点联合自适应框架 ActTune：采用轻量级决策树直接从配置动作误差中学习划分规则和叶节点精度配置，并通过共享驻留量化权重库实现配置切换，无需权重重建或额外策略推理调用
  • 定量评估：在 LIBERO 基准上相对 QVLA 与 ActQuant 将平均任务成功率提升最高 2.3%；相对原始 BF16 实现实现最高 2.02× 推理加速和最高 76.8% 每次成功任务能耗降低，静态模型存储最高减少 29.3%

04方法描述

  • 精度选择：离线校准阶段，以 BF16 参考策略的动作误差为损失函数，通过 PCA + K-means 引导的敏感度分析确定可切换矩阵及精度选项，构建共享驻留量化权重库（基于 AWQ 激活感知通道缩放与输出行裁剪）
  • 决策树：利用当前本体感觉和前一预测动作块的特征作为输入，学习二叉树的划分条件及叶节点配置；采用自底向上动态规划在给定叶数下优化动作一致性损失，选择复杂度时综合验证集动作损失与 CPU 路由开销
  • GPU 工作点控制：离线对各"区域-配置"对在候选频率-功率上限组合下进行能量与延迟 profile，建立查找表，在推理延迟增幅 ≤10% 的约束下选择估计能量最低的表；在线运行时异步预测下一负载并提前应用工作点
  • 高效整数内核：为 2/4/8 位权重量化实现 INT4×INT4 与 INT8×INT8 Tensor Core 内核（CUDA 实现），并融合激活量化与 GEMM epilogue（缩放、偏置、转换），减少内核启动与中间内存流量

05数据集与资源

  • 评估基准：LIBERO 的四个套件（Spatial、Object、Goal、Long），每套件 10 个任务 × 50 个初始状态，共 500 集/套件、2000 集/模型-精度设置
  • 评估模型：OpenVLA-OFT 与 π_0.5 两个 VLA 模型，配置包括 W4A16、W4A8、W4A4 精度预算
  • 对比基线：QVLA、ActQuant（VLA 量化方法）；SmoothQuant、GPTQ、AWQ（通用量化方法）
  • 硬件资源：NVIDIA RTX A6000 GPU（Ampere 架构，compute capability 8.6），参考工作点为 1800 MHz / 300 W

06评估与结果

  • 任务成功率：W4A8 下 OpenVLA-OFT 达 97.0%、π_0.5 达 98.4%；W4A4 相对最强基线分别高出 4.0 和 5.1 个百分点；W4A16 相对 QVLA 与 ActQuant 在两个模型上均取得更高成功率
  • 推理加速：优化后 π_0.5 的 W4A8/W4A4 实现相对 BF16 达 2.02×/1.81× 加速，OpenVLA-OFT 达 1.50×/1.53× 加速
  • 能耗降低：固定参考工作点下，W4A8/W4A4 相对 BF16 每次成功任务能耗降低 59.5%/59.9%（OpenVLA-OFT）和 70.9%/46.1%（π_0.5）；启用 GPU 工作点自适应后进一步降至 70.2%/68.0% 和 76.8%/56.9%
  • 延迟预算：GPU 工作点自适应使平均推理延迟增加 7.79%–8.63%，四个模型-精度设置均满足 10% 延迟预算；节能消融显示量化、内核/运行时优化与 DVFS 三者的贡献因模型和精度设置而异
  • 消融实验：三种叶子数量的决策树在 K=3 时取得最佳闭环成功率；region-and-configuration 联合 GPU 控制策略相比最优固定设置与仅配置控制分别多节省 4.15 和 4.91 个百分点的能耗
