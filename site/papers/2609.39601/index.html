02论文概述

  • 提出 GroundingPI，一个 4B 参数的 grounding 基础模型，以点和框等视觉基元为核心，通过共享的量化坐标词汇将多种感知任务统一为语言条件化的结构化生成。
  • 解决通用 VLM / WAM 主干在密集场景、微小物体和实时闭环控制中定位精度不足的问题，旨在为物理智能提供更强的感知基础。
  • 训练结合多模态预训练、空间预训练、SFT 与 GRPO 强化学习，在 34 个 grounding 基准、44 个基线、11 类感知能力上达到平均 73.68%，超过 GPT-6 Astra（71.54%），并在自动驾驶和机器人操控任务中验证了强迁移性。

03核心贡献

  • 提出 GroundingPI 模型：以共享量化坐标词汇（<0>–<999>）统一点/框输出，支持检测、referring、pointing、OCR、GUI/layout grounding 和视觉提示等多种感知任务。
  • 设计完整训练管线：基础 VLM 预训练 → 坐标对齐 SFT → GRPO 强化后训练，并配套多教师融合的数据引擎。
  • 在 34 个 benchmark、44 个 baseline 上取得 SOTA 平均 73.68%，超过更大的 GPT-6 Astra（71.54%）。
  • 在下游 RoboTwin 2.0 的四个 OOD 设置中全部优于所有主流主干，相对最强基线最高提升 24.8%；在 RoboCasa-GR1 上仅用 50% 演示即超过基线 75% 演示的性能。
  • 系统分析预训练规模与数据构成，发现 dense grounding 对自动驾驶与操控收益显著、OCR 可能作为感知学习催化剂，为具身基础模型设计提供重要洞察。

04方法描述

  • 架构采用 MoonViT-V2（Kimi K3） 视觉编码器 + Qwen3-4B 语言解码器；可学习投影层聚合 2×2 视觉特征并经两层 MLP 映射到语言嵌入空间。
  • 采用条件自回归生成：p(Y\|I,P)=∏ p(y_i\|V,P,y_{<i})，语义标签、协议标记和 1000 个量化坐标 token 共享输出词汇，缺失类别输出 None。
  • 训练分三阶段：①基础 VLM 训练（投影器对齐→联合多模态预训练→通用视觉/视频理解）；②SFT 坐标对齐（先更新全部模块，再冻结视觉编码器与投影器精修语言端）；③GRPO 强化（G=8，grounding 使用集合覆盖与严格定位奖励，OCR 使用匈牙利匹配奖励）。
  • 数据引擎实现多教师字段级融合、任务特定验证、专家迭代和局部观测修正，用于扩大监督并精化标注。

06评估与结果

  • 评估环境：44 个 baseline、34 个 grounding benchmark、11 类感知能力；指标采用 F1mIoU（box/OCR）、F1@Point（pointing）、accuracy（spatial/GUI 等）。
  • 总体性能：GroundingPI 平均 73.68%，超过 GPT-6 Astra（71.54%）。
  • 检测与参照定位：Dense200 达 74.53（Astra 为 65.04）；RefCOCOg val/test 达 88.56 / 85.62；RefCOCO avg 达 83.92，显著优于同规模模型。
  • 机器人操控：RoboTwin 2.0 四个 OOD 设置全部超越所有主流主干，相对最强主干最高提升 24.8%；RoboCasa-GR1 上 50% 演示训练的 GroundingPI 超过基线 75% 演示的性能。
  • 自动驾驶：在 nuScenes 上作为视觉主干，平均开环 L2 误差 0.296m。
  • 分析与消融：grounding 与动作学习随预训练规模增大同步提升；dense grounding 带来最大迁移收益，OCR 具有感知催化潜力。
