Card 02 论文概述

论文概述

  • 论文研究流策略（Flow Policy）的离线/离线到在线强化学习微调问题，目标是在不冻结预训练生成模型的前提下直接改进流模型本身。

Card 03 核心贡献

核心贡献

  • 提出 SQAM（Q-learning with Scalar Adjoint Matching）：用闭式标量伴随替代伴随匹配中每步的向量–雅可比乘积，显著降低计算开销。
  • 发现速度雅可比矩阵在对角线集中的经验规律，并推导出在各向同性雅可比假设下 lean adjoint ODE 的闭式解（Proposition 1），即 â_τ = -τ ∇_{X1} Q^π(s, X1)。
  • 揭示标量伴随下价值学习方案至关重要，并发现关键在于约束 critic 在策略自身生成动作处的价值，据此提出价值惩罚正则项（Equation 3）。
  • 在 OGBench 50 个任务上，SQAM 综合成功率 75%（最强基线 TRQAM 为 68%）；在最难的四个 domain 上比最强基线提升 18–35 个百分点。
  • 方法成功扩展至真实双机械臂机器人（RB-Y1 + Wuji Hand 2）上的视觉-语言-动作（VLA）大模型微调，三项任务均优于监督微调。
Card 04 方法描述

方法描述

  • 基于流匹配（Flow Matching）与线性插值路径 X_τ=(1-τ)X_0+τX_1 训练速度场 v_θ(s,X_τ,τ)，动作通过积分 ODE 采样得到。
  • 核心观察：预训练流策略的批量平均速度雅可比矩阵在对角线集中（Figure 2），因此近似 J_τ = c_τ I 并推导闭式标量伴随，只需在最终动作处计算一次 critic 梯度。
  • 提出价值惩罚（value penalty）：L_critic += c·(Q^π(s, sg(a_π)) - Q^π(s, a_data))，在策略更新所用的策略生成动作处直接约束 critic 值。
  • 默认采用 TRQAM 的路径空间 KL 信任域约束以保证训练稳定；未使用信任域的消融见附录 F.3。
Card 05 数据集与资源

数据集与资源

  • OGBench 基准：10 个 domain × 5 个任务 = 50 个任务，使用基于奖励的 single-task 变体。
  • 流策略先经过 300K 步行为克隆（BC）预训练，离线微调 1M 步，在线阶段至 1.5M 步。
  • 操纵类 domain 使用 action-chunking，chunk size = 5。
  • 实验使用 8 个随机种子；真实机器人平台为 Rainbow Robotics RB-Y1 双臂机器人，配备两只 Wuji Hand 2（各 20-DoF 灵巧手）。
  • 代码与博客已公开：github.com/yonghdong/sqam、yonghdong.github.io/blog/sqam。
Card 06 评估与结果

评估与结果

  • 对比基线（7 种）：FQL、CGQL-L、DSRL、IFQL、QAM、QAM-E、TRQAM（后三种同属伴随匹配家族）。
  • 主要评估指标：平均成功率（%），离线阶段 1M 步时报告（8 seeds 均值 ± 标准差）。
  • 最难四个 domain 的离线增益：antmaze-giant +21、humanoidmaze-large +18、cube-triple +22、cube-quadruple +35（SQAM 54% vs 最强基线 19%）。
  • 50 任务总体：SQAM 达 75%，最强基线 TRQAM 为 68%；该优势在在线阶段同样保持。
  • 真实机器人实验：SQAM 在全部三项操作任务上明显优于监督微调（SFT），而残差微调方法（EXPO-FT 类）在相同设定下表现不佳。
  • 消融实验表明：价值惩罚系数 c 与 KL 预算 ε_KL 对性能均有显著影响；只作用于数据集动作或动作距离的正则方法（如 IQL、ReBRAC）提升有限。
