Card 03 核心贡献

核心贡献

  • 统一评测框架：基于可执行任务的统一形式化（V-BDDL），将面向能力维度的 ID/OOD 配对评测、扰动鲁棒性评测以及诊断驱动模型改进整合为"评测—诊断—优化—复评"的单一闭环。
  • 诊断可归因的任务构建：构建覆盖 6 类能力（视觉感知、语义指代、常识与世界知识、空间推理、动作推理、组合能力）的受控任务族，在控制非目标变量的前提下提供配对 ID/OOD 任务，实现能力瓶颈级归因。
  • 组合扰动评测：构建分层扰动空间（3 大类、11 个因子、33 个属性、268 个经验证参数值），支持静态/动态与单因子/组合扰动，并通过单因子敏感性分析校准强度、筛选代表性扰动因子组合（PFC）。
  • 诊断驱动模型改进闭环：依据细粒度诊断结果挑选困难场景，在训练子集上做定向数据增强、采集成功示范并微调模型，最后在无重叠的留出场景上复评改进效果。
  • 开源资源：公开完整评测套件、训练示范、微调后的 VLA 模型及自动化生成/评测工具（https://vla-gauge-site.pages.dev/）。
Card 04 方法描述

方法描述

  • Variant-augmented BDDL（V-BDDL）：在 BDDL 基础上扩展可选的 :variant 变体块，将任务建模为四元组 T = (ℓ, O, C, E)（指令、场景布局、成功判据、执行条件配置），每个扰动项编码为 ρᵢ = (cᵢ, fᵢ, uᵢ, vᵢ, μᵢ)（类别、因子、属性、参数值、静态/动态）。
  • 扰动算子 P_E：通过 :variant 接口将执行条件集合 E 实例化为扰动任务 T̃ = P_E(T)，将异构真实扰动转为参数可控、可复现的扰动任务。
  • 双分支基准构建：① 细粒度能力套件（270 个干净基座场景均分至 6 个能力套件，每个套件含 ID 与 OOD 子套件）；② 分层扰动空间（视觉信息、空间结构、控制执行三类扰动）。
  • 扰动参数验证三准则：扰动有效性（模拟器/观测/控制属性确实改变）、物理可行性（可正确初始化与稳定执行）、语义一致性（指令、目标谓词、技能类型、成功判据不变）。
  • 评测协议：零样本泛化评测报告 ZS_ID / ZS_OOD / ZS_ALL；鲁棒性评测分三阶段——单因子敏感性分析、组合扰动筛选、组合扰动评测，均以 R-Score 衡量性能保持程度。
  • 关键创新点：以"单主诊断变量变化 + 非目标变量控制"的变量控制原则降低跨能力混淆；扰动强度经单因子分析校准；仅保留满足三准则的参数值以减少混杂。
Card 05 数据集与资源

数据集与资源

  • 基准规模：6,300 个任务实例、3,089 个候选物体、270 个干净基座场景；扰动空间含 3 大类、11 个因子、33 个属性、268 个验证参数值。
  • 任务资产：将 VLABench、SimplerEnv、RLBench、LIBERO、Behavior-1K 等已有工作的资产转换为兼容 Robosuite 的定义。
  • 参考分布：以所有被评测模型共享的 LIBERO 训练分布作为 ID 参考，在其上构建 ID 与 OOD 设定。
  • 被评测模型（12 个）：涵盖离散动作模型（UniVLA、Nora、FAST、DeepThinkVLA、SimpleVLA-RL）、连续动作模型（OpenVLA-OFT、RIPT-VLA、CronusVLA、OpenVLA、π0）与混合动作模型（π0.5）。
  • 评测配置：每个场景执行 50 次闭环 rollout，所有模型共享预定义初始状态与随机种子；难度按参考模型成功率 0.6 阈值划分为 Easy / Medium / Hard。

Card 06 评估与结果

评估与结果

  • 评估环境：基于 Robosuite 的闭环机器人操作仿真，统一执行时间限制与随机种子；模型参数在评测期间保持冻结。
  • 主要指标：零样本得分 ZS_y（ID/OOD/ALL 上的平均成功率）、扰动鲁棒性指标 R-Score。
  • 总体零样本性能：全部模型平均零样本得分仅 22.3%（ID 32.9%，OOD 仅 7.2%）。
  • 能力瓶颈：空间推理为最弱能力维度，平均 13.0%（即使在 ID 条件下已暴露）；组合能力在 OOD 上最差，平均仅 2.8%，12 个模型中有 9 个得分为 0。
  • 知名模型表现落差：SimpleVLA-RL（在其报告中对 LIBERO 成功率高达 99.1%）在 VLA-Gauge 上零样本得分仅 8.0%，在 12 个模型中排名倒数第二。
  • 组合扰动鲁棒性：三种代表性组合扰动配置下平均 R-Score 为 9.3；36 个"模型-配置"对中有 34 个得分不高于 17.7，且没有模型能在三种配置下始终保持领先；当组合涉及 1→3 类扰动时，平均 R-Score 由 16.5 降至 2.9。
  • 诊断驱动微调有效性：对 π0.5 的定向微调在留出场景上将其零样本泛化与指定组合扰动鲁棒性分别提升 72.4 与 31.8 分，后者显著超过 Libero-Plus 单因子微调带来的 10.9 分增益，且使用的成功轨迹更少。
  • 结论性发现：熟悉任务上的高报告成功率既不能保证对未见任务的强零样本泛化，也不能保证对组合扰动的鲁棒性；而诊断式评测可为定向模型改进提供可操作的信号。
