Card 02 论文概述

论文概述

  • 论文研究人形机器人全身移动操作（loco-manipulation）中的非马尔可夫决策问题：动态场景中物体变化、被遮挡或移出视野后，仅依赖当前观测的 VLA 策略无法做出正确决策
  • 提出预历史记忆（pre-history memory）概念，指机器人在执行目标动作前看到的所有物体事件记录
  • 针对现有记忆方法（长帧历史、压缩、均匀采样等）在全身人形平台上成本高、易丢失短暂线索或漏掉关键帧的问题，提出物体事件引导的自适应记忆选择机制
Card 03 核心贡献

核心贡献

  • 提出 WholeBodyMem：面向全身 VLA 的物体引导感知记忆，用物体事件（出现、消失、移动、形状变化）而非均匀采样来选择关键帧，并与物体 token 一起由动作专家读取
  • 引入 HuMeGo 基准：包含 6 个仿真任务和 6 个真实 Unitree G1 人形机器人任务，覆盖物体记忆、空间记忆和时间记忆三类，且决策与操作分离评分
  • 证明 WholeBodyMem 保持“正确的帧而非更多帧”，在决策准确率和任务成功率上均显著优于无记忆和均匀记忆基线，并在 SIMPLE 标准任务上也有提升
  • 在真实 G1 机器人上验证了方法的迁移能力（成功率从 36.7% 提升至 88.3%）
Card 04 方法描述

方法描述

  • 物体追踪：使用冻结的 SAM3（可提示视频分割模型）跟踪任务物体，并通过对连续帧背景特征拟合相似变换消除相机自身运动，得到物体相对场景的运动
  • 物体事件检测：当物体出现、消失（保留最后可见帧）、重新出现、移动超过图像对角线 3%、或形状变化（掩码重叠率低于 65%）时，将其标记为记忆候选帧；事件按类型和置信度排序
  • 因果自适应选择：始终保留首帧、中间帧和当前帧，剩余至多 4 个槽位按事件得分填充；同一物体的帧间隔小于 5 帧则跳过，内存总帧数 3–7（平均 5.4），且只用截至当前时刻的帧
  • 记忆读取：动作专家（6 个 DiT 块）通过交叉注意力和 FiLM 调制读取记忆 token；记忆 token 包含原生视觉骨干 token（每帧 77 个）+ 物体 token（每帧最多 2 个，含外观、几何和时间编码），并附加正弦位置编码
  • 决策头：一个可学习查询在记忆和物体 token 上进行注意力，输出每个候选答案的 logit，其 softmax 作为动态权重注入各块的 adaptive layer norm
Card 05 数据集与资源

数据集与资源

  • HuMeGo 基准：6 个仿真任务（FlashPad、HideMug、ShellGame、LitLamp、BlinkPad、TouchPad）+ 6 个真实 Unitree G1 任务（含咖啡厅座椅任务等）
  • 数据来自脚本化全身专家演示，每个仿真记忆任务 100 条训练演示、90 个测试场景；平均每个 episode 1155 个控制步（50Hz，约 23s），其中 40.7% 的步发生在决策点之后
  • 模型基于 Psi-0（π₀.₅ 架构的微调版本）作为基础策略；记忆预算 B_max=7 帧、每帧 K=77 个原生 token（7×11 网格），共 539 个记忆 token + 最多 14 个物体 token
  • 训练使用 MuJoCo（2000Hz 物理、50Hz 控制）仿真环境，通过 Isaac Sim 渲染头相机图像；SAM3 冻结，仅训练新增的记忆模块
Card 06 评估与结果

评估与结果

  • 仿真记忆任务：WholeBodyMem 平均成功率为 23.0 / 21.5 / 20.8（L0 / L1 / L2），对比 Ψ₀ 无记忆的 8.3 / 10.0 / 7.8 和均匀记忆的 12.0 / 14.3 / 13.7
  • 记忆决策准确率：WholeBodyMem 达到 94%，远高于 Ψ₀ 无记忆的 39% 和均匀记忆的 50%
  • SIMPLE 标准任务（14项）：WholeBodyMem 成功率 86.9%（365/420），对比 Ψ₀ 基线的 70.2%（295/420）和均匀记忆的 76.9%（323/420）
  • 真实机器人实验：在 Unitree G1 上，WholeBodyMem 将成功率从基础策略的 36.7% 提升至 88.3%，显著优于无记忆和均匀记忆基线
  • 对比基准：在表格中对比了 InternVLA-M1、DP、ACT、EgoVLA、π₀.₅、GR00T、Ψ₀ 和均匀记忆；WholeBodyMem 在绝大多数任务上取得最佳或次佳成绩
