MAST-VLA: Skill-Conditioned Adaptation with Trajectory-Affordance Priors for Multi-Skill Robot Manipulation

02论文概述

  • 提出 MAST-VLA，一种面向多技能机器人操作的双条件化 VLA 框架，解决当前多技能 VLA 策略对指令中“执行哪个基元技能”和“在哪里/如何接触与移动物体”建模不足的问题
  • 将多技能 VLA 适配建模为双重接地问题：在 LLM 主干中对齐基元技能结构与适配容量，并基于轨迹导出的交互几何来接地动作解码
  • 在 CALVIN ABC→D 长时程多技能跨场景泛化设置和真实机器人多技能序列实验中验证其有效性

03核心贡献

  • 提出 双条件化 VLA 框架，在共享策略中联合建模基元技能结构与交互相关空间接地
  • 引入 技能条件 LoRA-MoE 专业化，利用技能查询 token 和路由偏置在 LLM 主干中调节低秩专家专业化，减少跨技能干扰
  • 引入 轨迹-可供性空间先验，将未来夹爪运动与场景几何转换为热图监督和 patch 级空间偏置，强化交互感知的动作生成
  • 在 CALVIN ABC→D 上达到 Avg. Len 4.65，将 Success@5 从 80.0% 提升到 84.7%，取得 SOTA 性能
  • 真实机器人实验验证了在感知和控制噪声下的可部署性与顺序执行鲁棒性

04方法描述

  • 技能条件 LoRA-MoE 适配：在 LLM 主干中替换选定 FFN/MLP 子层为 LoRA-MoE 适配器；技能查询 bank 提供输入侧技能 token，分层路由偏置 bank 调制 Top-k 专家路由，形成软技能条件适配路径
  • 轨迹-可供性空间先验：从当前场景表面与未来夹爪轨迹的 3D 距离自动构建可供性热图目标；通过密集监督训练热图预测头；将预测热图归一化并下采样为 patch 级空间先验，以加性偏置注入动作头的注意力 logits
  • 基元技能条件：将细粒度操作指令匹配到紧凑的基元技能分类（旋转、滑动/推动、提升/拾取、放置/存储、堆叠、切换），仅用于索引技能查询和路由偏置 bank，不改变原始语言指令和动作目标
  • 训练目标：联合优化动作块回归（ℓ₁ 损失）、可供性热图监督（加权 BCE 损失）和 MoE 路由正则化（router auxiliary loss）

05数据集与资源

  • CALVIN ABC→D 基准：在场景 A–C 训练，在未见过场景 D 测试；标准五子任务协议评估 Success@1–5 和 Avg. Len
  • 真实机器人数据：基于 Franka Research 3 平台与 Franka 夹爪、两个 Intel RealSense D435i 相机；两个桌面场景，8 个长度-3 基元子任务序列；每个基元任务约 80–100 个演示
  • 主干模型为 VLA 基座，使用 LoRA-MoE 适配器进行参数高效微调；具体模型参数量与训练 GPU 资源在节选 HTML 中未明确列出

06评估与结果

  • 仿真评估（CALVIN ABC→D）：MAST-VLA 取得 Avg. Len 4.65，Success@1–5 分别为 99.4 / 97.4 / 94.2 / 89.2 / 84.7，优于 VLA-Adapter-Pro、FLOWER、FALCON、VPP、Seer-Large 等对比方法
  • 真实机器人评估：在 8 个长度-3 序列上，MAST-VLA 的每序列 Avg. Len 和整体序列完成率均优于基线，表现出对累积感知与控制误差的更强鲁棒性
  • 消融实验：技能查询 token 单独增益有限；加入 LoRA-MoE 后增益明显；轨迹-可供性空间先验进一步提升长时程完成；随机替换为不匹配技能条件时 Avg. Len 从 4.65 降至 4.55
  • 路由分析：不同技能呈现差异化的 Top-2 专家偏好，验证技能条件偏置诱导了专家专业化，同时保持内容依赖的软路由
  • 可供性热图分析：预测热图集中于未来交互区域（物体接触、目标容器、插入区域、堆叠界面），运动中心操作的热图沿物体运动方向延伸
