Card 02 论文概述

论文概述

  • 提出 HOIBlender，一个高效的人-物交互（HOI）检测框架，核心思想是将轻量级检测器特征、空间推理和视觉-语言先验知识有机融合到单一解码管线中
  • 解决现有 HOI 检测方法中检测头过重（依赖复杂的 Transformer 编码器）以及视觉-语言先验与视觉解码路径耦合不紧密的问题

Card 03 核心贡献

核心贡献

  • 提出一种 编码器无关的 HOI 检测器，直接从多尺度投影器输出中选取交互候选 token，去除了传统方法中笨重的 Transformer 编码器阶段
  • 设计了一个 双阶段交互解码器，第一阶段稳定人-物几何关系，第二阶段融合 BLIP-2 语义先验进行动词和 HOI 分类，并将 BLIP-2 文本嵌入用作分类器权重初始化
  • 引入 分组查询训练策略，在训练时使用多组查询丰富匹配多样性以改善优化，推理时仅保留单组查询，不增加推理成本
  • 在 HICO-DET 数据集上，以极少的训练轮次（9个 epoch）获得 44.49 mAP 的最佳结果，并在三种模型规模上全面超越 SOV-STG-VLA 和 Hybrid-SOV-VLA 等强基线
Card 04 方法描述

方法描述

  • 检测器优先基础：采用 DINOv2 作为视觉骨干，结合 RF-DETR/LW-DETR 风格的多尺度投影器，直接从投影特征中选取 Top-K token 作为主体和客体的候选查询
  • 双阶段解码：阶段 A 通过耦合解码流细化人-物空间几何关系；阶段 B 在稳定几何信息基础上，引入 BLIP-2 图像特征作为语义记忆，并使用 BLIP-2 文本嵌入初始化动词和 HOI 分类器权重
  • 多先验语义融合：在解码器记忆层和分类器权重层两个层面深度融合视觉-语言先验，使模型既能关注图像特定的语义特征，又能利用已组织的标签语义空间进行预测
  • 匹配与训练：使用匈牙利匹配进行端到端训练，损失函数包含目标分类、边界框回归、GIoU 损失以及动词和 HOI 的交互损失
Card 05 数据集与资源

数据集与资源

  • 数据集：HICO-DET（38,118 张训练图像，9,658 张测试图像，涵盖 80 个物体类别、117 个动词和 600 个 HOI 类别）
  • 模型变体：HOIBlender-N（Nano）、HOIBlender-S（Small）、HOIBlender-2XL，分别基于 DINOv2-S 和 DINOv2-B 骨干网络
  • 训练资源：8 张 NVIDIA A6000 GPU，批次大小为 16
  • 推理延迟评估：在单张 NVIDIA A100 GPU 上测量
Card 06 评估与结果

评估与结果

  • 评估基准：HICO-DET 数据集，使用 Default 和 Known Object 两种设置下的 Full、Rare、Non-Rare 子集 mAP 指标
  • 关键实验结果：

- HOIBlender-N：15 个 epoch 达到 41.36 Default Full mAP，超越 SOV-STG-VLA

- HOIBlender-S：15 个 epoch 达到 43.19 Default Full mAP，与 Hybrid-SOV-VLA 持平或更优，但解码器层数更少且无编码器

- HOIBlender-2XL：仅用 9 个 epoch 即达到 44.49 Default Full mAP，为对比方法中最高，同时 Non-Rare mAP 达到 44.86

  • 效率分析：HOIBlender 系列在准确率-延迟-参数量方面形成了有利的帕累托前沿，展示了轻量级设计、空间-语义解码与视觉-语言集成的高效融合
