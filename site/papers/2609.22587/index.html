React When You Need To: Event-Triggered Asynchronous Inference for VLA Policies

02论文概述

  • 针对现有视觉-语言-动作（VLA）模型在执行动作块期间无法对环境变化做出及时反应的问题，提出事件触发的动态推理策略
  • 现有异步推理方法依赖固定推理间隔，存在响应性与执行可靠性之间的权衡，本方法根据观察到的场景变化动态调整推理间隔
  • 在保持无停顿执行的同时，当无显著事件时保持最大可行间隔，检测到事件时立即触发新推理，同时保持运动一致性和快速响应性

03核心贡献

  • 提出事件触发的动态推理策略，在无显著事件时保持最大可行间隔，检测到事件时触发早期推理，同时保持运动一致性和快速响应性
  • 开发基于VLA视觉编码器的轻量级事件估计器，量化自最近策略推理以来的场景变化，以高达15 Hz频率运行
  • 从人类演示中自动构建事件监督数据集，避免人工标注事件发生和相关性
  • 进行全面的真实世界实验，涵盖静态和动态任务，平均成功率达95%，比最强基线高55个百分点

04方法描述

  • 事件监督构建：从人类演示中自动派生事件监督，包括数据收集、VLA微调和事件估计器数据集构建三个步骤
  • 事件估计器：由冻结的VLA视觉编码器和轻量级Transformer事件解码器组成，比较锚点场景与当前场景的视觉表示来预测事件分数
  • 分数到事件映射：定义P90阈值（静态演示分布的第90百分位数）将连续事件分数转换为二值推理决策，需连续两次评估超过阈值才触发事件
  • 事件驱动推理调度：策略推理和事件估计交替运行避免资源竞争，事件触发早期推理时使用指数加权混合实现平滑过渡

05数据集与资源

  • 每个任务收集40个静态环境演示和160个动态环境演示，共形成200个演示
  • 使用π0.5 VLA策略主干，微调30,000步，批次大小32
  • 微调使用6个NVIDIA A40 GPU
  • 推理在配备NVIDIA RTX 3090 GPU的工作站上执行
  • 实验平台：Franka Emika Panda机器人和3个Intel RealSense D435i相机

06评估与结果

  • 评估环境：两个真实世界操作任务——带静态/动态障碍物的抓取放置任务和移动目标放置任务
  • 比较方法：同步执行、DynamicVLA、RTC、四种固定间隔消融（g=0, 5, 25, 45）
  • 主要评估指标：阶段成功率和全任务成功率
  • 静态障碍物任务：本方法全任务成功率100%，多个基线方法在抓取阶段失败
  • 动态障碍物任务：本方法全任务成功率100%，所有基线方法不超过15%
  • 移动目标任务：本方法成功率85%，比RTC高45个百分点，比最佳固定间隔消融高25个百分点
  • 三种设置下平均成功率达95%，比最强基线高55个百分点
