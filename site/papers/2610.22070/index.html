02论文概述

  • 论文针对流式视频理解中长时历史记忆的核心难题：流式视觉语言模型（VLM）必须持续整合过去信息、理解当前观测，并保持对用户查询的实时响应。
  • 现有记忆机制（压缩、检索、缓存历史观测并重新注入输入上下文）导致历史记忆与当前观测争夺有限上下文，且需反复重算全量历史、推理开销大。
  • 提出 MaLoW（Memory as LoRA Weights），将历史上下文内部化到持续演化的轻量 LoRA 权重中，实现“历史作为权重、当前观测作为输入”的分离式记忆范式。

03核心贡献

  • 提出 MaLoW：一种将历史上下文内部化到演化 LoRA 权重中的流式记忆框架，与以往将历史放入上下文窗口的方法形成根本性区别。
  • 设计了循环 HyperNetwork，从流式视频及其他上下文增量更新 LoRA 记忆；并构建了大规模流式视频训练数据集 MaLoW-Instruct（56K 视频、381K QA 对），将公开数据集适配至流式设定。
  • 在 OVO-Bench、StreamingBench、StreamArena 等流式视频基准上取得竞争性甚至领先结果，并在 0.8B–11B 不同基座 VLM 上获得一致增益。
  • 进一步将 MaLoW 推广到视觉-语言-动作（VLA） 设定，在 Simpler WidowX 上动作成功率提升 9.3%。

04方法描述

  • 问题建模：将流式 VLM 形式化为 $R_t = M_{\theta+\Delta\theta_t}(I_t, C_t)$，历史 $C_{0:t-1}$ 通过超网络 $\Phi$ 编码为 LoRA 增量 $\Delta\theta_t$，仅当前观测 $C_t$ 与查询 $I_t$ 作为输入。
  • 上下文编码：使用可学习查询 $Q$ 结合视频嵌入 $V_{t-1}$ 与文本/时间戳嵌入 $T_{t-1}$，通过若干自注意力层压缩为紧凑表示 $q_{t-1}$。
  • 隐藏状态更新：将隐藏状态分解为两支——SSM 分支（基于 DeltaNet 建模局部时序依赖）与门控求和分支（保留全局历史语义，由视频相似度阈值触发的二值门控更新）。
  • LoRA 解码：通过 RMSNorm + 线性投影与可学习门控 $\alpha$ 将隐藏状态映射为 LoRA 权重，应用于下一时刻的 VLM。
  • 训练策略：冻结 VLM 参数 $\theta$，仅通过生成的 LoRA 权重回传梯度训练超网络，损失为 下一 token 预测损失 + LoRA 幅度正则项。
  • 理论分析（附录 A）：论证历史诱导的特征变换可由低秩参数更新表达，并分析其在 MLP 投影中的低秩实现与在线更新成本。

05数据集与资源

  • MaLoW-Instruct：56K 视频、381K 指令 QA 对；约 36% 的 QA 时间戳位于事件结束之后，以显式监督历史保留与检索能力。
  • 数据来源覆盖 14 个数据集，其中 CosMo-Cap、YouCook2、Charades-STA、ActivityNet-Captions 合计占 62.5%；问题类型在选择题、开放式、是非题间近似均匀分布。
  • 数据构建流程包含问题生成器、答案生成器与验证器；使用 Qwen3.5-122B-A10B 作为生成器、Qwen3.5-397B-A17B 作为验证器，并过滤掉 OVO-Bench 中的样本以防数据泄漏。
  • 基座 VLM 涵盖 0.8B–11B 参数规模，包括 Qwen3-VL-4B、Qwen3.5-9B、VideoChat3-4B、MOSS-VL-Realtime-11B。
  • 可训练参数：197.6M–321.1M（占基座 1.4%–4.0%）；训练 2,800 步、批大小 64、Adam 优化器、峰值学习率 8×10⁻⁵、余弦学习率调度。
  • 视频以 1 fps 采样，每个 $C_t$ 为 2 秒视频片段；LoRA 秩为 8，应用于各注意力层 MLP 与 v_proj 层等。

06评估与结果

  • 基准与协议：在 StreamingBench（Real-Time 划分）与 OVO-Bench（Real-Time 与 Backward 划分）上评估，后向划分包含 EPM（情节记忆）、ASI（动作序列识别）、HLD（幻觉检测）三个任务。
  • 对比基线：分为四类——离线 VLM、具备长时（全量）上下文的流式 VLM、仅使用局部上下文窗口的流式 VLM、以及带记忆机制的局部上下文流式 VLM。
  • 关键结果（OVO-Bench）：MaLoW (MOSS-VL-Real-11B) 取得 74.5 的 SOTA 平均分；MaLoW (Qwen3.5-9B) 取得最高的 EPM 63.6 分；MaLoW (Qwen3-VL-4B) 在 StreamingBench 上达到 84.8。
  • 相对增益：在 OVO-Bench 后向划分上，MaLoW 较先前记忆方法提升 3.9%–11.8%（不同视频基座），且仅带来适度的延迟开销。
  • 泛化性：跨 0.8B–11B 基座 VLM 均有稳定提升；在 VLA 设定下，引入历史观测与动作轨迹使 Simpler WidowX 动作成功率提升 9.3%。
