02论文概述

  • 论文提出 Imprint，一个与策略无关（policy-agnostic）的潜在记忆框架，为视觉-语言-动作（VLA）模型增强多流（multi-stream）记忆能力，而不预先限定策略应该记住什么。
  • 核心问题是：现有记忆增强策略通过“curation（筛选）”方式（如只保留近期帧、关键帧、文本摘要，或仅学习视觉流的潜在表示）来压缩历史，但这种预定义的“相关性”会丢失运动细节、感觉运动信息或久远历史，限制性能。
  • 目标是设计一种能压缩异构且不断增长的交互历史（视觉、动作、本体感觉）到有界潜在记忆的编码器，同时保持低推理延迟并避免策略学习到虚假捷径（spurious shortcuts）。

03核心贡献

  • 提出 Imprint，一个策略无关的潜在记忆框架，可高效压缩多流历史为潜在记忆，并在推理时增量更新。
  • 设计两阶段训练流程：先用历史重建（视觉特征、动作、本体感觉）和任务进度估计进行记忆预训练，再与策略通过动作损失联合微调，避免捷径学习。
  • 系统分析记忆容量、编码方式、训练目标和训练配方对下游任务性能的影响。
  • 在 RMBench、定制的 12 任务 RoboCasa 基准和三个真实世界任务上验证，并证明框架可跨多种 VLA 骨干（π₀、π₀.₅、MolmoAct2）泛化。
  • 相比基础 VLA 在 RMBench 上提升 47.4%、真实世界提升 50% 成功率，同时保持最低平均推理延迟 122.8 ms。

04方法描述

  • 多流记忆编码：将历史表示为四条 token 流——历史视频、近期图像、已执行动作、本体感觉状态；使用冻结的因果视频 tokenizer（Cosmos/Wan）压缩高冗余视频流，用 DINOv3 编码近期帧，用独立 MLP 嵌入动作与状态。
  • 记忆瓶颈：引入 B 个可学习 query embedding（类似 Perceiver），在任务描述条件下去读取四条 token 流，压缩为固定大小的潜在记忆 token，包括 Full Attention 瓶颈和 Recurrent（GDN 门控 delta 块）瓶颈两种实现。
  • 解耦记忆监督（两阶段训练）：

- Stage 1 记忆预训练：解码器对采样的 K 个历史步重建视觉特征、动作、状态，并预测归一化任务进度 ρ，损失为 L_mem，不含策略。

- Stage 2 策略无关记忆适配：丢弃解码器，初始化编码器，通过轻量级 action-expert adapter（cross-attention + FiLM 调制）将记忆注入不同 VLA，联合优化动作目标。

  • 创新点：放弃历史筛选，改为让记忆从多流数据中“自学习”该记住什么；通过重建 + 进度估计“prime”瓶颈，减少策略微调时的捷径依赖。

05数据集与资源

  • 仿真基准：RMBench 全部 9 个记忆依赖任务；基于 RoboCasa 与 ReMemBench 构建的 12 任务定制基准（6 个记忆任务 + 6 个非记忆任务）。
  • 真实世界：双臂 YAM 平台上的三个记忆任务——Dust Table、Scan Bottle、Fold Cloth。
  • 模型配置：默认以 π₀.₅ 为基础策略，记忆容量 B=256 tokens，维度 d=1024；对比骨干还包括 π₀ 与 MolmoAct2。
  • 推理资源：延迟测试在 L40S GPU 上进行，按每 50 步动作块统计。
  • 论文未明确给出训练 GPU/TPU 集群规模（细节见附录 A.1.5 训练超参与资源）。

06评估与结果

  • 评估设置：RMBench 每任务 100 次试验，RoboCasa 每任务 50 次试验；以任务成功率与推理延迟为主要指标，采用平滑密度分布（小提琴图）展示结果。
  • 仿真结果（RMBench）：启发式采样方法最高 67.8%，分层记忆方法最高 42.0%，先前潜在记忆方法最高 41.7%；Imprint 达到 72.8% 成功率（基础 VLA 仅 25.4%）。
  • RoboCasa 结果：记忆任务成功率提升至 65.3%，非记忆任务 68.0%，总体 66.7%；而启发式记忆虽提升记忆任务约 15.3%，却使非记忆任务下降约 22%。
  • 真实世界结果：三个任务分别达到 80% / 75% / 72% 成功率，相较最强基线（uniform sampling）平均提升 26.7%；OOD 设置下为 45% / 70% / 31%。
  • 推理效率：Imprint 以 122.8 ms 达到最高成功率，优于 HAMLET（28.1% @ 144 ms）、MemoryVLA（41.7% @ 321 ms）、EventVLA（67.8% @ 960 ms）及需数秒的分层方法。
  • 消融结论：多流输入优于单一视觉流；记忆容量从 1→256 token 提升显著，但 1024 token 反而略降；循环压缩在保持性能同时降低延迟；预训练 + 联合适配（50.8% → 58.8% → 72.7%）均重要；重建与进度估计目标互补。
