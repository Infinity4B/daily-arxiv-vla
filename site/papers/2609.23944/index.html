02论文概述

  • 聚焦视觉-语言-动作（VLA）策略在拓扑复杂的操作任务中的失效问题：复杂障碍物几何导致部分可观测下相似视觉/机器人配置需要本质不同的动作，常规VLA无法显式区分这类拓扑相关的动作差异
  • 提出拓扑引导的视觉提示（Topology-Informed Visual Prompting）框架，通过仿真规划生成拓扑纠正和任务续接的增强演示数据微调VLA，部署时用微调后的VLM生成拓扑感知的视觉提示引导VLA，无需部署时已知完整环境几何信息
  • 解决两个核心问题：一是VLA无法学习通用拓扑推理能力，二是VLM与动作联合训练会导致预训练推理能力退化的问题

03核心贡献

  • 提出virtual h-signature拓扑签名表示，通过虚拟边闭合开环的机器人-物体操作路径，将原本仅适用于闭环路径的h-signature适配到抓取前等开环操作场景，可表征物体是否穿过环、机器人路径是否绕过障碍物等关键拓扑性质
  • 提出预训练VLM微调方案，使VLM仅需视觉观测即可推理任务相关的virtual h-signature，无需完整环境几何信息
  • 提出拓扑感知的视觉提示框架，将VLM输出的拓扑引导信息以图像空间箭头的形式传递给VLA，在不修改VLA架构的前提下解决拓扑相关的动作歧义，同时保留VLM的预训练推理能力

04方法描述

  • 框架分为三个核心模块：拓扑感知演示生成、视觉提示构建、闭环VLM引导
  • 拓扑感知演示生成：首先用标称演示微调基础VLA策略$\pi_{\text{base}}$，随后在仿真中闭环执行$\pi_{\text{base}}$，对遇到的机器人配置添加高斯噪声扰动，利用仿真提供的特权$h^v$标签将无碰撞扰动配置分配到对应恢复数据分支，通过RRT规划器生成纠正拓扑签名的无碰撞轨迹，同时生成签名纠正后的任务续接轨迹，混合标称、纠正、续接三类数据微调最终VLA策略$\pi_{\text{VLA}}$
  • 视觉提示构建：将训练用的末端执行器轨迹投影到图像空间，按时间顺序连接为带方向箭头的路径，分为拓扑纠正箭头和任务续接箭头两类，覆盖在原始视觉观测上得到带提示的输入，供VLA学习视觉引导与连续动作的映射
  • 闭环VLM引导：微调Qwen3-VL-8B-Instruct模型同时完成$h^v$签名预测和图像空间路径点预测两个任务，部署时先预测当前$h^v$，再输出对应引导路径点，渲染为视觉提示后输入VLA输出动作，形成闭环更新提示
  • 关键创新：将拓扑推理与动作预测解耦，避免VLM与动作联合训练导致的灾难性遗忘；利用近似仿真自动生成拓扑纠正演示数据，无需大量真实硬件遥操作数据；提出的virtual h-signature可适配开环操作场景的拓扑表征需求

05数据集与资源

  • 使用VLA骨干：π₀（2B视觉语言骨干+300M动作专家）、π₀.₅
  • 使用VLM：Qwen3-VL-8B-Instruct
  • 仿真数据集：Rope Pulling、Cable Threading、Box Pickup三个双手操作任务的仿真数据集，包含标称轨迹、拓扑纠正轨迹、任务续接轨迹三类数据
  • 真实硬件数据：Box Pickup任务的15条真实到达把手短轨迹、3条$h^v$纠正轨迹，以及1000条真实随机配置的$h^v$人工标注数据
  • 训练资源：4块NVIDIA A40 GPU；VLA微调采用LoRA（视觉骨干秩16，动作专家秩32），训练20000步，全局batch size 32，学习率$5\times10^{-5}$，1000步预热，10步动作 horizon，输入图像尺寸$224\times224$，bfloat16精度；VLM微调采用LoRA（秩8，$\alpha=16$），训练1个epoch，全局batch size 32，4096 token上下文，最多262144图像像素，FP16精度，余弦学习率调度，10%预热，Box Pickup学习率$5\times10^{-5}$，Cable Threading学习率$1\times10^{-4}$

06评估与结果

  • 评估环境：3个仿真双手操作任务（Rope Pulling、Cable Threading、Box Pickup），真实硬件Box Pickup任务
  • 评估基准：Base Policy（仅用标称演示微调的VLA）、PEEK（现有VLM视觉提示基线）
  • 评估指标：任务成功率、$h^v$纠正成功率、VLM的$h^v$预测准确率
  • 关键实验结果：

- 仿真任务中，Cable Threading任务成功率比Base Policy高22-30%，比PEEK高57-58%；Box Pickup任务成功率比Base Policy高37-53%，比PEEK高16-27%；Rope Pulling任务与Base Policy性能相当，比PEEK高12-14%

- VLM的$h^v$预测准确率在Cable Threading任务上达74-76%，在Box Pickup任务上达92%

- 真实硬件Box Pickup任务中，方法任务成功率达60%，$h^v$纠正成功率达83%，分别超出最强基线40和53个百分点
