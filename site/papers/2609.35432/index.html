Card 03 核心贡献

核心贡献

  • 提出面向物理世界的编码智能体范式，定义 Physical Coding 核心概念，设计 Code as World 与 Code as Policy 两个耦合的可执行表示，为物理交互提供可检查、可修订、可复用的统一接口
  • 开发 HexaAnything 物理编码智能体，集成语言模型、状态观测、独立验证器、工具调用等模块，实现完整的“感知-决策-执行-验证-恢复”闭环
  • 在长程机器人操作、模拟科学实验、真实双臂机器人三类场景完成验证，证明Harness、工具、数据到模型层面的自进化可行性，提出 PhyBench 模拟实验室基准用于科学实验场景评估
Card 04 方法描述

方法描述

  • 核心方法为Physical Coding范式，包含两个核心可执行组件：Code as World 用代码表示任务相关的物体、关系、约束、观测、进度谓词，从图像、深度、传感器读数、工具输出增量生成，不依赖仿真器特权信息；Code as Policy 用代码表示任务分解、工具调用、执行、验证、恢复的完整流程，可调用从通用机器人工具到预训练VLA/WAM策略的各类动作工具
  • 设计物理自进化循环，遵循“生成-评估-选择”的进化模式，每轮包含规格指定、执行、验证、诊断、提议、评估、选择提交7个步骤，可对Harness、数据与环境、模型与算法、本体与计算底座四个目标进行迭代优化，所有修改需通过独立验证器的校验，保留可追溯性与可回滚性
  • HexaAnything的Harness作为物理环境与可执行程序之间的边界，提供观测接口、工具注册表、验证器、恢复操作符、溯源记忆、执行合约等能力，支撑编码-动作-状态-反馈的闭环运行
Card 05 数据集与资源

数据集与资源

  • 使用数据集与基准：RoboCasa365 长程机器人操作数据集、自主提出的 PhyBench 模拟实验室基准（包含胡克定律、单摆、耦合振子三个物理实验任务）、真实部署使用 AgileX 双臂机器人平台
  • 模型规模：基础动作模型采用 QwenGR00T（基于Qwen3-VL-4B骨干，GR00T风格动作头），后续基于Harness收集的轨迹训练得到 HexaModel
  • 训练资源：训练基于上述模型与数据集开展，真实机器人部署通过URAI接口完成，未明确披露具体GPU/TPU硬件配置
Card 06 评估与结果

评估与结果

  • 评估环境与基准：覆盖RoboCasa365操作基准、PhyBench科学实验基准、AgileX真实双臂机器人三类场景
  • 主要评估指标：任务成功率、长程执行鲁棒性、科学实验完成效率、模型泛化能力等
  • 关键实验结果：

- 在RoboCasa365上，HexaAnything的整体成功率与Composite-Unseen场景成功率均超过对比基线XR-1 VLA，用Harness收集的执行轨迹训练的HexaModel在所有数据划分上均优于基础模型，验证了代码轨迹可内化物理执行能力

- 在PhyBench模拟场景与真实双臂机器人上，智能体可自主完成物理实验与大部分桌面操作任务，多数场景的执行效率超过已发表结果

- 实验初步观测到数据、模型、工具层面的自进化效果，验证了Physical Coding范式的可行性
