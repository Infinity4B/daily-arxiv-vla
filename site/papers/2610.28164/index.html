From Predictive Geometry to Action: Learning Complementary Predictive Representations for Embodied Manipulation

02论文概述

  • 论文提出一种两阶段框架 CPR（Complementary Predictive Representations），从多视角视频片段中学习互补预测表示以提升具身操作策略
  • 解决的核心问题是：现有方法要么仅将当前场景几何作为输入增强，要么将未来预测作为辅助监督，但未明确如何表示预测几何以有效支持动作生成
  • 论文认为预测几何建模需要保留完整的场景结构，而动作生成需要强调与动作相关的几何过渡，因此提出学习两种互补表示并分别转移

03核心贡献

  • 识别出预测几何表示和运动表示在预测策略学习中的互补作用：预测几何需要保留结构化场景几何，而动作生成需要强调控制相关的几何过渡
  • 提出两阶段框架 CPR：预训练阶段学习预测几何表示和运动表示，后训练阶段通过几何查询和运动对齐两种角色特定路径将表示转移到下游策略
  • 在 LIBERO、LIBERO-Plus、SimplerEnv 和真实世界双臂与单臂操作任务中，一致提升多种 VLA 架构和 WAM 的性能，WidowX 评估绝对提升 10.4 个百分点
  • 验证方法可迁移至 GR00T、π₀ 等多种 VLA 模型和 FastWAM 世界动作模型，提升未来世界和动作预测

04方法描述

  • 预训练阶段：使用冻结 3D 基础模型提取多视角视频的稠密几何特征，通过分层查询编码器压缩为紧凑的时序状态
  • 预测几何表示学习：采用三个目标——几何重建、掩码表示预测、几何过渡预测，促使表征保留空间结构并捕获时序演化
  • 运动表示学习：从预测几何状态的过渡中通过动作监督提取动作相关的运动表示，强调与动作相关的几何变化
  • 后训练阶段：使用几何查询对齐预测几何表示，同时将运动表征用于中间特征的余弦距离对齐；未来观测和预训练模型仅在训练中作为特权监督，推理时无需使用

05数据集与资源

  • 预训练数据来自大规模异构交互视频，包括 Open X-Embodiment、DROID、LIBERO、Something-Something V2 等
  • 使用冻结的 3D 基础模型（Wang et al., 2025）作为几何特征提取器
  • 下游基准包括 LIBERO、LIBERO-Plus、SimplerEnv（WidowX） 和真实世界机器人任务
  • 训练资源（附录 B 中提供详细配置）：预训练约需 2 天，下游后训练约需 1 天（具体 GPU 类型在正文中未直接给出）

06评估与结果

  • LIBERO：平均成功率从 96.6% 提升至 98.6%（绝对增益 2.0%）
  • LIBERO-Plus：零样本任务计数加权成功率从 75.0% 提升至 81.7%
  • SimplerEnv WidowX：平均成功率从 61.5% 提升至 71.9%（绝对增益 10.4%），其中 Stack Cube 改善显著
  • 真实世界：在 Remove Stopper、Transfer Liquid 等精细操作任务上一致优于基线
  • 跨策略范式：GR00T 从 62.5% 提升至 74.0%，π₀ 从 59.4% 提升至 68.8%，FastWAM 从 97.6% 提升至 98.5%
  • 消融实验表明互补表示优于统一表示（71.9% vs 67.7%），验证了分离预测几何和运动表征的有效性
