02论文概述

  • 论文提出 Hydra-0，一种以 action flow（动作流） 为条件的通用世界模型，将机器人动作表示为像素运动（pixel motion），作为连接异构训练数据、开环策略评估和机器人控制的共享视觉接口。
  • 核心目标是为通用世界建模和控制建立跨具身（embodiment）、任务和环境的可迁移预测模型，解决现有世界模型依赖 embodiment 原生指令、难以泛化的关键问题。
  • 论文强调：Hydra-0 建模的是机器人运动的后果（consequences），而非复现任务特定行为，同时支持前向动力学预测与逆向运动预测两个模式。

03核心贡献

  • 提出 kinematically grounded action flow 公式：在离线训练时可从交互视频中直接恢复动作流；在线部署时通过 Isaac Lab 控制器与物理仿真、机器人几何和相机标定，从可执行命令推导出动作流，作为视觉条件。
  • 证明 action flow 的通用性：在多个视频生成骨干（Cosmos 2.5、Wan2.2 I2V-A14B、Wan2.2 TI2V-5B）上实现跨 embodiment 的通用世界建模，最佳配置相比动作条件基线实现 90.40% 更低的机器人运动误差 和 60.16% 更低的物体运动误差，并支持到机器人-可变形物体交互的零样本组合与数据高效迁移。
  • 实现开环策略评估：在 RoboLab 基准上对 5 个策略进行重放评估，重放成功率与参考成功率的 Pearson 相关系数达到 r=0.96。
  • 探索逆向控制模式：构建 world action model（世界动作模型） 作为概念验证，从人类演示迁移的目标物体流中推断兼容的机器人运动，并通过训练的动作头将潜在特征映射为真实机器人的可执行动作，无需任务特定的专家演示。
  • 采用 多具身中期训练（multi-embodiment mid-training） 提升数据效率，并通过 因果自回归转换 与 DMD2 少步蒸馏 实现高效长时程推理。

04方法描述

  • 动作流构建：采用两种互补路线——几何感知构建（利用机器人几何、相机标定和 Isaac Lab 仿真将 3D 表面点投影到图像平面，见公式 1）与纯视频构建（使用 AllTracker 流跟踪器恢复稠密轨迹，再通过 SAM 3 等模型进行具身/物体分割）。
  • 训练时流采样：从四种条件策略中随机采样——Embodiment（主动作条件）、Object（任务/期望运动流）、All（回退）、None（条件 dropout），仅决定哪些轨迹填充共享运动张量。
  • 运动条件注入：受 ATI 和 Wan-Move 启发，将轨迹位置与可见性池化到归一化潜在网格坐标系，通过双线性采样初始帧特征并沿时间维度用高斯权重传播，形成运动条件 C_motion=(M,g)；在三个骨干上分别通过拼接、通道扩展等方式注入 DiT。
  • 高效因果 Rollout：采用 LongLive-2.0 的自回归转换（将潜在序列划分为时间块，通过 KV cache 复用已生成上下文），并采用 DMD2 蒸馏实现每块 4 步采样。
  • 逆向模式：以目标物体流为条件，训练动作头从干净 DiT token 特征中解码可执行机器人动作，使用掩码 Huber 损失与速度平滑 L1 损失联合训练（公式 7）。

05数据集与资源

  • 多具身训练语料库由 7 个来源组成：DROID（单臂 Franka）、ABC-130k（双臂）、MolmoAct2（双臂）、EgoDex（人类手部）、Deform360（手持夹爪）、XVLA-Soft-Fold（双臂）、H1-Fold-Clothes（仿人双臂），总计 178,187 个片段、过滤后 1,565,634 个窗口、约 2,201.7 小时。
  • 数据预处理：重采样至 480p、16fps，切分为 81 帧非重叠窗口，使用 AllTracker 在 128×128 查询网格上计算稠密点轨迹，并附带语言描述、VAE 潜在编码和具身/物体标注。
  • 过滤策略：静态窗口过滤、冻结夹爪过滤、DROID 无内容语言标注过滤。
  • 模型骨干：Cosmos 2.5（2B）、Wan2.2 I2V-A14B、Wan2.2 TI2V-5B；训练采用冻结预训练权重 + rank-64 LoRA 微调（仅更新 DiT patch embedding 和注意力/前馈投影），世界动作模型使用 rank-32 LoRA。

06评估与结果

  • 评估基准包括 XVLA-Soft-Fold、Deform360、DROID 等留出集，以及 RoboLab 基准的 5 个策略；对比基线包括 Cosmos 2.5（原生动作条件）、ATI、Wan-Move（零样本轨迹条件）。
  • 主要指标：PSNR、SSIM（全参考保真度）、物体/夹爪 EPE（像素级运动误差）、FID/FVD（分布质量）、VLM 评分（1-5 分制）。
  • 关键结果：最佳配置 Ours (Wan2.2 A14B 4-step) 在多数数据集上全面领先——XVLA-Soft-Fold 上 PSNR 19.23、SSIM 0.781、物体 EPE 3.47、夹爪 EPE 3.20；Deform360 上 PSNR 20.63、SSIM 0.804、FVD 166.5。
  • 相比动作条件 Cosmos 2.5 基线，Hydra-0 实现 90.40% 更低的机器人运动误差 和 60.16% 更低的物体运动误差；在 RoboLab 上重放成功率与参考成功率的相关系数 r=0.96。
  • 消融验证了多具身中期训练带来的数据效率提升、少步蒸馏（4 步）几乎无损的推理加速，以及真实机器人上的开环策略评估与物体流迁移控制的概念验证。
