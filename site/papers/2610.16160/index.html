Card 03 核心贡献

核心贡献

  • 提出 FlowVLA——一种重建引导、可插拔的 3D Flow 学习框架，仅训练时使用时序对齐的 3D flow 监督，推理期完全丢弃辅助模块，零推理开销。
  • 设计双层 flow 监督（dual-level flow supervision）：Point-Level Flow 引导模型预测任务关键 3D 点的未来位移（场景级动态），TCP-Level Flow 将点运动聚合对齐到机器人末端执行器（TCP）轨迹（控制级信号）。
  • 引入基于幅值的 Top-K 选择（Magnitude-based Selection），聚焦语义上有意义的动态区域，避免静态背景与重建噪声的干扰。
  • 提出坐标对齐机制，将参考相机坐标系下的重建点轨迹变换到机器人基坐标系，使 3D flow 与 TCP 位移可直接比较。
  • 在 LIBERO、LIBERO-Plus 仿真基准及真实机器人任务上验证，跨多种 VLA 骨干（Seer、π_0.5）一致提升操作性能、零样本鲁棒性与数据效率。
Card 04 方法描述

方法描述

  • 使用 VDPM（前馈动态重建模型）从 RGB 观测中恢复时序一致的 3D 点轨迹，计算相邻帧位置差得到 3D flow，无需任何 3D 传感器输入。
  • 以第一帧为参考帧（t_ref=0），通过刚体变换 T_base←0 ∈ SE(3) 将参考锚定的 3D 点变换到机器人基坐标系，得到 ΔP_0(t', u)。
  • Top-K 选择：按窗口内平均流量幅值 m̄_t(u) 选出动态最显著的 K 个关键点，构造关键点集 U_t。
  • Point-Level Flow：将动作 latent token z_{t+j} 经 2 层 MLP g_φ 映射并广播至 K 个点，与选中点 3D 坐标融合后由 flow head h_flow 预测逐点位移 ΔP̂_0^(j)(t)，用 Smooth L1 损失监督。
  • TCP-Level Flow：通过 softmax 归一化的权重头 h_weight 预测重要性权重 r_t^(j)，加权求和得到 TCP flow 估计，与真实 TCP 位移对齐监督，实现场景到控制的蒸馏。
  • 总损失：L_total = L_action + λ_point·L_point + λ_tcp·L_tcp；辅助头与 3D 几何输入在推理时全部丢弃。

数据集与资源

  • 数据集：LIBERO（含 Spatial / Object / Goal / Long 四个子集）、LIBERO-Plus（零样本鲁棒性评估）、真实世界自采集数据。

Card 06 评估与结果

评估与结果

  • 评估环境：仿真（LIBERO、LIBERO-Plus）+ 真实世界（UR5e，7 个任务，每任务 15 次试验）。
  • 主要指标：任务成功率（Success Rate, %）；LIBERO-Plus 下按 Camera / Robot / Language / Light / Background / Noise / Layout 扰动分类报告。
  • LIBERO-Long：Seer 从 80.4% → 87.8%（+7.4%p）；π_0.5 从 92.4% → 94.8%；Seer 平均从 87.3% → 92.4%，π_0.5 平均从 96.8% → 97.5%。
  • LIBERO-Plus 零样本：Seer 平均 36.1% → 41.1%；π_0.5 平均 57.5% → 59.2%；Camera、Robot、Light、Noise、Layout 扰动提升尤为明显。
  • 真实世界：Stack Cups 15 次仅失败 1 次；Hang Cup 从 46.7% → 86.7%；Basketball 提升约 20%p。
  • 测试时变化鲁棒性：视角变化下 Seer 基线 0% → FlowVLA 46.7%；高度变化下 46.7% → 73.3%。
  • 消融实验（LIBERO-Long）：去除坐标对齐 86.3、去除参考帧对齐 85.2、去除幅值选择 84.0、去除 TCP-level loss 83.8、去除 point-level loss 84.8，均低于完整模型 87.8。
  • 监督信号对比：动态 3D flow（87.8%）优于静态 3D 点云（85.0%）与 2D 光流 CoTracker（84.5%），基线为 80.4%。
