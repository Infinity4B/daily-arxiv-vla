Card 03 核心贡献

核心贡献

  • 提出 VLA-Retain 配对基准，按七个扰动维度分离目标增益与非目标保留，并定义目标增益、平均非目标增益、最差非目标增益和 episode 加权整体增益四类指标。
  • 实证发现目标视觉微调并非局部：10 个模型–域配置中 8 个平均非目标增益为负，语言与物体布局维度在 9/10 配置中下降。
  • 证明非目标回归不能仅由源域遗忘解释；扣除原始 LIBERO 任务变化后，每个 Camera-view 微调模型和 4/5 个 Sensor-noise 微调模型仍然至少在一个非目标维度上退化。
  • 证明更广泛的训练覆盖提升整体增益但不能消除维度级回归；Mixed 训练下所有模型整体增益更高，但每个模型仍然至少在一个维度上下降。
  • 系统比较调优范围、WiSE-FT 权重插值和 DELTA-style 特征保持，发现调优策略具有模型依赖性：DELTA-style 对 X-VLA 显著改善，但对 OpenVLA-OFT 严重恶化。
Card 04 方法描述

方法描述

  • 将 VLA 分解为视觉模块 \(f_\theta\)（视觉骨干 + 连接器）与下游模块 \(g_\phi\)，目标视觉微调仅更新 \(\theta\) 而冻结 \(\phi\)。
  • 定义配对变化向量 \(\Delta_{m,c,d}=S^{tuned}_{m,c,d}-S^{base}_{m,d}\)（百分比点），通过目标、平均非目标、最差非目标、episode 加权整体增益四种指标总结。
  • 默认采用 Dual LoRA：对视觉骨干和连接器应用 rank-32 LoRA，冻结多模态骨干与动作模块；保持各模型官方学习率调度与归一化。
  • 采用四类控制：原始 LIBERO 对照、配对 cluster bootstrap 置信区间、检查点与训练种子分析；训练数据覆盖与调优策略作为变量。
  • 策略变体包括 backbone-only / connector-only LoRA、WiSE-FT 权重插值（\(\alpha=0.75\)）和 DELTA-style 特征保持正则。
Card 05 数据集与资源

数据集与资源

  • 使用 LIBERO-Plus 训练子集（Camera-view、Sensor-noise）和完整 Mixed 训练集，以及独立评估集 10,030 个 episode，覆盖七个扰动维度。
  • 五个开源 VLA 模型：OpenVLA-OFT、π₀.₅、InternVLA-A1.5、NORA-1.5、X-VLA；视觉模块参数占比从 10.64% 到 41.26%。
  • 训练配置：AdamW、BF16、有效 batch size 32、12,000 优化步；LoRA rank 32、\(\alpha=16\)、dropout 0；具体 GPU 数量未在提供文本中明确列出。
  • 仿真与评估环境：LIBERO simulator、robosuite 1.4.1、MuJoCo、vla-evaluation-harness。
Card 06 评估与结果

评估与结果

  • 评估指标采用百分比点变化（pp）：target gain、mean off-target gain、worst off-target gain、episode-weighted overall gain。
  • Camera-view 微调代表性结果：X-VLA 目标 +69.4、非目标均值 -4.6、最差 -10.7、整体 +7.0；OpenVLA-OFT 目标 +39.3、非目标 +1.4、最差 -2.8、整体 +7.5；NORA-1.5 目标 +28.7、非目标 -10.1、整体 -3.7。
  • Sensor-noise 微调中仍有 4/5 模型平均非目标增益为负；InternVLA-A1.5 在两种目标域下整体增益均为负。
  • 95% cluster bootstrap 置信区间显示：Camera-view 下 NORA-1.5 非目标收益 [-13.9, -6.7]、X-VLA [-7.4, -2.1]、OpenVLA-OFT [+0.2, +2.8]。
  • DELTA-style 使 X-VLA 非目标均值从 -4.6 升至 +1.2，整体从 +7.0 升至 +10.9；但使 OpenVLA-OFT 非目标从 +1.4 降至 -23.1，整体降至 -16.6。
  • WiSE-FT 权重插值在降低目标增益的同时改善保留：X-VLA 目标 +69.4→+59.8，非目标 -4.6→0.0，整体 +7.0→+9.4。
  • Mixed 训练对五个模型的整体增益均高于任一目标特定设置（最高 X-VLA +13.6），但每个模型仍然至少在一个维度上退化。
