Card 02 论文概述

论文概述

  • 论文提出 MHWA（Multi-timescale Hierarchical World-Action Model），面向 tokenized 自回归世界模型中开环 rollout 误差累积和漂移问题。
  • 现有分层世界模型可引入概念干扰和结构干扰，且不一定稳定优于平面基线；论文旨在用结构归纳偏置而非单纯扩大参数来提升 rollout 稳定性。
  • 在离线多游戏 Atari 基准上验证 MHWA 能以更小参数和更少 FLOPs 达到或超过更大基线。
Card 03 核心贡献

核心贡献

  • 提出干扰感知的分层世界-动作模型 MHWA，通过慢上下文通道与原生分辨率局部动态解耦，减少 compounding errors。
  • 设计 High-Level Manager：用 stride 下采样序列和 skip-step 预测目标学习慢变上下文，并用 stop-gradient 隔离低层梯度，缓解概念干扰。
  • 设计 Low-Level Worker：用稀疏 MoE 替换单体 FFN，门控同时条件于高层上下文和当前 token 状态，缓解结构干扰并实现模式感知与局部反应式路由。
  • 在 14-game Atari 10% 离线数据上，MHWA-77M 的 IQM HNS 达 0.884，优于匹配 JOWA-70M（0.529），与 JOWA-150M（0.833）数值相当，且参数量约一半、每序列训练 FLOPs 少 70.88%。
  • 通过开环预测、消融和 PCA 表示可视化验证结构归纳偏置带来的稳定性、模块化和跨游戏可解释性。
Card 04 方法描述

方法描述

  • 基于 VQ-VAE tokenizer 将观测编码为离散视觉 token，并与动作 token 交错形成自回归序列；保留任务嵌入和世界模型头 p_o, p_r, p_d 及 Q 头 h_Q。
  • High-Level Manager 对交错序列做 stride k=4 下采样，用 causal Transformer 推断慢变全局上下文 z^ctx，并以 skip-step 观测 token 预测损失 L_high 训练。
  • 高层上下文经 Context Projector 广播给低层，并在 k 个原子步内保持不变；stop-gradient 置于 manager 与 projector 之间，阻断低层损失对高层上下文的反传。
  • Low-Level Worker 在原子时间尺度运行，将 Transformer FFN 子层替换为稀疏 MoE；门控输入为当前 token 表示与广播上下文的拼接，采用 N=4 专家、Top-2 路由。
  • 训练目标为 L_total = L_base + L_critic + λ_h L_high + λ_a L_aux；L_base 预测下一观测、奖励和终止，L_critic 使用 TD 与 CQL，L_aux 为专家负载均衡 KL 正则。
  • 关键创新是跨层 stop-gradient 的慢上下文学习与上下文感知 MoE 路由的集成，分别针对概念干扰和结构干扰。
Card 05 数据集与资源

数据集与资源

  • 使用 RL Unplugged 的 rlu-atari 数据集替代不可公开的 DQN Replay Dataset，选取 14 款 Atari 游戏，按 easy/medium/hard 难度分布。
  • 每款游戏约 10M transitions（含 frame stacking），即 10% 子采样；沿用 2/5 训练 run。
  • MHWA 总参数量 77.27M，每前向激活 60.49M；使用 K=36 visual tokens/frame、L=8 帧上下文、k=4 manager stride。
  • 训练资源：2× NVIDIA A40 GPU，AdamW，学习率 1e-4，batch size 1024，0.875M gradient steps，总计 21.6 GPU-days。
  • 对比计算：MHWA 48.199 GFLOPs/sequence，少于 JOWA-70M 的 84.238 和 JOWA-150M 的 165.524。
  • 消融实验使用 44M 参数变体和 6-game 子集。
Card 06 评估与结果

评估与结果

  • 评估基准：14-game Atari 离线数据集，10% 低数据协议；采用 RLiable 的 seed-by-game 聚合和 IQM/Median HNS，以及 open-loop 重建指标 MSE/PSNR/SSIM。
  • 主结果：MHWA-77M 取得 IQM HNS 0.884，95% CI [0.736, 1.031]，优于匹配 JOWA-70M 的 0.529，与 JOWA-150M 的 0.833 数值相当。
  • 效率：MHWA 参数量约 77M，约为 JOWA-150M 的一半，每训练序列 FLOPs 少 70.88%，训练计算更省。
  • 开环动力学：在 t=5…8 rollout 中，MHWA 比 JOWA-70M 更稳定，MSE/SSIM 匹配或超过 JOWA-150M；更长 t=5…54 诊断也保持竞争力。
  • 消融：去掉 stride k=1 导致最大 IQM 下降 62.1%；去掉 state routing、manager、MoE、L_aux、L_high 分别下降约 36.3%、21.1%、20.2%、21.3%、10.8%；stop-gradient 和 4 专家 Top-2 配置有效。
  • 迁移：在 5 款未见 Atari 游戏微调中，MHWA 取得 0.643±0.007 IQM DNS，接近 JOWA-150M（0.647），高于 JOWA-70M（0.603）。
  • 可解释性：PCA 专家激活显示 Assault 与 Phoenix 在完整 MHWA 中共享相似专家组合，去掉高层监督或时间 stride 后该结构消失。
