02论文概述

  • 提出 Leap-VLA，解决现有 VLA 模型在每个控制步都重跑多亿参数 VLM 导致的算力浪费与控制频率受限问题
  • 核心思路是将语义理解（低频 VLM 语义锚点，缓存可复用上下文）与反应式控制（高频 flow-matching 动作专家）解耦
  • 通过可测缓存年龄条件、快速视觉流注入、staleness-aware 训练与 chunk 边界校正，在显著降低 VLM 调用频率的同时保持高成功率

03核心贡献

  • 提出 非对称频率 VLA 架构，在保留共享注意力 VLA 逐层语义耦合的前提下复用语义缓存
  • 提出 staleness-aware cache reuse：测量年龄条件 + 物理时钟 staleness 分布训练 + 部署同态像素损坏课程，使 LIBERO-Spatial 在语义刷新 2s 下从 61.4% 恢复到 95.5%
  • 提出 统一多模态注入接口：快速视觉流以可插拔 token-block 进入专家，配合机器人视频预训练（重建 + 光流 + 深度）获得运动与几何感知的冻结编码器
  • 提出 soft-nudge 前向 chunk 边界校正，无需反向传播即可匹配 autograd RTC 引导，使逐控制步重规划达到 97.1%
  • 构建 指令-场景一致性研究：零成本负样本训练的 CoT verdict gate 在指令与场景不匹配时冻结执行，且不损害可行任务成功率

04方法描述

  • 慢系统：Qwen2.5-VL-2B VLM 低频运行，缓存上下文；机器人状态不写入 prompt，避免缓存副本随运动立即失效；CoT 监督仅塑造 anchor 表示，不进入动作路径
  • 快系统：flow-matching 动作专家高频运行，通过 AdaRMS 接收 flow time 与测量 cache age τ；proprioception 作为独立 token 输入；视觉流采用双帧图像 token 序列拼接，其他流通过零初始化门控交叉注意力注入
  • 快速视觉流预训练：约 23M 参数编码器，双帧 early fusion，~49% 行/列 strip mask；三个共享解码器分别做重建、WAFT 光流、Depth Anything V2 深度预测
  • staleness-aware 训练：从真实 episode 历史采样 Δ ∈ [0, Δmax]，使用有效年龄 g(τ)=log(1+τ) 进行零初始化投影条件；对 stale 快照施加随年龄递增的矩形像素擦除
  • soft-nudge：前向更新 x_{t+δ} = x̂₁ + η w ⊙ (ℓ − x̂₁)，以恒等代替 RTC 引导中的 Jacobian 转置，省去反向传播

05数据集与资源

  • 评估数据集：LIBERO 四套件（Goal、Spatial、Object、Long）、LIBERO-plus、LIBERO-PRO 扰动基准
  • 真实机器人：四平台共 7 个任务，每任务 50 次试验；平台包括 Realman、Galaxea 双机械臂工作站、Dobot Atom 移动双臂人形、自研人形上半身
  • 快速编码器预训练数据：62 个机器人数据集，约 319k episodes、约 73M 帧；含 9 个多相机套件（约 63.5k episodes / 45M 帧）与 53 个公开 OXE 源（约 256k episodes / 28M 帧）
  • 模型规模：慢系统 Qwen2.5-VL-2B；快速视觉编码器约 23M 参数；动作专家为 1536 维、32 块 Transformer，动作 chunk 长度 H=20，4 次 Euler step，每相机 196 个 token（224²/patch-16）
  • 训练资源：论文未具体列出 GPU/TPU 型号与数量；推理在异步部署栈上运行，soft-nudge 支持 TensorRT/NPU 导出

06评估与结果

  • 评估环境：LIBERO 四套件、LIBERO-plus、LIBERO-PRO 及四平台真实机器人；部署线使用 50ms 控制周期、默认每 0.5s 重规划、语义刷新取 0.5s/1s/2s
  • 主要评估指标：任务成功率（%）为主，辅以 chunk 边界位移、峰值边界位移、动作 RMS 与路径长度
  • LIBERO 四套件：Leap-VLA 平均成功率 96.3%（Goal 97.2 / Spatial 97.5 / Object 98.0 / Long 92.4），在异步栈匹配频率点测得
  • 语义刷新降频：四套件平均从 0.5s 的 96.3% 降至 1s 的 95.2%、2s 的 94.5%；LIBERO-Spatial 从 97.5% 降至 95.9%（1s）与 95.5%（2s）
  • Staleness 消融：频率匹配参考在 2s 刷新下崩溃至 61.4%；异步曝光恢复至 91.8%，加入测量年龄条件至 92.9%，加入 stale-frame masking 后达到 95.5%
  • soft-nudge 结果：在 0.05s 逐控制步重规划下，异步训练 + soft-nudge 达到 97.1%；边界/内部位移比从 1.907 降至 1.035 ± 0.186，峰值边界位移从 0.281 降至 0.181
