Card 03 核心贡献

核心贡献

  • 物理接地的结构化规划目标：提出自动化数据整理流水线，从机器人本体的运动学线索（夹爪状态切换、运动学转向点）自动提取结构化帧，无需人工语义标注，提供稀疏且具有物理意义的进度锚点
  • 统一的StructVLA框架：设计两阶段训练范式，第一阶段训练世界模型自回归预测结构化帧作为视觉规划目标，第二阶段在共享的离散词表中将结构化规划能力迁移到低层动作生成，桥接高层视觉规划与低层运动控制
  • 强实证性能：在SimplerEnv-WidowX上取得75.0%平均任务成功率，LIBERO上取得94.8%平均任务成功率，真实世界部署中在基础抓取放置和复杂长程任务上均表现出可靠的完成度和强泛化性
Card 04 方法描述

方法描述

  • 采用物理接地的自动化数据整理流水线提取结构化帧：首先从原始机器人轨迹中基于两类核心运动学线索筛选候选帧：一是夹爪状态切换对应的接触状态变化帧（通过EMA平滑速度、自适应阈值筛选稳定状态）；二是运动方向切换前的运动学转向点（通过滑动窗口+低速阈值筛选低速稳定帧）；再通过动作L2变化最小的帧补充时间覆盖，最后用VLM（GPT-5.2）离线过滤冗余/任务无关帧，仅离线使用时调用，推理阶段无额外开销
  • 设计两阶段统一训练范式，采用共享离散词表（Emu3 VQ分词器统一视觉、语言、动作的token空间）：

1. 第一阶段（结构化规划器训练）：以语言指令和视觉上下文窗口为条件，自回归预测下一个结构化帧的离散token，仅对视觉token计算交叉熵损失，通过滑动窗口增强时间监督，采用LoRA（秩32）高效适配预训练世界模型权重，降低计算开销

2. 第二阶段（动作策略迁移）：将训练好的规划器直接转换为动作策略，输入为语言指令与交替排列的视觉、动作token序列，仅对动作token计算交叉熵损失，实现从视觉规划到低层动作生成的直接迁移

  • 核心创新：用机器人本体运动学线索替代人工语义标注生成结构化子目标，同时解决密集预测的误差累积和语义规划的物理对齐不足问题；两阶段在共享词表内完成，保证视觉规划与动作生成的模态一致性
Card 05 数据集与资源

数据集与资源

  • 使用的数据集：仿真训练采用BridgeData V2（SimplerEnv场景）、LIBERO四套任务数据集（Spatial/Object/Goal/Long共40个任务，每任务50条专家演示，联合训练）；真实世界采用自采集的4个抓取放置任务数据集（每任务288条轨迹，共1152条）和长程整理任务数据集（648条轨迹）
  • 模型规模：基于UniVLA的世界模型初始化，采用纯自回归Transformer架构，参数量8.5B；视觉特征采用Emu3 VQ分词器，空间压缩因子为8；动作采用FAST分词器离散化，词表大小1024，动作token映射到语言词表的最后1024个ID，视觉、语言、动作共享单一离散词表
  • 训练资源：采用LoRA（秩32）进行参数高效微调，降低计算开销；SimplerEnv场景下Stage1训练30K步（batch size 32）、Stage2训练20K步（batch size 128）；LIBERO场景下Stage1训练10K步（batch size 32）、Stage2训练4K步（batch size 196）；真实世界场景下Stage1和Stage2各训练2K步（batch size 32）
Card 06 评估与结果

评估与结果

  • 评估环境和基准：仿真评估采用SimplerEnv-WidowX基准（评估分布偏移下的策略迁移泛化性，涵盖光照、纹理、相机位点变化）、LIBERO四套任务基准（评估多任务学习与长程操作一致性，基于Franka Emika Panda机械臂）；真实世界评估采用Franka机械臂，覆盖基础抓取放置、长程整理任务，以及零样本泛化（未见颜色/几何物体）、动态扰动（人类干预）场景
  • 主要评估指标：任务成功率（%）、抓取成功率、抓取到任务完成的转化率、训练步数效率、不同历史上下文长度下的性能表现
  • 关键实验结果：

- SimplerEnv-WidowX基准上平均任务成功率为75.0%，超过所有对比基线（如UniVLA为69.8%，VideoVLA为53.1%），在需要持续进度跟踪和精确空间执行的Stack Green on Yellow Block任务上表现突出

- LIBERO基准上平均任务成功率为94.8%，在LIBERO-Long长程任务 suite 上优势显著（优于DreamVLA的92.6%、UniVLA的93.7%），多任务泛化性优异

- 真实世界基础抓取放置任务平均成功率为87.5%，较UniVLA提升20%，长程整理任务完成8/10次试验，远高于UniVLA的4/10和SpatialVLA的2/10

- 泛化与鲁棒性：零样本泛化到未见颜色/几何的抓取任务成功率达80%（UniVLA仅30%），长程任务 unseen objects 下成功率为70%；动态人类干预场景下成功率达80%（UniVLA为40%）

- 效率分析：仅需10K训练步（batch size 128）即可达到66.7%的SimplerEnv成功率，超过UniVLA 12K步的64.8%性能，训练效率更高；且性能随历史上下文长度增加持续提升（从2帧的70.8%升至4帧的75.0%），而UniVLA性能随上下文变长出现下降
