02论文概述

  • 提出 ActiveBridge，一种训练框架，从人类第一人称（egocentric）视频中学习主动感知先验，并通过世界-动作建模迁移到机器人操作任务。
  • 解决现有机器人基础模型忽略人类主动先验的问题：机器人被动处理给定观测，而非像人类一样主动调整视角获取缺失信息；同时，传统机器人依赖多摄像头（含腕部摄像头）与人类以头部为中心的感知方式不一致。
  • 通过联合预测未来第一人称视频与同步的头部-手腕动作轨迹，显式监督主动感知和物理交互，实现单一可动头部摄像头下的主动操作。

03核心贡献

  • 人类主动先验规模化：探索如何从第一人称视频中学习主动获取任务相关感知并指导物理交互的能力，覆盖遮挡等非结构化场景。
  • ActiveBridge 框架与主动机器人平台：显式预测头部动作以监督主动感知，并设计仅使用单个可动头部摄像头（无腕部摄像头）的机器人平台，对齐机器人感知与人类感知。
  • 最先进的性能与主动操作提升：在仿真和真实世界任务中，ActiveBridge 均优于基线，消融实验证实联合头部-手腕动作监督的有效性。

04方法描述

  • 数据引擎：从 EgoVerse 中选择 387 小时第一人称视频，使用 Qwen3-VL-8B-Instruct 生成任务指令，Depth Anything 3 估计相机轨迹作为头部姿态，HaWoR 重建手部运动得到手腕姿态，并通过首帧对齐统一到同一坐标系。
  • 人类演示构造：每个演示包含任务指令、第一人称视频序列和 21 维动作（头部、左腕、右腕的 3D 位置 + 4D 四元数）。
  • 训练目标：基于预训练世界-动作模型（如 LingBot-VA），联合优化视频预测损失和动作预测损失；动作损失包含头部动作项和手腕动作项，头部项权重为 λ，使用流匹配（flow-matching）目标；人类训练后再进行机器人后训练，以适应平台原生动作空间。
  • 机器人平台：采用 AgileX 的两个 NERO 手臂和一个 PiPER 颈部，单个 RealSense D455 相机安装在可动颈部上，无腕部摄像头，降低硬件成本和碰撞风险。

05数据集与资源

  • 人类数据集：来自 EgoVerse 的 387 小时第一人称视频，处理后形成人类演示数据集 \(\mathcal{D}_H\)。
  • 仿真基准：TAVIS-Head（含 Reachy-2 和 GR1T2 两种机器人，各 5 个主动操作任务）和 RoboTwin 2.0（50 个双手操作任务，清洁与随机化两种设置）。
  • 真实世界数据：4 个任务（茄子玩具放置、书本整理、餐桌整理、轴承装配），每个任务 64 个遥操作演示，共 256 个演示用于联合训练。
  • 模型规模与训练资源：论文未明确透露模型参数量和 GPU/TPU 具体配置，但使用预训练世界-动作模型（如 LingBot-VA）作为初始化，并进行人类训练和机器人后训练。

06评估与结果

  • 评估环境：TAVIS-Head 仿真基准（ID、空间 OOD、初始姿态 OOD 三种条件）、RoboTwin 2.0 仿真基准、真实机器人平台（无腕部摄像头）。
  • 主要指标：成功率（Success Rate）。
  • 关键实验结果：

- TAVIS-Head：ActiveBridge 在 Reachy-2 上 ID 成功率 77.1%、空间 OOD 55.9%、初始姿态 OOD 76.1%；在 GR1T2 上 ID 63.8%、空间 OOD 47.9%、初始姿态 OOD 58.1%，均优于所有基线。

- RoboTwin 2.0：clean 条件 92.3%，randomization 条件 90.5%，平均 91.40%，略高于直接适应基线（LingBot-VA）。

- 真实世界：ActiveBridge 在茄子玩具放置和书本整理任务上达到 10/10 成功，餐桌整理 3/10，轴承装配 2/10，整体优于 LingBot-VA 基线（平均成功率 62.5% vs 42.5%）。

- 消融实验：显式头部动作监督在 TAVIS-Head 所有条件下提升成功率（Reachy-2 ID 提升 2.4%，GR1T2 ID 提升 0.7%），在 RoboTwin 2.0 上平均提升 0.60%，证明联合头部-手腕监督的价值。
