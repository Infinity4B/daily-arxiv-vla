02论文概述

  • 论文针对世界动作模型对任务无关视觉扰动（如光照、纹理、背景等外观变化）过于脆弱的问题，指出传统 WAM 训练存在目标缺口：视频预测目标鼓励表征保留外观信息，而动作生成目标未显式强制对无关外观的不变性
  • 现有方法存在局限：数据增强仅独立监督每个观测，不要求扰动与正常观测产生一致的动作表征；外部表征对齐（如 DINOv3、V-JEPA 等语义编码器）无法保证跨外观的一致性
  • 提出 PICA-WAM，一种自监督训练框架，将扰动不变性建模为辅助的跨外观自对齐任务，在四个强 WAM 上验证了仿真与真实机器人的鲁棒性提升

03核心贡献

  • 提出 PICA-WAM 自监督训练框架：将扰动观测的动作表征对齐到由 EMA 教师从标称观测计算的更深、更干净的目标，无需外部编码器、额外数据和推理时计算
  • 设计配对诊断协议，追踪视觉扰动从逐层特征到执行动作的传播路径，证明仅靠数据增强在深层视频层（21–25 层）仍保留外观敏感性并泄漏至动作，而 PICA-WAM 同时降低两者
  • 在 RoboTwin 2.0 Clean-to-Random、LIBERO-Plus、EBench 和真实机器人操作上，跨四个强 WAM 骨干（含/不含具身预训练）取得一致的鲁棒性提升，同时保持分布内性能
  • 推理时丢弃教师与投影头，不改变 WAM 架构、参数量和采样流程，可应用于任何分层骨干的 WAM

04方法描述

  • 基于双流 WAM 架构：视频流由预训练视频扩散 Transformer 初始化，与动作流通过联合注意力逐层耦合，以 flow-matching 目标联合训练（L_gen = L_video + L_action）
  • 跨外观自对齐：学生（在线模型 θ）读取扰动观测，其浅层（第 m 层）动作表征经轻量 MLP 投影头 g_ψ 映射；EMA 教师 φ 读取同一任务状态的标称观测（更低噪声水平 σ−δ），提供更深层（第 n 层，n>m）的目标表征
  • 对齐损失为逐动作 token 的负余弦相似度（带 stop-gradient），总损失为 L = L_gen(z′, a) + λ·L_align
  • 对对跨越三个“间隙”：外观间隙（提供不变性信号）、噪声水平间隙与层间隙（使教师目标强于学生自身表征）
  • 仅对动作流施加对齐（消融显示优于对齐视频流或双流），通过联合注意力间接塑造视频表征；教师前向可在第 n 层提前停止以节省计算

05数据集与资源

  • 仿真基准：RoboTwin 2.0 Clean-to-Random（50 个双臂任务、每任务 50 条干净演示，100 episodes/任务）、LIBERO-Plus（10,030 个扰动任务、7 个扰动维度）、EBench（26 个任务，含移动操作与灵巧桌面操作）、LIBERO 四个套件
  • 应用的四个骨干：Fast-WAM（无具身预训练）、LingBot-VA、InternW0-Δ、OpenWAM-α（均具具身预训练）
  • 在 LIBERO 上构建三个受控 Fast-WAM 变体用于诊断：Baseline（标称片段训练）、+Aug（扰动片段训练）、PICA-WAM（+Aug 基础上加对齐项）

06评估与结果

  • 诊断协议在 LIBERO-Plus 配对观测上测量视频/动作敏感性（第 8 层）与末端执行器轨迹漂移：PICA-WAM 将未见扰动族的轨迹漂移从 Baseline 的 16.42 mm 降至 6.21 mm（降低 62%），动作敏感性从 0.486 降至 0.075
  • 层带干预显示 +Aug 在 21–25 层保留 Baseline 84% 的动作泄漏，而 PICA-WAM 降至 35%
  • RoboTwin 2.0 Clean-to-Random：基于 InternW0-Δ 的 PICA-WAM 达 74.7%（Random）/ 90.7%（Clean），平均 82.7%，为所有方法最佳；无具身预训练组中基于 Fast-WAM 的 PICA-WAM 达 63.8%（Random 从基线 1.9% 提升至 39.6%）
  • LIBERO-Plus：基于 InternW0-Δ 达 93.3%；基于 Fast-WAM 平均 85.2%（Baselines 51.5–81.3），在 Robot、Noise、Camera 等维度大幅领先
  • EBench：基于 OpenWAM-α 达 61.4%，为对比方法最佳
  • 真实机器人上视觉扰动下成功率提升，且降低视频特征对外观敏感性及其向动作的传播，包括训练中未见的扰动族
