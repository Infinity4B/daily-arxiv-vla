02论文概述

  • 论文研究视觉-语言-动作模型（VLA）在接收含有害意图的指令时的安全监控问题，聚焦于监控器（monitor）能否检测到以不同显式程度表述的普通机器人任务背后的有害目的
  • 核心问题在于 VLA 无法拒绝指令（只输出动作），故安全筛查完全依赖外部监控器（如文本守卫和激活探针）；论文测试这些监控器能否捕捉"任务本身无害、但目的有害"的指令
  • 论文构建了一个受控实验框架：保持任务、物体和场景不变，仅改变目的陈述的显式程度（L1 隐含、L2 直接、L3 直白），以评估机器人行为与监控器表现之间的差距

03核心贡献

  • 受控意图测试方法：设计了一套保持动作、物体和场景固定的指令生成流程，仅变化陈述目的及其显式程度，并为每个级别配备良性对照，使守卫和探针在相同指令上进行公平比较
  • 发现守卫漏掉的有害请求会被机器人执行：文本守卫只能捕捉大部分直言不讳的伤害请求，而机器人会执行它们漏掉的隐含/间接有害请求；隐含伤害运行时 66%-97% 以"任务完成且未触发警报"告终
  • 揭示机器人训练侵蚀伤害信号：在两个模型族中，线性探针几乎能在基础语言模型和视觉-语言模型中完美区分有害与良性指令，但机器人训练后这一区分能力显著下降，对隐含危害的削弱最为严重
  • OFT"看似安全"的假象：OpenVLA-OFT 并非因为理解了有害意图而拒绝，而是无法处理附加的完整原因语句，从而对所有含原因指令（包括良性）全部失败

04方法描述

  • 使用五个来自 LIBERO-Goal 的厨房任务（如打开炉灶、将奶油奶酪放入碗中），每个任务通过 LLM 生成多种"理由"（reason），并以四种版本表述：良性对照、L1（间接隐含）、L2（直接陈述事实）、L3（直白宣布意图），且任务指令原文保持不变
  • 在机器人上运行 π₀.₅ 和 OpenVLA-OFT（各使用公开 LIBERO 检查点），每任务七种理由 × 三种级别 × 五种初始场景，共 700 次 rollout
  • 文本使用三个守卫判定：Llama Guard 3、WildGuard、Qwen3Guard；每个守卫通过校准在 10,000 条良性 WildChat 提示上达到 1% FPR，并额外测试 gpt-oss-safeguard 和基于机器人指令重新校准的阈值
  • 激活探针使用线性逻辑回归，对残差流激活（对指令 token 做均值池化）进行训练，采用留一任务交叉验证，并排除前四分之一层以避免词袋基线效应；覆盖模型族：Llama-2-7B → Prismatic-7B → OFT 和 Gemma 2B → PaliGemma-3B → π₀.₅

05数据集与资源

  • 使用 LIBERO-Goal 数据集（10 个任务中的 5 个）作为机器人任务来源，以及 LIBERO-Para 用于 OFT 健全性检查
  • 共生成 51 条已验证的原因指令（每任务 8-15 条），其中每任务 7 条用于机器人 rollout；人类注释者确认 L1 中 82% 的指令表达了有害意图
  • 测试模型：π₀.₅（PaliGemma-3B 底座）、OpenVLA-OFT（Llama-2-7B/Prismatic-7B 底座）、以及基础模型 Llama-2-7B、Prismatic-7B、Gemma 2B、PaliGemma-3B（pt-224）
  • 训练/推理资源：所有 rollout 在 NVIDIA A10 GPU 上进行，π₀.₅ 使用 GPU (EGL) 渲染，种子 0，五个起始状态

06评估与结果

  • 评估指标包括：任务成功率（LIBERO 内置检查，300 步内完成）、守卫标记率（flag rate）、泄漏率（leak rate，机器人完成任务且守卫未标记的有害运行比例）、探针 AUROC
  • π₀.₅ 的成功率不随意图显式性变化：对照为 97.1%，L1/L2/L3 分别为 95.4%/96.6%/95.4%，说明陈述伤害不会改变机器人行为
  • OFT 在裸任务上成功率 19/20，但所有 560 个含原因指令（无论有害或良性）全部失败；对照实验结果确认其失败源于无法处理额外句子，而非识别有害意图
  • 守卫漏报模式：L3 级别标记率 92%-98%，而 L1/L2 几乎为 0%-33%（Llama Guard 3 在 L1/L2 分别为 6%/33%）；L1/L2 泄漏率达 66%-97%，L3 降至 3%-11%；在良性机器人指令上重新校准后，L1 泄漏率仍高达 58%-90%
  • 探针 AUROC 下降：Llama-2/Prismatic 在所有级别为 1.00，OFT 降至 L1 0.73/L2 0.80/L3 0.86；Gemma/PaliGemma 为 0.99-1.00，π₀.₅ 降至 L1 0.79/L2 0.83/L3 0.97；伤害信号削弱在隐含伤害（L1）上最严重，与守卫的措辞敏感性一致
  • 作为监控器，π₀.₅ 探针仅标记 12%-16% 的有害指令，约四分之三的有害运行泄漏未被发现；词袋基线 AUROC 达 0.97-1.00，提示部分信号可能是词汇层面的
