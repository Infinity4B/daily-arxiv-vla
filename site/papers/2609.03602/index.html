SV-WAM: An Efficient Surround-View World-Action Model for End-to-End Autonomous Driving

02论文概述

  • 提出 SV-WAM，一种高效的全景视图世界-动作模型，用于端到端自动驾驶，解决现有世界模型在推理时生成未来视频计算开销大且单目前视输入空间覆盖不足的问题
  • 将未来视频预测作为密集训练监督而非推理时间输出，通过以动作为中心的因果掩码实现仅动作推理，同时保留六目空间覆盖以支持变道、合流和转弯等安全关键操作
  • 引入可微的道路区域合规正则化器，惩罚车辆 footprint 接近或穿越可行驶边界，提升规划安全性和道路边界感知能力

03核心贡献

  • 提出 SV-WAM，配备以动作为中心的因果掩码，支持未来动作和全景未来视频潜变量的联合训练，同时实现仅动作推理和全六目条件输入
  • 引入可微的道路区域合规正则化器，鼓励预测轨迹保持在可行驶区域内，提高道路合规性和安全性，不增加推理成本
  • 在 NAVSIMv2 和 nuScenes 上达到SOTA性能，延迟低（342ms），具备竞争力的零样本迁移能力

04方法描述

  • 输入分词：六目视频沿宽度维度拼接后，使用冻结的 Wan2.2-TI2V-5B 3D causal VAE编码为潜变量；ego状态历史通过MLP映射为状态token；未来动作序列通过MLP tokenizer投影为动作token
  • 全景世界-动作模型：采用 flow matching 联合去噪未来动作和未来视频潜变量；核心是 action-centered causal mask，阻止动作token关注未来视频token，使视频分支可在部署时移除，实现以动作为中心的概率分解
  • 道路区域合规正则化：对车辆 footprint 的四个角点采样符号距离场，使用平滑边界惩罚和log-mean-exp聚合，计算可行驶区域合规损失，对高风险违规赋予更大权重
  • 高效仅动作推理：移除未来视频token和视频输出分支，缓存观察前缀作为key/value状态，避免未来视频去噪和解码，仅需2步推理

05数据集与资源

  • 使用 NAVSIMv2（closed-loop planning）和 nuScenes（open-loop zero-shot transfer）数据集
  • 模型基于 Wan2.2-5B DiT backbone，输入6目历史帧（H=4），预测12个未来动作token，使用12帧六目未来视频潜变量监督
  • 训练资源：16块 H800 GPU，主训练10k iterations（batch size 80, lr 1e-4），微调1k iterations（effective batch size 640, lr从1e-5衰减到1e-6），每阶段约1天

06评估与结果

  • 评估环境：NAVSIMv2 navtest split（closed-loop, human penalty enabled）和 nuScenes（open-loop zero-shot transfer，无目标域微调）
  • 主要指标：EPDMS (91.0, 无责任碰撞/道路合规/驾驶方向合规/交通灯合规/自车进度/碰撞时间/车道保持/历史舒适/扩展舒适的聚合分数)、L2 error (0.89m)、collision rate (0.16%)、latency (342ms on single NVIDIA H20)
  • 关键实验结果：在NAVSIMv2上达到91.0 EPDMS（SOTA），优于EponaV2 (88.9)和DriveLaW (88.9)；在nuScenes零样本迁移中达到0.89m平均L2误差和0.16%平均碰撞率，优于DriveVLA-W0 (1.43m, 0.77%)和PWM (3.99m, 0.36%)，与微调方法竞争
