02论文概述

  • 提出了 DualWAM，一种双系统世界动作模型（World Action Model, WAM），用于解决机器人操作中未来视觉预测计算昂贵、长动作块导致闭环响应迟钝的问题。
  • 核心思路是将世界动作生成解耦为全局规划（Global Planning）与局部细化（Local Refinement）两个互补阶段：System 2 负责低频、高噪声区间的全局轨迹规划，System 1 负责高频、低噪声区间的腕部局部细化。
  • 在 Franka 和 Galbot 机器人的零样本操作任务中，DualWAM 比最强基线平均成功率提升 4.5 个百分点，同时实现 16.6 倍关键路径加速，验证了双系统异步执行在性能和效率上的双重优势。

03核心贡献

  • 提出了双系统 WAM 架构，将全局规划和局部细化分配到共享去噪轨迹的互补阶段，兼顾全局生成一致性与高频闭环控制。
  • 在更新频率、去噪区间、视觉观测空间三个维度上对两个系统进行角色专门化：System 2 使用多视图观测、低频双向去噪；System 1 仅使用腕部观测、高频低噪声细化。
  • 设计了异步闭环执行框架，包含三 GPU CFG 并行、异步模型执行、CUDA Graph 编译、混合精度量化等系统级优化，将关键路径延迟从 2854ms 降至 63ms。
  • 发现双系统分解天然支持边缘–云部署，平均下行带宽比 AHA-WAM 降低 104.6 倍。
  • 验证了角色匹配的异构辅助数据（egocentric 视频用于 System 2，UMI 腕部演示用于 System 1）可进一步提升系统性能，成功率提升 14 个百分点。

04方法描述

  • 使用 rectified flow 作为统一噪声坐标，System 2 从 σ=1 去噪到阈值 τ，System 1 从 τ 继续去噪到 0，两者共享同一条世界-动作去噪轨迹。
  • System 2 采用双向注意力处理完整多视角世界状态 [Z^g, Z^w, A]，视野为 H₂，建立全局运动计划；System 1 为紧凑的腕部中心 WAM，仅处理 [Z^w, A] 局部窗口，视野 H₁ < H₂。
  • System 1 使用因果时序注意力，并在训练时引入随机时间偏移增广，模拟执行中全局轨迹与实际状态的对齐偏差，增强异步执行的鲁棒性。
  • 系统级优化包括：CFG 双分支跨 GPU 并行、System 1/2 完全异步执行、CUDA Graph 捕获整个 28 层生成栈、W8A8 混合精度量化、以及将 System 1 在线去噪前向次数从 4 次降为 1 次（2.27 倍端到端加速）。

05数据集与资源

  • Galbot 自采机器人语料库：43,058 个标注操作子任务，覆盖 74 个技能标签。
  • Egocentric 语料库：约 1,800 小时人类交互视频，用于训练 System 2。
  • UMI 腕部演示语料库：约 1,200 小时演示数据，用于训练 System 1。
  • 零样本评估任务：20 个未见过的真实机器人任务（10 个 Galbot G1 + 10 个 Franka FR3），按 DROID 设置。
  • 初始化模型：Cosmos3-Nano（System 2）、Cosmos3-Edge（System 1），以及 Cosmos3-Nano-Policy 用于 Franka 实验。
  • 训练资源：8 个节点，每个节点 8 张 NVIDIA H200 GPU，全局 batch size 1024，训练 10k 迭代。
  • 推理部署：3 张 NVIDIA GeForce RTX 4090 GPU。

06评估与结果

  • 零样本真实机器人操作：DualWAM 在 Franka 上成功率 54%（进度 81.6），Galbot 上成功率 45%（进度 80.6），分别超越最强基线 Cosmos3-Nano-Policy 5 和 4 个百分点，平均提升 4.5 个百分点。
  • 关键路径延迟：DualWAM 仅 63ms，对比 Cosmos3-Nano-Policy 的 1043ms，实现 16.6 倍加速；对比原单 GPU 4 步 baseline（2854ms），累计加速 45.3 倍。
  • 消融实验：仅 System 2（进度 76.6/成功率 49%）、仅 System 1（41.0/9%）；将 System 1 替换为 Action-only DiT（34.0/7%）或 Fast-WAM（47.3/14%）均明显下降，证实双系统分解和局部世界动作建模缺一不可。
  • 异步 vs 同步执行：异步执行将任务进度从 73.3 提升至 80.6，成功率从 39% 提升至 45%，延迟从 850ms 降至 63ms（13.5 倍加速）。
  • 边缘–云通信：与 AHA-WAM 相比，每次同步下行负载从 44.2MB 降至 0.423MB，平均下行带宽从 20.7MB/s 降至 0.198MB/s，104.6 倍降低；10GbE 传输上界从 36.0ms 降至 2.00ms（18.0 倍）。
  • 辅助数据效果：仅添加 egocentric 数据（SR 45%→54%）、仅添加 UMI 数据（SR 45%→51%）、两者联合（SR 45%→59%），任务进度从 80.6 提升至 89.6，最佳组合提升 14 个百分点成功率。
