ProMix: Efficient Data Mixture Optimization for Robotic Imitation via Proxy-Reference DRO

arXiv 原文 ↗ 中文翻译 ↗

提出 ProMix，一个面向机器人模仿学习的计算高效数据混合优化框架，解决异构机器人数据下 VLA 模型性能饱和的问题。

作者：Qie Sima、Wei Xue、Yike Guo

  • arXiv 2611.29873
  • 6 节精读
  • 约 8 分钟

01研究单位

  • 作者：Qie Sima、Wei Xue、Yike Guo
  • 所属机构：香港科技大学（Hong Kong University of Science and Technology）

02论文概述

  • 提出 ProMix，一个面向机器人模仿学习的计算高效数据混合优化框架，解决异构机器人数据下 VLA 模型性能饱和的问题。
  • 核心思想是用 15M 参数的 proxy 模型和冻结的 reference 模型进行分布鲁棒优化（DRO），学习每个数据域的采样权重，再将权重迁移到大模型（最高 7B），避免为权重搜索反复训练大规模策略。
  • 在 Open-X Embodiment 数据集上，ProMix 将平均成功率从均匀混合的 68.4% 提升至 76.2%，同时将混合优化成本降至与骨干规模无关的 11 GPU-hours。

03核心贡献

  • 提出 ProMix 框架，将数据混合优化成本降至固定的 11 GPU-hours，对比 Re-Mix 在 50M 规模需 16 GPU-hours、在 7B 规模需 192 GPU-hours。
  • 首次对机器人 DRO 中 reference 模型的作用进行受控分析，证明 excess-loss 目标能避免对噪声域的过度悲观，并识别出熵正则化是防止权重崩溃的必要组件。
  • 量化了跨尺度迁移性：15M proxy 学到的域权重直接迁移到 50M 和 7B VLA 模型，平均成功率提升 +7.8%，最差域成功率提升 +17.1%。
  • 公开了在 9500 个真实世界 episode 上的完整实验设置与消融结果，为资源受限实验室提供了可复现的数据优化方案。

04方法描述

  • 两阶段训练流程：第一阶段在 15M proxy 与冻结的 15M reference 之间进行 minimax 优化，学习域权重；第二阶段使用学到的权重训练最终 VLA 模型。
  • Proxy-Reference 架构：使用紧凑 VLA 模型（EfficientNet-B0 视觉编码器、T5-Base 语言编码器、6 层 Transformer 解码器），proxy 与 reference 均为 15M 可训练参数。
  • 优化目标：最小化最坏情况 excess loss（即 proxy 损失减去 reference 损失），并加入熵正则化项 \(\lambda H(\bm{p})\) 防止权重坍缩；权重更新采用指数梯度上升。
  • 训练细节：每个域每迭代独立采样 128 个样本，proxy 训练 100k 步，reference 使用均匀混合训练 100k 步后冻结，最终权重取最后 10k 步的平均。

05数据集与资源

  • 数据集：Open-X Embodiment 数据集的子集，包含 9500 个真实世界 episode，按机器人实施例和任务类型划分为 7 个域（如 pick-and-place、stacking cups、door opening 等）。
  • 模型规模：proxy/reference 模型约 15M 可训练参数；最终模型验证了 15M、50M 和 7B（使用 OpenVLA 7B checkpoint，冻结视觉/语言骨干，仅训练 decoder）三个尺度。
  • 训练资源：proxy/reference 训练使用 NVIDIA H100 GPU；混合优化总成本为 11 GPU-hours（reference 训练 3h，proxy 搜索 8h）；最终模型训练成本为 15M/2.1 GPU-hours、50M/8.0 GPU-hours（4 H100）、7B/96.0 GPU-hours（8 H100）。

06评估与结果

  • 评估环境：在对应物理机器人平台上进行封闭环真实机器人 rollout，使用 OXE 评估 split，15 个 held-out 任务，每个任务 20 次试验，报告 5 个随机种子的平均成功率与 95% 置信区间。
  • 主要指标：平均成功率（Avg. SR）和最差域成功率（Min Domain SR）。
  • 关键结果：

- ProMix 平均成功率达 76.2%，较均匀混合（68.4%）提升 +7.8%，较 Re-Mix（74.8%）高 +1.4%（在评估噪声范围内视为相当）。

- 最差域成功率从 51.4% 提升至 68.5%（+17.1%），验证了 minimax 公式对长尾域的提升作用。

- 消融实验：去掉 reference 模型导致平均成功率下降 -3.8%、最差域下降 -14.3%；去掉熵正则化导致权重熵从 1.24 降至 0.31，最差域成功率跌至 48.7%。

- 跨尺度迁移：15M proxy 学到的权重迁移到 50M 和 7B 模型，相对均匀混合分别获得 +7.3% ~ +11.4% 的持续提升。
