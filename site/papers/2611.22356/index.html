SR-VLA: Stall-Reduced VLA Execution via Predicted-Input Lookahead and Selective KV Cache Repair

02论文概述

  • 论文针对视觉-语言-动作（VLA）模型在机器人控制中因推理阻塞导致的控制停顿问题，提出 SR-VLA 框架。
  • 核心目标是在保持任务成功率的同时，通过预测输入前瞻和选择性 KV 缓存修复减少 VLA 推理带来的停顿延迟。
  • 现有异步推理虽然能隐藏部分延迟，但与实际输入不一致的风险会导致动作失配；SR-VLA 在预测输入基础上引入修复机制，兼顾速度与准确性。

03核心贡献

  • 提出动作条件化的下一决策边界输入预测器，同时预测未来的视觉观测和本体感受状态，并用冻结 VLA 预计算投机性 KV 缓存与动作块。
  • 设计实际输入引导的两级缓存重用机制：先通过观察驱动门和任务保护门决定是否修复，再根据预测-实际差异和任务相关性选择需要更新的 KV 条目。
  • 在LIBERO 基准上，与同步 π0.5 和 OpenVLA-OFT 基线相比，分别实现 2.67× 和 1.27× 的查询加速，且成功率保持竞争力。
  • 在目标运动扰动场景下，SR-VLA 保持与同步基线相当的成功率，同时仍获得 1.52×–1.93× 的查询加速。

04方法描述

  • 预测输入前瞻：轻量级预测器（约 10.08M 参数）利用当前观测、本体感受状态和已执行动作块，通过 U-Net 图像分支和 MLP 状态分支预测下一决策边界的图像和状态；使用 FiLM 调制将动作/状态信息融入图像分支。
  • 投机 KV 缓存与动作生成：将预测输入送入冻结的 VLA，预计算所有层的 KV 缓存和下一动作块。
  • 两级选择性修复：实际输入到达后，计算预测-实际图像 token 的余弦误差和本体感受 RMSE，结合任务相关注意力权重形成风险分数；若触发修复，则用 TopK 误差和 TopRatio 风险选择部分视觉 token 进行 KV 更新，其余 token 复用投机缓存，最终重新生成动作。

05数据集与资源

  • 使用 LIBERO 基准的四个子套件：Spatial、Object、Goal、Long。
  • 骨干模型为冻结的 π0.5（动作块长度 K=5）和 OpenVLA-OFT（动作块长度 K=8）。
  • 预测器在 13622 个样本上训练 100k 步，优化器为 AdamW（batch size 8，学习率 1e-4，权重衰减 1e-4），验证集 960 个样本。
  • 预测器参数量 10.08M，单次推理算力 51.52 GFLOPs。
  • 所有实验在 40GB A100 GPU 上完成。

06评估与结果

  • 评估环境：LIBERO 四个子套件，机器人为 30Hz 动作频率，A100 GPU 上测量端到端延迟。
  • 主要指标：任务成功率、查询/动作延迟（ms）、停顿均值（ms）、残差停顿（相对于同步 π0.5 的归一化值）、查询加速比。
  • SR-VLA (π0.5)：平均成功率 96.9%，查询/动作延迟 9.59 ms，停顿均值 47.95 ms，残差停顿 0.37，加速 2.67×（同步 π0.5 基线：成功率 96.4%，延迟 25.62 ms，停顿 128.11 ms）。
  • SR-VLA (OpenVLA-OFT)：平均成功率 97.2%，查询/动作延迟 13.27 ms，停顿均值 106.19 ms，残差停顿 0.83，加速 1.93×（同步 OFT 基线：成功率 97.1%，延迟 16.90 ms，停顿 135.18 ms）。
  • 目标运动扰动：在 LIBERO-Spatial 上，目标位移 5 cm 时，SR-VLA (π0.5) 查询加速 1.52×，成功率与同步基线相当，修复率随扰动幅度上升。
  • 消融实验：移除预测器的 FiLM、动作条件或本体感受分支均导致成功率显著下降；两级修复策略（输入驱动门、任务保护门、TopK 误差选择、TopRatio 风险选择）缺一不可，完整策略修复率 31.68%、更新 KV 比例 27.37% 时成功率与同步基线持平。
