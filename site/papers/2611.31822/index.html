G0.7: Scaling Up a Fast World Action Model with Long Context

02论文概述

  • 论文提出了 G0.7，一个通用世界行动模型（WAM），将 Fast-WAM 范式扩展到最长五分钟的上下文窗口，并大规模预训练在机器人遥操作与人类自我中心视频上
  • 解决现有 WAM 的三大局限：推理必须先生成未来视频导致延迟过高、仅依赖少量近期帧导致长时程记忆与上下文学习不足、公开预训练语料规模有限导致泛化能力弱
  • 目标是构建兼具物理常识、低延迟闭环反应性与长时程记忆的通用机器人操作策略

03核心贡献

  • 原生长上下文自回归建模：支持多达五分钟的历史观测，通过滑动窗口 KV 缓存实现，无需辅助记忆模块；支持视频上下文学习（ICL），可跟随人类演示视频完成任务
  • 双模式快速推理：同一检查点同时支持 IDM（先想象再行动）和 Fast（直接动作解码）模式；Fast 模式在单张 RTX 5090 上仅需 60 ms 解码一个 16 步动作块，比 IDM 快 7.6 倍，并支持无停顿实时分块
  • 大规模多源预训练：结合机器人遥操作数据和人类自我中心视频，将人手 3D 轨迹映射到统一末端执行器动作表示；采用三层语言标注提升指令跟随粒度
  • 全面的实验评估：在五个仿真基准、零样本真实机器人、上下文学习、真实世界后训练等场景中均显著优于 OpenWAM、G0.5、π0.5、Dream-1、Long-WAM 等基线
  • 数据缩放分析：证明机器人数据提升分布内性能，而人类自我中心视频对分布外泛化（零样本部署与 OOD ICL）贡献最大

04方法描述

  • G0.7 采用标准的双专家世界动作模型架构：语言专家编码任务指令与视觉上下文，视觉/动作专家处理因果视频 VAE 潜变量、本体状态与 16 步动作块（4:1 动作-视频频率比）
  • 长上下文建模：从头预训练就使用多块自回归序列，可变序列长度 K，随机位置偏移以泛化到更长 rollout；注意力在干净视频潜变量的滑动窗口 KV 缓存上操作，下游可无缝扩展上下文窗口
  • 快速路径训练：采用随机注意力掩码，动作 token 随机地要么关注未来视频潜变量（IDM 路径），要么仅关注历史观测（Fast 路径）；推理时 Fast 模式跳过视频生成，直接用五步流匹配去噪动作块
  • 数据管线：机器人轨迹采用三层语言标注（复杂指令、复合子目标、原子标签），过滤断续轨迹；人类自我中心视频通过 3D 手部姿态提取，将手腕 6-DoF 姿态对齐到 R1 夹爪 TCP 约定，并输出五指指尖位置
  • 与实时分块（RTC）无缝集成：Fast 模式推理时异步去噪下一块动作，实现连续无暂停运动

05数据集与资源

  • 机器人遥操作数据：Galaxea R1 Pro 与 R1 Lite 机队数据、DROID、RoboMIND、BridgeData V2
  • 人类自我中心视频：头戴摄像头采集的日常手工操作视频，包含大量第一人称操作与物体交互
  • 模型规模与参数量：论文未明确披露参数量；架构为双专家设计，包含语言专家和视觉/动作专家
  • 训练资源：推理在单张 RTX 5090 上进行，FP8 部署下 Fast 模式 60 ms/块；训练使用 BF16 与 FP8 混合精度，未公开具体 GPU 数量与训练时长
  • 预训练检查点：对比了 G0.7-20%（约 20% 机器人数据）、G0.7-Robot（全量机器人数据，无 ego）、G0.7（全量机器人 + 人类 ego）三种数据规模

06评估与结果

  • 仿真基准：在 LIBERO（含三个鲁棒性套件）、RoboTwin 2.0、VLABench、RMBench、RoboDojo 五个套件上后训练并评估，G0.7 平均得分 70.8，远高于 OpenWAM (43.9)、G0.5 (39.2)、π0.5 (33.9)
  • 零样本真实机器人：Galaxea R1 Pro 上 25 次试验成功 48%，R1 Lite 上 50 次试验成功 54%，显著优于 G0.5 和 Dream-1；人类 ego 数据使 R1 Lite 零样本成功率从 12% 跃升至 54%
  • 上下文学习（ICL）：在 shell game 任务上 ID 93.3% / OOD 80.0%，在 sorting by example 上 ID 93.3% / OOD 66.7%；经 ICL 中期训练后，平均 ID 96.7% / OOD 93.3%，显著优于 Long-WAM、G0.5、π0.5
  • 真实世界后训练：七个任务平均任务进度 86.9%，优于 G0.5 (64.3%)、π0.5 (41.7%)、OpenWAM (18.6%)；长时程生产任务（折叠运输箱、制作柠檬茶、产品装袋）成功率高，其中柠檬茶达 100%；工具使用任务平均进度 82%
  • 数据缩放：性能随预训练数据量持续提升，仿真平均分从 56.2（20% 数据）升至 70.8（全量），零样本和 OOD ICL 提升尤其明显，验证了人类 ego 视频对分布外泛化的关键作用
