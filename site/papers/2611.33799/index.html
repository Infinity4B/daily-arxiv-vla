02论文概述

  • 论文提出 CompactWAM 框架，研究世界动作模型（WAM）中的稀疏动态表示学习，用少量紧凑动态 token 表示预期变化，保留当前观测作为上下文锚点
  • 针对密集未来建模重复编码静态上下文、推理开销大的问题，探索在视频监督共享骨干中学习动作相关的稀疏预测表示
  • 核心挑战是在有限 token 预算下引导稀疏表示捕获既具有动态保真度又具有动作相关性的预期动态

03核心贡献

  • 开发 CompactWAM 稀疏-稠密联合预测框架，在视频监督共享骨干中实现稀疏表示学习，推理时仅需一次视觉前向传播编码当前观测和紧凑动态 token
  • 提出 Dynamic Forcing 学习策略，结合直接动作监督与特权密集未来引导，通过动作功能引导（FG）和动态感知分布匹配（DA）传递密集预测知识
  • 在 LIBERO、LIBERO-Plus、RoboTwin 2.0 和真实世界操作任务上验证了方法的有效性，在仅使用 9.2% 密集未来 token 预算下保持 98.3% 和 76.6% 的成功率

04方法描述

  • 稀疏-稠密联合预测框架：密集通路接受视频和动作监督，提供共享预测学习基础；稀疏通路通过动作监督学习紧凑预测表示，无需自身的视频重建目标
  • 紧凑动态 token 初始化：从当前观测的区域池化初始化动态 token，并赋予稀疏 3D-RoPE 坐标以保持时空组织
  • 动作功能引导：在动作专家的注意力读出空间中匹配稀疏与密集上下文的孤立贡献，使稀疏 token 保留密集未来对动作生成的功能影响
  • 动态感知分布匹配：构造关系增益分布，对齐稀疏与密集表示中相对于静态参考的时序关系变化，显式传递时间动态结构
  • 联合训练与推理：采用流匹配目标训练视频通路和两个动作专家，推理时仅使用稀疏通路，缓存视觉特征以加速动作去噪

05数据集与资源

  • 使用数据集：LIBERO（Spatial、Object、Goal、Long 四个套件共 40 个任务）、LIBERO-Plus（7 类扰动评估）、RoboTwin 2.0（50 个双臂任务）、真实机器人操作任务
  • 模型骨干：Wan2.2-TI2V-5B 作为视觉骨干，动作专家由兼容骨干权重初始化，VAE 和文本编码器冻结
  • 训练资源：在 8 块 NVIDIA H20 GPU 上训练，使用 AdamW 优化器，学习率 1e-4，权重衰减 1e-2，批大小 16，bfloat16 精度

06评估与结果

  • 评估环境：LIBERO 约 2000 次评估试验，RoboTwin 2.0 每个任务 100 次试验，LIBERO-Plus 跨 7 类扰动泛化测试
  • 主要指标：任务成功率
  • 关键实验结果：

- LIBERO 平均成功率 98.4%，LIBERO-Plus 平均成功率 77.9%

- 使用仅 18.4% 的预测视觉 token 即达到上述性能，进一步降至 9.2% token 预算时仍保持 98.3% 和 76.6% 的成功率

- RoboTwin 2.0 平均成功率 53.0%，在随机化场景中达到 23.2%，优于其他 WAM 方法

- 真实世界操作任务中，在分布内和分布外条件下均展现出较强的控制鲁棒性
