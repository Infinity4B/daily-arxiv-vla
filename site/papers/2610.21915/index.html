02论文概述

  • 论文研究视觉-语言-动作（VLA）策略的训练监督目标分配问题：在固定训练预算下，机器人策略究竟应该学会预测什么。
  • 传统做法以直接动作预测为主导目标，将潜在动作（LA）和未来视觉（FV）预测作为辅助目标；但二者共享同一训练预算，存在竞争关系。
  • 论文追问：把相当比例的训练样本分配给 LA/FV 而非进一步的动作预测，能否反而提升动作执行性能。

03核心贡献

  • 重新审视直接动作预测在 VLA 训练中的主导地位，系统研究将监督分配给 LA 与 FV 对策略学习的影响。
  • 提出统一的 VLA 训练框架，包含样本级训练路由器（sample-level router），在固定训练预算下显式控制动作监督与辅助监督的分配比例，从而支持多个 LA 与 FV 目标的可控对比。
  • 在 LIBERO、CALVIN 及四个真实机器人操作任务上进行大量实验，并结合表征探针与注意力分析，得出关于动作监督分配、LA 与 FV 性能差异及其表征特性的系统性结论。
  • 发现合适的 LA/FV 监督在同等预算下可超越纯动作训练（即使动作预测只占一半或更少样本）；FV 总体优于 LA，而最强的 LA 配置在 CALVIN 上仍具竞争力。

04方法描述

  • VLM 条件编码：使用预训练的 MiniCPM-V-4.6 编码当前视觉观测与语言指令，取最后隐状态，通过交叉注意力条件化两条专家流；机器人状态单独条件化动作专家。
  • 双流 MMDiT 预测头：由动作专家和辅助专家组成，二者使用独立的输入投影与前馈网络，并通过联合自注意力（joint self-attention）交换信息。
  • 样本级训练路由器：每个训练样本按伯努利分布 r_i ~ Bernoulli(p_A) 独立路由到动作损失或选定的 LA/FV 损失，每个样本只贡献单一损失；p_A = 0.25/0.50/0.75/1.00 分别记为 P25/P50/P75/P100。
  • LA 目标：用三种编码器 {LAPA, LAPA-DINOv2, LAPA-DINOv3} 将视觉转移编码为离散 token（含 K 个码本索引），策略预测展平为 H·K 个位置的 token 序列，用交叉熵损失监督。
  • FV 目标：用三种编码器 {DINOv3, V-JEPA 2, Wan2.2 VAE} 编码当前与未来观测为连续表征，以流匹配（flow matching）预测未来表征的流速度，FV 路由样本以干净示教动作作为条件。
  • 源匹配对照（source-matched control）：每个 FV 配置的 P100 版本保留相同编码器、MMDiT 输入、双流架构与训练设置，但所有样本走动作路由，使 FV 损失从不激活。
  • 推理时：仅使用与动作路由训练样本相同的计算路径，不提供未来观测或辅助目标，只解码并执行动作专家输出。

05数据集与资源

  • 仿真基准：LIBERO（Spatial / Object / Goal / Long 四个套件）、CALVIN（ABC→D 设置）。
  • 真实机器人：四个真机操作任务，涉及篮子取放与杯/物体重排，按完成进度评分。
  • 诊断数据：AgiBotWorld-Beta（双臂真机数据集）未见过任务，以及 CALVIN environment-D 验证集；采用 LARYBench 划分协议。
  • 模型规模：论文自建策略参数约 ≈2B；对比基线包括 OpenVLA（≈8B）、π0（≈3B）、UniVLA（≈7B）、π0.5（≈3B）。
  • 训练预算：LIBERO 与 CALVIN 上全预算为 60k 优化器更新，半预算为 30k；动作块长度 H = 8，FV 时间偏移 δ = 8。

06评估与结果

  • 评估环境与基准：LIBERO 报告任务成功率，CALVIN 报告平均任务链长度（Avg. Len.）与五任务成功率（SR-5），真机任务报告部分得分（每任务 20 次试验）。
  • 主要评估指标：LIBERO 平均成功率、CALVIN Avg. Len. 与 SR-5、真机任务完成度分数。
  • 动作监督并非必须占多数：在 P50 全预算下，所有三个 FV 配置在 LIBERO 上均超过全预算纯动作基线的 96.50%（Wan2.2 达 98.15%）；CALVIN 上 V-JEPA 2 达 4.451、LAPA-DINOv3 达 4.434，均超过基线 4.314。
  • 分配比例的影响呈任务依赖：CALVIN 上 V-JEPA 2 在 P25（75% 样本给 FV）达到 Avg. Len. 4.522，远超其源匹配对照的 4.091；但 LIBERO 上所有 P25 配置均低于其 P100 对照。
  • FV 总体优于 LA：LIBERO 上三个 FV 配置在平均成功率及 Spatial/Goal/Long 上全面超过三个 LA 配置；真机上每个 FV 配置在所有四个任务上均高于所有 LA 配置与纯动作基线（Wan2.2 最高），而没有任何 LA 配置超过纯动作基线。
  • CALVIN 例外：LAPA-DINOv3 在 P50 全预算下与最佳 FV 配置接近（4.434 vs. 4.451），并在 SR-5 上反超（77.0% vs. 76.0%），在 P75 上 Avg. Len. 最优（4.421）。
  • 诊断分析：三种 FV 源在 ABS（绝对位置）误差上均低于三种 LA 源；LAPA-DINO 变体在相对运动（Δc）误差上更低。特征聚类 NMI 显示 LAPA-DINO 与运动标签关联更强，FV 源与任务 ID 关联更强；LAPA-DINOv3 相关性最高（0.375）、NMSE 最低（0.807）。
  • 结论：DINO 系 LA 目标强调相对运动，FV 目标强调绝对位置与任务身份；LA/FV 监督还能重塑策略注意力，使其聚焦于任务相关物体与交互区域。
