02论文概述

  • 论文提出 WATCH（World-Action model Training from Cross-Human videos），一种仅使用人类视频的跨视频世界-动作模型预训练方法。
  • 核心问题是：标准的“视频内下一帧预测”让模型依赖同一演示中共享的外观线索，而非学习可跨场景、跨具身迁移的交互表征。
  • 目标是通过任务配对的人类-人类演示对进行跨视频联合动作-视频预测，学习具身不变的世界-动作表征，再通过机器人后训练迁移到真实机器人控制。

03核心贡献

  • 提出 WATCH 跨视频世界-动作预训练目标：以一条人类演示为参考、预测另一条演示的动作与未来帧，并构建任务匹配的人类-人类配对，无需配对的机器人演示即可引入具身与环境变化。
  • 通过表征分析证明跨视频预训练将表征从“来源特定外观”转向“任务相关的运动与交互”，表现为更强的运动对齐、跨具身检索与手-物交互注意力。
  • 在多种视频模型骨干、后训练协议和评估环境上取得一致提升，且在未见过的难度层级（L3）上增益最大。
  • 验证人类配对预训练所得表征接近机器人配对预训练的表征，支持人类演示作为可扩展的机器人预训练数据来源。
  • 展示预训练数据规模扩大带来持续性能提升，且性能优于视频内预训练与协同训练基线。

04方法描述

  • 基于 Cosmos Policy 配方，将状态与动作表示注入预训练视频模型的潜在 token 序列，采用 rectified-flow 联合速度匹配目标：视觉损失 + 动作损失（λ=48）。
  • 跨视频条件建模：给定查询窗口 q 与从其参考集 R(q) 中采样的参考窗口 r，模型预测 \(p_\theta(a^q_{t:t+C}, I^q_{t+1:t+C+1} \mid I^q_t, s^q_t, \ell, I^r_{u:u+C+1}, a^r_{u:u+C})\)。
  • 六槽位输入输出设计：当前查询帧、查询状态、参考视频、参考动作、预测未来视频、预测动作；每个 token 带槽位类型与物理时间位置编码，便于后训练时增删参考槽。
  • 配对构建：从 EgoVerse 不同 episode 构建查询-参考对，用语义任务分类法筛选候选，按运动轨迹的 DTW 距离排序；动作由后续身体构型导出并在共享人-机器人任务空间中以规范坐标系表示。
  • 后训练协议：支持 in-context（以人类演示为参考）与 context-free（移除参考槽）两种机器人后训练方式，动作表达在目标机器人的原生控制空间。

05数据集与资源

  • 预训练数据：EgoVerse 人类演示，构建 10.99M 查询-参考对，总计 10.0K 小时配对的 3 秒窗口；每个查询平均 10.52 个参考，其中 6.35 个为跨源匹配，90.7% 的查询至少有一个跨源参考。
  • 分析/评估数据：EgoVerse、RoboMIND（含三种机器人的配对机器人数据）、MimicDroid（GR1 人形，253 条训练 episode、每任务 100 条参考演示）。
  • 下游基准：MimicDroid（L1–L3，in-context 与 context-free）、TableTop-Sim（双臂 ALOHA）、RoboCasa Kitchen-H50（单臂 Franka，每任务 50 条人类演示）。
  • 骨干模型：Cosmos-Predict2.5（2B）、Cosmos3 Edge-2B；基线包括 Vid2Robot、HAND、MimicDroid、π0.5、GR00T-N1.7、MolmoAct2 等。
  • 训练资源（GPU/TPU 具体型号与数量）在提供的原文中未明确说明。

06评估与结果

  • 表征分析：对参考的敏感性上，任务变化带来的动作 MSE 增幅（0.0322→0.0367）显著大于来源变化（0.0322→0.0335）；运动检索中新方法比基线更早排到跨源/跨机器人匹配动作；跨具身回归 Spearman 相关在人类窗口达 0.18、机器人窗口达 0.24（原视频模型仅 0.06 与 0.01）。
  • 未见机器人预测：在 RoboMIND 上，动作 MSE 从视频内基线的 0.046 降至 0.039，动作精度从 55.6% 升至 68.5%；视频 FVD 从 1485.1 降至 154.9，FID 从 53.53 降至 8.33。
  • 与机器人配对训练对齐：人类训练 WATCH 与机器人训练模型的特征匹配 match@1 在人类窗口达 0.76、机器人窗口达 0.60，远高于原视频模型的 0.21 与 0.19。
  • In-context 后训练（MimicDroid L1–L3）：Cosmos Policy 平均成功率从 40.9% 提升至 68.3%（L2: 29.4%→72.5%，L3: 18.3%→40.8%）；Cosmos3 从 59.8% 提升至 77.7%（L3: 30.8%→55.0%）。
  • Context-free 后训练：MimicDroid 上 Cosmos Policy 平均从 49.3% 升至 69.0%，Cosmos3 从 49.7% 升至 63.4%；TableTop-Sim 上 Cosmos3 平均从 65.8% 升至 72.0%；RoboCasa 上 Cosmos Policy 从 56.0% 升至 63.6%。
  • 消融实验：跨视频预训练优于视频内预训练与协同训练，尤其在 L2/L3 与三个 context-free 基准上；联合动作-视频监督优于单纯动作或单纯视频监督；在 2× 速度参考下，视频内预训练收益消失而 WATCH 仍保留大部分增益；性能随配对人类数据量增加而提升。
