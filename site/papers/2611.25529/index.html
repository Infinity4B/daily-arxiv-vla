02论文概述

  • 论文提出了 CoachSI，一种仅通过语言指导实现机器人策略自改进的方法，无需人类操作员、奖励模型或测试时的 VLM。
  • 要解决的问题是：通用机器人策略在原子技能上表现可靠，但在将技能组合为长程任务时容易停滞，且仅靠策略自身收集经验难以突破其能力边界。
  • 核心发现是：策略在长程任务中停滞时，缺少的不是技能，而是“下一步该做什么”的指令；一个冻结的视觉语言模型（VLM）即可从相机图像中判断并给出该指令。

03核心贡献

  • 识别出长程操作中的一类“停滞”现象，并证明 单一的下一条指令可以在 WAM 和 VLA 两种架构上将停滞状态的子目标完成率提升 4.6 倍。
  • 提出 CoachSI 自改进框架：冻结 VLM 作为语言教练在数据收集阶段给出下一步指令，成功的受指导轨迹经事后重新标注（hindsight relabeling）后用于微调策略。
  • 证明了 CoachSI 在同等数据预算下优于人类演示微调和自收集成功轨迹微调：在 18 个长程任务中实现 59.3% 的成功率，相比预训练策略提升 11.9 个百分点。
  • 表明冻结的 VLM 从相机图像即可恢复 oracle 增益的 91%，且 CoachSI 的增益主要来自“仅有教练干预才能产生的成功轨迹”。
  • 指出在 World Action Model 中，仅更新视频骨干网络的自注意力层，动作骨干网络保持冻结，即可将受指导经验转化为策略独立完成任务的能力。

04方法描述

  • 每个复合任务预定义一组原子指令候选集 \(\mathcal{V}(g)\)，每条候选对应策略已具备的一种技能。
  • 语言教练 \(c_\phi\) 是一个冻结的现成 VLM（Qwen3.8-27B），在每个动作块边界读取相机视图和候选指令，选择第一个尚未完成的下一步指令，或返回 KEEP。
  • 教练不输出动作，所有动作均由冻结的策略自身产生，从而保证受指导轨迹中的动作来自策略已有技能。
  • 成功轨迹被 事后重新标注：将轨迹中的教练指令替换为原始任务指令 \(g\)，构建训练数据集 \(\mathcal{D}_{\mathrm{coach}}\)。
  • 微调时仅在视频损失上更新 World Action Model 的 视频骨干网络自注意力层，动作骨干网络保持冻结，使策略学会“在任务指令下预测下一步”，而非学习新动作技能。

05数据集与资源

  • 使用 RoboCasa365 基准，采用 18 个复合任务作为长程评估任务；数据收集和评估使用互不重叠的厨房场景集。
  • 研究两个公开模型：OpenWAM（World Action Model）和 Xiaomi-Robotics-1（VLA）。
  • 教练模型为 Qwen3.8-27B，在数据收集期间每个动作块被查询一次。
  • 微调设置：3,000 梯度步，batch size 16，训练样本 48,000 个，其中 80% 为 RoboCasa365 人类演示数据，20% 来自各任务的受指导成功轨迹（每任务 530 个样本）。
  • 评估使用 20 个未见场景，每任务 3 次试验，共 1,080 个评估 episode。

06评估与结果

  • 停滞状态分析：在 500 个停滞状态上，oracle 的下一步指令将子目标完成率提升 4.6 倍；冻结 VLM 仅凭相机图像恢复 oracle 增益的 91%。
  • 主要结果：CoachSI 将预训练策略在 18 个长程任务中的成功成功率从 47.4% 提升至 59.3%（+11.9 个百分点）。
  • 相比基线：人类演示微调达到 49.4%，自收集成功轨迹微调达到 51.9%；CoachSI 分别高出 9.8 和 7.3 个百分点。
  • 使用仅图像教练时 CoachSI 达到 56.8%，仍高于两个基线。
  • 消融实验：移除事后重新标注后成功率降至 51.7%，证明将轨迹重新标注为任务指令是必要组件。
  • 过程分析：在 320 步内，CoachSI 完成第一个子目标的比例为 41.5%，明显高于预训练策略（23.9%）、人类演示（24.9%）和自收集成功（28.8%）。
