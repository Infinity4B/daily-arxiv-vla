Decoupled Asynchronous System for Humanoids (DASH): Latency-Agnostic Scaling of Vision-Language-Action Models for Humanoid Manipulation

02论文概述

  • 论文提出 DASH（Decoupled Asynchronous System for Humanoids），解决视觉-语言-动作（VLA）模型在闭环控制中因推理延迟导致控制频率下降、动作滞后的问题
  • 将 VLA 策略解耦为慢速视觉语言模型（System 2）和快速 flow-matching 动作头（System 1），通过异步并发运行，使控制率仅由动作头决定，与骨干模型规模无关
  • 实现在人形机器人灵巧操作中，扩大 VLM 骨干规模的同时保持高控制频率和成功率

03核心贡献

  • DASH 异步系统：将 VLA 分成慢 VLM 和快动作头，通过 LCM 协议三进程并发（环境、VLM 服务器、动作服务器），控制率仅由动作头决定，并在真实人形机器人上部署
  • Latency-agnostic scaling：骨干模型脱离控制关键路径，从 0.8B 到 8B 保持 50ms 动作路径和 20Hz 控制率，同步则从 9.7 降至 4.1 Hz，且成功率更高
  • 跨时间尺度融合与训练 recipe：冻结 VLM 骨干 + 可训练动作头，内含 ResNet 视觉编码器提供新鲜视觉，融合缓存的 VLM 隐藏状态；去同步训练使策略适应部署时的 staleness
  • 自适应时间聚合：利用分数偏移和线性插值对齐异步推理下的重叠动作块，消除抖动

04方法描述

  • 解耦快慢系统：环境、VLM 服务器、动作服务器三进程通过 LCM（UDP 发布/订阅）通信，各进程独立速率运行（f_env ≥ f_action ≥ f_VLM），VLM 上下文在多步动作间复用
  • 动作头结构：12 层 cross-only DiT（1024 宽，8 头，4 步流匹配），查询为机器人状态嵌入和噪声动作块；cross-attention 融合来自冻结 VLM 的 stale 隐藏状态（按层映射 25/50/75/100%）与来自动作头自身 ResNet-152 的新鲜视觉 token
  • 去同步训练：训练时 VLM 输入与动作头输入来自不同时间戳（随机采样 Δ，覆盖部署 staleness 范围），使训练分布与推理一致；无需显式 staleness 输入
  • 自适应时间聚合：测量真实块到达间隔 T_k，计算分数偏移 ρ_k，整数部分移位，分数部分线性插值，并累加分数防止漂移

05数据集与资源

  • 模拟数据集：RoboTwin 50 任务套件，每任务 5 个场景种子，共 250 集评估；包含拾放、关节物体、工具使用、堆叠等
  • 真实机器人评估：24 次语言条件桌面拾放试验（日用品如可乐罐、薯片、玩具车、牛奶盒）
  • 模型规模：VLM 骨干为 Qwen3.5-0.8B / Qwen3-VL-2B/4B/8B；动作头为 12 层、1024 宽 DiT + ResNet-152，4 步流匹配
  • 训练资源：论文未明确训练硬件，但延迟测量在 RTX 4090 上（480×640 分辨率）

06评估与结果

  • 模拟评估：异步 RoboTwin 基准，将推理延迟计入模拟时间；DASH 在 0.8B/2B/4B/8B 下成功率分别 65.5/69.1/69.5/65.9%，同步为 64.5/66.4/63.6/62.7%；DASH 控制率恒为 20Hz，同步从 9.7 降至 4.1 Hz
  • 真实机器人：DASH 自适应聚合器成功 23/24（95.8%），同步固定偏移聚合器 16/24（66.7%）
  • 消融实验：在 4B 下，冻结骨干 + ResNet 编码器（DASH）成功率 69.5%，冻结无编码器 55.0%，全微调无编码器 62.6%，证明新鲜视觉编码器是关键
