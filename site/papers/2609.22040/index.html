PRIME: Perception Feedback with Situational Memory Embeddings in VLA Models

2026-09-18 · 原文 · 翻译 · 2609.22040

论文指出当前 VLA（Vision-Language-Action）自动驾驶模型主要以前馈方式进行推理，感知模块对下游推理和导航目标不可见，只能盲目处理视觉输入。 论文提出 PRIME（Perception Feedback with Situational Memory Embeddings）机制，通过学习到的反馈路径将情境记忆注入感知查询，使感知编码具有意图感知（intent-driven）能力。 在 Bench2Drive 闭环基准上，PRIME 以极低参数开销（仅增加 29.7M 参数，占基础模型的 0.41%）实现了 SOTA 的 Driving Score 82.47（+4.73 vs ORION）和 Success Rate 60.00%（+5.38 个百分点）。

Card 03 核心贡献

核心贡献

  • 提出 Situational Memory（情境记忆）模块：一个可学习的、有状态的组件，通过跨注意力在 L 步时间窗口内聚合六种潜在反馈源，涵盖场景感知、推理、导航目标和预测行为。
  • 设计两种集成模块以适配不同结构和基数的反馈源：FiLMXAttn（基于 FiLM 特征调制 + LoRA 风格适配）和 Attention Pooling（基于学习提取查询的注意力池化）。
  • 提出轻量级 adapter-based 方法论：在冻结骨干网络上学习源特定的低开销反馈通路，能够独立评估每种反馈源而无需昂贵的端到端重训练。
  • 系统实证研究了跨阶段反馈在 VLA 驾驶模型中的作用，揭示推理状态（Reasoning State）反馈是唯一能独立提升闭环驾驶性能的单一反馈源。
  • 证明端到端反馈能够提升 VLA 自动驾驶性能，PRIME-Full 在 Bench2Drive 上达到 Think2Drive-trained VLA 中最高的 Driving Score。
Card 04 方法描述

方法描述

  • 基础架构为 ORION（QT-Former 感知编码器 → LLM 推理 → 轨迹规划器），PRIME 在其上增加反馈路径。
  • QT-Former Query Conditioning：在感知查询处理当前相机特征之前，先用情境记忆条件化查询（即查询初始化阶段注入反馈），使特征选择过程变得任务感知。
  • Situational Memory 包含六种反馈源，按态势感知三个层次组织：

- SA1（场景感知）：QT-Former Latents（Q）、Latent Motion Predictions（M）

- SA2（情境理解与导航意图）：Latent Reasoning Token（R）、Planning Command（P）

- SA3（未来预测）：Predicted Ego-State Queries（S）、Predicted Ego Trajectory（T）

  • FiLMXAttn：用于紧凑源（R、P、T），通过源特定跨注意力从记忆检索内容，再通过 FiLM 仿射变换调制查询。
  • Attention Pooling：用于高基数源（Q、M、S），使用一组固定数量的 Extraction Queries 通过跨注意力将整个记忆缓冲压缩成紧凑表示。
  • Feedback Integration：源表示经源嵌入增强、拼接后，查询通过跨注意力检索相关上下文，最终以可学习的门控残差连接（sigmoid 初始化为 0.1）注入。
  • 训练策略采用 Alignment → E2E 顺序：先对齐 QT-Former 与反馈机制（冻结 LLM/Planner），再端到端联合优化全部组件。

Card 06 评估与结果

评估与结果

  • 主要指标：Driving Score（DS）、Success Rate（SR），辅助指标为 NDS（感知质量）和 mL2（轨迹误差）
  • PRIME-Full（Alignment→E2E）达到 DS 82.47（+4.73 vs ORION）、SR 60.00%（+5.38 个百分点），为 Think2Drive-trained VLA 中最高 DS
  • 训练策略消融：仅 Alignment 或仅 E2E 均低于 ORION 基线（DS 59.74 / 70.96），证明先对齐后端到端的顺序至关重要
  • 单源 adapter 消融：仅 Reasoning Token（R）反馈提升闭环表现（DS 77.74→79.31），而感知（Q）和预测（S）反馈虽提升 NDS 却显著降低 DS/SR
  • 跨阶段多样性消融：仅感知侧反馈（PRIME-SA1）导致闭环表现大幅下降（DS 64.18），完整跨阶段反馈（PRIME-Full）最佳（DS 82.47），说明高层次情境信息对感知引导至关重要
  • 与 SOTA 对比：PRIME-Full 在合并（Merge）场景表现最好（SR 47.50%），而 GeRo 在超车、紧急制动和交通标志场景更强，两种方法分别在感知前端和规划端改进，具有互补潜力
