02论文概述

  • 提出 WareFly-VLA，一个面向智能仓库场景下无人机（UAV）语言引导人类搜索与跟踪的视觉-语言-动作（VLA）数据集与基准框架。
  • 数据集包含 507 条人类遥操作飞行片段 和 8,504 个非终止高分辨率 RGB 转移样本，每个样本均配有手工编写的目标工人外观描述和同步的 4-DoF 连续飞行控制指令。
  • 旨在填补现有 UAV VLA 研究中“外观语言描述 + 连续底层飞行动作 + 真实工业环境 + 人类示教轨迹”组合缺失的问题，并系统评估当前开源 VLA 模型在航空平台上的语言条件控制能力。

03核心贡献

  • 构建并公开 WareFly-VLA 数据集：在 NVIDIA Isaac Sim 照片级真实仓库环境中采集，包含同步的视觉观测、外观语言注释、4-DoF 连续动作与位姿标注。
  • 设计 人类示教数据采集管线：采用确定性的“搜索-决策-接近”遥操作策略，自然捕获目标搜索、目标重识别、恢复机动和持续跟踪等真实飞行行为。
  • 定义两项 空中具身基准任务：approach-and-locate 与 person-following，覆盖遮挡、远距离搜索、高度变化、视角改变和杂乱工业环境等挑战。
  • 建立 统一空中 VLA 基准：在无泄漏的 episode 级划分协议和两种控制频率（1 FPS / 10 FPS）下评估 SmolVLA、GR00T N1.7、π0、OpenVLA 四种代表架构。
  • 提供 开源研究平台 与 世界模型研究方向：发布数据集、基准配置、训练流程与评测工具，支持预测表示学习、动作条件潜在动力学、语言条件规划及 sim-to-real 迁移研究。

04方法描述

  • 仿真与采集：基于 Pegasus Simulator（NVIDIA Isaac Sim 扩展）构建大型工业仓库场景；模拟四旋翼搭载前视 RGB 相机，以 1920×1440 分辨率采集观测。
  • 人类遥操作策略：使用有限状态机策略，包括原地 360° 偏航扫描（Look Around）、货架扫描（Scan Shelves）、移动到开阔区（Move to Open）、目标接近（Approach Target）等状态，保证行为一致性与轨迹多样性。
  • 动作表示：连续 4-DoF 机体坐标系动作 $\mathbf{a}_t=(\Delta x,\Delta y,\Delta z,\Delta\psi)$，平移分量通过旋转矩阵将世界位姿变换至机体坐标系，偏航角使用 $[-\pi,\pi]$ 环绕处理。
  • 语言注释：由人工标注者从远程 UAV 操作员视角撰写基于可观测外观（服装、颜色、PPE）的指令，提供多种释义并经过二次审核。
  • 基准模型适配：将各模型原生动作空间映射到 4-DoF UAV 控制；采用官方预训练权重加 WareFly-VLA 训练集微调，无测试时增强；评测指标为逐维度 MAE 与 Pearson 相关系数。

05数据集与资源

  • 数据集规模：507 个片段，8,504 个非终止转移（1 FPS；train/val = 7,276 / 1,228），10 FPS 下为 73,979 / 13,371 转移。
  • 视觉与动作：分辨率 1920×1440；动作维度 4-DoF（$\Delta x_\ell,\Delta y_\ell,\Delta z,\Delta\psi$）；指令词汇量 448 tokens，平均指令长度 20.0±5.1 词，共 15 个任务动词族。
  • 难度标签：包含 find / close / far / height_change / obstructed / extended 等挑战标签，支持分轴评估。
  • 模型规模：OpenVLA-7B（7.6B 总参数，49.3M 可训练，LoRA）、GR00T N1.7（3.1B 总参数，1.62B 可训练）、π0/OpenPI（3.3B 总参数，145M 可训练，LoRA）、SmolVLA（450M 全参数微调）。
  • 训练资源配置：论文未明确给出 GPU 型号；1 FPS 下 π0 与 SmolVLA 使用 15,000 步 的匹配优化预算，10 FPS 下 OpenVLA 预计超 50 小时、GR00T 因发散被排除。

06评估与结果

  • 评测环境：WareFly-VLA 验证集（76 个 held-out 片段，N=1,228 帧），采用 无泄漏 episode 级划分；额外在 10 FPS 下评测 π0 与 SmolVLA。
  • 主要指标：逐动作维度的 MAE 与 Pearson 相关系数，并对比 constant-mean 基线。
  • 关键结果：

- π0/OpenPI 取得最佳预测误差（Δx MAE 0.413，Δy 0.244，Δz 0.003，Δψ 0.220）；SmolVLA 次之（Δx 0.468），两者均优于 constant-mean 基线。

- OpenVLA-7B 表现差于基线（Δx MAE 0.620 vs 0.590），GR00T N1.7 在微调中出现发散（MAE 高达 5.728/3.867），表明地面/人形 VLA 接口向空中平台迁移困难。

- 连续动作生成（flow matching / diffusion）整体优于离散动作 tokenization；单帧条件下仅前向通道（Δx）可被可靠学习。

- 论文还报告了泛化差距、部署视角（成本-精度前沿、推理延迟、开环 rollout 漂移）等分析，表明语言条件空中控制仍是远未解决的开放问题。
