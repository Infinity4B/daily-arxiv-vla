VeriVLA: Adaptive Test-Time Verification for Flow-Based VLAs with Latent World Models

2026-10-15 · 原文 · 翻译 · 2610.21985

Card 03 核心贡献

核心贡献

  • 提出 Latent World Model as Verifier：利用预训练潜在世界模型产生的动作条件潜在表示，联合预测未来潜在状态与 delta progress，避免像素重建，实现高效准确的候选动作块排序。
  • 对 Flow-based VLA 的策略随机性进行实证刻画，提出 Two-Axis Trigger：结合时间轴动作变化（within-chunk temporal variation）与跨样本方差（cross-sample variance），无需训练即可检测关键状态并减少推理开销。
  • 提供完整的训练、评估与真实机器人部署流水线，在真实任务中每触发决策仅增加 326 ms 延迟，平均完成分数从 50.8% 提升至 65.5%，优于 VLM-based verifier 和 pixel-level world model verifier。
  • 在 RoboTwin 2.0 和 LIBERO 仿真环境中取得一致提升，并验证了潜在动态建模与预测器预训练的重要性。
Card 04 方法描述

方法描述

  • 问题形式化：将动作块质量定义为 delta progress，即执行动作块后任务进展的变化量，目标是从多次采样中选出使 delta progress 最大的动作块。
  • Two-Axis Trigger：使用 k=2 个初始采样动作块，计算时间轴变化 T_temp 与跨样本方差 T_cross，归一化后转为百分位，取最大值 τ(s_t)=max(τ_temp, τ_cross)，超过阈值 τ₀ 时激活验证。
  • Latent World Model Verifier：基于 JEPA 框架，包含冻结的 V-JEPA 2 视觉编码器和动作条件自回归预测器；引入具体 embodiment 的状态/动作编码器，将动作块分为 M 个子块进行多步潜在 rollout。
  • Delta Progress 预测分支：引入任务特定可学习 query token，并通过注意力掩码防止任务信息泄漏到潜在动态建模中；训练联合优化 Huber 回归损失 与 pairwise ranking loss，视觉预测采用 L1 损失，并使用 teacher forcing 与 self-forcing。
  • 推理优化：累积应用 KV cache 复用、并行化候选采样与编码、PyTorch 预编译三层优化，降低实际部署延迟。
Card 05 数据集与资源

数据集与资源

  • 真实世界任务：AgileX PiperX 双臂机器人，配备一个前视 RealSense D455 和两个腕部 RealSense D435 相机；任务包括 pen insertion、pipetting、apple placement。
  • 仿真基准：RoboTwin 2.0（clean 与 clean2random 设置）和 LIBERO（40 个任务）。
  • 基础策略：真实世界与 LIBERO 使用 π₀.₅，RoboTwin 2.0 使用 Hy-Embodied-0.5-VLA，LIBERO 还使用 StarVLA-GR00T。
  • 训练数据：每个真实任务收集 50 个演示 episode 微调基础策略，另收集 50 个 rollout episode 并用 Robometer 标注；预测器在 DROID 数据集 23k 条轨迹上预训练。
  • 计算资源：验证器训练使用单张 H800 GPU，真实部署使用单张 RTX 4090 GPU；采样参数为触发器 k=2、验证器 K=10。
Card 06 评估与结果

评估与结果

  • 评估环境：三个真实世界精细操作任务、RoboTwin 2.0 仿真、LIBERO 仿真；每个方法在真实与仿真中均评估 50 次试验/任务。
  • 主要指标：Rank Loss、Huber Loss、Completion Score（真实任务）、Success Rate（仿真任务）、触发器的 Status AUC 与 Variance Correlation。
  • 真实世界结果：平均完成分数从基线的 50.8% 提升至 65.5%（+14.7 个百分点），优于 RoboMonkey（56.0%）和 GPC-RANK（52.8%）；每触发决策增加 326 ms 采样与验证延迟（不含 14 ms 触发开销）。
  • 仿真结果：RoboTwin 2.0 Clean 平均成功率从 66.4% 升至 73.6%，Clean2Random 从 62.8% 升至 69.6%，LIBERO 平均从 96.9% 升至 97.6%（LIBERO-10 从 92.4% 升至 94.0%）。
  • 消融实验：移除世界建模（w/o WM）后完成分数降至 55.2%，无预测器预训练（w/o pretrain）降至 59.5%，均低于完整 VeriVLA 的 65.5%。
  • 触发分析：Two-Axis Trigger 的 Status AUC 为 0.727、Variance Correlation 为 0.887，优于随机、DINO、ACE 等基线，且额外延迟仅 14 ms。
