Card 03 核心贡献

核心贡献

  • 提出 CrossFly 基准，包含 15K 条轨迹、20+ 个重建场景，覆盖 Indoor、Outdoor 和 Indoor↔Outdoor 三类任务。
  • 提出 Interaction Readiness Rate (IRR) 指标，量化终端导航状态是否满足下游物理交互所需的空间接近与视角对齐条件。
  • 提出 CrossFly-Agent，一种分层智能体，由高层 VLM 规划器与低层 VLA 策略组成，支持子任务预测、6-DoF 飞行和操作调用信号生成。
  • 对 5 个代表性空中 VLA 智能体进行系统基准测试，揭示跨环境任务比单环境任务更具挑战性。
  • 通过下游抓取案例研究，验证 IRR 与后续物理交互成功之间的相关性。
Card 04 方法描述

方法描述

  • 场景重建：从手持 3D 扫描仪采集的多视角 RGB 和点云重建异构环境，生成 3D Gaussian Splatting (3DGS) 和 mesh 表示。
  • 轨迹采集：标注起始、中间、终端和转向路径点，使用 Ego-Planner 生成无碰撞参考轨迹，经 PD 控制器 跟踪，在 Isaac Sim 中模拟 UAV 动力学并记录同步自中心 RGB 与 6-DoF 状态。
  • 任务分解：按路径点将轨迹分段，用 GPT-5.5 生成子任务描述，经人工验证后作为高层规划监督信号。
  • 仿真环境：基于 NVIDIA Isaac Sim 与 PhysX，支持 6-DoF 动作空间和多种空中操作平台（SO100-ARM 四旋翼、手形 UAV）。
  • 评估协议：设置 Indoor、Outdoor、Indoor↔Outdoor 三个固定套件；提出 IRR，定义交互就绪状态集合（距离 ≤ 0.626 m，相对偏航 ∈ [-50.5°, 47.5°]）。
  • CrossFly-Agent：高层 VLM 规划器根据指令、夹爪状态和视觉上下文预测子任务；低层 VLA 策略基于 QwenPi，结合子任务、全局指令和视觉上下文生成动作块及操作调用信号。
Card 05 数据集与资源

数据集与资源

  • 数据集 CrossFly 包含 15K 条轨迹、3M 帧、160+ 小时、120 km 飞行距离，覆盖 23 个重建场景。
  • 场景类型分布：Indoor↔Outdoor 占 51.2%，Indoor 占 23.7%，Outdoor 占 25.1%。
  • 指令由 4/6/8 个子任务组成，其中 6 个子任务最常见（46.5%），4 个占 38.8%，8 个占 14.8%。
  • 基线模型包括 π0、π0-FAST、OpenFly-Agent、OpenVLA-OFT、GR00T-N1.7；CrossFly-Agent 使用 QwenPi。

Card 06 评估与结果

评估与结果

  • 评估在 Isaac Sim 闭环仿真中进行，覆盖 Indoor、Outdoor、Indoor↔Outdoor 三类任务套件，并区分 seen 与 unseen 场景。
  • 主要指标包括 Success Rate (SR)、Navigation Error (NE)、Oracle Success Rate (OSR) 和 Interaction Readiness Rate (IRR)。
  • seen 场景下，CrossFly-Agent 在所有指标和套件上最佳：Indoor SR 23.5% / IRR 51.0%；Outdoor SR 25.5% / IRR 50.3%；Indoor↔Outdoor SR 19.8% / IRR 43.0%。
  • unseen 场景下，所有智能体性能下降，CrossFly-Agent 仍保持最佳；Indoor↔Outdoor 最高 SR 仅 9.7%，IRR 为 29.3%。
  • 诊断实验表明，在匹配轨迹长度、子任务数和指令长度后，Indoor↔Outdoor 任务仍差于单域任务，说明跨环境转换本身带来额外挑战。
  • 抓取案例研究显示，满足 IRR 条件的终端状态可成功抓取，违反则失败；IRR 阈值通过下游抓取结果最大似然拟合获得，d_max=0.626 m，ψ ∈ [-50.5°, 47.5°]。
