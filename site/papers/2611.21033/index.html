POKE: Probe Offline, Keep Efficiently for Vision-Language-Action Models

02论文概述

  • 论文研究视觉-语言-动作（VLA）模型中的视觉 token 剪枝问题：现有基于注意力分数的剪枝方法无法直接衡量 token 对预测动作的影响
  • 论文定义“动作敏感度”作为 token 重要性度量，并指出在线计算该分数的两大障碍：在全图（未剪枝）上评分需要额外的前向/反向传播，导致推理过慢；在已剪枝图上评分则产生“评分图锁定”偏差——被移除的 token 失去直接计算路径而倾向获得低分，难以重新被选中
  • 提出 POKE 方法：离线计算全图动作敏感度标签并蒸馏到轻量学生模型，实现无反向传播、不依赖历史掩码的高效剪枝

03核心贡献

  • 动作敏感度度量：提出基于动作的一阶 token 重要性度量，通过共享随机探针单次反向传播估计全部 token 的敏感度，并给出配对排名行为的精确分析
  • 评分图锁定现象：通过受控干预和固定观测回放实验证明，剪枝图上的分数（包括梯度和注意力历史）即使在无反馈回路时也会偏向已保留的 token（随机掩码下重选率 59%，而随机期望仅 6%）
  • POKE 框架：离线全图敏感度蒸馏训练紧凑选择器（<0.3M 参数），推理时无需反向传播或历史掩码，在并行回归、流匹配和自回归策略上均优于注意力、多样性和蒸馏类基线
  • score 引导的多样性选择（MMDP）：在高分候选集内进行多样性选择，兼顾敏感度过滤与冗余降低

04方法描述

  • 动作敏感度定义：将视觉 token 替换为其相机均值表示时，预测动作的一阶变化幅度 sᵢ = ‖Jᵢδᵢ‖₂，其中 Jᵢ 为动作对 token 的雅可比矩阵
  • 单探针估计：从单位球采样共享方向 v，对 v^⊤a_θ 做一次反向传播即可获得所有 token 的无偏估计（避免 OpenVLA-OFT 的 56 次或 π₀.₅ 的 70 次反向传播），单探针分数与精确敏感度的相机内 Spearman 相关达 0.80
  • 全图教师：在策略微调演示观测上离线计算全图敏感度标签（策略保持冻结，标注每套数据不足 1 GPU 小时）；对流策略（π₀.₅）固定初始噪声并对最终动作块求导
  • 轻量学生：基于当前视觉 token、语言和状态上下文，单次前向传播预测分数，无需反向传播和历史掩码
  • 推理时选择：支持 top-k 排序或多样性选择（MMDP）两种方式保留 token

05数据集与资源

  • 基准环境：四个 LIBERO 套件（Spatial、Object、Goal、Long）及 LIBERO-Plus（观测偏移鲁棒性测试）、SimplerEnv
  • 评测策略：OpenVLA-OFT（并行回归，动作块 56 维）、π₀.₅（流匹配，70 维）、OpenVLA（自回归）
  • 学生模型规模：不到 0.3M 参数
  • 训练成本：教师标注每套环境不足 1 GPU 小时
  • 剪枝预算：512 个视觉 token 中保留 32 个

06评估与结果

  • 评估设置：LIBERO 闭环仿真，对比 Vanilla、Random、FastV、DivPrune、VLA-Cache、VLA-Pruner、SpecPrune-VLA、MAP 等基线，指标为任务成功率与相对加速比
  • OpenVLA-OFT 上 B=32：POKE（MMDP）平均成功率 95.15%，加速 1.85×，超过 VLA-Pruner（89.25%）5.90 个百分点，接近未剪枝 Vanilla 的 96.70%
  • π₀.₅ 上 B=32：POKE 平均成功率 90.80%，加速 1.26×，超过 VLA-Pruner（75.05%）约 15.75 个百分点
  • 鲁棒性：在 LIBERO-Plus 观测偏移下优势进一步扩大
  • 消融验证：以注意力标签替代动作敏感度标签进行蒸馏，在全部 8 种测试组合中均降低成功率，验证了动作敏感度监督的关键作用
  • 锁定偏差量化：剪枝图评分在随机掩码下重选 59% 的掩码 token（随机期望 6%），全图评分为 77% 的分数分配给掩码外 token，证明 POKE 离线全图蒸馏的必要性
